## 二、逐词说文解字

### 1. flight /flaɪt/ n. (尤指乘飞机的) 航程
- **词根·渊源**：古英语 **flyht**（飞行的动作）← 原始日耳曼语 *flugti-*，与 fly（飞）同源；本义“飞行的动作/能力”，后引申为“一次飞行、航班、航程”。
- **同根词**：fly（古英语 fleogan 飞→飞行）、flying（fly + **-ing** 动名词/形容词：飞行的）、flyer（fly + **-er** 人/物：飞行者、传单）。
- **前缀·后缀**：名词后缀 **-t**（例：weight, gift）；无前缀。
- **同义·反义**：同义 journey（旅程）, trip（旅行）；反义 无。
- **变形**：名词 → 复数：flights；形容词派生 → flighty adj. 轻浮的（由“飞行”引申为“飘忽不定”）。

### 2. schedule /ˈskɛʤʊl/ n. 日程安排
- **词根·渊源**：拉丁 **schedula**（小纸片）← 希腊 *skhedē*（纸草叶、便条）→ 古法语 *cedule* → 中古英语 *sedule*；本义“写有小字的小纸条”，引申为“列有时间安排的清单→日程安排”。
- **同根词**：scheduled（schedule + **-ed** 已安排的：预定的）、scheduling（schedule + **-ing** 动名词：日程安排工作）、reschedule（**re-** 再 + schedule = 重新安排）。
- **前缀·后缀**：名词后缀 **-ule**（指小，例：formula, capsule）；动词化前缀 **re-**（例：rebuild, rewrite）。
- **同义·反义**：同义 timetable（时间表）, agenda（议程）；反义 无。
- **变形**：名词 → 复数：schedules；动词派生 → schedule v. 安排；scheduled adj. 预定的。

### 3. everywhere /ˈɛvriˌwɛr/ adv. 到处；各个地方
- **词根·渊源**：古英语 **æfre**（永远）+ **hwær**（何处）→ 中古英语 *everihwer*；由 every（每一）+ where（何处）复合而成，本义“每一个地方”，即“到处”。
- **同根词**：everywhere 的构成词：every（古英语 æfre 永远 + ǣlc 每个→每一个）、where（古英语 hwær 何处→哪里）、everywhere 之外：anywhere（any 任何 + where 何处 = 任何地方）、somewhere（some 某 + where = 某处）、nowhere（no 无 + where = 无处）。
- **前缀·后缀**：无前后缀（复合词：every + where）。
- **同义·反义**：同义 all over（到处）, here and there（各处）；反义 nowhere（无处）。
- **变形**：副词 → 无比较级（地点副词，不作比较）；无词性派生。

### 4. challenge /ˈʧælənʤ/ v. 向(某人) 挑战
- **词根·渊源**：拉丁 **calumnia**（诬告、诽谤）→ 古法语 *chalenge*（指控、争辩）→ 中古英语 *chalenge*；本义“提出指控/质疑”，引申为“向对方提出质疑或竞赛要求→挑战”。
- **同根词**：challenger（challenge + **-er** 人：挑战者）、challenging（challenge + **-ing** 形容词：有挑战性的）、challenged（challenge + **-ed** 被挑战的：受到挑战的）。
- **前缀·后缀**：名词后缀 **-enge**（源自古法语，例：revenge, strange）；无前缀。
- **同义·反义**：同义 dare（激将、挑战）, defy（公然反抗）；反义 accept（接受）, yield（屈服）。
- **变形**：动词 → 第三人称单数：challenges；过去式：challenged；过去分词：challenged；现在分词：challenging；名词派生 → challenge n. 挑战；challenger n. 挑战者；形容词派生 → challenging adj. 有挑战性的。

### 5. prize /praɪz/ n. 奖赏；奖励
- **词根·渊源**：拉丁 **pretium**（价值、价格）→ 古法语 *pris*（价值、奖赏）→ 中古英语 *prise*；本义“有价值之物”，引申为“因优胜而获得的奖赏”。
- **同根词**：price（拉丁 pretium 价值→价格）、praise（拉丁 pretium 价值→古法语 preisier 估价→称赞）、precious（pretium 价值 + **-ous** …的：珍贵的）、appreciate（**ap-** 向 + pretium 价值 + **-ate** 动词：赏识、感激）。
- **前缀·后缀**：无前后缀（单纯词，源自拉丁 pretium）。
- **同义·反义**：同义 award（奖品）, reward（奖赏）；反义 penalty（处罚）, punishment（惩罚）。
- **变形**：名词 → 复数：prizes；动词派生 → prize v. 珍视；形容词派生 → prized adj. 珍贵的。

### 6. promise /ˈprɑməs/ v. 承诺；保证
- **词根·渊源**：拉丁 **promittere**（向前送出、许诺）= **pro-**（向前）+ **mittere**（送）→ 古法语 *promesse*；本义“把话向前送出→许下诺言”，即“承诺”。
- **同根词**：promising（promise + **-ing** 形容词：有前途的）、promissory（拉丁 promissum 许诺 + **-ory** …的：承诺的）、mission（mittere 送 + **-ion** 名词：派遣、使命）、submit（**sub-** 向下 + mittere 送 = 呈交、屈服）、transmit（**trans-** 穿过 + mittere 送 = 传送）。
- **前缀·后缀**：前缀 **pro-**（向前，例：progress, protect）；词根 **mit-**（送，例：admit, permit）。
- **同义·反义**：同义 pledge（保证）, vow（誓言）；反义 break（违背）, deny（否认）。
- **变形**：动词 → 第三人称单数：promises；过去式：promised；过去分词：promised；现在分词：promising；名词派生 → promise n. 诺言；形容词派生 → promising adj. 有前途的。

### 7. chessboard /ˈʧɛsˌbɔrd/ n. 国际象棋棋盘
- **词根·渊源**：chess（古法语 eschecs ← 拉丁 scacchi ← 波斯 shāh“国王”，本指“国王的游戏”）+ board（古英语 bord 木板）；复合词，本义“下棋用的木板”，即“棋盘”。
- **同根词**：chess（波斯 shāh 国王→国际象棋）、board（古英语 bord 木板→板、董事会）、check（波斯 shāh 国王→将军→检查）、checkmate（波斯 shāh māt 国王被困→将死）、blackboard（black 黑 + board 板 = 黑板）、keyboard（key 键 + board 板 = 键盘）。
- **前缀·后缀**：无前后缀（复合词：chess + board）。
- **同义·反义**：同义 无；反义 无。
- **变形**：名词 → 复数：chessboards；无词性派生。

### 8. silver /ˈsɪlvər/ n. 银
- **词根·渊源**：古英语 **seolfor**（银）← 原始日耳曼语 *silubra-*，来源存疑（一说与古斯拉夫语 serebro 同源）；本义即“银这种金属”。
- **同根词**：silvery（silver + **-y** …的：银色的）、silversmith（silver + smith 工匠 = 银匠）、silverware（silver + ware 器皿 = 银器）。
- **前缀·后缀**：名词后缀 **-er**（源自古英语，例：finger, water）；无前缀。
- **同义·反义**：同义 无（金属专名）；反义 无。
- **变形**：名词 → 复数：silvers（作“银”义时不可数）；形容词派生 → silvery adj. 银色的；silver adj. 银制的（无比较级，物质形容词）。

### 9. reply /rɪˈplaɪ/ v. 回复；答复
- **词根·渊源**：拉丁 **replicare**（折回、再折）= **re-**（回）+ **plicare**（折）→ 古法语 *replier*（折回）→ 中古英语 *reply*；本义“把话折回去→回话”，即“答复”。
- **同根词**：replica（re- 再 + plicare 折 = 再折一份→复制品）、replicate（re- 再 + plicare 折 + **-ate** 动词：复制）、complicated（**com-** 一起 + plicare 折 + **-ed**：折叠在一起的→复杂的）、duplicate（**du-** 二 + plicare 折 + **-ate**：折成两份→复制）、explicit（**ex-** 出 + plicare 折 = 折开展开→明确的）。
- **前缀·后缀**：前缀 **re-**（回、再，例：return, repeat）；词根 **plic-**（折，例：apply, multiply）。
- **同义·反义**：同义 answer（回答）, respond（回应）；反义 ask（问）, question（提问）。
- **变形**：动词 → 第三人称单数：replies；过去式：replied；过去分词：replied；现在分词：replying；名词派生 → reply n. 答复。

### 10. hesitation /ˌhɛzəˈteɪʃən/ n. 犹豫
- **词根·渊源**：拉丁 **haesitare**（卡住、踌躇）← **haerere**（粘住）→ 拉丁 *haesitatio* → 法语 *hésitation*；本义“像被粘住一样动不了→迟疑不决”，即“犹豫”。
- **同根词**：hesitate（拉丁 haesitare 卡住→犹豫）、hesitant（hesit- + **-ant** 形容词：犹豫的）、hesitating（hesitate + **-ing** 形容词：迟疑的）、adhere（**ad-** 向 + haerere 粘 = 粘附、坚持）、coherent（**co-** 一起 + haerere 粘 + **-ent**：粘在一起的→连贯的）。
- **前缀·后缀**：名词后缀 **-ation**（例：information, education）；无前缀。
- **同义·反义**：同义 uncertainty（不确定）, pause（停顿）；反义 decision（决定）, certainty（确定）。
- **变形**：名词 → 复数：hesitations；动词派生 → hesitate v. 犹豫；形容词派生 → hesitant adj. 犹豫的；副词派生 → hesitantly adv. 犹豫地。

### 11. wonder /ˈwəndər/ v. 想知道；琢磨
- **词根·渊源**：古英语 **wundor**（奇迹、惊奇之物）← 原始日耳曼语 *wundran*；本义“令人惊奇的事”，动词义“感到惊奇→想知道”，即“琢磨”。
- **同根词**：wonderful（wonder + **-ful** 充满…的：奇妙的）、wondering（wonder + **-ing** 形容词：感到惊奇的）、wonderment（wonder + **-ment** 名词：惊奇）、wondrous（wonder + **-ous** …的：奇异的）。
- **前缀·后缀**：名词后缀 **-er**（源自古英语，例：finger, thunder）；无前缀。
- **同义·反义**：同义 ponder（思索）, question（疑问）；反义 know（知道）, understand（理解）。
- **变形**：动词 → 第三人称单数：wonders；过去式：wondered；过去分词：wondered；现在分词：wondering；名词派生 → wonder n. 惊奇、奇迹；形容词派生 → wonderful adj. 奇妙的；副词派生 → wonderfully adv. 奇妙地。

### 12. agree /əˈgri/ v. 同意；赞成
- **词根·渊源**：古法语 **agreer**（使高兴、使合意）= **a-**（向）+ **gre**（拉丁 gratus 令人愉快的）；本义“使合心意→意见相合”，即“同意”。
- **同根词**：agreement（agree + **-ment** 名词：协议）、agreeable（agree + **-able** 可…的：令人愉快的）、disagree（**dis-** 不 + agree = 不同意）、grateful（拉丁 gratus 令人愉快的 + **-ful**：感激的）、gratitude（gratus + **-itude** 名词：感激）。
- **前缀·后缀**：前缀 **a-**（向，例：aloud, awake）、**dis-**（不，例：dislike, disagree）；词根 **grat-**（令人愉快的，例：grateful, congratulate）。
- **同义·反义**：同义 consent（同意）, approve（赞成）；反义 disagree（不同意）, object（反对）。
- **变形**：动词 → 第三人称单数：agrees；过去式：agreed；过去分词：agreed；现在分词：agreeing；名词派生 → agreement n. 协议；形容词派生 → agreeable adj. 令人愉快的。

### 13. percent /pərˈsɛnt/ n. 百分之……
- **词根·渊源**：拉丁 **per centum**（按一百计）= **per**（每）+ **centum**（一百）→ 意大利语 *per cento* → 英语 percent；本义“每一百中”，即“百分之……”。
- **同根词**：century（拉丁 centum 一百 + **-ury** 名词：一百年）、cent（拉丁 centum 一百→分，一元的百分之一）、centimeter（centi- 百分之一 + meter 米 = 厘米）、centipede（centi- 百 + pede 足 = 百足虫→蜈蚣）、percentage（percent + **-age** 名词：百分比）。
- **前缀·后缀**：前缀 **per-**（每，例：per capita, perfect）；词根 **cent-**（百，例：century, cent）。
- **同义·反义**：同义 percentage（百分比）；反义 无。
- **变形**：名词 → 复数：percents；形容词派生 → percent adj. 百分之……的（无比较级）。

### 14. currently /ˈkərəntli/ adv. 目前；当前
- **词根·渊源**：拉丁 **currere**（跑）→ 拉丁 *currens*（跑着的）→ 古法语 *corant* → 英语 current（流动的、当前的）+ **-ly**；本义“像水一样流动着的→正在发生的”，即“目前”。
- **同根词**：current（currere 跑 + **-ent** 形容词：流动的→当前的）、currency（current + **-cy** 名词：流通→货币）、occur（**oc-** 向 + currere 跑 = 跑到眼前→发生）、recur（**re-** 再 + currere 跑 = 再跑回来→复发）、course（拉丁 cursus 跑→路线、课程）。
- **前缀·后缀**：副词后缀 **-ly**（例：quickly, happily）；前缀 **oc-**（向，例：occupy）、**re-**（再，例：return）。
- **同义·反义**：同义 presently（目前）, now（现在）；反义 formerly（以前）, previously（先前）。
- **变形**：副词 → 无比较级（时间副词，不作比较）；形容词派生 → current adj. 当前的；名词派生 → currency n. 货币。

### 15. check /ʧɛk/ v. 检查；核查
- **词根·渊源**：古法语 **eschec**（将军、攻击）← 波斯 **shāh**（国王）；本义“国际象棋中‘将军’”，引申为“突然制止→核对、检查”。
- **同根词**：checker（check + **-er** 人/物：检查员、方格）、checkout（check + out 出 = 结账离开）、checkpoint（check + point 点 = 检查站）、chess（波斯 shāh 国王→国际象棋）、checkmate（波斯 shāh māt 国王被困→将死）。
- **前缀·后缀**：名词后缀 **-er**（例：teacher, worker）；无前缀。
- **同义·反义**：同义 examine（检查）, inspect（检验）；反义 ignore（忽视）, overlook（忽略）。
- **变形**：动词 → 第三人称单数：checks；过去式：checked；过去分词：checked；现在分词：checking；名词派生 → check n. 检查、支票；checker n. 检查员。

### 16. budget /ˈbəʤɪt/ n. 预算
- **词根·渊源**：古法语 **bougette**（小皮包）← 拉丁 **bulga**（皮袋）→ 中古英语 *bowgette*；本义“装钱的小皮包”，引申为“包里的钱款计划→预算”。
- **同根词**：budgetary（budget + **-ary** …的：预算的）、budgeted（budget + **-ed** 已编预算的：列入预算的）、budgeting（budget + **-ing** 动名词：预算编制）、bulge（拉丁 bulga 皮袋→鼓起的袋子→凸起）。
- **前缀·后缀**：名词后缀 **-et**（指小，例：pocket, ticket）；无前缀。
- **同义·反义**：同义 plan（计划）, allowance（拨款）；反义 无。
- **变形**：名词 → 复数：budgets；动词派生 → budget v. 编预算；形容词派生 → budgetary adj. 预算的。

### 17. province /ˈprɑvɪns/ n. 省份
- **词根·渊源**：拉丁 **provincia**（管辖区域、行省）→ 古法语 *province*；本义“罗马官员管辖的地区”，引申为“国家下辖的行政区→省份”。
- **同根词**：provincial（province + **-ial** …的：省的、地方的）、provincially（provincial + **-ly** 副词：地方上）、provincialism（provincial + **-ism** 名词：地方主义）。
- **前缀·后缀**：名词后缀 **-ince**（源自古法语，例：since, convince）；无前缀。

- **变形**：名词 → 复数：provinces；形容词派生 → provincial adj. 省的、地方的；副词派生 → provincially adv. 地方上。

### 18. sharply /ˈʃɑrpli/ adv. 急剧地；突然大幅度地
- **词根·渊源**：古英语 **scearp**（锋利的、尖锐的）← 原始日耳曼语 *skarpaz* → 英语 sharp（锋利的）+ **-ly**；本义“像刀刃一样锋利地”，引申为“急剧地、大幅度地”。
- **同根词**：sharp（古英语 scearp 锋利的→尖锐的）、sharpen（sharp + **-en** 使…：削尖）、sharpness（sharp + **-ness** 名词：锋利）、sharpener（sharpen + **-er** 物：削具）。
- **前缀·后缀**：副词后缀 **-ly**（例：quickly, badly）；动词后缀 **-en**（例：widen, deepen）。
- **同义·反义**：同义 suddenly（突然地）, steeply（急剧地）；反义 gently（平缓地）, gradually（逐渐地）。
- **变形**：副词 → 比较级：more sharply；最高级：most sharply；形容词派生 → sharp adj. 锋利的、急剧的；动词派生 → sharpen v. 削尖；名词派生 → sharpness n. 锋利。

### 19. count /kaʊnt/ v. 计算(或清点)总数
- **词根·渊源**：拉丁 **computare**（计算，com- 一起 + putare 估算）→ 古法语 *conter*（计算、叙述）→ 英语 count；本义“逐一清点”，引申为“计算总数、算作”。
- **同根词**：account（**ac-** 加强 + count 计算 = 算清楚→账户、解释）、discount（**dis-** 去除 + count 计算 = 从总数中扣除→折扣）、counter（count 计算 + **-er** 计数的人/物→柜台）、compute（com- 一起 + putare 估算 = 计算）、computer（compute 计算 + **-er** 物→计算机）、recount（**re-** 再 + count 数 = 再数一遍→重新计数、讲述）。
- **前缀·后缀**：前缀 **ac-**（例：accept, achieve）、**dis-**（例：discover, dislike）；名词后缀 **-er**（例：teacher, worker）。
- **同义·反义**：同义 calculate（计算）, number（数数）；反义 无。
- **变形**：动词 → 第三人称单数：counts；过去式：counted；过去分词：counted；现在分词：counting；名词派生 → count n. 计数；counter n. 计数器；形容词派生 → countable adj. 可数的；uncountable adj. 不可数的。

### 20. system /ˈsɪstəm/ n. 系统
- **词根·渊源**：希腊 **syn-**（一起）+ **histanai**（站立）→ 希腊 *systema*（组合整体）→ 晚期拉丁 *systema* → 法语 *système* → 英语 system；本义“各部分站在一起构成的整体”，引申为“系统、体系”。
- **同根词**：systematic（system 系统 + **-atic** …的→系统的）、systematically（systematic 系统的 + **-ally** 副词后缀→系统地）、ecosystem（**eco-** 生态 + system 系统 = 生态系统）、systematize（systematic 系统的 + **-ize** 使…化→使系统化）。
- **前缀·后缀**：前缀 **syn-**（例：synchronize, synonym）；名词后缀 **-em**（例：problem, poem）；形容词后缀 **-atic**（例：problematic, automatic）。
- **同义·反义**：同义 organization（组织）, structure（结构）；反义 chaos（混乱）。
- **变形**：名词 → 复数：systems；形容词派生 → systematic adj. 系统的；副词派生 → systematically adv. 系统地。

### 21. symbol /ˈsɪmbəl/ n. 符号；记号
- **词根·渊源**：希腊 **syn-**（一起）+ **ballein**（投掷）→ 希腊 *symbolon*（投在一起的对证物、标记）→ 拉丁 *symbolum* → 英语 symbol；本义“把两半信物投合以作凭证”，引申为“代表某事物的符号”。
- **同根词**：symbolic（symbol 符号 + **-ic** …的→象征的）、symbolize（symbol 符号 + **-ize** 使…化→象征）、symbolism（symbol 符号 + **-ism** 主义/体系→象征主义）、symptom（希腊 syn- 一起 + piptein 落下 = 一起出现→症状，与 symbol 同源近亲）。
- **前缀·后缀**：前缀 **syn-**（例：synchronize, synonym）；名词后缀 **-bol**（例：symbol 本身，同类较少）；形容词后缀 **-ic**（例：basic, historic）。
- **同义·反义**：同义 sign（标志）, mark（记号）；反义 无。
- **变形**：名词 → 复数：symbols；形容词派生 → symbolic adj. 象征的；动词派生 → symbolize v. 象征；副词派生 → symbolically adv. 象征性地。

### 22. represent /ˌrɛprɪˈzɛnt/ v. 代表
- **词根·渊源**：拉丁 **re-**（再）+ **praesentare**（使呈现，来自 praesens 在场的）→ 古法语 *representer* → 英语 represent；本义“使再次呈现于眼前”，引申为“代表、象征”。
- **同根词**：representation（represent 代表 + **-ation** 名词后缀→代表、表现）、representative（represent 代表 + **-ative** …的/人→代表的、代表）、present（**pre-** 在前 + sent 存在 = 呈现在前→现在的、呈现）、presentation（present 呈现 + **-ation** 名词后缀→展示）、presently（present 现在的 + **-ly** 副词后缀→目前）。
- **前缀·后缀**：前缀 **re-**（例：return, rebuild）、**pre-**（例：prepare, predict）；名词后缀 **-ation**（例：information, education）；形容词后缀 **-ative**（例：creative, active）。
- **同义·反义**：同义 stand for（代表）, symbolize（象征）；反义 无。
- **变形**：动词 → 第三人称单数：represents；过去式：represented；过去分词：represented；现在分词：representing；名词派生 → representation n. 代表；representative n. 代表；形容词派生 → representative adj. 代表的。

### 23. exactly /ɪgˈzæktli/ adv. 准确地；确切地
- **词根·渊源**：拉丁 **ex-**（出）+ **agere**（驱动、做）→ 拉丁 *exactus*（精确的，本义“驱出、量准的”）→ 英语 exact（精确的）+ **-ly** → exactly；本义“按量准做地”，引申为“准确地、确切地”。
- **同根词**：exact（ex- 出 + act 驱动 = 量得准的→精确的）、exactness（exact 精确的 + **-ness** 名词后缀→精确性）、exaction（exact 强取 + **-ion** 名词后缀→强征）、act（agere 驱动→行动）、action（act 行动 + **-ion** 名词后缀→行动）、agent（agere 驱动 + **-ent** 人→代理人）。
- **前缀·后缀**：前缀 **ex-**（例：exit, export）；副词后缀 **-ly**（例：quickly, happily）；名词后缀 **-ness**（例：kindness, happiness）。
- **同义·反义**：同义 precisely（精确地）, accurately（准确地）；反义 roughly（粗略地）, approximately（大约）。
- **变形**：副词 → 比较级：more exactly；最高级：most exactly；形容词派生 → exact adj. 精确的；名词派生 → exactness n. 精确性。
