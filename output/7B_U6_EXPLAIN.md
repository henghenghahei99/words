## 二、逐词说文解字

### 1. battery /ˈbætəri/ n. 电池
- **词根·渊源**：拉丁 **battuere**（打）→ 古法语 *batterie*（打击）→ 英语 battery，本义“连续打击”，后引申为“一组同类事物”，再特指“电池组”。
- **同根词**：battle（batt 打 + **-le** 反复动作 = 反复打→战斗）、battalion（batt 打 + **-alion** 名词后缀 = 战斗单位→营）、batter（batt 打 + **-er** 反复动作 = 连续打→猛击）、combat（**com-** 共同 + bat 打 = 一起打→战斗）、debate（**de-** 向下 + bat 打 = 打下去→辩论）。
- **前缀·后缀**：名词后缀 **-ery**（例：bakery, grocery）；前缀 **com-**（例：combine）、**de-**（例：defeat）。
- **同义·反义**：同义 cell（电池）, power pack（电源组）；反义 无。
- **变形**：名词 → 复数：batteries；形容词派生 → battery-powered adj. 电池驱动的。

### 2. electricity /ɪˌlekˈtrɪsəti/ n. 电；电能
- **词根·渊源**：希腊 **ēlektron**（琥珀）→ 拉丁 *electrum* → 英语 electric + **-ity**，本义“摩擦琥珀产生的现象”，后指“电”。
- **同根词**：electric（electr 电 + **-ic** …的：电的）、electrical（electric + **-al** …的：与电有关的）、electrician（electric + **-ian** 人：电工）、electrify（electr 电 + **-ify** 使…化：使 electrify→使通电）、electron（electr 电 + **-on** 粒子：电子）。
- **前缀·后缀**：名词后缀 **-ity**（例：activity, ability）；形容词后缀 **-ic**（例：basic, magic）。
- **同义·反义**：同义 power（电力）, current（电流）；反义 无。
- **变形**：名词 → 复数：不可数；形容词派生 → electric adj. 电的；electrical adj. 与电有关的；副词派生 → electrically adv. 用电地。

### 3. switch-off /ˈswɪtʃ ˈɒf/ adj. 关闭（电灯、机器等）的
- **词根·渊源**：中古荷兰语 *swijch*（细枝）→ 英语 switch（开关）+ **off**（离开），本义“用细枝抽打→拨动开关→关闭”。
- **同根词**：switch（swijch 细枝 → 开关：开关）、switchable（switch + **-able** 可…的：可切换的）、switchback（switch + back 回 = 来回折返→之字形路）、switchboard（switch + board 板 = 开关板→配电盘）、switchover（switch + over 越过 = 转换）。
- **前缀·后缀**：副词小品词 **off**（例：turnoff, takeoff）；无前缀。
- **同义·反义**：同义 turned-off（关闭的）, powered-down（断电的）；反义 switched-on（开启的）, powered-up（通电的）。
- **变形**：形容词 → 无比较级（关系形容词，不作比较）；名词派生 → switch-off n. 关闭。

### 4. task /tɑːsk/ n. 任务；活动
- **词根·渊源**：拉丁 **taxare**（评估）→ 古法语 *tasque*（税、义务）→ 英语 task，本义“征收的税→分派的工作→任务”。
- **同根词**：tax（tax 评估 → 税：税）、taxation（tax 税 + **-ation** 名词后缀：征税）、taxing（tax 评估 + **-ing** …的：费力的）、taxi（tax 评估 → 计程车：出租车）、surtax（**sur-** 超过 + tax 税 = 附加税）。
- **前缀·后缀**：无前后缀（单纯词）；相关前缀 **sur-**（例：surface）。
- **同义·反义**：同义 job（工作）, assignment（任务）；反义 leisure（闲暇）, rest（休息）。
- **变形**：名词 → 复数：tasks；动词派生 → task v. 派给任务；形容词派生 → tasking adj. 费力的。

### 5. while /waɪl/ n. 一段时间；一会儿
- **词根·渊源**：古英语 **hwīl**（一段时间）→ 中古英语 *while* → 英语 while，本义“一段时间”，引申为连词“当…时”。
- **同根词**：whilst（while + **-st** 副词后缀：当…时）、meanwhile（**mean-** 中间 + while 时间 = 其间）、awhile（**a-** 在 + while 时间 = 片刻）、worthwhile（worth 值得 + while 时间 = 值得的）、whiles（while + **-s** 副词后缀：有时）。
- **前缀·后缀**：前缀 **a-**（例：away, asleep）、**mean-**（例：meantime）；无后缀。
- **同义·反义**：同义 time（时间）, period（一段时间）；反义 无。
- **变形**：名词 → 复数：whiles；连词派生 → while conj. 当…时；副词派生 → awhile adv. 片刻。

### 6. tablet /ˈtæblət/ n. 平板电脑
- **词根·渊源**：拉丁 **tabula**（板、牌）→ 古法语 *tablete*（小板）→ 英语 tablet，本义“小板→药片→平板电脑”。
- **同根词**：table（tabula 板 → 桌子：桌子）、tabular（tabula 板 + **-ar** …的：表格的）、tabulate（tabula 板 + **-ate** 动词后缀：制表）、tabloid（tablet + **-oid** 像…的：小报）、tableau（tabula 板 → 画面：场景）。
- **前缀·后缀**：名词后缀 **-et**（例：packet, pocket）；无前缀。
- **同义·反义**：同义 pad（平板）, slate（平板）；反义 无。
- **变形**：名词 → 复数：tablets；形容词派生 → tablet-like adj. 平板状的。

### 7. fridge /frɪdʒ/ n. 冰箱
- **词根·渊源**：拉丁 **frigus**（冷）→ 英语 refrigerator 的缩略形式 fridge，本义“制冷设备→冰箱”。
- **同根词**：refrigerator（**re-** 再 + friger 冷 + **-ator** 物 = 使冷之物→冰箱）、refrigerate（**re-** 再 + friger 冷 + **-ate** 动词后缀：冷藏）、refrigeration（refrigerate + **-ion** 名词后缀：冷藏）、frigid（frig 冷 + **-id** …的：寒冷的）、frigidity（frigid + **-ity** 名词后缀：寒冷）。
- **前缀·后缀**：缩略后缀 **-dge**（例：bridge, edge）；前缀 **re-**（例：return）。
- **同义·反义**：同义 refrigerator（冰箱）, cooler（冷却器）；反义 heater（加热器）, oven（烤箱）。
- **变形**：名词 → 复数：fridges；形容词派生 → fridge-free adj. 无冰箱的。

### 8. yogurt /ˈjɒɡət/ n. 酸奶
- **词根·渊源**：土耳其语 **yoğurt**（凝乳）→ 英语 yogurt，本义“发酵凝乳→酸奶”。
- **同根词**：yoghurt（yogurt 的变体拼写：酸奶）、yogurt-maker（yogurt + maker 制作者 = 酸奶机）、yogurt-covered（yogurt + covered 覆盖的 = 裹酸奶的）、yogurt-like（yogurt + like 像…的 = 酸奶状的）、yogurt drink（yogurt + drink 饮料 = 酸奶饮料）。
- **前缀·后缀**：无前后缀（借词）。
- **同义·反义**：同义 curd（凝乳）, fermented milk（发酵奶）；反义 无。
- **变形**：名词 → 复数：yogurts（作“酸奶”义时不可数）；形容词派生 → yogurt-like adj. 酸奶状的。

### 9. apartment /əˈpɑːtmənt/ n. 公寓套房
- **词根·渊源**：拉丁 **pars / part-**（部分）→ 意大利语 *appartamento*（分开的房间）→ 法语 *appartement* → 英语 apartment，本义“分开的一套房间→公寓”。
- **同根词**：part（part 部分 → 部分：部分）、partial（part 部分 + **-ial** …的：部分的）、particle（part 部分 + **-icle** 小 = 小部分→微粒）、partner（part 部分 + **-ner** 人 = 分享者→伙伴）、depart（**de-** 离开 + part 部分 = 分开→离开）。
- **前缀·后缀**：前缀 **a-**（例：aside, around）；名词后缀 **-ment**（例：movement, agreement）。
- **同义·反义**：同义 flat（公寓）, suite（套房）；反义 house（房子）, villa（别墅）。
- **变形**：名词 → 复数：apartments；形容词派生 → apartmental adj. 公寓的。

### 10. household /ˈhaʊshəʊld/ adj. 家庭的
- **词根·渊源**：古英语 **hūs**（房子）+ **hold**（持有）→ 英语 household，本义“持家者→一家人→家庭的”。
- **同根词**：house（hūs 房子 → 房子：房子）、hold（hold 持有 → 持有：持有）、householder（house + holder 持有者 = 户主）、housekeeping（house + keeping 管理 = 家务）、household-name（household + name 名字 = 家喻户晓的名字）。
- **前缀·后缀**：无前后缀（复合词）。
- **同义·反义**：同义 domestic（家庭的）, family（家庭的）；反义 public（公共的）, institutional（机构的）。
- **变形**：形容词 → 无比较级（关系形容词，不作比较）；名词派生 → household n. 家庭；household n. → 复数：households。

### 11. against /əˈɡenst/ prep. 紧靠；碰；撞
- **词根·渊源**：古英语 **ongean**（朝向、对面）→ 中古英语 *agenes* → 英语 against，本义“面对→紧靠→反对”。
- **同根词**：again（a- 再 + gain 获得 = 再一次：再一次）、gain（gain 获得 → 获得：获得）、gainsay（gain 反对 + say 说 = 反驳）、againward（again + ward 向 = 反向的）、againstness（against + **-ness** 名词后缀：对立性）。
- **前缀·后缀**：前缀 **a-**（例：aboard, across）；副词后缀 **-st**（例：amidst, whilst）。
- **同义·反义**：同义 touching（紧靠）, opposite（对着）；反义 for（支持）, with（与…一起）。
- **变形**：介词 → 无形态变化；无词性派生。

### 12. speed /spiːd/ n. 速度；速率
- **词根·渊源**：古英语 **spēd**（成功、迅速）→ 中古英语 *spede* → 英语 speed，本义“成功→迅速→速度”。
- **同根词**：speedy（speed + **-y** …的：迅速的）、speedily（speedy + **-ly** 副词后缀：迅速地）、speedometer（speed + meter 测量仪 = 速度计）、speedway（speed + way 路 = 高速公路）、speedup（speed + up 向上 = 加速）。
- **前缀·后缀**：无前后缀（单纯词）；后缀 **-y**（例：rainy, windy）。
- **同义·反义**：同义 velocity（速度）, pace（步速）；反义 slowness（缓慢）, delay（延迟）。
- **变形**：名词 → 复数：speeds；动词派生 → speed v. 加速；形容词派生 → speedy adj. 迅速的；副词派生 → speedily adv. 迅速地。

### 13. safety /ˈseɪfti/ n. 安全；平安
- **词根·渊源**：拉丁 **salvus**（安全的）→ 古法语 *sauf* → 英语 safe + **-ty**，本义“安全的状态→安全”。
- **同根词**：safe（salvus 安全 → 安全的：安全的）、safely（safe + **-ly** 副词后缀：安全地）、safeguard（safe + guard 保护 = 保护措施）、safekeeping（safe + keeping 保管 = 妥善保管）、safety-belt（safety + belt 带 = 安全带）。
- **前缀·后缀**：名词后缀 **-ty**（例：beauty, loyalty）；无前缀。
- **同义·反义**：同义 security（安全）, protection（保护）；反义 danger（危险）, risk（风险）。
- **变形**：名词 → 复数：safeties；形容词派生 → safe adj. 安全的；副词派生 → safely adv. 安全地。

### 14. instruction /ɪnˈstrʌkʃn/ n. 用法说明；操作指南
- **词根·渊源**：拉丁 **instruere**（建造、教导）→ 拉丁 *instructio* → 古法语 *instruction* → 英语 instruction，本义“在…上堆建→教导→说明”。
- **同根词**：instruct（**in-** 在…上 + struct 建造 = 在心上建→教导）、instructor（instruct + **-or** 人 = 指导者）、instructive（instruct + **-ive** …的：有教育意义的）、structure（struct 建造 + **-ure** 名词后缀：结构）、construct（**con-** 共同 + struct 建造 = 建造）。
- **前缀·后缀**：前缀 **in-**（例：include, inform）、**con-**（例：connect）；名词后缀 **-ion**（例：action, station）。
- **同义·反义**：同义 direction（指示）, guideline（指南）；反义 无。
- **变形**：名词 → 复数：instructions；动词派生 → instruct v. 指导；形容词派生 → instructive adj. 有教育意义的；instructive → 比较级：more instructive；最高级：most instructive。

### 15. connect /kəˈnekt/ v.（使）连接
- **词根·渊源**：拉丁 **connectere**（绑在一起）→ 英语 connect，本义“绑在一起→连接”。
- **同根词**：connection（connect + **-ion** 名词后缀：连接）、connective（connect + **-ive** …的：连接的）、connector（connect + **-or** 物：连接器）、disconnect（**dis-** 去除 + connect 连接 = 断开）、interconnect（**inter-** 相互 + connect 连接 = 互相连接）。
- **前缀·后缀**：前缀 **con-**（例：combine, confirm）、**dis-**（例：disagree, disappear）、**inter-**（例：international, interact）；无后缀。
- **同义·反义**：同义 link（连接）, join（连接）；反义 disconnect（断开）, separate（分开）。
- **变形**：动词 → 第三人称单数：connects；过去式：connected；过去分词：connected；现在分词：connecting；名词派生 → connection n. 连接；形容词派生 → connected adj. 连接的。

### 16. device /dɪˈvaɪs/ n. 装置；设备
- **词根·渊源**：拉丁 **dividere**（分开）→ 古法语 *devis*（设计、安排）→ 英语 device，本义“分开思考→设计→装置”。
- **同根词**：devise（devis 设计 → 设计：设计）、divide（**di-** 分开 + vid 分 = 分开：分开）、division（divide + **-ion** 名词后缀：分开）、individual（**in-** 不 + divid 分 + **-ual** …的 = 不可分的→个人的）、dividend（divide + **-end** 名词后缀：被分之物→红利）。
- **前缀·后缀**：前缀 **de-**（例：depart, decide）、**di-**（例：direct, differ）；名词后缀 **-ice**（例：service, justice）。
- **同义·反义**：同义 gadget（小装置）, instrument（仪器）；反义 无。
- **变形**：名词 → 复数：devices；动词派生 → devise v. 设计。

### 17. rule /ruːl/ n. 规则；条例

- **同义·反义**：同义 regulation（规章）, law（法律）；反义 exception（例外）, freedom（自由）。
- **变形**：名词 → 复数：rules；动词派生 → rule v. 统治；形容词派生 → ruling adj. 统治的。

### 19. amount /əˈmaʊnt/ n. 数量；数额
- **词根·渊源**：拉丁 **ad-**（向）+ **mont-**（山，拉丁 mons）→ 古法语 *amonter*“往上爬、总计达到”→ 英语 amount，本义“升到某一高度/总计”，引申为“总计的数额、数量”。
- **同根词**：mount（拉丁 mons 山→登上、骑上）、mountain（mont 山 + **-ain** 名词后缀→山）、dismount（**dis-** 下 + mount 登 = 下马→下来）、paramount（**par-** 通过 + amount 上升 = 升到最高→至上的）、surmount（**sur-** 在上 + mount 登 = 登上越过→克服）。

- **变形**：名词 → 复数：amounts；动词派生 → amount v. 总计、等于。

### 20. power /ˈpaʊə(r)/ v. 驱动；推动（机器或车辆）
- **词根·渊源**：拉丁 **posse / pot-**（能够）→ 通俗拉丁 *potere* → 古法语 *povoir* → 英语 power，本义“能力”，引申为“力量、动力”，动词义“给…提供动力→驱动”。
- **同根词**：powerful（power + **-ful** 充满…的→强大的）、powerless（power + **-less** 无…的→无力的）、potent（pot 能 + **-ent** 形容词后缀→有力的）、potential（potent 有力 + **-ial** →潜在的）、omnipotent（**omni-** 全 + potent 能 = 全能→全能的）、possess（**pos-** 能 + **sess** 坐 = 能坐住→拥有）。
- **前缀·后缀**：前缀 **omni-**（例：omnipresent, omnipotent）；名词后缀 **-er**（例：teacher, worker）。
- **同义·反义**：同义 drive（驱动）, energize（供能）；反义 无。
- **变形**：动词 → 第三人称单数：powers；过去式：powered；过去分词：powered；现在分词：powering；名词派生 → power n. 力量、权力；形容词派生 → powerful adj. 强大的；副词派生 → powerfully adv. 强有力地。

### 22. landmark /ˈlændmɑːk/ n. 地标
- **词根·渊源**：古英语 **land**（土地）+ **mearc**（边界、记号）→ 英语 landmark，本义“标示土地边界的界标”，引申为“易辨认的标志物→地标”。
- **同根词**：landscape（land 土地 + **-scape** 景象 = 土地景象→风景）、landlord（land 土地 + lord 主人 = 地主→房东）、mainland（**main-** 主要 + land 土地 = 主要陆地→大陆）、border（与 mearc 同源，边界→边境）、mark（mearc 记号→标记）。
- **前缀·后缀**：前缀 **main-**（例：mainland, mainstream）；无后缀（复合词，例：无）。
- **同义·反义**：同义 monument（纪念物）, marker（标志物）；反义 无。
- **变形**：名词 → 复数：landmarks；形容词派生 → landmark adj. 标志性的。
