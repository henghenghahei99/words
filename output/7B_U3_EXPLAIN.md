## 二、逐词说文解字

### 1. branch /brɑːntʃ/ n. 树枝
- **词根·渊源**：晚期拉丁 **branca**（爪、掌）→ 古法语 *branche* → 英语，本义“（像爪一样分叉的）枝”，引申为“树枝”，再引申为“分支、分店”。
- **同根词**：branchy（branch + **-y** 多…的：多枝的）、branchlet（branch + **-let** 小：小枝）、branching（branch + **-ing** 名词/形容词后缀：分叉）、disbranch（**dis-** 去除 + branch 枝：去枝）。
- **前缀·后缀**：名词后缀 **-y**（例：rainy, dusty）、**-let**（例：booklet, leaflet）；动词化前缀 **dis-**（例：disconnect, disarm）。
- **同义·反义**：同义 bough（大树枝）, limb（大枝）；反义 trunk（树干）, stem（茎）。
- **变形**：名词 → 复数：branches；动词派生 → branch v. 分叉；形容词派生 → branchy adj. 多枝的。

### 2. root /ruːt/ n. 根；根茎
- **词根·渊源**：古英语 *rōt* ← 古诺斯语 *rót*，与拉丁 **radix**（根）同出 PIE *wrād-*（根、枝）；本义“植物的根”，引申为“根源、根基”。
- **同根词**：rootless（root + **-less** 无…的：无根的）、rooted（root + **-ed** 有…的：扎根的）、uproot（**up-** 向上 + root 根 = 连根拔起→根除）、radical（拉丁 radix 根 + **-al** …的：根本的→激进的）、radish（拉丁 radix 根 + **-ish** 小东西：萝卜）。
- **前缀·后缀**：形容词后缀 **-less**（例：hopeless, careless）、**-ed**（例：talented, wooded）；前缀 **up-**（例：uphold, upset）。
- **同义·反义**：同义 base（基部）, origin（起源）；反义 branch（树枝）, top（顶端）。
- **变形**：名词 → 复数：roots；动词派生 → root v. 生根；形容词派生 → rootless adj. 无根的；副词派生 → rootedly adv. 根深蒂固地。

### 3. silent /ˈsaɪlənt/ adj. 不说话的；沉默的
- **词根·渊源**：拉丁 **silēre**（沉默）→ 拉丁 *silentem*（silēre 的现在分词）→ 法语 *silent* → 英语；本义“不出声的”，引申为“沉默的、寂静的”。
- **同根词**：silence（sil 沉默 + **-ence** 名词后缀：沉默）、silently（silent + **-ly** 副词后缀：沉默地）、silentness（silent + **-ness** 名词后缀：沉默）。
- **前缀·后缀**：形容词后缀 **-ent**（例：different, patient）；名词后缀 **-ence**（例：difference, patience）；副词后缀 **-ly**（例：quickly, happily）。
- **同义·反义**：同义 quiet（安静的）, still（静止的）；反义 noisy（吵闹的）, talkative（健谈的）。
- **变形**：形容词 → 比较级：more silent；最高级：most silent；名词派生 → silence n. 沉默；副词派生 → silently adv. 沉默地。

### 4. overlook /ˌəʊvəˈlʊk/ v. 忽略；未注意到
- **词根·渊源**：**over-**（在上、越过）+ **look**（看）→ 中古英语 *overloken*，本义“从高处俯视”，因“居高临下而看漏”引申为“忽略、未注意”。
- **同根词**：look（单纯词：看）、lookout（look + **out** 向外：瞭望）、onlooker（**on-** 在旁 + look 看 + **-er** 人：旁观者）、overlooker（overlook + **-er** 人：监工）。
- **前缀·后缀**：前缀 **over-**（例：overcome, overdo）、**on-**（例：onlooker, onset）；名词后缀 **-er**（例：teacher, worker）。
- **同义·反义**：同义 ignore（忽视）, neglect（疏忽）；反义 notice（注意到）, observe（观察）。
- **变形**：动词 → 第三人称单数：overlooks；过去式：overlooked；过去分词：overlooked；现在分词：overlooking；名词派生 → overlooker n. 监工。

### 5. human /ˈhjuːmən/ n. 人
- **词根·渊源**：拉丁 **hūmānus**（人的、人性的）← 拉丁 *homō*（人）← PIE *dʰǵʰm̥on-*（地上的人）；本义“属于人的”，名词化后指“人”。
- **同根词**：humanity（human + **-ity** 名词后缀：人性、人类）、humane（human + **-e**：仁慈的）、humanly（human + **-ly** 副词后缀：以人的方式）、inhuman（**in-** 不 + human 人：无人性的）、superhuman（**super-** 超 + human 人：超人的）。
- **前缀·后缀**：名词后缀 **-ity**（例：activity, reality）；副词后缀 **-ly**（例：badly, truly）；前缀 **in-**（例：incorrect, invisible）、**super-**（例：supermarket, superstar）。
- **同义·反义**：同义 person（人）, human being（人类）；反义 animal（动物）, beast（野兽）。
- **变形**：名词 → 复数：humans；形容词派生 → human adj. 人的；副词派生 → humanly adv. 以人的方式；名词派生 → humanity n. 人性。

### 6. oxygen /ˈɒksɪdʒən/ n. 氧；氧气
- **词根·渊源**：希腊 **oxys**（尖锐、酸）+ 希腊 **-genēs**（产生者）→ 法语 *oxygène* → 英语；18世纪拉瓦锡造词，本义“产生酸的元素”，后指“氧”。
- **同根词**：oxide（ox 酸 + **-ide** 化合物：氧化物）、dioxide（**di-** 二 + oxide 氧化物：二氧化物）、oxygenate（oxygen + **-ate** 动词后缀：充氧）、oxygenous（oxygen + **-ous** …的：含氧的）。
- **前缀·后缀**：前缀 **di-**（例：dioxide, divide）；名词后缀 **-ide**（例：oxide, chloride）；动词后缀 **-ate**（例：activate, calculate）。
- **同义·反义**：同义 无；反义 无。
- **变形**：名词 → 不可数；动词派生 → oxygenate v. 充氧；形容词派生 → oxygenous adj. 含氧的。

### 7. create /kriˈeɪt/ v. 创造
- **词根·渊源**：拉丁 **creāre**（产生、创造）→ 拉丁 *creātus*（creāre 的过去分词）→ 英语；本义“使生长、使产生”，引申为“创造”。
- **同根词**：creation（creat 创造 + **-ion** 名词后缀：创造）、creative（creat + **-ive** …的：有创造力的）、creator（creat + **-or** 人：创造者）、creature（creat + **-ure** 名词后缀：生物）、recreate（**re-** 再 + create 创造：再创造）。
- **前缀·后缀**：名词后缀 **-ion**（例：action, education）、**-or**（例：actor, visitor）、**-ure**（例：picture, mixture）；前缀 **re-**（例：rebuild, rewrite）。
- **同义·反义**：同义 make（制作）, produce（生产）；反义 destroy（破坏）, ruin（毁灭）。
- **变形**：动词 → 第三人称单数：creates；过去式：created；过去分词：created；现在分词：creating；名词派生 → creation n. 创造；形容词派生 → creative adj. 有创造力的；副词派生 → creatively adv. 有创造性地。

### 8. environment /ɪnˈvaɪrənmənt/ n. 自然环境
- **词根·渊源**：古法语 **environ**（围绕）← **en-**（在…中）+ **viron**（圈、周围）→ 英语 *environment*；本义“围绕之物”，引申为“环境、自然环境”。
- **同根词**：environ（en- 在…中 + viron 圈：包围）、environmental（environment + **-al** …的：环境的）、environmentalist（environmental + **-ist** 人：环保主义者）、environs（environ + **-s** 复数：周围地区）。
- **前缀·后缀**：前缀 **en-**（例：enable, enclose）；形容词后缀 **-al**（例：natural, national）；名词后缀 **-ist**（例：artist, scientist）。
- **同义·反义**：同义 surroundings（周围环境）, setting（环境）；反义 无。
- **变形**：名词 → 复数：environments；形容词派生 → environmental adj. 环境的；名词派生 → environmentalist n. 环保主义者。

### 9. convenient /kənˈviːniənt/ adj. 便利的；方便的
- **词根·渊源**：拉丁 **convenīre**（聚集、适合）← **con-**（一起）+ **venīre**（来）→ 拉丁 *convenientem* → 英语；本义“聚到一起合适的”，引申为“方便的”。
- **同根词**：convenience（con- 一起 + ven 来 + **-ience** 名词后缀：方便）、conveniently（convenient + **-ly** 副词后缀：方便地）、inconvenient（**in-** 不 + convenient 方便的：不方便的）、convene（con- 一起 + ven 来：召集）、event（**e-** 出 + vent 来：发生的事）。
- **前缀·后缀**：前缀 **con-**（例：connect, collect）、**in-**（例：incorrect, invisible）、**e-**（例：event, eject）；形容词后缀 **-ent**（例：different, patient）。
- **同义·反义**：同义 handy（手边的）, suitable（合适的）；反义 inconvenient（不方便的）, awkward（不便的）。
- **变形**：形容词 → 比较级：more convenient；最高级：most convenient；名词派生 → convenience n. 方便；副词派生 → conveniently adv. 方便地。

### 10. furniture /ˈfɜːnɪtʃə(r)/ n. (可移动的)家具
- **词根·渊源**：法语 **fournir**（提供、装备）→ 法语 *fourniture*（供应物）→ 英语 *furniture*；本义“装备、供应之物”，引申为“家具”。
- **同根词**：furnish（furn 提供 + **-ish** 动词后缀：供应、布置）、furnishing（furnish + **-ing** 名词后缀：家具陈设）、furnisher（furnish + **-er** 人：供应者）。
- **前缀·后缀**：动词后缀 **-ish**（例：finish, punish）；名词后缀 **-ing**（例：building, meeting）、**-er**（例：teacher, worker）。
- **同义·反义**：同义 furnishings（家具陈设）, equipment（设备）；反义 无。
- **变形**：名词 → 不可数；动词派生 → furnish v. 供应、布置；名词派生 → furnishing n. 家具陈设。

### 11. wood /wʊd/ n. 木；木头
- **词根·渊源**：古英语 **wudu**（树、森林、木头）← 原始日耳曼语 *widuz*；本义“树木、林地”，引申为“木材、木头”。
- **同根词**：wooden（wood + **-en** …制的：木制的）、woody（wood + **-y** 多…的：多树的）、woodland（wood + **land** 地：林地）、woodcutter（wood + **cutter** 砍伐者：伐木工）。
- **前缀·后缀**：形容词后缀 **-en**（例：golden, woolen）、**-y**（例：rainy, dusty）；复合词后缀 **-land**（例：island, homeland）。
- **同义·反义**：同义 timber（木材）, lumber（木材）；反义 无。
- **变形**：名词 → 复数：woods（作“木头”义时不可数）；形容词派生 → wooden adj. 木制的；woody adj. 多树的。

### 12. treat /triːt/ v. 以……态度对待；以……方式对待
- **词根·渊源**：古法语 **traiter**（处理、对待）← 拉丁 **tractāre**（拉、处理）← **trahere**（拉）；本义“拉扯、处理”，引申为“对待、治疗、款待”。
- **同根词**：treatment（treat + **-ment** 名词后缀：对待、治疗）、treaty（treat + **-y** 名词后缀：条约）、treatable（treat + **-able** 可…的：可治疗的）、mistreat（**mis-** 坏 + treat 对待：虐待）、retreat（**re-** 回 + treat 拉：撤退）。
- **前缀·后缀**：名词后缀 **-ment**（例：movement, development）、**-y**（例：difficulty, discovery）、**-able**（例：comfortable, readable）；前缀 **mis-**（例：mistake, misunderstand）、**re-**（例：return, rebuild）。
- **同义·反义**：同义 handle（处理）, deal with（对待）；反义 mistreat（虐待）, ignore（忽视）。
- **变形**：动词 → 第三人称单数：treats；过去式：treated；过去分词：treated；现在分词：treating；名词派生 → treatment n. 对待、治疗；treaty n. 条约。

### 13. communicate /kəˈmjuːnɪkeɪt/ v. 交流；沟通
- **词根·渊源**：拉丁 **commūnicāre**（分享、共有）← **commūnis**（共同的）→ 拉丁 *commūnicātus* → 英语；本义“使共有、分享”，引申为“交流、沟通”。
- **同根词**：communication（communicat 交流 + **-ion** 名词后缀：交流）、communicative（communicat + **-ive** …的：爱交流的）、common（com- 共同 + mon 公共：共同的）、community（com- 共同 + mun 公共 + **-ity** 名词后缀：社区）、communism（commun 共同 + **-ism** 主义：共产主义）。
- **前缀·后缀**：前缀 **com-**（例：connect, collect）；名词后缀 **-ion**（例：action, education）、**-ity**（例：activity, reality）、**-ism**（例：socialism, realism）。
- **同义·反义**：同义 talk（交谈）, exchange（交流）；反义 无。
- **变形**：动词 → 第三人称单数：communicates；过去式：communicated；过去分词：communicated；现在分词：communicating；名词派生 → communication n. 交流；形容词派生 → communicative adj. 爱交流的。

### 14. species /ˈspiːʃiːz/ n. 种；物种
- **词根·渊源**：拉丁 **speciēs**（外观、种类）← **specere**（看）→ 英语；本义“所见的外观”，引申为“种类、物种”。
- **同根词**：special（spec 看 + **-ial** …的：特别的）、specific（spec 看 + **-ific** 使…的：具体的）、specify（spec 看 + **-ify** 动词后缀：具体说明）、specimen（spec 看 + **-men** 名词后缀：标本）、spectacle（spect 看 + **-acle** 名词后缀：景象）。
- **前缀·后缀**：形容词后缀 **-ial**（例：social, official）、**-ific**（例：scientific, terrific）；动词后缀 **-ify**（例：simplify, beautify）；名词后缀 **-men**（例：specimen, regimen）。
- **同义·反义**：同义 kind（种类）, type（类型）；反义 无。
- **变形**：名词 → 复数：species（单复数同形）；形容词派生 → specific adj. 具体的；动词派生 → specify v. 具体说明。

### 15. product /ˈprɒdʌkt/ n. 产品；制品
- **词根·渊源**：拉丁 **prōdūcere**（引出、生产）← **prō-**（向前）+ **dūcere**（引导）→ 拉丁 *prōductus* → 英语；本义“被引出的东西”，引申为“产品、产物”。
- **同根词**：produce（pro- 向前 + duc 引导：生产）、production（product + **-ion** 名词后缀：生产）、productive（product + **-ive** …的：多产的）、introduce（**intro-** 向内 + duc 引导：介绍）、conduct（**con-** 一起 + duct 引导：引导、指挥）。
- **前缀·后缀**：前缀 **pro-**（例：progress, promote）、**intro-**（例：introduce, introvert）、**con-**（例：connect, collect）；名词后缀 **-ion**（例：action, education）。
- **同义·反义**：同义 goods（商品）, output（产出）；反义 无。
- **变形**：名词 → 复数：products；动词派生 → produce v. 生产；名词派生 → production n. 生产；形容词派生 → productive adj. 多产的。

### 16. side /saɪd/ n. 一面
- **词根·渊源**：古英语 **sīde**（侧面、边）← 原始日耳曼语 *sīdō*；本义“身体的侧面”，引申为“一面、边”。
- **同根词**：sideways（side + **-ways** 方向：向侧面）、aside（**a-** 在 + side 边：在旁边）、beside（**be-** 在 + side 边：在…旁边）、outside（**out-** 外 + side 边：外面）、inside（**in-** 内 + side 边：里面）。
- **前缀·后缀**：副词后缀 **-ways**（例：sideways, always）；前缀 **a-**（例：aside, asleep）、**be-**（例：beside, below）、**out-**（例：outside, outdoor）、**in-**（例：inside, indoor）。
- **同义·反义**：同义 face（面）, edge（边缘）；反义 center（中心）, middle（中间）。
- **变形**：名词 → 复数：sides；形容词派生 → side adj. 旁边的；副词派生 → sideways adv. 向侧面。

### 17. borrow /ˈbɒrəʊ/ v. 借；借用
- **词根·渊源**：古英语 **borgian**（借、担保）← **borg**（抵押、担保）；本义“以担保方式取得”，引申为“借入”。（与 bear 词源关系存疑）
- **同根词**：borrower（borrow + **-er** 人：借入者）、borrowing（borrow + **-ing** 名词后缀：借入）。
- **前缀·后缀**：名词后缀 **-er**（例：teacher, worker）、**-ing**（例：building, meeting）。
- **同义·反义**：同义 无；反义 lend（借出）。
- **变形**：动词 → 第三人称单数：borrows；过去式：borrowed；过去分词：borrowed；现在分词：borrowing；名词派生 → borrower n. 借入者。

### 18. hole /həʊl/ n. 洞；孔；坑
- **词根·渊源**：古英语 **hol**（洞穴、孔）← 原始日耳曼语 *hulą*；本义“中空之处”，引申为“洞、孔、坑”。
- **同根词**：hollow（hol 洞 + **-low** 形容词后缀：中空的）、holly（hol 洞 + **-ly** 名词后缀：冬青，因叶有刺孔得名，存疑）。
- **前缀·后缀**：形容词后缀 **-low**（例：hollow, yellow）；名词后缀 **-ly**（例：holly, family）。
- **同义·反义**：同义 opening（开口）, cavity（洞）；反义 无。
- **变形**：名词 → 复数：holes；形容词派生 → hollow adj. 中空的。

### 19. stick /stɪk/ n. 棍；条
- **词根·渊源**：古英语 **sticca**（细枝、棍）→ 中古英语 *stikke* → 英语 stick；与古诺斯语 *stik*（棍）同源，本义“细树枝”引申为“棍、条”。
- **同根词**：sticky（stick + **-y** …的 = 像棍上涂了东西→黏的）、sticker（stick + **-er** 物 = 贴上去的东西→贴纸）、chopstick（chop 切 + stick 棍 = 切东西用的棍→筷子）、lipstick（lip 唇 + stick 棍 = 唇用棍状物→口红）、breadstick（bread 面包 + stick 条 = 面包条）。
- **前缀·后缀**：无前后缀（单纯词）。
- **同义·反义**：同义 rod（杆）, branch（树枝）；反义 无。
- **变形**：名词 → 复数：sticks；形容词派生 → sticky adj. 黏的；stuck adj. 卡住的。

### 20. accident /ˈæksɪdənt/ n. 意外；偶然的事
- **词根·渊源**：拉丁 **ad-**（向）+ **cadere**（落下）→ 拉丁 *accidere*（落到身上、发生）→ 古法语 *accident* → 英语；本义“偶然落到身上的事”，引申为“意外、事故”。
- **同根词**：accidental（accident + **-al** …的：偶然的）、accidentally（accidental + **-ly** 地：偶然地）、incident（**in-** 在上 + cid 落 = 落到上面发生的事→事件）、incidence（incident + **-ence** 名词后缀：发生率）、coincide（**co-** 共同 + in 上 + cid 落 = 一起落到一点→巧合）、decay（**de-** 向下 + cay 落 = 落下去→腐烂）。
- **前缀·后缀**：前缀 **ad-**（例：advance, admire）；名词后缀 **-ent**（例：student, president）。
- **同义·反义**：同义 mishap（小事故）, crash（撞车事故）；反义 无。
- **变形**：名词 → 复数：accidents；形容词派生 → accidental adj. 偶然的；副词派生 → accidentally adv. 偶然地。

### 21. knowledge /ˈnɒlɪdʒ/ n. 知识；学问
- **词根·渊源**：古英语 **cnāwan**（知道）→ 中古英语 *knowen* + 名词后缀 **-ledge** → knowledge；本义“知道的状态”，引申为“知识、学问”。
- **同根词**：know（古英语 cnāwan 知道：知道）、known（know + **-n** 过去分词：已知的）、unknown（**un-** 不 + known 已知的：未知的）、acknowledge（**ac-** 加强 + knowledge 知道 = 承认知道→承认）、knowledgeable（knowledge + **-able** 能…的：知识渊博的）。
- **前缀·后缀**：名词后缀 **-ledge**（例：acknowledge 中的 -ledge 同源）；否定前缀 **un-**（例：unhappy, unknown）。
- **同义·反义**：同义 learning（学问）, information（信息）；反义 ignorance（无知）。
- **变形**：名词 → 不可数；形容词派生 → knowledgeable adj. 知识渊博的；副词派生 → knowledgeably adv. 有见识地。

### 22. character /ˈkærəktə(r)/ n. 文字
- **词根·渊源**：希腊 **kharaktēr**（刻印的记号）→ 拉丁 *character*（标记、特征）→ 古法语 *caractere* → 英语；本义“刻下的记号”，引申为“文字、字符”，再引申为“性格、角色”。
- **同根词**：characteristic（character + **-istic** …的：特有的）、characterize（character + **-ize** 使…化：描绘…的特征）、characterization（characterize + **-ation** 名词后缀：人物刻画）。
- **前缀·后缀**：名词后缀 **-er**（例：teacher, worker）；形容词后缀 **-istic**（例：artistic, realistic）。
- **同义·反义**：同义 letter（字母）, symbol（符号）；反义 无。
- **变形**：名词 → 复数：characters；形容词派生 → characteristic adj. 特有的；动词派生 → characterize v. 描绘…的特征。

### 23. spread /sprɛd/ v. 传播
- **词根·渊源**：古英语 **sprǣdan**（展开、铺开）→ 中古英语 *spreden* → 英语 spread；本义“铺开、展开”，引申为“传播、散布”。
- **同根词**：widespread（wide 宽 + spread 展开 = 展开很宽的→广泛的）、spreadsheet（spread 展开 + sheet 纸 = 展开的表格→电子表格）、spreader（spread + **-er** 物：涂抹器）。
- **前缀·后缀**：无前后缀（单纯词）。
- **同义·反义**：同义 scatter（散布）, propagate（传播）；反义 gather（聚集）, collect（收集）。
- **变形**：动词 → 第三人称单数：spreads；过去式：spread；过去分词：spread；现在分词：spreading；名词派生 → spread n. 传播、蔓延。

### 24. translation /trænzˈleɪʃn/ n. 译文；译本
- **词根·渊源**：拉丁 **trans-**（越过）+ **latus**（搬运，ferre 的过去分词）→ 拉丁 *translatus*（搬过去）→ 古法语 *translation* → 英语；本义“搬过去”，引申为“翻译、译文”。
- **同根词**：translate（trans- 越过 + late 搬运 = 搬过去→翻译）、translator（translate + **-or** 人：译者）、transfer（trans- 越过 + fer 带 = 带过去→转移）、transport（trans- 越过 + port 运 = 运过去→运输）、transform（trans- 越过 + form 形状 = 改变形状→变形）。
- **前缀·后缀**：前缀 **trans-**（例：transport, transform）；名词后缀 **-ation**（例：information, education）。
- **同义·反义**：同义 version（版本）, rendering（译文）；反义 original（原文）。
- **变形**：名词 → 复数：translations；动词派生 → translate v. 翻译；名词派生 → translator n. 译者。
