## 二、逐词说文解字

### 1. contribution /ˌkɒntrɪˈbjuːʃn/ n. 贡献
- **词根·渊源**：拉丁 **tribu-**（给予、分配）→ 拉丁 *contribuere*（共同给予）→ 古法语 *contribution* → 英语；本义“共同拿出（财物）”，引申为“贡献”。
- **同根词**：contribute（**con-** 共同 + tribut 给予 + **-e** = 共同给予→贡献）、tribute（tribut 给予 + **-e** = 给予之物→贡品、致敬）、distribute（**dis-** 分开 + tribut 给予 = 分给各处→分配）、attribute（**ad-** 向 + tribut 给予 = 把……归于→归因）。
- **前缀·后缀**：前缀 **con-**（例：connect, combine）；名词后缀 **-ion**（例：action, invention）。
- **同义·反义**：同义 donation（捐赠）, offering（奉献物）；反义 无。
- **变形**：名词 → 复数：contributions；动词派生 → contribute v. 贡献；形容词派生 → contributive adj. 有贡献的。

### 2. hero /ˈhɪərəʊ/ n. 英雄
- **词根·渊源**：希腊 **hērōs**（半神、英雄）→ 拉丁 *heros* → 古法语 *heroe* → 英语；本义“神话中的半神勇士”，引申为“英雄”。
- **同根词**：heroic（hero + **-ic** ……的：英勇的）、heroism（hero + **-ism** 主义、精神：英雄气概）、heroine（hero + **-ine** 女性：女英雄）。
- **前缀·后缀**：无前缀；名词后缀 **-ine**（例：marine, medicine）。
- **同义·反义**：同义 champion（勇士）, idol（偶像）；反义 coward（懦夫）, villain（恶棍）。
- **变形**：名词 → 复数：heroes；形容词派生 → heroic adj. 英勇的；副词派生 → heroically adv. 英勇地。

### 3. pioneer /ˌpaɪəˈnɪə(r)/ n. 先锋；先驱
- **词根·渊源**：古法语 **peonier**（步兵、开路者）→ 英语；本义“走在队伍前面开路的步兵”，引申为“先锋、先驱”。
- **同根词**：pioneering（pioneer + **-ing** ……的：开创性的）、pioneerism（pioneer + **-ism** 精神：开拓精神）。
- **前缀·后缀**：无前缀；名词后缀 **-eer**（例：engineer, volunteer）。
- **同义·反义**：同义 forerunner（先驱）, trailblazer（开拓者）；反义 follower（追随者）。
- **变形**：名词 → 复数：pioneers；动词派生 → pioneer v. 开创；形容词派生 → pioneering adj. 开创性的。

### 4. technology /tekˈnɒlədʒi/ n. 科技
- **词根·渊源**：希腊 **tekhnē**（技艺）+ **-logia**（学问）→ 拉丁 *technologia* → 英语；本义“关于技艺的学问”，引申为“科技”。
- **同根词**：technical（techn 技艺 + **-ical** ……的：技术的）、technique（techn 技艺 + **-ique** 名词后缀：技巧）、technician（techn 技艺 + **-ician** 人：技术员）、technological（technology + **-ical** ……的：科技的）。
- **前缀·后缀**：无前缀；名词后缀 **-logy**（例：biology, geology）。
- **同义·反义**：同义 science（科学）；反义 无。
- **变形**：名词 → 复数：technologies；形容词派生 → technological adj. 科技的；副词派生 → technologically adv. 科技上。

### 5. receive /rɪˈsiːv/ v. 拿到；接到；收到
- **词根·渊源**：拉丁 **recipere**（re- 回 + capere 拿取）→ 古北法语 *receivre* → 英语；本义“拿回来、接过来”，引申为“收到”。
- **同根词**：receipt（**re-** 回 + ceipt 拿取 = 拿回之物→收据）、receiver（receive + **-er** 人/物：接收者）、reception（**re-** 回 + cept 拿取 + **-ion** = 接回→接待）、recipient（**re-** 回 + cip 拿取 + **-ient** 人：接受者）。
- **前缀·后缀**：前缀 **re-**（例：return, recall）；动词后缀 **-ceive**（例：conceive, perceive）。
- **同义·反义**：同义 get（得到）, obtain（获得）；反义 send（发送）, give（给予）。
- **变形**：动词 → 第三人称单数：receives；过去式：received；过去分词：received；现在分词：receiving；名词派生 → receiver n. 接收者；reception n. 接待。

### 6. engineering /ˌendʒɪˈnɪərɪŋ/ n. 工程学
- **词根·渊源**：拉丁 **ingenium**（天赋、巧智）→ 古法语 *engin*（巧计、机械）→ 英语 *engine*（引擎）+ **-eer**（人）+ **-ing**（……学）；本义“设计机械的巧智之术”，引申为“工程学”。
- **同根词**：engine（engin 巧智 + **-e** = 巧智造物→引擎）、engineer（engine + **-eer** 人：工程师）、ingenious（**in-** 内 + gen 天赋 + **-ious** ……的：有天赋的→巧妙的）。
- **前缀·后缀**：无前缀；名词后缀 **-ing**（例：building, teaching）。
- **同义·反义**：同义 无；反义 无。
- **变形**：名词 → 复数：不可数；名词派生 → engineer n. 工程师。

### 7. award /əˈwɔːd/ v. 授予；奖励；n.奖
- **词根·渊源**：古北法语 **awarder**（a- 向 + warder 看守、判断）→ 英语；本义“经审视后判定给予”，引申为“授予、奖”。
- **同根词**：reward（**re-** 回 + ward 看守 = 回看给予→回报、奖励）、ward（ward 看守 = 看守→保卫）、warden（ward 看守 + **-en** 人：看守人）。
- **前缀·后缀**：前缀 **a-**（例：aboard, asleep）；无后缀（单纯词）。
- **同义·反义**：同义 grant（授予）, prize（奖品）；反义 无。
- **变形**：动词 → 第三人称单数：awards；过去式：awarded；过去分词：awarded；现在分词：awarding；名词 → 复数：awards。

### 8. education /ˌedʒuˈkeɪʃn/ n. 教育
- **词根·渊源**：拉丁 **educare**（e- 出 + ducere 引导）→ 拉丁 *educatio* → 英语；本义“引导出来（潜能）”，引申为“教育”。
- **同根词**：educate（**e-** 出 + duc 引导 + **-ate** 动词后缀 = 引导出→教育）、educational（education + **-al** ……的：教育的）、educator（**e-** 出 + duc 引导 + **-ator** 人：教育者）、conduct（**con-** 共同 + duct 引导 = 共同引导→指挥）。
- **前缀·后缀**：前缀 **e-**（例：evade, eject）；名词后缀 **-ion**（例：action, invention）。
- **同义·反义**：同义 schooling（学校教育）, teaching（教学）；反义 无。
- **变形**：名词 → 复数：educations（多用不可数）；形容词派生 → educational adj. 教育的；副词派生 → educationally adv. 教育上；动词派生 → educate v. 教育。

### 9. spend /spɛnd/ v. 花（时间）；度过
- **词根·渊源**：拉丁 **expendere**（ex- 出 + pendere 称量、支付）→ 古英语 *spendan* → 英语；本义“称量付出（钱财）”，引申为“花费（时间、金钱）”。
- **同根词**：expend（**ex-** 出 + pend 支付 = 付出→花费）、expense（**ex-** 出 + pens 支付 + **-e** = 支出→费用）、expensive（expense + **-ive** ……的：昂贵的）、pension（pens 支付 + **-ion** = 付出之物→养老金）。
- **前缀·后缀**：无前缀（s- 为拉丁 ex- 的残留形式，存疑）；无后缀（单纯词）。
- **同义·反义**：同义 pass（度过）, use（使用）；反义 save（节省）。
- **变形**：动词 → 第三人称单数：spends；过去式：spent；过去分词：spent；现在分词：spending；名词派生 → spending n. 花费。

### 10. research /ˈriːsɜːtʃ/ n. 研究；调查
- **词根·渊源**：古法语 **recerche**（re- 反复 + cerchier 搜寻）→ 英语；本义“反复搜寻”，引申为“研究、调查”。
- **同根词**：search（cerch 搜寻 = 搜寻）、researcher（research + **-er** 人：研究者）、searchlight（search 搜寻 + light 灯 = 探照灯）。
- **前缀·后缀**：前缀 **re-**（例：return, recall）；无后缀（单纯词）。
- **同义·反义**：同义 study（研究）, investigation（调查）；反义 无。
- **变形**：名词 → 复数：researches（多用不可数）；动词派生 → research v. 研究；名词派生 → researcher n. 研究者。

### 11. achieve /əˈtʃiːv/ v.（凭长期努力）达到（某目标、地位、标准）
- **词根·渊源**：古法语 **achever**（a- 向 + chief 头、顶端）→ 英语；本义“到达顶端”，引申为“达到、实现”。
- **同根词**：achievement（achieve + **-ment** 名词后缀：成就）、chief（chief 头 = 首领）、mischief（**mis-** 坏 + chief 头 = 坏结果→恶作剧）。
- **前缀·后缀**：前缀 **a-**（例：aboard, asleep）；无后缀（单纯词）。
- **同义·反义**：同义 accomplish（完成）, attain（达到）；反义 fail（失败）。
- **变形**：动词 → 第三人称单数：achieves；过去式：achieved；过去分词：achieved；现在分词：achieving；名词派生 → achievement n. 成就。

### 12. well-respected /ˌwel rɪˈspektɪd/ adj. 受尊敬的
- **词根·渊源**：**well**（好）+ 拉丁 **respectus**（re- 回 + specere 看）→ 英语 *respect*（回看→尊敬）+ **-ed**（被……的）；本义“被好好看待的”，引申为“受尊敬的”。
- **同根词**：respect（**re-** 回 + spect 看 = 回看→尊敬）、respectful（respect + **-ful** 充满……的：恭敬的）、respectable（respect + **-able** 可……的：值得尊敬的）、inspect（**in-** 向内 + spect 看 = 向内看→检查）。
- **前缀·后缀**：前缀 **re-**（例：return, recall）；形容词后缀 **-ed**（例：talented, excited）。
- **同义·反义**：同义 esteemed（受敬重的）, admired（受钦佩的）；反义 despised（被鄙视的）。
- **变形**：形容词 → 无比较级（由分词转化，不作比较）；名词派生 → respect n. 尊敬；副词派生 → respectfully adv. 恭敬地。

### 13. found /faʊnd/ v. 建立（城镇或国家）
- **词根·渊源**：拉丁 **fundus**（底部、地基）→ 古法语 *fonder* → 英语；本义“打地基”，引申为“建立”。
- **同根词**：foundation（found + **-ation** 名词后缀：地基、基金会）、founder（found + **-er** 人：奠基者）、profound（**pro-** 向前 + found 底 = 深到底的→深刻的）。
- **前缀·后缀**：无前缀；无后缀（单纯词）。
- **同义·反义**：同义 establish（建立）, set up（建立）；反义 destroy（摧毁）, abolish（废除）。
- **变形**：动词 → 第三人称单数：founds；过去式：founded；过去分词：founded；现在分词：founding；名词派生 → founder n. 奠基者；foundation n. 基础。

### 14. eager /ˈiːɡə(r)/ adj. 热切的；渴望的
- **词根·渊源**：拉丁 **acer**（尖锐、猛烈）→ 古法语 *aigre*（尖锐的）→ 英语；本义“尖锐、急切”，引申为“热切的”。
- **同根词**：eagerness（eager + **-ness** 名词后缀：热切）、eagerly（eager + **-ly** 副词后缀：热切地）、acrid（acr 尖锐 + **-id** ……的：辛辣的）。
- **前缀·后缀**：无前缀；形容词后缀 **-er**（例：clever, tender）。
- **同义·反义**：同义 keen（热切的）, enthusiastic（热情的）；反义 indifferent（冷漠的）, reluctant（不情愿的）。
- **变形**：形容词 → 比较级：more eager；最高级：most eager；名词派生 → eagerness n. 热切；副词派生 → eagerly adv. 热切地。

### 15. raise /reɪz/ v. 增加；提高
- **词根·渊源**：古诺斯语 **reisa**（使升起）→ 中古英语 *raysen* → 英语；本义“使升起”，引申为“提高、增加”。
- **同根词**：rise（同源，自升→上升）、arise（**a-** 向上 + rise 升 = 升起→出现）、rear（同源，使升起→抚养）。
- **前缀·后缀**：无前缀；无后缀（单纯词）。
- **同义·反义**：同义 increase（增加）, lift（提高）；反义 lower（降低）, reduce（减少）。
- **变形**：动词 → 第三人称单数：raises；过去式：raised；过去分词：raised；现在分词：raising；名词派生 → raise n. 加薪。

### 16. mission /ˈmɪʃn/ n. 使命
- **词根·渊源**：拉丁 **mittere**（送、派）→ 拉丁 *missio*（派遣）→ 古法语 *mission* → 英语；本义“被派遣的任务”，引申为“使命”。
- **同根词**：missile（miss 送 + **-ile** 物 = 送出之物→导弹）、submit（**sub-** 下 + mit 送 = 送上去→提交）、transmit（**trans-** 横过 + mit 送 = 送过去→传送）、dismiss（**dis-** 离开 + miss 送 = 送走→解散）。
- **前缀·后缀**：无前缀；名词后缀 **-ion**（例：action, invention）。
- **同义·反义**：同义 task（任务）, duty（职责）；反义 无。
- **变形**：名词 → 复数：missions；形容词派生 → missional adj. 使命的。

### 17. honour /ˈɒnə(r)/ n. 荣誉；名誉
- **词根·渊源**：拉丁 **honor**（荣誉、尊敬）→ 古法语 *honor* → 英语；本义“尊敬、荣誉”，引申为“名誉”。
- **同根词**：honest（hon 荣誉 + **-est** ……的：有荣誉的→诚实的）、honourable（honour + **-able** 可……的：值得尊敬的）、honorary（honor + **-ary** ……的：荣誉的）。
- **前缀·后缀**：无前缀；无后缀（单纯词）。
- **同义·反义**：同义 glory（光荣）, reputation（名誉）；反义 shame（耻辱）, disgrace（丢脸）。
- **变形**：名词 → 复数：honours（多用不可数）；形容词派生 → honourable adj. 值得尊敬的；副词派生 → honourably adv. 光荣地。

### 18. public /ˈpʌblɪk/ n. 百姓；民众
- **词根·渊源**：拉丁 **publicus**（populus 人民 + -icus ……的）→ 古法语 *public* → 英语；本义“属于人民的”，引申为“公众、百姓”。
- **同根词**：people（同源，人民）、popular（popul 人民 + **-ar** ……的：人民的→流行的）、publish（publ 公众 + **-ish** 动词后缀 = 使公开→出版）、republic（**re-** 事物 + public 公众 = 公共之事→共和国）。
- **前缀·后缀**：无前缀；形容词后缀 **-ic**（例：basic, magic）。
- **同义·反义**：同义 people（人民）, masses（大众）；反义 无。
- **变形**：名词 → 复数：不可数；形容词派生 → public adj. 公共的；副词派生 → publicly adv. 公开地。

### 19. approval /əˈpruːvl/ n. 赞成；同意
- **词根·渊源**：拉丁 **prob-**（好、证明）→ 古法语 *aprover*（证明为好）→ 英语 approve + 名词后缀 **-al**；本义“证明为好的”，引申为“赞成、同意”。
- **同根词**：approve（**ap-** 向 + prove 证明 = 证明为好→赞成）、probable（prob 好 + **-able** 能…的 = 能证明好的→很可能的）、probation（prob 证明 + **-ation** 名词后缀 = 试用期）、prove（源自拉丁 probare 证明）、proof（源自拉丁 proba 证明→证据）。
- **前缀·后缀**：前缀 **ap-**（例：appear, apply）；名词后缀 **-al**（例：arrival, refusal）。
- **同义·反义**：同义 agreement（同意）, consent（赞同）；反义 disapproval（不赞成）, objection（反对）。
- **变形**：名词 → 复数：approvals；动词派生 → approve v. 赞成；形容词派生 → approving adj. 赞成的；副词派生 → approvingly adv. 赞许地。
