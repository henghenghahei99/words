## 二、逐词说文解字

### 1. ring /rɪŋ/ n. 环状物；圈形的东西
- **词根·渊源**：古英语 *hring*（环、圈）→ 中古英语 *ring*，本义“金属环”，引申为“环状物、圈形的东西”；与古北欧语 *hringr* 同源，存疑处在于与“铃声”义的 ring 是否同形异源（一般认为不同源）。
- **同根词**：ringlet（ring + **-let** 小 = 小环→小卷发）、ringed（ring + **-ed** 有…的 = 带环的）、earring（ear 耳 + ring 环 = 耳环）、ringside（ring 圈 + side 边 = 圈边座位）、ringworm（ring 环 + worm 虫 = 环癣）。
- **前缀·后缀**：名词后缀 **-let**（例：booklet, leaflet）；形容词后缀 **-ed**（例：winged, bearded）。
- **同义·反义**：同义 circle（圆圈）, loop（环）；反义 无。
- **变形**：名词 → 复数：rings；形容词派生 → ringed adj. 带环的；名词派生 → ringlet n. 小卷发。

### 2. collection /kəˈlɛkʃən/ n. (常指同类的)收集物
- **词根·渊源**：拉丁 **leg-/lect-**（挑选、收集）→ 拉丁 *collectio*（聚集）→ 古法语 *collection* → 英语，本义“聚集在一起的东西”，引申为“收集物、收藏品”。
- **同根词**：collect（**col-** 一起 + lect 挑选 = 收集）、select（**se-** 分开 + lect 挑选 = 选出）、elect（**e-** 出 + lect 挑选 = 选出→选举）、lecture（lect 读 + **-ure** 名词 = 诵读→讲座）、legend（leg 读 + **-end** = 应读之物→传说）、collector（collect + **-or** 人 = 收集者）。
- **前缀·后缀**：前缀 **col-**（例：collaborate, collide）；名词后缀 **-tion**（例：action, education）。
- **同义·反义**：同义 assortment（各类物品）, gathering（聚集物）；反义 无。
- **变形**：名词 → 复数：collections；动词派生 → collect v. 收集；名词派生 → collector n. 收集者。

### 3. own /oʊn/ v. 拥有；有
- **词根·渊源**：古英语 *āgan*（拥有）→ 中古英语 *owen*，本义“对某物有所有权”，引申为“拥有；有”；与古北欧语 *eiga* 同源，同出 PIE *aik-*（拥有）。
- **同根词**：owner（own + **-er** 人 = 拥有者）、ownership（owner + **-ship** 身份 = 所有权）、owe（古英语 *āgan* 的弱化形式 = 欠→应归因于）、ought（古英语 *āhte* 过去式 = 应尽之责→应该）。
- **前缀·后缀**：名词后缀 **-er**（例：worker, teacher）；名词后缀 **-ship**（例：friendship, leadership）。
- **同义·反义**：同义 possess（拥有）, have（有）；反义 lose（失去）, lack（缺少）。
- **变形**：动词 → 第三人称单数：owns；过去式：owned；过去分词：owned；现在分词：owning；名词派生 → owner n. 拥有者；ownership n. 所有权。

### 4. valuable /ˈvæljəbəl/ adj. 贵重的
- **词根·渊源**：拉丁 **val-**（强、值）→ 古法语 *value*（价值）→ 英语 value + **-able**，本义“值得的、有价值的”，引申为“贵重的”。
- **同根词**：value（val 值 + **-ue** 名词 = 价值）、valued（value + **-ed** 被重视的）、invaluable（**in-** 不 + valuable 可估价的 = 无法估价的→极宝贵的）、evaluate（**e-** 出 + valu 值 + **-ate** 动词 = 估出价值→评价）、valid（val 强 + **-id** = 强有力的→有效的）、valiant（val 强 + **-iant** = 勇敢的）。
- **前缀·后缀**：形容词后缀 **-able**（例：comfortable, readable）；否定前缀 **in-**（例：incorrect, invisible）。
- **同义·反义**：同义 precious（珍贵的）, costly（昂贵的）；反义 worthless（无价值的）, cheap（便宜的）。
- **变形**：形容词 → 比较级：more valuable；最高级：most valuable；名词派生 → value n. 价值；valuables n. 贵重物品；副词派生 → valuably adv. 有价值地。

### 5. handle /ˈhændəl/ v. (用手)触
- **词根·渊源**：古英语 **hand**（手）+ 后缀 **-le**（表反复动作）→ 中古英语 *handlen*，本义“用手反复触摸、操作”，引申为“触；处理”。
- **同根词**：hand（手）、handy（hand + **-y** 有…的 = 手边的→方便的）、handful（hand + **-ful** 满 = 一把→少量）、handbag（hand 手 + bag 包 = 手提包）、handwriting（hand 手 + writing 写 = 手写→笔迹）、handsome（hand 手 + **-some** 像…的 = 手边的→英俊的）。
- **前缀·后缀**：动词后缀 **-le**（例：sparkle, twinkle）；形容词后缀 **-y**（例：rainy, windy）。
- **同义·反义**：同义 touch（触摸）, feel（摸）；反义 无。
- **变形**：动词 → 第三人称单数：handles；过去式：handled；过去分词：handled；现在分词：handling；名词派生 → handle n. 把手；handler n. 处理者。

### 6. glove /gləv/ n. (分手指的)手套
- **词根·渊源**：古英语 *glōf*（手套）→ 中古英语 *glove*，本义“分手指的手套”；词源存疑，一般认为与古北欧语 *glōfi* 同源，可能与“手掌”义相关。
- **同根词**：gloved（glove + **-ed** 戴手套的）、glovebox（glove 手套 + box 箱 = 手套箱）、glovey（glove + **-y** 像手套的）。
- **前缀·后缀**：形容词后缀 **-ed**（例：gloved, masked）；名词后缀 **-y**（例：glovey, rainy）。
- **同义·反义**：同义 mitten（连指手套，近义）；反义 无。
- **变形**：名词 → 复数：gloves；形容词派生 → gloved adj. 戴手套的。

### 7. add /æd/ v. 增加；添加
- **词根·渊源**：拉丁 **addere**（**ad-** 向 + dare 给 = 给上去→加上）→ 古法语 *adder* → 英语，本义“把某物加到另一物上”，引申为“增加；添加”。
- **同根词**：addition（add + **-ition** 名词 = 增加）、additional（addition + **-al** …的 = 附加的）、additive（add + **-itive** 名词/形容词 = 添加剂）、adder（add + **-er** 人/物 = 加法器）。
- **前缀·后缀**：前缀 **ad-**（例：advance, admire）；名词后缀 **-ition**（例：condition, position）。
- **同义·反义**：同义 increase（增加）, append（附加）；反义 subtract（减去）, remove（移除）。
- **变形**：动词 → 第三人称单数：adds；过去式：added；过去分词：added；现在分词：adding；名词派生 → addition n. 增加；形容词派生 → additional adj. 附加的。

### 8. envelope /ˈɛnvəˌloʊp/ n. 信封
- **词根·渊源**：法语 **envelopper**（包裹）→ 古法语 *envoloper*（**en-** 在内 + voloper 包裹）→ 英语 envelope，本义“包裹物”，引申为“信封”。
- **同根词**：envelop（**en-** 在内 + velop 包裹 = 包住→包围）、development（**de-** 去掉 + velop 包裹 + **-ment** 名词 = 解开包裹→发展）、envelopment（envelop + **-ment** 名词 = 包围）。
- **前缀·后缀**：前缀 **en-**（例：enable, enclose）；名词后缀 **-ment**（例：movement, agreement）。
- **同义·反义**：同义 wrapper（包装纸）, cover（封套）；反义 无。
- **变形**：名词 → 复数：envelopes；动词派生 → envelop v. 包住；名词派生 → envelopment n. 包围。

### 9. absolutely /ˌæbsəˈlutli/ adv. 极其
- **词根·渊源**：拉丁 **absolutus**（**ab-** 离开 + solvere 解开 = 解开→完全的）→ 英语 absolute + **-ly**，本义“完全地”，引申为“极其”。
- **同根词**：absolute（**ab-** 离开 + solut 解开 = 完全的→绝对的）、absolution（**ab-** 离开 + solut 解开 + **-ion** 名词 = 解开罪责→赦免）、absolve（**ab-** 离开 + solve 解开 = 解开→赦免）、solution（solut 解开 + **-ion** 名词 = 解决办法）、solve（solv 解开 = 解决）。
- **前缀·后缀**：前缀 **ab-**（例：absent, abnormal）；副词后缀 **-ly**（例：quickly, happily）。
- **同义·反义**：同义 completely（完全地）, totally（完全地）；反义 partly（部分地）, relatively（相对地）。
- **变形**：副词 → 无比较级（绝对副词，不作比较）；形容词派生 → absolute adj. 绝对的；名词派生 → absoluteness n. 绝对性。

### 10. seem /sim/ v. 好像；似乎
- **词根·渊源**：古北欧语 *sœma*（适合、相称）→ 中古英语 *semen*，本义“看起来相称、合适”，引申为“好像；似乎”；与古英语 *sēman*（调和）同源。
- **同根词**：seeming（seem + **-ing** 形容词 = 表面上的）、seemly（seem + **-ly** 合适的→得体的）、unseemly（**un-** 不 + seemly 得体的 = 不得体的）。
- **前缀·后缀**：形容词后缀 **-ing**（例：interesting, boring）；否定前缀 **un-**（例：unhappy, unfair）。
- **同义·反义**：同义 appear（似乎）, look（看起来）；反义 无。
- **变形**：动词 → 第三人称单数：seems；过去式：seemed；过去分词：seemed；现在分词：seeming；形容词派生 → seeming adj. 表面上的；副词派生 → seemingly adv. 表面上。

### 11. impossible /ˌɪmˈpɑsəbəl/ adj. 不可能的
- **词根·渊源**：拉丁 **im-**（不）+ **possibilis**（可能的，来自 posse 能够）→ 古法语 *impossible* → 英语，本义“不能够的”，引申为“不可能的”。
- **同根词**：possible（poss 能够 + **-ible** 可…的 = 可能的）、possibility（possible + **-ity** 名词 = 可能性）、impossibly（impossible + **-ly** 副词 = 不可能地）、potent（pot 能够 + **-ent** = 有力的）、power（posse 能够 → 力量）。
- **前缀·后缀**：否定前缀 **im-**（例：impatient, immoral）；形容词后缀 **-ible**（例：visible, flexible）。
- **同义·反义**：同义 unattainable（无法达到的）, unthinkable（难以想象的）；反义 possible（可能的）, feasible（可行的）。
- **变形**：形容词 → 无比较级（绝对形容词，不作比较）；名词派生 → impossibility n. 不可能性；副词派生 → impossibly adv. 不可能地。

### 12. single /ˈsɪŋgəl/ adj. 单个的
- **词根·渊源**：拉丁 **singulus**（单个的）→ 古法语 *sengle* → 英语 single，本义“一个的、单独的”，引申为“单个的”。

- **前缀·后缀**：形容词后缀 **-ar**（例：similar, familiar）；名词后缀 **-ton**（例：simpleton, singleton）。
- **同义·反义**：同义 sole（唯一的）, individual（单个的）；反义 multiple（多个的）, double（双的）。
- **变形**：形容词 → 无比较级（绝对形容词，不作比较）；名词派生 → singleness n. 单一；副词派生 → singly adv. 单独地。

### 13. nail /neɪl/ n. 钉；钉子
- **词根·渊源**：古英语 **nægl**（指甲、钉子）→ 中古英语 *nail*，本义“指甲”，因形似引申为“钉子”；与古高地德语 *nagal* 同源，同出 PIE *nog-*（指甲）。

### 14. explain /ɪkˈspleɪn/ v. 解释；说明
- **词根·渊源**：拉丁 **ex-**（出）+ **planare**（使平坦，来自 planus 平的）→ 拉丁 *explanare*（摊平→说明）→ 古法语 *explainer* → 英语，本义“把…摊平展开”，引申为“解释；说明”。

### 15. bit /bɪt/ n. 一部分

### 16. similar /ˈsɪmələr/ adj. 相像的；类似的

### 19. sticker /ˈstɪkər/ n. 贴纸
- **词根·渊源**：古英语 **stician**（刺、粘附）→ 中古英语 *stiken* → 英语 stick（粘贴）+ 后缀 **-er**（表物），本义“粘贴之物”→ 贴纸。
