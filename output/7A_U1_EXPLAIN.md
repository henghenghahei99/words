## 二、逐词说文解字

### 1. guitar /gɪˈtɑr/ n. 吉他
- **词根·渊源**：希腊 **kithara**（一种弦乐器）→ 阿拉伯语 *qītār* → 西班牙语 *guitarra* → 英语 guitar；本义即“弦乐器”，词义基本未变。
- **同根词**：guitarist（guitar + **-ist** 人 = 弹吉他的人→吉他手）、guitarfish（guitar + fish 鱼 = 形似吉他的鱼→吉他鱼）。
- **前缀·后缀**：名词后缀 **-ist**（例：artist, pianist）。
- **同义·反义**：同义 无；反义 无。
- **变形**：名词 → 复数：guitars；名词派生 → guitarist n. 吉他手。

### 2. honest /ˈɑnəst/ adj. 诚实的
- **词根·渊源**：拉丁 **honos / honor-**（荣誉、尊敬）→ 古法语 *honeste* → 英语 honest；本义“有荣誉的、可敬的”，引申为“诚实的”。
- **同根词**：honesty（honest + **-y** 名词后缀 = 诚实）、honor（honor 荣誉→尊敬）、honorable（honor + **-able** 可…的 = 值得尊敬的→光荣的）、dishonest（**dis-** 不 + honest = 不诚实的）。
- **前缀·后缀**：形容词后缀 **-est**（例：modest, modest）；否定前缀 **dis-**（例：dishonest, disagree）。
- **同义·反义**：同义 truthful（诚实的）, sincere（真诚的）；反义 dishonest（不诚实的）, deceitful（欺骗的）。
- **变形**：形容词 → 比较级：more honest；最高级：most honest；名词派生 → honesty n. 诚实；副词派生 → honestly adv. 诚实地。

### 3. patient /ˈpeɪʃənt/ adj. 有耐心的
- **词根·渊源**：拉丁 **pati / pass-**（忍受、受苦）→ 拉丁 *patientem*（忍受的）→ 古法语 *patient* → 英语 patient；本义“能忍受的”，引申为“有耐心的”；名词义“病人”即“受苦者”。
- **同根词**：patience（pati 忍受 + **-ence** 名词后缀 = 耐心）、impatient（**im-** 不 + patient = 不耐烦的）、compatible（**com-** 共同 + pati 忍受 = 能共同忍受的→兼容的）、passion（pass 受苦 + **-ion** 名词后缀 = 受难→激情）。
- **前缀·后缀**：形容词后缀 **-ent**（例：different, silent）；否定前缀 **im-**（例：impossible, impolite）。
- **同义·反义**：同义 tolerant（容忍的）, forbearing（克制的）；反义 impatient（不耐烦的）, hasty（急躁的）。
- **变形**：形容词 → 比较级：more patient；最高级：most patient；名词 → 复数：patients；名词派生 → patience n. 耐心；副词派生 → patiently adv. 耐心地。

### 4. improve /ˌɪmˈpruv/ v. 改进；改善
- **词根·渊源**：古法语 *emprower*（使获利）← **en-** 使 + *prou* 利益（源自拉丁 **prode** 有利）→ 英语 improve；本义“使有利可图”，引申为“改进、改善”。
- **同根词**：improvement（improve + **-ment** 名词后缀 = 改进）、improved（improve + **-ed** 形容词后缀 = 改良的）、unimproved（**un-** 未 + improved = 未改善的）。
- **前缀·后缀**：动词前缀 **im-**（例：import, impose）；名词后缀 **-ment**（例：movement, development）。
- **同义·反义**：同义 better（改善）, enhance（提高）；反义 worsen（使恶化）, deteriorate（退化）。
- **变形**：动词 → 第三人称单数：improves；过去式：improved；过去分词：improved；现在分词：improving；名词派生 → improvement n. 改进；形容词派生 → improved adj. 改良的。

### 5. confident /ˈkɑnfədənt/ adj. 自信的；有自信心的
- **词根·渊源**：拉丁 **confidere**（完全信任）← **con-** 完全 + **fidere** 信任 → 法语 *confident* → 英语 confident；本义“完全信赖的”，引申为“自信的”。
- **同根词**：confidence（con- 完全 + fid 信任 + **-ence** 名词后缀 = 信心）、confidential（confident + **-ial** 形容词后缀 = 机密的）、faith（拉丁 fides 信任→信仰）、fidelity（fid 信任 + **-ity** 名词后缀 = 忠诚）。
- **前缀·后缀**：前缀 **con-**（例：connect, confirm）；形容词后缀 **-ent**（例：different, silent）。
- **同义·反义**：同义 assured（有把握的）, self-assured（自信的）；反义 diffident（缺乏自信的）, insecure（不安全的）。
- **变形**：形容词 → 比较级：more confident；最高级：most confident；名词派生 → confidence n. 信心；副词派生 → confidently adv. 自信地。

### 6. courage /kərɪʤ/ n. 勇气；胆量
- **词根·渊源**：拉丁 **cor / cord-**（心）→ 古法语 *corage*，本义“由心而发的力量”，即“勇气”；与 heart 同出 PIE *kerd-*。
- **同根词**：courageous（courage + **-ous** …的：勇敢的）、encourage（**en-** 使 + corage 心 = 给心打气→鼓励）、discourage（**dis-** 去除 + courage = 夺心→使气馁）、cordial（cor 心 + **-ial** 出自内心的→衷心的）、record（**re-** 回 + cor 心 = 记在心里→记录）、cardiac（希腊 kardia 心 + **-ac** 心脏的）。
- **前缀·后缀**：名词后缀 **-age**（例：marriage, package）；动词化前缀 **en-**（例：enable）、**dis-**（例：disagree）。
- **同义·反义**：同义 bravery（勇气）, boldness（大胆）；反义 cowardice（怯懦）, timidity（胆小）。
- **变形**：名词 → 复数：courages（多用不可数）；形容词派生 → courageous adj. 勇敢的；副词派生 → courageously adv. 勇敢地；动词派生 → encourage v. 鼓励；discourage v. 使气馁。

### 7. friendship /ˈfrɛndʃɪp/ n. 友谊；朋友关系
- **词根·渊源**：古英语 **frēond**（朋友，原为 freon“爱”的现在分词）+ **-scipe**（状态、关系）→ 英语 friendship；本义“朋友的身份/状态”，即“友谊”。
- **同根词**：friend（frēond 爱→朋友）、friendly（friend + **-ly** 形容词后缀 = 友好的）、friendliness（friendly + **-ness** 名词后缀 = 友好）、befriend（**be-** 使 + friend = 以朋友相待→帮助）。
- **前缀·后缀**：名词后缀 **-ship**（例：hardship, leadership）；形容词后缀 **-ly**（例：kindly, lovely）。
- **同义·反义**：同义 companionship（陪伴）, fellowship（友谊）；反义 enmity（敌意）, hostility（敌视）。
- **变形**：名词 → 复数：friendships；形容词派生 → friendly adj. 友好的；名词派生 → friend n. 朋友。

### 8. admiration /ˌædmərˈeɪʃən/ n. 钦佩；赞赏
- **词根·渊源**：拉丁 **admirari**（惊叹）← **ad-** 向 + **mirari** 惊奇（源自 mirus 奇妙的）→ 拉丁 *admiratio* → 古法语 → 英语 admiration；本义“对…感到惊奇”，引申为“钦佩、赞赏”。
- **同根词**：admire（**ad-** 向 + mir 惊奇 = 对…惊奇→钦佩）、admirable（admire + **-able** 可…的 = 值得钦佩的）、miracle（mir 惊奇 + **-acle** 名词后缀 = 奇迹）、mirror（mir 惊奇 + **-or** 名词后缀 = 映照之物→镜子）。
- **前缀·后缀**：前缀 **ad-**（例：advance, admit）；名词后缀 **-ation**（例：information, education）。
- **同义·反义**：同义 respect（尊敬）, esteem（敬重）；反义 contempt（蔑视）, scorn（轻蔑）。
- **变形**：名词 → 复数：admirations（多用不可数）；动词派生 → admire v. 钦佩；形容词派生 → admirable adj. 令人钦佩的；副词派生 → admiringly adv. 钦佩地。

### 9. respect /rɪˈspɛkt/ n. 尊敬；尊重
- **词根·渊源**：拉丁 **respectus**（回头看、顾及）← **re-** 回 + **specere** 看 → 法语 *respect* → 英语 respect；本义“回头看→顾及”，引申为“尊敬、尊重”。
- **同根词**：respectful（respect + **-ful** 充满…的 = 恭敬的）、respectable（respect + **-able** 可…的 = 可敬的）、inspect（**in-** 向内 + spect 看 = 向内看→检查）、spectator（spect 看 + **-ator** 人 = 观看者→观众）、suspect（**sus-** 下 + spect 看 = 从下看→怀疑）。
- **前缀·后缀**：前缀 **re-**（例：return, review）；名词后缀 **-t**（例：effect, product）。
- **同义·反义**：同义 esteem（敬重）, regard（尊重）；反义 contempt（蔑视）, disrespect（不敬）。
- **变形**：名词 → 复数：respects；动词 → 第三人称单数：respects；过去式：respected；过去分词：respected；现在分词：respecting；形容词派生 → respectful adj. 恭敬的；副词派生 → respectfully adv. 恭敬地。

### 10. support /səˈpɔrt/ n. 支持；鼓励
- **词根·渊源**：拉丁 **supportare**（从下面搬运、支撑）← **sub-** 在下 + **portare** 搬运 → 古法语 *supporter* → 英语 support；本义“从下面托住”，引申为“支持、鼓励”。
- **同根词**：supporter（support + **-er** 人 = 支持者）、supportive（support + **-ive** 形容词后缀 = 支持的）、portable（port 搬运 + **-able** 可…的 = 可携带的）、transport（**trans-** 转移 + port 搬运 = 运输）、export（**ex-** 出 + port 搬运 = 出口）。
- **前缀·后缀**：前缀 **sup-**（=sub-，例：suppose, suppress）；名词后缀 **-er**（例：teacher, worker）。
- **同义·反义**：同义 backing（支持）, encouragement（鼓励）；反义 opposition（反对）, hindrance（阻碍）。
- **变形**：名词 → 复数：supports；动词 → 第三人称单数：supports；过去式：supported；过去分词：supported；现在分词：supporting；形容词派生 → supportive adj. 支持的；名词派生 → supporter n. 支持者。

### 11. trust /trəst/ n. 信任；信赖
- **词根·渊源**：古诺斯语 **traust**（信任、依靠）→ 中古英语 trust；与 true（真实的）同出日耳曼语根，本义“可靠、忠实”，引申为“信任”。
- **同根词**：trusty（trust + **-y** 形容词后缀 = 可靠的）、trustful（trust + **-ful** 充满…的 = 信任的）、distrust（**dis-** 不 + trust = 不信任）、truth（true 真实 + **-th** 名词后缀 = 真理）。
- **前缀·后缀**：名词后缀 **-y**（例：rainy, healthy）；否定前缀 **dis-**（例：dislike, disagree）。
- **同义·反义**：同义 confidence（信心）, reliance（依赖）；反义 distrust（不信任）, suspicion（怀疑）。
- **变形**：名词 → 复数：trusts；动词 → 第三人称单数：trusts；过去式：trusted；过去分词：trusted；现在分词：trusting；形容词派生 → trustful adj. 信任的；副词派生 → trustingly adv. 信任地。

### 12. survey /ˈsərˌveɪ/ n. 调查
- **词根·渊源**：盎格鲁-法语 *surveier*（俯视、查看）← **sur-** 在上 + **veier** 看（源自拉丁 videre 看）→ 英语 survey；本义“从上面看→审视”，引申为“调查”。
- **同根词**：surveyor（survey + **-or** 人 = 测量员）、surveying（survey + **-ing** 名词后缀 = 测量）、view（拉丁 videre 看→视野）、vision（vid 看 + **-ion** 名词后缀 = 视力→远见）、visible（vis 看 + **-ible** 可…的 = 可见的）。
- **前缀·后缀**：前缀 **sur-**（=super-，例：surface, surpass）；名词后缀 **-or**（例：actor, visitor）。
- **同义·反义**：同义 investigation（调查）, poll（民意调查）；反义 无。
- **变形**：名词 → 复数：surveys；动词 → 第三人称单数：surveys；过去式：surveyed；过去分词：surveyed；现在分词：surveying；名词派生 → surveyor n. 测量员。

### 13. personal /ˈpərsɪnəl/ adj. 个性的
- **词根·渊源**：拉丁 **persona**（面具、角色→人）→ 拉丁 *personalis* → 英语 personal；本义“属于人的/角色的”，引申为“个人的、个性的”。
- **同根词**：person（persona 面具→人）、personality（personal + **-ity** 名词后缀 = 个性）、personally（personal + **-ly** 副词后缀 = 亲自地）、personify（person + **-ify** 使…化 = 使人格化→体现）。
- **前缀·后缀**：形容词后缀 **-al**（例：natural, national）；名词后缀 **-ity**（例：activity, reality）。
- **同义·反义**：同义 individual（个人的）, private（私人的）；反义 public（公共的）, impersonal（非个人的）。
- **变形**：形容词 → 比较级：more personal；最高级：most personal；名词派生 → personality n. 个性；副词派生 → personally adv. 亲自地。

### 14. quality /kˈwɑləti/ n. 品质；品德
- **词根·渊源**：拉丁 **qualis**（什么样的）→ 拉丁 *qualitas*（性质）→ 古法语 *qualité* → 英语 quality；本义“某物是什么样的→性质”，引申为“品质、品德”。
- **同根词**：qualify（quali 性质 + **-fy** 使… = 使具有性质→使合格）、qualification（qualify + **-ication** 名词后缀 = 资格）、qualitative（quality + **-ative** 形容词后缀 = 定性的）。
- **前缀·后缀**：名词后缀 **-ity**（例：activity, reality）；动词后缀 **-fy**（例：simplify, beautify）。
- **同义·反义**：同义 characteristic（特征）, trait（品质）；反义 无。
- **变形**：名词 → 复数：qualities；动词派生 → qualify v. 使合格；形容词派生 → qualitative adj. 定性的。

### 15. caring /ˈkɛrɪŋ/ adj. 关心他人的；体贴人的
- **词根·渊源**：古英语 **cearu**（忧虑、关心）→ 中古英语 care（关心）+ **-ing** 形容词后缀 → 英语 caring；本义“充满关心的”，即“体贴人的”。
- **同根词**：care（cearu 忧虑→关心）、careful（care + **-ful** 充满…的 = 小心的）、careless（care + **-less** 无…的 = 粗心的）、carefree（care + free 无 = 无忧无虑的）。
- **前缀·后缀**：形容词后缀 **-ing**（例：interesting, exciting）；否定后缀 **-less**（例：hopeless, homeless）。
- **同义·反义**：同义 kind（善良的）, thoughtful（体贴的）；反义 careless（粗心的）, indifferent（冷漠的）。
- **变形**：形容词 → 比较级：more caring；最高级：most caring；名词派生 → care n. 关心；副词派生 → caringly adv. 关心地。

### 16. describe /dɪˈskraɪb/ v. 描述；形容
- **词根·渊源**：拉丁 **describere**（写下、描摹）← **de-** 向下 + **scribere** 写 → 英语 describe；本义“写下来”，引申为“描述、形容”。
- **同根词**：description（de- 向下 + script 写 + **-ion** 名词后缀 = 描述）、descriptive（describe + **-ive** 形容词后缀 = 描述性的）、scribe（scribere 写→抄写员）、prescribe（**pre-** 预先 + scribe 写 = 预先写→开处方）、script（script 写→手稿）。
- **前缀·后缀**：前缀 **de-**（例：decline, decrease）；动词后缀 **-scribe**（例：prescribe, subscribe）。
- **同义·反义**：同义 depict（描绘）, portray（描写）；反义 无。
- **变形**：动词 → 第三人称单数：describes；过去式：described；过去分词：described；现在分词：describing；名词派生 → description n. 描述；形容词派生 → descriptive adj. 描述性的。

### 17. appearance /əˈpɪrəns/ n. 外貌
- **词根·渊源**：拉丁 **apparere**（出现）← **ad-** 向 + **parere** 出现 → 古法语 *apparence* → 英语 appearance；本义“出现”，引申为“外貌、外观”。
- **同根词**：appear（**ap-** 向 + pear 出现 = 出现）、apparent（apparere 出现 + **-ent** 形容词后缀 = 明显的）、disappear（**dis-** 不 + appear = 消失）、transparent（**trans-** 穿过 + par 出现 + **-ent** = 穿过去可见的→透明的）。
- **前缀·后缀**：前缀 **ap-**（=ad-，例：apply, approve）；名词后缀 **-ance**（例：importance, distance）。
- **同义·反义**：同义 look（外表）, aspect（外观）；反义 disappearance（消失）。
- **变形**：名词 → 复数：appearances；动词派生 → appear v. 出现；形容词派生 → apparent adj. 明显的。

### 18. straight /streɪt/ adj. 直的
- **词根·渊源**：中古英语 **streght**（拉紧的、直的），为 strecchen（拉直）的过去分词，与 stretch 同源 → 英语 straight；本义“被拉紧的”，引申为“直的”。
- **同根词**：stretch（strecchen 拉直→伸展）、straighten（straight + **-en** 使… = 使直）、straightforward（straight + forward 向前 = 直截了当的）、straightness（straight + **-ness** 名词后缀 = 直）。
- **前缀·后缀**：动词后缀 **-en**（例：widen, strengthen）；名词后缀 **-ness**（例：kindness, darkness）。
- **同义·反义**：同义 direct（直接的）, upright（笔直的）；反义 crooked（弯曲的）, curved（弯曲的）。
- **变形**：形容词 → 比较级：straighter；最高级：straightest；副词 → 无比较级（straight 兼 adv. 直接地）；动词派生 → straighten v. 使直；名词派生 → straightness n. 直。

### 19. dark /dɑrk/ adj. 褐色的；乌黑的
- **词根·渊源**：古英语 *deorc*（暗的、阴郁的）→ 中古英语 *derk* → 英语 dark；与古高地德语 *tarchan*（使暗）同源，本义“缺乏光线的”，引申指颜色深、接近黑或褐。
- **同根词**：darkness（dark + **-ness** 名词后缀：黑暗）、darken（dark + **-en** 动词后缀：使变暗）、darkly（dark + **-ly** 副词后缀：阴暗地）、darkroom（dark + room 房间 = 暗室）。
- **前缀·后缀**：形容词后缀 **-ly** 构成副词（例：quickly, slowly）；动词后缀 **-en**（例：widen, sharpen）；名词后缀 **-ness**（例：kindness, happiness）。
- **同义·反义**：同义 black（黑色的）, dim（昏暗的）；反义 bright（明亮的）, light（浅色的）。
- **变形**：形容词 → 比较级：darker；最高级：darkest；名词派生 → darkness n. 黑暗；动词派生 → darken v. 使变暗；副词派生 → darkly adv. 阴暗地。

### 20. same /seɪm/ adj. 同一的；相同的
- **词根·渊源**：古诺斯语 *samr*（相同的）→ 古英语 *same* → 中古英语 same；与拉丁 *similis*（相似的）、希腊 *homos*（相同的）同出 PIE *sem-*（一、一起），本义“同一个”，引申为“相同的”。
- **同根词**：similar（拉丁 similis 相似 + **-ar** 形容词后缀：相似的）、simile（拉丁 similis 相似：明喻）、simultaneous（拉丁 simul 同时 + **-aneous** …的：同时的）、assemble（**as-** 向 + 拉丁 simul 一起 = 聚到一起→集合）。
- **前缀·后缀**：前缀 **sim-**（例：simple, similar）；形容词后缀 **-ar**（例：familiar, popular）。
- **同义·反义**：同义 identical（完全相同的）, equal（相等的）；反义 different（不同的）, various（各种各样的）。
- **变形**：形容词 → 无比较级（表“同一的”时不作比较；表“相同的”可用 more/most）；名词派生 → sameness n. 相同、千篇一律；副词派生 → same 本身不作副词，用 similarly adv. 同样地。

### 21. basic /ˈbeɪsɪk/ adj. 基本的；基础的
- **词根·渊源**：希腊 *basis*（步、基础）→ 拉丁 *basis* → 英语 base + 形容词后缀 **-ic**；basic 本义“作为基础的”，引申为“基本的、基础的”。
- **同根词**：base（拉丁 basis 基础：基础、基地）、basis（希腊 basis 基础：基础、根据）、basically（basic + **-ally** 副词后缀：基本上）、basement（base + **-ment** 名词后缀：地下室）。
- **前缀·后缀**：形容词后缀 **-ic**（例：music, public）；副词后缀 **-ally**（例：typically, practically）；名词后缀 **-ment**（例：movement, development）。
- **同义·反义**：同义 fundamental（基本的）, elementary（初级的）；反义 advanced（高级的）, complex（复杂的）。
- **变形**：形容词 → 比较级：more basic；最高级：most basic；副词派生 → basically adv. 基本上；名词派生 → basic n. 基础、基本要素（复数 basics）。

### 22. thought /θɔt/ n. 想法
- **词根·渊源**：古英语 *þencan*（思考）的过去分词 *geþoht* → 中古英语 thought；与 think 同源，本义“思考的结果”，引申为“想法、思想”。
- **同根词**：think（古英语 þencan 思考：想）、thoughtful（thought + **-ful** 充满…的：体贴的、深思的）、thoughtless（thought + **-less** 无…的：轻率的）、thank（古英语 þanc 思想、好意：感谢，与 think 同源）。
- **前缀·后缀**：形容词后缀 **-ful**（例：helpful, careful）；形容词后缀 **-less**（例：hopeless, careless）。
- **同义·反义**：同义 idea（想法）, notion（概念）；反义 无。
- **变形**：名词 → 复数：thoughts；形容词派生 → thoughtful adj. 体贴的；thoughtless adj. 轻率的；副词派生 → thoughtfully adv. 体贴地。

### 23. however /ˌhaʊˈɛvər/ adv. 然而；不过
- **词根·渊源**：how（如何）+ ever（任何时候）→ 中古英语 *how ever*，本义“无论怎样”，后引申为转折副词“然而、不过”。
- **同根词**：whatever（what + ever 无论什么）、whoever（who + ever 无论谁）、whenever（when + ever 无论何时）、wherever（where + ever 无论哪里）。
- **前缀·后缀**：后缀 **-ever**（例：whatever, whoever）。
- **同义·反义**：同义 nevertheless（然而）, yet（然而）；反义 therefore（因此）, thus（因此）。
- **变形**：副词 → 无比较级（连接副词，不作比较）；无词性派生。

### 24. glad /glæd/ adj. 高兴的；愉快的
- **词根·渊源**：古英语 *glæd*（明亮的、高兴的）→ 中古英语 glad；与古诺斯语 *glaðr*（明亮的、高兴的）同源，本义“光亮、明朗”，引申为“心情愉快的”。
- **同根词**：gladly（glad + **-ly** 副词后缀：高兴地）、gladness（glad + **-ness** 名词后缀：高兴）、gladden（glad + **-en** 动词后缀：使高兴）。
- **前缀·后缀**：副词后缀 **-ly**（例：sadly, happily）；名词后缀 **-ness**（例：sadness, kindness）；动词后缀 **-en**（例：widen, brighten）。
- **同义·反义**：同义 happy（高兴的）, pleased（满意的）；反义 sad（悲伤的）, unhappy（不快乐的）。
- **变形**：形容词 → 比较级：gladder；最高级：gladdest；副词派生 → gladly adv. 高兴地；名词派生 → gladness n. 高兴；动词派生 → gladden v. 使高兴。

### 25. rise /raɪz/ v. 上升
- **词根·渊源**：古英语 *rīsan*（起来、升起）→ 中古英语 risen → 英语 rise；与古诺斯语 *rísa* 同源，本义“起身、升起”，引申为“上升、增长”。
- **同根词**：arise（**a-** 加强 + rise 升起：出现、产生）、raise（古诺斯语 reisa 使升起：举起、提高，与 rise 同源）、risen（rise 的过去分词：升起的）、sunrise（sun 太阳 + rise 升起：日出）。
- **前缀·后缀**：前缀 **a-**（例：arise, awake）；复合词 sun + rise（例：sunrise, sunset）。
- **同义·反义**：同义 ascend（上升）, climb（攀登）；反义 fall（下降）, descend（下降）。
- **变形**：动词 → 第三人称单数：rises；过去式：rose；过去分词：risen；现在分词：rising；名词派生 → rise n. 上升、增加。

### 26. end /ɛnd/ n. 结局
- **词根·渊源**：古英语 *ende*（末端、结局）→ 中古英语 end；与古高地德语 *enti* 同源，本义“尽头、末端”，引申为“结局、结束”。
- **同根词**：ending（end + **-ing** 名词后缀：结局、结尾）、endless（end + **-less** 无…的：无止境的）、endwise（end + wise 方向：末端朝前的）、weekend（week 周 + end 末端：周末）。
- **前缀·后缀**：名词后缀 **-ing**（例：beginning, meeting）；形容词后缀 **-less**（例：hopeless, careless）。
- **同义·反义**：同义 finish（结束）, conclusion（结论、结局）；反义 beginning（开始）, start（开端）。
- **变形**：名词 → 复数：ends；动词派生 → end v. 结束；形容词派生 → endless adj. 无止境的；副词派生 → endlessly adv. 无止境地。

### 27. heart /hɑrt/ n. 心
- **词根·渊源**：古英语 *heorte*（心）→ 中古英语 herte → 英语 heart；与拉丁 *cor / cord-*（心）、希腊 *kardia*（心）同出 PIE *kerd-*，本义“心脏”，引申为“内心、感情、核心”。
- **同根词**：hearty（heart + **-y** 形容词后缀：衷心的、丰盛的）、heartless（heart + **-less** 无…的：无情的）、heartily（hearty + **-ly** 副词后缀：衷心地）、cordial（拉丁 cor 心 + **-ial** …的：衷心的）、record（**re-** 回 + cor 心 = 记在心里→记录）。
- **前缀·后缀**：形容词后缀 **-y**（例：rainy, windy）；形容词后缀 **-less**（例：hopeless, careless）；副词后缀 **-ly**（例：happily, quickly）。
- **同义·反义**：同义 core（核心）, center（中心）；反义 无。
- **变形**：名词 → 复数：hearts；形容词派生 → hearty adj. 衷心的；heartless adj. 无情的；副词派生 → heartily adv. 衷心地。
