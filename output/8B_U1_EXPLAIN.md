## 二、逐词说文解字

### 1. raise /reɪz/ v. 筹募；募集；征集；增加；提高
- **词根·渊源**：古北欧语 *reisa*（使升起）→ 中古英语 *reisen*，本义“使升起、举起”，引申为“提高、增加”，再引申为“筹集（资金）”。
- **同根词**：rise（古英语 *rīsan* 自身升起→上升）、arise（**a-** 加强 + rise 升起→出现、产生）、rouse（源自古法语 *reuser*，与 raise 同源→唤醒、激起）。
- **前缀·后缀**：无前后缀（单纯词）。
- **同义·反义**：同义 lift（举起）, increase（增加）, collect（募集）；反义 lower（降低）, decrease（减少）。
- **变形**：动词 → 第三人称单数：raises；过去式：raised；过去分词：raised；现在分词：raising；名词派生 → raise n. 加薪、提高。

### 2. permission /pərˈmɪʃn/ n. 准许；批准；同意，许可
- **词根·渊源**：拉丁 **mittere / miss-**（送、放）→ 拉丁 *permittere*（让通过、允许）→ 古法语 *permission* → 英语，本义“放行、让其通过”，引申为“准许、许可”。
- **同根词**：permit（**per-** 通过 + mit 送 = 让通过→允许）、admit（**ad-** 向 + mit 送 = 送入→准许进入、承认）、submit（**sub-** 下 + mit 送 = 送到下面→提交、屈服）、transmit（**trans-** 横过 + mit 送 = 送过去→传送）、mission（miss 送 + **-ion** 名词后缀 = 被送出的事→使命）、dismiss（**dis-** 离开 + miss 送 = 送走→解散、解雇）。
- **前缀·后缀**：前缀 **per-**（例：perfect, perform）；名词后缀 **-ion**（例：action, decision）。
- **同义·反义**：同义 consent（同意）, authorization（授权）；反义 refusal（拒绝）, prohibition（禁止）。
- **变形**：名词 → 复数：permissions；动词派生 → permit v. 允许；形容词派生 → permissible adj. 可允许的；副词派生 → permissibly adv. 可允许地。

### 3. disabled /dɪsˈebəld/ adj. 丧失能力的；有残疾的
- **词根·渊源**：拉丁 **habilitas**（能力）→ 古法语 *able*（有能力的）→ 英语 able；加否定前缀 **dis-** 与形容词后缀 **-ed**，本义“被剥夺能力的”，引申为“有残疾的”。
- **同根词**：able（拉丁 *habilis* 易于操控的→有能力的）、ability（abil 能力 + **-ity** 名词后缀 = 能力）、enable（**en-** 使 + able 能 = 使能够）、disable（**dis-** 去除 + able 能 = 使失去能力）、unable（**un-** 不 + able 能 = 不能的）。
- **前缀·后缀**：前缀 **dis-**（例：disagree, disappear）；形容词后缀 **-ed**（例：talented, aged）。
- **同义·反义**：同义 handicapped（有残疾的）, impaired（受损的）；反义 able-bodied（体格健全的）, healthy（健康的）。
- **变形**：形容词 → 无比较级（关系形容词，不作比较）；名词派生 → disability n. 残疾、无能力；动词派生 → disable v. 使失去能力。

### 4. teenager /ˈtiːneɪdʒər/ n. 少年；青少年
- **词根·渊源**：英语 **teen**（13–19 的数词后缀 -teen）+ **age**（年龄）+ **-er**（人），本义“处于 -teen 年龄段的人”，即 13 至 19 岁的青少年。
- **同根词**：teenage（teen + age 年龄 = 青少年的）、teens（teen 的复数 = 十几岁）、thirteen（古英语 *þrēotīene* = 十三）、fifteen（古英语 *fīftīene* = 十五）、eighteen（古英语 *eahtatīene* = 十八）。
- **前缀·后缀**：名词后缀 **-er**（例：teacher, worker）；组合成分 **-teen**（例：fourteen, sixteen）。
- **同义·反义**：同义 adolescent（青少年）, youth（年轻人）；反义 adult（成年人）, senior（年长者）。
- **变形**：名词 → 复数：teenagers；形容词派生 → teenage adj. 青少年的。

### 5. offer /ˈɔːfər/ v. 提供；主动提出
- **词根·渊源**：拉丁 **offerre**（ob- 向 + ferre 拿、带 = 拿到面前）→ 古英语 *offrian*（献祭）→ 中古英语，本义“献上、呈上”，引申为“提供、主动提出”。
- **同根词**：transfer（**trans-** 横过 + fer 带 = 带过去→转移）、refer（**re-** 回 + fer 带 = 带回→提及、参考）、prefer（**pre-** 前 + fer 拿 = 拿到前面→更喜欢）、confer（**con-** 共同 + fer 带 = 带到一起→商议、授予）、differ（**dif-** 分开 + fer 带 = 分开带→不同）、fertile（fer 带来 + **-tile** 形容词后缀 = 能带来果实的→肥沃的）。
- **前缀·后缀**：前缀 **of-（ob-）**（例：occur, oppose）；无后缀（动词词干）。
- **同义·反义**：同义 provide（提供）, propose（提出）；反义 refuse（拒绝）, withdraw（撤回）。
- **变形**：动词 → 第三人称单数：offers；过去式：offered；过去分词：offered；现在分词：offering；名词派生 → offer n. 提议、报价；offering n. 供品、提供物。

### 6. suffer /ˈsʌfɚ/ v.（因疾病等）受苦；受折磨；患有（疾病等）；经受
- **词根·渊源**：拉丁 **sufferre**（sub- 在下 + ferre 承受 = 在下面承受）→ 古法语 *soffrir* → 英语，本义“在下面承受、忍受”，引申为“受苦、受折磨、患病”。
- **同根词**：suffering（suffer + **-ing** 名词后缀 = 痛苦）、sufferance（suffer + **-ance** 名词后缀 = 容忍）、transfer（**trans-** 横过 + fer 带 = 转移）、refer（**re-** 回 + fer 带 = 提及）、prefer（**pre-** 前 + fer 拿 = 更喜欢）。
- **前缀·后缀**：前缀 **suf-（sub-）**（例：support, suggest）；无后缀（动词词干）。
- **同义·反义**：同义 endure（忍受）, undergo（经受）；反义 enjoy（享受）, relieve（缓解）。
- **变形**：动词 → 第三人称单数：suffers；过去式：suffered；过去分词：suffered；现在分词：suffering；名词派生 → suffering n. 痛苦；sufferer n. 受苦者。

### 7. serious /ˈsɪriəs/ adj. 重要的；认真的，严肃的；严重的
- **词根·渊源**：拉丁 **serius**（重的、庄重的）→ 晚期拉丁 *seriosus* → 古法语 *serieux* → 英语，本义“有分量的、庄重的”，引申为“认真的、严肃的、严重的、重要的”。
- **同根词**：seriously（serious + **-ly** 副词后缀 = 认真地、严重地）、seriousness（serious + **-ness** 名词后缀 = 严肃、严重）、serious-minded（serious + minded 心思的 = 认真的）。
- **前缀·后缀**：形容词后缀 **-ous**（例：famous, dangerous）。
- **同义·反义**：同义 grave（严重的）, earnest（认真的）；反义 trivial（琐碎的）, joking（开玩笑的）。
- **变形**：形容词 → 比较级：more serious；最高级：most serious；副词派生 → seriously adv. 认真地、严重地；名词派生 → seriousness n. 严肃、严重。

### 8. illness /ˈɪlnəs/ n. 病，疾病
- **词根·渊源**：古北欧语 *illr*（坏的）→ 中古英语 *ille*（坏的、邪恶的）+ 名词后缀 **-ness**，本义“坏的状态”，引申为“身体不好的状态→疾病”。
- **同根词**：ill（古北欧语 *illr* 坏的→生病的、坏的）、illness 之外如 ill-tempered（ill + tempered 脾气的 = 脾气坏的）、illness 的同根词还有 ill health（ill + health 健康 = 健康不佳）。
- **前缀·后缀**：名词后缀 **-ness**（例：happiness, kindness）。
- **同义·反义**：同义 sickness（疾病）, disease（疾病）；反义 health（健康）, wellness（健康）。
- **变形**：名词 → 复数：illnesses；形容词派生 → ill adj. 生病的、坏的。

### 9. express /ɪkˈsprɛs/ v. 表示；表达；表露
- **词根·渊源**：拉丁 **exprimere**（ex- 出 + premere 压 = 压出）→ 古法语 *expresser* → 英语，本义“压出、挤出”，引申为“把想法压出来→表达”。
- **同根词**：expression（express + **-ion** 名词后缀 = 表达、表情）、expressive（express + **-ive** 形容词后缀 = 富有表现力的）、press（拉丁 *premere* 压→按压）、compress（**com-** 共同 + press 压 = 压在一起→压缩）、impress（**im-** 进入 + press 压 = 压入→给…深刻印象）、depress（**de-** 向下 + press 压 = 压下→使沮丧）。
- **前缀·后缀**：前缀 **ex-**（例：export, exit）；无后缀（动词词干）。
- **同义·反义**：同义 convey（传达）, state（陈述）；反义 suppress（压抑）, hide（隐藏）。
- **变形**：动词 → 第三人称单数：expresses；过去式：expressed；过去分词：expressed；现在分词：expressing；名词派生 → expression n. 表达、表情；形容词派生 → expressive adj. 富有表现力的。

### 10. pain /peɪn/ n. 疼痛；痛苦；苦恼
- **词根·渊源**：拉丁 **poena**（惩罚、代价）→ 古法语 *peine*（惩罚、痛苦）→ 英语，本义“惩罚带来的痛苦”，引申为“疼痛、痛苦、苦恼”。
- **同根词**：painful（pain + **-ful** 充满…的 = 疼痛的）、painless（pain + **-less** 无…的 = 无痛的）、penalty（拉丁 *poena* 惩罚 + **-ty** 名词后缀 = 处罚）、punish（拉丁 *punire* 惩罚→惩罚）、repent（**re-** 回 + pent 源自 poena 惩罚 = 回头悔恨→后悔）。
- **前缀·后缀**：无前后缀（单纯词）。
- **同义·反义**：同义 ache（疼痛）, suffering（痛苦）；反义 pleasure（快乐）, comfort（舒适）。
- **变形**：名词 → 复数：pains；形容词派生 → painful adj. 疼痛的；painless adj. 无痛的；副词派生 → painfully adv. 痛苦地。

### 11. lonely /ˈloʊnli/ adj. 孤独的；孤单的；寂寞的
- **词根·渊源**：中古英语 **alone**（al 全 + one 一 = 完全独自）→ 缩合为 *lone*（独自的）+ 形容词后缀 **-ly**，本义“独自一人的”，引申为“孤独的、寂寞的”。
- **同根词**：alone（**al-** 全 + one 一 = 完全独自→独自的）、lone（alone 缩合 = 独自的）、loneliness（lonely 变 y 为 i + **-ness** 名词后缀 = 孤独）、loner（lone + **-er** 人 = 独来独往的人）。
- **前缀·后缀**：形容词后缀 **-ly**（例：friendly, lovely）。
- **同义·反义**：同义 solitary（孤独的）, isolated（孤立的）；反义 accompanied（有人陪伴的）, sociable（好交际的）。
- **变形**：形容词 → 比较级：lonelier；最高级：loneliest；名词派生 → loneliness n. 孤独。

### 12. friendship /ˈfrendʃɪp/ n. 友情；友谊；友好
- **词根·渊源**：古英语 **frēond**（朋友，源自动词 *frēogan* 爱）+ 名词后缀 **-ship**（状态、关系），本义“朋友之间的关系”，即“友谊”。
- **同根词**：friend（古英语 *frēond* 爱着的人→朋友）、friendly（friend + **-ly** 形容词后缀 = 友好的）、friendless（friend + **-less** 无…的 = 无朋友的）、befriend（**be-** 使 + friend 朋友 = 以朋友相待→帮助）。
- **前缀·后缀**：名词后缀 **-ship**（例：hardship, leadership）。
- **同义·反义**：同义 companionship（陪伴）, amity（友好）；反义 enmity（敌意）, hostility（敌视）。
- **变形**：名词 → 复数：friendships；形容词派生 → friendly adj. 友好的。

### 13. difficulty /ˈdɪfɪkəlti/ n. 问题；困难；费劲；费力
- **词根·渊源**：拉丁 **difficultas**（dis- 不 + facilis 容易 = 不容易）→ 古法语 *difficulté* → 英语，本义“不容易的状态”，引申为“困难、费劲、难题”。
- **同根词**：difficult（dif- 不 + ficult 容易 = 困难的）、facile（拉丁 *facilis* 容易的→轻易的）、facility（facil 容易 + **-ity** 名词后缀 = 设施、便利）、facilitate（facil 容易 + **-itate** 动词后缀 = 使容易→促进）、fact（拉丁 *facere* 做→事实）。
- **前缀·后缀**：前缀 **dif-（dis-）**（例：differ, diffuse）；名词后缀 **-ty**（例：safety, beauty）。
- **同义·反义**：同义 problem（问题）, hardship（艰难）；反义 ease（容易）, simplicity（简单）。
- **变形**：名词 → 复数：difficulties；形容词派生 → difficult adj. 困难的。

### 14. joy /dʒɔɪ/ v. 愉快；欢乐，高兴；乐趣；喜悦
- **词根·渊源**：拉丁 **gaudium**（快乐）→ 古法语 *joie* → 英语，本义“快乐、欢欣”，引申为“喜悦、乐趣”。
- **同根词**：joyful（joy + **-ful** 充满…的 = 快乐的）、joyless（joy + **-less** 无…的 = 不快乐的）、enjoy（**en-** 使 + joy 快乐 = 使快乐→享受）、rejoice（**re-** 加强 + joice 快乐 = 使高兴→欢欣）。
- **前缀·后缀**：无前后缀（单纯词）。
- **同义·反义**：同义 delight（高兴）, pleasure（快乐）；反义 sorrow（悲伤）, sadness（难过）。
- **变形**：动词 → 第三人称单数：joys；过去式：joyed；过去分词：joyed；现在分词：joying；名词派生 → joy n. 喜悦；形容词派生 → joyful adj. 快乐的；副词派生 → joyfully adv. 快乐地。

### 15. peace /piːs/ n. 平静；宁静；和平
- **词根·渊源**：拉丁 **pax / pac-**（和平）→ 古法语 *pais* → 英语，本义“和平、安宁”，引申为“平静、宁静”。
- **同根词**：peaceful（peace + **-ful** 充满…的 = 和平的）、pacify（pac 和平 + **-ify** 使… = 使平静→安抚）、pacific（pac 和平 + **-ific** 造成…的 = 和平的）、pacifist（pac 和平 + **-ist** 人 = 和平主义者）。
- **前缀·后缀**：无前后缀（单纯词）。
- **同义·反义**：同义 calm（平静）, tranquility（宁静）；反义 war（战争）, conflict（冲突）。
- **变形**：名词 → 不可数；形容词派生 → peaceful adj. 和平的；副词派生 → peacefully adv. 和平地。

### 16. hurt /hɜːt/ v.（使）疼痛；受伤
- **词根·渊源**：古法语 **hurter**（撞击、冲撞）→ 中古英语 *hurten*，本义“撞击、猛碰”，引申为“使受伤、疼痛”。
- **同根词**：hurtful（hurt + **-ful** 充满…的 = 伤人的）、unhurt（**un-** 不 + hurt 受伤 = 未受伤的）、hurter（hurt + **-er** 人/物 = 造成伤害者）。
- **前缀·后缀**：无前后缀（单纯词）。
- **同义·反义**：同义 injure（伤害）, wound（使受伤）；反义 heal（治愈）, comfort（安慰）。
- **变形**：动词 → 第三人称单数：hurts；过去式：hurt；过去分词：hurt；现在分词：hurting；名词派生 → hurt n. 伤害、痛苦；形容词派生 → hurtful adj. 伤人的。

### 17. courage /ˈkɜ:rɪdʒ/ n. 勇敢；勇气；胆略
- **词根·渊源**：拉丁 **cor / cord-**（心）→ 古法语 *corage*，本义“由心而发的力量”，即“勇气”；与 heart 同出 PIE *kerd-*。
- **同根词**：courageous（courage + **-ous** …的 = 勇敢的）、encourage（**en-** 使 + corage 心 = 给心打气→鼓励）、discourage（**dis-** 去除 + courage = 夺心→使气馁）、cordial（cor 心 + **-ial** 出自内心的→衷心的）、record（**re-** 回 + cor 心 = 记在心里→记录）、cardiac（希腊 kardia 心 + **-ac** 心脏的）。
- **前缀·后缀**：名词后缀 **-age**（例：marriage, package）；动词化前缀 **en-**（例：enable）、**dis-**（例：disagree）。
- **同义·反义**：同义 bravery（勇气）, boldness（大胆）；反义 cowardice（怯懦）, timidity（胆小）。
- **变形**：名词 → 复数：courages（多用不可数）；形容词派生 → courageous adj. 勇敢的；副词派生 → courageously adv. 勇敢地；动词派生 → encourage v. 鼓励；discourage v. 使气馁。

### 18. spirits /ˈspɪrɪts/ n. 情绪；心境；态度
- **词根·渊源**：拉丁 **spiritus**（呼吸、气息）→ 古法语 *espirit* → 英语 spirit，本义“气息、灵魂”，复数 spirits 引申为“精神状态、情绪、心境”。
- **同根词**：spirit（拉丁 *spiritus* 呼吸→精神、灵魂）、spiritual（spirit + **-ual** 形容词后缀 = 精神的）、spirited（spirit + **-ed** 有…的 = 精神饱满的）、inspire（**in-** 进入 + spire 呼吸 = 吹入气息→鼓舞）、expire（**ex-** 出 + spire 呼吸 = 呼出最后一口气→到期、死亡）、respire（**re-** 反复 + spire 呼吸 = 呼吸）。
- **前缀·后缀**：名词后缀 **-s**（复数）（例：goods, manners）。
- **同义·反义**：同义 mood（情绪）, morale（士气）；反义 depression（沮丧）, gloom（忧郁）。
- **变形**：名词 → 复数：spirits（本词即复数形式）；形容词派生 → spirited adj. 精神饱满的；spiritual adj. 精神的。

### 19. pay /peɪ/ v. 付款,交款
- **词根·渊源**：拉丁 **pac-**（和平，使满意）→ 古法语 *paier*（使满意、偿付）→ 英语 pay；本义“使债主满意、平息债务”，引申为“付款”。
- **同根词**：payment（pay + **-ment** 名词后缀 = 付款）、payable（pay + **-able** 可…的 = 应付的）、peace（pac 和平 + **-e** = 和平）、pacify（pac 和平 + **-ify** 使… = 使平静）、pacifist（pac 和平 + **-ist** 人 = 和平主义者）。
- **前缀·后缀**：名词后缀 **-ment**（例：movement, development）；形容词后缀 **-able**（例：readable, comfortable）。
- **同义·反义**：同义 settle（结清）, compensate（补偿）；反义 owe（欠）, receive（收取）。
- **变形**：动词 → 第三人称单数：pays；过去式：paid；过去分词：paid；现在分词：paying；名词派生 → payment n. 付款；形容词派生 → payable adj. 应付的。

### 20. community /kəˈmjunɪti/ n. 社区；社团
- **词根·渊源**：拉丁 **commun-**（共同的）→ 古法语 *comunete* → 英语 community；本义“共同拥有、共同生活的人群”，引申为“社区、社团”。
- **同根词**：common（com 共同 + **-mon** 服务 = 共同的）、commune（com 共同 + **-mune** 义务 = 公社）、communicate（commun 共同 + **-icate** 使… = 交流共享）、communism（commun 共同 + **-ism** 主义 = 共产主义）、communion（commun 共同 + **-ion** 名词 = 共享、圣餐）。
- **前缀·后缀**：共同前缀 **com-**（例：combine, compare）；名词后缀 **-ity**（例：activity, ability）。
- **同义·反义**：同义 society（社会）, neighborhood（邻里）；反义 individual（个人）, isolation（孤立）。
- **变形**：名词 → 复数：communities；形容词派生 → communal adj. 公共的；副词派生 → communally adv. 共同地。
