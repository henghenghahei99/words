## 二、逐词说文解字

### 1. elderly /ˈɛldərli/ adj. 上了年纪的
- **词根·渊源**：古英语 **eld**（年老、年岁）→ 中古英语 *eldre*（更老的，old 的比较级）→ 英语 *elder* + 后缀 **-ly**，本义“较年长的”，引申为“上了年纪的”。
- **同根词**：elder（eld 老 + **-er** 比较级 = 年长的）、old（古英语 ald 年老→老的）、older（old + **-er** 比较级 = 较老的）、eldest（eld + **-est** 最高级 = 最年长的）。
- **前缀·后缀**：形容词后缀 **-ly**（例：friendly, lovely）。
- **同义·反义**：同义 aged（年老的）, old（老的）；反义 young（年轻的）, youthful（年轻的）。
- **变形**：形容词 → 无比较级（关系形容词，不作比较）；名词派生 → elderliness n. 年迈；副词派生 → elderlily adv. 上了年纪地（罕用）。

### 2. offer /ˈɔfər/ v. 主动提出
- **词根·渊源**：拉丁 **ob-**（向、在前）+ **ferre**（拿、带）→ 拉丁 *offerre*（呈上、奉献）→ 古英语 *offrian*（献祭）→ 英语 offer，本义“把东西捧到对方面前”，引申为“主动提出、提供”。
- **同根词**：transfer（**trans-** 横过 + fer 带 = 带过去→转移）、refer（**re-** 回 + fer 带 = 带回→提及、参考）、prefer（**pre-** 前 + fer 拿 = 拿到前面→更喜欢）、confer（**con-** 共同 + fer 带 = 带到一起→商议）、fertile（fer 带 + **-tile** 能带来的→肥沃的）。
- **前缀·后缀**：前缀 **ob-**（例：object）、**trans-**（例：transport）；动词后缀 **-er**（例：deliver）。
- **同义·反义**：同义 propose（提议）, provide（提供）；反义 refuse（拒绝）, withdraw（撤回）。
- **变形**：动词 → 第三人称单数：offers；过去式：offered；过去分词：offered；现在分词：offering；名词派生 → offer n. 提议、报价；offering n. 供品、献礼。

### 3. serious /ˈsɪriəs/ adj. 严重的
- **词根·渊源**：拉丁 **serius**（重的、庄重的）→ 晚期拉丁 *seriosus* → 古法语 *serieux* → 英语 serious，本义“有分量的、庄重的”，引申为“严肃的、严重的”。
- **同根词**：seriously（serious + **-ly** 副词后缀 = 严肃地、严重地）、seriousness（serious + **-ness** 名词后缀 = 严肃、严重）、seriocomedy（serio 严肃 + comedy 喜剧 = 严肃喜剧）。
- **前缀·后缀**：形容词后缀 **-ous**（例：famous, dangerous）。
- **同义·反义**：同义 grave（严重的）, severe（严重的）；反义 trivial（琐碎的）, slight（轻微的）。
- **变形**：形容词 → 比较级：more serious；最高级：most serious；名词派生 → seriousness n. 严重性；副词派生 → seriously adv. 严重地。

### 4. disease /dɪˈziz/ n. 病; 疾病
- **词根·渊源**：古法语 *desaise*（不适、不安）＝ **des-**（否定、相反）+ **aise**（安逸）→ 中古英语 *disease*，本义“不舒服、不安逸”，引申为“疾病”。
- **同根词**：ease（古法语 aise 安逸→轻松）、easy（ease + **-y** 形容词后缀 = 容易的）、uneasy（**un-** 不 + easy 安逸 = 不安的）、discomfort（**dis-** 相反 + comfort 舒适 = 不适）。
- **前缀·后缀**：否定前缀 **dis-**（例：disagree, disappear）。
- **同义·反义**：同义 illness（疾病）, sickness（疾病）；反义 health（健康）, wellness（健康）。
- **变形**：名词 → 复数：diseases；形容词派生 → diseased adj. 患病的；diseaseful adj. 有害的（罕用）。

### 5. cancer /ˈkænsər/ n. 癌; 癌症
- **词根·渊源**：拉丁 **cancer**（螃蟹）→ 希腊 *karkinos*（螃蟹）→ 英语 cancer；古希腊医生希波克拉底因肿瘤周围血管形似蟹足而用“螃蟹”命名，本义“螃蟹”，引申为“癌”。
- **同根词**：cancerous（cancer + **-ous** …的 = 癌的）、carcinogen（希腊 karkinos 蟹 + **-gen** 产生者 = 致癌物）、carcinoma（希腊 karkinos 蟹 + **-oma** 肿瘤 = 癌瘤）。
- **前缀·后缀**：名词后缀 **-oma**（例：sarcoma）、**-gen**（例：oxygen）。
- **同义·反义**：同义 malignancy（恶性肿瘤）, tumor（肿瘤）；反义 无。
- **变形**：名词 → 复数：cancers；形容词派生 → cancerous adj. 癌的；cancerous 副词派生 → cancerously adv. 癌性地（罕用）。

### 6. spirits /ˈspɪrɪts/ n. [pl.] 情绪; 心境
- **词根·渊源**：拉丁 **spiritus**（呼吸、气息、灵魂）← *spirare*（呼吸）→ 古法语 *espirit* → 英语 spirit，复数 spirits 本义“气息、精气”，引申为“情绪、心境”。
- **同根词**：spirit（spiritus 呼吸→精神）、spiritual（spirit + **-ual** …的 = 精神的）、inspire（**in-** 入 + spire 呼吸 = 吹气入内→鼓舞）、expire（**ex-** 出 + spire 呼吸 = 呼出最后一口气→到期、断气）、respire（**re-** 反复 + spire 呼吸 = 呼吸）、conspire（**con-** 共同 + spire 呼吸 = 同呼吸→密谋）。
- **前缀·后缀**：前缀 **in-**（例：inject）、**ex-**（例：export）；形容词后缀 **-ual**（例：actual）。
- **同义·反义**：同义 mood（情绪）, morale（士气）；反义 无。
- **变形**：名词 → 复数：spirits（本词即复数形式）；形容词派生 → spirited adj. 精神饱满的；spiritless adj. 无精打采的。

### 7. pain /peɪn/ n. 痛苦; 苦恼
- **词根·渊源**：拉丁 **poena**（惩罚、代价）→ 希腊 *poine*（罚金）→ 古法语 *peine*（惩罚、受苦）→ 英语 pain，本义“受罚、受苦”，引申为“痛苦、苦恼”。
- **同根词**：painful（pain + **-ful** 充满…的 = 痛苦的）、painless（pain + **-less** 无…的 = 无痛的）、penalty（拉丁 poena 惩罚 + **-alty** 名词后缀 = 处罚）、punish（拉丁 poena 惩罚 + **-ish** 动词后缀 = 惩罚）、repent（**re-** 回 + pent 悔 = 后悔→悔悟）。
- **前缀·后缀**：形容词后缀 **-ful**（例：helpful）、**-less**（例：hopeless）。
- **同义·反义**：同义 ache（疼痛）, suffering（痛苦）；反义 pleasure（快乐）, comfort（舒适）。
- **变形**：名词 → 复数：pains；形容词派生 → painful adj. 痛苦的；painless adj. 无痛的；副词派生 → painfully adv. 痛苦地。

### 8. belong /bɪˈlɔŋ/ v. 适应; 合得来
- **词源·渊源**：中古英语 *belongen*＝ **be-**（加强、使）+ **longen**（属于，源自古英语 *langian* 使适合）→ 英语 belong，本义“属于、适合”，引申为“适应、合得来”。
- **同根词**：belongings（belong + **-ings** 名词后缀 = 所有物）、belonging（belong + **-ing** 名词后缀 = 归属感）、long（古英语 langian 使适合→渴望，与 belong 同源，存疑）。
- **前缀·后缀**：加强前缀 **be-**（例：become, believe）。
- **同义·反义**：同义 fit（适合）, suit（适合）；反义 无。
- **变形**：动词 → 第三人称单数：belongs；过去式：belonged；过去分词：belonged；现在分词：belonging；名词派生 → belonging n. 归属；belongings n. 所有物。

### 9. spare /spɛr/ adj. 空闲的; 空余的
- **词根·渊源**：古英语 **sparian**（节省、饶恕）→ 中古英语 *spare*，本义“节省下来的、多余的”，引申为“空闲的、空余的”。
- **同根词**：sparing（spare + **-ing** 形容词后缀 = 节省的）、sparingly（sparing + **-ly** 副词后缀 = 节省地）、sparer（spare + **-er** 名词后缀 = 节省者）。
- **前缀·后缀**：形容词后缀 **-ing**（例：interesting）、副词后缀 **-ly**（例：quickly）。
- **同义·反义**：同义 free（空闲的）, extra（多余的）；反义 busy（忙的）, occupied（被占用的）。
- **变形**：形容词 → 比较级：sparer；最高级：sparest；动词派生 → spare v. 节省、抽出；名词派生 → spareness n. 节省；副词派生 → sparely adv. 节省地。

### 10. volunteer /ˌvɑlənˈtɪr/ v. 自愿做
- **词根·渊源**：拉丁 **voluntas**（意愿）← *velle*（想要）→ 古法语 *voluntaire* → 英语 volunteer，本义“出于意愿的人”，引申为“自愿做”。
- **同根词**：voluntary（拉丁 voluntas 意愿 + **-ary** …的 = 自愿的）、volition（拉丁 volo 我想要 + **-ition** 名词后缀 = 意志）、volunteerism（volunteer + **-ism** 主义 = 志愿精神）、benevolent（**bene-** 好 + vol 意愿 + **-ent** …的 = 好意的）。
- **前缀·后缀**：名词后缀 **-eer**（例：engineer, pioneer）；前缀 **bene-**（例：benefit）。
- **同义·反义**：同义 offer（主动提出）, enlist（自愿参加）；反义 force（强迫）, compel（强迫）。
- **变形**：动词 → 第三人称单数：volunteers；过去式：volunteered；过去分词：volunteered；现在分词：volunteering；名词派生 → volunteer n. 志愿者；形容词派生 → voluntary adj. 自愿的。

### 11. joy /ʤɔɪ/ n. 快乐；喜悦
- **词根·渊源**：拉丁 **gaudium**（快乐）← *gaudere*（高兴）→ 古法语 *joie* → 英语 joy，本义“高兴、快乐”，引申为“喜悦”。
- **同根词**：joyful（joy + **-ful** 充满…的 = 快乐的）、joyous（joy + **-ous** …的 = 喜悦的）、enjoy（**en-** 使 + joy 快乐 = 使快乐→享受）、rejoice（**re-** 加强 + joie 快乐 = 使高兴）、gaudy（拉丁 gaudium 快乐 + **-y** …的 = 华而不实的，存疑）。
- **前缀·后缀**：形容词后缀 **-ful**（例：useful）、**-ous**（例：famous）；前缀 **en-**（例：enable）。
- **同义·反义**：同义 happiness（快乐）, delight（喜悦）；反义 sorrow（悲伤）, sadness（悲伤）。
- **变形**：名词 → 复数：joys；形容词派生 → joyful adj. 快乐的；joyous adj. 喜悦的；副词派生 → joyfully adv. 快乐地。

### 12. lose /luz/ v. 丧失; 失去
- **词根·渊源**：古英语 **losian**（丢失、毁灭）← *leosan*（失去）→ 中古英语 *losen* → 英语 lose，本义“失去、丧失”，引申为“丧失、失去”。
- **同根词**：loss（古英语 los 丢失→损失）、lost（lose 的过去分词→丢失的）、loser（lose + **-er** 者 = 失败者）、loose（古诺斯语 lauss 松的→松的，与 lose 同源，存疑）。
- **前缀·后缀**：名词后缀 **-er**（例：teacher）。
- **同义·反义**：同义 miss（失去）, forfeit（丧失）；反义 gain（获得）, win（赢得）。
- **变形**：动词 → 第三人称单数：loses；过去式：lost；过去分词：lost；现在分词：losing；名词派生 → loss n. 损失；loser n. 失败者。

### 13. raise /reɪz/ v. 筹募
- **词根·渊源**：古诺斯语 **reisa**（使升起）→ 中古英语 *reisen* → 英语 raise，本义“使升起、举起”，引申为“筹集（钱款）、筹募”。
- **同根词**：rise（古英语 risan 升起→上升）、rear（古英语 ræran 使升起→抚养）、arousal（**a-** 使 + rouse 唤起 + **-al** 名词后缀 = 唤起）、rouse（古法语 reuser 使醒→唤醒）。
- **前缀·后缀**：名词后缀 **-al**（例：arrival）；前缀 **a-**（例：arise）。
- **同义·反义**：同义 collect（募集）, gather（收集）；反义 lower（降低）, reduce（减少）。
- **变形**：动词 → 第三人称单数：raises；过去式：raised；过去分词：raised；现在分词：raising；名词派生 → raise n. 加薪、提高；raiser n. 筹集者。

### 14. pound /paʊnd/ n. 英镑
- **词根·渊源**：拉丁 **pondus**（重量）→ 古英语 *pund*（磅，重量单位）→ 英语 pound，本义“重量单位磅”，因英镑原按一磅白银计值，引申为“英镑”。
- **同根词**：poundage（pound + **-age** 名词后缀 = 按磅计的重量/费用）、pounder（pound + **-er** 名词后缀 = 一磅重的东西）、ponder（拉丁 pondus 重量 + **-er** 动词后缀 = 掂量→沉思）、ponderous（ponder + **-ous** …的 = 沉重的）、preponderate（**pre-** 前 + ponder 重量 + **-ate** 动词后缀 = 重量超过→占优势）。
- **前缀·后缀**：名词后缀 **-age**（例：package）；前缀 **pre-**（例：preview）。
- **同义·反义**：同义 sterling（英镑）, quid（英镑，口语）；反义 无。
- **变形**：名词 → 复数：pounds；形容词派生 → poundal adj. 磅力的（物理，罕用）。

### 15. structure /ˈstrəkʧər/ n. 结构
- **词根·渊源**：拉丁 **struere**（建造、堆砌）→ 拉丁 *structura*（建造、构造）→ 法语 *structure* → 英语 structure，本义“建造的方式”，引申为“结构”。
- **同根词**：construct（**con-** 共同 + struct 建造 = 一起建造→建造）、instruct（**in-** 在内 + struct 建造 = 在心中建起→教导）、destroy（**de-** 向下 + stroy 建造 = 拆掉→破坏）、instrument（**in-** 在内 + stru 建造 + **-ment** 名词后缀 = 工具）、obstruct（**ob-** 反对 + struct 建造 = 挡在前面→阻碍）。
- **前缀·后缀**：前缀 **con-**（例：connect）、**in-**（例：include）；名词后缀 **-ure**（例：picture）。
- **同义·反义**：同义 framework（框架）, construction（构造）；反义 无。
- **变形**：名词 → 复数：structures；形容词派生 → structural adj. 结构的；动词派生 → structure v. 构建；副词派生 → structurally adv. 结构上地。

### 16. permission /pərˈmɪʃən/ n. 准许; 许可
- **词根·渊源**：拉丁 **per-**（通过、彻底）+ **mittere**（送、放）→ 拉丁 *permissio*（允许）→ 古法语 *permission* → 英语 permission，本义“放行通过”，引申为“准许、许可”。
- **同根词**：permit（**per-** 通过 + mit 送 = 放行→允许）、admit（**ad-** 向 + mit 送 = 送入→承认、准许进入）、submit（**sub-** 下 + mit 送 = 送上去→提交、屈服）、transmit（**trans-** 横过 + mit 送 = 传送）、mission（mit 送 + **-sion** 名词后缀 = 派遣、使命）、dismiss（**dis-** 离开 + miss 送 = 送走→解散）。
- **前缀·后缀**：前缀 **per-**（例：perfect）、**ad-**（例：advance）；名词后缀 **-sion**（例：decision）。
- **同义·反义**：同义 consent（同意）, authorization（授权）；反义 prohibition（禁止）, refusal（拒绝）。
- **变形**：名词 → 复数：permissions；动词派生 → permit v. 允许；形容词派生 → permissible adj. 可允许的。

### 17. arrange /əreɪnʤ/ v. 排列; 布置
- **词根·渊源**：古法语 **arengier**＝ **a-**（向）+ **reng**（行列、圈）→ 英语 arrange，本义“排成行列”，引申为“排列、布置”。
- **同根词**：arrangement（arrange + **-ment** 名词后缀 = 安排、布置）、range（古法语 reng 行列→范围、排列）、rank（古法语 ranc 行列→等级、排列）、derange（**de-** 去除 + range 行列 = 打乱→使混乱）。
- **前缀·后缀**：前缀 **a-**（例：arise）、**de-**（例：decrease）；名词后缀 **-ment**（例：movement）。
- **同义·反义**：同义 organize（组织）, order（安排）；反义 disorder（使混乱）, disturb（打乱）。
- **变形**：动词 → 第三人称单数：arranges；过去式：arranged；过去分词：arranged；现在分词：arranging；名词派生 → arrangement n. 安排；arranger n. 安排者。

### 18. donate /ˈdoʊˌneɪt/ v. 捐赠; 赠送
- **词根·渊源**：拉丁 **donare**（赠送）← **donum**（礼物）→ 英语 donate，本义“作为礼物送出”，引申为“捐赠、赠送”。
- **同根词**：donation（don 礼物 + **-ation** 名词后缀 = 捐赠）、donor（don 礼物 + **-or** 者 = 捐赠者）、donate 的派生 donative（don + **-ative** …的 = 捐赠的）、pardon（**par-** 完全 + don 给 = 完全给予→原谅）、don（拉丁 donum 礼物→赠予，存疑）。
- **前缀·后缀**：名词后缀 **-ation**（例：information）、**-or**（例：actor）；前缀 **par-**（例：parallel）。
- **同义·反义**：同义 give（给予）, contribute（捐献）；反义 receive（接受）, take（拿取）。
- **变形**：动词 → 第三人称单数：donates；过去式：donated；过去分词：donated；现在分词：donating；名词派生 → donation n. 捐赠；donor n. 捐赠者。

### 19. mighty /ˈmaɪti/ adj. 巨大的; 非凡的
- **词根·渊源**：古英语 **mihtig**（强大的）← **miht**（力量，与 might 同源）← 原始日耳曼语 *mahtiz*；本义“有力量的”，引申为“巨大的、非凡的”。
- **同根词**：might（miht 力量→力量、威力）、mightily（mighty + **-ly** …地：强有力地）、almighty（**al-** 全 + mighty 强大 = 全能的）、mightiness（mighty + **-ness** 名词后缀：强大）。
- **前缀·后缀**：形容词后缀 **-y**（例：rainy, sleepy）；名词后缀 **-ness**（例：kindness, darkness）；副词后缀 **-ly**（例：quickly, happily）。
- **同义·反义**：同义 powerful（强大的）, huge（巨大的）；反义 weak（虚弱的）, tiny（微小的）。
- **变形**：形容词 → 比较级：mightier；最高级：mightiest；名词派生 → might n. 力量；mightiness n. 强大；副词派生 → mightily adv. 强有力地。

### 20. pleasant /ˈplɛzənt/ adj. 令人愉快的; 宜人的
- **词根·渊源**：拉丁 **placere**（使高兴）→ 古法语 *plaisant*（令人愉快的）→ 英语；本义“使人高兴的”，即“令人愉快的、宜人的”。
- **同根词**：please（placere 使高兴→使满意）、pleasure（please + **-ure** 名词后缀：愉快）、pleasing（please + **-ing** …的：令人愉快的）、pleasantly（pleasant + **-ly** …地：愉快地）、displease（**dis-** 不 + please 高兴 = 使不高兴）。
- **前缀·后缀**：形容词后缀 **-ant**（例：important, distant）；名词后缀 **-ure**（例：failure, mixture）；否定前缀 **dis-**（例：dislike, disagree）。
- **同义·反义**：同义 enjoyable（令人愉快的）, agreeable（宜人的）；反义 unpleasant（令人不快的）, disagreeable（令人不快的）。
- **变形**：形容词 → 比较级：more pleasant；最高级：most pleasant；名词派生 → pleasure n. 愉快；副词派生 → pleasantly adv. 愉快地。

### 21. ease /iz/ v. 减轻; 缓解
- **词根·渊源**：古法语 **aise**（舒适、方便）→ 英语；本义“使舒适”，引申为“减轻、缓解”。
- **同根词**：easy（ease + **-y** …的：容易的）、easily（easy + **-ly** …地：容易地）、uneasy（**un-** 不 + easy 安适的 = 不安的）、easiness（easy + **-ness** 名词后缀：容易）、disease（**dis-** 不 + ease 舒适 = 不适→疾病）。
- **前缀·后缀**：形容词后缀 **-y**（例：windy, cloudy）；否定前缀 **un-**（例：unhappy, unfair）、**dis-**（例：dislike, disagree）；名词后缀 **-ness**（例：happiness, kindness）。
- **同义·反义**：同义 relieve（减轻）, lessen（减少）；反义 worsen（使恶化）, intensify（加剧）。
- **变形**：动词 → 第三人称单数：eases；过去式：eased；过去分词：eased；现在分词：easing；名词派生 → ease n. 舒适；形容词派生 → easy adj. 容易的；副词派生 → easily adv. 容易地。

### 22. ache /eɪk/ v. 疼痛; 隐痛
- **词根·渊源**：古英语 **acan**（疼痛）← 原始日耳曼语 *akan*；本义“持续地痛”，即“隐痛”。
- **同根词**：headache（head 头 + ache 痛 = 头痛）、toothache（tooth 牙 + ache 痛 = 牙痛）、stomachache（stomach 胃 + ache 痛 = 胃痛）、backache（back 背 + ache 痛 = 背痛）、aching（ache + **-ing** …的：疼痛的）。
- **前缀·后缀**：无前后缀（单纯词）；复合词中作后缀 **-ache**（例：earache, heartache）。
- **同义·反义**：同义 hurt（疼痛）, pain（疼痛）；反义 comfort（舒适）, relief（缓解）。
- **变形**：动词 → 第三人称单数：aches；过去式：ached；过去分词：ached；现在分词：aching；名词 → 复数：aches；形容词派生 → achy adj. 疼痛的；aching adj. 疼痛的。
