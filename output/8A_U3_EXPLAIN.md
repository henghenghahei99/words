## 二、逐词说文解字

### 1. order /ˈɔːrdər/ n. 点餐；订货；订购
- **词根·渊源**：拉丁 **ordo / ordin-**（顺序、行列）→ 古法语 *ordre* → 英语 order；本义“排列好的次序”，引申为“命令、订单”（按次序安排的事），再引申为“点餐、订货”。
- **同根词**：ordinary（ordin 顺序 + **-ary** 属于……的 = 按常规顺序的→普通的）、organize（源自希腊 organon，与 ordo 同出“安排”义，**-ize** 使……化 = 使有条理→组织）、ordinal（ordin 顺序 + **-al** ……的 = 表示顺序的→序数的）。
- **前缀·后缀**：无前缀；名词后缀 **-er**（例：worker, teacher）。
- **同义·反义**：同义 command（命令）, request（请求）；反义 disorder（混乱）, chaos（混沌）。
- **变形**：名词 → 复数：orders；动词派生 → order v. 订购、命令；形容词派生 → orderly adj. 有秩序的；副词派生 → orderly adv. 有秩序地。

### 2. compare /kəmˈper/ v. 比较；对比
- **词根·渊源**：拉丁 **com-**（一起）+ **par**（相等）→ 拉丁 *comparare*（使相等、配对）→ 古法语 *comparer* → 英语 compare；本义“把两物放在一起看是否相等”，引申为“比较、对比”。
- **同根词**：comparison（compare + **-ison** 名词后缀 = 比较）、comparable（com 一起 + par 相等 + **-able** 可……的 = 可相比的）、peer（源自 par 相等 = 同等的人→同辈）、pair（源自 par 相等 = 配对的一双）、parity（par 相等 + **-ity** 性质 = 相等、平价）。
- **前缀·后缀**：前缀 **com-**（一起）（例：combine, connect）；动词后缀 **-e**（例：create, debate）。
- **同义·反义**：同义 contrast（对比）, liken（比拟）；反义 contrast（形成对照）, differ（不同）。
- **变形**：动词 → 第三人称单数：compares；过去式：compared；过去分词：compared；现在分词：comparing；名词派生 → comparison n. 比较；形容词派生 → comparable adj. 可比较的；comparative adj. 比较的。

### 3. monitor /ˈmɑːnɪtə(r)/ n.（计算机）显示器；班长；监督员
- **词根·渊源**：拉丁 **monere / monit-**（警告、提醒）→ 拉丁 *monitor*（提醒者、劝告者）→ 英语 monitor；本义“提醒、警告的人”，引申为“监督员、班长”，再引申为“监视屏幕→显示器”。
- **同根词**：monition（monit 警告 + **-ion** 名词后缀 = 告诫）、admonish（**ad-** 向 + mon 警告 + **-ish** 动词后缀 = 向人警告→告诫）、monument（mon 提醒 + **-ment** 名词后缀 = 提醒后人的东西→纪念碑）、summon（**sub-** 在下 + mon 提醒 = 暗中提醒→传唤）。
- **前缀·后缀**：无前缀；名词后缀 **-or**（例：actor, doctor）。
- **同义·反义**：同义 screen（屏幕）, supervisor（监督者）；反义 无。
- **变形**：名词 → 复数：monitors；动词派生 → monitor v. 监视、监控；名词派生 → monitoring n. 监视。

### 4. speaker /ˈspiːkər/ n. 发言者，演讲者；说话者；讲某种语言的人；扬声器，喇叭
- **词根·渊源**：古英语 **specan / sprecan**（说话）→ 中古英语 *speken* → 英语 speak + **-er**（……的人/物）；本义“说话的人”，引申为“演讲者、讲某种语言的人”，再引申为“发出声音的装置→扬声器”。
- **同根词**：speech（speak 的名词形式，古英语 *spraec* = 说话→演讲、言语）、speak（本词根动词：说话）、bespeak（**be-** 加强 + speak = 预先说定→预订、显示）、spokesman（speak 的变体 spoke + **-s-man** 人 = 代言人）。
- **前缀·后缀**：无前缀；名词后缀 **-er**（例：teacher, worker）。
- **同义·反义**：同义 lecturer（演讲者）, orator（演说家）；反义 listener（听者）, audience（听众）。
- **变形**：名词 → 复数：speakers；动词派生 → speak v. 说话；形容词派生 → spoken adj. 口头的。

### 5. main unit /meɪn ˈjuːnɪt/ n.（计算机）主机；主要部件
- **同义搭配**：mainframe / system unit / host computer
- **反义搭配**：peripheral（外围设备）

### 6. keyboard /ˈkiːbɔːrd/ n. 键盘式电子乐器；键盘
- **词根·渊源**：**key**（键，源自古英语 *cæg* 钥匙）+ **board**（板，古英语 *bord*）→ 英语 keyboard；本义“带键的板”，即“键盘”，引申为“键盘式电子乐器”。
- **同根词**：key（本词根：钥匙→键）、board（本词根：板）、keyboardist（keyboard + **-ist** 人 = 键盘手）、keyhole（key 钥匙 + hole 孔 = 钥匙孔）、blackboard（black 黑 + board 板 = 黑板）。
- **前缀·后缀**：无前缀；名词后缀 **-ist**（例：artist, pianist）。
- **同义·反义**：同义 keypad（小键盘）；反义 无。
- **变形**：名词 → 复数：keyboards；名词派生 → keyboardist n. 键盘手；动词派生 → keyboard v. 用键盘输入。

### 7. mouse /maʊs/ n.（计算机）鼠标；老鼠，耗子
- **词根·渊源**：古英语 **mus**（老鼠）→ 中古英语 *mous* → 英语 mouse；本义“老鼠”，因计算机输入装置形似老鼠、带“尾巴”（线），20世纪引申为“鼠标”。
- **同根词**：mice（mouse 的不规则复数，古英语 *mys* = 老鼠的复数）、mousy（mouse + **-y** ……的 = 像老鼠的→灰褐色的、胆小的）、mousetrap（mouse 鼠 + trap 陷阱 = 捕鼠器）、dormouse（**dor-** 源自法语 dormir 睡 + mouse 鼠 = 睡鼠）。
- **前缀·后缀**：无前缀；形容词后缀 **-y**（例：rainy, windy）。
- **同义·反义**：同义 rat（大鼠）；反义 无。
- **变形**：名词 → 复数：mice（指老鼠）；mouses（指鼠标）；形容词派生 → mousy adj. 老鼠般的、胆小的。

### 8. type /taɪp/ n. 打字
- **词根·渊源**：希腊 **typos**（印记、模型）→ 拉丁 *typus* → 古法语 *type* → 英语 type；本义“印出的记号、活字”，引申为“类型”，再引申为“用打字机/键盘打出字→打字”。
- **同根词**：typical（typ 类型 + **-ical** ……的 = 典型的）、typewriter（type 打字 + writer 书写者 = 打字机）、typist（type + **-ist** 人 = 打字员）、prototype（**proto-** 原始 + type 模型 = 原型）、typography（typo 印 + **-graphy** 写 = 印刷术）。
- **前缀·后缀**：前缀 **proto-**（原始）（例：protocol, protozoa）；名词后缀 **-ist**（例：artist, tourist）。
- **同义·反义**：同义 kind（种类）, print（印刷体）；反义 无。
- **变形**：名词 → 复数：types；动词派生 → type v. 打字；名词派生 → typist n. 打字员；形容词派生 → typical adj. 典型的。

### 9. brain /breɪn/ n. 大脑；智力；脑力
- **词根·渊源**：古英语 **brægen**（脑）→ 中古英语 *brain* → 英语 brain；本义“脑器官”，引申为“智力、脑力”。
- **同根词**：brainy（brain + **-y** ……的 = 有头脑的→聪明的）、brainstorm（brain 脑 + storm 风暴 = 头脑风暴）、brainwash（brain 脑 + wash 洗 = 洗脑）、harebrained（hare 野兔 + brain 脑 + **-ed** 有……的 = 兔脑般的→轻率的）。
- **前缀·后缀**：无前缀；形容词后缀 **-y**（例：rainy, sleepy）。
- **同义·反义**：同义 mind（头脑）, intellect（智力）；反义 body（身体）, brawn（体力）。
- **变形**：名词 → 复数：brains；形容词派生 → brainy adj. 聪明的；brainless adj. 无脑的。

### 10. control /kənˈtroʊl/ n. 操作；操纵；控制，支配
- **词根·渊源**：中世纪拉丁 **contrarotulus**（对照账册）→ 古法语 *contrerolle* → 英语 control；本义“用副本账册核对”，引申为“核对、掌管”，再引申为“控制、操纵”。
- **同根词**：controller（control + **-er** 人/物 = 控制者、控制器）、controllable（control + **-able** 可……的 = 可控制的）、roll（源自拉丁 rotulus 卷轴，与 control 同源 = 卷、滚动）、enroll（**en-** 使 + roll 名册 = 使入名册→登记）。
- **前缀·后缀**：前缀 **contra-**（相反、对照）（例：contrast, contradict）；名词后缀 **-er**（例：worker, teacher）。
- **同义·反义**：同义 command（指挥）, manage（管理）；反义 freedom（自由）, release（释放）。
- **变形**：名词 → 复数：controls；动词派生 → control v. 控制；形容词派生 → controllable adj. 可控制的；名词派生 → controller n. 控制者。

### 11. expensive /ɪkˈspensɪv/ adj. 昂贵的；价格高的；花钱多的
- **词根·渊源**：拉丁 **expendere**（支出）→ 拉丁 *expensa*（花费）→ 英语 expense + **-ive**（……的）；本义“花费大的”，引申为“昂贵的”。
- **同根词**：expense（**ex-** 出 + pens 称量、支付 = 支出→费用）、expend（**ex-** 出 + pend 称量 = 付出→花费）、spend（expend 的变体 = 花费）、pension（pens 支付 + **-ion** 名词后缀 = 支付的款项→养老金）、compensate（**com-** 一起 + pens 称量 + **-ate** 动词后缀 = 一起称量→补偿）。
- **前缀·后缀**：前缀 **ex-**（出）（例：exit, export）；形容词后缀 **-ive**（例：active, creative）。
- **同义·反义**：同义 costly（昂贵的）, dear（昂贵的）；反义 cheap（便宜的）, inexpensive（不贵的）。
- **变形**：形容词 → 比较级：more expensive；最高级：most expensive；名词派生 → expense n. 费用；副词派生 → expensively adv. 昂贵地。

### 12. tiny /ˈtaɪni/ adj. 极小的；微小的
- **词根·渊源**：中古英语 **tine**（小的，来源存疑，一说与古英语 *tīnan* 有关）→ 英语 tiny + **-y**（……的）；本义“小的”，引申为“极小的”。
- **同根词**：tininess（tiny + **-ness** 名词后缀 = 微小）、tine（tiny 的词源形式，存疑，指小东西）。
- **前缀·后缀**：无前缀；形容词后缀 **-y**（例：rainy, happy）。
- **同义·反义**：同义 little（小的）, minute（微小的）；反义 huge（巨大的）, enormous（庞大的）。
- **变形**：形容词 → 比较级：tinier；最高级：tiniest；名词派生 → tininess n. 微小。

### 13. depend /dɪˈpɛnd/ v. 依靠；信赖；取决于
- **词根·渊源**：拉丁 **de-**（向下）+ **pendere**（悬挂）→ 拉丁 *dependere*（悬挂于下）→ 古法语 *dependre* → 英语 depend；本义“悬挂在……之下”，引申为“依靠、取决于”。
- **同根词**：dependent（depend + **-ent** ……的 = 依靠的→依赖的）、dependence（depend + **-ence** 名词后缀 = 依赖）、pendant（pend 悬挂 + **-ant** 物 = 悬挂物→吊坠）、pendulum（pend 悬挂 + **-ulum** 小物 = 摆锤）、suspend（**sus-** 在下 + pend 悬挂 = 悬吊→暂停）。
- **前缀·后缀**：前缀 **de-**（向下）（例：descend, decrease）；动词后缀 **-d**（例：divide, provide）。
- **同义·反义**：同义 rely（依靠）, trust（信赖）；反义 无。
- **变形**：动词 → 第三人称单数：depends；过去式：depended；过去分词：depended；现在分词：depending；名词派生 → dependence n. 依赖；形容词派生 → dependent adj. 依赖的。

### 14. calculate /ˈkælkjuleɪt/ v. 计算，核算；预测，推测
- **词根·渊源**：拉丁 **calculus**（小石子，用于计数）→ 拉丁 *calculare*（用石子计数）→ 英语 calculate；本义“用小石子计数”，引申为“计算、推测”。
- **同根词**：calculation（calculate + **-ion** 名词后缀 = 计算）、calculator（calculate + **-or** 物 = 计算器）、calculus（calcul 石子 + **-us** 拉丁名词后缀 = 微积分、结石）、incalculable（**in-** 不 + calculable 可计算的 = 不可计算的）。
- **前缀·后缀**：无前缀；动词后缀 **-ate**（例：create, operate）。
- **同义·反义**：同义 compute（计算）, reckon（估算）；反义 guess（猜测）, estimate（估计）。
- **变形**：动词 → 第三人称单数：calculates；过去式：calculated；过去分词：calculated；现在分词：calculating；名词派生 → calculation n. 计算；calculator n. 计算器。

### 15. speed /spiːd/ v. 速度；超速行驶
- **词根·渊源**：古英语 **spēd**（成功、迅速）→ 中古英语 *spede* → 英语 speed；本义“成功、兴旺”，引申为“迅速”，再引申为“速度、超速行驶”。
- **同根词**：speedy（speed + **-y** ……的 = 迅速的）、speedily（speedy + **-ly** 副词后缀 = 迅速地）、speedometer（speed 速度 + **-meter** 测量仪 = 速度计）、speeding（speed + **-ing** 名词后缀 = 超速行驶）。
- **前缀·后缀**：无前缀；形容词后缀 **-y**（例：rainy, windy）。
- **同义·反义**：同义 velocity（速度）, rapidity（迅速）；反义 slowness（缓慢）, delay（延迟）。
- **变形**：动词 → 第三人称单数：speeds；过去式：sped；过去分词：sped；现在分词：speeding；名词派生 → speed n. 速度；形容词派生 → speedy adj. 迅速的；副词派生 → speedily adv. 迅速地。

### 16. operate /ˈɑːpəreɪt/ v. 操纵，操作（机器或设备）；控制；（机器等）运转，运行
- **词根·渊源**：拉丁 **opus / oper-**（工作）→ 拉丁 *operari*（工作、劳作）→ 英语 operate；本义“工作、劳作”，引申为“操作机器、运转”。
- **同根词**：operation（operate + **-ion** 名词后缀 = 操作、手术）、operator（operate + **-or** 人 = 操作员）、cooperate（**co-** 共同 + oper 工作 + **-ate** 动词后缀 = 共同工作→合作）、opus（oper 的拉丁原形 = 作品）。
- **前缀·后缀**：前缀 **co-**（共同）（例：cooperate, connect）；动词后缀 **-ate**（例：create, calculate）。
- **同义·反义**：同义 run（运转）, control（控制）；反义 stop（停止）, halt（暂停）。
- **变形**：动词 → 第三人称单数：operates；过去式：operated；过去分词：operated；现在分词：operating；名词派生 → operation n. 操作；operator n. 操作员。

### 17. railway /ˈrelˌwe/ n. 铁路；铁道；铁路系统
- **词根·渊源**：**rail**（铁轨，源自古法语 *reille* 横杆）+ **way**（道路，古英语 *weg*）→ 英语 railway；本义“铺铁轨的路”，即“铁路”。
- **同根词**：rail（本词根：铁轨）、way（本词根：道路）、railroad（rail 铁轨 + road 路 = 铁路，美式）、railwayman（railway + **-man** 人 = 铁路工人）、subway（**sub-** 在下 + way 路 = 地下铁路）。
- **前缀·后缀**：前缀 **sub-**（在下）（例：submarine, subway）；名词后缀 **-man**（例：postman, policeman）。
- **同义·反义**：同义 railroad（铁路）, track（轨道）；反义 无。
- **变形**：名词 → 复数：railways；名词派生 → railwayman n. 铁路工人。

### 18. company /ˈkʌmpəni/ n. 公司
- **词根·渊源**：拉丁 **com-**（一起）+ **panis**（面包）→ 古法语 *compagnie*（同伴）→ 英语 company；本义“一起吃面包的人→同伴”，引申为“一群人”，再引申为“公司”。
- **同根词**：companion（com 一起 + pan 面包 + **-ion** 人 = 一起吃面包的人→同伴）、accompany（**ac-** 向 + company 同伴 = 陪伴）、pantry（pan 面包 + **-ry** 场所 = 放面包的地方→食品储藏室）、panini（意大利语 panino 小面包，源自 panis 面包 = 帕尼尼）。
- **前缀·后缀**：前缀 **com-**（一起）（例：combine, compare）；名词后缀 **-y**（例：study, memory）。
- **同义·反义**：同义 firm（公司）, business（企业）；反义 无。
- **变形**：名词 → 复数：companies；名词派生 → companion n. 同伴；动词派生 → accompany v. 陪伴。

### 19. price /praɪs/ n. 价格，价钱
- **词根·渊源**：拉丁 **pretium**（价值、报酬）→ 古法语 *pris*（价值、价格）→ 英语 price；本义“所值之物”，引申为“价格、价钱”。
- **同根词**：precious（preti 价值 + **-ous** …的 = 有价值的→珍贵的）、appreciate（**ap-** 向 + preci 价值 + **-ate** 动词后缀 = 给…估价→欣赏、感激）、depreciate（**de-** 下降 + preci 价值 + **-ate** = 价值下降→贬值）、praise（经古法语 *preisier* 估价→称赞，与 price 同源）。
- **前缀·后缀**：无前后缀（单纯词）。
- **同义·反义**：同义 cost（费用）, value（价值）；反义 无。
- **变形**：名词 → 复数：prices；形容词派生 → priceless adj. 无价的；pricey adj. 昂贵的；动词派生 → price v. 给…定价。

### 20. total /ˈtoʊtl/ adj. 总数；合计；总的；总体的
- **词根·渊源**：拉丁 **totus**（全部的）→ 中世纪拉丁 *totalis*（全部的）→ 古法语 *total* → 英语 total；本义“全部的”，引申为“总的、总体的”，再作名词“总数”。
- **同根词**：totally（total + **-ly** 副词后缀 = 完全地）、totality（total + **-ity** 名词后缀 = 整体、全部）、subtotal（**sub-** 在下 + total = 小计）、totalitarian（total + **-itarian** 形容词后缀 = 极权的，源自“全部”义）。
- **前缀·后缀**：形容词后缀 **-al**（例：natural, normal）；副词后缀 **-ly**（例：finally, usually）。
- **同义·反义**：同义 whole（全部的）, entire（整个的）；反义 partial（部分的）, incomplete（不完全的）。
- **变形**：形容词 → 无比较级（绝对形容词，不作比较）；名词 → 复数：totals；副词派生 → totally adv. 完全地；动词派生 → total v. 合计。

### 21. inch /ɪntʃ/ n. 英寸
- **词根·渊源**：拉丁 **uncia**（十二分之一）→ 古英语 *ynce* → 英语 inch；本义“一英尺的十二分之一”，即“英寸”。
- **同根词**：ounce（经古法语 *unce* 源自拉丁 uncia 十二分之一→盎司，与 inch 同源）、uncial（拉丁 uncia 十二分之一 + **-al** …的 = 一英寸高的→安色尔字体的）。
- **前缀·后缀**：无前后缀（单纯词）。
- **同义·反义**：同义 无；反义 无。
- **变形**：名词 → 复数：inches；形容词派生 → inchy adj. 英寸的（少用）。

### 22. sell /sɛl/ v. 出售；售卖；销售
- **词根·渊源**：古英语 **sellan**（给予、交出）→ 中古英语 *sellen* → 英语 sell；本义“交出、给予”，引申为“出售、售卖”。
- **同根词**：seller（sell + **-er** 者 = 卖者、卖方）、sale（sell 的名词形式，古英语 *sala* 出售→销售）、best-seller（**best** 最好 + seller 卖者 = 畅销品）。
- **前缀·后缀**：名词后缀 **-er**（例：teacher, worker）。
- **同义·反义**：同义 trade（交易）, market（销售）；反义 buy（买）, purchase（购买）。
- **变形**：动词 → 第三人称单数：sells；过去式：sold；过去分词：sold；现在分词：selling；名词派生 → seller n. 卖方；sale n. 销售。

### 23. popular /ˈpɒpjələ(r)/ adj. 受喜爱的；受欢迎的
- **词根·渊源**：拉丁 **populus**（人民）→ 拉丁 *popularis*（人民的）→ 古法语 *populaire* → 英语 popular；本义“属于人民的”，引申为“大众喜爱的、受欢迎的”。
- **同根词**：population（popul 人民 + **-ation** 名词后缀 = 人口）、populate（popul 人民 + **-ate** 动词后缀 = 居住于、使有人口）、popularity（popular + **-ity** 名词后缀 = 受欢迎、流行）、populist（popul 人民 + **-ist** 者 = 平民主义者）。
- **前缀·后缀**：形容词后缀 **-ar**（例：similar, familiar）；名词后缀 **-ity**（例：activity, reality）。
- **同义·反义**：同义 well-liked（受喜爱的）, favored（受青睐的）；反义 unpopular（不受欢迎的）, disliked（被讨厌的）。
- **变形**：形容词 → 比较级：more popular；最高级：most popular；名词派生 → popularity n. 受欢迎；副词派生 → popularly adv. 普遍地。
