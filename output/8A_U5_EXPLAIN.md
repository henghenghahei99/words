## 二、逐词说文解字

### 1. educational /ˌedʒuˈkeɪʃənl/ adj. 有关教育的；有教育意义的
- **词根·渊源**：拉丁 **educare**（养育、培养）→ 拉丁 *educatio*（培养）→ 英语 education + 后缀 -al；本义“培养、引导出来”，引申为“教育的、有教育意义的”。
- **同根词**：educate（**e-** 出 + duc 引导 + -ate 动词后缀 = 引导出来→教育）、education（educate + **-ion** 名词后缀 = 教育）、educator（educate + **-or** 人 = 教育者）、educe（**e-** 出 + duc 引导 = 引出）、duct（duc 引导 = 导管）、conduct（**con-** 共同 + duct 引导 = 引导→指挥）。
- **前缀·后缀**：前缀 **e-**（例：evoke, emerge）；后缀 **-al**（例：natural, cultural）。
- **同义·反义**：同义 instructive, academic；反义 uneducational。
- **词性变化**：education n. 教育；educate v. 教育；educator n. 教育者；educationally adv. 教育上地。

### 2. exchange /ɪksˈtʃendʒ/ n. 交流；互访；交换
- **词根·渊源**：拉丁 **cambiare**（交换）→ 古法语 *eschangier* → 英语 exchange；**ex-**（出、相互）+ change（交换），本义“互相换出”，引申为“交流、互访”。
- **同根词**：change（源自拉丁 cambiare 交换 = 改变）、changeable（change + **-able** 能…的 = 可改变的）、unchanged（**un-** 不 + change + **-ed** …的 = 未改变的）、interchange（**inter-** 相互 + change = 互换）、changeful（change + **-ful** 充满…的 = 多变的）。
- **前缀·后缀**：前缀 **ex-**（例：export, exit）；后缀 **-able**（例：changeable, readable）。
- **同义·反义**：同义 swap, interchange；反义 retention。
- **词性变化**：exchangeable adj. 可交换的；exchange v. 交换；changer n. 改变者。

### 3. culture /ˈkʌltʃər/ n. 文化，文明
- **词根·渊源**：拉丁 **colere / cult-**（耕种、培育）→ 拉丁 *cultura*（耕作、培养）→ 古法语 *culture* → 英语 culture；本义“耕种土地”，引申为“培育心智”，再引申为“文化、文明”。
- **同根词**：cultivate（cult 耕种 + **-ivate** 动词后缀 = 耕种→培养）、cultivation（cultivate + **-ion** 名词后缀 = 耕作→培养）、agriculture（**agri-** 田地 + culture 耕种 = 农业）、cultural（culture + **-al** …的 = 文化的）、cult（cult 耕种→培育→崇拜 = 教派）、horticulture（**horti-** 花园 + culture 耕种 = 园艺）。
- **前缀·后缀**：前缀 **agri-**（例：agriculture, agribusiness）；后缀 **-al**（例：cultural, natural）。
- **同义·反义**：同义 civilization, refinement；反义 barbarism。
- **词性变化**：cultural adj. 文化的；cultured adj. 有教养的；cultivate v. 培养；cultivation n. 培养。

### 4. host /hoʊst/ n. 主人；主持；东道主
- **词根·渊源**：拉丁 **hospes / hospit-**（客人、主人）→ 古法语 *hoste* → 英语 host；本义“接待客人的人”，引申为“主人、东道主”，再引申为“主持”。
- **同根词**：hostess（host + **-ess** 女性 = 女主人）、hospitality（hospit 客人 + **-ality** 名词后缀 = 好客）、hospital（hospit 客人 + **-al** 场所 = 接待客人之地→医院）、hostel（host + **-el** 小场所 = 旅舍）、hotel（源自 host 同源词 = 旅馆）、hospice（hospit 客人 + **-ice** 场所 = 招待所→临终关怀院）。
- **前缀·后缀**：后缀 **-ess**（例：actress, waitress）；后缀 **-el**（例：hostel, tunnel）。
- **同义·反义**：同义 entertainer, presenter；反义 guest。
- **词性变化**：hostess n. 女主人；host v. 主持；hospitality n. 好客。

### 5. local /ˈloʊkl/ adj. 当地的，本地的；地方的
- **词根·渊源**：拉丁 **locus**（地方）→ 拉丁 *localis* → 古法语 *local* → 英语 local；本义“关于某地方的”，引申为“当地的、本地的”。
- **同根词**：locate（loc 地方 + **-ate** 动词后缀 = 定位）、location（locate + **-ion** 名词后缀 = 位置）、locality（local + **-ity** 名词后缀 = 地点）、locomotive（**loco-** 地方→移动 + motive 动 = 火车头）、allocate（**al-** 向 + loc 地方 + -ate = 分配到某地）、dislocate（**dis-** 离开 + loc 地方 + -ate = 使脱位）。
- **前缀·后缀**：前缀 **al-**（例：allocate, allude）；后缀 **-ity**（例：locality, reality）。
- **同义·反义**：同义 regional, native；反义 national, global。
- **词性变化**：locally adv. 当地地；locality n. 地点；locate v. 定位；location n. 位置。

### 6. British /ˈbrɪtɪʃ/ adj. 英国的，英国人的，英国人
- **词根·渊源**：凯尔特语 **Priten / Brit-**（不列颠人）→ 拉丁 *Britannia*（不列颠）→ 古英语 *Bryttisc* → 英语 British；本义“不列颠人的”，引申为“英国的、英国人的”。
- **同根词**：Britain（Brit 不列颠 + **-ain** 地名后缀 = 不列颠）、Briton（Brit + **-on** 人 = 不列颠人）、Britannia（拉丁 Britannia = 不列颠尼亚）、Brit（Brit 缩写 = 英国人）、Britannic（Britannia + **-ic** …的 = 不列颠的）。
- **前缀·后缀**：后缀 **-ish**（例：English, Spanish）；后缀 **-ain**（例：Britain, mountain）。
- **同义·反义**：同义 Britannic, UK；反义 无。
- **词性变化**：Britain n. 不列颠；Briton n. 不列颠人；Brit n. 英国人。

### 7. glad /ɡlæd/ adj. 高兴；愉快；高兴的；快乐的
- **词根·渊源**：古英语 **glæd**（明亮的、高兴的），与古诺斯语 *glaðr* 同源，本义“明亮的、光滑的”，引申为“心情明朗的→高兴的”。
- **同根词**：gladly（glad + **-ly** 副词后缀 = 高兴地）、gladness（glad + **-ness** 名词后缀 = 高兴）、gladden（glad + **-en** 动词后缀 = 使高兴）、gladsome（glad + **-some** …的 = 令人高兴的）。
- **前缀·后缀**：后缀 **-ly**（例：quickly, happily）；后缀 **-ness**（例：kindness, happiness）。
- **同义·反义**：同义 happy, pleased；反义 sad, unhappy。
- **词性变化**：gladly adv. 高兴地；gladness n. 高兴；gladden v. 使高兴。

### 8. guest /ɡest/ n. 客人；宾客
- **词根·渊源**：古诺斯语 **gestr**（客人），与拉丁 *hostis*（陌生人、敌人）同出 PIE *ghos-ti-*（陌生人）；本义“外来者”，引申为“客人、宾客”。
- **同根词**：guesthouse（guest + house 房子 = 宾馆）、guestroom（guest + room 房间 = 客房）、guestly（guest + **-ly** …的 = 客人的）、host（与 guest 同源，拉丁 hostis 陌生人→主人）。
- **前缀·后缀**：无前后缀（单纯词）。
- **同义·反义**：同义 visitor, caller；反义 host。
- **词性变化**：guest v. 做客；guesthouse n. 宾馆。

### 9. chopstick /ˈtʃɑ:pstɪk/ n. 筷子
- **词根·渊源**：汉语 **快**（kuài，筷子）音译 + 英语 stick（棍）；chop 可能源自汉语“挟/夹”的洋泾浜音译（存疑），本义“夹东西的棍”，即“筷子”。
- **同根词**：stick（stic 刺、棍 = 棍子）、sticky（stick + **-y** …的 = 黏的）、chop（chop 砍 = 砍）、chopper（chop + **-er** 工具 = 斧头）、chopsticks（chop + stick + **-s** 复数 = 筷子）。
- **前缀·后缀**：后缀 **-s**（例：books, pens）；无前缀。
- **同义·反义**：同义 eating sticks；反义 无。
- **词性变化**：chopstick n. 筷子（单数）；chopsticks n. 筷子（复数）。

### 10. weekday /ˈwiːkdeɪ/ n. 工作日；平日（除周末以外的日子）
- **词根·渊源**：古英语 **wicu**（星期）+ 古英语 **dæg**（日）→ 英语 week + day；本义“星期中的日子”，引申为“工作日、平日”。
- **同根词**：week（wicu 星期 = 星期）、day（dæg 日 = 日）、weekend（week + **end** 末尾 = 周末）、weekly（week + **-ly** …的 = 每周的）、daily（day + **-ly** …的 = 每日的）、midday（**mid-** 中间 + day = 正午）。
- **前缀·后缀**：前缀 **mid-**（例：midday, midnight）；后缀 **-ly**（例：weekly, daily）。
- **同义·反义**：同义 workday；反义 weekend。
- **词性变化**：week n. 星期；day n. 日；weekend n. 周末；weekly adj. 每周的。

### 11. tour /tʊr/ n. 在......旅游；（短暂的）参观，游览
- **词根·渊源**：拉丁 **tornare**（转）→ 古法语 *torner* → 古法语 *tour*（一圈、巡回）→ 英语 tour；本义“转一圈”，引申为“巡回、旅游、参观”。
- **同根词**：tourism（tour + **-ism** 主义/活动 = 旅游业）、tourist（tour + **-ist** 人 = 游客）、tournament（tourn 转 + **-ament** 名词后缀 = 轮流比赛→锦标赛）、turn（源自拉丁 tornare 转 = 转动）、return（**re-** 回 + turn 转 = 返回）、detour（**de-** 离开 + tour 转 = 绕道）。
- **前缀·后缀**：前缀 **re-**（例：return, review）；后缀 **-ist**（例：tourist, artist）。
- **同义·反义**：同义 trip, journey；反义 无。
- **词性变化**：tourist n. 游客；tourism n. 旅游业；tour v. 旅游。

### 12. fantastic /fænˈtæstɪk/ adj. 极好的；了不起的
- **词根·渊源**：希腊 **phantazein**（使显现、想象）→ 拉丁 *phantasticus* → 古法语 *fantastique* → 英语 fantastic；本义“想象中的、幻想的”，引申为“离奇的”，再引申为“极好的、了不起的”。
- **同根词**：fantasy（希腊 phantasia 想象 = 幻想）、fantasize（fantasy + **-ize** 动词后缀 = 幻想）、fantastically（fantastic + **-ally** 副词后缀 = 极好地）、phantom（希腊 phantasma 幻影 = 幽灵）、phenomenon（希腊 phainomenon 显现 = 现象）。
- **前缀·后缀**：后缀 **-ic**（例：music, magic）；后缀 **-ally**（例：basically, dramatically）。
- **同义·反义**：同义 wonderful, excellent；反义 terrible, awful。
- **词性变化**：fantasy n. 幻想；fantasize v. 幻想；fantastically adv. 极好地。

### 13. experience /ɪkˈspɪriəns/ v. 经历，经验，体验
- **词根·渊源**：拉丁 **experiri**（尝试、试验）→ 拉丁 *experientia*（试验、经验）→ 古法语 *experience* → 英语 experience；**ex-**（出）+ periri（尝试），本义“尝试出来”，引申为“经历、经验、体验”。
- **同根词**：experiment（**ex-** 出 + periri 尝试 + **-ment** 名词后缀 = 实验）、expert（**ex-** 出 + periri 尝试→熟练 = 专家）、experienced（experience + **-ed** …的 = 有经验的）、inexperienced（**in-** 不 + experienced = 无经验的）、peril（periri 尝试→危险 = 危险）、empirical（**em-** 在内 + peiria 尝试 + **-ical** …的 = 经验的）。
- **前缀·后缀**：前缀 **ex-**（例：export, exit）；后缀 **-ment**（例：experiment, movement）。
- **同义·反义**：同义 undergo, encounter；反义 inexperience。
- **词性变化**：experience n. 经验；experienced adj. 有经验的；experiment n. 实验；expert n. 专家。

### 14. t'ai chi /ˌtaɪ ˈtʃiː/ n. 太极拳，太极

### 15. already /ɔːlˈredi/ adv. 已经；早已
- **词根·渊源**：古英语 **eall**（全部）+ **rǣde**（准备好）→ 中古英语 *al redy* → 英语 already；本义“完全准备好的”，引申为“已经、早已”。
- **同根词**：ready（古英语 rǣde 准备好 = 准备好的）、readily（ready + **-ly** 副词后缀 = 乐意地）、readiness（ready + **-ness** 名词后缀 = 准备就绪）、all（eall 全部 = 全部）、almighty（**al-** 全部 + mighty 强大 = 全能的）、almost（**al-** 全部 + most 最 = 几乎）。
- **前缀·后缀**：前缀 **al-**（例：almost, almighty）；后缀 **-ly**（例：readily, quickly）。
- **同义·反义**：同义 yet, by now；反义 not yet。
- **词性变化**：ready adj. 准备好的；readily adv. 乐意地；readiness n. 准备就绪。

### 16. introduce /ˌɪntrəˈduːs/ v. 使......初次了解......；使尝试；介绍，引见
- **词根·渊源**：拉丁 **ducere**（引导）→ 拉丁 *introducere*（引入）→ 英语 introduce；**intro-**（向内）+ duc（引导），本义“引导进入”，引申为“介绍、引见、使初次了解”。
- **同根词**：introduction（introduce + **-tion** 名词后缀 = 介绍）、introductory（introduction + **-ory** …的 = 介绍的）、duce（duc 引导 = 引导）、conduct（**con-** 共同 + duct 引导 = 指挥）、produce（**pro-** 向前 + duc 引导 = 生产）、reduce（**re-** 回 + duc 引导 = 减少）、educate（**e-** 出 + duc 引导 + -ate = 教育）。
- **前缀·后缀**：前缀 **intro-**（例：introduction, introvert）；后缀 **-tion**（例：introduction, production）。
- **同义·反义**：同义 present, acquaint；反义 withdraw。
- **词性变化**：introduction n. 介绍；introductory adj. 介绍的；introduce v. 介绍。

### 17. success /səkˈsɛs/ n. 成功，胜利
- **词根·渊源**：拉丁 **cedere**（走、让步）→ 拉丁 *successus*（随后而来、成功）→ 英语 success；**suc-**（= sub- 在下、随后）+ cess（走），本义“随后走到一起→结果良好”，引申为“成功、胜利”。
- **同根词**：succeed（suc- 随后 + ceed 走 = 成功）、successful（success + **-ful** 充满…的 = 成功的）、successfully（successful + **-ly** 副词后缀 = 成功地）、succession（suc- 随后 + cess 走 + **-ion** 名词后缀 = 连续）、process（**pro-** 向前 + cess 走 = 过程）、proceed（**pro-** 向前 + ceed 走 = 前进）、exceed（**ex-** 出 + ceed 走 = 超过）。
- **前缀·后缀**：前缀 **suc-**（例：succeed, succession）；后缀 **-ful**（例：successful, helpful）。
- **同义·反义**：同义 triumph, achievement；反义 failure。
- **词性变化**：succeed v. 成功；successful adj. 成功的；successfully adv. 成功地。

### 18. yet /jɛt/ adv. 还没有；尚未；仍未
- **词根·渊源**：古英语 **gīet**（仍然、至今），与古诺斯语 *enn* 同源，本义“仍然、至今”，引申为“还没有、尚未、仍未”。
- **同根词**：yet（古英语 gīet = 仍然）、yield（古英语 gieldan 付出，与 yet 同源存疑 = 产出）。
- **前缀·后缀**：无前后缀（单纯词）。
- **同义·反义**：同义 still, so far；反义 already。
- **词性变化**：yet adv. 尚未；yet conj. 然而。

### 19. respect /rɪˈspekt/ n. 慎重对待；尊敬，敬重
- **词根·渊源**：拉丁 **re-**（回、再）+ **specere / spect-**（看）→ 拉丁 *respectus*（回头看、顾及）→ 古法语 *respect* → 英语；本义“回头看、顾及”，引申为“重视、尊敬”。
- **同根词**：inspect（**in-** 向内 + spect 看 = 向内看→检查）、spectator（spect 看 + **-ator** 人 = 观看者→观众）、suspect（**su-** 下 + spect 看 = 从下往上看→怀疑）、prospect（**pro-** 向前 + spect 看 = 向前看→前景）、spectacle（spect 看 + **-acle** 物 = 供观看之物→景象）、respectful（respect + **-ful** 充满……的→恭敬的）。
- **前缀·后缀**：前缀 **re-**（例：return, review）；名词后缀 **-ful**（例：helpful, useful）。
- **同义·反义**：同义 esteem, regard；反义 contempt, disrespect。
- **词性变化**：respectful adj. 恭敬的；respectable adj. 可敬的；disrespect n. 不敬。

### 22. a bit of /ə bɪt əv/ n. 一点；小量
