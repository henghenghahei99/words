## 二、逐词说文解字

### 1. manage /ˈmænɪʤ/ v. 明智地使用(金钱、时间、信息等)
- **词根·渊源**：意大利语 *maneggiare*（驾驭马匹）→ 法语 *manège*（驯马）→ 英语 manage；本义“用手驾驭、操控”，引申为“管理、明智地使用”。
- **同根词**：management（manage + **-ment** 名词后缀 = 管理）、manager（manage + **-er** 人 = 管理者）、manipulate（拉丁 **manus** 手 + **-pulate** 填满 = 用手操作→操纵）、manual（**manu-** 手 + **-al** …的 = 手的→手册）。
- **前缀·后缀**：名词后缀 **-ment**（例：development, agreement）；名词后缀 **-er**（例：teacher, worker）。
- **同义·反义**：同义 handle（处理）, control（控制）；反义 mismanage（管理不善）, waste（浪费）。
- **变形**：动词 → 第三人称单数：manages；过去式：managed；过去分词：managed；现在分词：managing；名词派生 → management n. 管理；manager n. 管理者。

### 2. pressure /ˈprɛʃər/ n. 心理压力;紧张
- **词根·渊源**：拉丁 **press-**（压）→ 古法语 *presser*（压）→ 英语 pressure；本义“压的动作、压的力量”，引申为“心理压力、紧张”。
- **同根词**：press（**press** 压 = 按、压）、compress（**com-** 一起 + press 压 = 压在一起→压缩）、express（**ex-** 出 + press 压 = 压出来→表达）、impress（**im-** 进入 + press 压 = 压入→给…深刻印象）、depress（**de-** 向下 + press 压 = 向下压→使沮丧）。
- **前缀·后缀**：名词后缀 **-ure**（例：pleasure, failure）；动词前缀 **com-**（例：combine）、**ex-**（例：export）、**im-**（例：import）、**de-**（例：decline）。
- **同义·反义**：同义 stress（压力）, strain（紧张）；反义 relaxation（放松）, relief（缓解）。
- **变形**：名词 → 复数：pressures；形容词派生 → pressurize v. 对…施加压力；pressured adj. 有压力的。

### 3. addicted /əˈdɪktɪd/ adj. 上瘾的
- **词根·渊源**：拉丁 **addicere**（判给、献出）→ 拉丁 *addictus*（被判决让与的）→ 英语 addicted；本义“被判定归附于某物”，引申为“沉溺、上瘾的”。
- **同根词**：addict（**ad-** 向 + **dict** 说 = 宣判归与→使沉溺；上瘾者）、addiction（addict + **-ion** 名词后缀 = 上瘾）、dictate（**dict** 说 + **-ate** 动词后缀 = 口述、命令）、dictionary（**dict** 说 + **-ion** + **-ary** 物 = 说话汇集→词典）、predict（**pre-** 前 + dict 说 = 预先说→预言）。
- **前缀·后缀**：前缀 **ad-**（例：advance, admire）；形容词后缀 **-ed**（例：excited, tired）。
- **同义·反义**：同义 hooked（着迷的）, dependent（依赖的）；反义 unaddicted（未上瘾的）。
- **变形**：形容词 → 无比较级（描述状态，不作比较）；名词派生 → addict n. 上瘾者；addiction n. 上瘾；动词派生 → addict v. 使沉溺。

### 4. bullying /ˈbʊliɪŋ/ n. 霸凌;仗势作恶
- **词根·渊源**：中古荷兰语 *boele*（情人、兄弟）→ 英语 *bully*（原义“情人”，后转“仗势欺人者”）+ **-ing** 名词后缀 → bullying；本义“以强凌弱的行为”，即“霸凌”。
- **同根词**：bully（**bully** 仗势欺人者 = 欺凌；欺负）、bullied（bully + **-ed** 过去分词 = 被欺凌的）、bullyish（bully + **-ish** …似的 = 像恶霸的）。
- **前缀·后缀**：名词后缀 **-ing**（例：meeting, building）；形容词后缀 **-ish**（例：childish, foolish）。
- **同义·反义**：同义 harassment（骚扰）, intimidation（恐吓）；反义 protection（保护）, kindness（善意）。
- **变形**：名词 → 复数：bullyings（多作不可数）；动词派生 → bully v. 欺凌；形容词派生 → bullied adj. 被欺凌的。

### 5. charge /ʧɑrʤ/ n. 职责;责任
- **词根·渊源**：拉丁 **carricare**（装车、装载）→ 古法语 *chargier*（装载、负担）→ 英语 charge；本义“装载的负担”，引申为“职责、责任”。
- **同根词**：charged（charge + **-ed** 形容词后缀 = 充满的；被指控的）、charger（charge + **-er** 物 = 充电器）、discharge（**dis-** 去除 + charge 装载 = 卸下→排放、解雇）、cargo（拉丁 **carrus** 车 + **-go** 物 = 车上装载物→货物）、carriage（拉丁 **carrus** 车 + **-iage** 名词后缀 = 载运→马车）。
- **前缀·后缀**：前缀 **dis-**（例：discover, disagree）；名词后缀 **-er**（例：driver, printer）。
- **同义·反义**：同义 responsibility（责任）, duty（职责）；反义 irresponsibility（不负责任）。
- **变形**：名词 → 复数：charges；动词派生 → charge v. 收费；充电；指控；形容词派生 → charged adj. 充满的；被指控的。

### 6. awful /ˈɔfəl/ adj. 很坏的;极讨厌的
- **词根·渊源**：古英语 **ege**（恐惧）+ **-full**（充满…的）→ 中古英语 *agheful* → 英语 awful；本义“充满敬畏/恐惧的”，后转义为“可怕的、极坏的”。
- **同根词**：awe（**awe** 敬畏 = 敬畏）、awesome（awe + **-some** 引起…的 = 引起敬畏的→极好的）、awfully（awful + **-ly** 副词后缀 = 非常；糟糕地）、awestruck（awe + struck 被击 = 被敬畏击中的→肃然起敬的）。
- **前缀·后缀**：形容词后缀 **-ful**（例：helpful, useful）；副词后缀 **-ly**（例：quickly, happily）。
- **同义·反义**：同义 terrible（可怕的）, dreadful（糟糕的）；反义 wonderful（极好的）, pleasant（愉快的）。
- **变形**：形容词 → 比较级：more awful；最高级：most awful；副词派生 → awfully adv. 非常；糟糕地；名词派生 → awfulness n. 糟糕。

### 7. focus /ˈfoʊkɪs/ v. 集中(注意力)
- **词根·渊源**：拉丁 **focus**（炉灶、火塘）→ 拉丁 *focus*（中心点）→ 英语 focus；本义“炉火所在之处→中心”，引申为“焦点、集中注意力”。
- **同根词**：focal（focus + **-al** …的 = 焦点的）、focused（focus + **-ed** 形容词后缀 = 专注的）、focusing（focus + **-ing** 名词后缀 = 聚焦）、refocus（**re-** 再 + focus 焦点 = 重新聚焦）。
- **前缀·后缀**：前缀 **re-**（例：return, rebuild）；形容词后缀 **-al**（例：natural, musical）。
- **同义·反义**：同义 concentrate（集中）, center（集中）；反义 distract（分心）, scatter（分散）。
- **变形**：动词 → 第三人称单数：focuses；过去式：focused；过去分词：focused；现在分词：focusing；名词派生 → focus n. 焦点；形容词派生 → focused adj. 专注的。

### 8. affect /əˈfɛkt/ v. 影响
- **词根·渊源**：拉丁 **afficere**（对…做、施加）→ 拉丁 *affectus*（受影响的）→ 英语 affect；本义“对…施加作用”，引申为“影响”。
- **同根词**：affection（affect + **-ion** 名词后缀 = 影响→情感）、affective（affect + **-ive** …的 = 情感的）、affected（affect + **-ed** 形容词后缀 = 受影响的；做作的）、effect（**ef-** 出 + **fect** 做 = 做出来的结果→效果）、infect（**in-** 进入 + fect 做 = 做进去→感染）。
- **前缀·后缀**：前缀 **af-**（= ad- 向，例：affirm, afford）；名词后缀 **-ion**（例：action, nation）。
- **同义·反义**：同义 influence（影响）, impact（影响）；反义 leave（不改变）。
- **变形**：动词 → 第三人称单数：affects；过去式：affected；过去分词：affected；现在分词：affecting；名词派生 → affection n. 情感；effect n. 效果；形容词派生 → affected adj. 受影响的。

### 9. hate /heɪt/ v. 厌恶;讨厌
- **词根·渊源**：古英语 **hatian**（憎恨）→ 中古英语 *haten* → 英语 hate；本义“憎恨”，引申为“厌恶、讨厌”。
- **同根词**：hatred（hate + **-red** 名词后缀 = 憎恨）、hateful（hate + **-ful** 充满…的 = 可恨的）、hater（hate + **-er** 人 = 憎恨者）、hatefully（hateful + **-ly** 副词后缀 = 可恨地）。
- **前缀·后缀**：名词后缀 **-red**（例：kindred）；形容词后缀 **-ful**（例：hopeful, careful）。
- **同义·反义**：同义 dislike（不喜欢）, detest（憎恶）；反义 love（爱）, like（喜欢）。
- **变形**：动词 → 第三人称单数：hates；过去式：hated；过去分词：hated；现在分词：hating；名词派生 → hatred n. 憎恨；hater n. 憎恨者；形容词派生 → hateful adj. 可恨的。

### 10. embarrassed /ɪmˈbɛrəst/ adj. 窘迫的;尴尬的
- **词根·渊源**：法语 *embarrasser*（阻塞、妨碍）→ 西班牙语 *embarazar*（使为难）→ 英语 embarrass + **-ed** → embarrassed；本义“被挡住、陷入困境”，引申为“窘迫的、尴尬的”。
- **同根词**：embarrass（**em-** 使 + **barras** 障碍 = 使陷入障碍→使尴尬）、embarrassing（embarrass + **-ing** 形容词后缀 = 令人尴尬的）、embarrassment（embarrass + **-ment** 名词后缀 = 尴尬）。
- **前缀·后缀**：前缀 **em-**（= en- 使，例：enable, enrich）；形容词后缀 **-ed**（例：interested, surprised）。
- **同义·反义**：同义 awkward（尴尬的）, ashamed（羞愧的）；反义 confident（自信的）, proud（自豪的）。
- **变形**：形容词 → 比较级：more embarrassed；最高级：most embarrassed；名词派生 → embarrassment n. 尴尬；动词派生 → embarrass v. 使尴尬。

### 11. mad /mæd/ adj. 很生气
- **词根·渊源**：古英语 **gemād**（疯狂的、愚蠢的）→ 中古英语 *mad* → 英语 mad；本义“失去理智的”，后引申为“很生气的”（口语）。
- **同根词**：madly（mad + **-ly** 副词后缀 = 疯狂地）、madness（mad + **-ness** 名词后缀 = 疯狂）、madman（mad + man 人 = 疯子）、madden（mad + **-en** 动词后缀 = 使发疯）。
- **前缀·后缀**：副词后缀 **-ly**（例：sadly, badly）；名词后缀 **-ness**（例：happiness, kindness）。
- **同义·反义**：同义 angry（生气的）, furious（暴怒的）；反义 calm（平静的）, pleased（高兴的）。
- **变形**：形容词 → 比较级：madder；最高级：maddest；副词派生 → madly adv. 疯狂地；名词派生 → madness n. 疯狂。

### 12. mess /mɛs/ v. 弄脏;弄乱
- **词根·渊源**：古法语 **mes**（一道菜）→ 中古英语 *mes*（一份食物）→ 英语 mess；本义“一份食物→餐桌上的杂乱”，引申为“弄脏、弄乱”。
- **同根词**：messy（mess + **-y** 形容词后缀 = 凌乱的）、messily（messy + **-ly** 副词后缀 = 凌乱地）、messiness（messy + **-ness** 名词后缀 = 凌乱）。
- **前缀·后缀**：形容词后缀 **-y**（例：dirty, rainy）；名词后缀 **-ness**（例：darkness, softness）。
- **同义·反义**：同义 dirty（弄脏）, disorder（弄乱）；反义 clean（清洁）, tidy（整理）。
- **变形**：动词 → 第三人称单数：messes；过去式：messed；过去分词：messed；现在分词：messing；名词派生 → mess n. 混乱；形容词派生 → messy adj. 凌乱的。

### 13. radio /ˈreɪdiˌoʊ/ n. 广播
- **词根·渊源**：拉丁 **radius**（射线）→ 拉丁 *radius*（光线）→ 英语 radio；本义“辐射、射线”，因无线电波得名，引申为“广播、收音机”。
- **同根词**：radiate（**radi-** 射线 + **-ate** 动词后缀 = 辐射）、radiation（radiate + **-ion** 名词后缀 = 辐射）、radiator（radiate + **-or** 物 = 散热器）、radius（**radi-** 射线 + **-us** 名词后缀 = 半径）。
- **前缀·后缀**：动词后缀 **-ate**（例：create, calculate）；名词后缀 **-ion**（例：action, station）。
- **同义·反义**：同义 broadcast（广播）；反义 无。
- **变形**：名词 → 复数：radios；动词派生 → radio v. 用无线电发送；形容词派生 → radial adj. 辐射状的。

### 14. ashamed /əˈʃeɪmd/ adj. 惭愧;羞愧
- **词根·渊源**：古英语 **sceamu**（羞耻）→ 中古英语 *shame* → 英语 shame + **a-** 前缀 + **-ed** → ashamed；本义“处于羞耻之中的”，即“惭愧的、羞愧的”。
- **同根词**：shame（**shame** 羞耻 = 羞耻）、shameful（shame + **-ful** 充满…的 = 可耻的）、shameless（shame + **-less** 无…的 = 无耻的）、shamefully（shameful + **-ly** 副词后缀 = 可耻地）。
- **前缀·后缀**：前缀 **a-**（处于…状态，例：alive, asleep）；形容词后缀 **-ed**（例：tired, excited）。
- **同义·反义**：同义 embarrassed（尴尬的）, guilty（内疚的）；反义 proud（自豪的）, shameless（无耻的）。
- **变形**：形容词 → 无比较级（描述状态，不作比较）；名词派生 → shame n. 羞耻；形容词派生 → shameful adj. 可耻的；shameless adj. 无耻的。

### 15. respond /rɪˈspɑnd/ v. (口头或书面)回答
- **词根·渊源**：拉丁 **respondere**（回承诺、回应）→ 古法语 *respondre* → 英语 respond；本义“回话、回应”，引申为“回答”。
- **同根词**：response（respond + **-se** 名词后缀 = 回答、反应）、responsive（response + **-ive** …的 = 反应灵敏的）、respondent（respond + **-ent** 人 = 回答者）、correspond（**cor-** 共同 + respond 回应 = 共同回应→通信、相符）。
- **前缀·后缀**：前缀 **cor-**（= con- 共同，例：connect, collect）；形容词后缀 **-ive**（例：active, creative）。
- **同义·反义**：同义 reply（回答）, answer（回答）；反义 ignore（忽视）, ask（问）。
- **变形**：动词 → 第三人称单数：responds；过去式：responded；过去分词：responded；现在分词：responding；名词派生 → response n. 回答；respondent n. 回答者；形容词派生 → responsive adj. 反应灵敏的。

### 16. sympathy /ˈsɪmpəθi/ n. 同情
- **词根·渊源**：希腊 **syn-**（共同）+ **pathos**（感受）→ 希腊 *sympatheia* → 拉丁 *sympathia* → 英语 sympathy；本义“共同感受”，引申为“同情”。
- **同根词**：sympathetic（sympathy + **-etic** 形容词后缀 = 同情的）、sympathize（sympathy + **-ize** 动词后缀 = 同情）、sympathizer（sympathize + **-er** 人 = 同情者）、pathetic（**path** 感受 + **-etic** …的 = 引起怜悯的）、apathy（**a-** 无 + path 感受 + **-y** 名词后缀 = 无感情→冷漠）。
- **前缀·后缀**：前缀 **sym-**（= syn- 共同，例：symbol, system）；名词后缀 **-y**（例：history, memory）。
- **同义·反义**：同义 compassion（同情）, pity（怜悯）；反义 indifference（冷漠）, apathy（冷漠）。
- **变形**：名词 → 复数：sympathies；形容词派生 → sympathetic adj. 同情的；动词派生 → sympathize v. 同情。

### 17. section /ˈsɛkʃən/ n. 部分
- **词根·渊源**：拉丁 **secare**（切）→ 拉丁 *sectio*（切割）→ 法语 *section* → 英语 section；本义“切下的部分”，引申为“部分、部门”。
- **同根词**：sector（**sect** 切 + **-or** 物 = 切出的部分→部门）、insect（**in-** 进入 + sect 切 = 切入→昆虫，因身体分节）、dissect（**dis-** 分开 + sect 切 = 切开→解剖）、intersect（**inter-** 之间 + sect 切 = 在中间切→相交）、segment（**seg-** 切 + **-ment** 名词后缀 = 切下的部分→段）。
- **前缀·后缀**：前缀 **in-**（例：inside, include）、**dis-**（例：discover, dismiss）；名词后缀 **-ion**（例：action, nation）。
- **同义·反义**：同义 part（部分）, division（部分）；反义 whole（整体）, entirety（全部）。
- **变形**：名词 → 复数：sections；动词派生 → section v. 划分；形容词派生 → sectional adj. 部分的。

### 18. newspaper /ˈnuzˌpeɪpər/ n. 报纸
- **词根·渊源**：**news**（新闻）+ **paper**（纸）→ 英语 newspaper；本义“印有新闻的纸”，即“报纸”。
- **同根词**：news（**news** 新闻 = 新闻）、paper（**paper** 纸 = 纸）、newsprint（news + print 印刷 = 新闻纸）、paperback（paper + back 背 = 平装书）。
- **前缀·后缀**：无前后缀（复合词：news + paper）。
- **同义·反义**：同义 press（报刊）, journal（期刊）；反义 无。
- **变形**：名词 → 复数：newspapers；形容词派生 → newspapered adj. 登在报纸上的。

### 19. operate /ˈɔpərˌeɪt/ v. 运营;管理
- **词根·渊源**：拉丁 **oper-**（工作、劳作）→ 拉丁 *operari*（工作、忙碌）→ 拉丁 *operatus*（operari 的过去分词）→ 英语 operate；本义“劳作、从事工作”，引申为“使（机器、机构）运转工作”，再引申为“运营、管理”。
- **同根词**：operation（oper 工作 + **-ation** 名词后缀 = 工作过程→操作、手术、运营）、operator（operate + **-or** 做…的人 = 操作员）、operational（operation + **-al** …的 = 运作上的）、cooperate（**co-** 共同 + oper 工作 + **-ate** 动词后缀 = 一起工作→合作）、opera（意大利语，源自拉丁 opera“工作、作品”→ 歌剧）。
- **前缀·后缀**：动词后缀 **-ate**（例：create, calculate）；名词后缀 **-ation**（例：creation, information）；名词后缀 **-or**（例：actor, visitor）；前缀 **co-**（例：coexist, connect）。
- **同义·反义**：同义 run（经营）, manage（管理）；反义 无。
- **变形**：动词 → 第三人称单数：operates；过去式：operated；过去分词：operated；现在分词：operating；名词派生 → operation n. 操作、运营；operator n. 操作员；形容词派生 → operational adj. 运作上的；副词派生 → operationally adv. 运作上地。

### 20. helpline /'helplaɪn/ n. 服务热线(提供咨询和信息的电话)
- **词根·渊源**：复合词，由 **help**（帮助，古英语 *helpan*，日耳曼语源）+ **line**（线、电话线路，拉丁 *linea* 线 → 古英语 *line*）合成，20世纪中期英语新造复合词，本义“提供帮助的电话线路”，即“服务热线”。
- **同根词**：helpful（help + **-ful** 充满…的 = 有帮助的）、helpless（help + **-less** 无…的 = 无助的）、helper（help + **-er** 人 = 帮手）、line（line 线→电话线路）、online（**on-** 在…上 + line 线 = 在线的）、headline（head 头 + line 线 = 标题）。
- **前缀·后缀**：无前后缀（复合词，由 help + line 合成）。
- **同义·反义**：同义 hotline（热线）；反义 无。
- **变形**：名词 → 复数：helplines；形容词派生 → 无；副词派生 → 无。

### 21. click /klɪk/ n. (对鼠标的)点击
- **词根·渊源**：拟声词，模拟短促的“咔嗒”声，16世纪英语已有 *click*（咔嗒声）；20世纪计算机时代引申为“（鼠标）点击”，名词义即“一次点击”。
- **同根词**：click（动词，同形→点击）、clickable（click + **-able** 可…的 = 可点击的）、clicker（click + **-er** 物 = 点击器、遥控器）。
- **前缀·后缀**：名词后缀 **-er**（例：teacher, worker）；形容词后缀 **-able**（例：readable, usable）。
- **同义·反义**：同义 tap（轻点）, press（按压）；反义 无。
- **变形**：名词 → 复数：clicks；动词 → 第三人称单数：clicks；过去式：clicked；过去分词：clicked；现在分词：clicking；形容词派生 → clickable adj. 可点击的；名词派生 → clicker n. 点击器。
