## 二、逐词说文解字

### 1. online /ˌɑ:nˈlaɪn/ adj. 在线，联网；在线地；在线的
- **词根·渊源**：**on**（在……上）+ **line**（线，源自拉丁 *linea* 亚麻线 → 古法语 *ligne* → 英语 line），本义“在（电话）线路上”，20世纪随电信与计算机网络发展引申为“联网的、在线的”。
- **同根词**：line（单纯词，线）、outline（**out-** 外 + line 线 = 外轮廓→提纲）、lineage（line 线 + **-age** 名词后缀 = 血统线→世系）、linear（line 线 + **-ar** …的→线性的）、underline（**under-** 下 + line 线 = 在下面画线→强调）。
- **前缀·后缀**：前缀 **on-**（例：onset, onlooker）；无后缀（复合词）。
- **同义·反义**：同义 connected（联网的）, on the Internet（在网上）；反义 offline（离线的）。
- **变形**：形容词 → 无比较级（关系形容词，不作比较）；副词 → 无比较级；名词派生 → 无常用派生。

### 2. model /ˈmɑːdl/ n. 模范，典型；模特儿
- **词根·渊源**：拉丁 **modus**（尺度、方式）→ 拉丁 *modulus*（小尺度）→ 意大利语 *modello* → 法语 *modelle* → 英语，本义“小尺度的样板”，引申为“模范、模型”，再引申为“供人描画或展示的模特儿”。
- **同根词**：moderate（mod 尺度 + **-erate** 动词后缀 = 使合尺度→使适中）、modest（mod 尺度 + **-est** = 守尺度的→谦虚的）、modify（mod 尺度 + **-ify** 使…… = 使合尺度→修改）、mode（单纯词，方式、模式）、module（mod 尺度 + **-ule** 小 = 小尺度单位→模块）。
- **前缀·后缀**：名词后缀 **-el**（例：channel, tunnel）；无前缀。
- **同义·反义**：同义 example（榜样）, pattern（典范）；反义 无。
- **变形**：名词 → 复数：models；动词派生 → model v. 做模特儿、仿制（第三人称单数：models；过去式：modeled/modelled；过去分词：modeled/modelled；现在分词：modeling/modelling）；形容词派生 → model adj. 模范的（无比较级）。

### 3. diet /ˈdaɪɪt/ n. 日常饮食；规定饮食
- **词根·渊源**：希腊 **diaita**（生活方式、 regimen）→ 拉丁 *diaeta* → 古法语 *diete* → 英语，本义“生活方式”，因饮食是生活方式的核心，引申为“日常饮食”，再引申为“为健康或减肥而规定的饮食”。
- **同根词**：dietary（diet + **-ary** …的→饮食的）、dietitian（diet + **-itian** 从业者 = 饮食专家→营养师）、dietetic（希腊 diaita 生活 + **-etic** …的→饮食疗法的）。
- **前缀·后缀**：名词后缀 **-t**（例：flight, gift）；无前缀。
- **同义·反义**：同义 food（食物）, nutrition（营养）；反义 无。
- **变形**：名词 → 复数：diets；动词派生 → diet v. 节食（第三人称单数：diets；过去式：dieted；过去分词：dieted；现在分词：dieting）；形容词派生 → dietary adj. 饮食的。

### 4. though /ðoʊ/ adv. 不过；可是；虽然；尽管；但是
- **词根·渊源**：古英语 **þēah**（虽然、尽管），源自原始日耳曼语 *þauh*，与古诺斯语 *þó* 同源；本义即“虽然”，作副词时引申为“不过、可是”。
- **同根词**：although（**al-** 全 + though 虽然 = 尽管）、tho（though 的口语缩略拼写，单纯词）。
- **前缀·后缀**：无前后缀（单纯词）。
- **同义·反义**：同义 although（虽然）, however（然而）；反义 无。
- **变形**：连词/副词 → 无形态变化（不作比较级）。

### 5. awful /ˈɔfəl/ adj. 很坏的；极讨厌的
- **词根·渊源**：**awe**（敬畏，源自古诺斯语 *agi* 恐惧）+ **-ful**（充满……的），本义“充满敬畏的、令人敬畏的”，词义由“令人敬畏”弱化贬降为“可怕的”，再引申为“很坏的、极讨厌的”。
- **同根词**：awe（单纯词，敬畏）、awesome（awe 敬畏 + **-some** 引起……的 = 引起敬畏的→极好的）、awfully（awful + **-ly** 副词后缀→非常、极其）、awestruck（awe 敬畏 + struck 被击中的 = 被敬畏击中的→肃然起敬的）。
- **前缀·后缀**：形容词后缀 **-ful**（例：careful, hopeful）；无前缀。
- **同义·反义**：同义 terrible（可怕的）, dreadful（糟糕的）；反义 wonderful（极好的）, pleasant（令人愉快的）。
- **变形**：形容词 → 比较级：more awful；最高级：most awful；副词派生 → awfully adv. 非常、极其；名词派生 → awfulness n. 糟糕。

### 6. regret /rɪˈɡret/ v. 后悔；遗憾；懊悔
- **词根·渊源**：古法语 **regreter**（哀悼、怀念），可能源自日耳曼语 *grētan*（哭泣），**re-** 加强 + 日耳曼词根“哭”，本义“为……而哭”，引申为“后悔、遗憾”（词源细节存疑）。
- **同根词**：regretful（regret + **-ful** 充满……的→后悔的）、regrettable（regret + **-able** 可……的→令人遗憾的）、regrettably（regrettable + **-ly** 副词后缀→遗憾地）。
- **前缀·后缀**：前缀 **re-**（例：recall, return）；无后缀（动词词根）。
- **同义·反义**：同义 repent（悔悟）, be sorry（遗憾）；反义 无。
- **变形**：动词 → 第三人称单数：regrets；过去式：regretted；过去分词：regretted；现在分词：regretting；名词派生 → regret n. 后悔（复数：regrets）；形容词派生 → regretful adj. 后悔的；副词派生 → regretfully adv. 遗憾地。

### 7. ashamed /ə'ʃeɪmd/ adj. 惭愧；羞愧；感到羞愧，感到羞耻；羞于（做某事）
- **词根·渊源**：**a-**（处于……状态，源自古英语 *of-* 加强）+ **shame**（羞耻，古英语 *sceamu*）+ **-ed**（形容词后缀），本义“处于羞耻之中的”，即“感到羞愧的”。
- **同根词**：shame（单纯词，羞耻）、shameful（shame + **-ful** 充满……的→可耻的）、shameless（shame + **-less** 无……的→无耻的）、shamefully（shameful + **-ly** 副词后缀→可耻地）。
- **前缀·后缀**：前缀 **a-**（例：alive, asleep）；形容词后缀 **-ed**（例：tired, excited）。
- **同义·反义**：同义 embarrassed（尴尬的）, guilty（内疚的）；反义 proud（自豪的）, shameless（无耻的）。
- **变形**：形容词 → 无比较级（表心理状态，一般不作比较）；名词派生 → shame n. 羞耻；副词派生 → ashamedly adv. 羞愧地。

### 8. situation /ˌsɪtʃuˈeɪʃn/ n. 形势,情况；状况
- **词根·渊源**：拉丁 **situs**（位置，*sinere* 放置的过去分词）→ 中世纪拉丁 *situatio* → 法语 *situation* → 英语，本义“位置、坐落”，引申为“所处的位置、境况”，再引申为“形势、情况”。
- **同根词**：site（拉丁 situs 位置→地点）、situate（situs 位置 + **-ate** 动词后缀→使位于）、situated（situate + **-ed** …的→位于……的）、situation（本词）。
- **前缀·后缀**：名词后缀 **-ation**（例：information, education）；无前缀。
- **同义·反义**：同义 condition（状况）, circumstance（情形）；反义 无。
- **变形**：名词 → 复数：situations；形容词派生 → situational adj. 情境的；副词派生 → situationally adv. 情境上。

### 9. braces /b'reɪsɪz/ n. 牙箍
- **词根·渊源**：拉丁 **bracchia**（手臂，*bracchium* 的复数）→ 古法语 *brace*（手臂）→ 英语 brace，本义“手臂”，引申为“箍住、支撑之物”，复数 braces 指“矫正牙齿的箍”，即牙箍。
- **同根词**：brace（单纯词，支架、箍）、embrace（**em-** 使入 + brace 手臂 = 抱入手臂→拥抱）、bracelet（brace 手臂 + **-let** 小 = 手臂上的小环→手镯）、bracing（brace + **-ing** …的→使振作的）。
- **前缀·后缀**：名词复数后缀 **-s**（例：shoes, glasses）；无前缀。
- **同义·反义**：同义 orthodontic braces（正畸牙箍）, dental braces（牙套）；反义 无。
- **变形**：名词 → 复数：braces（本词即复数形式，单数 brace 指“支架”）；无比较级。

### 10. hate /heɪt/ v. 厌恶；憎恶；憎恨；讨厌
- **词根·渊源**：古英语 **hatian**（憎恨），源自原始日耳曼语 *hatōjan*，与古诺斯语 *hata* 同源；本义即“憎恨”，词义至今基本未变。
- **同根词**：hatred（hate 恨 + **-red** 状态后缀 = 憎恨状态→仇恨）、hateful（hate + **-ful** 充满……的→可恨的）、hater（hate + **-er** 人→憎恨者）、hatefully（hateful + **-ly** 副词后缀→可恨地）。
- **前缀·后缀**：无前后缀（单纯词）。
- **同义·反义**：同义 dislike（不喜欢）, detest（憎恶）；反义 love（爱）, like（喜欢）。
- **变形**：动词 → 第三人称单数：hates；过去式：hated；过去分词：hated；现在分词：hating；名词派生 → hate n. 憎恨（不可数）；形容词派生 → hateful adj. 可恨的；副词派生 → hatefully adv. 可恨地。

### 11. advantage /ədˈvæntɪdʒ/ n. 优势；优点；有利条件
- **词根·渊源**：古法语 **avant**（在前，源自拉丁 *ab ante* 从前面）+ **-age**（名词后缀），本义“处于前面、领先的位置”，引申为“优势、有利条件”。
- **同根词**：advance（**ad-** 向 + 拉丁 *ante* 前 = 向前→前进）、advantageous（advantage + **-ous** …的→有利的）、disadvantage（**dis-** 相反 + advantage = 不利条件→劣势）、advantaged（advantage + **-ed** …的→处于有利地位的）。
- **前缀·后缀**：前缀 **ad-**（例：advance, admit）；名词后缀 **-age**（例：marriage, package）。
- **同义·反义**：同义 benefit（好处）, edge（优势）；反义 disadvantage（劣势）, drawback（缺点）。
- **变形**：名词 → 复数：advantages；形容词派生 → advantageous adj. 有利的；副词派生 → advantageously adv. 有利地。

### 12. embarrassed /ɪmˈbærəst/ adj. 尴尬的；窘迫的
- **词根·渊源**：法语 **embarrasser**（阻碍、使窘迫），可能源自西班牙语 *embarazar*（阻碍），**em-** 使入 + *barra* 横杆（存疑），本义“用横杆拦住→使受阻”，引申为“使窘迫”，加 **-ed** 成形容词“尴尬的”。
- **同根词**：embarrass（**em-** 使入 + barra 横杆 = 使受阻→使窘迫）、embarrassment（embarrass + **-ment** 名词后缀→窘迫）、embarrassing（embarrass + **-ing** …的→令人尴尬的）、embarrassingly（embarrassing + **-ly** 副词后缀→令人尴尬地）。
- **前缀·后缀**：前缀 **em-**（例：enable, employ）；形容词后缀 **-ed**（例：tired, excited）。
- **同义·反义**：同义 awkward（尴尬的）, ashamed（羞愧的）；反义 confident（自信的）, at ease（自在的）。
- **变形**：形容词 → 比较级：more embarrassed；最高级：most embarrassed；名词派生 → embarrassment n. 窘迫；副词派生 → embarrassedly adv. 尴尬地。

### 13. suggest /səˈdʒest/ v. 建议；提议
- **词根·渊源**：拉丁 **suggerere**（在下面带来、提供），**sub-**（在下）+ **gerere**（携带）→ 拉丁 *suggestus* → 英语，本义“从下面悄悄递上”，引申为“在心头递上想法→建议、提议”。
- **同根词**：suggestion（suggest + **-ion** 名词后缀→建议）、suggestive（suggest + **-ive** …的→暗示的）、digest（**di-** 分开 + gest 携带 = 分开携带→消化）、gesture（gest 携带 + **-ure** 名词后缀 = 携带动作→手势）。
- **前缀·后缀**：前缀 **sug-**（= sub- 在下，例：suggest, support）；无后缀（动词词根）。
- **同义·反义**：同义 propose（提议）, recommend（推荐）；反义 无。
- **变形**：动词 → 第三人称单数：suggests；过去式：suggested；过去分词：suggested；现在分词：suggesting；名词派生 → suggestion n. 建议；形容词派生 → suggestive adj. 暗示的。

### 14. mad /mæd/ adj. 很生气；疯的；气愤
- **词根·渊源**：古英语 **gemād**（愚蠢的、疯的），源自原始日耳曼语 *ga-maidaz*，与 *maid* 变化义相关；本义“心智失常的→疯的”，美式英语引申为“很生气的”。
- **同根词**：madness（mad + **-ness** 名词后缀→疯狂）、madly（mad + **-ly** 副词后缀→疯狂地）、madman（mad 疯 + man 人 = 疯子）、madding（mad + **-ing** …的→使人发狂的）。
- **前缀·后缀**：无前后缀（单纯词）。
- **同义·反义**：同义 crazy（疯狂的）, angry（生气的）；反义 sane（神志正常的）, calm（平静的）。
- **变形**：形容词 → 比较级：madder；最高级：maddest；名词派生 → madness n. 疯狂；副词派生 → madly adv. 疯狂地。

### 15. mess /mɛs/ n. 肮脏；凌乱；杂乱；不整洁
- **词根·渊源**：古法语 **mes**（一道菜，源自拉丁 *mittere* 送、放），本义“摆上桌的一份食物”，引申为“一桌饭菜”，再引申为“混杂的一堆→凌乱、肮脏”。
- **同根词**：messy（mess + **-y** …的→凌乱的）、messily（messy + **-ly** 副词后缀→凌乱地）、messiness（messy + **-ness** 名词后缀→凌乱）。
- **前缀·后缀**：无前后缀（单纯词）。
- **同义·反义**：同义 disorder（混乱）, clutter（杂乱）；反义 order（整齐）, tidiness（整洁）。
- **变形**：名词 → 复数：messes；形容词派生 → messy adj. 凌乱的；副词派生 → messily adv. 凌乱地。

### 16. annoying /ə'nɔɪɪŋ/ adj. 令人恼火的；使恼怒的；使生气的
- **词根·渊源**：古法语 **anoier**（使厌烦，可能源自拉丁 *in odio* 处于憎恨中），**an-**（= ad- 向）+ 词根 *noi*（厌烦）→ 英语 annoy + **-ing**（形容词后缀），本义“使人厌烦的”，即“令人恼火的”。
- **同根词**：annoy（**an-** 向 + noi 厌烦 = 使厌烦→惹恼）、annoyance（annoy + **-ance** 名词后缀→恼怒）、annoyed（annoy + **-ed** …的→感到恼火的）、annoyingly（annoying + **-ly** 副词后缀→恼人地）。
- **前缀·后缀**：前缀 **an-**（例：announce, annoy）；形容词后缀 **-ing**（例：boring, exciting）。
- **同义·反义**：同义 irritating（恼人的）, bothersome（烦人的）；反义 pleasing（令人愉快的）, delightful（令人高兴的）。
- **变形**：形容词 → 比较级：more annoying；最高级：most annoying；名词派生 → annoyance n. 恼怒；副词派生 → annoyingly adv. 恼人地。

### 17. fail /feɪl/ v. 没有通过（考试）；不及格；失败
- **词根·渊源**：古法语 **faillir**（缺乏、失误），源自拉丁 *fallere*（欺骗、使失望）→ 英语，本义“使失望、缺失”，引申为“失败、不及格”。
- **同根词**：failure（fail + **-ure** 名词后缀→失败）、failing（fail + **-ing** 名词/形容词后缀→缺点、衰退的）、failsafe（fail 失败 + safe 安全 = 故障安全的）、fallible（拉丁 fallere 欺骗 + **-ible** 可……的→易犯错的）。
- **前缀·后缀**：无前后缀（单纯词）。
- **同义·反义**：同义 flunk（不及格）, lose（失败）；反义 succeed（成功）, pass（通过）。
- **变形**：动词 → 第三人称单数：fails；过去式：failed；过去分词：failed；现在分词：failing；名词派生 → failure n. 失败；形容词派生 → failing adj. 衰退的。

### 18. careless /ˈkeələs/ adj. 不小心的，粗心的
- **词根·渊源**：**care**（关心，古英语 *cearu* 忧虑）+ **-less**（无……的），本义“无关心的”，即“不小心的、粗心的”。
- **同根词**：care（单纯词，关心）、careful（care + **-ful** 充满……的→小心的）、carelessly（careless + **-ly** 副词后缀→粗心地）、carelessness（careless + **-ness** 名词后缀→粗心）、caring（care + **-ing** …的→有爱心的）。
- **前缀·后缀**：形容词后缀 **-less**（例：hopeless, homeless）；无前缀。
- **同义·反义**：同义 negligent（疏忽的）, thoughtless（欠考虑的）；反义 careful（小心的）, cautious（谨慎的）。
- **变形**：形容词 → 比较级：more careless；最高级：most careless；名词派生 → carelessness n. 粗心；副词派生 → carelessly adv. 粗心地。

### 19. comment /'kɒment/ v. 评论，意见；批评，指责；说明，写照
- **词根·渊源**：拉丁 **com-**（一起）+ **ment-**（心智，思考）→ 拉丁 *commentum*（发明，注释）→ 古法语 *comment* → 英语；本义“用心思考后一起说出的话”，引申为“评论、意见”。
- **同根词**：mental（**ment-** 心智 + **-al** …的 = 心智的→精神的）、mention（**ment-** 心智 + **-ion** 名词后缀 = 想到→提及）、commentary（comment + **-ary** 名词后缀 = 评论集→实况解说）、commentator（comment + **-ator** 人 = 评论员）。
- **前缀·后缀**：前缀 **com-**（例：combine, compare）；名词后缀 **-ment**（例：movement, argument）。
- **同义·反义**：同义 remark（评论）, observe（评论说）；反义 无。
- **变形**：动词 → 第三人称单数：comments；过去式：commented；过去分词：commented；现在分词：commenting；名词 → 复数：comments；名词派生 → comment n. 评论；commentator n. 评论员。

### 20. request /rɪˈkwɛst/ v. 要求；请求
- **词根·渊源**：拉丁 **re-**（再，加强）+ **quaerere**（寻求，询问）→ 拉丁 *requirere*（寻求）→ 古法语 *requeste* → 英语；本义“一再寻求”，引申为“请求、要求”。
- **同根词**：require（**re-** 再 + **quire** 寻求 = 一再寻求→需要，要求）、requirement（require + **-ment** 名词后缀 = 要求→必要条件）、question（**quest-** 寻求 + **-ion** 名词后缀 = 寻求答案→问题）、inquire（**in-** 向内 + **quire** 寻求 = 深入寻求→询问）、acquire（**ac-** 朝向 + **quire** 寻求 = 寻求得到→获得）。
- **前缀·后缀**：前缀 **re-**（例：return, repeat）；名词后缀 **-est**（例：interest, harvest）。
- **同义·反义**：同义 ask（请求）, demand（要求）；反义 无。
- **变形**：动词 → 第三人称单数：requests；过去式：requested；过去分词：requested；现在分词：requesting；名词 → 复数：requests；名词派生 → request n. 请求；requirement n. 要求。

### 21. polite /pəˈlaɪt/ adj. 客气；有礼貌的
- **词根·渊源**：拉丁 **politus**（磨光的，精炼的）→ 拉丁 *politus* 是 *polire*（磨光）的过去分词 → 英语；本义“被磨光的、精致的”，引申为“有教养的、有礼貌的”。
- **同根词**：polish（**pol-** 磨光 + **-ish** 动词后缀 = 磨光→抛光）、impolite（**im-** 不 + polite 有礼貌的 = 不礼貌的）、politeness（polite + **-ness** 名词后缀 = 礼貌）、politely（polite + **-ly** 副词后缀 = 礼貌地）。
- **前缀·后缀**：前缀 **im-**（例：impossible, impatient）；形容词后缀 **-ite**（例：favorite, opposite）。
- **同义·反义**：同义 courteous（有礼貌的）, civil（文明的）；反义 rude（粗鲁的）, impolite（不礼貌的）。
- **变形**：形容词 → 比较级：politer；最高级：politest；副词派生 → politely adv. 礼貌地；名词派生 → politeness n. 礼貌。

### 22. none /nʌn/ n. 没有一个；毫无；没有任何东西；没一人
- **词根·渊源**：古英语 **ne**（不）+ **ān**（一个）= *nān* → 中古英语 *noon* → 英语 none；本义“没有一个”，引申为“毫无、没有任何东西”。
- **同根词**：no（**ne** 不 + **ā** 一个 = 没有一个→不）、not（**ne** 不 + **ā** 一个 + **t** 后缀 = 不）、nothing（**no** 不 + **thing** 东西 = 没有东西）、nobody（**no** 不 + **body** 人 = 没有人）、never（**ne** 不 + **ever** 曾经 = 从不）。
- **前缀·后缀**：无前后缀（单纯词）。
- **同义·反义**：同义 nobody（没有人）, nothing（没有东西）；反义 all（全部）, everyone（每个人）。
- **变形**：名词 → 复数：不可数；无比较级（代词性名词，不作比较）。

### 23. exam /ɪɡˈzæm/ n. 考试；测验
- **词根·渊源**：拉丁 **ex-**（出）+ **ag-**（驱动，做）+ **-men**（名词后缀）→ 拉丁 *examen*（天平指针，检验）→ 英语 examination 的缩略形式 exam；本义“检验”，引申为“考试、测验”。
- **同根词**：examine（**exam-** 检验 + **-ine** 动词后缀 = 检验→检查）、examination（examine + **-ation** 名词后缀 = 检查→考试）、examiner（examine + **-er** 人 = 检查者→考官）、exact（**ex-** 出 + **act** 驱动 = 驱动出结果→精确的）。
- **前缀·后缀**：前缀 **ex-**（例：exit, export）；名词后缀 **-am**（例：diagram, program）。
- **同义·反义**：同义 test（测验）, quiz（小测验）；反义 无。
- **变形**：名词 → 复数：exams；名词派生 → examine v. 检查；examination n. 考试；examiner n. 考官。
