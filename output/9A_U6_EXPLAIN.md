## 二、逐词说文解字

### 1. preference /ˈprefrəns/ n. 偏爱，偏好；喜爱；更喜欢的人（或物）
- **词根·渊源**：拉丁 **prae-**（在前）+ **ferre**（拿、带）→ 拉丁 *praeferre*（放在前面）→ 古法语 *preferer* → 英语 prefer；preference 由 prefer + **-ence** 构成，本义“把某物放在前面”，引申为“偏爱、偏好”。
- **同根词**：prefer（**pre-** 在前 + fer 拿 = 拿到前面→更喜欢）、refer（**re-** 回 + fer 带 = 带回去→提及、参考）、transfer（**trans-** 横过 + fer 带 = 带过去→转移）、offer（**of-** 向 + fer 拿 = 拿到面前→提供）、confer（**con-** 共同 + fer 拿 = 拿到一起→商议）、fertile（fer 带来 + **-tile** 能…的 = 能带来果实的→肥沃的）。
- **前缀·后缀**：前缀 **pre-**（例：predict, prepare）；名词后缀 **-ence**（例：difference, silence）。
- **同义·反义**：同义 liking（喜爱）, fondness（偏爱）；反义 dislike（厌恶）, distaste（反感）。
- **变形**：名词 → 复数：preferences；动词派生 → prefer v. 更喜欢；形容词派生 → preferable adj. 更可取的；副词派生 → preferably adv. 更可取地。

### 2. review /rɪˈvjuː/ n. 评价；评论（文章）
- **词根·渊源**：古法语 *revoir*（再看）← **re-**（再）+ **voir**（看，源自拉丁 *videre*）→ 英语 review，本义“再看一遍”，引申为“复查、评论、评价”。
- **同根词**：view（voir 看→看、视野）、interview（**inter-** 相互 + view 看 = 相互看→面试、采访）、preview（**pre-** 先 + view 看 = 先看→预览）、revise（**re-** 再 + vis 看 = 再看→修订）、vision（vis 看 + **-ion** 名词后缀→视力、远见）、visible（vis 看 + **-ible** 能…的→可见的）。
- **前缀·后缀**：前缀 **re-**（例：return, rebuild）；名词后缀 **-view** 源自看（例：interview, preview）。
- **同义·反义**：同义 evaluation（评价）, critique（评论）；反义 无。
- **变形**：名词 → 复数：reviews；动词 → 第三人称单数：reviews；过去式：reviewed；过去分词：reviewed；现在分词：reviewing；名词派生 → reviewer n. 评论者。

### 3. bean /biːn/ n. 豆子；豆荚
- **词根·渊源**：古英语 *bēan*（豆）→ 中古英语 *bene* → 英语 bean；与德语 *Bohne*、古诺斯语 *baun* 同源，属日耳曼语固有词，本义即“豆”。
- **同根词**：beanstalk（bean + stalk 茎 = 豆茎）、soybean（soy 大豆 + bean = 大豆）、beanbag（bean + bag 袋 = 豆袋）、coffee bean（coffee 咖啡 + bean 豆 = 咖啡豆）。
- **前缀·后缀**：无前后缀（单纯词）。
- **同义·反义**：同义 legume（豆类）, pulse（豆类）；反义 无。
- **变形**：名词 → 复数：beans；形容词派生 → beany adj. 豆味的。

### 4. beef /biːf/ n. 牛肉
- **词根·渊源**：拉丁 **bos / bov-**（牛）→ 古法语 *buef*（牛）→ 中古英语 *beef*，本义“牛”，后受诺曼法语影响专指“牛肉”；与 cow 同出印欧语牛词根。
- **同根词**：bovine（bov 牛 + **-ine** …的→牛的）、bovine（同上，形容词“牛一般的”）、beefsteak（beef + steak 牛排 = 牛排）、beefy（beef + **-y** …的 = 牛肉般的→结实的）。
- **前缀·后缀**：无前后缀（单纯词）。
- **同义·反义**：同义 无；反义 无。
- **变形**：名词 → 复数：beefs（作“牛肉”义时不可数）；形容词派生 → beefy adj. 结实的。

### 5. product /ˈprɑ:dʌkt/ n. 产品；制品；成果
- **词根·渊源**：拉丁 **pro-**（向前）+ **ducere**（引导）→ 拉丁 *productus*（被引出的）→ 英语 product，本义“被引出来的东西”，引申为“产品、成果”。
- **同根词**：produce（**pro-** 向前 + duc 引导 = 引出→生产）、conduct（**con-** 共同 + duct 引导 = 共同引导→指挥）、introduce（**intro-** 向内 + duc 引导 = 引入→介绍）、reduce（**re-** 回 + duc 引导 = 引回→减少）、educate（**e-** 出 + duc 引导 = 引出才能→教育）、duct（duct 引导→管道）。
- **前缀·后缀**：前缀 **pro-**（例：progress, promote）；名词后缀 **-duct** 源自引导（例：conduct, duct）。
- **同义·反义**：同义 goods（商品）, output（产出）；反义 无。
- **变形**：名词 → 复数：products；动词派生 → produce v. 生产；形容词派生 → productive adj. 多产的；名词派生 → production n. 生产。

### 6. protein /ˈproʊtiːn/ n. 蛋白质
- **词根·渊源**：希腊 **prōteios**（首要的）← *prōtos*（第一）→ 法语 *protéine* → 英语 protein；1838 年由荷兰化学家穆尔德据“生命物质中最重要者”命名，本义“首要的物质”，即“蛋白质”。
- **同根词**：protoplasm（proto 第一 + plasm 浆 = 原生质）、protocol（proto 第一 + col 胶 = 第一层胶→原稿、礼仪）、prototype（proto 第一 + type 型 = 原型）、protozoan（proto 第一 + zo 动物 + **-an** = 原生动物）。
- **前缀·后缀**：前缀 **proto-**（例：prototype, protocol）；名词后缀 **-in** 化学名词（例：insulin, gelatin）。
- **同义·反义**：同义 无；反义 无。
- **变形**：名词 → 复数：proteins；形容词派生 → proteinous adj. 蛋白质的。

### 7. hamburger /ˈhæmbɜːɡə(r)/ n. 汉堡包
- **词根·渊源**：德语 *Hamburg*（汉堡城）+ **-er**（…的人/物）→ 英语 hamburger，本义“汉堡城的（牛肉饼）”；后因 hamburger 被误析为 ham + burger，产生 burger 一词。
- **同根词**：burger（由 hamburger 截短而来→汉堡包）、cheeseburger（cheese 奶酪 + burger = 芝士汉堡）、veggie burger（veggie 蔬菜 + burger = 素汉堡）。
- **前缀·后缀**：名词后缀 **-er**（例：teacher, worker）。
- **同义·反义**：同义 burger（汉堡包）；反义 无。
- **变形**：名词 → 复数：hamburgers。

### 8. cola /ˈkəʊlə/ n. 可乐
- **词根·渊源**：源自西非语言 *kola*（可乐果）→ 英语 cola；因可乐饮料最初用可乐果调味而得名，本义“可乐果”，引申为“可乐饮料”。
- **同根词**：kola（cola 的变体→可乐果）、cola nut（cola + nut 坚果 = 可乐果）。
- **前缀·后缀**：无前后缀（单纯词）。
- **同义·反义**：同义 soda（汽水）；反义 无。
- **变形**：名词 → 复数：colas。

### 9. sandwich /ˈsænwɪtʃ/ v. 三明治
- **词根·渊源**：源自英国贵族 *Sandwich* 伯爵四世（据传为不离开牌桌而用面包夹肉进食）→ 英语 sandwich，本义“桑威奇伯爵式的夹心食物”，引申为“三明治”，动词义“夹在中间”。
- **同根词**：sandwiched（sandwich + **-ed** 被夹住的）、sandwich board（sandwich + board 板 = 夹身广告牌）。
- **前缀·后缀**：无前后缀（专名转化词）。
- **同义·反义**：同义 无；反义 无。
- **变形**：动词 → 第三人称单数：sandwiches；过去式：sandwiched；过去分词：sandwiched；现在分词：sandwiching；名词 → 复数：sandwiches。

### 10. salad /ˈsæləd/ n. 蔬菜沙拉；混合沙拉
- **词根·渊源**：拉丁 **sal**（盐）→ 俗拉丁 *salata*（加盐的）→ 古法语 *salade* → 英语 salad，本义“加盐调味的蔬菜”，引申为“沙拉”。
- **同根词**：salt（sal 盐→盐）、saline（sal 盐 + **-ine** …的→盐的）、salary（sal 盐 + **-ary** 名词后缀 = 买盐钱→薪水）、sauce（sal 盐→调味汁）。
- **前缀·后缀**：名词后缀 **-ad** 源自法语（例：salad, ballad）。
- **同义·反义**：同义 greens（绿叶菜）；反义 无。
- **变形**：名词 → 复数：salads。

### 11. medical /ˈmɛdɪkəl/ adj. 医疗的；医学的
- **词根·渊源**：拉丁 **medicus**（医生）← *mederi*（治疗）→ 拉丁 *medicalis* → 英语 medical，本义“治疗的”，引申为“医疗的、医学的”。
- **同根词**：medicine（med 治疗 + **-icine** 名词后缀→医学、药）、medicate（med 治疗 + **-ate** 动词后缀→用药治疗）、medic（med 治疗 + **-ic** →医生、医学生）、remedy（**re-** 再 + med 治疗 + **-y** = 再治疗→补救、疗法）。
- **前缀·后缀**：形容词后缀 **-al**（例：natural, national）。
- **同义·反义**：同义 medicinal（药用的）, therapeutic（治疗的）；反义 无。
- **变形**：形容词 → 无比较级（关系形容词，不作比较）；副词派生 → medically adv. 医学上；名词派生 → medicine n. 医学。

### 12. fat /fæt/ adj. 脂肪，肥肉
- **词根·渊源**：古英语 *fǣtt*（肥的）→ 中古英语 *fat* → 英语 fat；与古高地德语 *feizit* 同源，本义“肥的”，名词义“脂肪”由形容词转化而来。
- **同根词**：fatty（fat + **-y** …的→脂肪的）、fatten（fat + **-en** 使…→使变肥）、fatness（fat + **-ness** 名词后缀→肥胖）。
- **前缀·后缀**：形容词后缀 **-y**（例：rainy, sunny）；动词后缀 **-en**（例：widen, sharpen）。
- **同义·反义**：同义 plump（丰满的）, obese（肥胖的）；反义 thin（瘦的）, lean（瘦的）。
- **变形**：形容词 → 比较级：fatter；最高级：fattest；名词 → 复数：fats（作“脂肪”义时不可数）；名词派生 → fatness n. 肥胖；动词派生 → fatten v. 使变肥。

### 13. sugar /ˈʃʊɡər/ n. 食糖；糖
- **词根·渊源**：梵语 **śarkarā**（糖粒）→ 阿拉伯语 *sukkar* → 中世纪拉丁 *succarum* → 古法语 *sucre* → 英语 sugar，本义“糖粒”，即“糖”。
- **同根词**：sugary（sugar + **-y** …的→含糖的）、sugarcane（sugar + cane 茎 = 甘蔗）、sugar-free（sugar + free 无…的 = 无糖的）。
- **前缀·后缀**：形容词后缀 **-y**（例：salty, healthy）。
- **同义·反义**：同义 无；反义 无。
- **变形**：名词 → 复数：sugars（作“糖”义时不可数）；形容词派生 → sugary adj. 含糖的。

### 14. state /steɪt/ v. 陈述，说明；规定，公布
- **词根·渊源**：拉丁 **stare**（站立）→ 拉丁 *status*（站立的姿态、状况）→ 古法语 *estat* → 英语 state，本义“站立的状态”，引申为“国家、状态”，动词义“使站定→陈述、规定”。
- **同根词**：station（stat 站 + **-ion** 名词后缀→车站）、statue（stat 站 + **-ue** = 站立之物→雕像）、status（stat 站 + **-us** 名词后缀→地位）、stable（sta 站 + **-ble** 能…的→稳定的）、statistics（stat 站 + **-istics** 学科 = 站着的状况→统计）、constant（**con-** 共同 + sta 站 = 始终站着→不变的）。
- **前缀·后缀**：无前后缀（单纯词）。
- **同义·反义**：同义 declare（宣布）, express（表达）；反义 无。
- **变形**：动词 → 第三人称单数：states；过去式：stated；过去分词：stated；现在分词：stating；名词 → 复数：states；名词派生 → statement n. 陈述。

### 15. necessary /ˈnesəseri/ adj. 必要的,必需的
- **词根·渊源**：拉丁 **necesse**（不可避免的）← *ne-*（不）+ *cedere*（让步）→ 拉丁 *necessarius* → 英语 necessary，本义“不可让步的”，引申为“必要的、必需的”。
- **同根词**：necessity（necess 必要 + **-ity** 名词后缀→必要性）、necessarily（necessary + **-ly** 副词后缀→必然地）、necessitate（necess 必要 + **-itate** 动词后缀→使成为必要）。
- **前缀·后缀**：形容词后缀 **-ary**（例：ordinary, military）。
- **同义·反义**：同义 essential（必要的）, required（必需的）；反义 unnecessary（不必要的）, optional（可选的）。
- **变形**：形容词 → 比较级：more necessary；最高级：most necessary；副词派生 → necessarily adv. 必然地；名词派生 → necessity n. 必要性。

### 16. research /ˈriːsɜːrtʃ/ v. 调查；研究；探索
- **词根·渊源**：古法语 *recercher*（仔细寻找）← **re-**（再）+ **cerchier**（搜寻，源自拉丁 *circare* 绕圈找）→ 英语 research，本义“反复寻找”，引申为“研究、调查”。
- **同根词**：search（cerch 搜寻→搜寻）、circle（circ 圈 + **-le** →圆圈）、circular（circ 圈 + **-ular** …的→圆形的）、circulate（circ 圈 + **-ulate** 动词后缀→循环）。
- **前缀·后缀**：前缀 **re-**（例：repeat, return）。
- **同义·反义**：同义 study（研究）, investigate（调查）；反义 无。
- **变形**：动词 → 第三人称单数：researches；过去式：researched；过去分词：researched；现在分词：researching；名词 → 复数：researches；名词派生 → researcher n. 研究者。

### 17. plenty /ˈplɛnti/ n. 大量；众多；充足
- **词根·渊源**：拉丁 **plenus**（满的）→ 古法语 *plente* → 英语 plenty，本义“满、充足”，引申为“大量、众多”。
- **同根词**：plentiful（plenty + **-ful** …的→充足的）、plenty（同上）、complete（**com-** 完全 + plet 满 = 完全满→完整的）、supply（**sup-** 从下 + ply 满 = 从下填满→供应）、plenary（plen 满 + **-ary** …的→全体的）。
- **前缀·后缀**：名词后缀 **-ty**（例：safety, beauty）。
- **同义·反义**：同义 abundance（丰富）, lots（许多）；反义 scarcity（缺乏）, shortage（短缺）。
- **变形**：名词 → 不可数；形容词派生 → plentiful adj. 充足的；副词派生 → plentifully adv. 充足地。

### 18. usual /ˈjuʒuəl/ adj. 通常的；寻常的
- **词根·渊源**：拉丁 **uti / us-**（使用）→ 拉丁 *usualis* → 古法语 *usuel* → 英语 usual，本义“常用的”，引申为“通常的、寻常的”。
- **同根词**：use（us 使用→使用）、useful（use + **-ful** …的→有用的）、useless（use + **-less** 无…的→无用的）、usage（us 使用 + **-age** 名词后缀→用法）、abuse（**ab-** 偏离 + use 使用 = 偏离使用→滥用）。
- **前缀·后缀**：形容词后缀 **-al**（例：natural, personal）。
- **同义·反义**：同义 common（常见的）, normal（正常的）；反义 unusual（不寻常的）, rare（稀少的）。
- **变形**：形容词 → 比较级：more usual；最高级：most usual；副词派生 → usually adv. 通常地。

### 19. coffee /ˈkɔːfi/ n. 咖啡
- **词根·渊源**：土耳其语 *kahve* → 意大利语 *caffè* → 荷兰语 *koffie* → 英语 coffee；源头可追溯至阿拉伯语 *qahwa*（本指一种酒/饮品），经奥斯曼土耳其传入欧洲；本义即“咖啡（饮品）”，词义基本未变。
- **同根词**：caffeine（coffee 的阿拉伯语源 *qahwa* + 化学后缀 **-ine** 表示生物碱 = 咖啡因）、café（法语借意大利语 *caffè* = 咖啡馆）、cafeteria（西班牙语 *cafetería*，café 咖啡 + **-tería** 场所 = 自助餐厅）。
- **前缀·后缀**：无前后缀（单纯词，借词）。
- **同义·反义**：同义 无；反义 无。
- **变形**：名词 → 复数：coffees（作“咖啡饮品”义可数，作“咖啡豆/咖啡粉”义不可数）；形容词派生 → coffee n. 作定语（如 coffee cup 咖啡杯，无形态变化）。

### 20. treat /triːt/ v. 买（可享受的东西）
- **词根·渊源**：拉丁 *tractare*（拉、拖、处理）→ 古法语 *traitier*（处理、对待）→ 英语 treat；本义“处理、对待”，引申为“招待、请客”，再引申为“买（可享受的东西）请客”。
- **同根词**：treatment（treat + **-ment** 名词后缀 = 对待→治疗）、treaty（treat + **-y** 名词后缀 = 处理→条约）、retreat（**re-** 回 + treat 拉 = 拉回→撤退）、tractable（tract 拉 + **-able** 能…的 = 易处理的→温顺的）、entreat（**en-** 使 + treat 处理 = 恳求）。
- **前缀·后缀**：前缀 **re-**（例：return, recall）、**en-**（例：enable, enjoy）；名词后缀 **-ment**（例：movement, development）、**-y**（例：discovery, delivery）。
- **同义·反义**：同义 entertain（招待）, regale（款待）；反义 无。
- **变形**：动词 → 第三人称单数：treats；过去式：treated；过去分词：treated；现在分词：treating；名词派生 → treatment n. 对待、治疗；treat n. 款待、乐事。

### 21. customer /ˈkʌstəmər/ n. 顾客，客户，消费者
- **词根·渊源**：拉丁 *consuetudo*（习惯）→ 古法语 *costume*（习俗）→ 英语 custom（习惯、惯例）→ customer；本义“习惯于某店铺的人”，引申为“顾客、客户”。
- **同根词**：custom（custom 习惯 = 习俗、惯例）、customary（custom + **-ary** …的 = 习惯的、惯常的）、accustom（**ac-** 使 + custom 习惯 = 使习惯）、customize（custom + **-ize** 使…化 = 定制）。
- **前缀·后缀**：前缀 **ac-**（例：accept, acquire）；名词后缀 **-er**（例：teacher, worker）、**-ary**（例：ordinary, necessary）、**-ize**（例：realize, organize）。
- **同义·反义**：同义 client（客户）, consumer（消费者）；反义 seller（卖家）, vendor（商贩）。
- **变形**：名词 → 复数：customers；形容词派生 → customer n. 作定语（customer service 客户服务，无形态变化）。

### 22. title /ˈtaɪtl/ n. 名称，标题；题目
- **词根·渊源**：拉丁 *titulus*（铭文、标签、头衔）→ 古法语 *title* → 英语 title；本义“刻写的标记/铭文”，引申为“标题、名称、头衔”。
- **同根词**：entitle（**en-** 使 + title 标题 = 给…题名→使有权）、titled（title + **-ed** 有…的 = 有头衔的）、titular（title 的拉丁词根 titul- + **-ar** …的 = 名义上的）。
- **前缀·后缀**：前缀 **en-**（例：enable, enclose）；形容词后缀 **-ed**（例：talented, gifted）、**-ar**（例：similar, familiar）。
- **同义·反义**：同义 heading（标题）, name（名称）；反义 无。
- **变形**：名词 → 复数：titles；动词派生 → entitle v. 给…题名、使有权；形容词派生 → titled adj. 有头衔的。

### 23. serve /sɜːrv/ v. 供应；提供
- **词根·渊源**：拉丁 *servire*（服务、服侍）→ 古法语 *servir* → 英语 serve；本义“服侍、服务”，引申为“供应、提供（食物等）”。
- **同根词**：service（serv 服务 + **-ice** 名词后缀 = 服务）、servant（serv 服务 + **-ant** 人 = 仆人）、deserve（**de-** 加强 + serve 服务 = 应得、值得）、preserve（**pre-** 预先 + serve 保护 = 保存）、reserve（**re-** 回 + serve 保存 = 保留）。
- **前缀·后缀**：前缀 **de-**（例：demand, depend）、**pre-**（例：preview, prepare）、**re-**（例：return, recall）；名词后缀 **-ice**（例：notice, justice）、**-ant**（例：assistant, applicant）。
- **同义·反义**：同义 supply（供应）, provide（提供）；反义 无。
- **变形**：动词 → 第三人称单数：serves；过去式：served；过去分词：served；现在分词：serving；名词派生 → service n. 服务；servant n. 仆人。

### 24. pound /paʊnd/ n. 英镑
- **词根·渊源**：拉丁 *pondo*（重量、磅）→ 古英语 *pund* → 英语 pound；本义“重量单位磅”，因英镑原按一磅白银计值，引申为“英镑”。
- **同根词**：poundage（pound 磅 + **-age** 名词后缀 = 按磅计的重量/费用）、poundal（pound 磅 + **-al** 名词后缀 = 磅达，力的单位）。
- **前缀·后缀**：名词后缀 **-age**（例：marriage, package）、**-al**（例：arrival, proposal）。
- **同义·反义**：同义 无；反义 无。
- **变形**：名词 → 复数：pounds（作货币单位复数常不变，如 ten pound）；动词派生 → pound v. 猛击、捣碎（同形异源，存疑）。

### 25. pie /paɪ/ n. 馅饼；派；果馅饼；果馅派
- **词根·渊源**：中世纪英语 *pie*，可能源自古法语 *pie*（喜鹊），因馅饼杂集多种馅料如喜鹊杂色羽毛；词源存疑；本义即“馅饼”，词义基本未变。
- **同根词**：无常用同根词。
- **前缀·后缀**：无前后缀（单纯词）。
- **同义·反义**：同义 tart（果馅饼）, pastry（糕点）；反义 无。
- **变形**：名词 → 复数：pies；形容词派生 → pie n. 作定语（如 pie crust 馅饼皮，无形态变化）。

### 26. chip /tʃɪp/ n. 炸土豆条；炸薯条
- **词根·渊源**：古英语 *cipp*（木片、碎片）→ 中世纪英语 *chip* → 英语 chip；本义“碎片”，因炸土豆条呈片/条状，引申为“炸薯条”。
- **同根词**：chipboard（chip 碎片 + board 板 = 刨花板）、chipper（chip + **-er** 使…者 = 使成碎片→削片机；另义“活泼的”）。
- **前缀·后缀**：名词后缀 **-er**（例：teacher, worker）。
- **同义·反义**：同义 fries（炸薯条）, crisp（炸薯片）；反义 无。
- **变形**：名词 → 复数：chips；动词派生 → chip v. 削、凿（碎片）；chipper adj. 活泼的。

### 27. service /ˈsɜːrvɪs/ n. 接待，服务
- **词根·渊源**：拉丁 *servitium*（奴役、服务）→ 古法语 *servise* → 英语 service；本义“服侍、服务”，引申为“接待、服务”。
- **同根词**：serve（serv 服务 + **-e** 动词 = 服务）、servant（serv 服务 + **-ant** 人 = 仆人）、servile（serv 服务 + **-ile** …的 = 奴性的）、deserve（**de-** 加强 + serve 服务 = 应得）、preserve（**pre-** 预先 + serve 保护 = 保存）。
- **前缀·后缀**：前缀 **de-**（例：demand, depend）、**pre-**（例：preview, prepare）；名词后缀 **-ice**（例：notice, justice）、**-ant**（例：assistant, applicant）、**-ile**（例：fragile, mobile）。
- **同义·反义**：同义 assistance（帮助）, attendance（接待）；反义 无。
- **变形**：名词 → 复数：services；动词派生 → service v. 维修、保养；形容词派生 → serviceable adj. 可用的。

### 28. seat /siːt/ n. 使就座
- **词根·渊源**：古诺斯语 *sæti*（座位）→ 古英语 *set* → 英语 seat；与 sit 同出 PIE *sed-*（坐）；本义“座位”，动词义“使就座”由名词转化而来。
- **同根词**：sit（PIE *sed-* 坐 = 坐）、settle（set 坐 + **-le** 反复后缀 = 安坐→定居）、session（拉丁 *sedere* 坐 + **-ion** 名词后缀 = 会议）、sediment（拉丁 *sedere* 坐 + **-ment** 名词后缀 = 沉淀物）。
- **前缀·后缀**：动词后缀 **-le**（例：handle, sparkle）；名词后缀 **-ion**（例：action, decision）、**-ment**（例：movement, development）。
- **同义·反义**：同义 chair（椅子）, place（座位）；反义 无。
- **变形**：名词 → 复数：seats；动词 → 第三人称单数：seats；过去式：seated；过去分词：seated；现在分词：seating；名词派生 → seating n. 座位安排。
