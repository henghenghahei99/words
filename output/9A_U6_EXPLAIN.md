## 二、逐词说文解字

### 1. boil /bɔɪl/ v. 用沸水煮(或烫洗)
- **词根·渊源**：拉丁 **bullire**（冒泡、沸腾）→ 古法语 *boillir* → 英语 *boil*；本义“冒气泡”引申为“用沸水煮”。
- **同根词**：boiler（boil + **-er** 表物 = 煮东西的器具→锅炉）、boiling（boil + **-ing** 表进行 = 沸腾的）、bubble（与 bullire 同源，拟声词根 = 气泡）。
- **前缀·后缀**：动词后缀 **-er** 构成名词表工具（例：cooker, mixer）；**-ing** 构成形容词（例：freezing, interesting）。
- **同义·反义**：同义 simmer（炖煮）, cook（煮）；反义 freeze（冷冻）, chill（冷却）。
- **变形**：动词 → 第三人称单数：boils；过去式：boiled；过去分词：boiled；现在分词：boiling；名词派生 → boiler n. 锅炉；形容词派生 → boiling adj. 沸腾的。

### 2. biscuit /ˈbɪskət/ n. 饼干
- **词根·渊源**：拉丁 **bis**（两次）+ **coctus**（煮熟的）→ 古法语 *bescuit* → 英语 *biscuit*；本义“烤两次的面包”，因古代饼干需二次烘烤以脱水保存，引申为“饼干”。
- **同根词**：cook（与 coctus 同源，拉丁 coquere 煮→烹饪）、kitchen（与 coquere 同源，拉丁 coquina 厨房→厨房）、biscotti（意大利语 bis + cotti = 烤两次的→意式脆饼）。
- **前缀·后缀**：前缀 **bis-**（两次，例：bisect, bilingual）；无后缀（单纯词）。
- **同义·反义**：同义 cookie（曲奇饼干）, cracker（薄脆饼干）；反义 无。
- **变形**：名词 → 复数：biscuits；形容词派生 → biscuity adj. 饼干似的。

### 3. score /skɔr/ n. 分数;得分
- **词根·渊源**：古诺斯语 **skor**（刻痕、切口）→ 中古英语 *score*；本义“刻痕”，古时用刻痕计数，引申为“得分、分数”。
- **同根词**：scoring（score + **-ing** 表动作 = 得分）、underscore（**under-** 在下 + score 刻 = 在下面划线→强调）、shore（与 skor 同源，古英语 *scora* 岸→海岸）。
- **前缀·后缀**：前缀 **under-**（在下，例：underline, underground）；无后缀（单纯词）。
- **同义·反义**：同义 points（分数）, mark（分数）；反义 无。
- **变形**：名词 → 复数：scores；动词派生 → score v. 得分；scorer n. 得分者；动词 → 第三人称单数：scores；过去式：scored；过去分词：scored；现在分词：scoring。

### 4. tofu /ˈtoʊfu/ n. 豆腐
- **词根·渊源**：汉语 **豆腐**（dòufu）→ 日语 *tōfu* → 英语 *tofu*；本义即“豆腐”，为汉语借词。
- **同根词**：bean curd（同义复合词，bean 豆 + curd 凝乳 = 豆腐）、soy（与豆腐同源文化词，日语 shōyu 酱油→大豆）。
- **前缀·后缀**：无前后缀（单纯词，外来借词）。
- **同义·反义**：同义 bean curd（豆腐）；反义 无。
- **变形**：名词 → 复数：tofus（作“豆腐”义时不可数）；形容词派生 → tofu-like adj. 豆腐般的。

### 5. stuff /stəf/ n. 东西
- **词根·渊源**：古法语 **estoffe**（材料、填充物）→ 中古英语 *stuff*；本义“填塞的材料”，引申为“东西、物品”。
- **同根词**：stuffing（stuff + **-ing** 表材料 = 填充物→馅料）、stuffy（stuff + **-y** …的 = 塞满的→闷热的）、overstuff（**over-** 过度 + stuff = 过度填塞）。
- **前缀·后缀**：前缀 **over-**（过度，例：overeat, overwork）；后缀 **-ing**（例：building, clothing）、**-y**（例：rainy, dirty）。
- **同义·反义**：同义 things（东西）, items（物品）；反义 无。
- **变形**：名词 → 复数：stuffs（作“东西”义时不可数）；动词派生 → stuff v. 填塞；stuffy adj. 闷热的；动词 → 第三人称单数：stuffs；过去式：stuffed；过去分词：stuffed；现在分词：stuffing。

### 6. overweight /ˌoʊvərˈweɪt/ adj. 超重的
- **词根·渊源**：**over-**（超过）+ **weight**（重量，古英语 *gewiht* 称重）→ 英语 *overweight*；本义“超过正常重量”，引申为“超重的”。
- **同根词**：weight（weigh 称 + **-t** 名词后缀 = 重量）、weigh（古英语 *wegan* 举起→称重）、underweight（**under-** 不足 + weight = 体重不足的）。
- **前缀·后缀**：前缀 **over-**（超过，例：overeat, overwork）、**under-**（不足，例：underweight, undercooked）；无后缀（复合词）。
- **同义·反义**：同义 fat（肥胖的）, heavy（重的）；反义 underweight（体重不足的）, thin（瘦的）。
- **变形**：形容词 → 无比较级（关系形容词，不作比较）；名词派生 → overweight n. 超重。

### 7. sugary /ˈʃʊgəri/ adj. 含糖的
- **词根·渊源**：梵语 **śarkarā**（糖粒）→ 阿拉伯语 *sukkar* → 拉丁 *succarum* → 古法语 *sucre* → 英语 *sugar* + **-y**；本义“糖的”，引申为“含糖的”。
- **同根词**：sugar（源自阿拉伯语 sukkar = 糖）、sugared（sugar + **-ed** 加糖的）、saccharine（拉丁 saccharum 糖 + **-ine** …的 = 糖精的）。
- **前缀·后缀**：形容词后缀 **-y**（例：rainy, salty）；**-ed**（例：salted, sugared）。
- **同义·反义**：同义 sweet（甜的）, sweetened（加糖的）；反义 sugar-free（无糖的）, unsweetened（未加糖的）。
- **变形**：形容词 → 比较级：sugarier；最高级：sugariest；名词派生 → sugariness n. 甜度。

### 8. menu /ˈmɛnju/ n. 菜单
- **词根·渊源**：拉丁 **minutus**（小的）→ 法语 *menu*（细小的、详细的）→ 英语 *menu*；本义“详细清单”，引申为“菜单”。
- **同根词**：minute（与 minutus 同源，拉丁 minutus 小的→分钟、微小的）、minimum（拉丁 minimus 最小 + **-um** = 最小值）、minor（拉丁 minor 较小的→次要的）。
- **前缀·后缀**：无前后缀（单纯词，法语借词）。
- **同义·反义**：同义 list（清单）, bill of fare（菜单）；反义 无。
- **变形**：名词 → 复数：menus。

### 9. cucumber /ˈkjukəmbər/ n. 黄瓜
- **词根·渊源**：拉丁 **cucumis**（黄瓜）→ 古法语 *coucombre* → 英语 *cucumber*；本义即“黄瓜”，词源存疑（一说与 cucumis 同源）。
- **同根词**：cucumiform（拉丁 cucumis 黄瓜 + **-form** 形状 = 黄瓜形的）、cucurbit（拉丁 cucurbita 葫芦 = 葫芦科植物）。
- **前缀·后缀**：无前后缀（单纯词）。
- **同义·反义**：同义 gherkin（小黄瓜）；反义 无。
- **变形**：名词 → 复数：cucumbers。

### 10. carrot /ˈkɛrət/ n. 胡萝卜
- **词根·渊源**：希腊 **karōton**（胡萝卜）→ 拉丁 *carota* → 古法语 *carotte* → 英语 *carrot*；本义即“胡萝卜”。
- **同根词**：carotene（拉丁 carota 胡萝卜 + **-ene** 化学名词后缀 = 胡萝卜素）、carroty（carrot + **-y** …的 = 胡萝卜色的）。
- **前缀·后缀**：化学后缀 **-ene**（例：benzene, toluene）；形容词后缀 **-y**（例：salty, rainy）。
- **同义·反义**：同义 无；反义 无。
- **变形**：名词 → 复数：carrots；形容词派生 → carroty adj. 胡萝卜色的。

### 11. cabbage /ˈkæbɪʤ/ n. 甘蓝;卷心菜
- **词根·渊源**：拉丁 **caput**（头）→ 古法语 *caboche*（头）→ *caboche* 变体 *cabbage*；本义“头状的菜”，因卷心菜呈头状，引申为“甘蓝、卷心菜”。
- **同根词**：capital（拉丁 caput 头 + **-al** …的 = 头等的→首都、资本）、captain（拉丁 caput 头 + **-ain** 人 = 首领→船长）、decapitate（**de-** 去除 + caput 头 + **-ate** 动词后缀 = 斩首）。
- **前缀·后缀**：前缀 **de-**（去除，例：decrease, defrost）；后缀 **-al**（例：natural, musical）、**-ate**（例：activate, educate）。
- **同义·反义**：同义 cole（油菜类）, kale（羽衣甘蓝）；反义 无。
- **变形**：名词 → 复数：cabbages。

### 12. preference /ˈprɛfərəns/ n. 偏爱;爱好
- **词根·渊源**：拉丁 **prae-**（在前）+ **ferre**（拿、带）→ 拉丁 *praeferre*（放在前面）→ 古法语 *preferer* → 英语 *prefer* + **-ence**；本义“放在前面”，引申为“偏爱”。
- **同根词**：prefer（**pre-** 在前 + fer 拿 = 放在前面→更喜欢）、refer（**re-** 回 + fer 拿 = 拿回→提及、参考）、transfer（**trans-** 横过 + fer 拿 = 拿过去→转移）、offer（**of-** 向 + fer 拿 = 拿向→提供）、conference（**con-** 共同 + fer 拿 + **-ence** = 拿到一起→会议）。
- **前缀·后缀**：前缀 **pre-**（在前，例：preview, predict）、**re-**（回，例：return, recall）、**trans-**（横过，例：transport, translate）；名词后缀 **-ence**（例：difference, silence）。
- **同义·反义**：同义 liking（喜爱）, fondness（爱好）；反义 dislike（厌恶）, aversion（反感）。
- **变形**：名词 → 复数：preferences；动词派生 → prefer v. 更喜欢；形容词派生 → preferential adj. 优先的。

### 13. waiter /ˈweɪtər/ n. 服务员
- **词根·渊源**：古法语 **waitier**（看守、注意）→ 英语 *wait* + **-er**；本义“看守者、等候者”，因服务员在桌旁等候服务，引申为“服务员”。
- **同根词**：wait（古法语 waitier 看守→等待）、waitress（wait + **-ress** 女性后缀 = 女服务员）、await（**a-** 加强 + wait 等待 = 等候）。
- **前缀·后缀**：前缀 **a-**（加强，例：arise, awake）；名词后缀 **-er**（例：teacher, worker）、**-ress**（例：actress, hostess）。
- **同义·反义**：同义 server（服务员）, attendant（侍者）；反义 无。
- **变形**：名词 → 复数：waiters；动词派生 → wait v. 等待；waitress n. 女服务员。

### 14. sweat /swɛt/ n. 汗水
- **词根·渊源**：古英语 **swāt**（汗）→ 中古英语 *swet* → 英语 *sweat*；本义即“汗水”，与德语 *Schweiß* 同源。
- **同根词**：sweaty（sweat + **-y** …的 = 出汗的）、sweater（sweat + **-er** 表物 = 使人出汗的衣物→毛衣）、sweatband（sweat + band 带 = 吸汗带）。
- **前缀·后缀**：形容词后缀 **-y**（例：rainy, dirty）；名词后缀 **-er**（例：cooker, mixer）。
- **同义·反义**：同义 perspiration（汗水）；反义 无。
- **变形**：名词 → 复数：sweats（作“汗水”义时不可数）；动词派生 → sweat v. 出汗；sweaty adj. 出汗的；动词 → 第三人称单数：sweats；过去式：sweated；过去分词：sweated；现在分词：sweating。

### 15. soil /sɔɪl/ n. 土壤
- **词根·渊源**：拉丁 **solum**（土地、基底）→ 古法语 *soil* → 英语 *soil*；本义“地面、土地”，引申为“土壤”。
- **同根词**：subsoil（**sub-** 在下 + soil = 底土）、topsoil（top 顶 + soil = 表土）、solum（拉丁 solum 土地 = 土层）。
- **前缀·后缀**：前缀 **sub-**（在下，例：subway, submarine）；无后缀（单纯词）。
- **同义·反义**：同义 earth（泥土）, dirt（泥土）；反义 无。
- **变形**：名词 → 复数：soils（作“土壤”义时不可数）；动词派生 → soil v. 弄脏。

### 16. welcoming /ˈwɛlkəmɪŋ/ adj. 令人感到惬意的
- **词根·渊源**：古英语 **wilcuma**（受欢迎的客人）→ 中古英语 *welcomen* → 英语 *welcome* + **-ing**；本义“受欢迎的”，引申为“令人感到惬意的”。
- **同根词**：welcome（古英语 wilcuma = 意愿 + 客人→欢迎）、welcomer（welcome + **-er** 人 = 欢迎者）、unwelcoming（**un-** 不 + welcoming = 不热情的）。
- **前缀·后缀**：前缀 **un-**（不，例：unhappy, unfair）；形容词后缀 **-ing**（例：interesting, boring）。
- **同义·反义**：同义 hospitable（好客的）, friendly（友好的）；反义 unwelcoming（不热情的）, hostile（敌对的）。
- **变形**：形容词 → 比较级：more welcoming；最高级：most welcoming；名词派生 → welcomingness n. 热情。

### 17. gentle /ˈʤɛnəl/ adj. 温和的
- **词根·渊源**：拉丁 **gentilis**（同族的、出身好的）→ 古法语 *gentil* → 英语 *gentle*；本义“出身高贵的”，引申为“温和的、文雅的”。
- **同根词**：gently（gentle + **-ly** 副词后缀 = 温和地）、gentleman（gentle + man 人 = 绅士）、gentry（gentle + **-ry** 集合名词 = 绅士阶层）、genuine（与 gentilis 同源，拉丁 genuinus 天生的→真正的）。
- **前缀·后缀**：副词后缀 **-ly**（例：quickly, happily）；集合名词后缀 **-ry**（例：bakery, jewelry）。
- **同义·反义**：同义 mild（温和的）, kind（和善的）；反义 rough（粗鲁的）, harsh（严厉的）。
- **变形**：形容词 → 比较级：gentler；最高级：gentlest；副词派生 → gently adv. 温和地；名词派生 → gentleness n. 温和。

### 18. whisper /ˈwɪspər/ v. 低语;私语
- **词根·渊源**：古英语 **hwisprian**（低语，拟声词）→ 中古英语 *whisperen* → 英语 *whisper*；本义“发出沙沙声”，引申为“低语、私语”。
- **同根词**：whispering（whisper + **-ing** 表进行 = 低语的）、whisperer（whisper + **-er** 人 = 低语者）、whist（拟声词根，与 whisper 同源 = 嘘声）。
- **前缀·后缀**：名词后缀 **-er**（例：teacher, worker）；形容词后缀 **-ing**（例：interesting, boring）。
- **同义·反义**：同义 murmur（低语）, mutter（嘟囔）；反义 shout（喊叫）, yell（大叫）。
- **变形**：动词 → 第三人称单数：whispers；过去式：whispered；过去分词：whispered；现在分词：whispering；名词派生 → whisper n. 低语；whisperer n. 低语者。

### 19. tend /tɛnd/ v. 照料;照管
- **词根·渊源**：拉丁 **tendere**（伸展、拉紧）→ 古法语 *tendre* → 英语 tend；本义“把注意力伸向某处”，引申为“照管、照料”（另一义“倾向”同源）。
- **同根词**：extend（**ex-** 向外 + tend 伸展 = 向外伸→延伸）、intend（**in-** 向内 + tend 伸 = 心思伸向→打算）、pretend（**pre-** 在前 + tend 伸 = 在前面张开→假装）、tension（tens 拉紧 + **-ion** 名词后缀 = 拉紧→紧张）、attention（**at-** 向 + tent 伸 + **-ion** = 心思伸向→注意）、tent（tend 的变体，伸展之物→帐篷）。
- **前缀·后缀**：前缀 **ex-**（例：export, exit）、**in-**（例：inside, import）；名词后缀 **-ion**（例：action, station）。
- **同义·反义**：同义 care for（照顾）, look after（照看）；反义 neglect（忽视）, ignore（不理睬）。
- **变形**：动词 → 第三人称单数：tends；过去式：tended；过去分词：tended；现在分词：tending；名词派生 → tendency n. 倾向；形容词派生 → tender adj. 温柔的（存疑，一说同源）。
