## 二、逐词说文解字

### 1. possible /ˈpɒsəbl/ adj. 可能
- **词根·渊源**：拉丁 **posse / poss-**（能够）→ 拉丁 *possibilis*（能够做到的）→ 古法语 *possible* → 英语，本义“有能力做到的”引申为“可能的”。
- **同根词**：impossible（**im-** 不 + possible 可能的 = 不可能的）、possibility（possible + **-ity** 名词后缀 = 可能性）、potent（拉丁 pot- 能够 + **-ent** …的 = 有能力的→强有力的）、power（古法语 poeir 能够 → 能力→力量）、potentate（potent 有权势的 + **-ate** 人 = 有权势者→君主）。
- **前缀·后缀**：形容词后缀 **-ible**（例：visible, flexible）；否定前缀 **im-**（例：impossible, impolite）。
- **同义·反义**：同义 likely（可能的）, probable（很可能的）；反义 impossible（不可能的）, unlikely（不太可能的）。
- **变形**：形容词 → 比较级：more possible；最高级：most possible；名词派生 → possibility n. 可能性；副词派生 → possibly adv. 可能地。

### 2. athlete /ˈæθliːt/ n. 运动员
- **词根·渊源**：希腊 **athlon**（奖品、竞赛）→ 希腊 *athlētēs*（为奖品而竞争的人）→ 拉丁 *athleta* → 英语，本义“争夺奖品者”引申为“运动员”。
- **同根词**：athletic（athlete + **-ic** …的 = 运动的、健壮的）、athletics（athletic + **-s** 名词化 = 体育运动）、athletically（athletic + **-ally** 副词后缀 = 运动地）、athleticism（athletic + **-ism** 主义、特性 = 运动能力）。
- **前缀·后缀**：名词后缀 **-lete**（例：athlete 本身；同类 -ete 如 complete 中的 -ete 不属此列，存疑）；形容词后缀 **-ic**（例：basic, historic）。
- **同义·反义**：同义 sportsman（运动员）, player（选手）；反义 无。
- **变形**：名词 → 复数：athletes；形容词派生 → athletic adj. 运动的；名词派生 → athletics n. 体育运动。

### 3. biologist /baɪˈɒlədʒɪst/ n. 生物学家
- **词根·渊源**：希腊 **bios**（生命）+ **logia**（研究、学问）→ 法语 *biologie* → 英语 biology，加 **-ist**（从事…的人）构成 biologist，本义“研究生命的人”。
- **同根词**：biology（bio 生命 + **-logy** 学科 = 生物学）、biological（biology + **-ical** …的 = 生物学的）、biography（bio 生命 + graph 写 = 写生平→传记）、antibiotic（**anti-** 反 + bio 生命 + **-tic** …的 = 抗生的→抗生素）、biosphere（bio 生命 + sphere 球 = 生命圈→生物圈）。
- **前缀·后缀**：名词后缀 **-ist**（例：artist, scientist）；组合成分 **bio-**（例：biochemistry, biodiversity）。
- **同义·反义**：同义 life scientist（生命科学家）；反义 无。
- **变形**：名词 → 复数：biologists；形容词派生 → biological adj. 生物学的；副词派生 → biologically adv. 生物学上。

### 4. instrument /ˈɪnstrəmənt/ n. 乐器；仪器
- **词根·渊源**：拉丁 **instruere**（建造、装备）→ 拉丁 *instrumentum*（工具、设备）→ 古法语 *instrument* → 英语，本义“工具、器具”引申为“仪器”，再指“演奏器具→乐器”。
- **同根词**：instrumental（instrument + **-al** …的 = 仪器的；乐器的→起作用的）、instrumentation（instrument + **-ation** 名词后缀 = 仪器装备）、instruct（**in-** 在内 + struct 建造 = 在内心建造→教导）、instructor（instruct + **-or** 人 = 教导者→教师）、construct（**con-** 共同 + struct 建造 = 共同建造→建造）。
- **前缀·后缀**：名词后缀 **-ment**（例：movement, government）；形容词后缀 **-al**（例：natural, musical）。
- **同义·反义**：同义 tool（工具）, device（装置）；反义 无。
- **变形**：名词 → 复数：instruments；形容词派生 → instrumental adj. 乐器的；起作用的。

### 5. interest /ˈɪntrəst/ n. 兴趣；业余爱好
- **词根·渊源**：拉丁 **interesse**（在…之间；有关系、重要）→ 古法语 *interest* → 英语，本义“介于其间→有关系、重要”，引申为“关心的事→兴趣”。
- **同根词**：interesting（interest + **-ing** …的 = 有趣的）、interested（interest + **-ed** 感到…的 = 感兴趣的）、disinterested（**dis-** 不 + interested 有私利的 = 无私的→不偏不倚的）、uninteresting（**un-** 不 + interesting 有趣的 = 无趣的）。
- **前缀·后缀**：前缀 **inter-**（例：international, interact）；名词后缀 **-est**（例：interest 本身，存疑）。
- **同义·反义**：同义 curiosity（好奇心）, hobby（爱好）；反义 boredom（无聊）, indifference（冷漠）。
- **变形**：名词 → 复数：interests；动词派生 → interest v. 使感兴趣；形容词派生 → interesting adj. 有趣的；interested adj. 感兴趣的；副词派生 → interestingly adv. 有趣地。

### 6. career /kəˈrɪə(r)/ n. 生涯；职业
- **词根·渊源**：拉丁 **carrus**（车）→ 拉丁 *carraria*（车道）→ 法语 *carrière*（跑道、道路）→ 英语，本义“跑道、道路”引申为“人生道路→生涯、职业”。
- **同根词**：car（拉丁 carrus 车 → 汽车）、carry（古法语 carier 用车运 → 运送）、cargo（西班牙语 cargar 装载 ← 拉丁 carricare 装车 = 货物）、carriage（carry + **-age** 名词后缀 = 运载→马车）、cart（古英语 cræt 车 → 手推车）。
- **前缀·后缀**：名词后缀 **-eer**（例：engineer, volunteer）。
- **同义·反义**：同义 profession（职业）, occupation（职业）；反义 无。
- **变形**：名词 → 复数：careers；形容词派生 → career adj. 职业的（作定语）。

### 7. lifetime /ˈlaɪftaɪm/ n. 一生；终身
- **词根·渊源**：古英语 **līf**（生命）+ **tīma**（时间）→ 合成词 lifetime，本义“生命的时间”即“一生”。
- **同根词**：life（古英语 lif 生命 → 生命）、lifelong（life + long 长 = 终身的）、lifelike（life + like 像 = 栩栩如生的）、lifestyle（life + style 方式 = 生活方式）、time（古英语 tima 时间 → 时间）。
- **前缀·后缀**：无前后缀（复合词：life + time）。
- **同义·反义**：同义 lifespan（寿命）, whole life（一生）；反义 无。
- **变形**：名词 → 复数：lifetimes；形容词派生 → lifetime adj. 终身的（作定语）。

### 8. diamond /ˈdaɪəmənd/ n. 钻石
- **词根·渊源**：希腊 **adamas**（不可征服的、坚硬的）→ 拉丁 *adamans* → 古法语 *diamant* → 英语，本义“坚硬无比之物”引申为“钻石”。
- **同根词**：adamant（希腊 adamas 坚硬 → 坚硬的→坚决的）、adamantine（adamant + **-ine** …的 = 坚硬如钻石的）。
- **前缀·后缀**：无前后缀（单纯词，源自外来词）。
- **同义·反义**：同义 gem（宝石）, jewel（珠宝）；反义 无。
- **变形**：名词 → 复数：diamonds；形容词派生 → diamond adj. 钻石的（作定语）。

### 9. belt /bɛlt/ n. 腰带
- **词根·渊源**：古英语 **belt** ← 拉丁 **balteus**（腰带、束带），本义“束带”即“腰带”。
- **同根词**：belted（belt + **-ed** 有…的 = 系腰带的）、beltless（belt + **-less** 无…的 = 无腰带的）、beltway（belt + way 路 = 环城路）。
- **前缀·后缀**：名词后缀 **-ed**（例：belted, bearded）；否定后缀 **-less**（例：careless, hopeless）。
- **同义·反义**：同义 strap（带子）, sash（腰带）；反义 无。
- **变形**：名词 → 复数：belts；动词派生 → belt v. 用带系；形容词派生 → belted adj. 系腰带的。

### 10. shoot /ʃuːt/ v. 冲；奔；飞驰
- **词根·渊源**：古英语 **scēotan**（射出、投掷）→ 中古英语 *shoten* → 英语，本义“射出”引申为“快速冲出→冲、奔、飞驰”。
- **同根词**：shot（shoot 的过去分词 → 射击→发射）、shooter（shoot + **-er** 人 = 射手）、shooting（shoot + **-ing** 名词后缀 = 射击）、shootout（shoot + out 出 = 枪战）、shuttle（古英语 scytel 飞镖 ← 同源 = 穿梭）。
- **前缀·后缀**：名词后缀 **-er**（例：teacher, worker）；动名词后缀 **-ing**（例：running, swimming）。
- **同义·反义**：同义 dash（猛冲）, rush（冲）；反义 crawl（爬行）, creep（缓慢移动）。
- **变形**：动词 → 第三人称单数：shoots；过去式：shot；过去分词：shot；现在分词：shooting；名词派生 → shooter n. 射手；shooting n. 射击。

### 11. extremely /ɪkˈstriːmli/ adv. 极其；极端；非常
- **词根·渊源**：拉丁 **extremus**（最外面的、极端的，ex- 出 + -ter 比较级后缀）→ 古法语 *extreme* → 英语 extreme，加 **-ly** 构成副词，本义“极端地”。
- **同根词**：extreme（拉丁 extremus 最外的 → 极端的）、extremity（extreme + **-ity** 名词后缀 = 极端→末端）、extremist（extreme + **-ist** 人 = 极端主义者）、extremism（extreme + **-ism** 主义 = 极端主义）。
- **前缀·后缀**：副词后缀 **-ly**（例：quickly, happily）；前缀 **ex-**（例：export, exit）。
- **同义·反义**：同义 very（非常）, highly（高度地）；反义 slightly（稍微）, mildly（轻微地）。
- **变形**：副词 → 比较级：more extremely；最高级：most extremely；形容词派生 → extreme adj. 极端的；名词派生 → extremity n. 极端。

### 12. curious /ˈkjʊəriəs/ adj. 求知欲强的；好奇的
- **词根·渊源**：拉丁 **cura**（关心、注意）→ 拉丁 *curiosus*（细心的、想知道的）→ 古法语 *curius* → 英语，本义“用心关注的”引申为“好奇的”。
- **同根词**：curiosity（curious + **-ity** 名词后缀 = 好奇心）、curiously（curious + **-ly** 副词后缀 = 好奇地）、cure（拉丁 cura 关心 → 治疗→治愈）、accurate（**ac-** 加强 + cur 关心 + **-ate** …的 = 精心做的→准确的）、secure（**se-** 分开 + cur 关心 = 无忧的→安全的）。
- **前缀·后缀**：形容词后缀 **-ous**（例：famous, dangerous）；名词后缀 **-ity**（例：activity, ability）。
- **同义·反义**：同义 inquisitive（好问的）, interested（感兴趣的）；反义 indifferent（漠不关心的）, uninterested（不感兴趣的）。
- **变形**：形容词 → 比较级：more curious；最高级：most curious；名词派生 → curiosity n. 好奇心；副词派生 → curiously adv. 好奇地。

### 13. increase /ɪnˈkriːs/ v. 增长；增多；增加
- **词根·渊源**：拉丁 **crescere**（生长）→ 拉丁 *increscere*（在内生长）→ 古法语 *encreistre* → 英语，本义“向上生长”引申为“增长、增加”。
- **同根词**：decrease（**de-** 向下 + crease 生长 = 向下长→减少）、crescent（拉丁 crescere 生长 + **-ent** …的 = 生长的→新月）、concrete（**con-** 共同 + cret 生长 = 一起长成→具体的）、recruit（**re-** 再 + cru 生长 = 再生长→招募新兵）、increase 本身名词（in- + crease = 增长）。
- **前缀·后缀**：前缀 **in-**（例：include, indoor）；词根 **cresc-/cret-**（例：crescent, concrete）。
- **同义·反义**：同义 grow（增长）, rise（上升）；反义 decrease（减少）, reduce（降低）。
- **变形**：动词 → 第三人称单数：increases；过去式：increased；过去分词：increased；现在分词：increasing；名词派生 → increase n. 增长；形容词派生 → increasing adj. 增长的；副词派生 → increasingly adv. 越来越。

### 14. host /həʊst/ v. 主持
- **词根·渊源**：拉丁 **hospes / hospit-**（主人、客人）→ 古法语 *hoste* → 英语，本义“主人”引申为“做主人→主持”。
- **同根词**：hostess（host + **-ess** 女性 = 女主人）、hostel（host + **-el** 小 = 小旅馆）、hotel（古法语 hostel 变体 = 旅馆）、hospital（拉丁 hospit- 客人 + **-al** 场所 = 接待客人之地→医院）、hospitality（hospit- 客人 + **-ality** 名词后缀 = 好客）。
- **前缀·后缀**：名词后缀 **-ess**（例：actress, waitress）；名词后缀 **-el**（例：hostel, tunnel）。
- **同义·反义**：同义 present（主持）, emcee（主持）；反义 无。
- **变形**：动词 → 第三人称单数：hosts；过去式：hosted；过去分词：hosted；现在分词：hosting；名词派生 → host n. 主人；hostess n. 女主人。

### 15. beyond /bɪˈjɒnd/ adv. 在另一边；在（或向）更远处
- **词根·渊源**：古英语 **begeondan**（be- 在 + geond 那边）→ 中古英语 *beyonden* → 英语，本义“在那边”引申为“在更远处、超出”。
- **同根词**：yonder（古英语 geond 那边 + **-er** 比较级 = 那边的）、yon（古英语 geon 那边 = 那边的）。
- **前缀·后缀**：前缀 **be-**（例：before, behind）。
- **同义·反义**：同义 farther（更远地）, past（超过）；反义 near（近的）, within（在…之内）。
- **变形**：副词 → 无比较级（方位副词，不作比较）。

### 16. audience /ˈɔːdiəns/ n. 观众；听众
- **词根·渊源**：拉丁 **audire**（听）→ 拉丁 *audientia*（听、听众）→ 古法语 *audience* → 英语，本义“听的行为”引申为“听的人→听众、观众”。
- **同根词**：audio（拉丁 audire 听 → 音频的）、audible（audire 听 + **-ible** 可…的 = 听得见的）、audition（audire 听 + **-ition** 名词后缀 = 试听→试演）、auditorium（audire 听 + **-orium** 场所 = 听众席→礼堂）、auditory（audire 听 + **-ory** …的 = 听觉的）。
- **前缀·后缀**：名词后缀 **-ence**（例：difference, silence）；词根 **audi-**（例：audio, audition）。
- **同义·反义**：同义 spectators（观众）, listeners（听众）；反义 performers（表演者）。
- **变形**：名词 → 复数：audiences；形容词派生 → auditory adj. 听觉的。

### 17. lively /ˈlaɪvli/ adj. 充满趣味的；令人兴奋的
- **词根·渊源**：古英语 **līf**（生命）→ 中古英语 *liflich*（有生命的）→ 英语 lively，本义“有生命的”引申为“活泼的、令人兴奋的”。
- **同根词**：live（古英语 lif 生命 → 活的→生活）、life（古英语 lif 生命 → 生命）、alive（**a-** 在 + live 活 = 活着的）、living（live + **-ing** …的 = 活着的）、lifeless（life + **-less** 无…的 = 无生命的）。
- **前缀·后缀**：形容词后缀 **-ly**（例：friendly, lovely）；前缀 **a-**（例：alive, asleep）。
- **同义·反义**：同义 energetic（精力充沛的）, active（活跃的）；反义 dull（沉闷的）, lifeless（无生气的）。
- **变形**：形容词 → 比较级：livelier；最高级：liveliest；名词派生 → liveliness n. 活泼；副词派生 → livelily adv. 活泼地。

### 18. actually /ˈæktʃuəli/ adv. 事实上
- **词根·渊源**：拉丁 **actus**（行动，agere 做 的过去分词）→ 拉丁 *actualis*（行动的、现实的）→ 英语 actual，加 **-ly** 构成副词，本义“在行动上、实际上”引申为“事实上”。
- **同根词**：actual（拉丁 actualis 行动的 → 实际的）、act（拉丁 actus 行动 → 行动）、action（act + **-ion** 名词后缀 = 行动）、active（act + **-ive** …的 = 活跃的）、agent（拉丁 agere 做 + **-ent** 人 = 做事者→代理人）。
- **前缀·后缀**：副词后缀 **-ly**（例：really, usually）；名词后缀 **-ion**（例：action, nation）。
- **同义·反义**：同义 really（真正地）, in fact（事实上）；反义 无。
- **变形**：副词 → 无比较级（程度副词，不作比较）；形容词派生 → actual adj. 实际的；名词派生 → actuality n. 现实。

### 19. sail /seɪl/ v. 驾驶（或乘坐）帆船航行
- **词根·渊源**：古英语 **segl**（帆）→ 古英语 *seglian*（扬帆航行）→ 中古英语 *sailen* → 英语 sail；本义“张帆而行”，引申为“驾驶/乘坐帆船航行”，再泛化为“航行”。
- **同根词**：sailor（sail + **-or** 人 = 驾帆船的人→水手）、sailing（sail + **-ing** 名词/动名词 = 航行）、sailboat（sail 帆 + boat 船 = 帆船）、sailcloth（sail 帆 + cloth 布 = 帆布）。
- **前缀·后缀**：名词后缀 **-or**（例：actor, visitor）；动名词后缀 **-ing**（例：swimming, running）。
- **同义·反义**：同义 navigate（航行）, cruise（乘船游览）；反义 无。
- **变形**：动词 → 第三人称单数：sails；过去式：sailed；过去分词：sailed；现在分词：sailing；名词派生 → sailor n. 水手；sailing n. 航行。

### 20. ability /əˈbɪləti/ n. 才能；本领
- **词根·渊源**：拉丁 **habilis**（易于掌握的、灵巧的）→ 拉丁 *habilitas*（能力）→ 古法语 *ableté/abilité* → 英语 ability；本义“灵巧、能干的品质”，引申为“才能、本领”。
- **同根词**：able（拉丁 habilis 经古法语 able = 能干的→能够的）、enable（**en-** 使 + able 能够 = 使能够）、disable（**dis-** 去除 + able = 使失去能力→使残疾）、unable（**un-** 不 + able = 不能的）、ability 本身含 **-ity** 名词后缀。
- **前缀·后缀**：名词后缀 **-ity**（例：activity, reality）；动词前缀 **en-**（例：enable）、**dis-**（例：disable）。
- **同义·反义**：同义 capability（能力）, skill（技能）；反义 inability（无能）, disability（残疾）。
- **变形**：名词 → 复数：abilities；形容词派生 → able adj. 能够的；副词派生 → ably adv. 能干地。

### 21. review /rɪˈvjuː/ n. 评论
- **词根·渊源**：拉丁 **videre / vis-**（看）→ 古法语 *revoir*（再看）→ 中古英语 *review*；**re-**（再）+ **view**（看）= 再看→复查→评论；本义“再次查看”，引申为“评论、回顾”。
- **同根词**：view（拉丁 videre 看→古法语 veue 看见→英语 view 看/视野）、vision（拉丁 visio 看 + **-ion** 名词 = 视力/远见）、visible（拉丁 visibilis 看得见的→可见的）、revise（**re-** 再 + vis 看 = 再看→修订）、supervise（**super-** 在上 + vis 看 = 从上面看→监督）、television（希腊 tele 远 + 拉丁 visio 看 = 远看→电视）。
- **前缀·后缀**：前缀 **re-**（例：return, rebuild）；名词后缀 **-ion**（例：action, decision）。
- **同义·反义**：同义 comment（评论）, criticism（批评）；反义 无。
- **变形**：名词 → 复数：reviews；动词派生 → review v. 评论；复查。

### 22. perform /pəˈfɔːm/ v. 演出；表演
- **词根·渊源**：古法语 **parfournir**（彻底完成）→ 中古英语 *performen*；**per-**（彻底）+ **fournir**（提供、完成）= 彻底完成→履行→表演；本义“彻底做完”，引申为“执行、演出”。
- **同根词**：performance（perform + **-ance** 名词 = 表演/表现）、performer（perform + **-er** 人 = 表演者）、furnish（古法语 fournir 提供 + **-ish** 动词 = 提供/布置）。
- **前缀·后缀**：前缀 **per-**（例：perfect, permit）；名词后缀 **-ance**（例：importance, distance）、**-er**（例：teacher, singer）。
- **同义·反义**：同义 act（表演）, execute（执行）；反义 无。
- **变形**：动词 → 第三人称单数：performs；过去式：performed；过去分词：performed；现在分词：performing；名词派生 → performance n. 表演；performer n. 表演者。

### 23. kiss /kɪs/ v. 吻
- **词根·渊源**：古英语 **cyssan**（吻）→ 中古英语 *kissen* → 英语 kiss；与古诺斯语 *kyssa*、德语 *küssen* 同源，本义即“用嘴唇接触表示亲爱”，词源更早来源存疑。
- **同根词**：kisser（kiss + **-er** 人/物 = 接吻者/嘴，口语）、kissing（kiss + **-ing** 动名词 = 接吻）。
- **前缀·后缀**：名词/施事后缀 **-er**（例：worker, singer）；动名词后缀 **-ing**（例：talking, dancing）。
- **同义·反义**：同义 peck（轻吻）, smooch（拥吻，口语）；反义 无。
- **变形**：动词 → 第三人称单数：kisses；过去式：kissed；过去分词：kissed；现在分词：kissing；名词派生 → kiss n. 吻；kisser n. 接吻者（口语）。

### 24. method /ˈmeθəd/ n. 方法；办法
- **词根·渊源**：希腊 **meta-**（沿着、之后）+ **hodos**（道路）= *methodos*（追寻之路、途径）→ 拉丁 *methodus* → 古法语 *methode* → 英语 method；本义“沿着某条路走”，引申为“方法、办法”。
- **同根词**：methodical（method + **-ical** …的 = 有条理的）、methodology（method + **-ology** 学科 = 方法论）、period（希腊 peri 周围 + hodos 路 = 绕一圈→时期）。
- **前缀·后缀**：前缀 **meta-**（例：metaphor, metabolism）；形容词后缀 **-ical**（例：musical, historical）；学科后缀 **-ology**（例：biology, psychology）。
- **同义·反义**：同义 way（方式）, approach（途径）；反义 无。
- **变形**：名词 → 复数：methods；形容词派生 → methodical adj. 有条理的；副词派生 → methodically adv. 有条理地。

### 25. compare /kəmˈpeə(r)/ v. 将……作比较
- **词根·渊源**：拉丁 **comparare**（使成对、比较）→ 古法语 *comparer* → 英语 compare；**com-**（共同）+ **par**（相等）= 放在一起看是否相等→比较。
- **同根词**：comparison（拉丁 comparatio 比较 + **-ison** 名词 = 比较）、comparable（compare + **-able** 可…的 = 可比较的）、comparative（compare + **-ative** …的 = 比较的）、pair（拉丁 par 相等→一对）、peer（拉丁 par 相等→同辈）、par（拉丁 par 相等→标准/平价）。
- **前缀·后缀**：前缀 **com-**（例：combine, connect）；形容词后缀 **-able**（例：readable, comfortable）、**-ative**（例：creative, talkative）。
- **同义·反义**：同义 contrast（对比）, liken（把…比作）；反义 无。
- **变形**：动词 → 第三人称单数：compares；过去式：compared；过去分词：compared；现在分词：comparing；名词派生 → comparison n. 比较；形容词派生 → comparable adj. 可比较的；comparative adj. 比较的。

### 26. nowadays /ˈnaʊədeɪz/ adv. 现今；现在；目前
- **词根·渊源**：中古英语 **now on days**（在如今的日子里）→ 缩合为 *nowadays*；**now**（现在）+ **on**（在）+ **days**（日子，复数）= 在现今这些日子里→现今。
- **同根词**：now（古英语 nu 现在→现在）、noway（now + way 方式 = 决不，古旧）、nowhere（no 无 + where 地方 = 无处）、nowness（now + **-ness** 名词 = 现在性）。
- **前缀·后缀**：名词后缀 **-ness**（例：kindness, happiness）；复合词无典型前后缀（now + a + days 组合）。
- **同义·反义**：同义 currently（目前）, presently（现在）；反义 formerly（从前）, once（曾经）。
- **变形**：副词 → 无比较级（时间副词，不作比较）；无词性派生。

### 28. lecture /ˈlektʃə(r)/ n. 讲座；讲课
- **词根·渊源**：拉丁 **legere / lect-**（读、选）→ 中世纪拉丁 *lectura*（诵读）→ 古法语 *lecture* → 英语 lecture；本义“诵读、宣读”，引申为“讲课、讲座”。
- **同根词**：lecturer（lecture + **-er** 人 = 讲师）、legend（拉丁 legenda 应读之物→传说）、lesson（拉丁 lectio 诵读→古法语 leçon→课）、collect（**col-** 共同 + lect 选 = 选到一起→收集）、select（**se-** 分开 + lect 选 = 挑出来→选择）、elect（**e-** 出 + lect 选 = 选出→选举）。
- **前缀·后缀**：名词后缀 **-er**（例：teacher, worker）；前缀 **col-**（例：collect）、**se-**（例：select）、**e-**（例：elect）。
- **同义·反义**：同义 talk（讲座）, speech（演讲）；反义 无。
- **变形**：名词 → 复数：lectures；动词派生 → lecture v. 讲课；名词派生 → lecturer n. 讲师。
