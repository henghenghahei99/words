## 二、逐词说文解字

### 1. possible /ˈpɒsəbl/ adj. 可能
- **词根·渊源**：拉丁 **posse**（能够）→ 拉丁 *possibilis*（能做的）→ 古法语 *possible* → 英语；本义“有能力做到的”引申为“可能的”。
- **同根词**：potent（**pot-** 能 + **-ent** …的 = 有能力的→强有力的）、potential（potent + **-ial** …的 = 有潜力的）、power（源自古法语 *povoir*，与 posse 同出拉丁“能够”义→力量）、impossible（**im-** 不 + possible 可能的 = 不可能的）、possibility（possible + **-ity** 名词后缀 = 可能性）。
- **前缀·后缀**：形容词后缀 **-ible**（例：visible, flexible）；否定前缀 **im-**（例：impossible, impolite）。
- **同义·反义**：同义 likely, feasible；反义 impossible, unlikely。
- **词性变化**：possibly adv. 可能地；possibility n. 可能性；impossible adj. 不可能的。

### 2. athlete /ˈæθliːt/ n. 运动员
- **词根·渊源**：希腊 **athlon**（奖品、竞赛）→ 希腊 *athlētēs*（为奖品而竞赛的人）→ 拉丁 *athleta* → 英语；本义“争夺奖品者”引申为“运动员”。
- **同根词**：athletic（athlete + **-ic** …的 = 运动的、健壮的）、athletics（athletic + **-s** 名词化 = 体育运动）、triathlon（**tri-** 三 + athlon 竞赛 = 三项全能）、decathlon（**deca-** 十 + athlon 竞赛 = 十项全能）、athlete 本身即词根词。
- **前缀·后缀**：名词后缀 **-ete**（例：concrete, complete 中的 -ete 部分）；组合前缀 **tri-**（例：triangle）、**deca-**（例：decade）。
- **同义·反义**：同义 sportsman, player；反义 无。
- **词性变化**：athletic adj. 运动的；athletics n. 体育运动。

### 3. biologist /baɪˈɒlədʒɪst/ n. 生物学家
- **词根·渊源**：希腊 **bios**（生命）+ **logia**（学问、研究）→ 法语 *biologie* → 英语 biology；加 **-ist**（从事…的人）构成 biologist，本义“研究生命学问的人”。
- **同根词**：biology（bio 生命 + **-logy** 学科 = 生物学）、biography（bio 生命 + **-graphy** 书写 = 生平传记）、antibiotic（**anti-** 反 + bio 生命 + **-tic** …的 = 抗生的→抗生素）、biosphere（bio 生命 + sphere 球 = 生物圈）、geology（**geo-** 地 + **-logy** 学科 = 地质学）。
- **前缀·后缀**：名词后缀 **-ist**（例：artist, scientist）；学科后缀 **-logy**（例：zoology, psychology）；前缀 **anti-**（例：antibody）。
- **同义·反义**：同义 life scientist；反义 无。
- **词性变化**：biology n. 生物学；biological adj. 生物的。

### 4. instrument /ˈɪnstrəmənt/ n. 乐器；仪器
- **词根·渊源**：拉丁 **instruere**（建造、装备）→ 拉丁 *instrumentum*（工具、设备）→ 古法语 *instrument* → 英语；本义“用来做事的东西”引申为“仪器”，再引申为“乐器”。
- **同根词**：instruct（**in-** 在内 + struct 建造 = 在头脑中构建→指导）、instruction（instruct + **-ion** 名词后缀 = 指导、说明）、instrumental（instrument + **-al** …的 = 仪器的；起作用的）、construct（**con-** 共同 + struct 建造 = 建造）、structure（struct 建造 + **-ure** 名词后缀 = 结构）。
- **前缀·后缀**：名词后缀 **-ment**（例：movement, equipment）；前缀 **in-**（例：include）、**con-**（例：connect）。
- **同义·反义**：同义 tool, device；反义 无。
- **词性变化**：instrumental adj. 仪器的；起作用的；instrumentation n. 仪器装备。

### 5. interest /ˈɪntrəst/ n. 兴趣；业余爱好
- **词根·渊源**：拉丁 **interesse**（在…之间；有关系、重要）→ 古法语 *interest* → 英语；本义“介于其间、与之相关”引申为“利害关系”，再引申为“兴趣”。
- **同根词**：interesting（interest + **-ing** …的 = 有趣的）、interested（interest + **-ed** 感到…的 = 感兴趣的）、disinterested（**dis-** 不 + interested 有私利的 = 无私的）、uninteresting（**un-** 不 + interesting 有趣的 = 无趣的）、essence（**ess-** 存在 + **-ence** 名词后缀，与 interesse 同出 esse“存在”→本质）。
- **前缀·后缀**：形容词后缀 **-ing**（例：boring, exciting）、**-ed**（例：bored, excited）；否定前缀 **dis-**（例：dislike）、**un-**（例：unhappy）。
- **同义·反义**：同义 curiosity, hobby；反义 boredom, indifference。
- **词性变化**：interesting adj. 有趣的；interested adj. 感兴趣的。

### 6. career /kəˈrɪə(r)/ n. 生涯；职业
- **词根·渊源**：拉丁 **carrus**（车）→ 拉丁 *carraria*（车道）→ 法语 *carrière*（跑道、道路）→ 英语；本义“车行的道路”引申为“人生的历程、生涯”。
- **同根词**：car（源自拉丁 carrus 车 → 汽车）、carry（源自古法语 *carier*，与 carrus 同出“用车运”→携带）、cargo（car 车 + **-go** 名词后缀 = 车载货物）、carriage（carry + **-age** 名词后缀 = 马车、车厢）、cart（与 car 同源 = 大车）。
- **前缀·后缀**：无前后缀（单纯词，源自拉丁 carrus）。
- **同义·反义**：同义 profession, occupation；反义 无。
- **词性变化**：career n. 生涯；职业（无常见派生词）。

### 7. lifetime /ˈlaɪftaɪm/ n. 一生；终身
- **词根·渊源**：古英语 **līf**（生命）+ **tīma**（时间）→ 中古英语 *lifetime*；本义“生命的时间”即“一生”。
- **同根词**：life（古英语 līf 生命 = 生命）、lively（life + **-ly** …的 = 活泼的）、live（古英语 libban 活着 = 生活）、time（古英语 tīma 时间 = 时间）、timely（time + **-ly** …的 = 及时的）。
- **前缀·后缀**：无前后缀（复合词：life + time）。
- **同义·反义**：同义 whole life, lifespan；反义 无。
- **词性变化**：无常见派生词。

### 8. diamond /ˈdaɪəmənd/ n. 钻石
- **词根·渊源**：希腊 **adamas**（不可征服的）→ 拉丁 *adamas / adamantem*（最硬的石头）→ 古法语 *diamant* → 英语；本义“坚硬无比的石头”即“钻石”。
- **同根词**：adamant（希腊 adamas 不可征服的 → 坚硬的、坚决的）、adamantine（adamant + **-ine** …的 = 坚硬如钻石的）；diamond 本身为借词，同根词较少。
- **前缀·后缀**：无前后缀（单纯词，源自希腊 adamas）。
- **同义·反义**：同义 gem, jewel；反义 无。
- **词性变化**：无常见派生词。

### 9. belt /bɛlt/ n. 腰带
- **词根·渊源**：古英语 **belt**（腰带），源自拉丁 **balteus**（腰带、束带）→ 日耳曼语 → 古英语；本义“束带”即“腰带”。
- **同根词**：belted（belt + **-ed** …的 = 系腰带的）、beltless（belt + **-less** 无…的 = 无腰带的）；belt 为日耳曼借词，同根词较少。
- **前缀·后缀**：名词后缀 **-ed**（例：winged, bearded）、**-less**（例：hopeless, careless）。
- **同义·反义**：同义 strap, band；反义 无。
- **词性变化**：belted adj. 系腰带的；beltless adj. 无腰带的。

### 10. shoot /ʃuːt/ v. 冲；奔；飞驰
- **词根·渊源**：古英语 **scēotan**（射击、投掷）→ 中古英语 *shoten*；本义“射出”引申为“快速冲出、飞奔”。
- **同根词**：shot（shoot 的过去分词 → 射击、投篮）、shooter（shoot + **-er** 人 = 射手）、shooting（shoot + **-ing** 名词后缀 = 射击）、shuttle（与 shoot 同源，古英语 scytel 飞镖 → 穿梭）、shout（与 shoot 同源，本义“喊出”→喊叫）。
- **前缀·后缀**：名词后缀 **-er**（例：teacher, worker）、**-ing**（例：running, swimming）。
- **同义·反义**：同义 rush, dash；反义 无。
- **词性变化**：shot n. 射击；shooter n. 射手；shooting n. 射击。

### 11. extremely /ɪkˈstriːmli/ adv. 极其；极端；非常
- **词根·渊源**：拉丁 **extremus**（最外的，exterus 的最高级）→ 古法语 *extreme* → 英语 extreme；加 **-ly** 构成副词，本义“到最外端”引申为“极其”。
- **同根词**：extreme（**ex-** 出 + trem 最外 + **-e** = 最外的→极端的）、extremist（extreme + **-ist** 人 = 极端主义者）、extremity（extreme + **-ity** 名词后缀 = 末端、极度）、exterior（**ex-** 出 + **-terior** 比较级后缀 = 外部的）、external（**ex-** 出 + **-ernal** …的 = 外部的）。
- **前缀·后缀**：副词后缀 **-ly**（例：quickly, happily）；前缀 **ex-**（例：exit, export）。
- **同义·反义**：同义 very, highly；反义 slightly, mildly。
- **词性变化**：extreme adj. 极端的；extremist n. 极端主义者；extremity n. 末端；极度。

### 12. curious /ˈkjʊəriəs/ adj. 求知欲强的；好奇的
- **词根·渊源**：拉丁 **cura**（关心、注意）→ 拉丁 *curiosus*（细心的、好奇的）→ 古法语 *curius* → 英语；本义“用心关注的”引申为“好奇的”。
- **同根词**：curiosity（curious + **-ity** 名词后缀 = 好奇心）、curio（curious 的缩略 = 珍奇物品）、cure（拉丁 cura 关心 → 照料→治疗）、accurate（**ac-** 加强 + cur 关心 + **-ate** …的 = 用心做的→准确的）、secure（**se-** 分开 + cure 关心 = 无忧的→安全的）。
- **前缀·后缀**：形容词后缀 **-ous**（例：famous, dangerous）；前缀 **ac-**（例：accept）、**se-**（例：separate）。
- **同义·反义**：同义 inquisitive, interested；反义 indifferent, uninterested。
- **词性变化**：curiosity n. 好奇心；curiously adv. 好奇地。

### 13. increase /ɪnˈkriːs/ v. 增长；增多；增加
- **词根·渊源**：拉丁 **crescere**（生长）→ 拉丁 *increscere*（在…上生长）→ 古法语 *encreistre* → 英语；本义“在上面长出来”引申为“增加”。
- **同根词**：decrease（**de-** 向下 + crease 生长 = 向下长→减少）、crescent（cresc 生长 + **-ent** …的 = 生长的→新月）、concrete（**con-** 共同 + cret 生长 + **-e** = 一起长成的→具体的）、create（cre 生长 + **-ate** 动词后缀 = 使生长→创造）、increment（**in-** 在内 + cre 生长 + **-ment** 名词后缀 = 增长）。
- **前缀·后缀**：前缀 **in-**（例：include）、**de-**（例：decline）、**con-**（例：connect）；名词后缀 **-ment**（例：movement）。
- **同义·反义**：同义 grow, rise；反义 decrease, reduce。
- **词性变化**：increase n. 增长；increasing adj. 增长的；increasingly adv. 越来越。

### 14. host /həʊst/ v. 主持
- **词根·渊源**：拉丁 **hospes / hospit-**（主人、客人）→ 古法语 *hoste* → 英语；本义“做主人招待客人”引申为“主持（活动）”。
- **同根词**：hostel（host 主人 + **-el** 小称 = 小客栈）、hotel（源自古法语 *hostel* 的变体 = 旅馆）、hospital（host 客人 + **-al** 名词后缀 = 接待客人之地→医院）、hospitality（hospital + **-ity** 名词后缀 = 好客）、hostess（host + **-ess** 女性 = 女主人）。
- **前缀·后缀**：名词后缀 **-el**（例：channel）、**-al**（例：arrival）、**-ess**（例：actress, waitress）。
- **同义·反义**：同义 present, organize；反义 无。
- **词性变化**：host n. 主人；hostess n. 女主人；hospitality n. 好客。

### 15. beyond /bɪˈjɒnd/ adv. 在另一边；在（或向）更远处
- **词根·渊源**：古英语 **begeondan**（在…那边），由 **be-**（在…旁）+ **geond**（越过）构成 → 中古英语 *beyond*；本义“越过那边”即“在更远处”。
- **同根词**：yonder（与 geond 同源 = 那边的）、yon（yonder 的缩略 = 那边的）；beyond 为古英语复合词，同根词较少。
- **前缀·后缀**：前缀 **be-**（例：before, behind）；无后缀。
- **同义·反义**：同义 past, farther；反义 within, near。
- **词性变化**：无常见派生词。

### 16. audience /ˈɔːdiəns/ n. 观众；听众
- **词根·渊源**：拉丁 **audire**（听）→ 拉丁 *audientia*（听）→ 古法语 *audience* → 英语；本义“听的行为”引申为“听的人→听众、观众”。
- **同根词**：audio（audi 听 + **-o** = 音频的）、audible（audi 听 + **-ible** 可…的 = 听得见的）、audition（audi 听 + **-tion** 名词后缀 = 试听→试演）、auditorium（audi 听 + **-torium** 场所 = 听众席）、obey（**ob-** 朝向 + audire 听 = 听从→服从）。
- **前缀·后缀**：名词后缀 **-ence**（例：difference, patience）；前缀 **ob-**（例：object）。
- **同义·反义**：同义 listeners, spectators；反义 无。
- **词性变化**：audible adj. 听得见的；audio adj. 音频的；audition n. 试演。

### 17. lively /ˈlaɪvli/ adj. 充满趣味的；令人兴奋的
- **词根·渊源**：古英语 **līf**（生命）→ **līflīc**（有生命的）→ 中古英语 *lively*；本义“有生命的、活泼的”引申为“充满趣味的”。
- **同根词**：life（古英语 līf 生命 = 生命）、live（古英语 libban 活着 = 生活）、alive（**a-** 在 + live 活 = 活着的）、living（live + **-ing** …的 = 活着的）、lifeless（life + **-less** 无…的 = 无生命的）。
- **前缀·后缀**：形容词后缀 **-ly**（例：friendly, lovely）；前缀 **a-**（例：awake, asleep）；否定后缀 **-less**（例：hopeless）。
- **同义·反义**：同义 energetic, exciting；反义 dull, lifeless。
- **词性变化**：life n. 生命；live v. 生活；alive adj. 活着的；liveliness n. 活泼。

### 18. actually /ˈæktʃuəli/ adv. 事实上
- **词根·渊源**：拉丁 **agere / act-**（做、行动）→ 拉丁 *actualis*（行动的）→ 英语 actual；加 **-ly** 构成副词，本义“在行动上”引申为“事实上”。
- **同根词**：act（act 做 = 行动）、action（act + **-ion** 名词后缀 = 行动）、active（act + **-ive** …的 = 积极的）、actual（act + **-ual** …的 = 实际的）、agent（**ag-** 做 + **-ent** 人 = 做事的人→代理人）。
- **前缀·后缀**：副词后缀 **-ly**（例：really, finally）；形容词后缀 **-ual**（例：usual, gradual）；名词后缀 **-ion**（例：invention）。
- **同义·反义**：同义 really, in fact；反义 无。
- **词性变化**：actual adj. 实际的；act v. 行动；action n. 行动；active adj. 积极的。

### 19. sail /seɪl/ v. 驾驶（或乘坐）帆船航行
- **词根·渊源**：古英语 **segel**（帆）→ 中古英语 *sail*，本义“帆”，后引申为“扬帆航行”；与古诺斯语 *segl* 同源，PIE 词根 *sek-*（切）存疑。
- **同根词**：sailor（sail + **-or** 人 = 驾帆船的人→水手）、sailing（sail + **-ing** 名词/形容词后缀→航行）、sailboat（sail 帆 + boat 船 = 帆船）。
- **前缀·后缀**：名词后缀 **-or**（例：actor, visitor）；动名词后缀 **-ing**（例：running, swimming）。
- **同义·反义**：同义 navigate, cruise；反义 无。
- **词性变化**：sailor n. 水手；sailing n. 航行。

### 20. ability /əˈbɪləti/ n. 才能；本领
- **词根·渊源**：拉丁 **habilis**（易于掌握的）→ 古法语 *able* → 英语 able + 拉丁后缀 **-ity**；本义“能够做到的性质”，引申为“才能”。
- **同根词**：able（拉丁 habilis 易于掌握的→能够的）、enable（**en-** 使 + able = 使能够）、disable（**dis-** 去除 + able = 使失去能力→使残疾）、unable（**un-** 不 + able = 不能的）、ability 本身由 able + **-ity** 构成。
- **前缀·后缀**：名词后缀 **-ity**（例：activity, reality）；否定前缀 **un-**（例：unhappy）、**dis-**（例：disagree）。
- **同义·反义**：同义 capability, skill；反义 inability, incapability。
- **词性变化**：able adj. 能够的；enable v. 使能够；disable v. 使残疾。

### 21. review /rɪˈvjuː/ n. 评论
- **词根·渊源**：拉丁 **videre**（看）→ 古法语 *revoir* → 英语 review；**re-**（再）+ **view**（看）= 再看→复查→评论。
- **同根词**：view（拉丁 videre 看→看）、interview（**inter-** 相互 + view 看 = 相互看→面试）、preview（**pre-** 先 + view 看 = 先看→预览）、revise（**re-** 再 + vis 看 = 再看→修订）、vision（vis 看 + **-ion** 名词后缀→视力）、visible（vis 看 + **-ible** 可…的→可见的）。
- **前缀·后缀**：前缀 **re-**（例：return, rebuild）、**inter-**（例：international）、**pre-**（例：prepare）；名词后缀 **-ion**（例：action, education）。
- **同义·反义**：同义 comment, critique；反义 无。
- **词性变化**：review v. 评论；reviewer n. 评论者。

### 22. perform /pəˈfɔːm/ v. 演出；表演
- **词根·渊源**：古法语 **parfournir**（彻底完成）→ 英语 perform；**per-**（彻底）+ **form**（形成/完成）= 彻底完成→执行→表演。
- **同根词**：performance（perform + **-ance** 名词后缀→表演）、performer（perform + **-er** 人→表演者）、form（拉丁 forma 形状→形式）、formal（form + **-al** …的→正式的）、inform（**in-** 进入 + form 形成 = 形成观念→通知）。
- **前缀·后缀**：前缀 **per-**（例：perfect, permit）、**in-**（例：inside, inform）；名词后缀 **-ance**（例：importance, distance）、**-er**（例：teacher, worker）。
- **同义·反义**：同义 act, execute；反义 无。
- **词性变化**：performance n. 表演；performer n. 表演者。

### 23. kiss /kɪs/ v. 吻
- **词根·渊源**：古英语 **cyssan**（吻）→ 中古英语 *kissen* → 英语 kiss；与古诺斯语 *kyssa* 同源，PIE 词根存疑。
- **同根词**：kissing（kiss + **-ing** 名词/形容词后缀→接吻）、kissable（kiss + **-able** 可…的→可亲吻的）。
- **前缀·后缀**：名词后缀 **-ing**（例：meeting, building）；形容词后缀 **-able**（例：comfortable, readable）。
- **同义·反义**：同义 peck, smooch；反义 无。
- **词性变化**：kiss n. 吻；kissing n. 接吻。

### 24. method /ˈmeθəd/ n. 方法；办法
- **词根·渊源**：希腊 **methodos**（追寻之路）→ 拉丁 *methodus* → 英语 method；**meta-**（沿着/之后）+ **hodos**（路）= 沿着路走→方法。
- **同根词**：methodical（method + **-ical** …的→有条理的）、methodology（method + **-ology** 学科→方法论）、period（**peri-** 周围 + hodos 路 = 绕一圈→时期）。
- **前缀·后缀**：前缀 **meta-**（例：metaphor, metabolism）、**peri-**（例：perimeter, period）；形容词后缀 **-ical**（例：musical, historical）；名词后缀 **-ology**（例：biology, technology）。
- **同义·反义**：同义 way, approach；反义 无。
- **词性变化**：methodical adj. 有条理的；methodology n. 方法论。

### 25. compare /kəmˈpeə(r)/ v. 将……作比较
- **词根·渊源**：拉丁 **comparare**（使平等）→ 古法语 *comparer* → 英语 compare；**com-**（共同）+ **par**（平等）= 使平等→比较。
- **同根词**：comparison（compare + **-ison** 名词后缀→比较）、comparable（compare + **-able** 可…的→可比较的）、comparative（compare + **-ative** …的→比较的）、pair（拉丁 par 平等→一对）、peer（拉丁 par 平等→同辈）。
- **前缀·后缀**：前缀 **com-**（例：combine, compete）；形容词后缀 **-able**（例：comfortable, readable）、**-ative**（例：creative, talkative）。
- **同义·反义**：同义 contrast, liken；反义 无。
- **词性变化**：comparison n. 比较；comparable adj. 可比较的；comparative adj. 比较的。

### 26. nowadays /ˈnaʊədeɪz/ adv. 现今；现在；目前
- **词根·渊源**：中古英语 **now**（现在）+ **a**（在）+ **days**（日子）= 在如今的日子里→现今；为复合副词。
- **同根词**：now（古英语 nu 现在→现在）、day（古英语 dæg 日→天）、today（to 在 + day 日 = 在今天→今天）、tonight（to 在 + night 夜 = 在今晚→今晚）。
- **前缀·后缀**：无前后缀（复合词）。
- **同义·反义**：同义 currently, presently；反义 formerly, previously。
- **词性变化**：无派生词。

### 28. lecture /ˈlektʃə(r)/ n. 讲座；讲课
- **词根·渊源**：拉丁 **legere**（读/选）→ 中世纪拉丁 *lectura*（阅读）→ 古法语 *lecture* → 英语 lecture；本义“读”，引申为“讲课”。
- **同根词**：lecturer（lecture + **-er** 人→讲师）、legend（拉丁 legere 读→传说）、lesson（拉丁 legere 读→课）、collect（**col-** 共同 + lect 选 = 选在一起→收集）、select（**se-** 分开 + lect 选 = 选出→选择）、elect（**e-** 出 + lect 选 = 选出→选举）。
- **前缀·后缀**：名词后缀 **-er**（例：teacher, worker）；前缀 **col-**（例：collect, collide）、**se-**（例：select, separate）、**e-**（例：elect, exit）。
- **同义·反义**：同义 speech, talk；反义 无。
- **词性变化**：lecturer n. 讲师；lecture v. 讲课。
