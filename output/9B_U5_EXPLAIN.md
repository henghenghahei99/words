## 二、逐词说文解字

### 1. announcement /ə'naʊnsmənt/ n. 公告；通告
- **词根·渊源**：拉丁 **nuntius**（信使）→ 拉丁 *annuntiare*（宣告）→ 古法语 *anoncier* → 英语 announce + 名词后缀 **-ment**；本义“把消息带给人们”，引申为“公告、通告”。
- **同根词**：announce（**an-** 向 + nounce 报告 = 向公众报告→宣布）、pronounce（**pro-** 向前 + nounce 说 = 向前说出→发音）、denounce（**de-** 向下 + nounce 说 = 向下说→谴责）、renounce（**re-** 回 + nounce 说 = 回绝声明→放弃）。
- **前缀·后缀**：动词前缀 **an-**（例：announce, annex）、**pro-**（例：pronounce, protect）；名词后缀 **-ment**（例：movement, development）。
- **同义·反义**：同义 notice（通知）, declaration（声明）；反义 无。
- **变形**：名词 → 复数：announcements；动词派生 → announce v. 宣布；形容词派生 → announced adj. 已宣布的。

### 2. passport /ˈpɑːspɔːt/ n. 护照
- **词根·渊源**：拉丁 **passus**（步、通过）＋ **portus**（港口）→ 古法语 *passer*（通过）＋ *port*（港口）→ 英语 passport；本义“通过港口的通行证”，引申为“护照”。
- **同根词**：pass（**pass-** 通过 = 走过→通过）、passage（pass + **-age** 名词后缀 = 通过的行为→通道）、passenger（pass + **-enger** 人 = 通过的人→乘客）、port（**port-** 港口 = 港口）、portable（port 携带 + **-able** 可…的 = 可携带的）、import（**im-** 进入 + port 港口 = 运进港口→进口）。
- **前缀·后缀**：无前后缀（复合词，pass + port）。
- **同义·反义**：同义 travel document（旅行证件）；反义 无。
- **变形**：名词 → 复数：passports。

### 3. the Pacific /ðə pəˈsɪfɪk/ n. 太平洋
- **同义搭配**：无
- **反义搭配**：无

### 4. Canada /ˈkænədə/ n. 加拿大
- **词根·渊源**：休伦-易洛魁语 **kanata**（村庄、聚居地）→ 法语 *Canada* → 英语 Canada；1535 年法国探险家卡蒂埃据当地土著语称此地为“村庄”，后成为国名。词源存疑（一说源自葡萄牙语 *cá nada*“这里什么都没有”）。
- **同根词**：Canadian（Canada + **-ian** 人/的 = 加拿大人/加拿大的）。
- **前缀·后缀**：无前后缀（专有名词）。
- **同义·反义**：同义 无；反义 无。
- **变形**：名词 → 复数：不可数（专有名词）。

### 5. resort /rɪˈzɔːrt/ n. 度假地
- **词根·渊源**：拉丁 **sort-**（命运、种类）→ 古法语 *resort*（recourse，求助）→ 英语 resort；本义“常去之处、求助之地”，引申为“度假地”。
- **同根词**：sort（**sort-** 种类 = 种类→分类）、assort（**as-** 向 + sort 种类 = 按种类分→分类）、consort（**con-** 共同 + sort 命运 = 共命运→配偶、结伴）。
- **前缀·后缀**：前缀 **re-**（例：return, recall）。
- **同义·反义**：同义 holiday spot（度假胜地）, retreat（休养地）；反义 无。
- **变形**：名词 → 复数：resorts；动词派生 → resort v. 求助、常去。

### 6. Canadian /kəˈneɪdiən/ adj. 加拿大的；加拿大人的
- **词根·渊源**：休伦-易洛魁语 **kanata**（村庄）→ 法语 *Canada* → 英语 Canada + 形容词/名词后缀 **-ian**；本义“加拿大的人/的”，引申为“加拿大的；加拿大人的”。
- **同根词**：Canada（**Canada** 国名 = 加拿大）。
- **前缀·后缀**：后缀 **-ian**（例：Italian, Australian）。
- **同义·反义**：同义 无；反义 无。
- **变形**：形容词 → 无比较级（关系形容词，不作比较）；名词 → 复数：Canadians；名词派生 → Canadian n. 加拿大人。

### 7. slope /sləʊp/ n. 斜坡；坡地
- **词根·渊源**：中古英语 **slopen**（倾斜、溜走）→ 英语 slope；本义“倾斜的动作”，引申为“斜坡、坡地”。词源存疑（可能与古英语 *slūpan*“滑”有关）。
- **同根词**：aslope（**a-** 在…状态 + slope 倾斜 = 倾斜的）。
- **前缀·后缀**：无前后缀（单纯词）。
- **同义·反义**：同义 incline（斜坡）, gradient（坡度）；反义 flat（平地）。
- **变形**：名词 → 复数：slopes；动词派生 → slope v. 倾斜；形容词派生 → sloping adj. 倾斜的。

### 8. opposite /ˈɑːpəzɪt/ adj. 在……的对面，相反的；对面的
- **词根·渊源**：拉丁 **opponere**（放在对面）→ 拉丁 *oppositus*（被放在对面的）→ 古法语 *opposite* → 英语 opposite；本义“被放在对面的”，引申为“对面的、相反的”。
- **同根词**：oppose（**op-** 反对 + pose 放 = 放在对面→反对）、opposition（oppose + **-ition** 名词后缀 = 反对的行为→反对）、opponent（op + pon 放 + **-ent** 人 = 放在对面的人→对手）、pose（**pose-** 放 = 摆放→姿势）、compose（**com-** 共同 + pose 放 = 放在一起→组成）。
- **前缀·后缀**：前缀 **op-**（例：oppose, oppress）；形容词后缀 **-ite**（例：favorite, definite）。
- **同义·反义**：同义 contrary（相反的）, facing（对面的）；反义 same（相同的）。
- **变形**：形容词 → 无比较级（关系形容词，不作比较）；名词 → 复数：opposites；名词派生 → opposite n. 对立面；副词派生 → oppositely adv. 相反地。

### 9. glove /ɡlʌv/ n.（分手指的）手套
- **词根·渊源**：古英语 **glōf**（手套）→ 中古英语 *glove* → 英语 glove；本义“手部覆盖物”，引申为“（分手指的）手套”。词源存疑（一说与 *lofe*“手掌”有关）。
- **同根词**：glover（glove + **-er** 人 = 做手套的人→手套商）。
- **前缀·后缀**：无前后缀（单纯词）。
- **同义·反义**：同义 mitten（连指手套，近义）；反义 无。
- **变形**：名词 → 复数：gloves。

### 10. couple /ˈkʌpl/ n. 一对夫妇
- **词根·渊源**：拉丁 **copula**（联结、纽带）→ 古法语 *cople* → 英语 couple；本义“联结在一起的两个”，引申为“一对、夫妇”。
- **同根词**：couple（**copul-** 联结 = 联结→一对）、couplet（couple + **-et** 小 = 小对→对联）、copula（**copula-** 联结 = 联结词→系动词）。
- **前缀·后缀**：无前后缀（单纯词）。
- **同义·反义**：同义 pair（一对）, twosome（两人组）；反义 single（单个人）。
- **变形**：名词 → 复数：couples；动词派生 → couple v. 连接、结合。

### 11. gentle /ˈdʒentl/ adj. 平缓的
- **词根·渊源**：拉丁 **gens / gent-**（家族、出身）→ 古法语 *gentil*（出身高贵的）→ 英语 gentle；本义“出身高贵的”，引申为“温和的、平缓的”。
- **同根词**：genteel（**gent-** 出身 + **-eel** 形容词后缀 = 出身高贵的→文雅的）、gentry（gent + **-ry** 阶层 = 贵族阶层→绅士们）、gentleman（gentle 高贵的 + man 人 = 出身高贵的人→绅士）、genuine（**gen-** 出生 + **-ine** …的 = 天生的→真正的）。
- **前缀·后缀**：形容词后缀 **-le**（例：little, noble）。
- **同义·反义**：同义 mild（温和的）, gradual（平缓的）；反义 steep（陡峭的）, harsh（严厉的）。
- **变形**：形容词 → 比较级：gentler；最高级：gentlest；副词派生 → gently adv. 温和地；名词派生 → gentleness n. 温和。

### 12. honest /ˈɑ:nɪst/ adj. 诚实的；老实的；正直的
- **词根·渊源**：拉丁 **honos / honor-**（荣誉）→ 古法语 *honeste* → 英语 honest；本义“有荣誉的”，引申为“诚实的、正直的”。
- **同根词**：honor（**honor-** 荣誉 = 荣誉）、honesty（honest + **-y** 名词后缀 = 诚实）、honorable（honor + **-able** 可…的 = 可敬的）、dishonest（**dis-** 不 + honest = 不诚实的）。
- **前缀·后缀**：形容词后缀 **-est**（例：modest, earnest）；否定前缀 **dis-**（例：dishonest, disagree）。
- **同义·反义**：同义 truthful（诚实的）, sincere（真诚的）；反义 dishonest（不诚实的）, deceitful（欺骗的）。
- **变形**：形容词 → 比较级：more honest；最高级：most honest；副词派生 → honestly adv. 诚实地；名词派生 → honesty n. 诚实。

### 13. rope /roʊp/ v. 绳子，绳索
- **词根·渊源**：古英语 **rāp**（绳）→ 中古英语 *rope* → 英语 rope；本义“绳索”，动词义“用绳捆”，引申为“绳子，绳索”。
- **同根词**：ropy（rope + **-y** …的 = 像绳子的→黏稠的）。
- **前缀·后缀**：无前后缀（单纯词）。
- **同义·反义**：同义 cord（细绳）, cable（缆绳）；反义 无。
- **变形**：名词 → 复数：ropes；动词 → 第三人称单数：ropes；过去式：roped；过去分词：roped；现在分词：roping。

### 14. rapid /ˈræpɪd/ adj. 迅速的；快速的
- **词根·渊源**：拉丁 **rapere**（抢夺、急速带走）→ 拉丁 *rapidus*（急速的）→ 法语 *rapide* → 英语 rapid；本义“急速带走”，引申为“迅速的”。
- **同根词**：rape（**rap-** 抢夺 = 抢夺→强奸）、rapture（rapt + **-ure** 名词后缀 = 被带走的状态→狂喜）、ravish（**rav-** 抢夺 + **-ish** 动词后缀 = 抢走→使狂喜）、rapidity（rapid + **-ity** 名词后缀 = 迅速）。
- **前缀·后缀**：形容词后缀 **-id**（例：valid, vivid）。
- **同义·反义**：同义 fast（快的）, swift（迅速的）；反义 slow（慢的）。
- **变形**：形容词 → 比较级：more rapid；最高级：most rapid；副词派生 → rapidly adv. 迅速地；名词派生 → rapidity n. 迅速。

### 15. over /ˈəʊvə(r)/ adv. 结束；穿过；多于
- **词根·渊源**：古英语 **ofer**（在上方、越过）→ 中古英语 *over* → 英语 over；本义“在上方、越过”，引申为“结束、穿过、多于”。
- **同根词**：overcome（**over-** 越过 + come 来 = 越过困难→克服）、overlook（over 越过 + look 看 = 越过看→俯瞰、忽视）、overcoat（over 在上 + coat 外套 = 在外套上→大衣）、overdo（over 过度 + do 做 = 做得过度→过度做）。
- **前缀·后缀**：前缀 **over-**（例：overcome, overlook）。
- **同义·反义**：同义 above（在上方）, finished（结束的）；反义 under（在下方）。
- **变形**：副词 → 无比较级（方位副词，不作比较）。

### 16. shame /ʃem/ v. 可惜；遗憾
- **词根·渊源**：古英语 **sceamu**（羞耻）→ 中古英语 *shame* → 英语 shame；本义“羞耻感”，引申为感叹“可惜、遗憾”。
- **同根词**：shameful（shame + **-ful** 充满…的 = 可耻的）、ashamed（**a-** 在…状态 + shame 羞耻 = 感到羞耻的）、shameless（shame + **-less** 无…的 = 无耻的）。
- **前缀·后缀**：形容词后缀 **-ful**（例：helpful, useful）、**-less**（例：hopeless, careless）。
- **同义·反义**：同义 pity（可惜）, regret（遗憾）；反义 honor（荣誉）。
- **变形**：名词 → 复数：shames；动词 → 第三人称单数：shames；过去式：shamed；过去分词：shamed；现在分词：shaming；形容词派生 → shameful adj. 可耻的；副词派生 → shamefully adv. 可耻地。

### 17. fee /fiː/ n. 费用
- **词根·渊源**：古英语 **feoh**（牲畜、财产）→ 中古英语 *fee* → 英语 fee；本义“牲畜（作为财产）”，引申为“费用、酬金”。
- **同根词**：fief（**fief-** 封地 = 封地）、feudal（feud + **-al** …的 = 封建的）。
- **前缀·后缀**：无前后缀（单纯词）。
- **同义·反义**：同义 charge（收费）, payment（付款）；反义 无。
- **变形**：名词 → 复数：fees。

### 18. enter /ˈentə(r)/ v. 报名参加
- **词根·渊源**：拉丁 **intra**（在内）→ 拉丁 *intrare*（进入）→ 古法语 *entrer* → 英语 enter；本义“进入”，引申为“报名参加”。
- **同根词**：entry（**entr-** 进入 + **-y** 名词后缀 = 进入的行为→入口、条目）、entrance（enter + **-ance** 名词后缀 = 进入→入口）、entrant（entr + **-ant** 人 = 进入的人→参赛者）。
- **前缀·后缀**：无前后缀（单纯词）。
- **同义·反义**：同义 join（参加）, enroll（报名）；反义 exit（退出）, leave（离开）。
- **变形**：动词 → 第三人称单数：enters；过去式：entered；过去分词：entered；现在分词：entering；名词派生 → entry n. 进入、条目；entrance n. 入口。

### 19. semi-final /ˌsemi ˈfaɪnl/ adj. 半决赛
- **词根·渊源**：拉丁 **semi-**（一半）+ 拉丁 **finis**（终点、界限）→ 拉丁 *finalis*（最终的）→ 英语 final；semi- + final 本义“一半决赛”，即半决赛。
- **同根词**：final（fin 终点 + **-al** …的 = 最终的）、finish（古法语 *finir* 完成 ← 拉丁 *finire* 结束）、finite（fin 界限 + **-ite** 有界限的→有限的）、infinite（**in-** 无 + finite 有限的 = 无限的）、semiconductor（**semi-** 半 + conductor 导体 = 半导体）、semitone（**semi-** 半 + tone 音 = 半音）。
- **前缀·后缀**：前缀 **semi-**（例：semicircle, semicolon）；形容词后缀 **-al**（例：natural, national）。
- **同义·反义**：同义 无；反义 final（决赛）。
- **变形**：形容词 → 无比较级（关系形容词，不作比较）；名词派生 → semi-finalist n. 半决赛选手。

### 20. final /ˈfaɪnl/ adj. 决赛
- **词根·渊源**：拉丁 **finis**（终点、界限）→ 拉丁 *finalis*（最终的）→ 古法语 *final* → 英语；本义“到了终点的”，引申为“最终的”，名词化为“决赛”。
- **同根词**：finish（古法语 *finir* 完成 ← 拉丁 *finire* 结束）、finite（fin 界限 + **-ite** 有界限的→有限的）、infinite（**in-** 无 + finite 有限的 = 无限的）、define（**de-** 彻底 + fin 界限 = 划定界限→定义）、confine（**con-** 共同 + fin 界限 = 限制在界限内→限制）、semi-final（**semi-** 半 + final 决赛 = 半决赛）。
- **前缀·后缀**：形容词后缀 **-al**（例：natural, formal）；否定前缀 **in-**（例：infinite, incorrect）。
- **同义·反义**：同义 last（最后的）, ultimate（最终的）；反义 first（最初的）, initial（开始的）。
- **变形**：形容词 → 无比较级（关系形容词，不作比较）；名词 → 复数：finals；副词派生 → finally adv. 最后；动词派生 → finalize v. 最终确定。

### 21. badminton /ˈbædmɪntən/ n. 羽毛球运动
- **词根·渊源**：源自英国格洛斯特郡的庄园 **Badminton House**（巴德明顿庄园），1873 年在此首次举行现代羽毛球表演赛，运动因庄园得名；庄园名源自古英语 *Badimyncgtun*（Baduhelm 家族的地产），属专名，非普通词根构词。
- **同根词**：无（专有地名来源，无常用同根词）。
- **前缀·后缀**：无前后缀（单纯词，专名来源）。
- **同义·反义**：同义 无；反义 无。
- **变形**：名词 → 复数：不可数（作运动名称）；名词派生 → badminton player n. 羽毛球运动员。

### 22. stress /strɛs/ n. 精神压力；心理负担；紧张
- **词根·渊源**：拉丁 **strictus**（拉紧的，*stringere* 拉紧的过去分词）→ 古法语 *estrece*（狭窄、压迫）→ 中古英语 *stresse*（艰难、压迫）；本义“拉紧、压迫”，引申为“精神上的紧张、压力”。
- **同根词**：strict（拉丁 *strictus* 拉紧的→严格的）、restrict（**re-** 回 + strict 拉紧 = 拉回→限制）、constrict（**con-** 共同 + strict 拉紧 = 一起拉紧→收缩）、district（**dis-** 分开 + strict 拉紧 = 划出的区域→地区）、strain（拉丁 *stringere* 拉紧→拉紧、 strain 压力）、stringent（string 拉紧 + **-ent** …的→严格的）。
- **前缀·后缀**：无前后缀（单纯词，源自拉丁过去分词）。
- **同义·反义**：同义 pressure（压力）, tension（紧张）；反义 relaxation（放松）, calm（平静）。
- **变形**：名词 → 复数：stresses；动词 → 第三人称单数：stresses；过去式：stressed；过去分词：stressed；现在分词：stressing；形容词派生 → stressful adj. 有压力的；stressed adj. 感到压力的。
