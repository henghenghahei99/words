## 二、逐词说文解字

### 1. continent /ˈkɑntənənt/ n. 大陆；洲
- **词根·渊源**：拉丁 **continere**（连在一起、保持连续）→ 拉丁 *continens*（连续的、连成一片的）→ 古法语 → 英语；本义“连成一片的陆地”，引申为“大陆；洲”。
- **同根词**：contain（**con-** 共同 + tain 握持 = 握在一起→包含）、content（**con-** 完全 + tent 持有 = 全部持有→内容；满足的）、continue（**con-** 共同 + tin 保持 = 保持在一起→继续）、continuous（continue + **-ous** …的：连续的）、continent 本身即“连成一片的陆地”。
- **前缀·后缀**：前缀 **con-**（例：connect, contain）；形容词后缀 **-ent**（例：different, silent）。
- **同义·反义**：同义 mainland（大陆）, landmass（陆块）；反义 island（岛屿）, ocean（海洋）。
- **变形**：名词 → 复数：continents；形容词派生 → continental adj. 大陆的。

### 2. relation /riˈleɪʃən/ n. 关系；联系；交往
- **词根·渊源**：拉丁 **referre**（带回、关联）→ 拉丁 *relatio*（带回、报告）→ 古法语 *relation* → 英语；本义“带回、讲述”，引申为“把事物联系起来”→ 关系；联系。
- **同根词**：relate（**re-** 回 + lat 带 = 带回→使关联）、relative（relate + **-ive** …的：相关的→相对的；亲戚）、relatively（relative + **-ly** …地：相对地）、correlate（**cor-** 共同 + relate 关联 = 相互关联）、translate（**trans-** 转移 + lat 带 = 带过去→翻译）。
- **前缀·后缀**：前缀 **re-**（例：return, recall）；名词后缀 **-tion**（例：action, station）。
- **同义·反义**：同义 connection（联系）, association（关联）；反义 separation（分离）, independence（独立）。
- **变形**：名词 → 复数：relations；动词派生 → relate v. 使关联；形容词派生 → relational adj. 关系的；副词派生 → relatively adv. 相对地。

### 3. passenger /ˈpæsənʤər/ n. 乘客；旅客
- **词根·渊源**：古法语 **passager**（过路的人）→ 古法语 *passagier*（旅行者）→ 英语；源自 *passage*（通行、旅程），本义“赶路的人”，引申为“乘客；旅客”。
- **同根词**：passage（pass 通过 + **-age** 名词后缀 = 通行→通道；旅程）、pass（通过）、passable（pass + **-able** 可…的：可通过的）、passport（pass 通过 + port 港口 = 过港证件→护照）、passenger 本身即“赶路的人”。
- **前缀·后缀**：无前缀；名词后缀 **-er**（例：driver, teacher）。
- **同义·反义**：同义 traveler（旅行者）, rider（乘车者）；反义 driver（司机）, crew（乘务员）。
- **变形**：名词 → 复数：passengers；无比较级。

### 4. ton /tən/ n. 吨
- **词根·渊源**：古英语 **tunne**（大桶）→ 中古英语 *tonne*（大桶、容量单位）→ 英语；本义“大酒桶”，后指桶的容量，再定为重量单位“吨”。
- **同根词**：tun（大桶）、tonnage（ton + **-age** 名词后缀 = 吨位）、tonne（公吨，同源变体）。
- **前缀·后缀**：无前后缀（单纯词）。
- **同义·反义**：同义 tonne（公吨）；反义 无。
- **变形**：名词 → 复数：tons；形容词派生 → tonnage n. 吨位。

### 5. pepper /ˈpɛpər/ n. 胡椒粉
- **词根·渊源**：拉丁 **piper**（胡椒）→ 古英语 *pipor* → 英语；源自希腊 *peperi*，本义“胡椒”，引申为“胡椒粉”。
- **同根词**：peppery（pepper + **-y** …的：胡椒味的）、peppercorn（pepper + corn 粒 = 胡椒粒）、pepper 本身即“胡椒”。
- **前缀·后缀**：无前缀；名词后缀 **-er**（例：water, teacher）。
- **同义·反义**：同义 spice（香料）；反义 无。
- **变形**：名词 → 复数：peppers（作“胡椒粉”义时不可数）；形容词派生 → peppery adj. 胡椒味的。

### 6. giraffe /ʤəræf/ n. 长颈鹿
- **词根·渊源**：阿拉伯语 **zarāfa**（长颈鹿）→ 意大利语 *giraffa* → 法语 *girafe* → 英语；本义即“长颈鹿”，词源存疑（一说源自非洲语言）。
- **同根词**：无常用同根词。
- **前缀·后缀**：无前后缀（单纯词）。
- **同义·反义**：同义 无；反义 无。
- **变形**：名词 → 复数：giraffes；无比较级。

### 7. period /ˈpɪriəd/ n. 阶段；时期
- **词根·渊源**：希腊 **periodos**（绕行一圈）→ 拉丁 *periodus* → 古法语 → 英语；本义“绕行一圈的时间”，引申为“阶段；时期”。
- **同根词**：periodic（period + **-ic** …的：周期的）、periodical（periodic + **-al** …的：周期的；期刊）、periodically（periodical + **-ly** …地：周期性地）。
- **前缀·后缀**：前缀 **peri-**（例：perimeter, periscope）；名词后缀 **-od**（例：method, episode）。
- **同义·反义**：同义 phase（阶段）, stage（时期）；反义 无。
- **变形**：名词 → 复数：periods；形容词派生 → periodic adj. 周期的；副词派生 → periodically adv. 周期性地。

### 8. rope /roʊp/ n. 粗绳；绳索
- **词根·渊源**：古英语 **rāp**（绳）→ 中古英语 *rope* → 英语；本义“绳”，引申为“粗绳；绳索”。
- **同根词**：ropy（rope + **-y** …的：绳状的）、roped（rope + **-ed** …的：用绳围的）。
- **前缀·后缀**：无前后缀（单纯词）。
- **同义·反义**：同义 cord（细绳）, cable（缆绳）；反义 无。
- **变形**：名词 → 复数：ropes；形容词派生 → ropy adj. 绳状的。

### 9. nationality /ˌnæʃəˈnælɪti/ n. 国籍
- **词根·渊源**：拉丁 **nasci**（出生）→ 拉丁 *natio*（出生、民族）→ 法语 *nationalité* → 英语；本义“出生的归属”，引申为“国籍”。
- **同根词**：nation（nat 出生 + **-ion** 名词后缀 = 出生之地→民族；国家）、national（nation + **-al** …的：国家的）、native（nat 出生 + **-ive** …的：出生的→本地的）、nature（nat 出生 + **-ure** 名词后缀 = 天生→自然）、international（**inter-** 之间 + national 国家的 = 国际的）。
- **前缀·后缀**：前缀 **inter-**（例：international, interact）；名词后缀 **-ity**（例：activity, reality）。
- **同义·反义**：同义 citizenship（公民身份）；反义 无。
- **变形**：名词 → 复数：nationalities；形容词派生 → national adj. 国家的；副词派生 → nationally adv. 全国性地。

### 10. rapid /ˈræpɪd/ adj. 瞬间的；短时间内发生的
- **词根·渊源**：拉丁 **rapere**（抢夺、迅速带走）→ 拉丁 *rapidus*（迅速的）→ 法语 *rapide* → 英语；本义“迅速夺取的”，引申为“瞬间的；短时间内发生的”。
- **同根词**：rapidly（rapid + **-ly** …地：迅速地）、rapidity（rapid + **-ity** 名词后缀 = 迅速）、rape（rap 抢夺 + **-e** = 抢夺→强奸）、rapture（rapt 被夺 + **-ure** 名词后缀 = 被夺走心神→狂喜）。
- **前缀·后缀**：无前缀；形容词后缀 **-id**（例：valid, solid）。
- **同义·反义**：同义 quick（快的）, swift（迅速的）；反义 slow（慢的）, gradual（逐渐的）。
- **变形**：形容词 → 比较级：more rapid；最高级：most rapid；副词派生 → rapidly adv. 迅速地；名词派生 → rapidity n. 迅速。

### 11. citizen /ˈsɪtɪzən/ n. 居民；市民
- **词根·渊源**：拉丁 **civis**（公民）→ 古法语 *citeain*（市民）→ 英语；源自 *cité*（城市），本义“城里人”，引申为“居民；市民”。
- **同根词**：city（cit 城市 + **-y** 名词后缀 = 城市）、civic（civ 公民 + **-ic** …的：公民的）、civil（civ 公民 + **-il** …的：公民的→文明的）、civilize（civil + **-ize** 使…化：使文明）、civilization（civilize + **-ation** 名词后缀 = 文明）。
- **前缀·后缀**：无前缀；名词后缀 **-en**（例：chicken, wooden）。
- **同义·反义**：同义 resident（居民）, inhabitant（居民）；反义 foreigner（外国人）, alien（外侨）。
- **变形**：名词 → 复数：citizens；名词派生 → citizenship n. 公民身份。

### 12. regret /rɪˈgrɛt/ v. 感到遗憾，惋惜
- **词根·渊源**：古法语 **regreter**（哀悼、怀念）→ 英语；可能源自古诺斯 *grāta*（哭泣），本义“为失去而哭”，引申为“感到遗憾，惋惜”；词源存疑。
- **同根词**：regretful（regret + **-ful** 充满…的：遗憾的）、regrettable（regret + **-able** 可…的：令人遗憾的）、regrettably（regrettable + **-ly** …地：遗憾地）。
- **前缀·后缀**：前缀 **re-**（例：return, recall）；无后缀。
- **同义·反义**：同义 lament（哀叹）, rue（后悔）；反义 rejoice（欣喜）, celebrate（庆祝）。
- **变形**：动词 → 第三人称单数：regrets；过去式：regretted；过去分词：regretted；现在分词：regretting；名词派生 → regret n. 遗憾；形容词派生 → regretful adj. 遗憾的；副词派生 → regretfully adv. 遗憾地。

### 13. absent /ˈæbsənt/ adj. 不存在，缺少
- **词根·渊源**：拉丁 **absens**（不在场的）→ 拉丁 *absentem* → 古法语 → 英语；由 **ab-**（离开）+ **esse**（存在）构成，本义“离开存在”，引申为“不存在，缺少”。
- **同根词**：absence（ab 离开 + sence 存在 = 不在→缺席）、present（**pre-** 在前 + sent 存在 = 在场→现在的；礼物）、essence（ess 存在 + **-ence** 名词后缀 = 本质）、essential（essence + **-ial** …的：本质的）。
- **前缀·后缀**：前缀 **ab-**（例：abnormal, absorb）；形容词后缀 **-ent**（例：different, silent）。
- **同义·反义**：同义 missing（缺少的）, lacking（缺乏的）；反义 present（在场的）, existing（存在的）。
- **变形**：形容词 → 无比较级（关系形容词，不作比较）；名词派生 → absence n. 缺席；副词派生 → absently adv. 心不在焉地。

### 14. estimate /ˈɛstəˌmeɪt/ v. 估计；估算
- **词根·渊源**：拉丁 **aestimare**（评价、估价）→ 拉丁 *aestimatus* → 法语 *estimer* → 英语；本义“评定价值”，引申为“估计；估算”。
- **同根词**：estimation（estimate + **-ion** 名词后缀 = 估计；评价）、estimable（estimate + **-able** 可…的：可估计的→值得尊敬的）、esteem（同源，e 出 + steem 估价 = 看重→尊敬）。
- **前缀·后缀**：无前缀；动词后缀 **-ate**（例：create, calculate）。
- **同义·反义**：同义 calculate（计算）, evaluate（评估）；反义 无。
- **变形**：动词 → 第三人称单数：estimates；过去式：estimated；过去分词：estimated；现在分词：estimating；名词派生 → estimation n. 估计；形容词派生 → estimable adj. 可估计的。

### 15. enthusiastic /ɪnˌθuziˈæstɪk/ adj. 热情的
- **词根·渊源**：希腊 **enthous**（神灵附体）→ 希腊 *enthousiastikos* → 拉丁 → 英语；本义“神灵附体的”，引申为“充满激情的→热情的”。
- **同根词**：enthusiasm（en 在内 + thus 神 + **-iasm** 名词后缀 = 神在内→热情）、enthusiast（enthusiasm + **-ast** 人 = 热情的人）、enthusiastically（enthusiastic + **-ally** …地：热情地）。
- **前缀·后缀**：前缀 **en-**（例：enable, enjoy）；形容词后缀 **-ic**（例：basic, historic）。
- **同义·反义**：同义 passionate（热情的）, eager（热切的）；反义 indifferent（冷淡的）, apathetic（冷漠的）。
- **变形**：形容词 → 比较级：more enthusiastic；最高级：most enthusiastic；名词派生 → enthusiasm n. 热情；副词派生 → enthusiastically adv. 热情地。

### 16. statue /ˈstæˌʧu/ n. 雕塑，雕像
- **词根·渊源**：拉丁 **statua**（立像）→ 拉丁 *statuere*（立起）→ 古法语 → 英语；本义“立起的东西”，引申为“雕塑，雕像”。
- **同根词**：statute（stat 立 + **-ute** 名词后缀 = 立下的规定→法规）、status（stat 立 + **-us** 名词后缀 = 站立的状态→地位）、station（stat 立 + **-ion** 名词后缀 = 站立之处→车站）、stable（sta 立 + **-ble** 能…的：稳固的）、establish（**e-** 出 + stabl 立 + **-ish** 动词后缀 = 使立起来→建立）。
- **前缀·后缀**：无前缀；名词后缀 **-ue**（例：value, tissue）。
- **同义·反义**：同义 sculpture（雕塑）, figure（人像）；反义 无。
- **变形**：名词 → 复数：statues；无比较级。

### 17. fellow /ˈfɛloʊ/ adj. 同类的，同伴的
- **词根·渊源**：古诺斯 **félagi**（合伙人）→ 古英语 *feolaga* → 英语；由 **fe**（钱财）+ **laga**（放置）构成，本义“共同出钱的人”，引申为“同类的，同伴的”。
- **同根词**：fellowship（fellow + **-ship** 名词后缀 = 伙伴关系→友谊）、fellow 本身即“同伴”。
- **前缀·后缀**：无前后缀（单纯词）。
- **同义·反义**：同义 companion（同伴）, peer（同辈）；反义 stranger（陌生人）, rival（对手）。
- **变形**：形容词 → 无比较级（关系形容词，不作比较）；名词派生 → fellowship n. 友谊；名词 → 复数：fellows。

### 18. set sail v. 起航
- **同义搭配**：set out / depart
- **反义搭配**：drop anchor

### 19. cultural tie  n. 文化纽带
- **同义搭配**：cultural bond / cultural connection
- **反义搭配**：cultural barrier（文化隔阂）

### 20. at home and abroad  prep. 在国内外
- **同义搭配**：domestically and internationally / in one's own country and overseas
- **反义搭配**：无
