## 二、逐词说文解字

### 1. dolphin /ˈdɒlfɪn/ n. 海豚
- **词根·渊源**：希腊 **delph-**（子宫，因海豚外形似子宫或因其胎生）→ 希腊 *delphis*（海豚）→ 拉丁 *delphinus* → 古法语 *daulphin* → 英语 dolphin；本义即“海豚”，词义未变。
- **同根词**：delphinium（希腊 delphin 海豚 + **-ium** 植物名词后缀 = 花形似海豚的植物→翠雀属）、dauphin（古法语 dauphin，原为法国东南部一贵族家族名，其纹章有海豚→法国王太子称号）。
- **前缀·后缀**：无前后缀（借词整体进入英语）。
- **同义·反义**：同义 sea dolphin（海豚，较少用）；反义 无。
- **变形**：名词 → 复数：dolphins；形容词派生 → dolphinlike adj. 似海豚的。

### 2. hen /hɛn/ n. 母鸡
- **词根·渊源**：古英语 **henn**（母鸡）→ 中古英语 *hen* → 英语 hen；与古高地德语 *henna* 同源，本义即“雌禽”，后专指母鸡。
- **同根词**：henhouse（hen 母鸡 + house 房子 = 鸡舍）、henpecked（hen 母鸡 + pecked 被啄的 = 被母鸡啄的→怕老婆的）、henparty（hen 母鸡 + party 聚会 = 女性聚会）。
- **前缀·后缀**：无前后缀（单纯词）。
- **同义·反义**：同义 chicken（母鸡，口语）, fowl（家禽）；反义 cock（公鸡）, rooster（公鸡）。
- **变形**：名词 → 复数：hens；形容词派生 → henlike adj. 似母鸡的。

### 3. blind /blaɪnd/ adj. 瞎的；失明的
- **词根·渊源**：古英语 **blind**（瞎的）→ 中古英语 *blind* → 英语 blind；与古诺斯语 *blindr*、德语 *blind* 同源，本义“瞎的”，引申为“盲目的、无判断力的”。
- **同根词**：blindness（blind 瞎的 + **-ness** 名词后缀 = 失明）、blindly（blind 瞎的 + **-ly** 副词后缀 = 盲目地）、blindfold（blind 瞎的 + fold 折叠 = 蒙住眼睛→蒙眼布）、colorblind（color 颜色 + blind 瞎的 = 色盲的）。
- **前缀·后缀**：形容词后缀 **-ness**（例：kindness, darkness）；副词后缀 **-ly**（例：quickly, happily）。
- **同义·反义**：同义 sightless（失明的）, unseeing（看不见的）；反义 sighted（有视力的）, seeing（能看见的）。
- **变形**：形容词 → 比较级：blinder；最高级：blindest；名词派生 → blindness n. 失明；副词派生 → blindly adv. 盲目地；动词派生 → blind v. 使失明。

### 4. wool /wʊl/ n.（羊等的）毛
- **词根·渊源**：古英语 **wull**（羊毛）→ 中古英语 *wol* → 英语 wool；与德语 *Wolle*、拉丁 *vellus*（羊毛）同源，本义即“羊毛”，引申为毛线、毛织品。
- **同根词**：woolen（wool 羊毛 + **-en** 形容词后缀 = 羊毛的）、woolly（wool 羊毛 + **-y** 形容词后缀 = 羊毛状的）、woolgathering（wool 羊毛 + gathering 收集 = 收集羊毛→心不在焉）。
- **前缀·后缀**：形容词后缀 **-en**（例：golden, wooden）；形容词后缀 **-y**（例：rainy, windy）。
- **同义·反义**：同义 fleece（羊毛）, yarn（毛线）；反义 无。
- **变形**：名词 → 复数：wools（作“羊毛”义时不可数）；形容词派生 → woolen adj. 羊毛的；woolly adj. 羊毛状的。

### 5. receptionist /rɪˈsepʃənɪst/ n. 接待员
- **词根·渊源**：拉丁 **re-**（回）+ **capere**（拿、取）→ 拉丁 *receptio*（接收）→ 古法语 *reception* → 英语 reception（接待）+ **-ist**（人）→ receptionist；本义“接收的人”，引申为“接待员”。
- **同根词**：reception（**re-** 回 + cept 拿 + **-ion** 名词后缀 = 接收→接待）、receive（**re-** 回 + ceive 拿 = 接收）、receipt（**re-** 回 + ceipt 拿 = 收据）、recipient（**re-** 回 + cip 拿 + **-ient** 人 = 接收者）、capture（capt 拿 + **-ure** 名词后缀 = 捕获）。
- **前缀·后缀**：前缀 **re-**（例：return, review）；名词后缀 **-ist**（例：artist, scientist）；名词后缀 **-ion**（例：action, station）。
- **同义·反义**：同义 front-desk clerk（前台职员）, greeter（迎接员）；反义 无。
- **变形**：名词 → 复数：receptionists；名词派生 → reception n. 接待；动词派生 → receive v. 接收。

### 6. allow /əˈlaʊ/ v. 允许进入（或出去、通过）
- **词根·渊源**：拉丁 **ad-**（向）+ **laudare**（赞扬）→ 古法语 *alouer*（分配、准许）→ 中古英语 *allowen* → 英语 allow；本义“赞扬、认可”，引申为“准许、允许”。
- **同根词**：allowance（allow 允许 + **-ance** 名词后缀 = 允许→津贴）、allowable（allow 允许 + **-able** 可…的 = 可允许的）、disallow（**dis-** 不 + allow 允许 = 不允许）。
- **前缀·后缀**：前缀 **ad-**（例：advance, admit）；名词后缀 **-ance**（例：importance, distance）；形容词后缀 **-able**（例：readable, comfortable）。
- **同义·反义**：同义 permit（允许）, let（让）；反义 forbid（禁止）, prohibit（禁止）。
- **变形**：动词 → 第三人称单数：allows；过去式：allowed；过去分词：allowed；现在分词：allowing；名词派生 → allowance n. 津贴；形容词派生 → allowable adj. 可允许的。

### 7. apologize /əˈpɒlədʒaɪz/ v. 道歉
- **词根·渊源**：希腊 **apo-**（离开）+ **logos**（言辞、理由）→ 希腊 *apologia*（辩护辞）→ 拉丁 *apologia* → 英语 apology（道歉）+ **-ize**（动词后缀）→ apologize；本义“为…辩护”，后转为“道歉”。
- **同根词**：apology（**apo-** 离开 + log 言辞 + **-y** 名词后缀 = 辩护→道歉）、apologetic（apology 道歉 + **-etic** 形容词后缀 = 道歉的）、apologist（**apo-** 离开 + log 言辞 + **-ist** 人 = 辩护者）、logic（log 言辞 + **-ic** 学科 = 逻辑）。
- **前缀·后缀**：前缀 **apo-**（例：apostle, apocalypse）；动词后缀 **-ize**（例：realize, organize）；名词后缀 **-y**（例：history, victory）。
- **同义·反义**：同义 say sorry（说对不起）, make an apology（道歉）；反义 无。
- **变形**：动词 → 第三人称单数：apologizes；过去式：apologized；过去分词：apologized；现在分词：apologizing；名词派生 → apology n. 道歉；形容词派生 → apologetic adj. 道歉的。

### 8. asleep /əˈsliːp/ adj. 睡着
- **词根·渊源**：古英语 **on**（在…上）+ **slǣpan**（睡觉）→ 中古英语 *aslepe* → 英语 asleep；本义“在睡眠中”，引申为“睡着的”。
- **同根词**：sleep（古英语 slǣpan 睡觉 = 睡眠）、sleepy（sleep 睡眠 + **-y** 形容词后缀 = 困倦的）、sleepless（sleep 睡眠 + **-less** 无 = 失眠的）、oversleep（**over-** 过度 + sleep 睡 = 睡过头）。
- **前缀·后缀**：前缀 **a-**（例：awake, alive）；形容词后缀 **-y**（例：happy, angry）；形容词后缀 **-less**（例：hopeless, careless）。
- **同义·反义**：同义 sleeping（睡着的）, dormant（休眠的）；反义 awake（醒着的）, alert（警觉的）。
- **变形**：形容词 → 无比较级（表语形容词，不作比较）；名词派生 → sleep n. 睡眠；形容词派生 → sleepy adj. 困倦的。

### 9. smoke /sməʊk/ n. 烟
- **词根·渊源**：古英语 **smoca**（烟）→ 中古英语 *smoke* → 英语 smoke；与德语 *Schmauch* 同源，本义即“烟”，引申为“吸烟”。
- **同根词**：smoky（smoke 烟 + **-y** 形容词后缀 = 冒烟的）、smoker（smoke 吸烟 + **-er** 人 = 吸烟者）、smokeless（smoke 烟 + **-less** 无 = 无烟的）、smokescreen（smoke 烟 + screen 幕 = 烟幕）。
- **前缀·后缀**：形容词后缀 **-y**（例：cloudy, dusty）；名词后缀 **-er**（例：teacher, worker）；形容词后缀 **-less**（例：fearless, endless）。
- **同义·反义**：同义 fume（烟气）, vapor（蒸汽）；反义 无。
- **变形**：名词 → 复数：smokes（作“烟”义时不可数）；动词 → 第三人称单数：smokes；过去式：smoked；过去分词：smoked；现在分词：smoking；形容词派生 → smoky adj. 冒烟的；名词派生 → smoker n. 吸烟者。

### 10. fireman /ˈfaɪəmən/ n. 消防队员
- **词根·渊源**：古英语 **fȳr**（火）+ **mann**（人）→ 中古英语 *fireman* → 英语 fireman；本义“火的人”，引申为“消防队员”。
- **同根词**：fire（古英语 fȳr 火 = 火）、firefighter（fire 火 + fighter 战斗者 = 消防员）、fireplace（fire 火 + place 地方 = 壁炉）、firework（fire 火 + work 作品 = 烟花）。
- **前缀·后缀**：无前后缀（复合词）。
- **同义·反义**：同义 firefighter（消防员）, fireman（消防队员）；反义 无。
- **变形**：名词 → 复数：firemen；形容词派生 → firemanlike adj. 似消防员的。

### 11. type /taɪp/ n. 类型；种类
- **词根·渊源**：希腊 **typos**（印记、模型）→ 拉丁 *typus* → 古法语 *type* → 英语 type；本义“印记、模型”，引申为“类型、种类”。
- **同根词**：typical（type 类型 + **-ical** 形容词后缀 = 典型的）、typist（type 打字 + **-ist** 人 = 打字员）、typewriter（type 打字 + writer 书写者 = 打字机）、prototype（**proto-** 原始 + type 模型 = 原型）。
- **前缀·后缀**：形容词后缀 **-ical**（例：historical, musical）；名词后缀 **-ist**（例：pianist, tourist）；前缀 **proto-**（例：protocol, protozoa）。
- **同义·反义**：同义 kind（种类）, sort（类别）；反义 无。
- **变形**：名词 → 复数：types；动词 → 第三人称单数：types；过去式：typed；过去分词：typed；现在分词：typing；形容词派生 → typical adj. 典型的；名词派生 → typist n. 打字员。

### 12. search-and-rescue /ˈsɜːtʃ ənd ˈreskju/ n. 搜索救援
- **同义搭配**：search and rescue / rescue operation
- **反义搭配**：无

### 13. service /ˈsɜːvɪs/ n. 服务
- **词根·渊源**：拉丁 **servus**（奴隶）→ 拉丁 *servitium*（奴役、服务）→ 古法语 *servise* → 英语 service；本义“奴仆的职责”，引申为“服务”。
- **同根词**：serve（拉丁 servus 奴隶 → 古法语 servir 服务 = 服务）、servant（serve 服务 + **-ant** 人 = 仆人）、servile（serv 奴仆 + **-ile** 形容词后缀 = 奴性的）、servitude（serv 奴仆 + **-itude** 状态 = 奴役）。
- **前缀·后缀**：名词后缀 **-ice**（例：justice, notice）；名词后缀 **-ant**（例：assistant, merchant）；形容词后缀 **-ile**（例：fragile, mobile）。
- **同义·反义**：同义 assistance（帮助）, help（帮助）；反义 无。
- **变形**：名词 → 复数：services；动词 → 第三人称单数：services；过去式：serviced；过去分词：serviced；现在分词：servicing；形容词派生 → serviceable adj. 可用的。

### 14. disaster /dɪˈzɑːstə(r)/ n. 灾难；灾害
- **词根·渊源**：拉丁 **dis-**（坏、相反）+ **astrum**（星）→ 意大利语 *disastro* → 古法语 *desastre* → 英语 disaster；本义“星位不吉”，古人认为灾祸由凶星所致，引申为“灾难”。
- **同根词**：disastrous（disaster 灾难 + **-ous** 形容词后缀 = 灾难性的）、astrology（astro 星 + **-logy** 学科 = 占星术）、astronomy（astro 星 + **-nomy** 法则 = 天文学）、asterisk（aster 星 + **-isk** 小 = 小星号）。
- **前缀·后缀**：前缀 **dis-**（例：disagree, disappear）；形容词后缀 **-ous**（例：famous, dangerous）；名词后缀 **-logy**（例：biology, geology）。
- **同义·反义**：同义 calamity（灾难）, catastrophe（大灾难）；反义 blessing（幸事）, fortune（好运）。
- **变形**：名词 → 复数：disasters；形容词派生 → disastrous adj. 灾难性的；副词派生 → disastrously adv. 灾难性地。

### 15. guest /ɡest/ n. 旅客；房客
- **词根·渊源**：古诺斯语 **gestr**（客人）→ 古英语 *gæst* → 中古英语 *gest* → 英语 guest；与拉丁 *hostis*（陌生人、敌人）同源，本义“陌生人”，引申为“客人、旅客”。
- **同根词**：guesthouse（guest 客人 + house 房子 = 宾馆）、guestroom（guest 客人 + room 房间 = 客房）、host（拉丁 hostis 陌生人 = 主人，与 guest 同源）、hostel（host 主人 + **-el** 小 = 旅舍）。
- **前缀·后缀**：无前后缀（单纯词）。
- **同义·反义**：同义 visitor（访客）, lodger（房客）；反义 host（主人）, hostess（女主人）。
- **变形**：名词 → 复数：guests；形容词派生 → guestlike adj. 似客人的。

### 16. team /tiːm/ n. 组；班
- **词根·渊源**：古英语 **tēam**（一队牲口）→ 中古英语 *team* → 英语 team；本义“套在一起拉车的牲口”，引申为“一组人、团队”。
- **同根词**：teammate（team 队 + mate 伙伴 = 队友）、teamwork（team 队 + work 工作 = 协作）、teamster（team 队 + **-ster** 人 = 赶牲口的人→卡车司机）。
- **前缀·后缀**：名词后缀 **-ster**（例：gangster, youngster）。
- **同义·反义**：同义 group（组）, squad（小队）；反义 individual（个人）。
- **变形**：名词 → 复数：teams；动词 → 第三人称单数：teams；过去式：teamed；过去分词：teamed；现在分词：teaming；名词派生 → teamwork n. 协作。

### 17. transport /ˈtrænspɔːt/ v. 运输；运送
- **词根·渊源**：拉丁 **trans-**（穿过）+ **portare**（携带）→ 拉丁 *transportare* → 古法语 *transporter* → 英语 transport；本义“带过去”，引申为“运输”。
- **同根词**：portable（port 携带 + **-able** 可…的 = 可携带的）、porter（port 携带 + **-er** 人 = 搬运工）、export（**ex-** 出 + port 携带 = 出口）、import（**im-** 入 + port 携带 = 进口）、transportation（transport 运输 + **-ation** 名词后缀 = 运输）。
- **前缀·后缀**：前缀 **trans-**（例：translate, transfer）；前缀 **ex-**（例：exit, export）；前缀 **im-**（例：import, impossible）；名词后缀 **-ation**（例：information, education）。
- **同义·反义**：同义 carry（运送）, convey（传送）；反义 无。
- **变形**：动词 → 第三人称单数：transports；过去式：transported；过去分词：transported；现在分词：transporting；名词派生 → transportation n. 运输；形容词派生 → transportable adj. 可运输的。

### 18. guard /ɡɑːd/ v. 守卫；保卫
- **词根·渊源**：古法语 **garder**（看守）→ 中古英语 *garden* → 英语 guard；与古高地德语 *wartēn*（看守）同源，本义“看守”，引申为“守卫、保卫”。
- **同根词**：guardian（guard 守卫 + **-ian** 人 = 监护人）、guardsman（guard 守卫 + **-sman** 人 = 卫兵）、safeguard（safe 安全 + guard 守卫 = 保护）、regard（**re-** 回 + gard 看守 = 注视→关心）。
- **前缀·后缀**：名词后缀 **-ian**（例：musician, librarian）；前缀 **re-**（例：return, review）。
- **同义·反义**：同义 protect（保护）, defend（保卫）；反义 attack（攻击）, abandon（放弃）。
- **变形**：动词 → 第三人称单数：guards；过去式：guarded；过去分词：guarded；现在分词：guarding；名词 → 复数：guards；名词派生 → guardian n. 监护人；形容词派生 → guarded adj. 谨慎的。

### 19. honey /ˈhʌni/ n. 蜂蜜
- **词根·渊源**：古英语 **hunig**（蜂蜜）→ 中古英语 *honi* → 英语 honey；与德语 *Honig* 同源，原始日耳曼语 *hunagam*，更早词源存疑。
- **同根词**：honeybee（honey 蜂蜜 + bee 蜂 = 蜜蜂）、honeycomb（honey 蜂蜜 + comb 梳状格 = 蜂巢）、honeymoon（honey 蜂蜜 + moon 月 = 蜜月）、honeydew（honey 蜂蜜 + dew 露 = 蜜露）。
- **前缀·后缀**：无前后缀（单纯词）。
- **同义·反义**：同义 nectar（花蜜）；反义 无。
- **变形**：名词 → 复数：honeys（作“蜂蜜”义时不可数）；形容词派生 → honeyed adj. 甜如蜜的；honey-like adj. 蜜状的。

### 20. material /məˈtɪəriəl/ n. 材料；原料
- **词根·渊源**：拉丁 **materia**（物质、材料）→ 晚期拉丁 *materialis*（物质的）→ 古法语 *material* → 英语 material；本义“构成事物的物质”，引申为“材料；原料”。
- **同根词**：matter（源自拉丁 materia 物质→事情）、materialism（material 物质的 + **-ism** 主义 = 唯物主义）、materialize（material 物质的 + **-ize** 使…化 = 使具体化）、immaterial（**im-** 不 + material 物质的 = 非物质的）、maternal（拉丁 mater 母亲 + **-al** …的 = 母亲的）。
- **前缀·后缀**：形容词后缀 **-ial**（例：social, special）；名词后缀 **-ism**（例：realism, tourism）。
- **同义·反义**：同义 substance（物质）, stuff（材料）；反义 无。
- **变形**：名词 → 复数：materials；形容词派生 → material adj. 物质的；副词派生 → materially adv. 物质上；动词派生 → materialize v. 实现。

### 21. either /ˈaɪðə(r)/ adv. 也
- **词根·渊源**：古英语 **ǣgther**（两者中的每一个）→ 中古英语 *either* → 英语 either；由 *ā*（永远）+ *hwæther*（两者中哪一个）构成，本义“两者中任一个”，副词义“也”用于否定句。
- **同根词**：neither（**n-** 不 + either 两者之一 = 两者都不）、whether（与 either 同出 *hwæther* 两者中哪一个→是否）。
- **前缀·后缀**：无前后缀（单纯词）。
- **同义·反义**：同义 also（也，用于肯定句）, too（也）；反义 neither（也不）。
- **变形**：副词 → 无比较级；形容词派生 → either adj. 两者中任一的；代词派生 → either pron. 两者之一；连词派生 → either conj. 或者。

### 22. shark /ʃɑːk/ n. 鲨鱼
- **词根·渊源**：词源存疑；一说源自中古荷兰语 *schurck* 或古英语 *scuric*（一种鱼），16 世纪英语文献始见 shark 指鲨鱼，确切来源不明。
- **同根词**：sharklike（shark 鲨鱼 + **-like** 像…的 = 鲨鱼般的）、shark-infested（shark 鲨鱼 + infested 侵扰的 = 鲨鱼出没的）。
- **前缀·后缀**：无前后缀（单纯词）。
- **同义·反义**：同义 无；反义 无。
- **变形**：名词 → 复数：sharks；形容词派生 → sharklike adj. 鲨鱼般的。

### 23. scared /skeəd/ adj. 害怕；恐惧
- **词根·渊源**：古诺斯语 **skirra**（使害怕）→ 中古英语 *skerren* → 英语 scare（惊吓）+ **-ed**（…的）= scared；本义“被惊吓的”，引申为“害怕；恐惧”。
- **同根词**：scare（scare 惊吓→使害怕）、scary（scare 惊吓 + **-y** …的 = 可怕的）、scaring（scare + **-ing** 令人害怕的）。
- **前缀·后缀**：形容词后缀 **-ed**（例：tired, excited）；名词后缀 **-y**（例：rainy, windy）。
- **同义·反义**：同义 afraid（害怕的）, frightened（受惊的）；反义 brave（勇敢的）, fearless（无畏的）。
- **变形**：形容词 → 比较级：more scared；最高级：most scared；名词派生 → scare n. 惊吓；动词派生 → scare v. 使害怕；副词派生 → scaredly adv. 害怕地。

### 24. grey /ɡreɪ/ adj. 灰色的
- **词根·渊源**：古英语 **grǣg**（灰色）→ 中古英语 *grei* → 英语 grey（美式拼作 gray）；与德语 *grau* 同源，原始日耳曼语 *grēwaz*，本义“灰色的”。
- **同根词**：greyish（grey 灰色 + **-ish** 略带…的 = 浅灰色的）、greyness（grey + **-ness** 名词后缀 = 灰色）、greyhound（grey 灰色 + hound 猎犬 = 灵缇，词源存疑）。
- **前缀·后缀**：形容词后缀 **-ish**（例：reddish, childish）；名词后缀 **-ness**（例：kindness, darkness）。
- **同义·反义**：同义 gray（灰色的，美式拼写）；反义 无。
- **变形**：形容词 → 比较级：greyer；最高级：greyest；名词派生 → grey n. 灰色；greyness n. 灰色；副词派生 → greyly adv. 灰暗地。

### 25. somewhere /ˈsʌmweə(r)/ adv. 在某处；到某处
- **词根·渊源**：古英语 **sum**（某个）+ **hwǣr**（何处）→ 中古英语 *somwhere* → 英语 somewhere；复合词，本义“在某个地方”，引申为“在某处；到某处”。
- **同根词**：somewhere（some 某个 + where 何处 = 在某处）、anywhere（any 任何 + where 何处 = 在任何地方）、everywhere（every 每个 + where 何处 = 到处）、nowhere（no 没有 + where 何处 = 无处）、wherever（where 何处 + **-ever** 无论 = 无论哪里）。
- **前缀·后缀**：无前后缀（复合词）。
- **同义·反义**：同义 someplace（在某处）；反义 nowhere（无处）。
- **变形**：副词 → 无比较级；名词派生 → somewhere n. 某个地方。

### 26. probably /ˈprɒbəbli/ adv. 很可能；大概
- **词根·渊源**：拉丁 **probare**（证明、检验）→ 拉丁 *probabilis*（可证明的）→ 古法语 *probable* → 英语 probable（很可能的）+ **-ly**（…地）= probably；本义“可证明地”，引申为“很可能；大概”。
- **同根词**：probable（prob 证明 + **-able** 可…的 = 很可能的）、probability（probable + **-ity** 名词后缀 = 可能性）、probation（prob 检验 + **-ation** 名词后缀 = 试用期）、probe（prob 检验→探查）、approve（**ap-** 向 + prove 证明 = 赞成）。
- **前缀·后缀**：副词后缀 **-ly**（例：quickly, happily）；形容词后缀 **-able**（例：comfortable, readable）。
- **同义·反义**：同义 likely（很可能）, perhaps（也许）；反义 improbably（不大可能地）, unlikely（不太可能）。
- **变形**：副词 → 无比较级；形容词派生 → probable adj. 很可能的；名词派生 → probability n. 可能性。

### 27. source /sɔːs/ n. 来源；出处
- **词根·渊源**：拉丁 **surgere**（升起）的过去分词 *sursus* → 古法语 *sourse*（泉源）→ 英语 source；本义“水涌出之处”，引申为“来源；出处”。
- **同根词**：resource（**re-** 再 + source 源泉 = 可再取的资源）、surge（拉丁 surgere 升起→汹涌）、resurge（**re-** 再 + surge 涌起 = 再起）、insurgent（**in-** 向上 + surg 升起 + **-ent** …的 = 起义的）。
- **前缀·后缀**：名词前缀 **re-**（例：resource, review）；名词后缀 **-ent**（例：student, resident）。
- **同义·反义**：同义 origin（起源）, root（根源）；反义 无。
- **变形**：名词 → 复数：sources；动词派生 → source v. 采购；形容词派生 → sourceable adj. 可溯源的。

### 28. sometime /ˈsʌmtaɪm/ adv. 在某时
- **词根·渊源**：古英语 **sum**（某个）+ **tīma**（时间）→ 中古英语 *somtime* → 英语 sometime；复合词，本义“在某个时间”，引申为“在某时”。
- **同根词**：sometimes（some 某个 + times 次数 = 有时）、sometime（some + time 时间 = 在某时）、timely（time 时间 + **-ly** …的 = 及时的）、timeless（time + **-less** 无…的 = 永恒的）、overtime（**over-** 超过 + time 时间 = 超时）。
- **前缀·后缀**：无前后缀（复合词）。
- **同义·反义**：同义 once（曾经）；反义 never（从不）。
- **变形**：副词 → 无比较级；形容词派生 → sometime adj. 以前的。

### 29. extinct /ɪkˈstɪŋkt/ adj. 已灭绝的；绝种的
- **词根·渊源**：拉丁 **exstinguere**（熄灭）的过去分词 *exstinctus* → 英语 extinct；**ex-**（出）+ *stinguere*（刺、熄灭），本义“被熄灭的”，引申为“已灭绝的；绝种的”。
- **同根词**：extinction（extinct + **-ion** 名词后缀 = 灭绝）、extinguish（**ex-** 出 + stingu 熄灭 + **-ish** 动词后缀 = 熄灭）、distinct（**dis-** 分开 + stinct 刺 = 刺分开→清楚的）、instinct（**in-** 内 + stinct 刺 = 内在冲动→本能）、stimulate（拉丁 stimulare 刺→刺激）。
- **前缀·后缀**：前缀 **ex-**（例：exit, export）；名词后缀 **-ion**（例：action, nation）。
- **同义·反义**：同义 died out（灭绝的）；反义 extant（现存的）, living（活着的）。
- **变形**：形容词 → 无比较级；名词派生 → extinction n. 灭绝；形容词派生 → extinctive adj. 使灭绝的。

### 30. effort /ˈefət/ n. 艰难的尝试；试图
- **词根·渊源**：拉丁 **fortis**（强）→ 古法语 *esforz*（力量、努力）→ 英语 effort；**ef-**（= ex- 出）+ *fortis* 强，本义“使出力量”，引申为“艰难的尝试；试图”。
- **同根词**：effortless（effort 努力 + **-less** 无…的 = 不费力的）、fortify（fort 强 + **-ify** 使…化 = 加强）、fortitude（fort 强 + **-itude** 名词后缀 = 坚毅）、comfort（**com-** 共同 + fort 强 = 使强大→安慰）、force（fort 强→力量）。
- **前缀·后缀**：前缀 **ef-**（例：effect, efficient）；名词后缀 **-less**（例：careless, hopeless）。
- **同义·反义**：同义 attempt（尝试）, endeavor（努力）；反义 ease（轻松）。
- **变形**：名词 → 复数：efforts；形容词派生 → effortless adj. 不费力的；副词派生 → effortlessly adv. 不费力地。
