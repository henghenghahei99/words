## 二、逐词说文解字

### 1. recognize /ˈrɛkəgˌnaɪz/ v. 认出；辨别出
- **词根·渊源**：拉丁 **re-**（再）+ **cognoscere**（知道）→ 古法语 *reconoistre* → 英语；本义“再次知道”，引申为“认出、辨别出”。
- **同根词**：recognition（**re-** 再 + **cognit-** 知道 + **-ion** 名词后缀 = 认出→承认）、cognitive（**cognit-** 知道 + **-ive** …的 = 认知的）、cognize（**cogn-** 知道 + **-ize** 动词后缀 = 认知）、diagnose（**dia-** 穿过 + **gnos-** 知道 = 彻底知道→诊断）、ignore（**i-** 不 + **gnor-** 知道 = 不知道→忽视）。
- **前缀·后缀**：前缀 **re-**（例：recall, return）；后缀 **-ize**（例：realize, modernize）。
- **同义·反义**：同义 identify（辨认）, distinguish（辨别）；反义 overlook（忽略）, miss（错过）。
- **变形**：动词 → 第三人称单数：recognizes；过去式：recognized；过去分词：recognized；现在分词：recognizing；名词派生 → recognition n. 认出、承认；形容词派生 → recognizable adj. 可认出的。

### 2. mirror /ˈmɪrər/ n. 镜子
- **词根·渊源**：拉丁 **mirari**（惊奇、注视）→ 古法语 *mirer*（注视）→ *mirour* → 英语；本义“注视之物”，引申为“镜子”。
- **同根词**：miracle（**mir-** 惊奇 + **-acle** 名词后缀 = 令人惊奇的事→奇迹）、mirage（**mir-** 注视 + **-age** 名词后缀 = 看到的东西→海市蜃楼）、admire（**ad-** 向 + **mir-** 惊奇 = 对…感到惊奇→钦佩）、marvel（拉丁 mirari 惊奇→奇迹→惊叹）。
- **前缀·后缀**：无前后缀（单纯词）。
- **同义·反义**：同义 glass（镜子）, looking glass（镜子）；反义 无。
- **变形**：名词 → 复数：mirrors；动词派生 → mirror v. 反映；形容词派生 → mirrored adj. 有镜子的。

### 3. gun /gən/ n. 枪；炮
- **词根·渊源**：中古英语 *gunne*，可能源自中世纪英语女性名 *Gunilda*（一种大炮的名称）→ 英语；本义“大炮”，后泛指“枪、炮”（词源存疑）。
- **同根词**：gunner（gun + **-er** 人 = 炮手）、gunpowder（gun + powder 粉末 = 火药）、handgun（hand 手 + gun = 手枪）、machine gun（machine 机器 + gun = 机枪）。
- **前缀·后缀**：无前后缀（单纯词）。
- **同义·反义**：同义 firearm（火器）, weapon（武器）；反义 无。
- **变形**：名词 → 复数：guns；动词派生 → gun v. 开枪射击；名词派生 → gunner n. 炮手。

### 4. handsome /ˈhænsəm/ adj. 漂亮的；英俊的
- **词根·渊源**：中古英语 **hand**（手）+ **-some**（…的）→ 英语；本义“手边的、方便的”，引申为“得体的”，再引申为“漂亮的、英俊的”。
- **同根词**：handy（hand + **-y** …的 = 手边的→方便的）、handful（hand + **-ful** 满 = 一把）、handbag（hand + bag 包 = 手提包）、handshake（hand + shake 摇 = 握手）。
- **前缀·后缀**：后缀 **-some**（例：troublesome, awesome）。
- **同义·反义**：同义 attractive（有吸引力的）, good-looking（好看的）；反义 ugly（丑的）, unattractive（不吸引人的）。
- **变形**：形容词 → 比较级：handsomer；最高级：handsomest；副词派生 → handsomely adv. 英俊地、大方地；名词派生 → handsomeness n. 英俊。

### 5. force /fɔrs/ v. 强迫；迫使
- **词根·渊源**：拉丁 **fortis**（强壮的）→ 俗拉丁 *fortia* → 古法语 *force* → 英语；本义“力量”，引申为“用力量迫使”。
- **同根词**：forceful（force + **-ful** 充满…的 = 有力的）、forceless（force + **-less** 无…的 = 无力的）、fortify（**fort-** 强 + **-ify** 使… = 使坚固→加强）、fortress（**fort-** 强 + **-ress** 名词后缀 = 坚固之地→堡垒）、effort（**ef-** 出 + **fort-** 力 = 使出力量→努力）。
- **前缀·后缀**：无前后缀（单纯词）。
- **同义·反义**：同义 compel（强迫）, oblige（迫使）；反义 allow（允许）, permit（准许）。
- **变形**：动词 → 第三人称单数：forces；过去式：forced；过去分词：forced；现在分词：forcing；名词派生 → force n. 力量；形容词派生 → forceful adj. 有力的。

### 6. corn /kɔrn/ n. 谷物；谷粒
- **词根·渊源**：古英语 **corn**（谷物、种子）→ 英语；与拉丁 **granum**（谷粒）同出 PIE *gre-no-*；本义“谷粒”，引申为“谷物”。
- **同根词**：cornfield（corn + field 田 = 玉米田）、cornflakes（corn + flakes 薄片 = 玉米片）、popcorn（pop 爆 + corn = 爆米花）、cornmeal（corn + meal 粉 = 玉米粉）。
- **前缀·后缀**：无前后缀（单纯词）。
- **同义·反义**：同义 grain（谷物）, cereal（谷类）；反义 无。
- **变形**：名词 → 复数：corns（作“谷物”义时不可数）；形容词派生 → corny adj. 谷物的、陈腐的。

### 7. direction /dɪˈrɛkʃɪn/ n. 方向；方位
- **词根·渊源**：拉丁 **dirigere**（引导、使直）→ **direct-**（引导）+ **-ion**（名词后缀）→ 英语；本义“引导的行为”，引申为“方向、方位”。
- **同根词**：direct（**di-** 使 + **rect-** 直 = 使直→直接的、指导）、director（direct + **-or** 人 = 指导者→导演）、directly（direct + **-ly** 副词后缀 = 直接地）、correct（**cor-** 加强 + **rect-** 直 = 使直→改正）、erect（**e-** 出 + **rect-** 直 = 竖直的→竖立）。
- **前缀·后缀**：后缀 **-ion**（例：action, nation）。
- **同义·反义**：同义 way（方向）, orientation（方位）；反义 无。
- **变形**：名词 → 复数：directions；形容词派生 → directional adj. 方向的；副词派生 → directionally adv. 方向地。

### 8. progress /ˈprɑˌgrɛs/ n. 前进；行进
- **词根·渊源**：拉丁 **pro-**（向前）+ **gradi**（走）→ **progressus** → 英语；本义“向前走”，引申为“前进、进步”。
- **同根词**：progressive（progress + **-ive** …的 = 进步的）、aggress（**ag-** 向 + **gress-** 走 = 走向→侵略）、congress（**con-** 一起 + **gress-** 走 = 走到一起→集会）、grade（拉丁 gradus 步→等级）、gradual（**grad-** 步 + **-ual** …的 = 逐步的）。
- **前缀·后缀**：前缀 **pro-**（例：promote, produce）。
- **同义·反义**：同义 advance（前进）, improvement（进步）；反义 regress（倒退）, decline（衰退）。
- **变形**：名词 → 复数：progresses（作“进步”义时不可数）；动词派生 → progress v. 前进；形容词派生 → progressive adj. 进步的。

### 9. value /ˈvælju/ v. 重视；珍视
- **词根·渊源**：拉丁 **valere**（有价值、强壮）→ 古法语 *value* → 英语；本义“价值”，引申为“重视、珍视”。
- **同根词**：valuable（value + **-able** 能…的 = 有价值的）、valueless（value + **-less** 无…的 = 无价值的）、evaluate（**e-** 出 + value 价值 + **-ate** 动词后缀 = 估出价值→评估）、valid（**val-** 强壮 + **-id** …的 = 有效的）、valor（**val-** 强壮 + **-or** 名词后缀 = 勇猛）。
- **前缀·后缀**：无前后缀（单纯词）。
- **同义·反义**：同义 treasure（珍视）, cherish（珍爱）；反义 despise（轻视）, neglect（忽视）。
- **变形**：动词 → 第三人称单数：values；过去式：valued；过去分词：valued；现在分词：valuing；名词派生 → value n. 价值；形容词派生 → valuable adj. 有价值的。

### 10. official /əˈfɪʃəl/ adj. 官方的
- **词根·渊源**：拉丁 **officium**（职责、服务）→ **offici-**（职责）+ **-al**（…的）→ 英语；本义“与职责有关的”，引申为“官方的”。
- **同根词**：office（**of-** 向 + **fic-** 做 = 做事的地方→办公室）、officer（office + **-er** 人 = 官员）、officially（official + **-ly** 副词后缀 = 官方地）、efficient（**ef-** 出 + **fic-** 做 + **-ient** …的 = 做出成效的→高效的）、suffice（**suf-** 在下 + **fic-** 做 = 在下面做→足够）。
- **前缀·后缀**：后缀 **-al**（例：natural, national）。
- **同义·反义**：同义 formal（正式的）, authorized（授权的）；反义 unofficial（非官方的）, informal（非正式的）。
- **变形**：形容词 → 无比较级（关系形容词，不作比较）；副词派生 → officially adv. 官方地；名词派生 → official n. 官员。

### 11. throw /θroʊ/ v. 抛；扔
- **词根·渊源**：古英语 **þrāwan**（扭、转）→ 中古英语 *throwen* → 英语；本义“扭转”，引申为“抛、扔”。
- **同根词**：thrower（throw + **-er** 人 = 投掷者）、overthrow（**over-** 过度 + throw = 推翻）、throwaway（throw + away 离开 = 一次性用品）。
- **前缀·后缀**：无前后缀（单纯词）。
- **同义·反义**：同义 toss（抛）, cast（投掷）；反义 catch（接住）, hold（握住）。
- **变形**：动词 → 第三人称单数：throws；过去式：threw；过去分词：thrown；现在分词：throwing；名词派生 → throw n. 投掷。

### 12. law /lɔ/ n. 法律；法规
- **词根·渊源**：古英语 **lagu**（法律）→ 中古英语 *lawe* → 英语；与古诺斯语 *lag*（放置、规定）同源；本义“被规定之事”，引申为“法律”。
- **同根词**：lawful（law + **-ful** 充满…的 = 合法的）、lawless（law + **-less** 无…的 = 无法无天的）、lawyer（law + **-yer** 人 = 律师）、outlaw（**out-** 出 + law = 法律之外→歹徒）。
- **前缀·后缀**：无前后缀（单纯词）。
- **同义·反义**：同义 rule（规则）, regulation（法规）；反义 无。
- **变形**：名词 → 复数：laws；形容词派生 → lawful adj. 合法的；副词派生 → lawfully adv. 合法地。

### 13. punish /ˈpənɪʃ/ v. 处罚；惩罚
- **词根·渊源**：拉丁 **poena**（惩罚）→ 古法语 *punir* → **puniss-** → 英语；本义“施加惩罚”，引申为“处罚、惩罚”。
- **同根词**：punishment（punish + **-ment** 名词后缀 = 惩罚）、punishable（punish + **-able** 能…的 = 可惩罚的）、penalty（**pen-** 惩罚 + **-alty** 名词后缀 = 处罚）、penal（**pen-** 惩罚 + **-al** …的 = 刑罚的）、pain（拉丁 poena 惩罚→疼痛）。
- **前缀·后缀**：后缀 **-ish**（例：finish, establish）。
- **同义·反义**：同义 penalize（处罚）, discipline（惩戒）；反义 reward（奖励）, forgive（原谅）。
- **变形**：动词 → 第三人称单数：punishes；过去式：punished；过去分词：punished；现在分词：punishing；名词派生 → punishment n. 惩罚；形容词派生 → punishable adj. 可惩罚的。

### 14. blog /blɔg/ n. 博客
- **词根·渊源**：英语 **web**（网络）+ **log**（日志）缩合为 *weblog* → 再缩为 **blog** → 英语；本义“网络日志”，即“博客”。
- **同根词**：blogger（blog + **-er** 人 = 博客作者）、blogging（blog + **-ing** 名词后缀 = 写博客）、weblog（web 网络 + log 日志 = 网络日志）、vlog（video 视频 + log 日志 = 视频博客）。
- **前缀·后缀**：无前后缀（缩合词）。
- **同义·反义**：同义 weblog（网络日志）, online journal（网络日志）；反义 无。
- **变形**：名词 → 复数：blogs；动词派生 → blog v. 写博客；名词派生 → blogger n. 博客作者。

### 15. publish /ˈpəblɪʃ/ v. 发表；公布
- **词根·渊源**：拉丁 **publicare**（使公开）→ 古法语 *publier* → **publiss-** → 英语；本义“使公开”，引申为“发表、公布”。
- **同根词**：public（**publ-** 公众 + **-ic** …的 = 公众的）、publication（**publ-** 公众 + **-ation** 名词后缀 = 出版）、publicity（public + **-ity** 名词后缀 = 公开→宣传）、republic（**re-** 事物 + public 公众 = 公共之事→共和国）、publisher（publish + **-er** 人 = 出版者）。
- **前缀·后缀**：后缀 **-ish**（例：finish, punish）。
- **同义·反义**：同义 announce（宣布）, release（发布）；反义 suppress（压制）, conceal（隐瞒）。
- **变形**：动词 → 第三人称单数：publishes；过去式：published；过去分词：published；现在分词：publishing；名词派生 → publication n. 出版；publisher n. 出版者。

### 16. shoulder /ˈʃoʊldər/ n. 肩膀；肩胛
- **词根·渊源**：古英语 **sculdor**（肩）→ 中古英语 *schuldre* → 英语；本义“肩”，引申为“肩膀、肩胛”。
- **同根词**：shoulder blade（shoulder + blade 片 = 肩胛骨）、shoulder strap（shoulder + strap 带 = 肩带）、cold shoulder（cold 冷 + shoulder = 冷淡对待）。
- **前缀·后缀**：无前后缀（单纯词）。
- **同义·反义**：同义 无；反义 无。
- **变形**：名词 → 复数：shoulders；动词派生 → shoulder v. 承担；形容词派生 → shouldered adj. 有肩的。

### 17. rare /rɛr/ adj. 稀罕的；珍贵的
- **词根·渊源**：拉丁 **rarus**（稀疏的）→ 古法语 *rare* → 英语；本义“稀疏的”，引申为“稀罕的、珍贵的”。
- **同根词**：rarely（rare + **-ly** 副词后缀 = 很少地）、rareness（rare + **-ness** 名词后缀 = 稀罕）、rarity（**rar-** 稀罕 + **-ity** 名词后缀 = 稀有）。
- **前缀·后缀**：无前后缀（单纯词）。
- **同义·反义**：同义 scarce（稀少的）, uncommon（不常见的）；反义 common（常见的）, abundant（丰富的）。
- **变形**：形容词 → 比较级：rarer；最高级：rarest；副词派生 → rarely adv. 很少地；名词派生 → rarity n. 稀有。

### 18. slim /slɪm/ adj. 苗条的；纤细的
- **词根·渊源**：荷兰语 **slim**（狡猾的、细的）→ 英语；本义“细的”，引申为“苗条的、纤细的”（词源存疑）。
- **同根词**：slimness（slim + **-ness** 名词后缀 = 苗条）、slimly（slim + **-ly** 副词后缀 = 苗条地）、slimmer（slim + **-er** 人 = 减肥者）。
- **前缀·后缀**：无前后缀（单纯词）。
- **同义·反义**：同义 slender（苗条的）, thin（瘦的）；反义 fat（胖的）, stout（粗壮的）。
- **变形**：形容词 → 比较级：slimmer；最高级：slimmest；动词派生 → slim v. 减肥；名词派生 → slimness n. 苗条。

### 19. alarmed /əˈlɑrmd/ adj. 担忧的
- **词根·渊源**：意大利语 **all'arme**（到武器旁）→ 法语 *alarme* → 英语 alarm，本义“警报、警钟”，引申为“使惊恐”；alarmed 为 alarm 的过去分词形容词，表示“被警报惊动的→担忧的”。
- **同根词**：alarm（**al** 到 + **arm** 武器 = 号召拿起武器→警报）、alarming（alarm + **-ing** …的：令人惊恐的）、alarmist（alarm + **-ist** 人：危言耸听者）。
- **前缀·后缀**：前缀 **al-**（例：almost, already）；后缀 **-ed**（例：excited, worried）。
- **同义·反义**：同义 worried（担忧的）, anxious（焦虑的）；反义 calm（平静的）, relaxed（放松的）。
- **变形**：形容词 → 比较级：more alarmed；最高级：most alarmed；名词派生 → alarm n. 警报；动词派生 → alarm v. 使惊恐；副词派生 → alarmedly adv. 惊恐地。

### 20. typical /ˈtɪpɪkəl/ adj. 典型的；有代表性的
- **词根·渊源**：希腊 **typos**（印记、模型）→ 拉丁 *typicus* → 法语 *typique* → 英语 typical，本义“符合模型的”，引申为“典型的、有代表性的”。
- **同根词**：type（typ 模型 + **-e** = 模型→类型）、typically（typical + **-ly** 地：典型地）、typify（typ 模型 + **-ify** 使成为：是……的典型）、typist（type + **-ist** 人：打字员）、prototype（**proto-** 最初 + type 模型 = 原型）。
- **前缀·后缀**：后缀 **-ical**（例：medical, logical）；前缀 **proto-**（例：prototype, protocol）。
- **同义·反义**：同义 representative（有代表性的）, characteristic（典型的）；反义 atypical（非典型的）, unusual（不寻常的）。
- **变形**：形容词 → 比较级：more typical；最高级：most typical；名词派生 → type n. 类型；副词派生 → typically adv. 典型地；动词派生 → typify v. 是……的典型。

### 21. thirsty /ˈθərsti/ adj. 渴的；口渴的
- **词根·渊源**：古英语 **þurst**（渴）→ 中古英语 *thurst* → 英语 thirst，加形容词后缀 **-y** 构成 thirsty，本义“有渴的”，引申为“渴望的”。
- **同根词**：thirst（þurst 渴 = 渴→渴望）、thirstily（thirsty + **-ly** 地：口渴地）、thirstiness（thirsty + **-ness** 性质：口渴）。
- **前缀·后缀**：后缀 **-y**（例：rainy, sleepy）；后缀 **-ness**（例：happiness, kindness）。
- **同义·反义**：同义 dry（口渴的）, parched（口干舌燥的）；反义 hydrated（水分充足的）, quenched（解渴的）。
- **变形**：形容词 → 比较级：thirstier；最高级：thirstiest；名词派生 → thirst n. 渴；副词派生 → thirstily adv. 口渴地。

### 22. sore /sɔr/ adj. 疼痛的；酸痛的
- **词根·渊源**：古英语 **sār**（疼痛的、悲伤的）→ 中古英语 *sor* → 英语 sore，本义“疼痛的”，引申为“酸痛的、恼火的”。
- **同根词**：sorely（sore + **-ly** 地：疼痛地→极其）、soreness（sore + **-ness** 性质：疼痛）、sorrow（与 sore 同源，sār 悲伤 + **-ow** = 悲伤）。
- **前缀·后缀**：后缀 **-ly**（例：sadly, badly）；后缀 **-ness**（例：sadness, illness）。
- **同义·反义**：同义 painful（疼痛的）, aching（酸痛的）；反义 painless（无痛的）, comfortable（舒适的）。
- **变形**：形容词 → 比较级：sorer；最高级：sorest；名词派生 → soreness n. 疼痛；副词派生 → sorely adv. 极其、疼痛地。
