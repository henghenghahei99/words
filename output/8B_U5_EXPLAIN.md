## 二、逐词说文解字

### 1. endangered /ɪnˈdendʒɚd/ adj. 濒危的
- **词根·渊源**：古法语 **danger**（权势、支配权）→ 古法语 *dangier*（损害、危险）→ 英语 danger（危险）+ 后缀 **-ed**（被置于……状态的）= 陷入危险境地的→濒危的。
- **同根词**：danger（本身即“危险”）、dangerous（danger + **-ous** 充满……的 = 充满危险的→危险的）、endanger（**en-** 使 + danger 危险 = 使陷入危险→危及）。
- **前缀·后缀**：前缀 **en-**（例：enable, enrich）；后缀 **-ed**（例：talented, wooded）。
- **同义·反义**：同义 threatened（受威胁的）, vulnerable（易受伤害的）；反义 safe（安全的）, secure（安全的）。
- **变形**：形容词 → 无比较级（关系形容词，不作比较）；名词派生 → endangeredness n. 濒危状态（罕用）；动词派生 → endanger v. 危及。

### 2. file /faɪl/ v. 档案；文件
- **词根·渊源**：拉丁 **filum**（线）→ 古法语 *fil*（线）→ 英语 file，本义“用线串起来保存的文件”，引申为“档案、文件”，动词义“归档”。
- **同根词**：filament（fila 线 + **-ment** 物 = 细线→灯丝）、profile（**pro-** 向前 + filum 线 = 勾出轮廓线→侧面像、简介）、filigree（fili 线 + granum 颗粒 = 金丝细工）。
- **前缀·后缀**：前缀 **pro-**（例：proceed, promote）；后缀 **-ment**（例：movement, argument）。
- **同义·反义**：同义 document（文件）, record（记录）；反义 无。
- **变形**：动词 → 第三人称单数：files；过去式：filed；过去分词：filed；现在分词：filing；名词 → 复数：files；名词派生 → filing n. 归档、锉屑。

### 3. giant panda /ˌdʒaɪənt ˈpændə/ n. 大熊猫；大猫熊
- **同义搭配**：panda（熊猫）/ giant panda bear（大熊猫）
- **反义搭配**：无

### 4. obligation /ˌɑːblɪˈɡeɪʃn/ n.（法律上或道义上的）义务，责任；恩惠
- **词根·渊源**：拉丁 **lig-**（捆绑，来自 *ligare*）→ 拉丁 *obligatio*（约束、义务）→ 古法语 *obligacion* → 英语 obligation，本义“被绑住的状态”，引申为“义务、责任”。
- **同根词**：oblige（**ob-** 向 + lig 捆绑 = 把（人）绑住→使有义务、施恩于）、ligament（liga 捆绑 + **-ment** 物 = 起捆绑作用的东西→韧带）、ally（**al-** 向 + lig 捆绑 = 绑在一起→结盟）、league（同源，绑在一起→联盟）、liable（lig 捆绑 + **-able** 可……的 = 可被约束的→有责任的）。
- **前缀·后缀**：前缀 **ob-**（例：obtain, observe）；后缀 **-ation**（例：information, education）。
- **同义·反义**：同义 duty（义务）, responsibility（责任）；反义 right（权利）, freedom（自由）。
- **变形**：名词 → 复数：obligations；形容词派生 → obligatory adj. 义务的；obligated adj. 有义务的；动词派生 → oblige v. 使有义务；副词派生 → obligatorily adv. 义务地。

### 5. wild /waɪld/ adj. 自然环境；野生状态；偏远地区，人烟稀少的地区
- **词根·渊源**：古英语 **wilde**（未驯化的、自然的）→ 中古英语 *wild* → 英语 wild，源自日耳曼语 *wilthja-*，本义“未开化的、未驯服的”，引申为“野生的、荒凉的”。
- **同根词**：wilderness（wilder 荒野 + **-ness** 状态 = 荒野、荒地）、bewilder（**be-** 使 + wilder 迷路 = 使迷失方向→使困惑）、wildlife（wild 野生的 + life 生命 = 野生动物）。
- **前缀·后缀**：前缀 **be-**（例：belittle, becalm）；后缀 **-ness**（例：kindness, darkness）。
- **同义·反义**：同义 untamed（未驯服的）, natural（自然的）；反义 tame（驯服的）, domestic（家养的）。
- **变形**：形容词 → 比较级：wilder；最高级：wildest；副词派生 → wildly adv. 野蛮地、疯狂地；名词派生 → wildness n. 野生、荒凉。

### 6. bamboo /ˌbæmˈbuː/ n. 竹子
- **词根·渊源**：荷兰语 **bamboe**（竹子）→ 葡萄牙语 *bambu* → 英语 bamboo，最终源自马来语 *bambu*，本义即“竹子”，为借词，无构词分析。
- **同根词**：无（借词，无同根派生词）。
- **前缀·后缀**：无前后缀（单纯词）。
- **同义·反义**：同义 无；反义 无。
- **变形**：名词 → 复数：bamboos；形容词派生 → bamboo adj. 竹制的（作定语）。

### 7. adult /əˈdʌlt/ n. 成年人；成年动物
- **词根·渊源**：拉丁 **adultus**（已长大的，*adolescere* 的过去分词）→ 拉丁 *adultum* → 英语 adult，本义“已长成的人”，引申为“成年人”。
- **同根词**：adolescent（**ad-** 向 + al 生长 + **-escent** 正在……的 = 正在成长的→青少年）、adolescence（adolesc 成长 + **-ence** 状态 = 青春期）、adult（本身即“已长成”）。
- **前缀·后缀**：前缀 **ad-**（例：advance, admit）；后缀 **-escent**（例：convalescent, effervescent）。
- **同义·反义**：同义 grown-up（成年人）, mature person（成熟的人）；反义 child（儿童）, minor（未成年人）。
- **变形**：名词 → 复数：adults；形容词 → 无比较级（关系形容词）；形容词派生 → adult adj. 成年的；adulthood n. 成年期。

### 8. weight /weɪt/ n. 体重；重量
- **词根·渊源**：古英语 **gewiht**（重量，来自 *wegan* 称重）→ 中古英语 *weight* → 英语 weight，本义“称量所得之量”，即“重量”。
- **同根词**：weigh（本身即“称重”）、weighty（weight + **-y** 有……性质的 = 有分量的→重要的）、lightweight（light 轻 + weight 重量 = 轻量级的）、overweight（**over-** 超过 + weight 重量 = 超重的）。
- **前缀·后缀**：前缀 **over-**（例：overcome, overdo）；后缀 **-y**（例：rainy, healthy）。
- **同义·反义**：同义 mass（质量）, load（负荷）；反义 lightness（轻）, weightlessness（失重）。
- **变形**：名词 → 复数：weights；形容词派生 → weighty adj. 重的、重要的；weightless adj. 无重量的；动词派生 → weigh v. 称重。

### 9. kilogram /ˈkɪləɡræm/ n. 千克；公斤
- **词根·渊源**：希腊 **khilioi**（一千）→ 法语 *kilo*（千）+ 希腊 **gramma**（小重量）→ 法语 *kilogramme* → 英语 kilogram，本义“一千克”，即“千克”。
- **同根词**：kilometer（kilo 千 + meter 米 = 千米）、kilowatt（kilo 千 + watt 瓦特 = 千瓦）、gram（本身即“克”）、milligram（**milli-** 千分之一 + gram 克 = 毫克）。
- **前缀·后缀**：前缀 **kilo-**（例：kilometer, kilowatt）；后缀 **-gram**（例：telegram, diagram）。
- **同义·反义**：同义 kilo（千克）, kg（千克）；反义 无。
- **变形**：名词 → 复数：kilograms；形容词派生 → kilogram adj. 千克的（作定语）。

### 10. population /ˌpɑ:pjuˈleɪʃn/ n. 某领域的生物，族群；人口；人口数量
- **词根·渊源**：拉丁 **populus**（人民）→ 拉丁 *populatio*（居民、人口）→ 英语 population，本义“居住在同一地区的人群”，引申为“人口、族群”。
- **同根词**：popular（popul 人民 + **-ar** 属于……的 = 属于人民的→受欢迎的）、populate（popul 人民 + **-ate** 使…… = 使有人居住→居住于）、populous（popul 人民 + **-ous** 多……的 = 人口稠密的）、public（同源，属于人民的→公共的）。
- **前缀·后缀**：前缀 **-ate**（例：activate, educate）；后缀 **-ation**（例：information, education）。
- **同义·反义**：同义 inhabitants（居民）, residents（居民）；反义 无。
- **变形**：名词 → 复数：populations；动词派生 → populate v. 居住于；形容词派生 → populous adj. 人口稠密的；popular adj. 受欢迎的。

### 11. behaviour /bɪˈheɪvjər/ n. 行为，举止，态度；活动方式，特点，特性；习惯
- **词根·渊源**：古英语 **behabban**（持有、控制，**be-** 加强 + habban 持有）→ 中古英语 *behaven*（举止得体）→ 英语 behaviour，本义“自我控制的方式”，引申为“行为、举止”。
- **同根词**：behave（**be-** 加强 + have 持有 = 控制自己→举止得体）、behavioural（behaviour + **-al** ……的 = 行为的）、misbehave（**mis-** 坏 + behave 举止 = 举止不端）、misbehaviour（mis- 坏 + behaviour 行为 = 不良行为）。
- **前缀·后缀**：前缀 **be-**（例：belong, become）、**mis-**（例：mistake, misunderstand）；后缀 **-al**（例：natural, musical）。
- **同义·反义**：同义 conduct（行为）, manner（举止）；反义 无。
- **变形**：名词 → 复数：behaviours；形容词派生 → behavioural adj. 行为的；动词派生 → behave v. 举止、表现。

### 12. birth /bɜ:rθ/ n. 出生；诞生
- **词根·渊源**：古诺斯语 **byrth**（出生，与 *bera* 携带、生育同源）→ 中古英语 *birth* → 英语 birth，本义“被生出”，即“出生、诞生”。
- **同根词**：bear（本身即“生育、携带”）、birthday（birth 出生 + day 日 = 生日）、birthplace（birth 出生 + place 地方 = 出生地）、rebirth（**re-** 再 + birth 出生 = 再生、复兴）。
- **前缀·后缀**：前缀 **re-**（例：return, rebuild）；后缀 无（单纯词加复合成分）。
- **同义·反义**：同义 nativity（出生）, delivery（分娩）；反义 death（死亡）, demise（逝世）。
- **变形**：名词 → 复数：births；形容词派生 → natal adj. 出生的（同源异形）；动词派生 → bear v. 生育。

### 13. patch /pætʃ/ n. 色斑；斑点
- **词根·渊源**：中古英语 **pacche**（补丁、小块）→ 英语 patch，词源存疑（一说与古法语 *pieche* 碎片有关），本义“小块补丁”，引申为“小块色斑、斑点”。
- **同根词**：patchy（patch + **-y** 有……性质的 = 斑驳的、不完整的）、patchwork（patch 补丁 + work 工作 = 拼缝物）。
- **前缀·后缀**：后缀 **-y**（例：cloudy, dirty）。
- **同义·反义**：同义 spot（斑点）, blotch（斑块）；反义 无。
- **变形**：名词 → 复数：patches；动词 → 第三人称单数：patches；过去式：patched；过去分词：patched；现在分词：patching；形容词派生 → patchy adj. 斑驳的。

### 14. shoulder /ˈʃəʊldə(r)/ n. 肩，肩膀
- **词根·渊源**：古英语 **sculdor**（肩）→ 中古英语 *shulder* → 英语 shoulder，源自日耳曼语 *skuldr-*，本义即“肩膀”，词源存疑（一说与“盾牌”有关）。
- **同根词**：shoulder（本身即“肩”）、shoulder blade（shoulder 肩 + blade 片 = 肩胛骨）。
- **前缀·后缀**：无前后缀（单纯词）。
- **同义·反义**：同义 无；反义 无。
- **变形**：名词 → 复数：shoulders；动词 → 第三人称单数：shoulders；过去式：shouldered；过去分词：shouldered；现在分词：shouldering；动词派生 → shoulder v. 承担、用肩推。

### 15. central /ˈsentrəl/ adj. 中心的；中央的
- **词根·渊源**：希腊 **kentron**（中心点、刺）→ 拉丁 *centrum*（中心）→ 英语 centre/center（中心）+ 后缀 **-al**（……的）= 中心的、中央的。
- **同根词**：center（本身即“中心”）、centralize（central + **-ize** 使……化 = 使集中→集中管理）、eccentric（**ec-** 出 + centr 中心 + **-ic** ……的 = 偏离中心的→古怪的）、concentrate（**con-** 共同 + centr 中心 + **-ate** 使…… = 使聚向中心→集中）。
- **前缀·后缀**：前缀 **ec-**（例：ecstasy, eclipse）、**con-**（例：connect, combine）；后缀 **-al**（例：natural, formal）。
- **同义·反义**：同义 middle（中间的）, main（主要的）；反义 peripheral（外围的）, marginal（边缘的）。
- **变形**：形容词 → 无比较级（关系形容词）；名词派生 → center n. 中心；centrality n. 中心性；动词派生 → centralize v. 集中；副词派生 → centrally adv. 在中心。

### 16. menu /ˈmenjuː/ n. 菜单
- **词根·渊源**：拉丁 **minutus**（小的，*minuere* 的过去分词）→ 法语 *menu*（细小的、详细的）→ 英语 menu，本义“详细的小清单”，引申为“菜单”。
- **同根词**：minute（min 小 + **-ute** = 微小的→分钟）、diminish（**di-** 向下 + min 小 + **-ish** 使…… = 使变小→减少）、minimum（min 小 + **-imum** 最…… = 最小值）、minor（本身即“较小的”）。
- **前缀·后缀**：前缀 **di-**（例：divide, divert）；后缀 **-ute**（例：minute, acute）。
- **同义·反义**：同义 list（清单）, bill of fare（菜单）；反义 无。
- **变形**：名词 → 复数：menus；形容词派生 → menu adj. 菜单的（作定语）。

### 17. fur /fɜː(r)/ n.（某些动物的）浓密的软毛
- **词根·渊源**：古法语 **forre / fuerre**（鞘、衬里）→ 中古英语 *fur* → 英语 fur，本义“用作衬里的毛皮”，引申为“动物的软毛”。
- **同根词**：furry（fur + **-y** 有……的 = 毛茸茸的）、furrier（fur + **-ier** 从事……的人 = 皮货商）。
- **前缀·后缀**：后缀 **-y**（例：sunny, hairy）、**-ier**（例：cashier, soldier）。
- **同义·反义**：同义 pelt（毛皮）, coat（皮毛）；反义 无。
- **变形**：名词 → 复数：furs；形容词派生 → furry adj. 毛茸茸的；furrier n. 皮货商。

### 18. cruel /ˈkruəl/ adj. 残酷的；残忍的
- **词根·渊源**：拉丁 **crudelis**（残忍的，与 *crudus* 生的、粗糙的同源）→ 古法语 *cruel* → 英语 cruel，本义“如生肉般粗野的”，引申为“残酷的、残忍的”。
- **同根词**：cruelty（cruel + **-ty** 性质 = 残忍、残酷）、crude（同源，生的、粗糙的→天然的、粗鲁的）、crudity（crud 粗糙 + **-ity** 性质 = 粗糙、粗鲁）。
- **前缀·后缀**：后缀 **-ty**（例：safety, loyalty）、**-ity**（例：activity, reality）。
- **同义·反义**：同义 brutal（残忍的）, savage（野蛮的）；反义 kind（善良的）, merciful（仁慈的）。
- **变形**：形容词 → 比较级：crueller（英）/ crueler（美）；最高级：cruellest（英）/ cruelest（美）；名词派生 → cruelty n. 残忍；副词派生 → cruelly adv. 残忍地。

### 19. organization /ˌɔːrɡənəˈzeɪʃn/ n. 组织，机构；组织工作，筹备工作
- **词根·渊源**：希腊 **organon**（工具、器官）→ 拉丁 *organum* → 古法语 *organe* → 英语 organ（器官；机构）；加动词后缀 **-ize** 构成 organize（组织），再加名词后缀 **-ation** 构成 organization，本义“使各部分像器官一样协同运作→组织、机构”。
- **同根词**：organ（organ 器官→机构）、organize（organ + **-ize** 使…化 = 使成器官般有序→组织）、organic（organ + **-ic** …的 = 器官的→有机的）、organism（organ + **-ism** 表实体 = 有机体）、organist（organ + **-ist** 人 = 管风琴演奏者）。
- **前缀·后缀**：动词后缀 **-ize**（例：realize, modernize）；名词后缀 **-ation**（例：information, education）。
- **同义·反义**：同义 institution（机构）, association（协会）；反义 无。
- **变形**：名词 → 复数：organizations；动词派生 → organize v. 组织；形容词派生 → organizational adj. 组织的；副词派生 → organizationally adv. 组织上地。

### 20. danger /ˈdeɪndʒər/ n. 危险；风险
- **词根·渊源**：拉丁 **dominus**（主人）→ 通俗拉丁 *dominiarium*（支配权）→ 古法语 *dangier*（权势、支配；为难）→ 英语 danger，本义“受人支配、身不由己的处境”→ 引申为“危险、风险”。
- **同根词**：dangerous（danger + **-ous** …的 = 充满危险的→危险的）、endanger（**en-** 使 + danger 危险 = 使陷入危险→危及）、dangerously（dangerous + **-ly** …地 = 危险地）。
- **前缀·后缀**：名词后缀 **-er**（例：teacher, worker）；形容词后缀 **-ous**（例：famous, nervous）；动词化前缀 **en-**（例：enable, enlarge）。
- **同义·反义**：同义 risk（风险）, hazard（危险）；反义 safety（安全）, security（安全）。
- **变形**：名词 → 复数：dangers；形容词派生 → dangerous adj. 危险的；副词派生 → dangerously adv. 危险地；动词派生 → endanger v. 危及。

### 21. face /feɪs/ n. 面临，遭遇；正视，面对
- **词根·渊源**：拉丁 **facies**（外形、面貌）→ 古法语 *face* → 英语 face，本义“脸、面容”；由“面对面”引申出动词义“面对、正视”，再引申为“面临、遭遇”。
- **同根词**：facial（face + **-ial** …的 = 面部的→面部的）、surface（**sur-** 在上 + face 面 = 表面）、interface（**inter-** 之间 + face 面 = 界面）、facade（法语 façade，face 同源 = 建筑物的正面→门面）、deface（**de-** 去除 + face 面 = 毁容→损毁外观）。
- **前缀·后缀**：名词后缀 **-ial**（例：social, official）；前缀 **sur-**（例：surround, surpass）、**inter-**（例：international, interact）、**de-**（例：decrease, defrost）。
- **同义·反义**：同义 confront（面对）, encounter（遭遇）；反义 avoid（避免）, evade（逃避）。
- **变形**：名词 → 复数：faces；动词 → 第三人称单数：faces；过去式：faced；过去分词：faced；现在分词：facing；形容词派生 → facial adj. 面部的；副词派生 → facially adv. 面部地。

### 22. Asian /ˈeɪʃn/ adj. 亚洲（人）的；亚洲人
- **词根·渊源**：希腊 **Asia**（亚细亚，原指小亚细亚）→ 拉丁 *Asia* → 英语 Asia；加形容词/名词后缀 **-an** 构成 Asian，本义“属于 Asia 的（人）”。
- **同根词**：Asia（Asia 地名→亚洲）、Asiatic（Asia + **-atic** …的 = 亚洲的，旧称）、Eurasia（**eur-** 欧洲 + Asia 亚洲 = 欧亚大陆）、Eurasian（Eurasia + **-an** …的 = 欧亚的）。
- **前缀·后缀**：形容词/名词后缀 **-an**（例：American, African）；组合前缀 **eur-**（例：Europe, Eurasian）。
- **同义·反义**：同义 无；反义 无。
- **变形**：形容词 → 无比较级（关系形容词，不作比较）；名词 → 复数：Asians；名词派生 → Asia n. 亚洲。

### 23. weigh /weɪ/ v. 重量有...；重；有...重
- **词根·渊源**：古英语 **wegan**（搬运、称量）→ 中古英语 *weien* → 英语 weigh；与 way（路）、wagon（车）同出 PIE *wegh-*（搬运），本义“搬运→用秤称→重量为”。
- **同根词**：weight（weigh + **-t** 名词后缀 = 称量之物→重量）、weighty（weight + **-y** …的 = 有分量的→重要的）、weighbridge（weigh 称 + bridge 桥 = 地磅）、weigh-in（weigh 称 + **in** 在内 = 赛前称重）。
- **前缀·后缀**：名词后缀 **-t**（例：gift, flight）；形容词后缀 **-y**（例：rainy, healthy）。
- **同义·反义**：同义 measure（测量）, consider（权衡）；反义 无。
- **变形**：动词 → 第三人称单数：weighs；过去式：weighed；过去分词：weighed；现在分词：weighing；名词派生 → weight n. 重量；形容词派生 → weighty adj. 重的、重要的。

### 24. in the wild
