## 二、逐词说文解字

### 1. gift /ɡɪft/ n. 礼物；礼品
- **词根·渊源**：古诺斯语 **gift / gipt**（赠品、礼物）→ 古英语 *gift*，与 give 同源，本义“所给之物”，引申为“礼物；天赋”。
- **同根词**：give（古英语 giefan 给→给予）、forgive（**for-** 完全 + give 给 = 完全给予→原谅）、given（give + **-en** 过去分词→给定的）。
- **前缀·后缀**：名词后缀 **-th** 变体（例：birth, death）；无前缀。
- **同义·反义**：同义 present（礼物）, donation（捐赠物）；反义 无。
- **变形**：名词 → 复数：gifts；形容词派生 → gifted adj. 有天赋的；副词派生 → gifted 无副词派生。

### 2. graduation /ˈɡrædʒuˈeʃən/ n. 毕业；毕业典礼
- **词根·渊源**：拉丁 **gradus**（步、级）→ 中世纪拉丁 *graduare*（授予学位）→ 英语 *graduation*，本义“按等级授予学位”，引申为“毕业；毕业典礼”。
- **同根词**：graduate（grad 步 + **-uate** 使……→毕业）、grade（grad 步→等级）、gradual（grad 步 + **-ual** 逐步的→逐渐的）、degrade（**de-** 向下 + grade 级 = 降级→贬低）、upgrade（**up-** 向上 + grade 级 = 升级→提升）。
- **前缀·后缀**：名词后缀 **-ation**（例：education, information）；前缀 **de-**（例：decline）、**up-**（例：uplift）。
- **同义·反义**：同义 commencement（毕业典礼）；反义 无。
- **变形**：名词 → 复数：graduations；动词派生 → graduate v. 毕业；形容词派生 → gradual adj. 逐渐的。

### 3. cent /sɛnt/ n. 分；分币；美分
- **词根·渊源**：拉丁 **centum**（一百）→ 古法语 *cent* → 英语 *cent*，本义“百分之一”，即一元的百分之一，引申为“分；美分”。
- **同根词**：century（cent 百 + **-ury** 集合名词 = 一百年→世纪）、percent（**per-** 每 + cent 百 = 每百→百分之）、centimeter（cent 百 + meter 米 = 百分之一米→厘米）、centipede（cent 百 + pede 足 = 百足→蜈蚣）。
- **前缀·后缀**：前缀 **per-**（例：permit）、**centi-**（例：centigram）；无后缀。
- **同义·反义**：同义 penny（便士）；反义 无。
- **变形**：名词 → 复数：cents；形容词派生 → cent 无常见形容词派生。

### 4. count /kaʊnt/ v. 计算（或清点）总数；计数，点数目；把……算入
- **词根·渊源**：拉丁 **computare**（计算）→ 古法语 *conter* → 英语 *count*，本义“逐一计算”，引申为“计数；把……算入”。
- **同根词**：account（**ac-** 加强 + count 计算 = 计算清楚→账户；解释）、discount（**dis-** 去除 + count 计算 = 扣除计算→折扣）、counter（count 计算 + **-er** 人/物 = 计数者→柜台）、compute（**com-** 一起 + put 计算 = 一起算→计算）、recount（**re-** 再 + count 计算 = 再数→重新计数）。
- **前缀·后缀**：前缀 **ac-**（例：accept）、**dis-**（例：dislike）、**re-**（例：rewrite）；名词后缀 **-er**（例：teacher）。
- **同义·反义**：同义 calculate（计算）, tally（清点）；反义 无。
- **变形**：动词 → 第三人称单数：counts；过去式：counted；过去分词：counted；现在分词：counting；名词派生 → counter n. 柜台；countable adj. 可数的；副词派生 → countlessly adv. 无数地。

### 5. afford /əˈfɔ:rd/ v. 承担得起（后果）；买得起；能做
- **词根·渊源**：古英语 **geforðian**（促进、提供）→ 中古英语 *aforthen*，**a-** 加强 + forth 向前，本义“向前提供”，引申为“承担得起；买得起”。
- **同根词**：ford（古英语 ford 渡口→涉水）、forth（向前→向前）、further（forth 的比较级→更远地）。
- **前缀·后缀**：前缀 **a-**（例：aloud, awake）；无后缀。
- **同义·反义**：同义 manage（设法做到）, bear（承担）；反义 无。
- **变形**：动词 → 第三人称单数：affords；过去式：afforded；过去分词：afforded；现在分词：affording；形容词派生 → affordable adj. 买得起的；副词派生 → affordably adv. 买得起地。

### 6. present /ˈpreznt , prɪˈzent/ v. 礼物
- **词根·渊源**：拉丁 **praesent-**（在场的）→ 古法语 *present* → 英语 *present*，本义“呈现在眼前的”，名词引申为“礼物”，动词引申为“呈现；赠送”。
- **同根词**：presence（**pre-** 在前 + sens 存在 = 在场→出席）、presentation（present + **-ation** 名词→呈现；演示）、represent（**re-** 再 + present 呈现 = 再呈现→代表）、absent（**ab-** 离开 + sens 存在 = 不在场→缺席的）。
- **前缀·后缀**：前缀 **pre-**（例：prepare）、**re-**（例：return）、**ab-**（例：abnormal）；名词后缀 **-ation**（例：information）。
- **同义·反义**：同义 gift（礼物）, offering（赠品）；反义 无。
- **变形**：名词 → 复数：presents；动词 → 第三人称单数：presents；过去式：presented；过去分词：presented；现在分词：presenting；形容词派生 → presentable adj. 拿得出手的；副词派生 → presently adv. 目前。

### 7. knee /niː/ n. 膝；膝盖
- **词根·渊源**：古英语 **cnēow**（膝）→ 中古英语 *knee*，与拉丁 *genu*（膝）同出 PIE *genu-*，本义“膝”，词义未变。
- **同根词**：kneel（knee 膝 + **-el** 动词后缀 = 用膝→跪下）、kneecap（knee 膝 + cap 帽 = 膝盖骨→护膝）、genuflect（拉丁 genu 膝 + flect 弯 = 屈膝→跪拜）。
- **前缀·后缀**：无前缀；动词后缀 **-el**（例：kneel）。
- **同义·反义**：同义 无；反义 无。
- **变形**：名词 → 复数：knees；动词派生 → kneel v. 跪下；形容词派生 → kneed adj. 有膝的。

### 8. sign /saɪn/ n. 标识；招牌；标牌
- **词根·渊源**：拉丁 **signum**（记号、标志）→ 古法语 *signe* → 英语 *sign*，本义“记号”，引申为“标识；招牌；标牌”。
- **同根词**：signal（sign 记号 + **-al** 名词/形容词 = 信号→信号）、signature（sign 记号 + **-ature** 名词 = 签下的记号→签名）、design（**de-** 向下 + sign 记号 = 做记号→设计）、assign（**as-** 向 + sign 记号 = 做记号分配→分配）、significant（sign 记号 + **-ificant** 有意义的→重要的）。
- **前缀·后缀**：前缀 **de-**（例：decline）、**as-**（例：assist）；名词后缀 **-al**（例：arrival）、**-ature**（例：creature）。
- **同义·反义**：同义 mark（标记）, symbol（符号）；反义 无。
- **变形**：名词 → 复数：signs；动词 → 第三人称单数：signs；过去式：signed；过去分词：signed；现在分词：signing；名词派生 → signal n. 信号；形容词派生 → significant adj. 重要的。

### 9. goods /ɡʊdz/ n. 商品；货品；货物
- **词根·渊源**：古英语 **gōd**（好的、财产）→ 中古英语 *goods*，本义“好的东西、财产”，复数形式专指“商品；货物”。
- **同根词**：good（古英语 god 好的→好的）、goodness（good + **-ness** 名词 = 好→善良）、goodly（good + **-ly** 形容词 = 好的→相当大的）。
- **前缀·后缀**：无前缀；名词后缀 **-s** 复数（例：books）、**-ness**（例：kindness）。
- **同义·反义**：同义 merchandise（商品）, wares（货物）；反义 无。
- **变形**：名词 → 复数：goods（只用复数）；形容词派生 → good adj. 好的；副词派生 → well adv. 好地。

### 10. search /sɜːrtʃ/ n. 搜寻；查找；寻找
- **词根·渊源**：拉丁 **circare**（绕圈走）→ 古法语 *cerchier* → 英语 *search*，本义“绕圈寻找”，引申为“搜寻；查找”。
- **同根词**：research（**re-** 再 + search 搜寻 = 反复搜寻→研究）、circle（拉丁 circ 圈 + **-le** = 圆圈→圆）、circus（拉丁 circ 圈 + **-us** = 圆圈→马戏团）。
- **前缀·后缀**：前缀 **re-**（例：return）；无后缀。
- **同义·反义**：同义 hunt（搜寻）, pursuit（追寻）；反义 无。
- **变形**：名词 → 复数：searches；动词 → 第三人称单数：searches；过去式：searched；过去分词：searched；现在分词：searching；名词派生 → researcher n. 研究者；形容词派生 → searching adj. 搜寻的。

### 11. chain /tʃeɪn/ n. 链子；（用链条）束缚
- **词根·渊源**：拉丁 **catena**（链子）→ 古法语 *chaeine* → 英语 *chain*，本义“链子”，动词引申为“用链条束缚”。
- **同根词**：concatenate（**con-** 一起 + caten 链 + **-ate** 动词 = 连成链→连接）、catenary（caten 链 + **-ary** 名词 = 链状曲线→悬链线）。
- **前缀·后缀**：前缀 **con-**（例：connect）；无后缀。
- **同义·反义**：同义 bond（束缚）, shackle（镣铐）；反义 无。
- **变形**：名词 → 复数：chains；动词 → 第三人称单数：chains；过去式：chained；过去分词：chained；现在分词：chaining；形容词派生 → chained adj. 被束缚的。

### 12. bill /bɪl/ n. 账单；账款
- **词根·渊源**：中世纪拉丁 **bulla**（印章、文书）→ 古法语 *bulle* → 英语 *bill*，本义“盖印的文书”，引申为“账单；账款”。
- **同根词**：bullet（bull 文书 + **-et** 小 = 小文书→子弹）、bulletin（bull 文书 + **-etin** 小 = 小公告→公告）。
- **前缀·后缀**：无前缀；名词后缀 **-et**（例：packet）、**-etin**（例：bulletin）。
- **同义·反义**：同义 invoice（发票）, account（账目）；反义 无。
- **变形**：名词 → 复数：bills；动词 → 第三人称单数：bills；过去式：billed；过去分词：billed；现在分词：billing；名词派生 → billing n. 开账单。

### 13. step /stɛp/ n. 迈步，脚步；脚步声；梯级，台阶
- **词根·渊源**：古英语 **stæpe**（步、台阶）→ 中古英语 *step*，与 *stapan*（走）同源，本义“迈步”，引申为“脚步；台阶”。
- **同根词**：stepfather（step 继 + father 父 = 继父）、footstep（foot 脚 + step 步 = 脚步）、stepwise（step 步 + **-wise** 方式 = 逐步地）。
- **前缀·后缀**：无前缀；后缀 **-wise**（例：clockwise）。
- **同义·反义**：同义 pace（步伐）, stair（台阶）；反义 无。
- **变形**：名词 → 复数：steps；动词 → 第三人称单数：steps；过去式：stepped；过去分词：stepped；现在分词：stepping；形容词派生 → stepwise adj. 逐步的。

### 14. draw /drɔː/ v. 掏出
- **词根·渊源**：古英语 **dragan**（拉、拖）→ 中古英语 *drawen*，本义“拉”，引申为“掏出（拉出）”。
- **同根词**：drawer（draw 拉 + **-er** 物 = 拉的东西→抽屉）、drawing（draw 拉 + **-ing** 名词 = 拉线→图画）、withdraw（**with-** 向后 + draw 拉 = 向后拉→撤回）、drawbridge（draw 拉 + bridge 桥 = 可拉起的桥→吊桥）。
- **前缀·后缀**：前缀 **with-**（例：withstand）；名词后缀 **-er**（例：teacher）、**-ing**（例：building）。
- **同义·反义**：同义 pull（拉）, extract（抽出）；反义 push（推）。
- **变形**：动词 → 第三人称单数：draws；过去式：drew；过去分词：drawn；现在分词：drawing；名词派生 → drawing n. 图画；drawer n. 抽屉。

### 15. set /sɛt/ v. 一套，一双，一幅，一组
- **词根·渊源**：古英语 **settan**（放置）→ 中古英语 *setten*，本义“放置”，名词引申为“放置在一起的一套（一组）”。
- **同根词**：settle（set 放置 + **-tle** 反复 = 安放下来→定居）、setting（set 放置 + **-ing** 名词 = 放置→环境）、offset（**off-** 离开 + set 放置 = 放偏→抵消）、upset（**up-** 向上 + set 放置 = 翻倒→使心烦）。
- **前缀·后缀**：前缀 **off-**（例：offend）、**up-**（例：uplift）；名词后缀 **-ing**（例：building）。
- **同义·反义**：同义 group（组）, collection（一套）；反义 无。
- **变形**：动词 → 第三人称单数：sets；过去式：set；过去分词：set；现在分词：setting；名词 → 复数：sets；名词派生 → setting n. 环境。

### 16. comb /koʊm/ n. 梳子；发插
- **词根·渊源**：古英语 **camb**（梳子）→ 中古英语 *comb*，与希腊 *gombos*（齿）同源，本义“有齿的工具”，即“梳子”。
- **同根词**：comb（古英语 camb 梳子→梳子）、unkempt（**un-** 不 + kempt 梳理 = 未梳理的→蓬乱的）。
- **前缀·后缀**：前缀 **un-**（例：unhappy）；无后缀。
- **同义·反义**：同义 无；反义 无。
- **变形**：名词 → 复数：combs；动词 → 第三人称单数：combs；过去式：combed；过去分词：combed；现在分词：combing；形容词派生 → unkempt adj. 蓬乱的。

### 17. accuse /əˈkjuːz/ v. 控告，指控；指责，谴责，归咎于
- **词根·渊源**：拉丁 **accusare**（控告）→ 古法语 *acuser* → 英语 *accuse*，**ac-** 向 + causa 原因/诉讼，本义“向法庭提出诉讼”，引申为“控告；指责”。
- **同根词**：accusation（accuse + **-ation** 名词 = 控告→指控）、accused（accuse + **-ed** 形容词 = 被控告的→被告）、cause（caus 原因→原因）、excuse（**ex-** 出 + cuse 原因 = 拿出原因→借口）。
- **前缀·后缀**：前缀 **ac-**（例：accept）、**ex-**（例：export）；名词后缀 **-ation**（例：information）。
- **同义·反义**：同义 charge（指控）, blame（责备）；反义 defend（辩护）, praise（赞扬）。
- **变形**：动词 → 第三人称单数：accuses；过去式：accused；过去分词：accused；现在分词：accusing；名词派生 → accusation n. 指控；形容词派生 → accusing adj. 指责的。

### 18. America /əˈmerɪkə/ n. 美国；美洲
- **词根·渊源**：新拉丁 **America**，源自意大利航海家 Amerigo Vespucci 的名字，1507 年地图学家 Waldseemüller 以其名命名新大陆，本义“亚美利哥之地”，引申为“美洲；美国”。
- **同根词**：American（America + **-an** 人/的 = 美洲的→美国的）、Americana（America + **-ana** 集合 = 美国文物→美国风物志）。
- **前缀·后缀**：无前缀；形容词/名词后缀 **-an**（例：African）、**-ana**（例：Victoriana）。
- **同义·反义**：同义 无；反义 无。
- **变形**：名词 → 复数：Americas（指南北美洲时）；形容词派生 → American adj. 美国的；名词派生 → American n. 美国人。

### 19. wife /waɪf/ n. 妻子，太太
- **词根·渊源**：古英语 **wīf**（女人、妻子）→ 中古英语 *wif* → 英语 wife；本义泛指“女人”，后专指“已婚女子”，与德语 *Weib*（女人）同源。
- **同根词**：housewife（house 家 + wife 女人 = 管家妇→家庭主妇）、midwife（mid 与……一起 + wife 女人 = 陪伴产妇的女人→助产士）、oldwife（old 老 + wife 女人 = 老妇→一种鱼名）、fishwife（fish 鱼 + wife 女人 = 卖鱼妇→泼妇）。
- **前缀·后缀**：无前后缀（单纯词）。
- **同义·反义**：同义 spouse（配偶）, partner（伴侣）；反义 husband（丈夫）, bachelor（单身汉）。
- **变形**：名词 → 复数：wives；形容词派生 → wifely adj. 妻子般的；名词派生 → wifehood n. 妻子身份。

### 20. album /ˈælbəm/ n. 相册，影集，集邮册
- **词根·渊源**：拉丁 **albus**（白的）→ 拉丁 *album*（空白木板、白色公告板）→ 英语 album；本义“白色空白板”，后指“供粘贴收藏品的空白册子”，引申为相册、集邮册。
- **同根词**：albumen（alb 白 + **-men** 物质 = 蛋白）、albino（alb 白 + **-ino** 表人 = 白化病人）、alb（alb 白 = 白色祭袍）。
- **前缀·后缀**：名词后缀 **-um**（例：museum, forum）；形容词后缀 **-ine**（例：crystalline, saline）。
- **同义·反义**：同义 scrapbook（剪贴簿）, collection（收藏集）；反义 无。
- **变形**：名词 → 复数：albums；形容词派生 → albumen n. 蛋白（同根名词）。

### 21. note /noʊt/ n. 笔记；记录
- **词根·渊源**：拉丁 **nota**（记号、标记）→ 拉丁 *notare*（做记号）→ 古法语 *note* → 英语 note；本义“做记号”，引申为“记下的文字→笔记、记录”。
- **同根词**：notebook（note 笔记 + book 本 = 笔记本）、notice（not 知道 + **-ice** 名词后缀 = 知悉→注意）、notify（not 知道 + **-ify** 使 = 使知道→通知）、notion（not 知道 + **-ion** 名词 = 所知→概念）、annotate（**an-** 加以 + not 记号 + **-ate** 动词 = 加记号→注释）。
- **前缀·后缀**：名词后缀 **-ion**（例：action, nation）；动词后缀 **-ify**（例：simplify, beautify）。
- **同义·反义**：同义 record（记录）, memo（备忘录）；反义 无。
- **变形**：名词 → 复数：notes；动词派生 → note v. 注意、记下；形容词派生 → notable adj. 值得注意的；副词派生 → notably adv. 显著地。
