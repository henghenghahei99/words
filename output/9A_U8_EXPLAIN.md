## 二、逐词说文解字

### 1. wallet /ˈwɔlət/ n. 钱包
- **词根·渊源**：日耳曼语 *wal-*（卷、包裹）→ 盎格鲁-诺曼法语 *walet*（背包、行囊）→ 英语 wallet；本义“装物品的卷包”引申为“钱包”。
- **同根词**：无可靠同根词（存疑：与 wallow 可能同源，但不确定）。
- **前缀·后缀**：名词后缀 **-et**（指小，例：packet, pocket）。
- **同义·反义**：同义 purse（钱包）, billfold（钱夹）；反义 无。
- **变形**：名词 → 复数：wallets。

### 2. possession /pəˈzɛʃən/ n. 私人物品;个人财产
- **词根·渊源**：拉丁 **possidere**（占有）= **pot-**（能力）+ **sedere**（坐）→ 拉丁 *possessio* → 古法语 *possession* → 英语；本义“能坐拥某物”引申为“拥有、财产”。
- **同根词**：possess（**pos-** 能力 + **sess** 坐 = 能坐拥→拥有）、session（**sess** 坐 + **-ion** 名词后缀 = 坐下→会议、会期）、sediment（**sed** 坐 + **-iment** 名词后缀 = 沉坐下去的东西→沉淀物）、sedate（**sed** 坐 + **-ate** 形容词后缀 = 坐定的→镇静的）。
- **前缀·后缀**：名词后缀 **-ion**（例：action, decision）。
- **同义·反义**：同义 property（财产）, belongings（财物）；反义 无。
- **变形**：名词 → 复数：possessions；形容词派生 → possessive adj. 拥有的、占有欲强的；动词派生 → possess v. 拥有。

### 3. knee /ni/ n. 膝;膝盖
- **词根·渊源**：古英语 *cneo*（膝）→ 中古英语 *knee* → 英语；与拉丁 **genu**（膝）、希腊 **gony**（膝）同出 PIE *genu-*。
- **同根词**：kneel（knee + **-el** 动词后缀 = 用膝着地→跪下）、genuflect（拉丁 **genu** 膝 + **flect** 弯 = 屈膝→跪拜）、genuine（拉丁 **genu** 膝 + **-ine** 形容词后缀 = 放在膝上认作亲生→真正的）。
- **前缀·后缀**：无前后缀（单纯词）。
- **同义·反义**：同义 无；反义 无。
- **变形**：名词 → 复数：knees；动词派生 → kneel v. 跪下。

### 4. scarf /skɑrf/ n. 围巾
- **词根·渊源**：古北法语 *escarpe*（肩带、饰带）→ 中古英语 *scarf*；本义“斜挂的带子”引申为“围巾”（词源存疑，一说与拉丁 **scarp-** 有关）。
- **同根词**：无可靠同根词（存疑）。
- **前缀·后缀**：无前后缀（单纯词）。
- **同义·反义**：同义 shawl（披肩）, muffler（围巾）；反义 无。
- **变形**：名词 → 复数：scarves / scarfs。

### 5. cash /kæʃ/ n. 现金
- **词根·渊源**：拉丁 **capsa**（盒子）→ 意大利语 *cassa*（钱箱）→ 古法语 *casse* → 英语 cash；本义“钱箱里的钱”引申为“现金”。
- **同根词**：case（拉丁 **capsa** 盒子→箱子、盒子）、capsule（**caps** 盒 + **-ule** 指小后缀 = 小盒子→胶囊）、chase（同源存疑：与 cash 同出拉丁 capsa，本义“匣子”）。
- **前缀·后缀**：无前后缀（单纯词）。
- **同义·反义**：同义 money（钱）, currency（货币）；反义 credit（赊账）。
- **变形**：名词 → 不可数（作“现金”义）；动词派生 → cash v. 兑现。

### 6. scissors /ˈsɪzərz/ n. (pl.)剪刀
- **词根·渊源**：拉丁 **caedere**（切、割）→ 拉丁 *cisoria*（切割工具）→ 古法语 *cisoires* → 英语 scissors；本义“切割之物”引申为“剪刀”。
- **同根词**：decide（**de-** 离 + **cid** 切 = 切掉犹豫→决定）、precise（**pre-** 先 + **cis** 切 = 先切好的→精确的）、incision（**in-** 入 + **cis** 切 + **-ion** 名词后缀 = 切入→切口）、circumcise（**circum-** 环绕 + **cis** 切 = 环切）。
- **前缀·后缀**：名词复数后缀 **-s**（例：trousers, glasses）。
- **同义·反义**：同义 shears（大剪刀）；反义 无。
- **变形**：名词 → 复数：scissors（本身为复数形式）。

### 7. chain /ʧeɪn/ n. 链子
- **词根·渊源**：拉丁 **catena**（链子）→ 古法语 *chaeine* → 英语 chain；本义“连接之物”引申为“链子、一连串”。
- **同根词**：concatenate（**con-** 共同 + **caten** 链 + **-ate** 动词后缀 = 连成链→串联）、catenary（**caten** 链 + **-ary** 形容词后缀 = 链状的）。
- **前缀·后缀**：无前后缀（单纯词）。
- **同义·反义**：同义 link（环节）, series（系列）；反义 无。
- **变形**：名词 → 复数：chains；动词派生 → chain v. 用链锁住。

### 8. display /dɪˈspleɪ/ n. 陈列;展览
- **词根·渊源**：拉丁 **displicare**（展开）= **dis-**（分开）+ **plicare**（折叠）→ 古法语 *despleier* → 英语 display；本义“把折叠的东西展开”引申为“陈列、展示”。
- **同根词**：ply（**plic** 折叠→层、股）、apply（**ap-** 向 + **ply** 折叠 = 折向→应用）、imply（**im-** 入 + **ply** 折叠 = 折进去→暗示）、reply（**re-** 回 + **ply** 折叠 = 折回去→回答）、explicit（**ex-** 出 + **plic** 折叠 = 折出来的→明确的）。
- **前缀·后缀**：前缀 **dis-**（分开，例：discover, divide）。
- **同义·反义**：同义 exhibition（展览）, show（展示）；反义 concealment（隐藏）。
- **变形**：名词 → 复数：displays；动词派生 → display v. 陈列、展示。

### 9. shelf /ʃɛlf/ n. 架子;搁板
- **词根·渊源**：古英语 *scylfe*（搁板、岩架）→ 中古英语 *shelfe* → 英语 shelf；本义“突出的平台”引申为“架子、搁板”。
- **同根词**：无可靠同根词（存疑）。
- **前缀·后缀**：无前后缀（单纯词）。
- **同义·反义**：同义 ledge（壁架）, rack（架子）；反义 无。
- **变形**：名词 → 复数：shelves。

### 10. bill /bɪl/ n. 账单
- **词根·渊源**：拉丁 **bulla**（气泡、印章、文书）→ 中世纪拉丁 *billa*（文件）→ 盎格鲁-诺曼法语 *bille* → 英语 bill；本义“盖印的文书”引申为“账单、法案”。
- **同根词**：bullet（**bull** 文书 + **-et** 指小后缀 = 小文书→子弹，因形似小纸卷）、bulletin（**bull** 文书 + **-etin** 指小后缀 = 小公告→公告）。
- **前缀·后缀**：无前后缀（单纯词）。
- **同义·反义**：同义 invoice（发票）, check（账单）；反义 无。
- **变形**：名词 → 复数：bills；动词派生 → bill v. 开账单。

### 11. handmade /ˈhænˈmeɪd/ adj. 手工制作的
- **词根·渊源**：古英语 **hand**（手）+ 古英语 **macian**（做）→ 英语 hand + made；本义“用手做的”即“手工制作的”。
- **同根词**：handwork（**hand** 手 + **work** 工作 = 手工活）、handicraft（**hand** 手 + **craft** 技艺 = 手工艺）、manmade（**man** 人 + **made** 做 = 人造的）、handful（**hand** 手 + **-ful** 满 = 一把）。
- **前缀·后缀**：无前后缀（复合词）。
- **同义·反义**：同义 handcrafted（手工制作的）；反义 machine-made（机器制造的）。
- **变形**：形容词 → 无比较级（关系形容词，不作比较）。

### 12. mutton /ˈmətən/ n. 羊肉
- **词根·渊源**：拉丁 **multo**（公羊）→ 古法语 *moton*（绵羊）→ 英语 mutton；本义“绵羊”后专指“羊肉”（与法语 mouton 同源）。
- **同根词**：无可靠同根词（存疑：与拉丁 multo 相关，但同根词少）。
- **前缀·后缀**：名词后缀 **-on**（例：button, ribbon）。
- **同义·反义**：同义 lamb（羔羊肉）；反义 无。
- **变形**：名词 → 不可数。

### 13. oven /ˈəvən/ n. 烤箱
- **词根·渊源**：古英语 *ofen*（炉子）→ 中古英语 *oven* → 英语 oven；与德语 *Ofen* 同源，本义“烤炉”引申为“烤箱”。
- **同根词**：无可靠同根词（存疑）。
- **前缀·后缀**：无前后缀（单纯词）。
- **同义·反义**：同义 stove（炉灶）, furnace（熔炉）；反义 无。
- **变形**：名词 → 复数：ovens。

### 14. lie /laɪ/ v. 平放
- **词根·渊源**：古英语 *licgan*（躺、平放）→ 中古英语 *lien* → 英语 lie；本义“躺卧”引申为“平放、位于”。
- **同根词**：lying（**lie** + **-ing** 现在分词 = 躺着）、lay（使役形式，**lay** 放置，与 lie 同源）、lair（**lie** 躺 + **-er** 处所 = 躺卧之处→兽穴）。
- **前缀·后缀**：无前后缀（单纯词）。
- **同义·反义**：同义 recline（躺卧）, rest（放置）；反义 stand（站立）。
- **变形**：动词 → 第三人称单数：lies；过去式：lay；过去分词：lain；现在分词：lying；名词派生 → lie n. 位置。

### 15. analysis /æˈnælɪsɪs/ n. (对事物的)分析
- **词根·渊源**：希腊 **analyein**（解开）= **ana-**（向上、分开）+ **lyein**（松开）→ 拉丁 *analysis* → 英语 analysis；本义“把事物拆开”引申为“分析”。
- **同根词**：analyze（**ana-** 分开 + **lyze** 松开 = 拆开→分析）、catalyst（**cata-** 向下 + **lyst** 松开 = 松开→催化剂）、paralysis（**para-** 旁 + **lysis** 松开 = 旁边松弛→瘫痪）、dialyze（**dia-** 穿过 + **lyze** 松开 = 透过松开→透析）。
- **前缀·后缀**：名词后缀 **-sis**（例：basis, crisis）。
- **同义·反义**：同义 examination（检查）, breakdown（分解）；反义 synthesis（综合）。
- **变形**：名词 → 复数：analyses；动词派生 → analyze v. 分析；形容词派生 → analytical adj. 分析的。

### 16. conditions /kənˈdɪʃənz/ n. (居住、工作或做事情的)环境
- **词根·渊源**：拉丁 **condicio**（约定、状况）= **con-**（共同）+ **dicere**（说）→ 古法语 *condition* → 英语 condition；本义“共同约定的事”引申为“状况、环境”。
- **同根词**：condition（**con-** 共同 + **dit** 说 + **-ion** 名词后缀 = 共同说定→条件）、dictate（**dict** 说 + **-ate** 动词后缀 = 说→口述、命令）、predict（**pre-** 先 + **dict** 说 = 先说→预言）、verdict（**ver** 真 + **dict** 说 = 说真话→裁决）。
- **前缀·后缀**：名词复数后缀 **-s**（例：situations, surroundings）。
- **同义·反义**：同义 circumstances（环境）, surroundings（周围环境）；反义 无。
- **变形**：名词 → 复数：conditions（本身为复数形式）；形容词派生 → conditional adj. 有条件的。

### 17. selfless /ˈsɛlfləs/ adj. 无私的
- **词根·渊源**：古英语 **self**（自己）+ 古英语 **leas**（无、缺少）→ 英语 selfless；本义“没有自己的”引申为“无私的”。
- **同根词**：selfish（**self** 自己 + **-ish** 形容词后缀 = 自私的）、selfhood（**self** 自己 + **-hood** 名词后缀 = 自我）、selfsame（**self** 自己 + **same** 相同 = 完全相同的）、unselfish（**un-** 不 + selfish = 不自私的）。
- **前缀·后缀**：形容词后缀 **-less**（无，例：hopeless, careless）。
- **同义·反义**：同义 unselfish（不自私的）, altruistic（利他的）；反义 selfish（自私的）。
- **变形**：形容词 → 比较级：more selfless；最高级：most selfless；名词派生 → selflessness n. 无私。

### 18. poverty /ˈpɑvərti/ n. 贫困
- **词根·渊源**：拉丁 **pauper**（贫穷的）→ 古法语 *poverte* → 英语 poverty；本义“贫穷的状态”引申为“贫困”。
- **同根词**：poor（拉丁 **pauper** 贫穷的→贫穷的）、pauper（**pauper** 贫穷的→贫民）、impoverish（**im-** 使 + **pover** 贫穷 + **-ish** 动词后缀 = 使贫穷）。
- **前缀·后缀**：名词后缀 **-ty**（例：safety, beauty）。
- **同义·反义**：同义 need（贫困）, want（匮乏）；反义 wealth（财富）, affluence（富裕）。
- **变形**：名词 → 不可数；形容词派生 → poor adj. 贫穷的。

### 19. handwritten /ˈhænˌdrɪtən/ adj. 手写的
- **词根·渊源**：**hand**（手，日耳曼语源）+ **write**（写，古英语 *wrītan* 刻划）+ 过去分词后缀 **-en**；由“用手写出”的短语 hand-write 加 -en 构成复合形容词，本义“用手写成的”。
- **同根词**：handwriting（hand 手 + writing 写 = 手写→笔迹）、handmade（hand 手 + made 做 = 手工制作的）、handbook（hand 手 + book 书 = 手边小书→手册）、handful（hand 手 + **-ful** 满 = 一把→少量）、rewrite（**re-** 再 + write 写 = 重写）、writer（write 写 + **-er** 人 = 写的人→作家）。
- **前缀·后缀**：过去分词后缀 **-en**（例：broken, spoken）；名词后缀 **-er**（例：teacher, singer）。
- **同义·反义**：同义 written by hand（手写的）；反义 typed（打字的）, printed（印刷的）。
- **变形**：形容词 → 无比较级（关系形容词，不作比较）；名词派生 → handwriting n. 笔迹、手写。

### 20. degree /dɪˈgri/ n. 度(温度单位)
- **词根·渊源**：拉丁 **de-**（向下）+ **gradus**（步、级）→ 古法语 *degre*，本义“下的一级台阶”，引申为“等级、程度”，再指温度计上的“刻度、度”。
- **同根词**：grade（grad 步、级 = 等级→年级）、gradual（grad 步 + **-ual** …的 = 一步一步的→逐渐的）、graduate（grad 步 + **-uate** 使… = 走完一级→毕业）、degrade（**de-** 向下 + grade 级 = 降级→贬低）、upgrade（**up-** 向上 + grade 级 = 升级）、centigrade（centi 百 + grade 度 = 百分度→摄氏的）。
- **前缀·后缀**：前缀 **de-**（例：decline, decrease）；名词后缀 **-ee**（例：employee, trainee）。
- **同义·反义**：同义 level（水平）, extent（程度）；反义 无。
- **变形**：名词 → 复数：degrees；副词派生 → 无（degree 无常用副词派生）。

### 21. flu /flu/ n. 流感
- **词根·渊源**：**influenza** 的缩略形式；意大利语 *influenza* 本义“影响、流入”，源自拉丁 **in-**（进入）+ **fluere**（流），旧时认为流感由星体“影响”所致，故得名；口语缩略为 flu。
- **同根词**：influence（**in-** 进入 + flu 流 + **-ence** 名词 = 流入→影响）、fluent（flu 流 + **-ent** …的 = 流利的）、fluid（flu 流 + **-id** 物 = 流体）、flush（flu 流 + **-sh** = 冲流→冲洗）、affluent（**af-** 向 + flu 流 + **-ent** = 流向→富裕的）。
- **前缀·后缀**：前缀 **in-**（例：income, inside）；形容词后缀 **-ent**（例：silent, different）。
- **同义·反义**：同义 influenza（流行性感冒）, grippe（流感）；反义 无。
- **变形**：名词 → 复数：flus（多作不可数）；形容词派生 → flu-like adj. 流感样的。

### 22. pale /peɪl/ adj. 苍白的
- **词根·渊源**：拉丁 **pallidus**（苍白的）→ 古法语 *paile* → 英语 pale；与 pallor（苍白）同源，本义即“颜色淡的、苍白的”。
- **同根词**：pallid（pall 苍白 + **-id** …的 = 苍白的）、pallor（pall 苍白 + **-or** 名词 = 苍白）、pallidly（pallid + **-ly** 地 = 苍白地）。
- **前缀·后缀**：形容词后缀 **-id**（例：humid, rigid）；名词后缀 **-or**（例：color, error）。
- **同义·反义**：同义 white（白的）, wan（苍白的）；反义 ruddy（红润的）, rosy（玫瑰色的）。
- **变形**：形容词 → 比较级：paler；最高级：palest；名词派生 → paleness n. 苍白；副词派生 → palely adv. 苍白地；动词派生 → pale v. 变苍白。

### 23. earn /ərn/ v. 挣得;赚得
- **词根·渊源**：古英语 **earnian**（劳作获得、赚取），日耳曼语源，与德语 *ernten*（收获）同源；本义“靠劳动收获”，引申为“挣得、赢得”。
- **同根词**：earnings（earn 挣 + **-ing** 名词 + **-s** 复数 = 收入）、earner（earn 挣 + **-er** 人 = 挣钱者）、unearned（**un-** 不 + earn 挣 + **-ed** …的 = 不劳而获的）。
- **前缀·后缀**：名词后缀 **-ing**（例：building, feeling）；否定前缀 **un-**（例：unhappy, unfair）。
- **同义·反义**：同义 gain（获得）, obtain（得到）；反义 lose（失去）, spend（花费）。
- **变形**：动词 → 第三人称单数：earns；过去式：earned；过去分词：earned；现在分词：earning；名词派生 → earnings n. 收入；earner n. 挣钱者。

### 24. upstairs /əpˈstɛrz/ adv. 在(或向)楼上
- **词根·渊源**：**up**（向上，古英语 *up*）+ **stairs**（楼梯，古英语 *stǣger* 的复数）；由“沿楼梯向上”合成副词，本义“在楼上、向楼上”。
- **同根词**：downstairs（**down-** 向下 + stairs 楼梯 = 在楼下）、upward（up 向上 + **-ward** 向 = 向上的）、uphold（**up-** 向上 + hold 持 = 举起→支持）、staircase（stair 楼梯 + case 框架 = 楼梯间）、stairway（stair 楼梯 + way 路 = 楼梯通道）。
- **前缀·后缀**：方向前缀 **up-**（例：uphill, update）；方向后缀 **-ward**（例：forward, backward）。
- **同义·反义**：同义 above（在上面）；反义 downstairs（在楼下）。
- **变形**：副词 → 无比较级；形容词派生 → upstairs adj. 楼上的；名词派生 → upstairs n. 楼上。

### 25. freeze /friz/ v. (使)冻结;结冰
- **词根·渊源**：古英语 **frēosan**（结冰），日耳曼语源，与 frost（霜）同源；本义“因寒冷而凝固”，引申为“冻结、冻住”。
- **同根词**：frost（fr- 冻 + **-ost** = 霜）、freezer（freeze 冻 + **-er** 物 = 冷冻箱）、freezing（freeze 冻 + **-ing** …的 = 极冷的）、frozen（freeze 的过去分词 = 冰冻的）、antifreeze（**anti-** 抗 + freeze 冻 = 防冻剂）。
- **前缀·后缀**：名词后缀 **-er**（例：cooker, printer）；前缀 **anti-**（例：antibody, antisocial）。
- **同义·反义**：同义 chill（使变冷）, ice（结冰）；反义 melt（融化）, thaw（解冻）。
- **变形**：动词 → 第三人称单数：freezes；过去式：froze；过去分词：frozen；现在分词：freezing；名词派生 → freezer n. 冷冻箱；形容词派生 → frozen adj. 冰冻的。

### 26. porridge /ˈpɔrəʤ/ n. 粥
- **词根·渊源**：中古英语 *porrage*，源自法语 *potage*（汤、浓汤），与 **pot**（锅）同源；本义“锅里煮的浓稠食物”，引申为“粥”。
- **同根词**：pot（同源，锅）、potage（pot 锅 + **-age** 名词 = 浓汤）、pottage（pot 锅 + **-age** = 菜粥）。
- **前缀·后缀**：名词后缀 **-age**（例：village, package）。
- **同义·反义**：同义 gruel（稀粥）, oatmeal（燕麦粥）；反义 无。
- **变形**：名词 → 复数：porridges（多作不可数）；形容词派生 → porridgy adj. 粥状的。
