## 二、逐词说文解字

### 1. concern /kənˈsɜːn/ n. 担心；忧虑
- **词根·渊源**：拉丁 **con-**（共同、一起）+ **cernere**（筛选、分辨）→ 拉丁 *concernere*（混合、筛在一起→涉及、有关系）→ 古法语 *concerner* → 英语；本义“把事物筛到一起加以辨别”，引申为“与……有关”，再引申为“牵动人心的事→担心、忧虑”。
- **同根词**：discern（**dis-** 分开 + cern 筛 = 分开筛选→辨别）、certain（cert 确定 < cernere 分辨 + **-ain** 形容词后缀 = 分辨清楚的→确定的）、secret（**se-** 分开 + cret 筛 = 分开藏起→秘密的）、discriminate（**dis-** 分开 + crimin 分辨 + **-ate** 动词后缀 = 加以区分→歧视）。
- **前缀·后缀**：前缀 **con-**（例：connect, confirm）；名词后缀无（-n 为词干尾）。
- **同义·反义**：同义 worry, anxiety；反义 unconcern, indifference。
- **词性变化**：concerned adj. 担心的；concerning prep. 关于。

### 2. atmosphere /'ætməsfɪə(r)/ n. 大气层
- **词根·渊源**：希腊 **atmos**（蒸汽、气）+ **sphaira**（球、天球）→ 新拉丁 *atmosphaera*（17世纪科学家造词）→ 英语；本义“包围地球的气球层”，即“大气层”，后引申为“气氛”。
- **同根词**：sphere（sphaira 球→球体、领域）、hemisphere（**hemi-** 半 + sphere 球 = 半球）、atmospheric（atmosphere + **-ic** …的：大气的）、biosphere（**bio-** 生命 + sphere 球 = 生物圈）。
- **前缀·后缀**：前缀 **atmo-**（例：atmometer 汽化计）；名词后缀 **-sphere**（例：lithosphere, hydrosphere）。
- **同义·反义**：同义 air, sky；反义 无。
- **词性变化**：atmospheric adj. 大气的；atmospherically adv. 在大气方面。

### 3. temperature /ˈtemprətʃər/ n. 温度
- **词根·渊源**：拉丁 **temperare**（调和、混合适度）→ 拉丁 *temperatura*（适度的混合）→ 法语 *température* → 英语；本义“调和到适中状态”，引申为“冷热适中的程度→温度”。
- **同根词**：temper（temperare 调和→使缓和、脾气）、temperate（temper + **-ate** …的：有节制的、温带的）、temperament（temper + **-ament** 名词后缀 = 调和成的体质→气质）、distemper（**dis-** 坏 + temper 调和 = 调坏→疾病）。
- **前缀·后缀**：前缀无；名词后缀 **-ature**（例：creature, signature）。
- **同义·反义**：同义 heat level；反义 无。
- **词性变化**：temperate adj. 温和的；temper v. 调和。

### 4. consumer /kənˈsjuːmə(r)/ n. 消费者
- **词根·渊源**：拉丁 **con-**（完全）+ **sumere**（拿取，< sub- 下 + emere 买）→ 拉丁 *consumere*（拿光、用尽）→ 古法语 *consumer* → 英语；本义“把东西用光”，引申为“消耗、消费”，加 **-er** 表“做某事的人”→消费者。
- **同根词**：consume（**con-** 完全 + sume 拿取 = 拿光→消耗）、consumption（consume + **-ption** 名词后缀 = 消耗、消费）、assume（**as-** 向 + sume 拿 = 拿向自己→假定）、resume（**re-** 再 + sume 拿 = 再拿起→恢复、继续）、presume（**pre-** 先 + sume 拿 = 先拿→假定）。
- **前缀·后缀**：前缀 **con-**（例：contain, conclude）；后缀 **-er**（例：worker, teacher）。
- **同义·反义**：同义 buyer, user；反义 producer。
- **词性变化**：consume v. 消耗；consumption n. 消费。

### 5. guess /ɡes/ v. 猜，猜测
- **词根·渊源**：可能来自中古英语 *gessen*，与古诺斯语 *geta*（获得、猜想）同源，原始日耳曼语 *getan*（得到）→ 英语；本义“设法得到、估计”，引申为“凭推测判断→猜测”（词源细节存疑）。
- **同根词**：get（同源日耳曼词，得到）、forget（**for-** 失去 + get 得到 = 失去记忆→忘记）、beget（**be-** 加强 + get 得到 = 生出）。
- **前缀·后缀**：无前后缀（单纯词）。
- **同义·反义**：同义 suppose, estimate；反义 know, prove。
- **词性变化**：guess n. 猜测；guesswork n. 猜测。

### 6. green /ɡriːn/ adj. 环境保护的；赞成环境保护的
- **词根·渊源**：古英语 **grēne**，原始日耳曼语 *grōniz*，与 grow（生长）同源，PIE *ghre-*（生长、变绿）→ 英语；本义“草木生长的颜色→绿色的”，20世纪引申为“环保的”（因绿色象征自然）。
- **同根词**：grow（同源，生长）、grass（同源，草）、greenhouse（green + house 房子 = 温室）。
- **前缀·后缀**：无前后缀（单纯词）。
- **同义·反义**：同义 eco-friendly；反义 polluting。
- **词性变化**：green n. 绿色；greenery n. 绿植。

### 7. lifeless /'laɪfləs/ adj. 无生命的；无生物生长的
- **词根·渊源**：古英语 **līf**（生命）+ 后缀 **-less**（无）→ 中古英语 *lifles* → 英语；本义“没有生命的”，引申为“无生物生长的、死气沉沉的”。
- **同根词**：life（līf 生命）、lively（life + **-ly** …的：有生气的）、alive（**a-** 在 + live 活 = 活着的）、livelihood（live + **-lihood** 名词后缀 = 生计）。
- **前缀·后缀**：后缀 **-less**（例：hopeless, careless）。
- **同义·反义**：同义 dead, barren；反义 living, lively。
- **词性变化**：life n. 生命；live v. 生活。

### 8. fuel /ˈfjuːəl/ v. 燃料
- **词根·渊源**：拉丁 **focus**（炉灶、火心）→ 古法语 *fouaille*（柴火）→ 英语 *fuel*；本义“炉灶里烧的柴”，引申为“燃料”，动词义“给……加燃料→助长”。
- **同根词**：focus（拉丁 focus 炉灶→焦点）、focal（focus + **-al** …的：焦点的）。
- **前缀·后缀**：无前后缀（单纯词）。
- **同义·反义**：同义 power, energize；反义 无。
- **词性变化**：fuel n. 燃料；fueling n. 加燃料。

### 9. coal /koʊl/ v. 煤；煤块，煤炭
- **词根·渊源**：古英语 **col**，原始日耳曼语 *kula-*，与荷兰语 *kool*、德语 *Kohle* 同源，PIE 词根 *guel-*（烧、发光）→ 英语；本义“烧过的炭→煤”。
- **同根词**：charcoal（char 烧焦 + coal 煤 = 木炭）、colliery（coal + **-ery** 场所 = 煤矿）。
- **前缀·后缀**：无前后缀（单纯词）。
- **同义·反义**：同义 charcoal；反义 无。
- **词性变化**：coal n. 煤；coaly adj. 含煤的。

### 10. result /rɪˈzʌlt/ n. 结果；后果
- **词根·渊源**：拉丁 **re-**（回）+ **saltare**（跳，< salire 跳）→ 拉丁 *resultare*（跳回来、反弹）→ 中世纪拉丁“作为结果产生” → 英语；本义“弹回来”，引申为“事情反弹回来的东西→结果”。
- **同根词**：assault（**as-** 向 + sault 跳 = 跳向→攻击）、insult（**in-** 向 + sult 跳 = 跳向→侮辱）、exult（**ex-** 出 + ult 跳 = 跳出→欢跃）、resilient（**re-** 回 + sil 跳 + **-ent** …的 = 弹回的→有弹性的）。
- **前缀·后缀**：前缀 **re-**（例：return, react）；名词后缀无。
- **同义·反义**：同义 outcome, consequence；反义 cause。
- **词性变化**：result v. 导致；resultant adj. 作为结果的。

### 11. increase /ɪnˈkris/ n. 增加；增长
- **词根·渊源**：拉丁 **in-**（向内、加强）+ **crescere**（生长）→ 拉丁 *increscere* → 古法语 *encreistre* → 英语；本义“在里面长起来”，引申为“增加、增长”。
- **同根词**：crescent（cresc 生长 + **-ent** …的 = 生长的→新月）、create（cre 生长 + **-ate** 动词后缀 = 使生长→创造）、decrease（**de-** 向下 + crease 生长 = 向下长→减少）、concrete（**con-** 一起 + cret 生长 = 长在一起→具体的）。
- **前缀·后缀**：前缀 **in-**（例：include, inflate）；名词后缀无。
- **同义·反义**：同义 growth, rise；反义 decrease, reduction。
- **词性变化**：increase v. 增加；increasing adj. 增加的。

### 12. sea level /ˈsiː levl/ n. 海平面
- **同义搭配**：ocean level / mean sea level / water level
- **反义搭配**：无

### 13. destroy /dɪ'strɔɪ/ v. 摧毁；毁灭
- **词根·渊源**：拉丁 **de-**（向下、反）+ **struere**（建造、堆起）→ 拉丁 *destruere*（拆掉建造的东西）→ 古法语 *destruire* → 英语；本义“拆毁建筑”，引申为“彻底破坏→摧毁”。
- **同根词**：structure（**stru-** 建造 + **-ure** 名词后缀 = 建造物→结构）、construct（**con-** 一起 + struct 建造 = 一起建造→建造）、instruct（**in-** 在内 + struct 建造 = 在心中建起→教导）、destruction（destroy + **-tion** 名词后缀 = 毁灭）。
- **前缀·后缀**：前缀 **de-**（例：decline, decrease）；动词后缀无。
- **同义·反义**：同义 ruin, wreck；反义 build, create。
- **词性变化**：destruction n. 毁灭；destructive adj. 破坏性的。

### 14. nature /ˈneɪtʃə(r)/ n. 自然界；大自然
- **词根·渊源**：拉丁 **natura**（出生、天性，< nasci 出生）→ 古法语 *nature* → 英语；本义“与生俱来的性质”，引申为“万物的本性→自然界”。
- **同根词**：native（nat 出生 + **-ive** …的：出生的→本地的）、nation（nat 出生 + **-ion** 名词后缀 = 出生的人群→民族）、natural（nature + **-al** …的：自然的）、innate（**in-** 在内 + nat 出生 = 生来就有的→天生的）。
- **前缀·后缀**：名词后缀 **-ure**（例：culture, picture）。
- **同义·反义**：同义 environment, world；反义 无。
- **词性变化**：natural adj. 自然的；naturally adv. 自然地。

### 15. surface /ˈsɜ:rfɪs/ n. 表面；表层
- **词根·渊源**：法语 **sur-**（在上，< 拉丁 super 上）+ **face**（脸，< 拉丁 facies 外形）→ 法语 *surface* → 英语；本义“在上面的脸面”，即“表面、表层”。
- **同根词**：face（facies 外形→脸）、superficial（super 上 + fici 面 + **-al** …的 = 表面的→肤浅的）、superior（super 上 + **-ior** 比较级 = 更高的）、surpass（**sur-** 超过 + pass 通过 = 超过）。
- **前缀·后缀**：前缀 **sur-**（例：surround, survey）；名词后缀无。
- **同义·反义**：同义 exterior, top；反义 interior, bottom。
- **词性变化**：surface v. 浮出水面；surficial adj. 地表的。

### 16. soil /sɔɪl/ n. 泥土，土壤
- **词根·渊源**：古法语 **soil**（土地、地块），可能来自拉丁 *solum*（土地、地面）→ 英语；本义“地面、地块”，引申为“泥土、土壤”（词源细节存疑）。
- **同根词**：solum（拉丁 土地）、solar（**sol-** 太阳 + **-ar** …的：太阳的，与 solum 不同源，存疑）。
- **前缀·后缀**：无前后缀（单纯词）。
- **同义·反义**：同义 earth, dirt；反义 无。
- **词性变化**：soil v. 弄脏；soily adj. 多泥的。

### 17. flood /flʌd/ n. 洪水；水灾
- **词根·渊源**：古英语 **flōd**，原始日耳曼语 *flōduz*，与 flow（流）同源，PIE *pleu-*（流动）→ 英语；本义“大水流动”，即“洪水、水灾”。
- **同根词**：flow（同源，流动）、float（同源，漂浮）、fluent（**flu-** 流 + **-ent** …的：流动的→流利的）、fluid（flu 流 + **-id** 名词后缀 = 流体）。
- **前缀·后缀**：无前后缀（单纯词）。
- **同义·反义**：同义 deluge, inundation；反义 drought。
- **词性变化**：flood v. 淹没；flooding n. 水淹。

### 18. habit /ˈhæbɪt/ n. 习惯
- **词根·渊源**：拉丁 **habere**（持有、拥有）→ 拉丁 *habitus*（持有的状态、举止）→ 古法语 *habit* → 英语；本义“持有一贯的行为方式”，即“习惯”。
- **同根词**：inhabit（**in-** 在内 + habit 持有 = 住在里面→居住）、exhibit（**ex-** 出 + habit 持有 = 拿出来→展出）、ability（**abil-** 能持有 + **-ity** 名词后缀 = 能力）、habitual（habit + **-ual** …的：习惯的）。
- **前缀·后缀**：名词后缀 **-it**（例：credit, spirit）。
- **同义·反义**：同义 custom, routine；反义 无。
- **词性变化**：habitual adj. 习惯的；habituate v. 使习惯。

### 19. proper /ˈprɑːpər/ adj. 正规的,合适的；恰当的
- **词根·渊源**：拉丁 **proprius**（自己的、特有的）→ 古法语 *propre* → 英语 proper；本义“属于自己的、固有的”，引申为“适合的、恰当的、正规的”。
- **同根词**：property（proper 自己的 + **-ty** 名词后缀 = 自己拥有的东西→财产）、proprietor（propri 自己的 + **-etor** 人 = 拥有者→业主）、appropriate（**ap-** 朝向 + propri 自己的 + **-ate** = 使之成为自己的→适当的）、improper（**im-** 不 + proper 合适的 = 不合适的）。
- **前缀·后缀**：形容词后缀 **-er**（例：teacher, worker）；否定前缀 **im-**（例：impossible, impolite）。
- **同义·反义**：同义 suitable, appropriate, correct；反义 improper, unsuitable。
- **词性变化**：properly adv. 恰当地；property n. 财产；improper adj. 不合适的。

### 20. friendly /ˈfrendli/ adj. 无害的
- **词根·渊源**：古英语 **frēond**（朋友，源自动词 frēogan“爱”）+ 后缀 **-lic**（……样的）→ 古英语 *frēondlic* → 英语 friendly；本义“像朋友一样的”，引申为“友善的、无害的”。
- **同根词**：friend（古英语 frēond 朋友：朋友）、friendship（friend + **-ship** 名词后缀表关系 = 友谊）、friendless（friend + **-less** 无 = 无朋友的）、befriend（**be-** 使 + friend = 以朋友相待→帮助）。
- **前缀·后缀**：形容词后缀 **-ly**（例：lovely, weekly）；名词后缀 **-ship**（例：membership, leadership）。
- **同义·反义**：同义 kind, harmless, amiable；反义 unfriendly, harmful。
- **词性变化**：friend n. 朋友；friendship n. 友谊；friendliness n. 友善。

### 21. recycle /ˌriːˈsaɪkl/ v. 回收利用，循环利用
- **词根·渊源**：**re-**（再）+ 拉丁 **cyclus**（圆圈，源自希腊 kyklos 圆环）→ 英语 cycle（循环）+ **-le** 动词化；本义“使再进入循环”，即“回收利用”。
- **同根词**：cycle（希腊 kyklos 圆环→循环）、bicycle（**bi-** 二 + cycle 轮 = 两轮车→自行车）、cyclist（cycle + **-ist** 人 = 骑自行车的人）、recycling（recycle + **-ing** 名词后缀 = 回收利用）。
- **前缀·后缀**：前缀 **re-**（例：rebuild, rewrite）；名词后缀 **-ing**（例：building, meeting）。
- **同义·反义**：同义 reuse, reprocess；反义 waste, discard。
- **词性变化**：recycling n. 回收利用；recyclable adj. 可回收的；cycle n. 循环。

### 22. purpose /ˈpɜ:rpəs/ n. 目的；目标；意图
- **词根·渊源**：古法语 **porposer**（提出、打算）→ 英语 purpose；由 **pur-**（= pro-，向前）+ **pose**（放置，拉丁 ponere）构成，本义“放在前面（的计划）”，引申为“目的、意图”。
- **同根词**：propose（**pro-** 向前 + pose 放 = 放到前面→提议）、proposal（propose + **-al** 名词后缀 = 提议）、pose（拉丁 ponere 放置→摆姿势）、position（pos 放 + **-ition** 名词后缀 = 放置的位置→位置）、compose（**com-** 一起 + pose 放 = 放在一起→组成）。
- **前缀·后缀**：前缀 **pur-**（= pro-，例：pursue, purchase）；名词后缀 **-ose**（例：close, dose）。
- **同义·反义**：同义 aim, goal, intention；反义 无。
- **词性变化**：purposeful adj. 有目的的；purposely adv. 故意地；propose v. 提议。

### 23. solution /səˈluːʃn/ n. 解决办法；处理手段
- **词根·渊源**：拉丁 **solutio**（解开、溶解），源自 **solvere**（松开、解开：se- 分开 + luere 松开）→ 古法语 *solucion* → 英语 solution；本义“解开（难题）”，引申为“解决办法”。
- **同根词**：solve（拉丁 solvere 解开→解决）、solvable（solve + **-able** 可……的 = 可解决的）、dissolve（**dis-** 分开 + solve 松开 = 使分开→溶解）、absolute（**ab-** 离开 + solu 松开 + **-te** = 松开限制的→绝对的）、resolve（**re-** 再 + solve 解开 = 再解决→决心）。
- **前缀·后缀**：名词后缀 **-tion**（例：action, education）；前缀 **dis-**（例：disappear, discover）。
- **同义·反义**：同义 answer, resolution, remedy；反义 problem, puzzle。
- **词性变化**：solve v. 解决；solvable adj. 可解决的；dissolve v. 溶解。

### 24. government /ˈgʌvərnmənt/ n. 政府；内阁
- **词根·渊源**：古法语 **governer**（治理，源自拉丁 gubernare 掌舵、驾驶，源自希腊 kybernan 掌舵）+ 后缀 **-ment**（名词后缀）→ 英语 government；本义“掌舵、治理的行为”，引申为“治理机构→政府”。
- **同根词**：govern（拉丁 gubernare 掌舵→治理）、governor（govern + **-or** 人 = 治理者→州长）、governance（govern + **-ance** 名词后缀 = 治理、管理）。
- **前缀·后缀**：名词后缀 **-ment**（例：movement, development）；名词后缀 **-or**（例：actor, visitor）。
- **同义·反义**：同义 administration, regime；反义 无。
- **词性变化**：govern v. 治理；governor n. 州长；governmental adj. 政府的。
