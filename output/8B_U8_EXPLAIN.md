## 二、逐词说文解字

### 1. mention /ˈmɛnʃən/ v. 提到；说到
- **词根·渊源**：拉丁 **mens / ment-**（心、思考）→ 拉丁 *mentio*（提及）→ 古法语 *mention* → 英语；本义“在心中想起”，引申为“在话中提起”。
- **同根词**：mental（ment 心 + **-al** …的→心理的）、mentionable（mention + **-able** 可…的→可提及的）、comment（**com-** 共同 + ment 心 = 一起想→评论）、mentality（mental + **-ity** 名词后缀→心态）。
- **前缀·后缀**：名词后缀 **-ion**（例：action, station）；形容词后缀 **-able**（例：readable, comfortable）。
- **同义·反义**：同义 refer to（提及）, speak of（谈到）；反义 omit（省略）, ignore（忽视）。
- **变形**：动词 → 第三人称单数：mentions；过去式：mentioned；过去分词：mentioned；现在分词：mentioning；名词派生 → mention n. 提及。

### 2. tonight /təˈnaɪt/ adv. 在今夜；在今晚
- **词根·渊源**：古英语 *tō niht* = **to**（在）+ **night**（夜），本义“在夜里”，后专指“今夜”。
- **同根词**：night（单纯词：夜）、nightly（night + **-ly** …的/每夜的）、midnight（**mid-** 中间 + night = 午夜）、overnight（**over-** 过 + night = 一夜之间）。
- **前缀·后缀**：无前后缀（复合词 to + night）。
- **同义·反义**：同义 this evening（今晚）；反义 无。
- **变形**：副词 → 无比较级（时间副词，不作比较）。

### 3. frightened /ˈfraɪtənd/ adj. 受惊的；害怕的
- **词根·渊源**：古英语 *fyrhto*（恐惧）→ 中古英语 *frighten*（使害怕）→ frighten + **-ed**；本义“被吓到的”，即“受惊的”。
- **同根词**：fright（单纯词：惊吓）、frighten（fright + **-en** 使…→使害怕）、frightening（frighten + **-ing** 令人…的→吓人的）、frightful（fright + **-ful** 充满…的→可怕的）。
- **前缀·后缀**：动词后缀 **-en**（例：strengthen, widen）；形容词后缀 **-ed**（例：tired, excited）。
- **同义·反义**：同义 scared（害怕的）, afraid（恐惧的）；反义 brave（勇敢的）, fearless（无畏的）。
- **变形**：形容词 → 比较级：more frightened；最高级：most frightened；名词派生 → fright n. 惊吓；动词派生 → frighten v. 使害怕；副词派生 → frightenedly adv. 惊恐地。

### 4. throat /θroʊt/ n. 咽喉；喉咙
- **词根·渊源**：古英语 *þrote*（咽喉）→ 中古英语 *throte* → 英语 throat；与德语 *Drossel* 同源，本义即“吞咽的通道”。
- **同根词**：throaty（throat + **-y** 有…特征的→喉音的）、throated（throat + **-ed** 有…喉的，如 full-throated）。
- **前缀·后缀**：形容词后缀 **-y**（例：rainy, healthy）。
- **同义·反义**：同义 gullet（食道）, pharynx（咽）；反义 无。
- **变形**：名词 → 复数：throats；形容词派生 → throaty adj. 沙哑的。

### 5. cough /kɔf/ v. 咳嗽
- **词根·渊源**：中古英语 *coughen*，拟声词，模仿咳嗽声；与中古荷兰语 *kuchen* 同源，本义即“咳”。
- **同根词**：coughing（cough + **-ing** 名词/形容词→咳嗽的）、cougher（cough + **-er** 人→咳嗽者）。
- **前缀·后缀**：名词后缀 **-er**（例：teacher, worker）；动名词后缀 **-ing**（例：running, swimming）。
- **同义·反义**：同义 hack（干咳）；反义 无。
- **变形**：动词 → 第三人称单数：coughs；过去式：coughed；过去分词：coughed；现在分词：coughing；名词派生 → cough n. 咳嗽。

### 6. fear /fɪr/ n. 害怕；惧怕
- **词根·渊源**：古英语 *fǣr*（突然的危险）→ 中古英语 *fere* → 英语 fear；本义“突袭的危险”，引申为“因危险而生的惧怕”。
- **同根词**：fearful（fear + **-ful** 充满…的→害怕的）、fearless（fear + **-less** 无…的→无畏的）、fearsome（fear + **-some** 令人…的→可怕的）。
- **前缀·后缀**：形容词后缀 **-ful**（例：helpful, useful）、**-less**（例：hopeless, careless）。
- **同义·反义**：同义 dread（恐惧）, fright（惊吓）；反义 courage（勇气）, bravery（勇敢）。
- **变形**：名词 → 复数：fears；动词派生 → fear v. 害怕；形容词派生 → fearful adj. 害怕的；副词派生 → fearfully adv. 害怕地。

### 7. creature /ˈkriʧər/ n. 生物
- **词根·渊源**：拉丁 **creare**（创造）→ 拉丁 *creatura*（被创造之物）→ 古法语 *creature* → 英语；本义“被造物”，引申为“生物”。
- **同根词**：create（cre 创造 + **-ate** 动词后缀→创造）、creation（create + **-ion** 名词后缀→创造）、creative（create + **-ive** …的→有创造力的）、creator（create + **-or** 人→创造者）。
- **前缀·后缀**：名词后缀 **-ure**（例：nature, picture）；动词后缀 **-ate**（例：celebrate, educate）。
- **同义·反义**：同义 being（生物）, organism（有机体）；反义 无。
- **变形**：名词 → 复数：creatures；形容词派生 → creatural adj. 生物的。

### 8. ugly /ˈəgli/ adj. 丑陋的；难看的
- **词根·渊源**：古诺斯语 *uggligr*（可怕的）→ 中古英语 *ugly*；本义“令人恐惧的”，后弱化为“难看的”。
- **同根词**：ugliness（ugly + **-ness** 名词后缀→丑陋）。
- **前缀·后缀**：形容词后缀 **-ly**（例：friendly, lovely）；名词后缀 **-ness**（例：kindness, darkness）。
- **同义·反义**：同义 hideous（丑恶的）, unattractive（不吸引人的）；反义 beautiful（美丽的）, pretty（漂亮的）。
- **变形**：形容词 → 比较级：uglier；最高级：ugliest；名词派生 → ugliness n. 丑陋。

### 9. crazy /ˈkreɪzi/ adj. 不理智的；疯狂的
- **词根·渊源**：中古英语 *crasen*（使破碎）→ crazy；本义“脑子破碎的”，引申为“疯狂的”。
- **同根词**：craze（单纯词：狂热）、crazily（crazy + **-ly** 副词后缀→疯狂地）、craziness（crazy + **-ness** 名词后缀→疯狂）。
- **前缀·后缀**：形容词后缀 **-y**（例：rainy, sleepy）；副词后缀 **-ly**（例：quickly, happily）。
- **同义·反义**：同义 mad（发疯的）, insane（精神失常的）；反义 sane（理智的）, sensible（明智的）。
- **变形**：形容词 → 比较级：crazier；最高级：craziest；名词派生 → craziness n. 疯狂；副词派生 → crazily adv. 疯狂地。

### 10. refuse /ˈrɛfˌjuz/ v. 拒绝；回绝
- **词根·渊源**：拉丁 **re-**（回）+ **fundere**（倒、流）→ 拉丁 *refundere*（倒回）→ 古法语 *refuser*；本义“倒回去”，引申为“拒绝接受”。
- **同根词**：refusal（refuse + **-al** 名词后缀→拒绝）、refusable（refuse + **-able** 可…的→可拒绝的）、confuse（**con-** 共同 + fuse 倒 = 倒在一起→混淆）、transfuse（**trans-** 转移 + fuse 倒→输血）。
- **前缀·后缀**：前缀 **re-**（例：return, rebuild）；名词后缀 **-al**（例：arrival, approval）。
- **同义·反义**：同义 decline（谢绝）, reject（拒绝）；反义 accept（接受）, agree（同意）。
- **变形**：动词 → 第三人称单数：refuses；过去式：refused；过去分词：refused；现在分词：refusing；名词派生 → refusal n. 拒绝。

### 11. emergency /ˈimərʤənsi/ n. 紧急情况
- **词根·渊源**：拉丁 **emergere**（浮现）→ 拉丁 *emergentia* → 英语 emergency；本义“突然浮现之事”，引申为“紧急情况”。
- **同根词**：emerge（**e-** 出 + merge 沉 = 从沉没中出来→浮现）、emergent（emerge + **-ent** …的→ emergent 紧急的）、emergence（emerge + **-ence** 名词后缀→出现）。
- **前缀·后缀**：前缀 **e-**（例：exit, elect）；名词后缀 **-ency**（例：efficiency, tendency）。
- **同义·反义**：同义 crisis（危机）, urgency（紧急）；反义 无。
- **变形**：名词 → 复数：emergencies；形容词派生 → emergent adj. 紧急的。

### 12. camera /ˈkæmərə/ n. 照相机
- **词根·渊源**：拉丁 **camera**（房间）→ 拉丁 *camera obscura*（暗室）→ 英语 camera；本义“暗室”，因成像原理得名“照相机”。
- **同根词**：cameraman（camera + man 人→摄影师）、camcorder（camera + recorder 记录器→摄像机）。
- **前缀·后缀**：无前后缀（借词）。
- **同义·反义**：同义 无；反义 无。
- **变形**：名词 → 复数：cameras。

### 13. tent /tɛnt/ n. 帐篷；帐棚
- **词根·渊源**：拉丁 **tendere**（伸展）→ 古法语 *tente* → 英语 tent；本义“伸展的布”，即“帐篷”。
- **同根词**：tentative（tent 伸展 + **-ative** …的→试探性的）、extend（**ex-** 出 + tend 伸展→延伸）、tension（tens 伸展 + **-ion** 名词后缀→张力）。
- **前缀·后缀**：无前后缀（单纯词）。
- **同义·反义**：同义 无；反义 无。
- **变形**：名词 → 复数：tents。

### 14. unnecessary /ənˈnɛsəˌsɛri/ adj. 不需要的；不必要的；多余的
- **词根·渊源**：拉丁 **necessarius**（必需的）→ 英语 necessary；加否定前缀 **un-** 构成 unnecessary，本义“非必需的”。
- **同根词**：necessary（**ne-** 不 + cess 走 + **-ary** …的 = 不能走的→必需的）、necessity（necess + **-ity** 名词后缀→必要性）、necessitate（necessity + **-ate** 动词后缀→使成为必要）。
- **前缀·后缀**：否定前缀 **un-**（例：unhappy, unfair）；形容词后缀 **-ary**（例：ordinary, military）。
- **同义·反义**：同义 needless（不必要的）, superfluous（多余的）；反义 necessary（必要的）, essential（必需的）。
- **变形**：形容词 → 比较级：more unnecessary；最高级：most unnecessary；名词派生 → unnecessary n. 不必要之物；副词派生 → unnecessarily adv. 不必要地。

### 15. whether /ˈwɛðər/ conj. 是否
- **词根·渊源**：古英语 *hwæþer*（两者中的哪一个）→ 中古英语 *whether*；本义“二者择一”，引申为“是否”。
- **同根词**：either（**e-** 每 + ther 二者之一→两者之一）、neither（**n-** 不 + either = 两者都不）。
- **前缀·后缀**：无前后缀（单纯词）。
- **同义·反义**：同义 if（是否）；反义 无。
- **变形**：连词 → 无形态变化。

### 16. backward /ˈbækwərd/ adv. 朝反方向；倒着
- **词根·渊源**：古英语 *bæc*（背）→ 英语 back + **-ward**（向…方向）；本义“向背后”，引申为“朝反方向”。
- **同根词**：back（单纯词：背）、backwards（back + **-wards** 向…方向→向后）、forward（**for-** 前 + ward 向…方向→向前）。
- **前缀·后缀**：方向后缀 **-ward**（例：forward, toward）。
- **同义·反义**：同义 backwards（向后）, rearward（向后）；反义 forward（向前）。
- **变形**：副词 → 无比较级（方向副词，不作比较）；形容词派生 → backward adj. 向后的。

### 17. disappoint /ˌdɪsəˈpɔɪnt/ v. 使失望
- **词根·渊源**：古法语 *desapointer* = **des-**（去除）+ **apointier**（安排）→ 英语 disappoint；本义“解除任命”，引申为“使希望落空”。
- **同根词**：disappointment（disappoint + **-ment** 名词后缀→失望）、disappointed（disappoint + **-ed** …的→失望的）、disappointing（disappoint + **-ing** 令人…的→令人失望的）、appoint（**ap-** 向 + point 点 = 指定→任命）。
- **前缀·后缀**：否定前缀 **dis-**（例：disagree, disappear）；名词后缀 **-ment**（例：movement, agreement）。
- **同义·反义**：同义 let down（使失望）, dishearten（使沮丧）；反义 satisfy（使满意）, encourage（鼓励）。
- **变形**：动词 → 第三人称单数：disappoints；过去式：disappointed；过去分词：disappointed；现在分词：disappointing；名词派生 → disappointment n. 失望；形容词派生 → disappointed adj. 失望的。

### 18. argue /ˈɑrgju/ v. 争吵；争辩
- **词根·渊源**：拉丁 **arguere**（使明白、证明）→ 古法语 *arguer* → 英语 argue；本义“论证”，引申为“争辩”。
- **同根词**：argument（argue + **-ment** 名词后缀→争论）、arguable（argue + **-able** 可…的→可争辩的）、argumentative（argument + **-ative** …的→好争辩的）。
- **前缀·后缀**：名词后缀 **-ment**（例：movement, agreement）；形容词后缀 **-able**（例：readable, comfortable）。
- **同义·反义**：同义 quarrel（争吵）, debate（辩论）；反义 agree（同意）, concede（让步）。
- **变形**：动词 → 第三人称单数：argues；过去式：argued；过去分词：argued；现在分词：arguing；名词派生 → argument n. 争论；形容词派生 → arguable adj. 可争辩的。

### 19. be frightened of  v. 害怕
- **同义搭配**：be afraid of（害怕）/ be scared of（害怕）
- **反义搭配**：be brave enough to（有勇气做）

### 20. have a cough  v. 咳嗽
- **同义搭配**：cough（咳嗽）/ catch a cough（患咳嗽）
- **反义搭配**：无

### 21. in an emergency  prep. 在紧急情况下
- **同义搭配**：in a crisis（在危机中）/ in urgent situations（在紧急情况下）
- **反义搭配**：in normal times（在正常情况下）

### 22. take photos  v. 拍照
- **同义搭配**：take pictures（拍照）/ snap photos（快照）
- **反义搭配**：无

### 23. set up a tent  v. 搭帐篷
- **同义搭配**：put up a tent（搭帐篷）/ pitch a tent（搭帐篷）
- **反义搭配**：take down a tent（拆帐篷）

### 24. argue with  n. 与……争吵
- **同义搭配**：quarrel with（与……争吵）/ have an argument with（与……争论）
- **反义搭配**：agree with（同意……）
