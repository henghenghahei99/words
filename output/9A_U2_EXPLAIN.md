## 二、逐词说文解字

### 1. firm /fərm/ adj. 牢固的;坚硬的
- **词根·渊源**：拉丁 **firmus**（坚固的、稳定的）→ 古法语 *ferme* → 英语 firm；本义即“坚固的”，引申为“牢固的、坚硬的”，再引申出“坚定的”等抽象义。
- **同根词**：confirm（**con-** 加强 + firm 坚固 = 使更坚固→确认）、affirm（**af-** 向 + firm 坚固 = 向…断言使其坚固→肯定）、infirm（**in-** 不 + firm 坚固 = 不坚固的→虚弱的）、firmament（firm 坚固 + **-ament** 名词后缀 = 坚固的天穹→苍穹）。
- **前缀·后缀**：无前后缀（单纯词，源自拉丁 firmus）。
- **同义·反义**：同义 solid（坚固的）, steady（稳固的）；反义 loose（松的）, unstable（不稳定的）。
- **变形**：形容词 → 比较级：firmer；最高级：firmest；副词派生 → firmly adv. 牢固地；名词派生 → firmness n. 坚固。

### 2. ignorance /ˈɪgnərəns/ n. 无知
- **词根·渊源**：拉丁 **ignorare**（不知道）← **i-**（=in- 不）+ **gnor-**（=gnoscere 知道）→ 古法语 *ignorance* → 英语；本义“不知道的状态”，即“无知”。
- **同根词**：ignore（i- 不 + gnor 知道 = 不知道→忽视）、ignorant（ignor 不知道 + **-ant** …的→无知的）、recognize（**re-** 再 + cogn 知道 + **-ize** 动词后缀 = 再知道→认出）、diagnose（**dia-** 穿过 + gnose 知道 = 彻底知道→诊断）。
- **前缀·后缀**：否定前缀 **i-/in-**（例：invisible, illegal）；名词后缀 **-ance**（例：importance, distance）。
- **同义·反义**：同义 unawareness（不觉察）, illiteracy（文盲）；反义 knowledge（知识）, awareness（意识）。
- **变形**：名词 → 复数：不可数；形容词派生 → ignorant adj. 无知的；副词派生 → ignorantly adv. 无知地。

### 3. application /ˌæpləˈkeɪʃən/ n. (尤指理论、发现等的)应用
- **词根·渊源**：拉丁 **applicare**（贴上、附加）← **ad-**（向）+ **plicare**（折叠）→ 古法语 *application* → 英语；本义“把一物贴附到另一物上”，引申为“把理论用于实际”，即“应用”。
- **同根词**：apply（**ap-** 向 + ply 折叠 = 贴上去→应用、申请）、applicant（applic 应用 + **-ant** 人 = 申请人）、applicable（applic 应用 + **-able** 可…的 = 适用的）、complicate（**com-** 一起 + plic 折叠 = 折在一起→使复杂）、imply（**im-** 向内 + ply 折叠 = 折进去→暗示）、reply（**re-** 回 + ply 折叠 = 折回去→回复）。
- **前缀·后缀**：方向前缀 **ad-/ap-**（例：advance, approach）；名词后缀 **-ation**（例：information, education）。
- **同义·反义**：同义 use（使用）, employment（运用）；反义 无。
- **变形**：名词 → 复数：applications；动词派生 → apply v. 应用、申请；形容词派生 → applicable adj. 适用的。

### 4. fancy /ˈfænsi/ adj. 精致的;绚丽的
- **词根·渊源**：由名词 fancy（想象力、幻想）转作形容词，fancy 是 **fantasy** 的缩略形式，源自希腊 **phantasia**（想象、显现）→ 拉丁 *phantasia* → 古法语 *fantasie* → 英语；本义“想象出来的”，引申为“花哨的、精致的、绚丽的”。
- **同根词**：fantasy（希腊 phantasia 想象→幻想）、fantastic（fantas 想象 + **-tic** …的 = 想象出来的→极好的、奇异的）、phantom（希腊 phantasma 显现的影像→幽灵）、phenomenon（希腊 phainomenon 显现之物→现象）。
- **前缀·后缀**：无前后缀（单纯词，fantasy 的缩略）。
- **同义·反义**：同义 elaborate（精美的）, ornate（华丽的）；反义 plain（朴素的）, simple（简单的）。
- **变形**：形容词 → 比较级：fancier；最高级：fanciest；名词派生 → fancy n. 想象力、爱好；动词派生 → fancy v. 想象、想要。

### 5. satisfied /ˈsætɪsˌfaɪd/ adj. 满意的;满足的
- **词根·渊源**：拉丁 **satisfacere**（做够、使满足）← **satis**（足够）+ **facere**（做）→ 古法语 *satisfaire* → 英语 satisfy，过去分词 satisfied 作形容词；本义“被做够了”，即“满足的”。
- **同根词**：satisfy（satis 足够 + fy 做 = 做够→使满足）、satisfaction（satis 足够 + fact 做 + **-ion** 名词后缀 = 做够的状态→满意）、saturate（satis 足够 + **-ate** 动词后缀 = 使足够→使饱和）、satisfactory（satis 足够 + fact 做 + **-ory** …的 = 令人满意的）。
- **前缀·后缀**：无前缀；后缀 **-ed** 构成过去分词/形容词（例：tired, interested）。
- **同义·反义**：同义 content（满足的）, pleased（高兴的）；反义 dissatisfied（不满的）, unsatisfied（未满足的）。
- **变形**：形容词 → 无比较级（多作表语/定语，一般不作比较）；动词派生 → satisfy v. 使满意；名词派生 → satisfaction n. 满意。

### 6. prince /prɪns/ n. 王子
- **词根·渊源**：拉丁 **princeps**（第一人、首领）← **primus**（第一）+ **capere**（拿、取）→ 古法语 *prince* → 英语；本义“居首位者”，后专指“君主的儿子”，即“王子”。
- **同根词**：principal（prin 第一 + cip 拿 + **-al** …的 = 居首的→主要的）、principle（prin 第一 + cip 拿 + **-le** = 首要的东西→原则）、prime（拉丁 primus 第一→首要的）、primary（prim 第一 + **-ary** …的 = 最初的→首要的）、princess（prince 王子 + **-ess** 女性 = 公主）。
- **前缀·后缀**：无前缀；名词后缀 **-ess** 表女性（例：actress, hostess）。
- **同义·反义**：同义 无；反义 无。
- **变形**：名词 → 复数：princes；名词派生 → princess n. 公主；形容词派生 → princely adj. 王子的、高贵的。

### 7. displace /dɪˈspleɪs/ v. 排出;挤出;取代；替代
- **词根·渊源**：**dis-**（离开、去掉）+ **place**（位置）→ 法语 *déplacer* → 英语；本义“使离开原位”，引申为“排出、挤出”，再引申为“取代”。
- **同根词**：place（拉丁 platea 宽街→位置）、replace（**re-** 回 + place 位置 = 放回原位→取代）、placement（place 位置 + **-ment** 名词后缀 = 放置、安置）、displacement（displace 排出 + **-ment** 名词后缀 = 排出、取代）。
- **前缀·后缀**：否定/分离前缀 **dis-**（例：disappear, disconnect）；名词后缀 **-ment**（例：movement, agreement）。
- **同义·反义**：同义 replace（取代）, remove（移走）；反义 restore（恢复）, reinstate（使复位）。
- **变形**：动词 → 第三人称单数：displaces；过去式：displaced；过去分词：displaced；现在分词：displacing；名词派生 → displacement n. 排出、取代。

### 8. fool /ful/ v. 欺骗;愚弄
- **词根·渊源**：古法语 **fol**（愚蠢的、疯子）→ 英语 fool，本为形容词/名词“愚人”，后转为动词“愚弄、欺骗”；词源可追溯至拉丁 *follis*（风箱、傻瓜），存疑。
- **同根词**：foolish（fool 愚人 + **-ish** …的 = 愚蠢的）、folly（古法语 fol 愚蠢 + **-y** 名词后缀 = 愚蠢）、befool（**be-** 使 + fool 愚人 = 愚弄）。
- **前缀·后缀**：无前缀；后缀 **-ish** 构成形容词（例：childish, selfish）。
- **同义·反义**：同义 deceive（欺骗）, trick（哄骗）；反义 enlighten（启发）, undeceive（使醒悟）。
- **变形**：动词 → 第三人称单数：fools；过去式：fooled；过去分词：fooled；现在分词：fooling；名词派生 → fool n. 傻瓜；形容词派生 → foolish adj. 愚蠢的。

### 9. prison /ˈprɪzən/ n. 监狱;牢狱
- **词根·渊源**：拉丁 **prehendere**（抓住）→ 拉丁 *prensio*（抓捕）→ 古法语 *prison* → 英语；本义“被抓住、被囚禁的状态”，引申为“关押犯人的地方”，即“监狱”。
- **同根词**：prisoner（prison 监狱 + **-er** 人 = 囚犯）、apprehend（**ap-** 向 + prehend 抓住 = 抓住→逮捕、理解）、comprehend（**com-** 完全 + prehend 抓住 = 完全抓住→理解）、prehensile（prehend 抓住 + **-ile** 能…的 = 能抓握的）。
- **前缀·后缀**：无前缀；名词后缀 **-er** 表人（例：teacher, worker）。
- **同义·反义**：同义 jail（监狱）, cell（牢房）；反义 freedom（自由）, liberty（自由）。
- **变形**：名词 → 复数：prisons；名词派生 → prisoner n. 囚犯。

### 10. wire /waɪər/ n. 金属丝;电线
- **词根·渊源**：古英语 **wīr**（金属丝）→ 中古英语 *wir* → 英语；本义“拉成细条的金属”，引申为“电线”；与拉丁 *viere*（编织）可能同源，存疑。
- **同根词**：wireless（wire 电线 + **-less** 无…的 = 无线的→无线电）、wiring（wire 电线 + **-ing** 名词后缀 = 布线）、wiretap（wire 电线 + tap 窃听 = 搭线窃听）。
- **前缀·后缀**：无前缀；后缀 **-less** 构成否定形容词（例：hopeless, careless）。
- **同义·反义**：同义 cable（电缆）, line（线）；反义 无。
- **变形**：名词 → 复数：wires；动词派生 → wire v. 接电线、电汇；形容词派生 → wiry adj. 铁丝般的、瘦而结实的。

### 11. prove /pruv/ v. 证明;证实
- **词根·渊源**：拉丁 **probare**（检验、证明）← **probus**（好的、正直的）→ 古法语 *prover* → 英语；本义“检验是否良好”，引申为“证明、证实”。
- **同根词**：proof（拉丁 proba 检验→证据）、probable（prob 检验 + **-able** 可…的 = 可检验的→很可能的）、probation（prob 检验 + **-ation** 名词后缀 = 试用期、缓刑）、approve（**ap-** 向 + prove 检验 = 检验后认可→批准）、disprove（**dis-** 不 + prove 证明 = 证明不成立→反驳）。
- **前缀·后缀**：无前缀；后缀 **-able** 构成形容词（例：readable, comfortable）。
- **同义·反义**：同义 verify（核实）, confirm（证实）；反义 disprove（反驳）, refute（驳斥）。
- **变形**：动词 → 第三人称单数：proves；过去式：proved；过去分词：proved / proven；现在分词：proving；名词派生 → proof n. 证据。

### 12. hardly /ˈhɑrdli/ adv. 几乎不;几乎没有
- **词根·渊源**：古英语 **heard**（硬的、严厉的）→ 中古英语 *hard* → 英语 hard（艰难的）+ **-ly**（副词后缀）→ hardly；本义“艰难地、严厉地”，后引申为“几乎不”。
- **同根词**：hard（古英语 heard 硬的→艰难的）、harden（hard 硬 + **-en** 使… = 使变硬）、hardy（hard 硬 + **-y** …的 = 耐劳的、坚强的）、hardness（hard 硬 + **-ness** 名词后缀 = 坚硬）。
- **前缀·后缀**：无前缀；副词后缀 **-ly**（例：quickly, happily）。
- **同义·反义**：同义 barely（几乎不）, scarcely（几乎不）；反义 无。
- **变形**：副词 → 无比较级（本身含否定义，不作比较）；形容词派生 → hard adj. 艰难的、硬的。

### 13. balanced /ˈbælənst/ adj. 保持(或显示)平衡的
- **词根·渊源**：拉丁 **bilanx**（两秤盘的）← **bi-**（二）+ **lanx**（秤盘）→ 晚期拉丁 *bilancia* → 古法语 *balance* → 英语 balance，加 **-ed** 构成形容词；本义“两盘相等的”，引申为“平衡的”。
- **同根词**：balance（bi- 二 + lanc 秤盘 = 两秤盘→天平、平衡）、imbalance（**im-** 不 + balance 平衡 = 不平衡）、unbalanced（**un-** 不 + balanced 平衡的 = 不平衡的）、counterbalance（**counter-** 相反 + balance 平衡 = 抗衡）。
- **前缀·后缀**：无前缀；后缀 **-ed** 构成形容词（例：talented, aged）。
- **同义·反义**：同义 steady（稳定的）, even（均衡的）；反义 unbalanced（不平衡的）, lopsided（偏斜的）。
- **变形**：形容词 → 无比较级（多作定语/表语，一般不作比较）；名词派生 → balance n. 平衡；动词派生 → balance v. 使平衡。

### 14. reject /ˈriʤɛkt/ v. 拒绝接受;不予考虑
- **词根·渊源**：拉丁 **reicere**（扔回）← **re-**（回）+ **iacere**（扔）→ 拉丁 *rejectus* → 英语；本义“扔回去”，引申为“拒绝接受、不予考虑”。
- **同根词**：eject（**e-** 出 + ject 扔 = 扔出去→弹出）、inject（**in-** 入 + ject 扔 = 扔进去→注射）、project（**pro-** 向前 + ject 扔 = 向前扔→投射、项目）、subject（**sub-** 在下 + ject 扔 = 扔在下面→使服从、主题）、object（**ob-** 反对 + ject 扔 = 扔到对面→反对、物体）。
- **前缀·后缀**：回/反前缀 **re-**（例：return, recall）；词根 **ject** 扔（例：inject, eject）。
- **同义·反义**：同义 refuse（拒绝）, decline（谢绝）；反义 accept（接受）, approve（批准）。
- **变形**：动词 → 第三人称单数：rejects；过去式：rejected；过去分词：rejected；现在分词：rejecting；名词派生 → rejection n. 拒绝。

### 15. thus /ðəs/ adv. 因此;如此
- **词根·渊源**：古英语 **þus**（如此、这样）→ 中古英语 *thus* → 英语；本义“以这种方式”，引申为“因此、如此”。
- **同根词**：无常用同根词（古英语单纯词，现代英语中无派生词族）。
- **前缀·后缀**：无前后缀（单纯词）。
- **同义·反义**：同义 therefore（因此）, consequently（因此）；反义 无。
- **变形**：副词 → 无比较级（不作比较）。

### 16. as a whole  prep. 作为一个整体;总体上
- **同义搭配**：on the whole / in general
- **反义搭配**：in part

### 17. get something across  v. 把某事讲清楚
- **同义搭配**：make something clear / put something over
- **反义搭配**：无
