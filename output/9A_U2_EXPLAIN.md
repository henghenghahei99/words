## 二、逐词说文解字

### 1. mind /maɪnd/ n. 聪明人，富有才智的人
- **词根·渊源**：古英语 **gemynd**（记忆、思想）→ 原始日耳曼语 *ga-mundiz*，与拉丁 **mens / ment-**（心智）同出 PIE *men-*（思考）；本义“记忆、心智”，引申指“有才智的人”。
- **同根词**：mental（ment 心智 + **-al** …的→心理的）、mention（ment 心智 + **-ion** 名词后缀：在脑中想起→提及）、comment（**com-** 共同 + ment 心智 = 共同思考→评论）、remind（**re-** 再 + mind 心 = 再想起→提醒）、mindful（mind + **-ful** 充满…的→留心的）。
- **前缀·后缀**：无前后缀（单纯词）。
- **同义·反义**：同义 intellect（才智之士）, brain（聪明人）；反义 fool（傻瓜）。
- **变形**：名词 → 复数：minds；形容词派生 → mindful adj. 留心的；副词派生 → mindfully adv. 留心地；动词派生 → mind v. 介意。

### 2. astronomer /əˈstrɑːnəmər/ n. 天文学家
- **词根·渊源**：希腊 **astron**（星）+ **nomos**（法则、规律）→ 拉丁 *astronomia* → 古法语 *astronomie* → 英语 astronomy；本义“研究星辰规律之学”，加 **-er** 指从事此学的人。
- **同根词**：astronomy（astro 星 + nom 法则 + **-y** 学科→天文学）、astronaut（astro 星 + naut 航行者→宇航员）、asteroid（aster 星 + **-oid** 像…的→小行星）、disaster（**dis-** 坏 + aster 星 = 星位不吉→灾难）、astrology（astro 星 + log 言说 + **-y** →占星术）。
- **前缀·后缀**：名词后缀 **-er**（例：teacher, worker）；组合成分 astro-（例：astronaut, asteroid）。
- **同义·反义**：同义 stargazer（观星者）；反义 无。
- **变形**：名词 → 复数：astronomers；形容词派生 → astronomical adj. 天文的；副词派生 → astronomically adv. 天文学上。

### 3. genius /ˈdʒiːniəs/ n. 天才；有天才的,天才人物
- **词根·渊源**：拉丁 **genius**（守护神、天生的禀赋）← 词根 **gen-**（生、产生）→ 英语；本义“人与生俱来的神灵”，引申为“天赋”及“有天赋的人”。
- **同根词**：generate（gen 生 + **-erate** 动词后缀→产生）、generation（generate + **-ion** →一代）、genetic（gen 生 + **-etic** …的→基因的）、genuine（gen 生 + **-uine** 天生的→真正的）、pregnant（**pre-** 前 + gn 生 = 产前→怀孕的）。
- **前缀·后缀**：名词后缀 **-ius**（例：radius, stadium）。
- **同义·反义**：同义 talent（天才）, prodigy（奇才）；反义 idiot（白痴）。
- **变形**：名词 → 复数：geniuses；形容词派生 → genius adj. 有天才的；ingenious adj. 灵巧的。

### 4. consider /kənˈsɪdər/ v. 认为；觉得
- **词根·渊源**：拉丁 **considerare**（仔细察看，原指观察星象）← **com-** 加强 + **sidus / sider-**（星辰）→ 古法语 *considerer* → 英语；本义“细看星象以定吉凶”，引申为“仔细思考、认为”。
- **同根词**：consideration（consider + **-ation** 名词后缀→考虑）、considerate（consider + **-ate** …的→体贴的）、considerable（consider + **-able** 值得…的→相当大的）、desire（**de-** 加强 + sider 星 = 盼星→渴望）、sidereal（sider 星 + **-eal** …的→恒星的）。
- **前缀·后缀**：前缀 **con-**（例：connect, confirm）；动词后缀 **-er**（例：deliver, recover）。
- **同义·反义**：同义 regard（认为）, deem（视为）；反义 ignore（忽视）。
- **变形**：动词 → 第三人称单数：considers；过去式：considered；过去分词：considered；现在分词：considering；名词派生 → consideration n. 考虑；形容词派生 → considerate adj. 体贴的；副词派生 → considering adv. 考虑到。

### 5. sense /sɛns/ n. 理解力，判断力
- **词根·渊源**：拉丁 **sensus**（感觉、知觉）← **sentire**（感觉）→ 古法语 *sens* → 英语；本义“感官知觉”，引申为“理解力、判断力”。
- **同根词**：sensitive（sens 感觉 + **-itive** …的→敏感的）、sensation（sens 感觉 + **-ation** →感觉）、sensible（sens 感觉 + **-ible** 能…的→明智的）、consent（**con-** 共同 + sent 感觉 = 同感→同意）、sentiment（sent 感觉 + **-iment** →情感）。
- **前缀·后缀**：无前后缀（单纯词）。
- **同义·反义**：同义 judgment（判断力）, understanding（理解力）；反义 nonsense（荒谬）。
- **变形**：名词 → 复数：senses；形容词派生 → sensible adj. 明智的；副词派生 → sensibly adv. 明智地；动词派生 → sense v. 感觉到。

### 6. humour /'hjuːmə(r)/ n. 幽默，幽默感；感觉，心情
- **词根·渊源**：拉丁 **humor**（体液）→ 古法语 *humour* → 英语；中世纪医学认为人体四种体液决定性情，本义“体液→性情”，引申为“心情”及“幽默”。
- **同根词**：humid（hum 湿 + **-id** …的→潮湿的）、humidity（humid + **-ity** 名词后缀→湿度）、humoral（humor 体液 + **-al** …的→体液的）、humorist（humor + **-ist** 人→幽默作家）、inhume（**in-** 入 + hum 土 = 入土→埋葬）。
- **前缀·后缀**：名词后缀 **-our**（例：colour, favour）。
- **同义·反义**：同义 wit（风趣）, mood（心情）；反义 seriousness（严肃）。
- **变形**：名词 → 复数：humours；形容词派生 → humorous adj. 幽默的；副词派生 → humorously adv. 幽默地。

### 7. invitation /ˌɪnvɪˈteɪʃn/ n. 邀请；请帖
- **词根·渊源**：拉丁 **invitare**（邀请）← **in-** 向 + **vitare**（追求、召唤，存疑）→ 古法语 *invitation* → 英语；本义“向人召唤”，引申为“邀请、请帖”。
- **同根词**：invite（**in-** 向 + vit 召唤 + **-e** →邀请）、inviting（invite + **-ing** …的→诱人的）、invitational（invitation + **-al** …的→邀请的）、visitor（vis 看 + **-itor** 人→来访者，与 vit 形近义通，存疑）。
- **前缀·后缀**：前缀 **in-**（例：include, invent）；名词后缀 **-ation**（例：education, information）。
- **同义·反义**：同义 request（请求）, summons（召唤）；反义 refusal（拒绝）。
- **变形**：名词 → 复数：invitations；动词派生 → invite v. 邀请；形容词派生 → invitational adj. 邀请的。

### 8. theory /ˈθiːəri/ n. 学说，理论；论；说
- **词根·渊源**：希腊 **theoria**（观看、沉思）← **theoros**（观看者）← **thea**（景象）→ 拉丁 *theoria* → 英语；本义“静观沉思”，引申为“理论、学说”。
- **同根词**：theoretical（theory + **-etical** …的→理论的）、theorist（theory + **-ist** 人→理论家）、theorize（theory + **-ize** 动词化→理论化）、theater（thea 景象 + **-ter** 场所→剧场）、theorem（theo 观 + **-rem** 名词后缀→定理）。
- **前缀·后缀**：名词后缀 **-y**（例：history, memory）。
- **同义·反义**：同义 hypothesis（假说）, doctrine（学说）；反义 practice（实践）。
- **变形**：名词 → 复数：theories；形容词派生 → theoretical adj. 理论的；副词派生 → theoretically adv. 理论上；动词派生 → theorize v. 建立理论。

### 9. university /ˌjuːnɪˈvɜːsəti/ n. 大学
- **词根·渊源**：拉丁 **universitas**（全体、团体）← **unus**（一）+ **versus**（转）→ 古法语 *université* → 英语；本义“转为一体的团体”，指师生行会，引申为“大学”。
- **同根词**：universe（uni 一 + vers 转 + **-e** = 转为一体的万物→宇宙）、universal（universe + **-al** …的→普遍的）、unite（uni 一 + **-ite** 动词化→联合）、unique（uni 一 + **-que** …的→唯一的）、version（vers 转 + **-ion** →版本）。
- **前缀·后缀**：前缀 **uni-**（例：uniform, unicorn）；名词后缀 **-ity**（例：activity, reality）。
- **同义·反义**：同义 college（学院）, academy（学府）；反义 无。
- **变形**：名词 → 复数：universities；形容词派生 → universal adj. 普遍的；副词派生 → universally adv. 普遍地。

### 10. pleasure /ˈpleʒər/ n. 乐事，趣事，快事
- **词根·渊源**：拉丁 **placere**（使高兴）→ 古法语 *plaisir* → 英语；本义“使人愉悦之事”，引申为“乐事、愉快”。
- **同根词**：please（pleas 取悦 + **-e** →使高兴）、pleasant（pleas 取悦 + **-ant** …的→令人愉快的）、pleasing（please + **-ing** …的→讨人喜欢的）、pleasurable（pleasure + **-able** 能…的→令人愉快的）、complacent（**com-** 加强 + plac 取悦 + **-ent** …的→自满的）。
- **前缀·后缀**：名词后缀 **-ure**（例：nature, culture）。
- **同义·反义**：同义 delight（乐事）, joy（快乐）；反义 pain（痛苦）。
- **变形**：名词 → 复数：pleasures；形容词派生 → pleasant adj. 令人愉快的；副词派生 → pleasantly adv. 愉快地。

### 11. avoid /əˈvɔɪd/ v. 避免；避开
- **词根·渊源**：古法语 **esvuidier**（清空）← **es-** 出 + **vuide** 空 → 英语；本义“腾空、离开”，引申为“避开、避免”。
- **同根词**：avoidance（avoid + **-ance** 名词后缀→避免）、void（void 空→空的）、devoid（**de-** 完全 + void 空→缺乏的）、vacant（vac 空 + **-ant** …的→空的，与 void 同源）、vacation（vac 空 + **-ation** →假期）。
- **前缀·后缀**：前缀 **a-**（例：aloud, awake）；动词后缀 **-oid**（例：void, devoid）。
- **同义·反义**：同义 evade（逃避）, escape（逃脱）；反义 face（面对）。
- **变形**：动词 → 第三人称单数：avoids；过去式：avoided；过去分词：avoided；现在分词：avoiding；名词派生 → avoidance n. 避免；形容词派生 → avoidable adj. 可避免的。

### 12. lecture /ˈlektʃər/ n. 讲座；演讲
- **词根·渊源**：拉丁 **lectura**（诵读）← **legere**（读、选）→ 古法语 *lecture* → 英语；本义“诵读”，引申为“讲座、演讲”。
- **同根词**：lecturer（lecture + **-er** 人→讲师）、collect（**col-** 共同 + lect 选 = 选到一起→收集）、select（**se-** 分开 + lect 选→挑选）、elect（**e-** 出 + lect 选→选举）、legend（leg 读 + **-end** 名词后缀→传说）。
- **前缀·后缀**：名词后缀 **-ure**（例：picture, nature）。
- **同义·反义**：同义 speech（演讲）, talk（讲座）；反义 无。
- **变形**：名词 → 复数：lectures；动词派生 → lecture v. 讲课；名词派生 → lecturer n. 讲师。

### 13. tonight /təˈnaɪt/ n. 在今晚；在今夜
- **词根·渊源**：古英语 **tō niht**（在夜里）← **tō**（在）+ **niht**（夜）→ 中古英语 *tonight*；本义“在这一夜”，引申为“今晚”。
- **同根词**：night（niht 夜→夜晚）、nightly（night + **-ly** …的→每夜的）、midnight（**mid-** 中间 + night 夜→午夜）、nightmare（night 夜 + mare 梦魇→噩梦）、fortnight（**fourteen** 十四 + night 夜→两星期）。
- **前缀·后缀**：前缀 **to-**（例：today, tomorrow）。
- **同义·反义**：同义 this evening（今晚）；反义 无。
- **变形**：名词 → 复数：tonights（少用）；副词 → 无比较级（时间副词，不作比较）。

### 14. audience /ˈɔːdiəns/ n. 观众，听众；读者；觐见，拜见
- **词根·渊源**：拉丁 **audientia**（听）← **audire**（听）→ 古法语 *audience* → 英语；本义“听的行为”，引申为“听众、观众”及“觐见”。
- **同根词**：audio（audi 听 + **-o** →音频的）、audible（audi 听 + **-ible** 能…的→听得见的）、audition（audi 听 + **-ition** →试听）、auditorium（audi 听 + **-orium** 场所→礼堂）、obey（**ob-** 向 + aud 听 = 听从→服从）。
- **前缀·后缀**：名词后缀 **-ence**（例：silence, patience）。
- **同义·反义**：同义 listeners（听众）, spectators（观众）；反义 performers（表演者）。
- **变形**：名词 → 复数：audiences；形容词派生 → auditory adj. 听觉的。

### 15. trust /trʌst/ v. 相信；信任；信赖
- **词根·渊源**：古诺斯语 **traust**（信任、依靠）→ 中古英语 *trust*；与 **true** 同出日耳曼语 *treuwaz*（忠实）；本义“依靠、忠实”，引申为“信任”。
- **同根词**：true（tru 忠实 + **-e** →真实的）、truth（true + **-th** 名词后缀→真理）、trusty（trust + **-y** …的→可信赖的）、trustworthy（trust + worthy 值得的→值得信赖的）、betroth（**be-** 加强 + troth 忠实→订婚）。
- **前缀·后缀**：无前后缀（单纯词）。
- **同义·反义**：同义 believe（相信）, rely（信赖）；反义 distrust（不信任）。
- **变形**：动词 → 第三人称单数：trusts；过去式：trusted；过去分词：trusted；现在分词：trusting；名词派生 → trust n. 信任；形容词派生 → trustful adj. 信任的；副词派生 → trustingly adv. 信任地。

### 16. seat /siːt/ n. 座位，座处
- **词根·渊源**：古诺斯语 **sæti**（座位）← 原始日耳曼语 *sēt-*（坐）→ 古英语 *set*；与 **sit** 同出 PIE *sed-*（坐）；本义“坐的地方”，引申为“座位”。
- **同根词**：sit（sit 坐→坐）、session（sess 坐 + **-ion** →会议）、settle（set 坐 + **-tle** 动词化→安顿）、reside（**re-** 回 + sid 坐 = 坐下→居住）、president（**pre-** 前 + sid 坐 + **-ent** 人 = 坐在前面的人→总统）。
- **前缀·后缀**：无前后缀（单纯词）。
- **同义·反义**：同义 chair（椅子）, place（座位）；反义 无。
- **变形**：名词 → 复数：seats；动词派生 → seat v. 使就座；形容词派生 → seated adj. 坐着的。

### 17. applause /əˈplɔːz/ n. 掌声，喝彩
- **词根·渊源**：拉丁 **applausus**（拍手）← **ad-** 向 + **plaudere**（拍手）→ 英语；本义“拍手”，引申为“掌声、喝彩”。
- **同根词**：applaud（**ap-** 向 + plaud 拍手→鼓掌）、plausible（plaus 拍手 + **-ible** 能…的 = 值得拍手的→似乎合理的）、explode（**ex-** 出 + plod 拍手 = 拍手赶下台→爆炸，存疑）、plaudit（plaud 拍手 + **-it** →喝彩）。
- **前缀·后缀**：前缀 **ap-**（例：appear, apply）；名词后缀 **-ause**（例：cause, pause）。
- **同义·反义**：同义 clapping（掌声）, cheers（喝彩）；反义 boos（嘘声）。
- **变形**：名词 → 复数：applauses（多用不可数）；动词派生 → applaud v. 鼓掌。

### 18. pale /peɪl/ adj. 苍白的；灰白的
- **词根·渊源**：拉丁 **pallidus**（苍白的）← **pallere**（发白）→ 古法语 *paile* → 英语；本义“颜色淡白”，引申为“苍白的、灰白的”。
- **同根词**：pallid（pall 苍白 + **-id** …的→苍白的）、pallor（pall 苍白 + **-or** 名词后缀→苍白）、pallidness（pallid + **-ness** 名词后缀→苍白）、palladium（pall 苍白 + **-adium** →钯，存疑）。
- **前缀·后缀**：无前后缀（单纯词）。
- **同义·反义**：同义 white（白的）, wan（苍白的）；反义 ruddy（红润的）。
- **变形**：形容词 → 比较级：paler；最高级：palest；名词派生 → paleness n. 苍白；副词派生 → palely adv. 苍白地；动词派生 → pale v. 变苍白。

### 19. achievement /əˈtʃivmənt/ n. 成绩，成就；完成，实现
- **词根·渊源**：拉丁 **ad-**（向）+ **caput / capit-**（头）→ 古法语 *achever*（完成、达到顶点）→ 英语 achieve + 名词后缀 **-ment**；本义“做到头、达到顶点”，引申为“完成”及“所完成之事→成就”。
- **同根词**：achieve（**a-** 向 + chief 头 = 达到顶点→完成、实现）、chief（caput 头→首领）、captain（capit 头 + **-ain** 人 = 领头人→首领、船长）、capital（capit 头 + **-al** …的 = 头等的→首都、资本）、chapter（capit 头→章节，书的分段）。
- **前缀·后缀**：前缀 **a-**（例：achieve, arise）；名词后缀 **-ment**（例：movement, development）。
- **同义·反义**：同义 accomplishment（成就）, success（成功）；反义 failure（失败）。
- **变形**：名词 → 复数：achievements；动词派生 → achieve v. 完成，实现；形容词派生 → achievable adj. 可完成的。

### 20. universe /ˈju:nɪvɜ:rs/ n. 宇宙，天地万物
- **词根·渊源**：拉丁 **unus**（一）+ **versus**（转，vert- 的过去分词）→ 拉丁 *universum*（转成一体、合为一体）→ 古法语 *univers* → 英语；本义“万物合为一体”，引申为“宇宙、天地万物”。
- **同根词**：universal（universe + **-al** …的 = 全体的→普遍的）、university（拉丁 universitas 全体 + **-ity** 名词 = 师生全体→大学）、version（**vers-** 转 + **-ion** 名词 = 转成的说法→版本）、convert（**con-** 完全 + vert 转 = 完全转过来→转变）、reverse（**re-** 回 + vers 转 = 转回去→颠倒）、diverse（**di-** 分开 + vers 转 = 转向不同方向→多样的）。
- **前缀·后缀**：前缀 **uni-**（例：uniform, unite）；词根 **vers-**（例：version, reverse）。
- **同义·反义**：同义 cosmos（宇宙）, creation（天地万物）；反义 无。
- **变形**：名词 → 复数：universes；形容词派生 → universal adj. 普遍的，全体的；副词派生 → universally adv. 普遍地。

### 21. philosopher /fə'lɒsəfə(r)/ n. 哲学家，哲人；思想深刻的人
- **词根·渊源**：希腊 **philos**（爱）+ **sophos**（智慧）→ 希腊 *philosophos*（爱智慧者）→ 拉丁 *philosophus* → 古法语 *philosophe* → 英语；本义“爱智慧的人”，引申为“哲学家、思想深刻的人”。
- **同根词**：philosophy（philo 爱 + soph 智慧 + **-y** 名词 = 爱智慧→哲学）、sophomore（sophos 智慧 + moros 愚人 = 半懂不懂的智者→二年级学生）、sophisticated（sophist 智者 + **-icated** …的 = 像智者般精明的→老练的）、philanthropy（phil 爱 + anthrop 人 + **-y** = 爱人类→慈善）。
- **前缀·后缀**：词根 **philo-**（例：philology, philanthropy）；名词后缀 **-er**（例：teacher, worker）。
- **同义·反义**：同义 thinker（思想家）, sage（智者）；反义 无。
- **变形**：名词 → 复数：philosophers；形容词派生 → philosophic adj. 哲学的；philosophical adj. 哲学的；副词派生 → philosophically adv. 哲学上。

### 22. obey /ə'beɪ/ v. 遵守，服从，听从
- **词根·渊源**：拉丁 **ob-**（朝向、对着）+ **audire**（听）→ 拉丁 *oboedire*（听从）→ 古法语 *obeir* → 英语；本义“听某人的话”，引申为“服从、遵守”。
- **同根词**：obedient（ob 朝向 + ed 听 + **-ient** …的 = 听话的→服从的）、obedience（obedient + **-ence** 名词 = 服从）、audience（audi 听 + **-ence** 名词 = 听的人→听众）、audio（audi 听 + **-o** = 声音的→音频的）、audible（audi 听 + **-ible** 可…的 = 听得见的）。
- **前缀·后缀**：前缀 **ob-**（例：object, obtain）；词根 **audi-**（例：audience, audio）。
- **同义·反义**：同义 follow（遵从）, comply（服从）；反义 disobey（不服从）, defy（违抗）。
- **变形**：动词 → 第三人称单数：obeys；过去式：obeyed；过去分词：obeyed；现在分词：obeying；名词派生 → obedience n. 服从；形容词派生 → obedient adj. 服从的。

### 23. reduce /rɪˈdu:s/ v. 减少，降低；减低；缩小
- **词根·渊源**：拉丁 **re-**（回）+ **ducere**（引导）→ 拉丁 *reducere*（引回、带回）→ 古法语 *reducer* → 英语；本义“引回、带回”，引申为“使回到较小状态→减少、降低”。
- **同根词**：reduction（reduce + **-tion** 名词 = 减少）、produce（**pro-** 向前 + duc 引导 = 向前引出→生产）、introduce（**intro-** 向内 + duc 引导 = 引入→介绍）、conduct（**con-** 共同 + duct 引导 = 共同引导→指挥、行为）、educate（**e-** 出 + duc 引导 = 引出（才能）→教育）、duct（duc 引导→管道）。
- **前缀·后缀**：前缀 **re-**（例：return, recall）；词根 **duc-/duct-**（例：produce, conduct）。
- **同义·反义**：同义 decrease（减少）, lower（降低）；反义 increase（增加）, raise（提高）。
- **变形**：动词 → 第三人称单数：reduces；过去式：reduced；过去分词：reduced；现在分词：reducing；名词派生 → reduction n. 减少；形容词派生 → reduced adj. 减少的。

### 24. exactly /ɪɡˈzæktli/ adv. 确切地；精确地；完全；[口]（表示赞同）确实如此
- **词根·渊源**：拉丁 **ex-**（出）+ **agere**（驱动、做）→ 拉丁 *exactus*（精确的，exigere 的过去分词，“称量出、做到位”）→ 英语 exact + 副词后缀 **-ly**；本义“称量得丝毫不差”，引申为“确切地、完全”。
- **同根词**：exact（ex 出 + act 驱动 = 称量出的→精确的）、act（agere 做→行动）、agent（ag 做 + **-ent** 人 = 做事的人→代理人）、agenda（ag 做 + **-enda** 应做之事→议程）、exam（ex 出 + ag 做→考查，examination 的缩略）。
- **前缀·后缀**：前缀 **ex-**（例：exit, export）；副词后缀 **-ly**（例：quickly, happily）。
- **同义·反义**：同义 precisely（精确地）, completely（完全地）；反义 roughly（粗略地）, approximately（大约）。
- **变形**：副词 → 无比较级（绝对副词，不作比较）；形容词派生 → exact adj. 精确的；名词派生 → exactness n. 精确。

### 25. action /ˈækʃ(ə)n/ n. 动作；（故事、戏剧等中的）情节
- **词根·渊源**：拉丁 **agere / act-**（驱动、做）→ 拉丁 *actio*（做、行动）→ 古法语 *action* → 英语；本义“做的过程”，引申为“动作、行为”，戏剧中引申为“情节”。
- **同根词**：act（agere 做→行动、表演）、active（act 做 + **-ive** …的 = 活跃的）、actor（act 做 + **-or** 人 = 做事的人→演员）、react（**re-** 回 + act 做 = 反过来做→反应）、exact（ex 出 + act 做 = 做到位→精确的）、agenda（ag 做 + **-enda** 应做之事→议程）。
- **前缀·后缀**：名词后缀 **-tion**（例：nation, education）；前缀 **re-**（例：react, return）。
- **同义·反义**：同义 deed（行为）, act（行动）；反义 inaction（不行动）, inactivity（不活动）。
- **变形**：名词 → 复数：actions；形容词派生 → active adj. 活跃的；actionable adj. 可起诉的；动词派生 → act v. 行动，表演。
