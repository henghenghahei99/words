## 二、逐词说文解字

### 1. adventure /ədˈventʃər/ v. 冒险；冒险(经历)
- **词根·渊源**：拉丁 **ad-**（向）+ **vent-**（来）+ **-ure**（名词后缀）→ 拉丁 *adventurus*“将要到来的事”→ 古法语 *aventure*“偶然发生的事、命运”→ 英语 adventure；本义“将来临之事（多指未知、有风险的事）”，引申为“冒险、冒险经历”。
- **同根词**：venture（**vent-** 来 + **-ure** 名词后缀 = 冒风险去做→冒险）、event（**e-** 出 + vent 来 = 出来发生的事→事件）、invent（**in-** 进入 + vent 来 = 想法进入脑中→发明）、prevent（**pre-** 前 + vent 来 = 先来挡住→阻止）、convention（**con-** 共同 + vent 来 + **-ion** 名词后缀 = 大家走到一起→会议、惯例）、avenue（**a-** 向 + ven 来 + **-ue** = 来去的通道→大街）。
- **前缀·后缀**：前缀 **ad-**（例：advance, admire）；名词后缀 **-ure**（例：pleasure, failure）。
- **同义·反义**：同义 venture（冒险）, exploit（壮举）；反义 safety（安全）, security（安稳）。
- **变形**：动词 → 第三人称单数：adventures；过去式：adventured；过去分词：adventured；现在分词：adventuring；名词派生 → adventure n. 冒险；形容词派生 → adventurous adj. 爱冒险的；副词派生 → adventurously adv. 冒险地。

### 2. novel /ˈnɑ:vl/ n.（长篇）小说
- **词根·渊源**：拉丁 **nov-**（新）+ **-el**（形容词/名词后缀）→ 拉丁 *novellus*“新的、新奇的”→ 古法语 *novel*“新的”→ 英语 novel；本义“新奇的事物”，后专指“新奇的、虚构的长篇故事”，即“小说”。
- **同根词**：novelty（novel 新 + **-ty** 名词后缀 = 新奇→新奇事物）、novice（nov 新 + **-ice** 人 = 新手→初学者）、innovate（**in-** 使 + nov 新 + **-ate** 动词后缀 = 使变新→创新）、renovate（**re-** 再 + nov 新 + **-ate** = 再使变新→翻新）、november（nov 九 + **-ember** 月 = 古罗马历第九月→十一月）。
- **前缀·后缀**：前缀 **in-**（例：increase）、**re-**（例：return）；名词后缀 **-el**（例：channel, tunnel）。
- **同义·反义**：同义 fiction（小说）, story（故事）；反义 nonfiction（非虚构作品）, fact（事实）。
- **变形**：名词 → 复数：novels；形容词派生 → novel adj. 新奇的；novelistic adj. 小说的；名词派生 → novelist n. 小说家。

### 3. frog /frɒɡ/ n. 蛙；青蛙
- **词根·渊源**：古英语 *frogga / frosc*“青蛙”，与古诺尔斯语 *froskr* 同源，属日耳曼语族固有词；词源更早来源存疑（一说与“跳”义相关），本义即“蛙”，现义不变。
- **同根词**：无常用同根词（单纯词）。
- **前缀·后缀**：无前后缀（单纯词）。
- **同义·反义**：同义 toad（蟾蜍，近义不同物）；反义 无。
- **变形**：名词 → 复数：frogs；形容词派生 → froggy adj. 多蛙的、蛙似的。

### 4. congratulations /kənˌgrætʃəˈleɪʃənz/ n. 祝贺；恭贺
- **词根·渊源**：拉丁 **con-**（共同）+ **grat-**（高兴、感谢）+ **-ul-** + **-ation**（名词后缀）+ **-s**（复数）→ 拉丁 *congratulari*“共同表示高兴”→ 英语 congratulate → congratulations；本义“大家一起高兴”，引申为“祝贺、贺词”。
- **同根词**：congratulate（**con-** 共同 + grat 高兴 + **-ulate** 动词后缀 = 共同高兴→祝贺）、grateful（grat 感谢 + **-ful** 充满…的 = 充满感谢的→感激的）、gratitude（grat 感谢 + **-itude** 名词后缀 = 感谢→感激）、gratify（grat 高兴 + **-ify** 使… = 使高兴→使满足）、grace（拉丁 gratia 感谢、恩惠→优雅、恩惠）。
- **前缀·后缀**：前缀 **con-**（例：connect, collect）；名词后缀 **-ation**（例：information, education）；复数后缀 **-s**（例：books, friends）。
- **同义·反义**：同义 compliments（祝贺、称赞）, felicitations（祝贺）；反义 condolences（哀悼）, criticism（批评）。
- **变形**：名词 → 复数：congratulations（常用复数）；动词派生 → congratulate v. 祝贺；形容词派生 → congratulatory adj. 祝贺的。

### 5. sympathy /'sɪmpəθi/ n. 同情（心），理解；赞同，支持
- **词根·渊源**：希腊 **syn-**（共同）+ **path-**（感受、痛苦）+ **-y**（名词后缀）→ 希腊 *sympatheia*“共同感受”→ 拉丁 *sympathia* → 英语 sympathy；本义“与他人共同感受”，引申为“同情、理解、赞同”。
- **同根词**：sympathetic（sym 共同 + path 感受 + **-etic** 形容词后缀 = 共同感受的→同情的）、sympathize（sym 共同 + path 感受 + **-ize** 动词后缀 = 共同感受→同情）、pathetic（path 感受 + **-etic** = 引人感受的→可怜的）、apathy（**a-** 无 + path 感受 + **-y** = 无感受→冷漠）、pathos（path 感受 + **-os** 名词后缀 = 情感→悲怆）、empathy（**em-** 进入 + path 感受 + **-y** = 进入他人感受→共情）。
- **前缀·后缀**：前缀 **syn-/sym-**（例：synonym, symphony）；名词后缀 **-y**（例：history, memory）。
- **同义·反义**：同义 compassion（同情）, understanding（理解）；反义 indifference（冷漠）, antipathy（反感）。
- **变形**：名词 → 复数：sympathies；形容词派生 → sympathetic adj. 同情的；副词派生 → sympathetically adv. 同情地；动词派生 → sympathize v. 同情。

### 6. steamboat /'stiːmbəʊt/ n. 汽船，轮船
- **词根·渊源**：**steam**（蒸汽）+ **boat**（船）复合而成；steam 源自古英语 *stēam*“蒸汽”，boat 源自古英语 *bāt*“船”；本义“以蒸汽为动力的船”，即“汽船、轮船”。
- **同根词**：steamship（steam 蒸汽 + ship 船 = 蒸汽船→轮船）、steamengine（steam 蒸汽 + engine 发动机 = 蒸汽机）、steamer（steam 蒸汽 + **-er** 物 = 蒸具、汽船）、steam（蒸汽，单纯词）、boat（船，单纯词）。
- **前缀·后缀**：复合词无前后缀；构词成分 **steam**（例：steamship, steamengine）、**boat**（例：sailboat, rowboat）。
- **同义·反义**：同义 steamship（汽船）, steamer（汽船）；反义 sailboat（帆船）, rowboat（划艇）。
- **变形**：名词 → 复数：steamboats。

### 7. steam /stiːm/ v. 蒸汽，水蒸气；水汽，雾气；蒸汽动力
- **词根·渊源**：古英语 *stēam*“蒸汽、热气”，属日耳曼语族固有词，与荷兰语 *stoom* 同源；本义“冒出的热气、水汽”，引申为“蒸汽动力”，动词义“冒蒸汽、蒸”。
- **同根词**：steamer（steam 蒸汽 + **-er** 物 = 蒸具→汽船、蒸锅）、steamy（steam 蒸汽 + **-y** 形容词后缀 = 蒸汽的→闷热的）、steamboat（steam 蒸汽 + boat 船 = 汽船）、steamship（steam 蒸汽 + ship 船 = 轮船）。
- **前缀·后缀**：名词/形容词后缀 **-er**（例：worker, cooker）、**-y**（例：rainy, windy）。
- **同义·反义**：同义 vapor（蒸汽）, mist（雾气）；反义 无。
- **变形**：动词 → 第三人称单数：steams；过去式：steamed；过去分词：steamed；现在分词：steaming；名词 → 复数：steams（作“蒸汽”义时不可数）；形容词派生 → steamy adj. 蒸汽的、闷热的；副词派生 → steaming adv. 热气腾腾地。

### 8. writer /ˈraɪtə(r)/ n. 作家，作者
- **词根·渊源**：古英语 **writ-**（写）+ **-er**（人）→ 古英语 *writere*“书写者”→ 英语 writer；本义“写字的人”，引申为“作家、作者”。
- **同根词**：write（写，单纯词）、writing（writ 写 + **-ing** 名词后缀 = 写→写作、作品）、writ（writ 写 + 过去分词 = 写好的东西→令状）、rewrite（**re-** 再 + write 写 = 再写→改写）、typewriter（type 打字 + writer 写者 = 打字机）。
- **前缀·后缀**：前缀 **re-**（例：rebuild, reread）；名词后缀 **-er**（例：teacher, worker）。
- **同义·反义**：同义 author（作者）, novelist（小说家）；反义 reader（读者）。
- **变形**：名词 → 复数：writers；动词派生 → write v. 写；名词派生 → writing n. 写作。

### 9. humorous /ˈhjumərəs/ adj. 有幽默感的；滑稽有趣的；诙谐的
- **词根·渊源**：拉丁 **humor-**（体液、湿气）+ **-ous**（充满…的）→ 英语 humour/humor“体液”→ humorous；中世纪医学认为人体四种“体液”决定性格，本义“体液性的、多液的”，后引申为“性情古怪有趣的→幽默的、诙谐的”。
- **同根词**：humor（体液→幽默，单纯词）、humorist（humor 幽默 + **-ist** 人 = 幽默家）、humorless（humor 幽默 + **-less** 无 = 无幽默感的）、humid（hum 湿 + **-id** 形容词后缀 = 湿的→潮湿的）、humidity（humid 湿 + **-ity** 名词后缀 = 湿度）。
- **前缀·后缀**：形容词后缀 **-ous**（例：famous, dangerous）；名词后缀 **-ist**（例：artist, scientist）；否定后缀 **-less**（例：hopeless, careless）。
- **同义·反义**：同义 funny（滑稽的）, witty（诙谐的）；反义 serious（严肃的）, solemn（庄重的）。
- **变形**：形容词 → 比较级：more humorous；最高级：most humorous；名词派生 → humor n. 幽默；副词派生 → humorously adv. 幽默地。

### 10. fence /fɛns/ v. 篱笆，栅栏，围栏
- **词根·渊源**：**fens-**（防御、挡住）+ **-e** → 中古英语 *fens*，缩略自 **defence**（防御）→ 英语 fence；本义“防御物”，引申为“篱笆、栅栏”，动词义“围以栅栏、击剑”。
- **同根词**：defence（**de-** 去除 + fens 防御 + **-ce** 名词后缀 = 防御→保卫）、defend（**de-** 去除 + fend 打击 = 挡开→保卫）、defensive（defens 防御 + **-ive** 形容词后缀 = 防御的）、offend（**of-** 对着 + fend 打击 = 对着打→冒犯）、offensive（offens 冒犯 + **-ive** = 冒犯的→进攻的）。
- **前缀·后缀**：前缀 **de-**（例：defend, decrease）、**of-**（例：offend）；名词后缀 **-ce**（例：defence, silence）。
- **同义·反义**：同义 barrier（障碍物）, railing（栏杆）；反义 opening（开口）, gap（缺口）。
- **变形**：动词 → 第三人称单数：fences；过去式：fenced；过去分词：fenced；现在分词：fencing；名词 → 复数：fences；名词派生 → fencing n. 击剑、栅栏材料。

### 11. task /tæsk/ v. 任务；工作
- **词根·渊源**：古法语 **tasque**“税、劳役”→ 中世纪拉丁 *tasca*“税赋、工作”，可能与拉丁 *taxare*“评定、征税”相关 → 英语 task；本义“分派的劳役、赋税”，引申为“任务、工作”，动词义“派给任务”。
- **同根词**：tax（拉丁 taxare 评定、征税→税；与 task 同源）、taxation（tax 税 + **-ation** 名词后缀 = 征税）、taxpayer（tax 税 + payer 支付者 = 纳税人）。
- **前缀·后缀**：名词后缀 **-ation**（例：information, education）；复合成分 **payer**（例：taxpayer, employer）。
- **同义·反义**：同义 job（工作）, assignment（任务）；反义 leisure（闲暇）, rest（休息）。
- **变形**：动词 → 第三人称单数：tasks；过去式：tasked；过去分词：tasked；现在分词：tasking；名词 → 复数：tasks。

### 12. yard /jɑːrd/ n. 码（长度单位）
- **词根·渊源**：古英语 **gerd / gyrd**“棍、杆”，属日耳曼语族固有词，与“杖、杆”义相关；本义“一根棍子的长度”，后固定为长度单位“码”（约 0.914 米），另义“院子”来自另一同形词。
- **同根词**：无常用同根词（单纯词；与 gird“束、围”远源相关，存疑）。
- **前缀·后缀**：无前后缀（单纯词）。
- **同义·反义**：同义 无；反义 无。
- **变形**：名词 → 复数：yards。

### 13. board /bɔːd/ n. 布告牌；木板
- **词根·渊源**：古英语 **bord**“木板、桌面”，属日耳曼语族固有词，与德语 *Bord* 同源；本义“木板”，引申为“桌面→饭桌→董事会、布告牌”。
- **同根词**：blackboard（black 黑 + board 板 = 黑板）、cupboard（cup 杯 + board 板 = 放杯的板→碗柜）、keyboard（key 键 + board 板 = 键盘）、aboard（**a-** 在 + board 船板 = 在船上→上船）、boarding（board 板 + **-ing** 名词后缀 = 上船/登机→寄宿）。
- **前缀·后缀**：前缀 **a-**（例：aboard, asleep）；名词后缀 **-ing**（例：building, meeting）。
- **同义·反义**：同义 plank（木板）, panel（板）；反义 无。
- **变形**：名词 → 复数：boards；动词派生 → board v. 上（船、车）；名词派生 → boarder n. 寄宿者。

### 14. survey /ˈsɜːrveɪ/ v. 查看，审视，检查
- **词根·渊源**：拉丁 **super-**（在上）+ **vid-**（看）+ **-y** → 盎格鲁-法语 *surveier*“从上往下看”→ 英语 survey；本义“俯视、纵览”，引申为“查看、审视、调查”。
- **同根词**：vision（vid 看 + **-ion** 名词后缀 = 看→视力、视野）、visible（vis 看 + **-ible** 可…的 = 可看见的）、video（vid 看 + **-eo** = 我看见→视频）、supervise（**super-** 在上 + vis 看 = 从上看→监督）、evident（**e-** 出 + vid 看 + **-ent** = 看得出→明显的）、revise（**re-** 再 + vis 看 = 再看→修订）。
- **前缀·后缀**：前缀 **super-**（例：supermarket, supervise）、**re-**（例：review, return）；名词后缀 **-ion**（例：action, decision）。
- **同义·反义**：同义 inspect（检查）, examine（审视）；反义 ignore（忽视）, overlook（忽略）。
- **变形**：动词 → 第三人称单数：surveys；过去式：surveyed；过去分词：surveyed；现在分词：surveying；名词派生 → survey n. 调查；名词派生 → surveyor n. 测量员。

### 15. progress /ˈprɑ:gres/ v. 进步；进展
- **词根·渊源**：拉丁 **pro-**（向前）+ **gress-**（走）→ 拉丁 *progredi*“向前走”→ 英语 progress；本义“向前走”，引申为“进步、进展”。
- **同根词**：congress（**con-** 共同 + gress 走 = 走到一起→会议、国会）、aggressive（**ag-** 向 + gress 走 + **-ive** = 向前走的→侵略的）、digress（**di-** 离开 + gress 走 = 走开→离题）、transgress（**trans-** 越过 + gress 走 = 越过界限→违犯）、grade（grad 走、步→等级）。
- **前缀·后缀**：前缀 **pro-**（例：promote, produce）、**con-**（例：connect, congress）；名词后缀 **-ive**（例：active, creative）。
- **同义·反义**：同义 advance（前进）, improvement（改进）；反义 regress（倒退）, decline（衰退）。
- **变形**：动词 → 第三人称单数：progresses；过去式：progressed；过去分词：progressed；现在分词：progressing；名词派生 → progress n. 进步；形容词派生 → progressive adj. 进步的。

### 16. rest /rɛst/ v. 休息（时间）
- **词根·渊源**：古英语 **ræst**“休息、安歇”，属日耳曼语族固有词，与德语 *Rast* 同源；本义“歇息、安歇之处”，引申为“休息、休息时间”。
- **同根词**：restful（rest 休息 + **-ful** 充满…的 = 充满休息的→宁静的）、restless（rest 休息 + **-less** 无 = 无休息的→不安的）、restroom（rest 休息 + room 房间 = 休息室→洗手间）。
- **前缀·后缀**：形容词后缀 **-ful**（例：helpful, useful）、**-less**（例：homeless, careless）。
- **同义·反义**：同义 break（休息）, relaxation（放松）；反义 work（工作）, labor（劳作）。
- **变形**：动词 → 第三人称单数：rests；过去式：rested；过去分词：rested；现在分词：resting；名词 → 复数：rests；形容词派生 → restful adj. 宁静的；副词派生 → restfully adv. 宁静地。

### 17. pity /ˈpɪti/ n. 遗憾；可惜
- **词根·渊源**：拉丁 **pietas**（虔诚、怜悯）→ 古法语 *pité*“怜悯”→ 英语 pity；本义“虔诚、怜悯之心”，引申为“同情、遗憾、可惜”。
- **同根词**：pious（拉丁 pius 虔诚的 + **-ous** = 虔诚的）、piety（piet 虔诚 + **-y** 名词后缀 = 虔诚）、pitiful（pity 怜悯 + **-ful** 充满…的 = 可怜的）、pitiless（pity 怜悯 + **-less** 无 = 无情的）。
- **前缀·后缀**：形容词后缀 **-ful**（例：careful, hopeful）、**-less**（例：fearless, endless）。
- **同义·反义**：同义 compassion（同情）, regret（遗憾）；反义 cruelty（残忍）, indifference（冷漠）。
- **变形**：名词 → 复数：pities；形容词派生 → pitiful adj. 可怜的；pitiless adj. 无情的；副词派生 → pitifully adv. 可怜地。

### 18. silence /ˈsaɪləns/ n. 寂静，无声；沉默，默不作声:；保持沉默，拒绝回答
- **词根·渊源**：拉丁 **sil-**（安静）+ **-ence**（名词后缀）→ 拉丁 *silentium*“安静”→ 古法语 *silence* → 英语 silence；本义“安静状态”，引申为“寂静、沉默”。
- **同根词**：silent（sil 安静 + **-ent** 形容词后缀 = 安静的）、silently（silent 安静的 + **-ly** 副词后缀 = 安静地）。
- **前缀·后缀**：名词后缀 **-ence**（例：difference, patience）；形容词后缀 **-ent**（例：different, patient）。
- **同义·反义**：同义 quiet（安静）, stillness（寂静）；反义 noise（噪音）, sound（声音）。
- **变形**：名词 → 复数：silences；动词派生 → silence v. 使安静；形容词派生 → silent adj. 安静的；副词派生 → silently adv. 安静地。

### 19. while /waɪl/ n. 在...期间；一会儿，一段时间；当...的时候
- **词根·渊源**：古英语 *hwīl*（一段时间）→ 中古英语 *while*，本义“一段时间”，引申为连词“当……的时候”及名词“一会儿”。
- **同根词**：whilst（while + **-st** 副词性后缀：当……时，英式）、worthwhile（worth 值得 + while 一段时间 = 值得花时间的→值得的）、awhile（**a-** 在……中 + while 一段时间 = 片刻）。
- **前缀·后缀**：无前后缀（单纯词）。
- **同义·反义**：同义 moment（片刻）, time（时间）；反义 无。
- **变形**：名词 → 复数：whiles（多作连词，名词复数少用）；连词无形态变化。

### 20. careful /ˈkeəfl/ adj. 小心；谨慎；小心的；仔细的，认真的
- **词根·渊源**：古英语 *caru*（忧虑、关心）→ *care*（关心）+ **-ful**（充满……的）→ careful，本义“充满关心的”，引申为“小心的、仔细的”。
- **同根词**：care（关心）、careless（care + **-less** 无 = 不小心的）、carefully（careful + **-ly** 地 = 小心地）、caring（care + **-ing** ……的 = 关心的）。
- **前缀·后缀**：形容词后缀 **-ful**（例：helpful, useful）。
- **同义·反义**：同义 cautious（谨慎的）, attentive（专注的）；反义 careless（粗心的）, negligent（疏忽的）。
- **变形**：形容词 → 比较级：more careful；最高级：most careful；副词派生 → carefully adv. 小心地；名词派生 → carefulness n. 小心。

### 21. deal /diːl/ v. 协议；交易；处理；给予
- **词根·渊源**：古英语 *dǣlan*（分开、分配）→ 中古英语 *delen*，本义“分份”，引申为“交易、处理”。
- **同根词**：dealer（deal + **-er** 人 = 商人）、dealing（deal + **-ing** 名词 = 交易）、misdeal（**mis-** 错误 + deal = 发错牌）。
- **前缀·后缀**：名词后缀 **-er**（例：teacher, worker）。
- **同义·反义**：同义 trade（交易）, handle（处理）；反义 无。
- **变形**：动词 → 第三人称单数：deals；过去式：dealt；过去分词：dealt；现在分词：dealing；名词 → 复数：deals；名词派生 → dealer n. 商人。

### 22. coat /koʊt/ v. 涂料层，覆盖层
- **词根·渊源**：古法语 *cote*（外衣）→ 中古英语 *cote*，本义“外套”，引申为“覆盖层、涂料层”。
- **同根词**：coating（coat + **-ing** 名词 = 涂层）、coated（coat + **-ed** 形容词 = 有涂层的）、overcoat（**over-** 在上 + coat = 大衣）。
- **前缀·后缀**：名词后缀 **-ing**（例：building, painting）。
- **同义·反义**：同义 layer（层）, covering（覆盖物）；反义 无。
- **变形**：动词 → 第三人称单数：coats；过去式：coated；过去分词：coated；现在分词：coating；名词 → 复数：coats；名词派生 → coating n. 涂层。

### 23. celebrated /ˈselɪbreɪtɪd/ adj. 著名的；闻名的；有名望的
- **词根·渊源**：拉丁 *celeber*（著名的、热闹的）→ *celebrāre*（庆祝）→ 英语 *celebrate* + **-ed** → celebrated，本义“被庆祝的”，引申为“著名的”。
- **同根词**：celebrate（celebr + **-ate** 动词 = 庆祝）、celebration（celebrate + **-ion** 名词 = 庆祝）、celebrity（celebr + **-ity** 名词 = 名人）。
- **前缀·后缀**：形容词后缀 **-ed**（例：talented, excited）。
- **同义·反义**：同义 famous（著名的）, renowned（闻名的）；反义 unknown（无名的）, obscure（默默无闻的）。
- **变形**：形容词 → 比较级：more celebrated；最高级：most celebrated；动词派生 → celebrate v. 庆祝。

### 24. lead /liːd; led/ n. 铅
- **词根·渊源**：古英语 *lēad*（铅）→ 中古英语 *lead*，本义“铅金属”，词源存疑（可能源自凯尔特语）。
- **同根词**：leaden（lead + **-en** 形容词 = 铅制的）、leaded（lead + **-ed** 形容词 = 含铅的）。
- **前缀·后缀**：形容词后缀 **-en**（例：wooden, golden）。
- **同义·反义**：同义 无；反义 无。
- **变形**：名词 → 不可数；形容词派生 → leaden adj. 铅制的。

### 25. plot /plɑːt/ v. 阴谋，密谋；故事情节；构思（情节）
- **词根·渊源**：古英语 *plot*（一块地）→ 中古英语 *plot*，本义“小块土地”，引申为“情节布局、阴谋”。
- **同根词**：plotter（plot + **-er** 人 = 密谋者）、plotting（plot + **-ing** 名词 = 密谋）。
- **前缀·后缀**：名词后缀 **-er**（例：writer, singer）。
- **同义·反义**：同义 scheme（密谋）, conspire（策划）；反义 无。
- **变形**：动词 → 第三人称单数：plots；过去式：plotted；过去分词：plotted；现在分词：plotting；名词 → 复数：plots；名词派生 → plotter n. 密谋者。

### 26. lazy /ˈleɪzi/ adj. 懒惰的，懒散的
- **词根·渊源**：中古英语 *lasy*（可能源自低地德语 *lasich* 懒散的）→ 英语 lazy，本义“懒散的”，词源存疑。
- **同根词**：lazily（lazy + **-ly** 地 = 懒散地）、laziness（lazy + **-ness** 名词 = 懒惰）、laze（lazy 去 y + **-e** 动词 = 懒散）。
- **前缀·后缀**：形容词后缀 **-y**（例：rainy, sunny）。
- **同义·反义**：同义 idle（懒散的）, slothful（懒惰的）；反义 diligent（勤奋的）, industrious（勤勉的）。
- **变形**：形容词 → 比较级：lazier；最高级：laziest；副词派生 → lazily adv. 懒散地；名词派生 → laziness n. 懒惰。

### 27. pretend /prɪˈtend/ v. 伪装，假装；佯装；（玩游戏时）假扮，装扮
- **词根·渊源**：拉丁 *praetendere*（**prae-** 在前 + **tendere** 伸展 = 向前伸展→声称）→ 古法语 *pretendre* → 英语 pretend，本义“声称”，引申为“假装”。
- **同根词**：pretence（pretend 变体 + **-ce** 名词 = 假装）、pretender（pretend + **-er** 人 = 冒充者）、pretension（**pre-** 前 + tens 伸 + **-ion** 名词 = 自称）。
- **前缀·后缀**：前缀 **pre-**（例：prepare, predict）；动词后缀 **-end**（例：attend, extend）。
- **同义·反义**：同义 feign（假装）, fake（伪造）；反义 无。
- **变形**：动词 → 第三人称单数：pretends；过去式：pretended；过去分词：pretended；现在分词：pretending；名词派生 → pretence n. 假装。
