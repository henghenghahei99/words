## 二、逐词说文解字

### 1. associate /əˈsoʊʃiˌeɪt/ v. 联系
- **词根·渊源**：拉丁 **soci-**（同伴、伙伴，源自 socius）→ 拉丁 *associare*（使联合）→ 古法语 *associer* → 英语；本义“使成为同伴”，引申为“把……联系在一起”。
- **同根词**：social（soci 同伴 + **-al** ……的 = 同伴间的→社会的）、society（soci 同伴 + **-ety** 名词后缀 = 同伴关系→社会）、associate 的名词义 association（**ad-** 向 + soci 同伴 + **-ation** 名词后缀 = 结成同伴→协会、联系）、sociable（soci 同伴 + **-able** 能……的 = 能交友的→好交际的）。
- **前缀·后缀**：前缀 **ad-**（例：advance, adapt）；后缀 **-ate**（例：activate, calculate）。
- **同义·反义**：同义 connect（联系）, link（连接）；反义 separate（分开）, disconnect（断开）。
- **变形**：动词 → 第三人称单数：associates；过去式：associated；过去分词：associated；现在分词：associating；名词派生 → association n. 协会、联系；形容词派生 → associated adj. 相关的。

### 2. humour /ˈhjumər/ n. 幽默;幽默感
- **词根·渊源**：拉丁 **humor-**（体液、湿气）→ 古法语 *humour* → 英语；中世纪医学认为人体四种“体液”决定性情，后指“性情、心境”，再引申为“逗人发笑的情趣→幽默”。
- **同根词**：humid（hum 湿 + **-id** ……的 = 湿的→潮湿的）、humorous（humour + **-ous** ……的 = 有幽默感的→幽默的）、humorist（humour + **-ist** 人 = 幽默的人→幽默作家）。
- **前缀·后缀**：后缀 **-ous**（例：famous, dangerous）；后缀 **-ist**（例：artist, scientist）。
- **同义·反义**：同义 fun（乐趣）, wit（风趣）；反义 seriousness（严肃）, dullness（沉闷）。
- **变形**：名词 → 复数：humours（作“幽默感”义时不可数）；形容词派生 → humorous adj. 幽默的；副词派生 → humorously adv. 幽默地。

### 3. fence /fɛns/ n. 栅栏;篱笆
- **词根·渊源**：由 **fend / fens-**（抵挡、防御，拉丁 *defendere* 的缩略）→ 中古英语 *fens* → 英语；本义“防御之物”，即围起来挡人的“栅栏、篱笆”。
- **同根词**：defend（**de-** 去除 + fend 抵挡 = 挡开→防御）、defence（**de-** + fenc 抵挡 + **-e** 名词 = 防御）、offend（**of-** 对着 + fend 撞 = 撞上去→冒犯）、fender（fend 抵挡 + **-er** 物 = 挡的东西→挡泥板）。
- **前缀·后缀**：前缀 **de-**（例：decline, defeat）；后缀 **-er**（例：worker, teacher）。
- **同义·反义**：同义 barrier（障碍物）, railing（栏杆）；反义 无。
- **变形**：名词 → 复数：fences；动词派生 → fence v. 围以栅栏；fencing n. 击剑、栅栏材料。

### 4. sink /sɪŋk/ v. 下沉;下陷
- **词根·渊源**：古英语 **sincan**（下沉）→ 中古英语 *sinken* → 英语；日耳曼语固有词，本义即“往下沉”，引申为“下陷、降低”。
- **同根词**：sunken（sink 的过去分词 sunk + **-en** 形容词后缀 = 沉下去的→下陷的）、sinker（sink 沉 + **-er** 物 = 下沉之物→钓锤）。
- **前缀·后缀**：无前后缀（单纯词）。
- **同义·反义**：同义 descend（下降）, drop（落下）；反义 rise（上升）, float（漂浮）。
- **变形**：动词 → 第三人称单数：sinks；过去式：sank；过去分词：sunk；现在分词：sinking；名词派生 → sink n. 水槽。

### 5. yard /jɑrd/ n. 码(长度单位,等于0.9144米)
- **词根·渊源**：古英语 **gyrd / gerd**（棍、杆）→ 中古英语 *yerde* → 英语；本义“一根直棍”，古人以棍量长，遂成长度单位“码”；同源词义“围场”另出一支。
- **同根词**：yardstick（yard 码 + stick 棍 = 量码的棍→标准、尺度）。
- **前缀·后缀**：无前后缀（单纯词）。
- **同义·反义**：同义 无；反义 无。
- **变形**：名词 → 复数：yards；无比较级（单位名词，不作比较）。

### 6. survey /ˈsərˌveɪ/ v. 查看;审视
- **词根·渊源**：拉丁 **vid / vis-**（看）→ 拉丁 *supervidere*（从上往下看）→ 盎格鲁法语 *surveier* → 英语；本义“俯瞰、察看”，引申为“审视、调查”。
- **同根词**：vision（vis 看 + **-ion** 名词 = 看的能力→视力）、visible（vis 看 + **-ible** 可……的 = 可见的）、supervise（**super-** 在上 + vis 看 = 从上看→监督）、revise（**re-** 再 + vis 看 = 再看一遍→修订）、evident（**e-** 出 + vid 看 + **-ent** ……的 = 看得出的→明显的）。
- **前缀·后缀**：前缀 **sur- / super-**（例：surface, supervise）；后缀 **-ey**（例：tourney）。
- **同义·反义**：同义 examine（检查）, inspect（审视）；反义 ignore（忽视）, overlook（忽略）。
- **变形**：动词 → 第三人称单数：surveys；过去式：surveyed；过去分词：surveyed；现在分词：surveying；名词派生 → survey n. 调查；surveyor n. 测量员。

### 7. aloud /əˈlaʊd/ adv. 大声地
- **词根·渊源**：古英语 **hlūd**（响亮的）→ 中古英语 *loud* + 前缀 **a-**（在……状态中）→ 英语 *aloud*；本义“以响亮之声”，即“出声地、大声地”。
- **同根词**：loud（loud 响亮 = 大声的）、loudly（loud + **-ly** 副词后缀 = 大声地）、loudness（loud + **-ness** 名词后缀 = 响亮）。
- **前缀·后缀**：前缀 **a-**（例：awake, asleep）；后缀 **-ly**（例：quickly, slowly）。
- **同义·反义**：同义 loudly（大声地）, out loud（出声地）；反义 silently（无声地）, quietly（安静地）。
- **变形**：副词 → 无比较级（方式副词，不作比较）。

### 8. pity /ˈpɪti/ n. 遗憾;可惜
- **词根·渊源**：拉丁 **pietas**（虔诚、怜悯）→ 古法语 *pité* → 英语；本义“对神与人的尽责之情”，引申为“怜悯、同情”，再引申为“令人遗憾之事”。
- **同根词**：pious（pi 虔诚 + **-ous** ……的 = 虔诚的）、piety（pi 虔诚 + **-ety** 名词后缀 = 虔诚）、pitiful（pity + **-ful** 充满……的 = 令人怜悯的）、pitiless（pity + **-less** 无……的 = 无情的）。
- **前缀·后缀**：后缀 **-ful**（例：helpful, careful）；后缀 **-less**（例：hopeless, careless）。
- **同义·反义**：同义 sympathy（同情）, shame（遗憾）；反义 cruelty（残忍）, indifference（冷漠）。
- **变形**：名词 → 复数：pities；形容词派生 → pitiful adj. 可怜的；pitiless adj. 无情的；副词派生 → pitifully adv. 可怜地。

### 9. gentleman /ˈʤɛnəlmən/ n. 彬彬有礼的人；有教养的人
- **词根·渊源**：古法语 **gentil**（出身高贵的，拉丁 *gentilis* 同族的）→ 中古英语 *gentle* + **man**（人）→ 英语；本义“出身高贵的人”，后转指“有教养、彬彬有礼的人”。
- **同根词**：gentle（gent 出身高贵 + **-le** 形容词后缀 = 出身好的→温和的）、gently（gentle + **-ly** 副词后缀 = 温和地）、gentry（gent 高贵 + **-ry** 集合名词 = 绅士阶层）、genuine（拉丁 gen 出生 + **-ine** ……的 = 天生的→真正的）。
- **前缀·后缀**：后缀 **-man**（例：policeman, chairman）；后缀 **-ly**（例：badly, truly）。
- **同义·反义**：同义 nobleman（贵族）, sir（先生）；反义 boor（粗人）, lout（粗鲁的人）。
- **变形**：名词 → 复数：gentlemen；形容词派生 → gentlemanly adj. 绅士风度的；副词派生 → gentlemanly adv. 绅士般地。

### 10. concern /kənˈsərn/ n. 担心;忧虑
- **词根·渊源**：拉丁 **cern-**（筛选、分辨）→ 拉丁 *concernere*（混合、筛在一起）→ 古法语 *concerner* → 英语；本义“搅在一起、相关涉”，引申为“关心、担心”。
- **同根词**：discern（**dis-** 分开 + cern 筛 = 筛分开→辨别）、certain（cert 确定 + **-ain** ……的 = 已分辨清的→确定的）、secret（**se-** 分开 + cret 筛 = 分开藏起→秘密的）、concert（**con-** 共同 + cert 筛 = 协调一致→音乐会）。
- **前缀·后缀**：前缀 **con-**（例：connect, confirm）；后缀 **-ern**（例：pattern）。
- **同义·反义**：同义 worry（担心）, anxiety（忧虑）；反义 calm（平静）, unconcern（漠不关心）。
- **变形**：名词 → 复数：concerns；动词派生 → concern v. 涉及、使担心；形容词派生 → concerned adj. 担心的；concerning prep. 关于。

### 11. sort /sɔrt/ n. 种类;类别
- **词根·渊源**：拉丁 **sort-**（命运、份额，源自 sors）→ 古法语 *sorte* → 英语；本义“分得的份额、命运”，引申为“按份额分出的类别→种类”。
- **同根词**：assort（**as-** 向 + sort 种类 = 按种类分→分类）、assorted（**as-** + sort + **-ed** ……的 = 分好类的→各式各样的）、consort（**con-** 共同 + sort 命运 = 共命运→配偶、结伴）。
- **前缀·后缀**：前缀 **as- / ad-**（例：assist, attract）；后缀 **-ed**（例：tired, excited）。
- **同义·反义**：同义 kind（种类）, type（类型）；反义 无。
- **变形**：名词 → 复数：sorts；动词派生 → sort v. 分类；名词派生 → sorter n. 分类者、分拣机。

### 12. spring /spərɪŋ/ n. 活力;朝气
- **词根·渊源**：古英语 **springan**（跳起、涌出）→ 中古英语 *springen* → 英语；本义“跳跃、涌出”，引申为“泉水涌出之处→春天（万物萌发）”，再引申为“活力、朝气”。
- **同根词**：springy（spring 跳 + **-y** ……的 = 有弹性的）、springboard（spring 跳 + board 板 = 跳板）、offspring（**off-** 离开 + spring 生出 = 生出的后代→子孙）。
- **前缀·后缀**：前缀 **off-**（例：offshore, offset）；后缀 **-y**（例：rainy, windy）。
- **同义·反义**：同义 energy（活力）, vitality（生气）；反义 dullness（沉闷）, lethargy（无精打采）。
- **变形**：名词 → 复数：springs；动词派生 → spring v. 跳跃、涌出；形容词派生 → springy adj. 有弹性的。

### 13. bet /bɛt/ n. 打赌
- **词根·渊源**：词源存疑；一般认为可能来自古英语 *bētan*（使更好、激励）或与“使固定”义相关，16 世纪出现“打赌”义，确切来源存疑。
- **同根词**：betting（bet + **-ing** 名词后缀 = 打赌行为）、bettor（bet + **-or** 人 = 打赌者）。
- **前缀·后缀**：后缀 **-ing**（例：running, building）；后缀 **-or**（例：actor, visitor）。
- **同义·反义**：同义 wager（赌注）, gamble（赌博）；反义 无。
- **变形**：名词 → 复数：bets；动词 → 第三人称单数：bets；过去式：bet；过去分词：bet；现在分词：betting。

### 14. afterwards /ˈæftərwərdz/ adv. 后来
- **词根·渊源**：古英语 **æfter**（在后）+ **weard**（朝向）+ 副词性 **-s** → 中古英语 *afterward* → 英语 *afterwards*；本义“朝后方”，引申为“后来、之后”。
- **同根词**：after（after 在后 = 在……之后）、afterward（after + ward 朝向 = 后来）、afternoon（after 后 + noon 正午 = 午后）。
- **前缀·后缀**：后缀 **-ward(s)**（例：towards, backwards）。
- **同义·反义**：同义 later（后来）, subsequently（随后）；反义 before（以前）, beforehand（事先）。
- **变形**：副词 → 无比较级（时间副词，不作比较）。

### 15. brief /brif/ adj. 简洁的;简单的
- **词根·渊源**：拉丁 **brev-**（短）→ 拉丁 *brevis* → 古法语 *brief* → 英语；本义“短的”，引申为“（言语）简短的、简洁的”。
- **同根词**：brevity（brev 短 + **-ity** 名词后缀 = 简短）、abbreviate（**ab-** 向 + brev 短 + **-iate** 动词 = 使变短→缩写）、briefly（brief + **-ly** 副词后缀 = 简短地）。
- **前缀·后缀**：前缀 **ab-**（例：absent, abstract）；后缀 **-ly**（例：sadly, happily）。
- **同义·反义**：同义 short（短的）, concise（简明的）；反义 long（长的）, lengthy（冗长的）。
- **变形**：形容词 → 比较级：briefer；最高级：briefest；名词派生 → brief n. 摘要；副词派生 → briefly adv. 简短地。

### 16. journalist /ˈʤərnəlɪst/ n. 新闻记者
- **词根·渊源**：拉丁 **diurn-**（每日的，源自 dies 日）→ 古法语 *journal*（每日的）→ 英语 *journal*（日报）+ **-ist**（人）→ 英语；本义“写日报的人”，即“新闻记者”。
- **同根词**：journal（diurn 日 + **-al** ……的 = 每日的→日报、期刊）、journey（jour 日 + **-ney** = 一天的行程→旅行）、diary（di 日 + **-ary** 物 = 记日之物→日记）、adjourn（**ad-** 向 + journ 日 = 推到某日→延期）。
- **前缀·后缀**：后缀 **-ist**（例：artist, pianist）；后缀 **-al**（例：natural, musical）。
- **同义·反义**：同义 reporter（记者）, correspondent（通讯员）；反义 无。
- **变形**：名词 → 复数：journalists；形容词派生 → journalistic adj. 新闻业的；名词派生 → journalism n. 新闻业。

### 17. pilot /ˈpaɪlət/ n. 领航员;引水员
- **词根·渊源**：希腊 **pēdon**（桨）+ *pēdōn*（舵手）→ 意大利语 *pilota* → 古法语 *pilot* → 英语；本义“掌舵引路之人”，即“领航员、引水员”，后引申为“飞行员”。
- **同根词**：pilotage（pilot + **-age** 名词后缀 = 领航、引水费）。
- **前缀·后缀**：后缀 **-age**（例：marriage, package）。
- **同义·反义**：同义 navigator（领航员）, guide（向导）；反义 无。
- **变形**：名词 → 复数：pilots；动词派生 → pilot v. 驾驶、引导。

### 18. failure /ˈfeɪljər/ n. 失败
- **词根·渊源**：拉丁 **fall-**（跌倒、欺骗，源自 fallere）→ 古法语 *faillir*（失败、缺乏）→ 英语 *fail* + **-ure**（名词后缀）→ 英语；本义“跌倒、落空”，引申为“失败”。
- **同根词**：fail（fall 跌倒 = 失败）、failing（fail + **-ing** 名词后缀 = 缺点）、fallible（fall 跌倒 + **-ible** 可……的 = 可能出错的→易犯错的）、false（fals 欺骗 + **-e** = 欺骗的→假的）、fault（fall 跌倒 + **-t** = 失足→过错）。
- **前缀·后缀**：后缀 **-ure**（例：pleasure, mixture）；后缀 **-ible**（例：possible, visible）。
- **同义·反义**：同义 defeat（失败）, loss（损失）；反义 success（成功）, victory（胜利）。
- **变形**：名词 → 复数：failures；动词派生 → fail v. 失败；形容词派生 → failed adj. 失败的。

### 19. regard /rɪˈgɑrd/ v. 把······视为;看待
- **词根·渊源**：古法语 **regarder**（看、注视）→ 中古英语 *regarden*，源自古法语 re-（再、加强）+ garder（看守、注视，日耳曼语源）；本义“仔细看、注视”，引申为“在心目中看待、视为”。
- **同根词**：regardless（regard + **-less** 无……的 = 不加留意的→不顾的）、regards（regard + **-s** 复数 = 问候、致意）、disregard（**dis-** 不 + regard 看 = 不看→漠视）、guard（与 garder 同源，看守→守卫）、ward（同源，看守→保卫、病房）。
- **前缀·后缀**：前缀 **re-**（例：return, review）；名词后缀 **-less**（例：careless, hopeless）。
- **同义·反义**：同义 consider（认为）, view（看待）；反义 ignore（忽视）, neglect（忽略）。
- **变形**：动词 → 第三人称单数：regards；过去式：regarded；过去分词：regarded；现在分词：regarding；名词派生 → regard n. 关注、尊重；形容词派生 → regardful adj. 留心的；副词派生 → regardless adv. 不顾地。
