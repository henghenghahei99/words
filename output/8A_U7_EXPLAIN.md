## 二、逐词说文解字

### 1. memory /ˈmeməri/ n. 记忆力；记性；记忆，回忆
- **词根·渊源**：拉丁 **memor**（记忆的，不忘的）→ 拉丁 *memoria*（记忆）→ 古法语 *memoire* → 英语 memory；本义“记忆的能力/记忆的内容”，引申为“回忆、记性”。
- **同根词**：memorize（memory 的动词化：记住）、memorial（memor 记忆 + **-ial** …的：纪念的）、remember（**re-** 再 + member 记忆 = 再次记起→记得）、commemorate（**com-** 共同 + memor 记忆 + **-ate** 动词后缀：共同纪念）、memorable（memor 记忆 + **-able** 可…的：值得记住的）。
- **前缀·后缀**：名词后缀 **-y**（例：history, victory）；动词后缀 **-ize**（例：realize, organize）。
- **同义·反义**：同义 recollection（回忆）, remembrance（记忆）；反义 forgetfulness（健忘）, oblivion（遗忘）。
- **变形**：名词 → 复数：memories；动词派生 → memorize v. 记住；形容词派生 → memorable adj. 难忘的；副词派生 → memorably adv. 难忘地。

### 2. corner /ˈkɔ:rnə(r)/ n. 角；拐角；角落
- **词根·渊源**：拉丁 **cornu**（角，兽角）→ 古法语 *corniere*（角落）→ 英语 corner；本义“角状物、突出的角”，引申为“拐角、角落”。
- **同根词**：cornet（corn 角 + **-et** 小：小号角→短号）、unicorn（**uni-** 一 + corn 角：独角兽）、cornucopia（cornu 角 + copia 丰富：丰饶角）、bicorn（**bi-** 二 + corn 角：双角的）。
- **前缀·后缀**：名词后缀 **-er**（例：teacher, worker）；前缀 **uni-**（例：uniform）、**bi-**（例：bicycle）。
- **同义·反义**：同义 angle（角）, nook（角落）；反义 center（中心）, middle（中间）。
- **变形**：名词 → 复数：corners；形容词派生 → cornered adj. 有角的、被逼入角落的；动词派生 → corner v. 使陷入困境。

### 3. lose /luːz/ v.（过去式lost）丧失；失去；遗失；丢失；输掉
- **词根·渊源**：古英语 *losian*（丢失、毁灭），与 *leosan*（失去）同源，源自日耳曼语 *lausa-*（松散的、失去的）；本义“使松散、失去”，引申为“丧失、输掉”。
- **同根词**：loss（lose 的名词形式：损失）、lost（lose 的过去分词：丢失的）、loser（lose + **-er** 人：失败者）、forlorn（**for-** 完全 + lorn 失去 = 被完全抛弃的→孤苦的）。
- **前缀·后缀**：动词后缀 **-er** 构成名词（例：winner, teacher）；前缀 **for-**（例：forgive, forbid）。
- **同义·反义**：同义 misplace（放错）, forfeit（丧失）；反义 find（找到）, win（赢）。
- **变形**：动词 → 第三人称单数：loses；过去式：lost；过去分词：lost；现在分词：losing；名词派生 → loss n. 损失；loser n. 失败者；形容词派生 → lost adj. 丢失的。

### 4. improve /ɪmˈpruːv/ v. 改进；改善
- **词根·渊源**：古法语 *emprower*（使获利、改进），源自 * prou*（利益），与拉丁 **pro-**（向前、为了）有关；本义“使有利可图”，引申为“改进、改善”。
- **同根词**：improvement（improve + **-ment** 名词后缀：改进）、improver（improve + **-er** 人：改进者）、approve（**ap-** 向 + prove 证明 = 证明为好→批准）、proof（与 prove 同源：证明）。
- **前缀·后缀**：前缀 **im-**（=in-，使…）（例：import, impress）；名词后缀 **-ment**（例：movement, development）。
- **同义·反义**：同义 better（改善）, enhance（提高）；反义 worsen（使恶化）, deteriorate（恶化）。
- **变形**：动词 → 第三人称单数：improves；过去式：improved；过去分词：improved；现在分词：improving；名词派生 → improvement n. 改进；形容词派生 → improved adj. 改良的。

### 5. mention /ˈmɛnʃən/ v. 提到；说到
- **词根·渊源**：拉丁 **mens / ment-**（心、思想）→ 拉丁 *mentio*（提及）→ 古法语 *mention* → 英语 mention；本义“在心中想起→说出”，引申为“提到、说到”。
- **同根词**：mental（ment 心 + **-al** …的：心理的）、mentionable（mention + **-able** 可…的：可提及的）、comment（**com-** 共同 + ment 心 = 共同思考→评论）、mentality（mental + **-ity** 名词后缀：心态）、demented（**de-** 去除 + ment 心：失去心智的）。
- **前缀·后缀**：名词后缀 **-tion**（例：action, nation）；前缀 **com-**（例：compare, combine）、**de-**（例：decrease, depart）。
- **同义·反义**：同义 refer to（提及）, cite（引用）；反义 omit（省略）, ignore（忽视）。
- **变形**：动词 → 第三人称单数：mentions；过去式：mentioned；过去分词：mentioned；现在分词：mentioning；名词派生 → mention n. 提及；形容词派生 → mentionable adj. 可提及的。

### 6. method /ˈmɛθəd/ n. 方法；措施；办法
- **词根·渊源**：希腊 **meta-**（沿着、之后）+ **hodos**（道路）→ 希腊 *methodos*（追寻之路、方法）→ 拉丁 *methodus* → 英语 method；本义“沿着道路走→途径”，引申为“方法、办法”。
- **同根词**：methodical（method + **-ical** …的：有条理的）、methodology（method + **-ology** 学科：方法论）、period（**peri-** 周围 + hodos 路 = 绕一圈的路→时期）、exodus（**ex-** 出 + hodos 路 = 出去的路→大批离去）。
- **前缀·后缀**：前缀 **meta-**（例：metaphor, metabolism）、**peri-**（例：perimeter, periscope）；名词后缀 **-ology**（例：biology, psychology）。
- **同义·反义**：同义 way（方式）, approach（方法）；反义 无。
- **变形**：名词 → 复数：methods；形容词派生 → methodical adj. 有条理的；副词派生 → methodically adv. 有条理地。

### 7. spelling /ˈspɛlɪŋ/ v. 拼写，拼法
- **词根·渊源**：古英语 *spellian*（讲述、拼读）→ 中古英语 *spellen*（拼写）+ 名词后缀 **-ing**；本义“讲述字母→拼读”，引申为“拼写、拼法”。
- **同根词**：spell（spelling 的动词原形：拼写）、speller（spell + **-er** 人：拼写者）、gospel（**god** 神 + spell 讲述 = 神的好消息→福音）、spellbound（spell 咒语 + bound 被束缚的：被咒语定住的→入迷的）。
- **前缀·后缀**：名词后缀 **-ing**（例：reading, writing）；名词后缀 **-er**（例：reader, writer）。
- **同义·反义**：同义 orthography（正字法）, writing（书写）；反义 无。
- **变形**：名词 → 复数：spellings；动词派生 → spell v. 拼写；名词派生 → speller n. 拼写者。

### 8. mind /maɪnd/ n. 头脑；大脑；心智
- **词根·渊源**：古英语 *gemynd*（记忆、思想），源自日耳曼语 *ga-mundi-*，与拉丁 **mens**（心）同出 PIE *men-*（思考）；本义“记忆、思想”，引申为“头脑、心智”。
- **同根词**：mental（ment 心 + **-al** …的：心理的）、mention（ment 心 + **-ion** 名词后缀：提及）、remind（**re-** 再 + mind 心 = 再次想起→提醒）、mindful（mind + **-ful** 充满…的：留心的）、mindless（mind + **-less** 无…的：无心的）。
- **前缀·后缀**：前缀 **re-**（例：return, recall）；形容词后缀 **-ful**（例：helpful, useful）、**-less**（例：hopeless, careless）。
- **同义·反义**：同义 brain（大脑）, intellect（智力）；反义 body（身体）, matter（物质）。
- **变形**：名词 → 复数：minds；形容词派生 → mindful adj. 留心的；mindless adj. 无心的；副词派生 → mindfully adv. 留心地。

### 9. silly /ˈsɪli/ adj. 可笑的；愚蠢的；傻的
- **词根·渊源**：古英语 *sælig*（幸福的、有福的）→ 中古英语 *sely*（天真的、单纯的）→ 英语 silly；本义“有福的”，经“天真→单纯→傻”的语义贬降，引申为“愚蠢的、可笑的”。
- **同根词**：silliness（silly + **-ness** 名词后缀：愚蠢）、sillily（silly + **-ly** 副词后缀：愚蠢地）。
- **前缀·后缀**：形容词后缀 **-y**（例：happy, rainy）；名词后缀 **-ness**（例：happiness, kindness）。
- **同义·反义**：同义 foolish（愚蠢的）, stupid（笨的）；反义 wise（明智的）, sensible（明智的）。
- **变形**：形容词 → 比较级：sillier；最高级：silliest；名词派生 → silliness n. 愚蠢；副词派生 → sillily adv. 愚蠢地。

### 10. mile /maɪl/ n. 英里
- **词根·渊源**：拉丁 **mille**（一千）→ 拉丁 *milia passuum*（一千步）→ 古英语 *mil* → 英语 mile；本义“一千（步）”，引申为长度单位“英里”。
- **同根词**：millennium（mille 千 + ann 年 + **-ium** 名词后缀：一千年）、million（mille 千 + **-ion** 增大后缀：百万）、millimeter（mille 千 + meter 米：毫米）、mileage（mile + **-age** 名词后缀：英里数）。
- **前缀·后缀**：名词后缀 **-age**（例：package, marriage）；数词前缀 **milli-**（例：milligram, milliliter）。
- **同义·反义**：同义 无；反义 无。
- **变形**：名词 → 复数：miles；名词派生 → mileage n. 英里数。

### 11. letter /ˈletə(r)/ n. 字母
- **词根·渊源**：拉丁 **littera**（字母、文字）→ 古法语 *lettre* → 英语 letter；本义“字母（文字的基本单位）”，引申为“信件”。
- **同根词**：literate（littera 字母 + **-ate** …的：识字的）、literature（littera 文字 + **-ature** 名词后缀：文学）、literal（littera 字母 + **-al** …的：字面的）、illiterate（**il-** 不 + literate 识字的：文盲的）、letters（letter 的复数：文学、学问）。
- **前缀·后缀**：名词后缀 **-er**（例：teacher, worker）；前缀 **il-**（=in-，不）（例：illegal, logical）。
- **同义·反义**：同义 character（字符）, epistle（书信）；反义 无。
- **变形**：名词 → 复数：letters；形容词派生 → literal adj. 字面的；literate adj. 识字的；名词派生 → literature n. 文学。

### 12. worth /wɜ:rθ/ n. 值得；有……价值（的）
- **词根·渊源**：古英语 *weorþ*（价值、值得的），源自日耳曼语 *wertha-*（价值），与 *wer*（人）有关，本义“与人相称的价值”；引申为“值得、有……价值”。
- **同根词**：worthy（worth + **-y** …的：值得的）、worthless（worth + **-less** 无…的：无价值的）、worthwhile（worth + while 时间 = 值得花时间的→值得做的）、unworthy（**un-** 不 + worthy 值得的：不值得的）。
- **前缀·后缀**：形容词后缀 **-y**（例：rainy, healthy）、**-less**（例：hopeless, careless）；前缀 **un-**（例：unhappy, unfair）。
- **同义·反义**：同义 value（价值）, merit（优点）；反义 worthlessness（无价值）。
- **变形**：名词 → 复数：不可数；形容词派生 → worthy adj. 值得的；worthless adj. 无价值的；副词派生 → worthily adv. 值得地。

### 13. spell /spɛl/ v. 拼写，拼出
- **词根·渊源**：古英语 *spellian*（讲述、宣告），源自日耳曼语 *spellam*（讲述）；本义“讲述”，引申为“逐字母说出→拼写”。
- **同根词**：spelling（spell + **-ing** 名词后缀：拼写）、speller（spell + **-er** 人：拼写者）、gospel（**god** 神 + spell 讲述 = 神的好消息→福音）、spellbound（spell 咒语 + bound 被束缚的：入迷的）。
- **前缀·后缀**：名词后缀 **-ing**（例：reading, writing）；名词后缀 **-er**（例：reader, writer）。
- **同义·反义**：同义 write out（写出）, decipher（辨认）；反义 无。
- **变形**：动词 → 第三人称单数：spells；过去式：spelled/spelt；过去分词：spelled/spelt；现在分词：spelling；名词派生 → spelling n. 拼写；speller n. 拼写者。

### 14. unless /ʌnˈlɛs/ adj. 除非；如果不
- **词根·渊源**：中古英语 *on lesse*（在较少的情况下）→ 缩合为 *unless*；由 **un-**（不）+ **less**（较少）构成，本义“除非在较少…的情况下”，引申为连词“除非、如果不”。
- **同根词**：less（unless 的词根：较少的）、lessen（less + **-en** 动词后缀：减少）、lest（与 less 同源：以免）。
- **前缀·后缀**：前缀 **un-**（例：unhappy, unfair）；后缀 **-less**（例：hopeless, careless）。
- **同义·反义**：同义 except（除非）, if not（如果不）；反义 无。
- **变形**：连词 → 无形态变化；无比较级。

### 15. trouble /ˈtrʌbl/ n. 困难；问题；麻烦事
- **词根·渊源**：拉丁 **turbula**（骚动）→ 古法语 *truble* → 英语 trouble；源自拉丁 *turba*（骚动、人群），本义“骚动、混乱”，引申为“困难、麻烦”。
- **同根词**：troublesome（trouble + **-some** 引起…的：麻烦的）、troubled（trouble + **-ed** …的：困扰的）、trouble-free（trouble + free 无…的：无麻烦的）、disturb（**dis-** 加强 + turb 骚动：打扰）、turbulent（turb 骚动 + **-ulent** …的：动荡的）。
- **前缀·后缀**：形容词后缀 **-some**（例：handsome, awesome）；前缀 **dis-**（例：disagree, discover）。
- **同义·反义**：同义 difficulty（困难）, problem（问题）；反义 ease（容易）, comfort（舒适）。
- **变形**：名词 → 复数：troubles；形容词派生 → troublesome adj. 麻烦的；troubled adj. 困扰的；动词派生 → trouble v. 使烦恼。

### 16. list /lɪst/ n. 名单;目录;清单
- **词根·渊源**：古英语 *liste*（边缘、条带）→ 中古英语 *liste*（名单、目录）；本义“条带、边缘”，引申为“写有条目的纸条→名单、清单”。
- **同根词**：listen（与 list 同源，古英语 *hlysnan* 听：倾听）、listless（list 意愿 + **-less** 无…的：无精打采的）、enlist（**en-** 使 + list 名单 = 使入名单→征募）。
- **前缀·后缀**：名词后缀 **-less**（例：hopeless, careless）；前缀 **en-**（例：enable, enlarge）。
- **同义·反义**：同义 catalog（目录）, roll（名册）；反义 无。
- **变形**：名词 → 复数：lists；动词派生 → list v. 列出；形容词派生 → listless adj. 无精打采的。

### 17. step /stɛp/ n. 步，一步；步骤；措施
- **词根·渊源**：古英语 *stæpe*（步子、台阶），源自日耳曼语 *stapiz*（步），与 *stapan*（走）同源；本义“脚步、台阶”，引申为“步骤、措施”。
- **同根词**：stepwise（step + **-wise** 方式：逐步的）、footstep（foot 脚 + step 步：脚步）、stepfather（step 继 + father 父：继父）、stepping-stone（step + **-ing** + stone 石：踏脚石→垫脚石）。
- **前缀·后缀**：副词后缀 **-wise**（例：clockwise, likewise）；名词后缀 **-ing**（例：reading, writing）。
- **同义·反义**：同义 pace（步）, stage（阶段）；反义 无。
- **变形**：名词 → 复数：steps；动词派生 → step v. 踏、走；形容词派生 → stepwise adj. 逐步的。

### 18. cycle /ˈsaɪkl/ n. 循环，周期
- **词根·渊源**：希腊 **kyklos**（圆圈、轮子）→ 拉丁 *cyclus* → 英语 cycle；本义“圆圈、轮子”，引申为“循环、周期”。
- **同根词**：bicycle（**bi-** 二 + cycle 轮：两轮车→自行车）、tricycle（**tri-** 三 + cycle 轮：三轮车）、cyclone（cycl 圆 + **-one** 名词后缀：旋风）、recycle（**re-** 再 + cycle 循环：再循环→回收）、cyclist（cycle + **-ist** 人：骑自行车的人）。
- **前缀·后缀**：前缀 **bi-**（例：bilingual, bimonthly）、**tri-**（例：triangle, tricycle）、**re-**（例：return, rebuild）；名词后缀 **-ist**（例：artist, scientist）。
- **同义·反义**：同义 circle（循环）, rotation（轮转）；反义 无。
- **变形**：名词 → 复数：cycles；动词派生 → cycle v. 循环、骑自行车；名词派生 → cyclist n. 骑自行车的人；形容词派生 → cyclic adj. 循环的。

### 19. similar /ˈsɪməlɚ/ adj. 相像的；同样的，类似的
- **词根·渊源**：拉丁 **similis**（相像的）→ 法语 *similaire* → 英语 similar；本义即“相像的”，引申为“同样的、类似的”。
- **同根词**：simile（simil 相像 + **-e** = 相像的说法→明喻）、similitude（simil 相像 + **-itude** 状态 = 相像→相似）、assimilate（**as-** 向 + simil 相像 + **-ate** 使 = 使相像→同化）、simulate（simil 相像 + **-ate** 使 = 使相像→模仿）、simultaneous（simul 同时 + **-aneous** …的 = 同时的）。
- **前缀·后缀**：形容词后缀 **-ar**（例：familiar, regular）；前缀 **as-**（例：assist, associate）。
- **同义·反义**：同义 alike（相像的）, like（相似的）；反义 different（不同的）, dissimilar（不相似的）。
- **变形**：形容词 → 比较级：more similar；最高级：most similar；名词派生 → similarity n. 相似性；副词派生 → similarly adv. 同样地。

### 20. note /noʊt/ n. 纸币
- **词根·渊源**：拉丁 **nota**（记号、标记）→ 古法语 *note* → 英语 note；本义“记号、记录”，后指“票据、纸币”（banknote 的缩略），故有“纸币”义。
- **同根词**：notebook（note 记录 + book 本 = 记事的本子→笔记本）、notice（not 知道 + **-ice** = 使人知道→注意）、notify（not 知道 + **-ify** 使 = 使知道→通知）、notion（not 知道 + **-ion** 名词 = 所知→概念）、annotate（**an-** 加 + not 记号 + **-ate** = 加记号→注释）。
- **前缀·后缀**：名词后缀 **-ion**（例：action, nation）；动词后缀 **-ify**（例：simplify, beautify）。
- **同义·反义**：同义 bill（钞票）, banknote（纸币）；反义 无。
- **变形**：名词 → 复数：notes；动词派生 → note v. 注意、记录；形容词派生 → notable adj. 值得注意的；副词派生 → notably adv. 显著地。

### 21. wallet /ˈwɑːlɪt/ n. 钱包；皮夹子
- **词根·渊源**：古法语 *walet*（背包、行囊）→ 英语 wallet；本义“旅行用的背包”，后缩小为“装钱物的小包”，即“钱包、皮夹子”。
- **同根词**：无常用同根词（单纯词）。
- **前缀·后缀**：名词后缀 **-et**（指小，例：packet, pocket）。
- **同义·反义**：同义 purse（钱包）, billfold（皮夹）；反义 无。
- **变形**：名词 → 复数：wallets。

### 22. basket /ˈbɑːskɪt/ n. 篮；筐
- **词根·渊源**：古法语 *basket*（篮、筐）→ 英语 basket；词源存疑，一说与拉丁 *bascauda*（盆、篮）有关；本义即“编织的容器”，引申为“篮、筐”。
- **同根词**：basketry（basket 篮 + **-ry** 技艺 = 编篮术）、basketful（basket 篮 + **-ful** 满 = 一篮之量）。
- **前缀·后缀**：名词后缀 **-et**（指小，例：hatchet, ticket）；名词后缀 **-ry**（例：poetry, jewelry）。
- **同义·反义**：同义 hamper（大篮子）, container（容器）；反义 无。
- **变形**：名词 → 复数：baskets；形容词派生 → basketlike adj. 篮状的。

### 23. manager /ˈmænɪdʒɚ/ n. 经理；经营者
- **词根·渊源**：意大利语 *maneggiare*（驾驭马匹）→ 法语 *ménager*（管理家务）→ 英语 manage + **-er**；本义“驾驭、掌管”，加表人后缀 **-er** 即“掌管事务的人”，故为“经理、经营者”。
- **同根词**：manage（man 手 + **-age** 动作 = 用手驾驭→管理）、management（manage 管理 + **-ment** 名词 = 管理）、managerial（manager 经理 + **-ial** …的 = 经理的）、manipulate（man 手 + **-ipulate** 操作 = 用手操作→操纵）。
- **前缀·后缀**：表人后缀 **-er**（例：teacher, worker）；名词后缀 **-ment**（例：movement, agreement）。
- **同义·反义**：同义 director（主管）, administrator（管理者）；反义 employee（雇员）, worker（工人）。
- **变形**：名词 → 复数：managers；名词派生 → management n. 管理；形容词派生 → managerial adj. 经理的；动词派生 → manage v. 管理。

### 24. take out /teɪk aʊt/ v. 取出；去掉；提取
- **同义搭配**：remove（取出）/ withdraw（提取）
- **反义搭配**：put in（放入）

### 25. pour out /pɔː aʊt/ n. 涌出；倾吐；诉说
- **同义搭配**：spill out（涌出）/ confide（倾诉）
- **反义搭配**：hold back（抑制）
