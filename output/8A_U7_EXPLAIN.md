## 二、逐词说文解字

### 1. regularly /ˈrɛgjələrli/ adv. 有规律地
- **词根·渊源**：拉丁 **regula**（规则、尺子）→ 晚期拉丁 *regularis*（有规则的）→ 古法语 *reguler* → 英语 regular + **-ly**；本义“按尺子量过的”，引申为“有规律地”。
- **同根词**：regular（regula 规则 + **-ar** 形容词后缀：规则的）、regulate（regula 规则 + **-ate** 动词后缀：按规则管理→调节）、regulation（regulate + **-ion** 名词后缀：规章）、rule（regula 经古法语 *reule* 缩合：规则）、rail（regula 同源，本义“直尺→横杆→铁轨”）。
- **前缀·后缀**：副词后缀 **-ly**（例：quickly, happily）；形容词后缀 **-ar**（例：similar, popular）。
- **同义·反义**：同义 routinely（例行地）, consistently（一贯地）；反义 irregularly（不规则地）, randomly（随机地）。
- **变形**：副词 → 比较级：more regularly；最高级：most regularly；形容词派生 → regular adj. 有规律的；名词派生 → regularity n. 规律性。

### 2. repeat /rɪˈpit/ v. 重复
- **词根·渊源**：拉丁 **petere**（寻求、追求）→ 拉丁 *repetere*（再次寻求）→ 古法语 *repetir* → 英语；本义“再次去求取”，引申为“再说一遍、重复”。
- **同根词**：repetition（**re-** 再 + pet 求 + **-ition** 名词后缀：重复）、compete（**com-** 共同 + pet 求 = 共同追求→竞争）、petition（pet 求 + **-ition**：请求→请愿）、appetite（**ad-** 向 + pet 求 = 向食物求取→食欲）、impetus（**in-** 向 + pet 求 = 冲劲→推动力）。
- **前缀·后缀**：前缀 **re-**（再）（例：rewrite, rebuild）；动词后缀 **-ate**（例：create, donate）。
- **同义·反义**：同义 restate（重述）, duplicate（复制）；反义 无。
- **变形**：动词 → 第三人称单数：repeats；过去式：repeated；过去分词：repeated；现在分词：repeating；名词派生 → repetition n. 重复；形容词派生 → repeated adj. 反复的；副词派生 → repeatedly adv. 反复地。

### 3. note /noʊt/ n. 笔记；记录
- **词根·渊源**：拉丁 **nota**（记号、标记）→ 拉丁 *notare*（做标记）→ 古法语 *note* → 英语；本义“做的记号”，引申为“笔记、记录、便条”。
- **同根词**：notice（not 记号 + **-ice** = 用记号标出→注意）、notion（not 记号 + **-ion** = 心中记下的概念→观念）、notable（not 记号 + **-able** 可被标记的→值得注意的→著名的）、notify（not 记号 + **-ify** 使……做标记→通知）、annotate（**an-** 加 + not 记号 + **-ate** = 加记号→注释）。
- **前缀·后缀**：名词后缀 **-ion**（例：action, nation）；动词后缀 **-ify**（例：simplify, beautify）。
- **同义·反义**：同义 record（记录）, memo（备忘录）；反义 无。
- **变形**：名词 → 复数：notes；动词派生 → note v. 注意；记下；形容词派生 → notable adj. 值得注意的；名词派生 → notation n. 记号法。

### 4. mentally /ˈmɛnəli/ adv. 精神上
- **词根·渊源**：拉丁 **mens / ment-**（心、心智）→ 拉丁 *mentalis* → 英语 mental + **-ly**；本义“与心有关的”，引申为“精神上、在头脑中”。
- **同根词**：mental（ment 心 + **-al** 形容词后缀：心理的）、mention（ment 心 + **-ion** = 心中想起→提及）、comment（**com-** 共同 + ment 心 = 一起想→评论）、mind（与 ment 同出 PIE *men-* 想：头脑）、demented（**de-** 去除 + ment 心 + **-ed** = 失去心智的→精神错乱的）。
- **前缀·后缀**：副词后缀 **-ly**（例：badly, truly）；形容词后缀 **-al**（例：natural, personal）。
- **同义·反义**：同义 psychologically（心理上）, intellectually（智力上）；反义 physically（身体上）。
- **变形**：副词 → 比较级：more mentally；最高级：most mentally；形容词派生 → mental adj. 精神的；名词派生 → mentality n. 心态。

### 5. list /lɪst/ n. 清单
- **词根·渊源**：古英语 **liste**（边、条、布条）→ 中世纪英语“纸条→名单”；一说与古法语 *liste*（边条）同源，本义“一条一条列出的东西”，引申为“清单”（词源细节存疑）。
- **同根词**：listen（古英语 *hlysnan* 听，与 list 形近但不同源，存疑）、listless（list 古义“意愿” + **-less** 无 = 无精打采的，与“清单”义不同源，存疑）。
- **前缀·后缀**：无前后缀（单纯词）。
- **同义·反义**：同义 catalog（目录）, inventory（清单）；反义 无。
- **变形**：名词 → 复数：lists；动词派生 → list v. 列出；形容词派生 → listed adj. 列出的。

### 6. especially /əˈspɛʃəli/ adv. 尤其
- **词根·渊源**：拉丁 **species**（外观、种类）→ 拉丁 *specialis*（特定种类的）→ 古法语 *especial* → 英语 especial + **-ly**；本义“属于某一特别种类的”，引申为“尤其、特别”。
- **同根词**：special（spec 看 + **-ial** = 值得特别看的→特别的）、species（spec 看 + **-ies** = 看到的样子→种类）、specify（spec 种类 + **-ify** 使……具体→具体说明）、specific（spec 种类 + **-ific** 形成种类的→特定的）、inspect（**in-** 向内 + spect 看 = 向内看→检查）。
- **前缀·后缀**：副词后缀 **-ly**（例：finally, usually）；形容词后缀 **-ial**（例：social, official）。
- **同义·反义**：同义 particularly（特别地）, specially（专门地）；反义 generally（一般地）, ordinarily（通常地）。
- **变形**：副词 → 比较级：more especially；最高级：most especially；形容词派生 → especial adj. 特别的；special adj. 特别的。

### 7. diet /daɪət/ n. 日常饮食
- **词根·渊源**：希腊 **diaita**（生活方式、饮食规定）→ 拉丁 *diaeta* → 古法语 *diete* → 英语；本义“生活方式”，后专指“规定的饮食”，引申为“日常饮食”。
- **同根词**：dietary（diet 饮食 + **-ary** 形容词后缀：饮食的）、dietician（diet 饮食 + **-ician** 专家后缀：营养师）、dietetics（diet 饮食 + **-etics** 学科后缀：饮食学）。
- **前缀·后缀**：名词后缀 **-ician**（例：musician, physician）；形容词后缀 **-ary**（例：ordinary, necessary）。
- **同义·反义**：同义 food（食物）, nutrition（营养）；反义 无。
- **变形**：名词 → 复数：diets；动词派生 → diet v. 节食；形容词派生 → dietary adj. 饮食的。

### 8. maintain /meɪnˈteɪn/ v. 维持；保持
- **词根·渊源**：拉丁 **manus**（手）→ 拉丁 *manutenere*（用手握住）→ 古法语 *maintenir* → 英语；本义“用手握住不放”，引申为“维持、保持”。
- **同根词**：maintenance（maintain + **-ance** 名词后缀：维持）、manual（manu 手 + **-al** 手的→手工的）、manage（man 手 + **-age** = 用手操控→管理）、manipulate（mani 手 + **-pulate** 操作：操纵）、manuscript（manu 手 + script 写 = 手写的→手稿）。
- **前缀·后缀**：前缀 **main-**（手，来自拉丁 manus）（例：manual, manage）；名词后缀 **-ance**（例：importance, distance）。
- **同义·反义**：同义 keep（保持）, preserve（维持）；反义 abandon（放弃）, neglect（忽视）。
- **变形**：动词 → 第三人称单数：maintains；过去式：maintained；过去分词：maintained；现在分词：maintaining；名词派生 → maintenance n. 维持；形容词派生 → maintainable adj. 可维持的。

### 9. nut /nət/ n. 坚果
- **词根·渊源**：古英语 **hnutu**（坚果）→ 中世纪英语 *note* → 现代英语 nut；与德语 *Nuss*、拉丁 *nux* 同出 PIE *kneu-*（坚果），本义即“硬壳果”。
- **同根词**：nutty（nut 坚果 + **-y** 形容词后缀：有坚果味的→古怪的）、nutmeg（nut 坚果 + 古法语 *mugue* 麝香 = 坚果状香料→肉豆蔻）、walnut（古英语 *wealh* 外来的 + nut 坚果 = 外来的坚果→核桃）、chestnut（古法语 *chasteigne* 栗树 + nut = 栗子）、peanut（pea 豌豆 + nut 坚果 = 豌豆状坚果→花生）。
- **前缀·后缀**：形容词后缀 **-y**（例：rainy, salty）。
- **同义·反义**：同义 kernel（果仁）, seed（种子）；反义 无。
- **变形**：名词 → 复数：nuts；形容词派生 → nutty adj. 有坚果味的；古怪的。

### 10. relax /rɪˈlæks/ v. 放松；休息
- **词根·渊源**：拉丁 **laxus**（松的）→ 拉丁 *relaxare*（放松、松开）→ 古法语 *relaxer* → 英语；本义“使松开”，引申为“放松、休息”。
- **同根词**：relaxation（relax + **-ation** 名词后缀：放松）、lax（lax 松的：松弛的）、laxative（lax 松 + **-ative** = 使肠道松动的→泻药）、release（**re-** 回 + lease 松 = 松开→释放）、slack（与 lax 同源：松弛的）。
- **前缀·后缀**：前缀 **re-**（回、再）（例：return, recall）；名词后缀 **-ation**（例：creation, information）。
- **同义·反义**：同义 rest（休息）, loosen（放松）；反义 tense（使紧张）, tighten（收紧）。
- **变形**：动词 → 第三人称单数：relaxes；过去式：relaxed；过去分词：relaxed；现在分词：relaxing；名词派生 → relaxation n. 放松；形容词派生 → relaxed adj. 放松的；relaxing adj. 令人放松的。

### 11. stressed /strɛst/ adj. 心力交瘁的；焦总不安的
- **词根·渊源**：拉丁 **strictus**（拉紧的）→ 古法语 *estrece*（狭窄、压迫）→ 英语 distress（痛苦）缩略为 stress + **-ed**；本义“被拉紧的”，引申为“承受压力的、心力交瘁的”。
- **同根词**：stress（strict 拉紧 → stress 压力：压力）、distress（**dis-** 分开 + stress 拉紧 = 拉散→痛苦）、strict（strict 拉紧的：严格的）、restrict（**re-** 回 + strict 拉紧 = 拉回→限制）、constrict（**con-** 共同 + strict 拉紧 = 一起拉紧→收缩）。
- **前缀·后缀**：形容词后缀 **-ed**（例：tired, excited）；前缀 **dis-**（例：disturb, discover）。
- **同义·反义**：同义 anxious（焦虑的）, tense（紧张的）；反义 relaxed（放松的）, calm（平静的）。
- **变形**：形容词 → 比较级：more stressed；最高级：most stressed；名词派生 → stress n. 压力；动词派生 → stress v. 强调；使紧张。

### 12. tend /tɛnd/ v. 往往会；常常就
- **词根·渊源**：拉丁 **tendere**（伸展、拉向）→ 古法语 *tendre* → 英语；本义“朝某方向伸展”，引申为“倾向于、往往会”。
- **同根词**：tendency（tend 倾向 + **-ency** 名词后缀：倾向）、extend（**ex-** 向外 + tend 伸 = 向外伸→延伸）、intend（**in-** 向内 + tend 伸 = 心向内伸→打算）、attend（**ad-** 向 + tend 伸 = 把心思伸向→出席；照料）、tension（tens 伸紧 + **-ion** = 拉紧→紧张）。
- **前缀·后缀**：前缀 **ex-**（向外）（例：export, exit）；名词后缀 **-ency**（例：urgency, frequency）。
- **同义·反义**：同义 incline（倾向于）, be likely to（往往）；反义 无。
- **变形**：动词 → 第三人称单数：tends；过去式：tended；过去分词：tended；现在分词：tending；名词派生 → tendency n. 倾向。

### 13. normal /ˈnɔrməl/ adj. 正常的
- **词根·渊源**：拉丁 **norma**（木匠的角尺、标准）→ 拉丁 *normalis*（按角尺的、合乎标准的）→ 英语；本义“合乎角尺标准的”，引申为“正常的”。
- **同根词**：norm（norma 标准：规范）、normalize（normal + **-ize** 使……化：使正常化）、abnormal（**ab-** 偏离 + normal 正常 = 偏离正常的→反常的）、enormous（**e-** 出 + norm 标准 + **-ous** = 超出标准的→巨大的）、normative（norm 标准 + **-ative** 标准的→规范的）。
- **前缀·后缀**：前缀 **ab-**（偏离）（例：absent, abstract）；动词后缀 **-ize**（例：realize, modernize）。
- **同义·反义**：同义 regular（常规的）, ordinary（普通的）；反义 abnormal（反常的）, unusual（不寻常的）。
- **变形**：形容词 → 比较级：more normal；最高级：most normal；名词派生 → normality n. 正常状态；动词派生 → normalize v. 使正常化；副词派生 → normally adv. 正常地。

### 14. loss /lɔs/ n. 丧失；损失
- **词根·渊源**：古英语 **los**（毁灭、丧失）→ 中世纪英语 *los* → 现代英语 loss；与动词 lose 同源，本义“失去的状态”，引申为“丧失、损失”。
- **同根词**：lose（古英语 *losian* 失去：丢失）、lost（lose 的过去分词：丢失的）、loser（lose + **-er** 人：失败者）、loose（与 lose 同源，本义“松开”：松的）。
- **前缀·后缀**：无前后缀（单纯词）。
- **同义·反义**：同义 damage（损害）, deprivation（丧失）；反义 gain（获得）, profit（收益）。
- **变形**：名词 → 复数：losses；动词派生 → lose v. 失去；形容词派生 → lossy adj. 有损耗的。

### 15. fork /fɔrk/ n. 餐叉
- **词根·渊源**：拉丁 **furca**（叉子、干草叉）→ 古英语 *forca* → 中世纪英语 *forke* → 英语；本义“农用的叉子”，后指“餐叉”，引申为“分叉”。
- **同根词**：forked（fork 叉 + **-ed** 形容词后缀：分叉的）、forkful（fork 叉 + **-ful** 满的量：一叉之量）、bifurcate（**bi-** 二 + furc 叉 + **-ate** = 分成两叉→分叉）。
- **前缀·后缀**：形容词后缀 **-ed**（例：pointed, wooded）；名词后缀 **-ful**（例：spoonful, handful）。
- **同义·反义**：同义 无；反义 无。
- **变形**：名词 → 复数：forks；动词派生 → fork v. 分叉；形容词派生 → forked adj. 分叉的。

### 16. onion /ˈənjən/ n. 洋葱
- **词根·渊源**：拉丁 **unio**（单一、一体）→ 拉丁 *unionem* → 古法语 *oignon* → 英语；本义“一体之物”（因洋葱层层包裹成一个球），引申为“洋葱”。
- **同根词**：union（uni 一 + **-ion** = 合为一体→联合）、unit（uni 一 + **-t** = 一个单位）、unite（uni 一 + **-ite** 动词后缀：联合）、unique（uni 一 + **-que** = 唯一的）、unanimous（un 一 + anim 心 + **-ous** = 一条心的→一致的）。
- **前缀·后缀**：名词后缀 **-ion**（例：opinion, region）；形容词后缀 **-ous**（例：famous, dangerous）。
- **同义·反义**：同义 无；反义 无。
- **变形**：名词 → 复数：onions；形容词派生 → oniony adj. 洋葱味的。

### 17. ant /ænt/ n. 蚂蚁
- **词根·渊源**：古英语 **ǣmette**（蚂蚁）→ 中世纪英语 *amete* → 现代英语 ant；本义即“蚂蚁”，词首元音因与冠词 a 连读而脱落（词源细节存疑）。
- **同根词**：anthill（ant 蚂蚁 + hill 丘 = 蚁丘）、antacid（**ant-** 抗 + acid 酸 = 抗酸药，与“蚂蚁”义不同源，存疑）。
- **前缀·后缀**：无前后缀（单纯词）。
- **同义·反义**：同义 无；反义 无。
- **变形**：名词 → 复数：ants；形容词派生 → antlike adj. 像蚂蚁的。

### 18. context /ˈkɑntɛkst/ n. 上下文；语境
- **词根·渊源**：拉丁 **texere**（编织）→ 拉丁 *contextus*（编织在一起的）→ 英语；本义“编织在一起的文字”，引申为“上下文、语境”。
- **同根词**：text（text 编织→文本：课文）、textile（text 编织 + **-ile** 可编织的→纺织品）、texture（text 编织 + **-ure** 名词后缀：质地）、technical（techn 技艺 + **-ical** 技艺的→技术的，与 texere 同出 PIE *teks-* 编织，存疑）、subtle（**sub-** 下 + tle 编织 = 细密编织的→微妙的，存疑）。
- **前缀·后缀**：前缀 **con-**（共同）（例：connect, combine）；名词后缀 **-ure**（例：picture, mixture）。
- **同义·反义**：同义 setting（背景）, background（背景）；反义 无。
- **变形**：名词 → 复数：contexts；形容词派生 → contextual adj. 上下文的；副词派生 → contextually adv. 从上下文看。

### 19. image /ˈɪmɪʤ/ n. 图像
- **词根·渊源**：拉丁 **imago / imagin-**（像、影像）→ 古法语 *image* → 英语；本义“模仿之物、塑像”，引申为“图像、形象”。
- **同根词**：imagine（image + **-ine** 动词化 = 在心中形成图像→想象）、imagination（imagin- 像 + **-ation** 名词后缀 = 形成图像的能力→想象力）、imaginative（imagin- + **-ative** …的 = 富有想象力的）、imitate（拉丁 imitari 模仿，与 imago 同源存疑 = 模仿）。
- **前缀·后缀**：名词后缀 **-age**（例：village, message）；动词后缀 **-ine**（例：imagine, examine）。
- **同义·反义**：同义 picture（图片）, likeness（肖像）；反义 无。
- **变形**：名词 → 复数：images；词性派生 → 名词派生：imagination n. 想象力；形容词派生：imaginary adj. 想象中的；副词派生：无。

### 20. sense /sɛns/ n. 感觉官能 (即视、听、嗅、味、触五觉)
- **词根·渊源**：拉丁 **sent- / sens-**（感觉、感知，源自 sentire 感觉）→ 古法语 *sens* → 英语；本义“感知能力”，引申为“感觉官能、意义、判断力”。
- **同根词**：sensation（sens 感觉 + **-ation** 名词后缀 = 感觉→知觉）、sensitive（sens + **-itive** …的 = 敏感的）、sensible（sens + **-ible** 能…的 = 能感知的→明智的）、sentence（拉丁 sententia 意见，源自 sentire 感觉 = 表达想法→句子）、consent（**con-** 共同 + sent 感觉 = 感觉一致→同意）、sentiment（sent 感觉 + **-iment** 名词后缀 = 情感）。
- **前缀·后缀**：名词后缀 **-ation**（例：information, education）；前缀 **con-**（例：connect, confirm）。
- **同义·反义**：同义 feeling（感觉）, perception（知觉）；反义 无。
- **变形**：名词 → 复数：senses；词性派生 → 形容词派生：sensory adj. 感觉的；副词派生：无；动词派生：sense v. 感觉到。

### 21. summary /ˈsəməri/ n. 总结；概括
- **词根·渊源**：拉丁 **summ-**（最高的、总的，源自 summus 最高的）→ 中世纪拉丁 *summarius* → 英语；本义“总的、概要的”，引申为“总结、概括”。
- **同根词**：sum（拉丁 summus 最高→总数）、summit（summ 最高 + **-it** = 最高点→顶峰）、summarize（summary + **-ize** 动词化 = 做总结→概括）、summarily（summary + **-ly** 副词后缀 = 概括地→立即地）。
- **前缀·后缀**：名词后缀 **-ary**（例：dictionary, library）；动词后缀 **-ize**（例：realize, organize）。
- **同义·反义**：同义 outline（概要）, abstract（摘要）；反义 无。
- **变形**：名词 → 复数：summaries；词性派生 → 动词派生：summarize v. 总结；形容词派生：summary adj. 概括的；副词派生：summarily adv. 概括地。

### 22. contain /kənˈteɪn/ v. 包含；含有
- **词根·渊源**：拉丁 **ten- / tain-**（握、持，源自 tenere 握住）→ 古法语 *contenir* → 英语；**con-**（共同、完全）+ tenere（握）= 完全握住→容纳、包含。
- **同根词**：container（contain + **-er** 名词后缀 = 容纳之物→容器）、maintain（**main-** 手 + tain 握 = 用手握住→维持）、obtain（**ob-** 朝向 + tain 握 = 握到手→获得）、retain（**re-** 回 + tain 握 = 握回来→保留）、tenant（ten 握 + **-ant** 人 = 持有房屋的人→房客）、tenable（ten 握 + **-able** 能…的 = 能守住的→站得住脚的）。
- **前缀·后缀**：前缀 **con-**（例：connect, confirm）、**re-**（例：return, review）；名词后缀 **-er**（例：teacher, worker）。
- **同义·反义**：同义 include（包括）, hold（容纳）；反义 exclude（排除）。
- **变形**：动词 → 第三人称单数：contains；过去式：contained；过去分词：contained；现在分词：containing；词性派生 → 名词派生：container n. 容器；形容词派生：containable adj. 可容纳的；副词派生：无。

### 23. particular /ˌpɑˈtɪkjələr/ adj. 专指的；特指的
- **词根·渊源**：拉丁 **part-**（部分，源自 pars 部分）+ **-icul-**（小）→ 拉丁 *particularis*（关于小部分的）→ 古法语 *particulier* → 英语；本义“涉及小部分的”，引申为“特定的、专指的、特别的”。
- **同根词**：part（拉丁 pars 部分→部分）、particle（part 部分 + **-icle** 小 = 小部分→微粒）、partner（part 部分 + **-ner** 人 = 分享部分的人→伙伴）、partial（part + **-ial** …的 = 部分的→偏袒的）、participate（part 部分 + **-cip-** 拿 + **-ate** = 拿一份→参加）、partition（part + **-ition** 名词后缀 = 分成部分→分隔）。
- **前缀·后缀**：形容词后缀 **-ar**（例：similar, familiar）；指小后缀 **-icle**（例：particle, article）。
- **同义·反义**：同义 specific（特定的）, special（特别的）；反义 general（一般的）, universal（普遍的）。
- **变形**：形容词 → 比较级：more particular；最高级：most particular；词性派生 → 名词派生：particularity n. 特殊性；副词派生：particularly adv. 特别地。

### 24. chemistry /ˈkɛmɪstri/ n. 化学性质；化学
- **词根·渊源**：阿拉伯语 **al-kīmiyā**（炼金术）→ 中世纪拉丁 *alchimia* → 英语 *chemistry*；本义“炼金术”，后指研究物质组成的科学，即“化学、化学性质”。
- **同根词**：chemical（chemist + **-al** …的 = 化学的）、chemist（chemistry 去后缀 + **-ist** 人 = 化学家）、alchemy（阿拉伯 al-kīmiyā 炼金术→炼金术）。
- **前缀·后缀**：名词后缀 **-istry**（例：industry, ministry）；形容词后缀 **-al**（例：natural, musical）。
- **同义·反义**：同义 无；反义 无。
- **变形**：名词 → 复数：chemistries（作“化学性质”义时可数）；词性派生 → 形容词派生：chemical adj. 化学的；名词派生：chemist n. 化学家；副词派生：chemically adv. 化学上。
