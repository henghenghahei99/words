## 二、逐词说文解字

### 1. advice /ədˈvaɪs/ n. 建议
- **词根·渊源**：拉丁 **ad-**（向）+ **vid-**（看）→ 古法语 *avis*（看法）→ 英语 advice；本义“看过去形成的看法”，引申为“建议”。
- **同根词**：advise（**ad-** 向 + vis 看 = 使看→给看法→建议）、visible（vis 看 + **-ible** 可…的 = 可见的）、vision（vis 看 + **-ion** 名词后缀 = 视力、远见）、evident（**e-** 出 + vid 看 = 看得出来的→明显的）、provide（**pro-** 前 + vid 看 = 预先看到→准备、提供）、supervise（**super-** 上 + vis 看 = 从上面看→监督）。
- **前缀·后缀**：前缀 **ad-**（例：advance, admire）；名词后缀 **-ice**（例：service, justice）。
- **同义·反义**：同义 suggestion（建议）, counsel（忠告）；反义 无。
- **变形**：名词 → 复数：advices（多用不可数）；动词派生 → advise v. 建议；形容词派生 → advisable adj. 明智的；副词派生 → advisably adv. 明智地。

### 2. encourage /ɪnˈkʌrɪdʒ/ v. 鼓励；激励
- **词根·渊源**：拉丁 **cor / cord-**（心）→ 古法语 *corage*（勇气）→ 英语 courage；加前缀 **en-**（使…）构成“给心打气→鼓励”。
- **同根词**：courage（cor 心 + **-age** 名词后缀 = 由心而发的力量→勇气）、courageous（courage + **-ous** …的 = 勇敢的）、discourage（**dis-** 去除 + courage = 夺心→使气馁）、cordial（cor 心 + **-ial** …的 = 出自内心的→衷心的）、record（**re-** 回 + cor 心 = 记在心里→记录）。
- **前缀·后缀**：前缀 **en-**（例：enable, enrich）；名词后缀 **-age**（例：marriage, package）。
- **同义·反义**：同义 inspire（激励）, motivate（激发）；反义 discourage（使气馁）, dishearten（使沮丧）。
- **变形**：动词 → 第三人称单数：encourages；过去式：encouraged；过去分词：encouraged；现在分词：encouraging；名词派生 → encouragement n. 鼓励；形容词派生 → encouraging adj. 鼓舞人心的；副词派生 → encouragingly adv. 鼓舞人心地。

### 3. retire /rɪˈtaɪə(r)/ v. (令)退休；(使)退休
- **词根·渊源**：古法语 *retirer*（**re-** 回 + *tirer* 拉 = 拉回）→ 英语 retire；本义“拉回到安静处”，引申为“退下、退休”。
- **同根词**：retirement（retire + **-ment** 名词后缀 = 退休）、retired（retire + **-ed** …的 = 退休的）、tirade（*tirer* 拉 + **-ade** 名词后缀 = 拉长的话→长篇抨击，存疑）。
- **前缀·后缀**：前缀 **re-**（例：return, recall）；动词后缀 **-e**（例：arrive, divide）。
- **同义·反义**：同义 withdraw（退出）, step down（退下）；反义 continue（继续）, remain（留下）。
- **变形**：动词 → 第三人称单数：retires；过去式：retired；过去分词：retired；现在分词：retiring；名词派生 → retirement n. 退休；形容词派生 → retired adj. 退休的。

### 4. cheerful /ˈtʃɪəfl/ adj. 快乐的；高兴的
- **词根·渊源**：古法语 *chiere*（面容、神色）→ 英语 cheer（心情）→ cheer + **-ful**（充满…的）= 心情满满的→快乐的。
- **同根词**：cheer（*chiere* 面容 = 使面容开朗→欢呼）、cheerfully（cheerful + **-ly** 副词后缀 = 快乐地）、cheerfulness（cheerful + **-ness** 名词后缀 = 快乐）、cheery（cheer + **-y** …的 = 兴高采烈的）。
- **前缀·后缀**：形容词后缀 **-ful**（例：helpful, useful）；副词后缀 **-ly**（例：quickly, happily）。
- **同义·反义**：同义 happy（快乐的）, joyful（高兴的）；反义 sad（悲伤的）, gloomy（忧郁的）。
- **变形**：形容词 → 比较级：more cheerful；最高级：most cheerful；副词派生 → cheerfully adv. 快乐地；名词派生 → cheerfulness n. 快乐。

### 5. community /kəˈmjuːnəti/ n. 社区
- **词根·渊源**：拉丁 **communis**（共同的）→ 古法语 *comunete* → 英语 community；本义“共同生活的群体”，引申为“社区”。
- **同根词**：common（**com-** 共同 + mun 公共 = 共同的）、commune（**com-** 共同 + mun 公共 = 公社、共享）、communicate（commun 共同 + **-icate** 动词后缀 = 使共同→交流）、communism（commun 共同 + **-ism** 主义 = 共产主义）、communion（commun 共同 + **-ion** 名词后缀 = 共享、交流）。
- **前缀·后缀**：前缀 **com-**（例：combine, compare）；名词后缀 **-ity**（例：activity, ability）。
- **同义·反义**：同义 neighborhood（邻里）, society（社会）；反义 无。
- **变形**：名词 → 复数：communities；形容词派生 → communal adj. 公共的；名词派生 → communality n. 共同性。

### 6. medical /ˈmedɪkl/ adj. 医学的；医疗的
- **词根·渊源**：拉丁 **medicus**（医生）→ 拉丁 *medicus* + **-al** → 英语 medical；本义“与医生有关的”，引申为“医学的”。
- **同根词**：medicine（medic 医 + **-ine** 名词后缀 = 医学、药）、medicate（medic 医 + **-ate** 动词后缀 = 用药治疗）、medication（medicate + **-ion** 名词后缀 = 药物治疗）、medic（medic 医 = 医生、卫生员）。
- **前缀·后缀**：形容词后缀 **-al**（例：natural, national）；名词后缀 **-ine**（例：routine, marine）。
- **同义·反义**：同义 healing（治疗的）, therapeutic（治疗的）；反义 无。
- **变形**：形容词 → 无比较级（关系形容词，不作比较）；副词派生 → medically adv. 医学上；名词派生 → medicine n. 医学、药。

### 7. fried /fraɪd/ adj. 油炸的；油煎的；油炒的
- **词根·渊源**：拉丁 **frigere**（煎、炸）→ 古法语 *frire* → 英语 fry → fry + **-ed**（过去分词作形容词）= 油炸的。
- **同根词**：fry（*frire* 煎炸 = 油炸）、frying（fry + **-ing** 名词/形容词后缀 = 油炸、煎的）、fryer（fry + **-er** 工具后缀 = 油炸锅）。
- **前缀·后缀**：形容词后缀 **-ed**（例：boiled, baked）；动词后缀 **-y**（例：carry, study）。
- **同义·反义**：同义 deep-fried（油炸的）, pan-fried（煎的）；反义 boiled（煮的）, steamed（蒸的）。
- **变形**：形容词 → 无比较级（关系形容词，不作比较）；动词派生 → fry v. 油炸；名词派生 → fryer n. 油炸锅。

### 8. wherever /weərˈevə(r)/ conj. 各处；处处
- **词根·渊源**：古英语 **hwær**（哪里）+ **efre**（永远）→ where + ever 合成 → 英语 wherever；本义“无论哪里”，引申为“各处、处处”。
- **同根词**：where（hwær 哪里 = 哪里）、whenever（when + ever = 无论何时）、whatever（what + ever = 无论什么）、whoever（who + ever = 无论谁）、however（how + ever = 无论如何）。
- **前缀·后缀**：后缀 **-ever**（例：whenever, whatever）。
- **同义·反义**：同义 anywhere（任何地方）, everywhere（到处）；反义 nowhere（无处）。
- **变形**：连词 → 无形态变化；无词性派生。

### 9. future /ˈfjuːtʃə(r)/ n. 将来；未来
- **词根·渊源**：拉丁 **futurus**（将要发生的，*esse* 的将来分词）→ 古法语 *futur* → 英语 future；本义“将要来的”，引申为“将来”。
- **同根词**：futuristic（future + **-istic** …的 = 未来主义的）、futurity（future + **-ity** 名词后缀 = 未来性）、futurology（future + **-ology** 学科 = 未来学）。
- **前缀·后缀**：名词后缀 **-ure**（例：nature, culture）；形容词后缀 **-istic**（例：artistic, realistic）。
- **同义·反义**：同义 tomorrow（明天）, prospect（前景）；反义 past（过去）, present（现在）。
- **变形**：名词 → 复数：futures；形容词派生 → future adj. 将来的；futuristic adj. 未来主义的。

### 10. soon /suːn/ adv. 很快；马上；不久
- **词根·渊源**：古英语 **sōna**（立刻）→ 中古英语 *sone* → 英语 soon；本义“立刻”，引申为“很快、不久”。
- **同根词**：sooner（soon + **-er** 比较级后缀 = 更早）、soonest（soon + **-est** 最高级后缀 = 最早）。
- **前缀·后缀**：无前后缀（单纯词）。
- **同义·反义**：同义 shortly（不久）, quickly（很快）；反义 later（较晚）, eventually（最终）。
- **变形**：副词 → 比较级：sooner；最高级：soonest；无词性派生。

### 11. smart /smɑːt/ adj. 聪明的；机敏的
- **词根·渊源**：古英语 **smeortan**（刺痛）→ 中古英语 *smert*（疼痛的、尖锐的）→ 英语 smart；本义“刺痛的”，引申为“敏锐的→聪明的”。
- **同根词**：smartly（smart + **-ly** 副词后缀 = 聪明地）、smartness（smart + **-ness** 名词后缀 = 聪明）、smartphone（smart 智能 + phone 电话 = 智能手机）。
- **前缀·后缀**：副词后缀 **-ly**（例：quickly, badly）；名词后缀 **-ness**（例：kindness, darkness）。
- **同义·反义**：同义 clever（聪明的）, bright（机灵的）；反义 stupid（愚蠢的）, dull（迟钝的）。
- **变形**：形容词 → 比较级：smarter；最高级：smartest；副词派生 → smartly adv. 聪明地；名词派生 → smartness n. 聪明。

### 12. attention /əˈtenʃn/ n. 专心；注意力
- **词根·渊源**：拉丁 **ad-**（向）+ **tend-**（伸展）→ 拉丁 *attendere*（伸向）→ 古法语 *atencion* → 英语 attention；本义“把心思伸向某处”，引申为“注意力”。
- **同根词**：attend（**at-** 向 + tend 伸 = 伸向→出席、照料）、attentive（attend + **-ive** …的 = 专心的）、intend（**in-** 向内 + tend 伸 = 伸向内心→打算）、extend（**ex-** 向外 + tend 伸 = 向外伸→延伸）、tendency（tend 伸 + **-ency** 名词后缀 = 倾向）。
- **前缀·后缀**：前缀 **ad-**（例：advance, admire）；名词后缀 **-ion**（例：action, nation）。
- **同义·反义**：同义 focus（专注）, concentration（专心）；反义 inattention（不注意）, distraction（分心）。
- **变形**：名词 → 复数：attentions（多用不可数）；形容词派生 → attentive adj. 专心的；副词派生 → attentively adv. 专心地；动词派生 → attend v. 出席、照料。

### 13. seldom /ˈseldəm/ adv. 不常；很少；难得
- **词根·渊源**：古英语 **seldan**（不常）→ 中古英语 *selden* → 英语 seldom；本义“不常”，引申为“很少、难得”。
- **同根词**：seldom 为单纯词，无常用同根词。
- **前缀·后缀**：无前后缀（单纯词）。
- **同义·反义**：同义 rarely（很少）, infrequently（不常）；反义 often（经常）, frequently（频繁地）。
- **变形**：副词 → 无比较级（不作比较）；无词性派生。

### 14. bored /bɔːd/ adj. (对某人/事物)厌倦的；烦闷的
- **词根·渊源**：古英语 **borian**（钻孔）→ 英语 bore（钻孔→钻透→使厌烦）→ bore + **-ed**（过去分词作形容词）= 被钻透的→厌倦的。
- **同根词**：bore（borian 钻孔 = 钻孔→使厌烦）、boring（bore + **-ing** …的 = 令人厌烦的）、boredom（bore + **-dom** 名词后缀 = 厌倦）。
- **前缀·后缀**：形容词后缀 **-ed**（例：tired, excited）；名词后缀 **-dom**（例：freedom, kingdom）。
- **同义·反义**：同义 tired（厌倦的）, weary（厌烦的）；反义 interested（感兴趣的）, excited（兴奋的）。
- **变形**：形容词 → 比较级：more bored；最高级：most bored；动词派生 → bore v. 使厌烦；名词派生 → boredom n. 厌倦。

### 15. strict /strɪkt/ adj. 要求严格的；严厉的
- **词根·渊源**：拉丁 **strictus**（拉紧的，*stringere* 的过去分词）→ 拉丁 *strictus* → 英语 strict；本义“拉紧的”，引申为“严格约束的→严厉的”。
- **同根词**：strictly（strict + **-ly** 副词后缀 = 严格地）、strictness（strict + **-ness** 名词后缀 = 严格）、restrict（**re-** 回 + strict 拉紧 = 拉回→限制）、constrict（**con-** 共同 + strict 拉紧 = 一起拉紧→收缩）、stringent（string 拉紧 + **-ent** …的 = 严格的）。
- **前缀·后缀**：副词后缀 **-ly**（例：quickly, badly）；名词后缀 **-ness**（例：kindness, darkness）。
- **同义·反义**：同义 severe（严厉的）, stern（严格的）；反义 lenient（宽容的）, lax（松懈的）。
- **变形**：形容词 → 比较级：stricter；最高级：strictest；副词派生 → strictly adv. 严格地；名词派生 → strictness n. 严格。

### 16. relative /ˈrelətɪv/ n. 亲戚；亲属
- **词根·渊源**：拉丁 **re-**（回）+ **lat-**（带）→ 拉丁 *relatus*（带回、关联）→ 拉丁 *relativus* → 英语 relative；本义“有关联的”，引申为“有亲属关系的人”。
- **同根词**：relate（**re-** 回 + lat 带 = 带回→关联、讲述）、relation（relate + **-ion** 名词后缀 = 关系、亲属）、relationship（relation + **-ship** 名词后缀 = 关系）、relative 的形容词义（relat 关联 + **-ive** …的 = 相对的）、translate（**trans-** 转移 + lat 带 = 带过去→翻译）。
- **前缀·后缀**：前缀 **re-**（例：return, recall）；形容词/名词后缀 **-ive**（例：active, native）。
- **同义·反义**：同义 kin（亲属）, family member（家庭成员）；反义 stranger（陌生人）。
- **变形**：名词 → 复数：relatives；形容词派生 → relative adj. 相对的；副词派生 → relatively adv. 相对地；动词派生 → relate v. 关联、讲述。

### 17. uniform /ˈjuːnɪfɔːm/ n. 制服；校服
- **词根·渊源**：拉丁 **unus**（一）+ **forma**（形状）→ 拉丁 *uniformis*（同一形状的）→ 法语 *uniforme* → 英语 uniform；本义“形式统一的”，引申为“制服”。
- **同根词**：unify（**uni-** 一 + fy 使 = 使统一）、union（uni 一 + **-on** 名词后缀 = 联合、工会）、unique（uni 一 + **-que** …的 = 唯一的）、form（forma 形状 = 形状、形式）、reform（**re-** 再 + form 形状 = 再塑形→改革）、uniformity（uniform + **-ity** 名词后缀 = 一致性）。
- **前缀·后缀**：前缀 **uni-**（例：unify, unique）；名词后缀 **-ity**（例：activity, ability）。
- **同义·反义**：同义 outfit（服装）, costume（服装）；反义 无。
- **变形**：名词 → 复数：uniforms；形容词派生 → uniform adj. 统一的；副词派生 → uniformly adv. 一致地；名词派生 → uniformity n. 一致性。

### 18. personality /ˌpɜːsəˈnæləti/ n. 性格；个性
- **词根·渊源**：拉丁 **persona**（面具、角色）→ 拉丁 *personalitas* → 英语 personality；本义“面具所代表的角色”，引申为“人的性格、个性”。
- **同根词**：person（persona 面具 = 人）、personal（person + **-al** …的 = 个人的）、personally（personal + **-ly** 副词后缀 = 亲自地）、personify（person + **-ify** 使…化 = 使人格化、体现）、personnel（person + **-el** 名词后缀 = 全体人员）。
- **前缀·后缀**：名词后缀 **-ality**（例：reality, nationality）；形容词后缀 **-al**（例：natural, national）。
- **同义·反义**：同义 character（性格）, nature（本性）；反义 无。
- **变形**：名词 → 复数：personalities；形容词派生 → personal adj. 个人的；副词派生 → personally adv. 亲自地；动词派生 → personify v. 体现、人格化。

### 19. characteristic /ˌkærəktəˈrɪstɪk/ n. 特点；品质
- **词根·渊源**：希腊 **kharakter**（刻印的记号、特征）→ 拉丁 *characteristicus* → 英语；本义“刻下的标记”，引申为“区别于他物的特征、品质”。
- **同根词**：character（kharakter 刻印→性格、特征）、characterize（character + **-ize** 使……化 = 刻画特征→描述……的特性）、characteristically（characteristic + **-ally** 以……方式地→典型地）。
- **前缀·后缀**：形容词后缀 **-istic**（例：artistic, realistic）；名词后缀 **-ic**（例：music, magic）。
- **同义·反义**：同义 feature（特征）, trait（品质）；反义 无。
- **变形**：名词 → 复数：characteristics；形容词 → 无比较级（关系形容词，不作比较）；副词派生 → characteristically adv. 典型地。

### 20. topic /ˈtɒpɪk/ n. 话题；标题
- **词根·渊源**：希腊 **topos**（地方）→ 拉丁 *topica*（论题，亚里士多德书名）→ 英语；本义“所在地”，引申为“论述所围绕的题目、话题”。
- **同根词**：topical（topic + **-al** ……的 = 话题的→时事的）、topography（topo 地方 + **-graphy** 写 = 地方志→地形学）、topicality（topical + **-ity** 性质→时事性）。
- **前缀·后缀**：名词后缀 **-ic**（例：music, magic）；形容词后缀 **-al**（例：natural, personal）。
- **同义·反义**：同义 subject（主题）, theme（题目）；反义 无。
- **变形**：名词 → 复数：topics；形容词派生 → topical adj. 话题的、时事的；副词派生 → topically adv. 就话题而言地。

### 21. active /ˈæktɪv/ adj. 忙碌的；活跃的
- **词根·渊源**：拉丁 **agere / act-**（做、驱动）→ 拉丁 *activus* → 英语；本义“正在做事的”，引申为“活跃的、忙碌的”。
- **同根词**：act（act 做→行动）、action（act + **-ion** 行为→行动）、actor（act + **-or** 做的人→演员）、react（**re-** 回 + act 做 = 回做→反应）、exact（**ex-** 出 + act 做 = 做出精确的→精确的）、agenda（ag 做 + **-enda** 应做之事→议程）。
- **前缀·后缀**：形容词后缀 **-ive**（例：creative, native）；前缀 **re-**（例：react）、**ex-**（例：export）。
- **同义·反义**：同义 busy（忙碌的）, lively（活跃的）；反义 inactive（不活跃的）, passive（被动的）。
- **变形**：形容词 → 比较级：more active；最高级：most active；名词派生 → activity n. 活动；副词派生 → actively adv. 活跃地。

### 22. smartphone /ˈsmɑːtfəʊn/ n. 智能手机
- **词根·渊源**：**smart**（聪明的，古英语 *smeortan* 刺痛→机敏的）+ **phone**（希腊 *phōnē* 声音→电话）复合而成；本义“聪明的电话”，即“智能手机”。
- **同根词**：phone（phōnē 声音→电话）、telephone（tele 远 + phone 声音 = 远传声→电话）、smart（古英语 smeortan 刺痛→机敏的→智能的）、smartly（smart + **-ly** ……地→机敏地）。
- **前缀·后缀**：复合词无前后缀（smart + phone 复合）；相关后缀 **-ly**（例：quickly, badly）。
- **同义·反义**：同义 mobile phone（手机）, cell phone（手机）；反义 无。
- **变形**：名词 → 复数：smartphones；形容词派生 → smartphone-like adj. 类似智能手机的。

### 23. wisely /ˈwaɪzli/ adv. 聪明地；明智地
- **词根·渊源**：古英语 **wīs**（有智慧的）→ 形容词 wise + 副词后缀 **-ly**；本义“以有智慧的方式”，即“明智地”。
- **同根词**：wise（古英语 wīs 有智慧的→明智的）、wisdom（wise + **-dom** 状态 = 智慧状态→智慧）、unwise（**un-** 不 + wise = 不明智的）、wizard（wise + **-ard** 人 = 智者→巫师）。
- **前缀·后缀**：副词后缀 **-ly**（例：quickly, bravely）；否定前缀 **un-**（例：unhappy, unfair）。
- **同义·反义**：同义 cleverly（聪明地）, sensibly（明智地）；反义 foolishly（愚蠢地）, unwisely（不明智地）。
- **变形**：副词 → 比较级：more wisely；最高级：most wisely；形容词派生 → wise adj. 明智的；名词派生 → wisdom n. 智慧。

### 24. competition /ˌkɒmpəˈtɪʃn/ n. 比赛；竞赛
- **词根·渊源**：拉丁 **petere**（追求、寻求）→ 拉丁 *competere*（共同追求）→ 拉丁 *competitio* → 英语；本义“一起追求同一目标”，引申为“竞争、比赛”。
- **同根词**：compete（**com-** 共同 + pet 追求 = 共同追求→竞争）、competitor（compete + **-itor** 人→竞争者）、competitive（compete + **-itive** ……的→有竞争力的）、appetite（**ad-** 向 + pet 追求 = 追求食欲→食欲）、petition（pet 追求 + **-ition** 行为→请愿）。
- **前缀·后缀**：前缀 **com-**（例：combine, compare）；名词后缀 **-ition**（例：condition, addition）。
- **同义·反义**：同义 contest（竞赛）, match（比赛）；反义 cooperation（合作）。
- **变形**：名词 → 复数：competitions；动词派生 → compete v. 竞争；形容词派生 → competitive adj. 有竞争力的；副词派生 → competitively adv. 竞争地。

### 25. shower /ˈʃaʊə(r)/ n. 淋浴
- **词根·渊源**：古英语 **scūr**（阵雨、急降）→ 中古英语 *shour* → 英语；本义“阵雨”，引申为“像阵雨般喷洒的淋浴”。
- **同根词**：shower 的动词形式 shower（阵雨→淋浴→大量给予）、showery（shower + **-y** 多……的 = 多阵雨的→阵雨般的）。
- **前缀·后缀**：名词后缀 **-er**（例：worker, teacher）；形容词后缀 **-y**（例：rainy, windy）。
- **同义·反义**：同义 bath（洗澡）, rain（阵雨）；反义 无。
- **变形**：名词 → 复数：showers；动词 → 第三人称单数：showers；过去式：showered；过去分词：showered；现在分词：showering；形容词派生 → showery adj. 阵雨般的。

### 26. online /ˈɒnˈlaɪn/ adj. 在线的
- **词根·渊源**：**on**（在……上）+ **line**（线，拉丁 *linea* 亚麻线→线）复合；本义“在线上”，引申为“联网的、在线的”。
- **同根词**：line（linea 线→线）、linear（line + **-ar** ……的 = 线的→线性的）、outline（**out-** 外 + line 线 = 外轮廓→大纲）、offline（**off-** 离 + line 线 = 离线→脱机的）。
- **前缀·后缀**：复合词无前后缀（on + line 复合）；相关前缀 **out-**（例：outside, outdoor）。
- **同义·反义**：同义 connected（联网的）, networked（联网的）；反义 offline（离线的）。
- **变形**：形容词 → 无比较级（关系形容词，不作比较）；副词派生 → online adv. 在线地。

### 27. site /saɪt/ n. 建筑工地
- **词根·渊源**：拉丁 **situs**（位置、地点）→ 古法语 *site* → 英语；本义“所在地”，引申为“建筑工地、场所”。
- **同根词**：situate（situs 位置 + **-ate** 使…… = 使处于位置→使位于）、situation（situate + **-ion** 状态→位置、形势）、situated（situate + **-ed** ……的→位于……的）。
- **前缀·后缀**：名词后缀 **-ion**（例：action, nation）；动词后缀 **-ate**（例：create, calculate）。
- **同义·反义**：同义 location（地点）, place（地方）；反义 无。
- **变形**：名词 → 复数：sites；动词派生 → situate v. 使位于；名词派生 → situation n. 位置、形势。

### 28. narrow /ˈnærəʊ/ adj. 狭窄的；窄小的
- **词根·渊源**：古英语 **nearu**（狭窄的、紧的）→ 中古英语 *narwe* → 英语；本义“紧的、狭窄的”，现义不变。
- **同根词**：narrowly（narrow + **-ly** ……地 = 狭窄地→勉强地）、narrowness（narrow + **-ness** 性质 = 狭窄性质→狭窄）、narrow-minded（narrow + mind + **-ed** 有……的 = 心胸狭窄的→狭隘的）。
- **前缀·后缀**：副词后缀 **-ly**（例：quickly, badly）；名词后缀 **-ness**（例：kindness, darkness）。
- **同义·反义**：同义 tight（紧的）, thin（细的）；反义 wide（宽的）, broad（宽阔的）。
- **变形**：形容词 → 比较级：narrower；最高级：narrowest；动词 → 第三人称单数：narrows；过去式：narrowed；过去分词：narrowed；现在分词：narrowing；名词派生 → narrowness n. 狭窄；副词派生 → narrowly adv. 狭窄地、勉强地。

### 29. superman /ˈsuːpəmæn/ n. 超人
- **词根·渊源**：拉丁 **super**（在上、超过）+ 古英语 **mann**（人）复合；本义“超越常人的人”，即“超人”。
- **同根词**：super（super 在上→超级的）、superb（super + **-b** 出众的→极好的）、superior（super + **-ior** 较……的 = 在上方的→优越的）、supermarket（super 超级 + market 市场 = 超级市场）、man（古英语 mann 人→男人、人）。
- **前缀·后缀**：前缀 **super-**（例：supermarket, superstar）；复合词无后缀（super + man 复合）。
- **同义·反义**：同义 hero（英雄）, superhuman（超人）；反义 无。
- **变形**：名词 → 复数：supermen（不规则复数）；形容词派生 → superhuman adj. 超人的。
