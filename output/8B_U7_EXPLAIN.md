## 二、逐词说文解字

### 1. beef /bif/ n. 牛肉
- **词根·渊源**：拉丁 **bos / bov-**（牛）→ 古法语 *boef*（牛）→ 英语 beef，本义“牛”，后专指“牛肉”；与 cow 同出印欧语牛类词根，但 beef 走的是法语借词路线。
- **同根词**：bovine（**bov-** 牛 + **-ine** …的：牛的）、bovine（同上，形容词“牛一般的”）、bucolic（希腊 **bou-** 牛 + **-col-** 耕种 + **-ic**：牧牛的→田园的）。
- **前缀·后缀**：无前后缀（单纯词）。
- **同义·反义**：同义 cattle meat（牛肉，少用）, cow meat（牛肉，口语少用）；反义 无。
- **变形**：名词 → 复数：beefs（作“牛肉”义时不可数）；形容词派生 → beefy adj. 牛肉般的、结实的。

### 2. seafood /ˈsiˌfud/ n. 海鲜
- **词根·渊源**：**sea**（海）+ **food**（食物）复合而成，字面“海里的食物”，即“海鲜”；sea 出自古英语 *sǣ*，food 出自古英语 *fōda*。
- **同根词**：seaside（sea 海 + side 边：海边）、seaman（sea 海 + man 人：海员）、seawater（sea 海 + water 水：海水）、foodstuff（food 食物 + stuff 材料：食品原料）。
- **前缀·后缀**：无前后缀（复合词）。
- **同义·反义**：同义 marine food（海产食品）, shellfish（贝类海鲜）；反义 无。
- **变形**：名词 → 复数：seafoods（作“海鲜”义时通常不可数）；形容词派生 → seafoody adj. 海鲜味的（少用）。

### 3. afford /əˈfɔrd/ v. 承担得起（后果）
- **词根·渊源**：古英语 *geforðian*（推进、提供）→ 中古英语 *aforthen*，**a-**（加强）+ **forth**（向前）→ 本义“拿出、提供”，引申为“负担得起、承担得起”。
- **同根词**：forth（向前：同源副词）、forward（**for-** 前 + **-ward** 向：向前）、further（更远：forth 的比较级形式）。
- **前缀·后缀**：前缀 **a-**（例：arise, awake）。
- **同义·反义**：同义 bear（承担）, manage（设法做到）；反义 无。
- **变形**：动词 → 第三人称单数：affords；过去式：afforded；过去分词：afforded；现在分词：affording；形容词派生 → affordable adj. 负担得起的；名词派生 → affordability n. 可负担性。

### 4. mistake /mɪˈsteɪk/ n. 错误；失误
- **词根·渊源**：古诺斯语 *mistaka*（拿错）→ 中古英语，**mis-**（错）+ **take**（拿）→ 本义“拿错、误解”，引申为“错误、失误”。
- **同根词**：take（拿：基础动词）、mistaken（mistake + **-en** 过去分词：弄错的）、misunderstand（**mis-** 错 + understand 理解：误解）、misuse（**mis-** 错 + use 用：误用）。
- **前缀·后缀**：前缀 **mis-**（例：mislead, misplace）。
- **同义·反义**：同义 error（错误）, fault（过错）；反义 correctness（正确）, accuracy（准确）。
- **变形**：名词 → 复数：mistakes；动词 → 第三人称单数：mistakes；过去式：mistook；过去分词：mistaken；现在分词：mistaking；形容词派生 → mistaken adj. 错误的；副词派生 → mistakenly adv. 错误地。

### 5. stick /stɪk/ v. 粘；贴
- **词根·渊源**：古英语 *stician*（刺、扎）→ 中古英语 sticken，本义“刺入、扎住”，由“扎住使固定”引申为“粘住、贴住”。
- **同根词**：sticky（stick + **-y** …的：粘的）、sticker（stick + **-er** 物：贴纸）、stickiness（sticky + **-ness** 名词：粘性）、stuck（stick 的过去分词：卡住的）。
- **前缀·后缀**：无前后缀（单纯词）。
- **同义·反义**：同义 adhere（粘附）, attach（贴上）；反义 detach（分离）, loosen（松开）。
- **变形**：动词 → 第三人称单数：sticks；过去式：stuck；过去分词：stuck；现在分词：sticking；名词派生 → sticker n. 贴纸；形容词派生 → sticky adj. 粘的。

### 6. hit /hɪt/ v. 碰撞；撞击
- **词根·渊源**：古英语 *hyttan*（遇见、撞击）→ 中古英语 hitten，本义“碰上、打中”，引申为“碰撞、撞击”；词源细节存疑。
- **同根词**：hitter（hit + **-er** 人：击打者）、hit-and-run（hit 撞 + and 和 + run 跑：肇事逃逸的）、hitman（hit 打击 + man 人：职业杀手）。
- **前缀·后缀**：无前后缀（单纯词）。
- **同义·反义**：同义 strike（击打）, knock（碰撞）；反义 miss（错过）, avoid（避开）。
- **变形**：动词 → 第三人称单数：hits；过去式：hit；过去分词：hit；现在分词：hitting；名词 → 复数：hits；名词派生 → hitter n. 击打者。

### 7. muscle /ˈməsəl/ n. 肌肉
- **词根·渊源**：拉丁 **musculus**（小老鼠）→ 古法语 *muscle* → 英语，本义“小老鼠”，因肌肉收缩时形似小老鼠而得名，引申为“肌肉”。
- **同根词**：muscular（muscle + **-ar** …的：肌肉的）、musculature（muscle + **-ature** 集合名词：肌肉系统）、musculoskeletal（musculo- 肌肉 + skeletal 骨骼的：肌肉骨骼的）。
- **前缀·后缀**：名词后缀 **-le**（例：bottle, handle）。
- **同义·反义**：同义 sinew（肌腱，近义）, brawn（肌肉，壮实）；反义 无。
- **变形**：名词 → 复数：muscles；形容词派生 → muscular adj. 肌肉的、强壮的；名词派生 → musculature n. 肌肉系统。

### 8. gym /ʤɪm/ n. 健身房
- **词根·渊源**：希腊 **gymnós**（裸体的）→ 拉丁 *gymnasium* → 希腊 *gymnasion*（裸体锻炼的场所）→ 英语 gymnasium 的缩略形式 gym，本义“裸体训练场”，引申为“健身房”。
- **同根词**：gymnasium（gymn- 裸体 + **-asium** 场所：体育馆）、gymnast（gymn- 裸体 + **-ast** 人：体操运动员）、gymnastics（gymnast + **-ics** 学科：体操）。
- **前缀·后缀**：无前后缀（缩略词）。
- **同义·反义**：同义 fitness center（健身中心）, health club（健身俱乐部）；反义 无。
- **变形**：名词 → 复数：gyms；形容词派生 → gymless adj. 无健身房的（少用）。

### 9. satellite /ˈsætəˌlaɪt/ n. 人造卫星
- **词根·渊源**：拉丁 **satelles / satellit-**（随从、卫兵）→ 法语 *satellite* → 英语，本义“随从”，17世纪用于“行星的卫星”，20世纪引申为“人造卫星”。
- **同根词**：satellitic（satellite + **-ic** …的：卫星的）、satellites（satellite 的复数形式：卫星们）、satelloid（satellite + **-oid** 似…的：准卫星）。
- **前缀·后缀**：名词后缀 **-ite**（例：favorite, granite）。
- **同义·反义**：同义 moon（卫星，天体）, spacecraft（航天器，近义）；反义 无。
- **变形**：名词 → 复数：satellites；形容词派生 → satellitic adj. 卫星的。

### 10. destroy /dɪˈstrɔɪ/ v. 摧毁
- **词根·渊源**：拉丁 **de-**（向下、相反）+ **struere**（建造）→ 拉丁 *destruere*（拆毁）→ 古法语 *destruire* → 英语，本义“拆掉建造之物”，引申为“摧毁”。
- **同根词**：destruction（**de-** 相反 + **struct-** 建造 + **-ion** 名词：破坏）、destructive（**de-** + **struct-** + **-ive** …的：破坏性的）、construct（**con-** 一起 + **struct-** 建造：建造）、structure（**struct-** 建造 + **-ure** 名词：结构）、instruct（**in-** 在内 + **struct-** 建造：指导）。
- **前缀·后缀**：前缀 **de-**（例：decrease, decode）；动词后缀 **-oy**（例：enjoy, annoy）。
- **同义·反义**：同义 ruin（毁坏）, demolish（拆毁）；反义 build（建造）, create（创造）。
- **变形**：动词 → 第三人称单数：destroys；过去式：destroyed；过去分词：destroyed；现在分词：destroying；名词派生 → destruction n. 破坏；形容词派生 → destructive adj. 破坏性的。

### 11. average /ˈævərɪʤ/ adj. 平均的
- **词根·渊源**：阿拉伯语 **ʿawāriyya**（损坏的货物）→ 意大利语 *avaria*（海损）→ 法语 *avarie* → 英语 average，本义“海损分摊”，引申为“平均分摊→平均的”。
- **同根词**：averagely（average + **-ly** 副词：平均地）、averageness（average + **-ness** 名词：平均状态）、averaging（average + **-ing** 名词/形容词：平均化）。
- **前缀·后缀**：形容词后缀 **-age**（例：courage, village）。
- **同义·反义**：同义 mean（平均的）, ordinary（普通的）；反义 exceptional（异常的）, extraordinary（非凡的）。
- **变形**：形容词 → 比较级：more average；最高级：most average；名词 → 复数：averages；动词 → 第三人称单数：averages；过去式：averaged；过去分词：averaged；现在分词：averaging；副词派生 → averagely adv. 平均地。

### 12. probable /ˈprɑbəbəl/ adj. 很可能发生（或存在等）的
- **词根·渊源**：拉丁 **probare**（检验、证明）→ 拉丁 *probabilis*（可证明的）→ 古法语 *probable* → 英语，本义“可验证的”，引申为“很可能的”。
- **同根词**：probably（probable + **-ly** 副词：很可能）、probability（probable + **-ity** 名词：可能性）、probation（**prob-** 检验 + **-ation** 名词：试用期）、prove（**prob-** 检验：证明）、proof（**prob-** 检验：证据）。
- **前缀·后缀**：形容词后缀 **-able**（例：comfortable, readable）。
- **同义·反义**：同义 likely（可能的）, possible（可能的）；反义 improbable（不可能的）, unlikely（不太可能的）。
- **变形**：形容词 → 比较级：more probable；最高级：most probable；副词派生 → probably adv. 很可能；名词派生 → probability n. 可能性。

### 13. select /səˈlɛkt/ v. 挑选；选拔
- **词根·渊源**：拉丁 **se-**（分开）+ **legere**（挑选、读）→ 拉丁 *selectus* → 英语，本义“挑出来”，即“挑选、选拔”。
- **同根词**：selection（select + **-ion** 名词：选择）、selective（select + **-ive** …的：选择性的）、elect（**e-** 出 + **lect-** 选：选举）、collect（**col-** 一起 + **lect-** 选/收：收集）、lecture（**lect-** 读 + **-ure** 名词：讲座）。
- **前缀·后缀**：前缀 **se-**（例：separate, secure）；词根 **-lect-**（例：collect, elect）。
- **同义·反义**：同义 choose（选择）, pick（挑选）；反义 reject（拒绝）, refuse（拒绝）。
- **变形**：动词 → 第三人称单数：selects；过去式：selected；过去分词：selected；现在分词：selecting；名词派生 → selection n. 选择；形容词派生 → selective adj. 选择性的；副词派生 → selectively adv. 选择性地。

### 14. spaceflight /spe sfla t/ n. 航天；宇宙飞行
- **词根·渊源**：**space**（空间、太空）+ **flight**（飞行）复合而成，字面“太空飞行”，即“航天”；space 出自拉丁 *spatium*，flight 出自古英语 *flyht*。
- **同根词**：spacecraft（space 太空 + craft 船：航天器）、spaceman（space 太空 + man 人：宇航员）、flightless（flight 飞行 + **-less** 无：不能飞的）、spacewalk（space 太空 + walk 走：太空行走）。
- **前缀·后缀**：无前后缀（复合词）。
- **同义·反义**：同义 space travel（太空旅行）, space navigation（航天导航）；反义 无。
- **变形**：名词 → 复数：spaceflights；形容词派生 → spaceflight-related adj. 与航天有关的（复合派生）。

### 15. serve /sərv/ v. 为……工作；服务
- **词根·渊源**：拉丁 **servus**（奴隶）→ 拉丁 *servire*（服侍）→ 古法语 *servir* → 英语，本义“像仆人一样服侍”，引申为“服务、为……工作”。
- **同根词**：service（serv- 服务 + **-ice** 名词：服务）、servant（serv- 服务 + **-ant** 人：仆人）、servile（serv- 奴隶 + **-ile** …的：奴性的）、deserve（**de-** 加强 + serv- 服务：应得）、servitude（serv- 奴隶 + **-itude** 名词：奴役）。
- **前缀·后缀**：无前后缀（单纯词）。
- **同义·反义**：同义 work for（为……工作）, assist（协助）；反义 无。
- **变形**：动词 → 第三人称单数：serves；过去式：served；过去分词：served；现在分词：serving；名词派生 → service n. 服务；servant n. 仆人；形容词派生 → servile adj. 奴性的。

### 16. deliver /dɪˈlɪvər/ v. 传送；运载
- **词根·渊源**：拉丁 **de-**（离开）+ **liberare**（使自由）→ 古法语 *delivrer*（释放、交出）→ 英语，本义“释放、交出”，引申为“传送、运载”。
- **同根词**：delivery（deliver + **-y** 名词：递送）、deliverance（deliver + **-ance** 名词：解救）、liberate（**liber-** 自由 + **-ate** 动词：解放）、liberty（**liber-** 自由 + **-ty** 名词：自由）。
- **前缀·后缀**：前缀 **de-**（例：depart, decline）；动词后缀 **-er**（例：recover, suffer）。
- **同义·反义**：同义 transport（运输）, convey（传送）；反义 receive（接收）, withhold（扣留）。
- **变形**：动词 → 第三人称单数：delivers；过去式：delivered；过去分词：delivered；现在分词：delivering；名词派生 → delivery n. 递送；deliverance n. 解救。

### 17. fuel /fjuəl/ n. 燃料
- **词根·渊源**：拉丁 **focus**（炉灶、火）→ 古法语 *fouaille*（柴火）→ 英语 fuel，本义“炉火用的柴”，引申为“燃料”。
- **同根词**：fueling（fuel + **-ing** 名词：加燃料）、fueled（fuel + **-ed** 形容词：有燃料的）、focal（**foc-** 炉灶/焦点 + **-al** …的：焦点的）、focus（**foc-** 炉灶→焦点：焦点）。
- **前缀·后缀**：无前后缀（单纯词）。
- **同义·反义**：同义 combustible（可燃物）, energy source（能源）；反义 无。
- **变形**：名词 → 复数：fuels；动词 → 第三人称单数：fuels；过去式：fueled；过去分词：fueled；现在分词：fueling；形容词派生 → fueled adj. 有燃料的。

### 18. supply /səˈplaɪ/ n. 供应量；供给量
- **词根·渊源**：拉丁 **supplere**（填满、补足）→ 古法语 *suppleer* → 英语 supply，**sup-**（在下、补充）+ **plere**（填满），本义“补足”，引申为“供应、供给量”。
- **同根词**：supplement（**sup-** 补充 + **ple-** 填满 + **-ment** 名词：补充物）、complete（**com-** 完全 + **ple-** 填满：完整的）、plenty（**ple-** 填满 + **-ty** 名词：充足）、deplete（**de-** 去除 + **ple-** 填满：耗尽）。
- **前缀·后缀**：前缀 **sup-**（例：support, suppose）；名词后缀 **-ly**（例：ally, assembly）。
- **同义·反义**：同义 provision（供应）, stock（储备）；反义 demand（需求）, shortage（短缺）。
- **变形**：名词 → 复数：supplies；动词 → 第三人称单数：supplies；过去式：supplied；过去分词：supplied；现在分词：supplying；名词派生 → supplier n. 供应商。

### 19. point /pɔɪnt/ n. 时刻；阶段
- **词根·渊源**：拉丁 **punctum**（刺出的小孔、点）→ 古法语 *point* → 英语 point；本义“刺出的点”，引申为“时间上的一个点”，即“时刻；阶段”。
- **同根词**：punctual（punct 点 + **-ual** …的 = 守时的）、punctuate（punct 点 + **-uate** 动词后缀 = 加标点）、puncture（punct 刺 + **-ure** 名词后缀 = 刺孔→扎破）、pungent（拉丁 pungere 刺 + **-ent** …的 = 刺鼻的）、compunction（**com-** 加强 + punct 刺 = 内心被刺→内疚）、expunge（**ex-** 出 + pung 刺 = 刺掉→删除）。
- **前缀·后缀**：无前缀；名词兼动词后缀 **-ment** 见于同族（例：punctuation, appointment）。
- **同义·反义**：同义 moment（时刻）, stage（阶段）；反义 无。
- **变形**：名词 → 复数：points；动词 → 第三人称单数：points；过去式：pointed；过去分词：pointed；现在分词：pointing；形容词派生 → pointed adj. 尖的；副词派生 → pointedly adv. 尖锐地。

### 20. lab /læb/ n. 实验室
- **词根·渊源**：laboratory 的缩略口语形式；拉丁 **laborare**（劳作）→ 中世纪拉丁 *laboratorium*（劳作之处）→ 英语 laboratory → 缩略 lab；本义“做实验工作的地方”，即“实验室”。
- **同根词**：laboratory（labor 劳作 + **-atory** 场所 = 实验室）、labor（拉丁 labor 劳作 = 劳动）、laborious（labor 劳作 + **-ious** …的 = 费力的）、elaborate（**e-** 出 + labor 劳作 = 费力做出→精心制作的）、collaborate（**col-** 共同 + labor 劳作 = 合作）、laborer（labor 劳作 + **-er** 人 = 劳动者）。
- **前缀·后缀**：缩略后缀 **-y** 见于原词（例：library, factory）；前缀 **col-**（例：collect）、**e-**（例：elect）。
- **同义·反义**：同义 laboratory（实验室）, research room（研究室）；反义 无。
- **变形**：名词 → 复数：labs；形容词派生 → lab-based adj. 基于实验室的。
