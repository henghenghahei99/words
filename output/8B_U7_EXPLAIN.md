## 二、逐词说文解字

### 1. unknown /ˌʌnˈnoʊn/ adj. 未知的；陌生的，默默无闻的
- **词根·渊源**：古英语 **cnāwan**（知道）→ 过去分词 *cnāwen* → 中古英语 *unknowen*；由否定前缀 **un-**（不）+ know 的过去分词 known（已知的）构成，本义“不被知道的”，引申为“陌生的、默默无闻的”。
- **同根词**：know（古英语 cnāwan 知道→知道）、known（know + **-n** 过去分词→已知的）、knowledge（know + **-ledge** 名词后缀→知识）、acknowledge（**ac-** 加强 + knowledge 知道 = 承认知道→承认）、unknown 本身不再列。
- **前缀·后缀**：否定前缀 **un-**（例：unhappy, untrue）；过去分词后缀 **-n**（例：known, grown）。
- **同义·反义**：同义 unfamiliar（不熟悉的）, obscure（无名的）；反义 known（已知的）, famous（著名的）。
- **变形**：形容词 → 无比较级（由分词转化，不作比较）；名词派生 → unknown n. 未知事物（the unknown 未知领域）。

### 2. alien /ˈeɪliən/ n. 外星人
- **词根·渊源**：拉丁 **aliēnus**（别人的、外来的）← *alius*（其他的）→ 古法语 *alien* → 英语；本义“外邦人、外来者”，20 世纪科幻语境中引申为“外星人”。
- **同根词**：alienate（alien + **-ate** 动词后缀 = 使成为外人→使疏远）、alienation（alienate + **-ion** 名词后缀→疏远）、alias（拉丁 alius 其他 + **-as** → 别名）、alibi（拉丁 alius 其他 + ibi 在那里 = 在别处→不在场证明）。
- **前缀·后缀**：形容词/名词后缀 **-en**（例：citizen, heathen）；动词后缀 **-ate**（例：activate, separate）。
- **同义·反义**：同义 extraterrestrial（外星生物）, foreigner（外国人）；反义 native（本地人）, citizen（公民）。
- **变形**：名词 → 复数：aliens；形容词派生 → alien adj. 外来的、陌生的；动词派生 → alienate v. 使疏远；名词派生 → alienation n. 疏远。

### 3. astronaut /ˈæstrəˌnɔt/ n. 宇航员；航天员
- **词根·渊源**：希腊 **astron**（星星）+ **nautēs**（水手）→ 法语 *astronaute* → 英语；本义“星际水手”，即“航行于星海的人→宇航员”。
- **同根词**：astronomy（astron 星 + **-nomy** 法则→天文学）、astronaut 本身不再列、asteroid（aster 星 + **-oid** 像…的→小行星）、disaster（**dis-** 坏 + aster 星 = 星位不正→灾难）、nautical（naut 水手 + **-ical** …的→航海的）、cosmonaut（cosmo 宇宙 + naut 水手→宇航员）。
- **前缀·后缀**：组合形式 **astro-**（例：astrology, astrophysics）；名词后缀 **-naut**（例：cosmonaut, aquanaut）。
- **同义·反义**：同义 spaceman（太空人）, cosmonaut（宇航员）；反义 无。
- **变形**：名词 → 复数：astronauts；形容词派生 → astronautical adj. 航天的。

### 4. receive /rɪˈsiːv/ v. 收到，得到，接到
- **词根·渊源**：拉丁 **recipere**（取回）← **re-**（回）+ **capere**（拿、抓）→ 古北法语 *receivre* → 英语；本义“把东西拿回来→接到、收到”。
- **同根词**：receipt（re + ceipt←capere 拿 = 拿到的凭据→收据）、reception（re + cept 拿 + **-ion** 名词后缀→接待）、recipient（re + cip 拿 + **-ient** 人→接受者）、capture（capt 抓 + **-ure** → 捕获）、accept（**ac-** 向 + cept 拿 = 拿到自己这边→接受）、conceive（**con-** 共同 + ceive 拿 = 拿到一起孕育→构想）。
- **前缀·后缀**：前缀 **re-**（例：return, recall）；动词后缀 **-ceive**（例：conceive, deceive）。
- **同义·反义**：同义 get（得到）, obtain（获得）；反义 send（发送）, give（给予）。
- **变形**：动词 → 第三人称单数：receives；过去式：received；过去分词：received；现在分词：receiving；名词派生 → receiver n. 接收者、听筒；reception n. 接待；形容词派生 → receptive adj. 乐于接受的。

### 5. hill /hɪl/ n. 山丘：小山
- **词根·渊源**：古英语 **hyll**（山丘）→ 中古英语 *hill* → 英语；与拉丁 *collis*（山丘）、*culmen*（顶）同出 PIE *kel-*（高起），本义即“隆起的高地→小山”。
- **同根词**：hilly（hill + **-y** 多…的→多小山的）、hilltop（hill + top 顶→山顶）、foothill（foot 脚 + hill = 山脚的小丘→山麓）、downhill（down 向下 + hill = 向山下→下坡的）。
- **前缀·后缀**：名词后缀 **-y** 构成形容词（例：rainy, sandy）；无前缀。
- **同义·反义**：同义 mound（土丘）, hillock（小丘）；反义 valley（山谷）, plain（平原）。
- **变形**：名词 → 复数：hills；形容词派生 → hilly adj. 多小山的。

### 6. aloud /əˈlaʊd/ adv. 大声地；响亮的；高声地
- **词根·渊源**：古英语 **hlūd**（响亮的）→ 中古英语 *loud*；由 **a-**（在…状态，源自 on）+ loud（响亮的）构成，本义“以响亮的方式→出声地、大声地”。
- **同根词**：loud（古英语 hlūd 响亮的→大声的）、loudly（loud + **-ly** 副词后缀→大声地）、loudness（loud + **-ness** 名词后缀→响亮）、loudspeaker（loud + speaker 说话器→扬声器）。
- **前缀·后缀**：副词性前缀 **a-**（例：abroad, asleep）；无后缀（aloud 本身即副词）。
- **同义·反义**：同义 loudly（大声地）, audibly（可听见地）；反义 quietly（安静地）, silently（无声地）。
- **变形**：副词 → 无比较级（方式副词，不作比较）；无词性派生（aloud 仅作副词）。

### 7. explore /ɪkˈsplɔːr/ v. 探讨，探究；考察，探索
- **词根·渊源**：拉丁 **explorare**（探查、侦察）← **ex-**（出）+ **plorare**（喊叫，原指猎人呼喝驱赶）→ 古法语 *explorer* → 英语；本义“喊叫着搜出猎物→探查→探索、探究”。
- **同根词**：exploration（explore + **-ation** 名词后缀→探索）、explorer（explore + **-er** 人→探险者）、exploratory（explore + **-atory** …的→探索性的）、deplore（**de-** 向下 + plor 哭喊 = 哀哭→悲叹）、implore（**im-** 向内 + plor 喊 = 向里呼喊→恳求）。
- **前缀·后缀**：前缀 **ex-**（例：export, exit）；动词后缀 **-plore**（例：implore, deplore）。
- **同义·反义**：同义 investigate（调查）, search（搜寻）；反义 ignore（忽视）, neglect（忽略）。
- **变形**：动词 → 第三人称单数：explores；过去式：explored；过去分词：explored；现在分词：exploring；名词派生 → exploration n. 探索；explorer n. 探险者；形容词派生 → exploratory adj. 探索性的。

### 8. bush /bʊʃ/ n. 灌木；灌木丛
- **词根·渊源**：古英语 **bysc**（灌木丛）→ 中古英语 *busk* / *bush* → 英语；与古诺斯语 *buskr* 同源，本义即“丛生的矮树→灌木、灌木丛”。
- **同根词**：bushy（bush + **-y** 多…的→灌木茂密的）、bushland（bush + land 地→灌木地）、bushfire（bush + fire 火→丛林大火）、ambush（**am-**←in 进入 + bush 灌木 = 藏进灌木丛→伏击）。
- **前缀·后缀**：名词后缀 **-y** 构成形容词（例：leafy, woody）；前缀 **am-**（例：ambush 仅此常见）。
- **同义·反义**：同义 shrub（灌木）, thicket（灌木丛）；反义 tree（树）。
- **变形**：名词 → 复数：bushes；形容词派生 → bushy adj. 灌木茂密的。

### 9. quiet /ˈkwaɪət/ adj. 安静的；寂静的
- **词根·渊源**：拉丁 **quietus**（安静的，*quiescere* 休息的过去分词）← *quies*（休息）→ 古法语 *quiet* → 英语；本义“处于休息状态的→安静的、寂静的”。
- **同根词**：quietly（quiet + **-ly** 副词后缀→安静地）、quietness（quiet + **-ness** 名词后缀→安静）、quieten（quiet + **-en** 动词后缀→使安静）、acquit（**ac-** 向 + quit 休息 = 使了结→宣告无罪）、requiem（**re-** 再 + quies 休息 = 安息→安魂曲）、quiescent（quies 休息 + **-escent** 处于…的→静止的）。
- **前缀·后缀**：副词后缀 **-ly**（例：slowly, badly）；动词后缀 **-en**（例：widen, sharpen）。
- **同义·反义**：同义 silent（寂静的）, still（静止的）；反义 noisy（吵闹的）, loud（大声的）。
- **变形**：形容词 → 比较级：quieter；最高级：quietest；副词派生 → quietly adv. 安静地；名词派生 → quietness n. 安静；动词派生 → quieten v. 使安静；本词兼作名词 → 复数：quiets（多不可数）。

### 10. round /raʊnd/ adj. 圆形的；球形的
- **词根·渊源**：拉丁 **rotundus**（圆的）← *rota*（轮子）→ 古法语 *roond* / *round* → 英语；本义“像轮子一样的→圆形的、球形的”。
- **同根词**：around（**a-** 在 + round 圆 = 在周围→围绕）、surround（**sur-** 在上 + round 圆 = 围成圈→包围）、rotund（rot 轮 + **-und** …的→圆胖的）、rotate（rot 轮 + **-ate** 动词后缀→旋转）、roundabout（round + about 周围→迂回的、环岛）。
- **前缀·后缀**：前缀 **a-**（例：around, away）、**sur-**（例：surface, surpass）；形容词后缀 **-und**（例：rotund, jocund）。
- **同义·反义**：同义 circular（圆形的）, spherical（球形的）；反义 square（方形的）, angular（有棱角的）。
- **变形**：形容词 → 比较级：rounder；最高级：roundest；本词兼作名词 → 复数：rounds；兼作动词 → 第三人称单数：rounds；过去式：rounded；过去分词：rounded；现在分词：rounding；副词派生 → roundly adv. 全面地、严厉地。

### 11. damage /ˈdæmɪdʒ/ n. 损害；毁坏；破坏
- **词根·渊源**：拉丁 **damnum**（损失、罚金）→ 古法语 *damage*（损害）→ 英语；本义“造成的损失→损害、毁坏”。
- **同根词**：damn（拉丁 damnum 损失→判罪、咒骂）、condemn（**con-** 加强 + demn←damnum 罚 = 判罚→谴责）、indemnity（**in-** 不 + demn 损失 + **-ity** 名词后缀 = 补偿损失→赔偿）、damages（damage + **-s** 复数→损害赔偿金）。
- **前缀·后缀**：名词后缀 **-age**（例：marriage, package）；前缀 **con-**（例：confirm, connect）。
- **同义·反义**：同义 harm（伤害）, destruction（破坏）；反义 repair（修理）, benefit（益处）。
- **变形**：名词 → 复数：damages（作“损害”义时不可数，作“赔偿金”义可数）；本词兼作动词 → 第三人称单数：damages；过去式：damaged；过去分词：damaged；现在分词：damaging；形容词派生 → damaging adj. 有害的；damaged adj. 受损的。

### 12. crash /kræʃ/ v. 碰撞；相撞；撞车，坠毁；猛撞
- **词根·渊源**：中古英语 **crasschen**（发出撞击声），拟声词，模拟物体碎裂的声响，可能受 *craze*（碎裂）影响；本义“发出碎裂巨响→猛撞、坠毁”。
- **同根词**：crasher（crash + **-er** 人/物→闯入者）、crashing（crash + **-ing** 分词→猛撞的）、crash-land（crash + land 着陆→迫降）、gatecrash（gate 门 + crash 闯入→不请自来）。
- **前缀·后缀**：名词后缀 **-er**（例：worker, teacher）；分词后缀 **-ing**（例：running, falling）。
- **同义·反义**：同义 collide（碰撞）, smash（猛撞）；反义 无。
- **变形**：动词 → 第三人称单数：crashes；过去式：crashed；过去分词：crashed；现在分词：crashing；本词兼作名词 → 复数：crashes；名词派生 → crasher n. 闯入者。

### 13. frightened /ˈfraɪtnd/ adj. 害怕的，受惊的；惊吓的
- **词根·渊源**：古英语 **fyrhto**（恐惧）→ 中古英语 *fright*（惊吓）+ 动词后缀 **-en** 构成 frighten（使害怕）+ **-ed** 过去分词 → frightened；本义“被吓到的→害怕的、受惊的”。
- **同根词**：fright（古英语 fyrhto 恐惧→惊吓）、frighten（fright + **-en** 使…→使害怕）、frightening（frighten + **-ing** …的→令人害怕的）、frightful（fright + **-ful** 充满…的→可怕的）。
- **前缀·后缀**：动词后缀 **-en**（例：widen, strengthen）；过去分词后缀 **-ed**（例：tired, excited）。
- **同义·反义**：同义 scared（害怕的）, terrified（惊恐的）；反义 brave（勇敢的）, fearless（无畏的）。
- **变形**：形容词 → 比较级：more frightened；最高级：most frightened；名词派生 → fright n. 惊吓；动词派生 → frighten v. 使害怕；副词派生 → frighteningly adv. 令人恐惧地。

### 14. discover /dɪˈskʌvər/ v. 发现；找到；发觉
- **词根·渊源**：拉丁 **discooperire**（揭开盖子）← **dis-**（去除）+ **cooperire**（遮盖）→ 古法语 *descovrir* → 英语；本义“揭开覆盖物→显露→发现”。
- **同根词**：discovery（discover + **-y** 名词后缀→发现）、discoverer（discover + **-er** 人→发现者）、cover（拉丁 cooperire 遮盖→覆盖）、recover（**re-** 再 + cover 遮盖 = 重新盖好→恢复）、uncover（**un-** 去除 + cover 遮盖→揭开）。
- **前缀·后缀**：前缀 **dis-**（例：disappear, disagree）；名词后缀 **-y**（例：delivery, bravery）。
- **同义·反义**：同义 find（找到）, detect（察觉）；反义 hide（隐藏）, conceal（隐瞒）。
- **变形**：动词 → 第三人称单数：discovers；过去式：discovered；过去分词：discovered；现在分词：discovering；名词派生 → discovery n. 发现；discoverer n. 发现者。

### 15. terrible /ˈterəbl/ adj. 极坏的；可怕的；非常讨厌的；令人极不快的
- **词根·渊源**：拉丁 **terribilis**（可怕的）← *terrere*（使恐惧）+ **-ibilis**（可…的）→ 古法语 *terrible* → 英语；本义“令人恐惧的→可怕的、极坏的”。
- **同根词**：terror（terr 恐惧 + **-or** 名词后缀→恐怖）、terrify（terr 恐惧 + **-ify** 使…→使恐惧）、terrorist（terror + **-ist** 人→恐怖分子）、deter（**de-** 去除 + terr 恐惧 = 吓退→阻止）、terrific（terr 恐惧 + **-ific** 产生…的，原义“可怕的”，今义“极好的”）。
- **前缀·后缀**：形容词后缀 **-ible**（例：visible, possible）；前缀 **de-**（例：decrease, defend）。
- **同义·反义**：同义 awful（可怕的）, dreadful（可怕的）；反义 wonderful（极好的）, pleasant（令人愉快的）。
- **变形**：形容词 → 比较级：more terrible；最高级：most terrible；副词派生 → terribly adv. 可怕地、非常；名词派生 → terror n. 恐怖；动词派生 → terrify v. 使恐惧。

### 16. fear /fɪə(r)/ v. 害怕；惧怕
- **词根·渊源**：古英语 **fǣr**（突然的灾祸、危险）→ 中古英语 *fere* / *fear*；本义“遭遇的危险”，后转指危险引起的情绪，即“害怕、惧怕”。
- **同根词**：fearful（fear + **-ful** 充满…的→害怕的）、fearless（fear + **-less** 无…的→无畏的）、fearsome（fear + **-some** 引起…的→可怕的）、afraid（**a-** 在 + fray←fear 恐惧 = 处于恐惧中→害怕的）。
- **前缀·后缀**：形容词后缀 **-ful**（例：helpful, useful）、**-less**（例：hopeless, careless）；前缀 **a-**（例：afraid, asleep）。
- **同义·反义**：同义 dread（惧怕）, be afraid of（害怕）；反义 dare（敢于）, brave（勇敢面对）。
- **变形**：动词 → 第三人称单数：fears；过去式：feared；过去分词：feared；现在分词：fearing；本词兼作名词 → 复数：fears；形容词派生 → fearful adj. 害怕的；fearless adj. 无畏的；副词派生 → fearfully adv. 害怕地。

### 17. creature /ˈkriːtʃər/ n. 生物，动物
- **词根·渊源**：拉丁 **creatura**（被创造之物）← *creare*（创造）+ **-ura**（名词后缀）→ 古法语 *creature* → 英语；本义“被创造出来的东西→生物、动物”。
- **同根词**：create（cre 创造 + **-ate** 动词后缀→创造）、creation（create + **-ion** 名词后缀→创造）、creative（create + **-ive** …的→有创造力的）、creator（create + **-or** 人→创造者）、creature 本身不再列、procreate（**pro-** 向前 + create 创造 = 繁衍→生育）。
- **前缀·后缀**：名词后缀 **-ure**（例：picture, nature）；前缀 **pro-**（例：produce, promote）。
- **同义·反义**：同义 being（生物）, animal（动物）；反义 无。
- **变形**：名词 → 复数：creatures；形容词派生 → creaturely adj. 生物般的；动词派生 → create v. 创造；名词派生 → creation n. 创造；creator n. 创造者。

### 18. feather /ˈfeðər/ v. 羽毛；用羽毛装饰
- **词根·渊源**：古英语 **feþer**（羽毛）→ 中古英语 *fether* → 英语；与古高地德语 *fedara*、拉丁 *penna*（羽）同出 PIE *pet-*（飞、扑），本义“鸟用来飞的羽→羽毛”；作动词即“给…装上羽毛→用羽毛装饰”。
- **同根词**：feathery（feather + **-y** 多…的→羽毛般的）、feathered（feather + **-ed** 有…的→有羽毛的）、featherweight（feather + weight 重量→羽量级）、pinion（拉丁 penna 羽 + **-ion** → 翅羽）。
- **前缀·后缀**：形容词后缀 **-y**（例：windy, sunny）、**-ed**（例：winged, bearded）；无前缀。
- **同义·反义**：同义 plume（羽毛）, plumage（全身羽毛）；反义 无。
- **变形**：名词 → 复数：feathers；本词兼作动词 → 第三人称单数：feathers；过去式：feathered；过去分词：feathered；现在分词：feathering；形容词派生 → feathery adj. 羽毛般的；feathered adj. 有羽毛的。

### 19. wonder /ˈwʌndər/ v. 想知道；想弄明白
- **词根·渊源**：古英语 **wundor**（奇迹、令人惊奇之事）→ 中古英语 *wonder*，本义“感到惊奇”，由“对奇事感到惊异”引申为“心中疑惑、想知道”。
- **同根词**：wonderful（wonder 惊奇 + **-ful** 充满……的 = 令人惊奇的→精彩的）、wondrous（wonder + **-ous** ……的 = 奇妙的）、wonderment（wonder + **-ment** 名词后缀 = 惊奇感）。
- **前缀·后缀**：名词后缀 **-ful**（例：helpful, useful）、**-ous**（例：famous, dangerous）、**-ment**（例：movement, development）。
- **同义·反义**：同义 ponder（思索）, question（疑问）；反义 know（知道）, understand（明白）。
- **变形**：动词 → 第三人称单数：wonders；过去式：wondered；过去分词：wondered；现在分词：wondering；名词派生 → wonder n. 惊奇、奇迹；形容词派生 → wonderful adj. 精彩的；副词派生 → wonderfully adv. 精彩地。

### 20. line /laɪn/ n. 行，排，列；线；线条
- **词根·渊源**：拉丁 **linea**（亚麻线、绳）→ 古法语 *ligne* → 英语 line，本义“拉直的绳线”，引申为“线条、行列”。
- **同根词**：linear（line 线 + **-ar** ……的 = 线的→线性的）、lineage（line 线 + **-age** 名词后缀 = 血脉一线相承→血统）、outline（**out-** 外 + line 线 = 外沿线→轮廓）、underline（**under-** 下 + line 线 = 在下面画线→强调）。
- **前缀·后缀**：名词后缀 **-ar**（例：similar, familiar）、**-age**（例：marriage, package）；前缀 **out-**（例：outside）、**under-**（例：underground）。
- **同义·反义**：同义 row（排）, string（线）；反义 无。
- **变形**：名词 → 复数：lines；动词派生 → line v. 画线、排队；形容词派生 → linear adj. 线性的。

### 21. refuse /rɪˈfju:z/ v. 拒绝，回绝
- **词根·渊源**：拉丁 **refusare**（**re-** 回 + **fundere** 倒 = 倒回去）→ 古法语 *refuser* → 英语 refuse，本义“把东西倒回、退回”，引申为“拒绝接受”。
- **同根词**：refusal（refuse + **-al** 名词后缀 = 拒绝）、refuse（**re-** 回 + fus 倒 = 倒回→拒绝，同源异形）、confuse（**con-** 共同 + fus 倒 = 倒在一起→混淆）、transfuse（**trans-** 转移 + fus 倒 = 倒过去→输血）。
- **前缀·后缀**：前缀 **re-**（例：return, repeat）、**con-**（例：connect, collect）、**trans-**（例：transport, translate）；名词后缀 **-al**（例：arrival, approval）。
- **同义·反义**：同义 decline（婉拒）, reject（拒绝）；反义 accept（接受）, agree（同意）。
- **变形**：动词 → 第三人称单数：refuses；过去式：refused；过去分词：refused；现在分词：refusing；名词派生 → refusal n. 拒绝。

### 22. spread /sprɛd/ v. 展开，打开；张开，伸开
- **词根·渊源**：古英语 **sprǣdan**（展开、铺开），与 PIE *sper-*（散开）相关，本义“把东西铺展开”，引申为“张开、传播”。
- **同根词**：spreadable（spread + **-able** 能……的 = 可涂抹的）、widespread（**wide** 宽 + spread 展开 = 广泛分布的）、spreader（spread + **-er** 工具 = 涂抹器）。
- **前缀·后缀**：形容词后缀 **-able**（例：readable, comfortable）、名词后缀 **-er**（例：teacher, worker）；复合前缀 **wide-**（例：wide-open）。
- **同义·反义**：同义 unfold（展开）, extend（伸展）；反义 fold（折叠）, gather（聚集）。
- **变形**：动词 → 第三人称单数：spreads；过去式：spread；过去分词：spread；现在分词：spreading；名词派生 → spread n. 传播、涂抹酱。

### 23. mark /mɑːrk/ v. 表明；标志；符号；记号；痕迹；分数
- **词根·渊源**：古英语 **mearc**（边界、记号）→ 中古英语 *mark*，本义“划定的边界标记”，引申为“记号、痕迹、分数”，动词义“做标记、表明”。
- **同根词**：remark（**re-** 再 + mark 标记 = 再标记→评论）、remarkable（remark + **-able** 能……的 = 值得评论的→非凡的）、marked（mark + **-ed** ……的 = 有标记的→显著的）、marker（mark + **-er** 工具 = 记号笔）。
- **前缀·后缀**：前缀 **re-**（例：return, repeat）；后缀 **-able**（例：readable, comfortable）、**-ed**（例：talented, excited）、**-er**（例：teacher, worker）。
- **同义·反义**：同义 sign（标记）, indicate（表明）；反义 无。
- **变形**：动词 → 第三人称单数：marks；过去式：marked；过去分词：marked；现在分词：marking；名词 → 复数：marks；形容词派生 → marked adj. 显著的；名词派生 → marker n. 记号笔。

### 24. desert /ˈdezərt/ v. 沙漠；荒漠
- **词根·渊源**：拉丁 **desertum**（被遗弃之地，**de-** 离开 + **serere** 连接 = 断开连接→遗弃）→ 古法语 *desert* → 英语 desert，本义“荒无人烟之地”，引申为“沙漠、荒漠”。
- **同根词**：deserted（desert + **-ed** ……的 = 被遗弃的）、deserter（desert + **-er** 人 = 遗弃者→逃兵）、desertion（desert + **-ion** 名词后缀 = 遗弃）。
- **前缀·后缀**：前缀 **de-**（例：depart, decline）；后缀 **-ed**（例：talented, excited）、**-er**（例：teacher, worker）、**-ion**（例：action, education）。
- **同义·反义**：同义 wasteland（荒地）, wilderness（荒野）；反义 oasis（绿洲）, fertile land（沃土）。
- **变形**：名词 → 复数：deserts；形容词派生 → deserted adj. 被遗弃的；名词派生 → deserter n. 逃兵。

### 25. tent /tɛnt/ n. 帐篷
- **词根·渊源**：拉丁 **tendere**（伸展、拉紧）→ 古法语 *tente* → 英语 tent，本义“拉紧撑开的布”，即“帐篷”。
- **同根词**：tension（tens 拉紧 + **-ion** 名词后缀 = 拉紧→紧张）、extend（**ex-** 向外 + tend 伸展 = 向外伸→延伸）、intend（**in-** 向内 + tend 伸展 = 心向内伸→打算）、attention（**at-** 向 + tent 伸展 + **-ion** = 把心伸向→注意）。
- **前缀·后缀**：前缀 **ex-**（例：export, exit）、**in-**（例：inside, include）、**at-**（例：attend, attract）；名词后缀 **-ion**（例：action, education）。
- **同义·反义**：同义 shelter（遮蔽处）, camp（营地）；反义 无。
- **变形**：名词 → 复数：tents；动词派生 → tent v. 搭帐篷。

### 26. knife /naɪf/ n. 刀
- **词根·渊源**：古英语 **cnīf**（刀），可能借自古诺斯语 *knífr*，本义“切割工具”，即“刀”。
- **同根词**：knives（knife 的复数，**-ves** 变体 = 刀）、knife-edge（knife 刀 + edge 刃 = 刀刃）、penknife（**pen** 笔 + knife 刀 = 削笔刀）。
- **前缀·后缀**：无前后缀（单纯词）。

### 27. explain /ɪkˈsplen/ v. 解释；说明
- **词根·渊源**：拉丁 **explanare**（**ex-** 向外 + **planus** 平的 = 把平面铺开）→ 古法语 *expliquer* → 英语 explain，本义“铺平展开”，引申为“讲清楚、解释”。
- **同根词**：explanation（explain + **-ation** 名词后缀 = 解释）、plain（plan 平 + **-ain** = 平坦的→简单的）、plane（plan 平 = 平面）、explicit（**ex-** 向外 + plic 折叠 = 向外展开→明确的）。
- **前缀·后缀**：前缀 **ex-**（例：export, exit）；名词后缀 **-ation**（例：education, information）。
- **同义·反义**：同义 clarify（澄清）, illustrate（说明）；反义 confuse（使困惑）, obscure（使模糊）。
- **变形**：动词 → 第三人称单数：explains；过去式：explained；过去分词：explained；现在分词：explaining；名词派生 → explanation n. 解释。

### 28. pleased /pliːzd/ adj. 高兴；满意；愉快；开心的，高兴的

- **变形**：形容词 → 比较级：more pleased；最高级：most pleased；名词派生 → pleasure n. 愉快；副词派生 → pleasedly adv. 高兴地。
