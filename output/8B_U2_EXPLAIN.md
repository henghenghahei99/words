## 二、逐词说文解字

### 1. language /ˈlæŋɡwɪdʒ/ n. 语言
- **词根·渊源**：拉丁 **lingua**（舌头；语言）→ 古法语 *langage* → 英语 language；本义“用舌头发出的东西”，引申为“语言”。
- **同根词**：linguist（lingu 舌头/语言 + **-ist** 人 = 语言研究者→语言学家）、bilingual（**bi-** 二 + lingu 语言 + **-al** …的 = 双语的）、linguistics（linguist + **-ics** 学科 = 语言学）。
- **前缀·后缀**：名词后缀 **-age**（例：marriage, package）；前缀 **bi-**（例：bicycle, bilingual）。
- **同义·反义**：同义 speech（言语）, tongue（语言）；反义 无。
- **变形**：名词 → 复数：languages；形容词派生 → linguistic adj. 语言的；副词派生 → linguistically adv. 语言上地。

### 2. communication /kəˌmjunɪˈkeʃən/ n. 交流；交际；沟通
- **词根·渊源**：拉丁 **communis**（共同的）→ 拉丁 *communicare*（使共同、分享）→ 古法语 *communication* → 英语 communication；本义“使共有、分享”，引申为“交流、沟通”。
- **同根词**：communicate（communic 共同 + **-ate** 动词后缀 = 使共同→交流）、common（com 共同 + mun 服务/义务 = 共同的）、community（com 共同 + mun + **-ity** 名词后缀 = 共同体→社区）、communism（commune 公社 + **-ism** 主义 = 共产主义）。
- **前缀·后缀**：前缀 **com-**（例：common, community）；名词后缀 **-ation**（例：information, education）。
- **同义·反义**：同义 exchange（交流）, contact（联系）；反义 silence（沉默）, isolation（隔离）。
- **变形**：名词 → 复数：communications；动词派生 → communicate v. 交流；形容词派生 → communicative adj. 善于交流的；副词派生 → communicatively adv. 交流地。

### 3. ballet /bæˈleɪ/ n. 芭蕾舞剧；芭蕾舞团；芭蕾舞；芭蕾舞曲
- **词根·渊源**：意大利 **ballare**（跳舞）→ 意大利 *balletto*（小舞蹈）→ 法语 *ballet* → 英语 ballet；本义“小舞蹈”，引申为“芭蕾舞”。
- **同根词**：ball（ball 跳舞→舞会→球）、ballad（ball 跳舞 + **-ad** 名词后缀 = 伴舞的歌→民谣）、ballroom（ball 舞会 + room 房间 = 舞厅）。
- **前缀·后缀**：名词后缀 **-et**（例：ballet, pocket）；无前缀。
- **同义·反义**：同义 dance（舞蹈）；反义 无。
- **变形**：名词 → 复数：ballets；名词派生 → ballet dancer n. 芭蕾舞演员。

### 4. accept /ækˈsɛpt/ v. 接受（建议、邀请等）；收受
- **词根·渊源**：拉丁 **capere**（拿、取）→ 拉丁 *accipere*（ac- 向 + capere 拿 = 拿到手）→ 古法语 *accepter* → 英语 accept；本义“拿到手”，引申为“接受”。
- **同根词**：receive（**re-** 回 + ceive 拿 = 拿回来→收到）、concept（**con-** 一起 + cept 拿 = 拿到一起→概念）、except（**ex-** 出 + cept 拿 = 拿出来→除外）、capture（capt 拿 + **-ure** 名词后缀 = 抓住→捕获）、participate（**part** 部分 + **cip** 拿 + **-ate** = 拿一份→参加）。
- **前缀·后缀**：前缀 **ac-**（= ad- 向，例：accept, access）；词根 **-cept-**（例：concept, except）。
- **同义·反义**：同义 receive（收到）, take（接受）；反义 reject（拒绝）, refuse（拒绝）。
- **变形**：动词 → 第三人称单数：accepts；过去式：accepted；过去分词：accepted；现在分词：accepting；名词派生 → acceptance n. 接受；形容词派生 → acceptable adj. 可接受的；副词派生 → acceptably adv. 可接受地。

### 5. reject /rɪˈdʒɛkt/ v. 拒绝接受；不予考虑；否决（提议、建议或请求）
- **词根·渊源**：拉丁 **jacere**（扔、投）→ 拉丁 *reicere*（re- 回 + jacere 扔 = 扔回去）→ 古法语 *rejecter* → 英语 reject；本义“扔回去”，引申为“拒绝”。
- **同根词**：project（**pro-** 向前 + ject 扔 = 向前扔→投射→项目）、inject（**in-** 进入 + ject 扔 = 扔进去→注射）、object（**ob-** 反对 + ject 扔 = 扔到对面→反对→物体）、subject（**sub-** 在下 + ject 扔 = 扔到下面→主题→臣民）、eject（**e-** 出 + ject 扔 = 扔出去→驱逐）。
- **前缀·后缀**：前缀 **re-**（例：return, review）；词根 **-ject-**（例：project, inject）。
- **同义·反义**：同义 refuse（拒绝）, decline（谢绝）；反义 accept（接受）, approve（批准）。
- **变形**：动词 → 第三人称单数：rejects；过去式：rejected；过去分词：rejected；现在分词：rejecting；名词派生 → rejection n. 拒绝；形容词派生 → rejective adj. 拒绝的。

### 6. meaning /ˈminɪŋ/ v. 意义；意思
- **词根·渊源**：古英语 **mænan**（意欲、打算）→ 中古英语 *menen* → 英语 mean + **-ing** 名词后缀 → meaning；本义“意图、打算”，引申为“意义、意思”。
- **同根词**：mean（mean 意欲→意思是）、meaningful（meaning + **-ful** 充满…的 = 有意义的）、meaningless（meaning + **-less** 无…的 = 无意义的）。
- **前缀·后缀**：名词后缀 **-ing**（例：building, feeling）；无前缀。
- **同义·反义**：同义 sense（意义）, significance（重要性）；反义 nonsense（无意义的话）。
- **变形**：名词 → 复数：meanings；形容词派生 → meaningful adj. 有意义的；副词派生 → meaningfully adv. 有意义地。

### 7. gesture /'dʒestʃə(r)/ n. 手势，姿势；姿态，表示
- **词根·渊源**：拉丁 **gerere**（携带、表现）→ 拉丁 *gestura*（举止、姿态）→ 中世纪拉丁 *gestura* → 英语 gesture；本义“举止、姿态”，引申为“手势、表示”。
- **同根词**：suggest（**sug-** 在下 + gest 携带 = 在下面携带→暗示）、digest（**di-** 分开 + gest 携带 = 分开携带→消化）、congest（**con-** 一起 + gest 携带 = 携带到一起→拥挤）。
- **前缀·后缀**：名词后缀 **-ure**（例：picture, nature）；无前缀。
- **同义·反义**：同义 sign（手势）, signal（信号）；反义 无。
- **变形**：名词 → 复数：gestures；动词派生 → gesticulate v. 做手势；形容词派生 → gestural adj. 手势的。

### 8. message /ˈmesɪdʒ/ n.（书面或口头的）信息；消息；便条；信；口信
- **词根·渊源**：拉丁 **mittere**（送、派）→ 拉丁 *missus*（送出的）→ 古法语 *message* → 英语 message；本义“送出的东西”，引申为“消息、信息”。
- **同根词**：mission（miss 送 + **-ion** 名词后缀 = 送出去的任务→使命）、submit（**sub-** 在下 + mit 送 = 从下送上→提交）、permit（**per-** 通过 + mit 送 = 送过去→允许）、transmit（**trans-** 穿过 + mit 送 = 送过去→传送）、dismiss（**dis-** 离开 + miss 送 = 送走→解散）。
- **前缀·后缀**：名词后缀 **-age**（例：language, package）；无前缀。
- **同义·反义**：同义 information（信息）, note（便条）；反义 无。
- **变形**：名词 → 复数：messages；名词派生 → messenger n. 信使。

### 9. bored /bɔːd/ adj. 厌倦的；厌烦的;无聊的
- **词根·渊源**：古英语 **borian**（钻孔）→ 中古英语 *boren* → 英语 bore（钻孔→使厌烦）+ **-ed** 形容词后缀 → bored；本义“被钻透的”，引申为“被烦透的→厌倦的”。
- **同根词**：bore（bore 钻孔→使厌烦）、boring（bor + **-ing** …的 = 令人厌烦的）、boredom（bore + **-dom** 状态 = 厌倦）。
- **前缀·后缀**：形容词后缀 **-ed**（例：tired, excited）；无前缀。
- **同义·反义**：同义 tired（厌倦的）, weary（厌烦的）；反义 interested（感兴趣的）, excited（兴奋的）。
- **变形**：形容词 → 比较级：more bored；最高级：most bored；名词派生 → boredom n. 厌倦；动词派生 → bore v. 使厌烦。

### 10. part time /pɑːt taɪm/ n. 兼职的；部分时间的
- **同义搭配**：part-time job（兼职工作） / half-time（半日制的）
- **反义搭配**：full-time（全职的）

### 11. well-dressed /ˌwel ˈdrest/ adj. 穿着考究的；穿着入时的
- **词根·渊源**：古英语 **well**（好地）+ 古法语 **dresser**（安排、整理）→ 英语 well + dress + **-ed** → well-dressed；本义“穿着整理得好的”，引申为“穿着考究的”。
- **同根词**：dress（dress 整理→穿衣）、dressing（dress + **-ing** 名词后缀 = 穿衣→调料）、dressy（dress + **-y** …的 = 讲究穿着的）。
- **前缀·后缀**：副词前缀 **well-**（例：well-known, well-made）；形容词后缀 **-ed**（例：tired, excited）。
- **同义·反义**：同义 smart（穿着讲究的）, elegant（优雅的）；反义 badly-dressed（穿着邋遢的）, shabby（破旧的）。
- **变形**：形容词 → 比较级：better-dressed；最高级：best-dressed；无名词派生。

### 12. lady /ˈleɪdi/ n. 女士；夫人；小姐
- **词根·渊源**：古英语 **hlæfdige**（hlaf 面包 + dige 揉制者 = 揉面包的人→女主人）→ 中古英语 *lady* → 英语 lady；本义“做面包的女主人”，引申为“女士、夫人”。
- **同根词**：lord（hlaf 面包 + weard 看守者 = 看管面包的人→主人）、ladybird（lady 女士 + bird 鸟 = 瓢虫）、ladyship（lady + **-ship** 身份 = 夫人身份）。
- **前缀·后缀**：名词后缀 **-y**（例：lady, army）；无前缀。
- **同义·反义**：同义 woman（女人）, madam（夫人）；反义 gentleman（绅士）, lord（老爷）。
- **变形**：名词 → 复数：ladies；形容词派生 → ladylike adj. 淑女的。

### 13. sigh /saɪ/ v. 叹气，叹息
- **词根·渊源**：古英语 **sīcan**（叹息）→ 中古英语 *sigen* → 英语 sigh；本义“叹息”，词源存疑（一说拟声）。
- **同根词**：无常用同根词。
- **前缀·后缀**：无前后缀（单纯词）。
- **同义·反义**：同义 groan（呻吟）, moan（呻吟）；反义 无。
- **变形**：动词 → 第三人称单数：sighs；过去式：sighed；过去分词：sighed；现在分词：sighing；名词派生 → sigh n. 叹息。

### 14. matter /ˈmætər/ n. 怎么了
- **词根·渊源**：拉丁 **mater**（母亲）→ 拉丁 *materia*（材料、物质）→ 古法语 *matere* → 英语 matter；本义“物质、材料”，引申为“事情、问题”，短语“What's the matter?”即“怎么了”。
- **同根词**：material（mater 物质 + **-ial** …的 = 物质的→材料）、maternal（mater 母亲 + **-nal** …的 = 母亲的）、matrix（mater 母亲 + **-ix** 名词后缀 = 母体→矩阵）。
- **前缀·后缀**：名词后缀 **-er**（例：matter, teacher）；无前缀。
- **同义·反义**：同义 problem（问题）, issue（事情）；反义 无。
- **变形**：名词 → 复数：matters；形容词派生 → matterful adj. 有内容的。

### 15. expression /ɪkˈspreʃn/ n. 表情；表示；神色；表达方式
- **词根·渊源**：拉丁 **premere**（压）→ 拉丁 *exprimere*（ex- 出 + premere 压 = 压出来）→ 英语 express + **-ion** 名词后缀 → expression；本义“压出来的东西”，引申为“表达、表情”。
- **同根词**：express（**ex-** 出 + press 压 = 压出来→表达）、press（press 压→按）、impress（**im-** 进入 + press 压 = 压进去→使印象深刻）、compress（**com-** 一起 + press 压 = 压到一起→压缩）、depress（**de-** 向下 + press 压 = 向下压→使沮丧）。
- **前缀·后缀**：前缀 **ex-**（例：express, export）；名词后缀 **-ion**（例：action, education）。
- **同义·反义**：同义 look（神色）, phrase（表达方式）；反义 无。
- **变形**：名词 → 复数：expressions；动词派生 → express v. 表达；形容词派生 → expressive adj. 富有表现力的；副词派生 → expressively adv. 表现力强地。

### 16. appearance /əˈpɪrəns/ n. 出现，起源；外表；外貌
- **词根·渊源**：拉丁 **parere**（出现）→ 拉丁 *apparere*（ad- 向 + parere 出现 = 出现）→ 古法语 *apparence* → 英语 appearance；本义“出现”，引申为“外表、外貌”。
- **同根词**：appear（**ap-** 向 + pear 出现 = 出现）、apparent（appar 出现 + **-ent** …的 = 明显的）、disappear（**dis-** 否定 + appear 出现 = 消失）、transparent（**trans-** 穿过 + par 出现 + **-ent** = 穿过去能看见→透明的）。
- **前缀·后缀**：前缀 **ap-**（= ad- 向，例：appear, approach）；名词后缀 **-ance**（例：importance, distance）。
- **同义·反义**：同义 look（外表）, arrival（出现）；反义 disappearance（消失）, absence（缺席）。
- **变形**：名词 → 复数：appearances；动词派生 → appear v. 出现；形容词派生 → apparent adj. 明显的。

### 17. impression /ɪmˈpreʃn/ n. 印象，感想；影响，作用
- **词根·渊源**：拉丁 **premere**（压）→ 拉丁 *imprimere*（im- 进入 + premere 压 = 压进去）→ 英语 impress + **-ion** 名词后缀 → impression；本义“压进去的痕迹”，引申为“印象”。
- **同根词**：impress（**im-** 进入 + press 压 = 压进去→使印象深刻）、express（**ex-** 出 + press 压 = 压出来→表达）、press（press 压→按）、compress（**com-** 一起 + press 压 = 压到一起→压缩）、depress（**de-** 向下 + press 压 = 向下压→使沮丧）。
- **前缀·后缀**：前缀 **im-**（= in- 进入，例：impress, import）；名词后缀 **-ion**（例：action, education）。
- **同义·反义**：同义 feeling（感觉）, effect（影响）；反义 无。
- **变形**：名词 → 复数：impressions；动词派生 → impress v. 使印象深刻；形容词派生 → impressive adj. 令人印象深刻的；副词派生 → impressively adv. 令人印象深刻地。

### 18. towards /tɔ:rdz/ adv. 朝；向；对着
- **词根·渊源**：古英语 **tōweard**（tō 向 + -weard 朝向…的）→ 中古英语 *toward* + **-s** 副词后缀 → towards；本义“朝…方向”，引申为“朝、向”。
- **同根词**：toward（toward 朝…方向）、forward（**for-** 向前 + ward 朝向 = 向前的）、backward（back 后 + ward 朝向 = 向后的）、upward（up 上 + ward 朝向 = 向上的）、homeward（home 家 + ward 朝向 = 向家的）。
- **前缀·后缀**：副词后缀 **-s**（例：towards, upwards）；后缀 **-ward**（例：forward, backward）。
- **同义·反义**：同义 toward（朝）, to（向）；反义 away from（远离）。
- **变形**：副词 → 无比较级；无词性派生。

### 19. hold /hoʊld/ v. 使保持（在某位置）
- **词根·渊源**：古英语 *healdan*（握持、看守）→ 中古英语 *holden*，本义“用手握住”，引申为“使保持在某位置、容纳、举行”。
- **同根词**：holder（hold + **-er** 者 = 持有者）、holding（hold + **-ing** 名词后缀 = 持有物、股份）、uphold（**up-** 向上 + hold 持 = 支持、维护）、withhold（**with-** 向后 + hold 持 = 扣留、不给）、foothold（foot 脚 + hold 抓 = 立足点）、household（house 家 + hold 持 = 一家人）。
- **前缀·后缀**：名词后缀 **-er**（例：worker, teacher）；名词后缀 **-ing**（例：building, meeting）；前缀 **up-**（例：uphold, update）、**with-**（例：withdraw, withstand）。
- **同义·反义**：同义 keep（保持）, grasp（握住）；反义 release（松开）, drop（掉落）。
- **变形**：动词 → 第三人称单数：holds；过去式：held；过去分词：held；现在分词：holding；名词派生 → hold n. 握、控制；holder n. 持有者。

### 20. later /ˈleɪtə(r)/ adj. 后来，以后
- **词根·渊源**：古英语 *læt*（慢的、迟的）→ 中古英语 *lat* → late + 比较级后缀 **-er**，本义“更迟的”，引申为“后来的、以后的”。
- **同根词**：late（本词原级：迟的）、latest（late + **-est** 最高级 = 最新的）、lately（late + **-ly** 副词后缀 = 最近）、lateness（late + **-ness** 名词后缀 = 迟、晚）。
- **前缀·后缀**：比较级后缀 **-er**（例：faster, taller）；副词后缀 **-ly**（例：quickly, badly）；名词后缀 **-ness**（例：kindness, darkness）。
- **同义·反义**：同义 afterwards（后来）, subsequently（随后）；反义 earlier（更早地）, before（以前）。
- **变形**：形容词/副词 → 比较级：later；最高级：latest；副词派生 → later adv. 后来；lately adv. 最近。

### 21. remind /rɪˈmaɪnd/ v. 提醒；使响起
- **词根·渊源**：**re-**（再、回）+ 古英语 *gemynd*（记忆、心）→ mind，本义“使再想起”，引申为“提醒”。
- **同根词**：mind（本词根词：心、头脑）、reminder（remind + **-er** 者/物 = 提醒物、提示）、mindful（mind + **-ful** 充满的 = 留心的）、mindless（mind + **-less** 无的 = 无心的）、mention（拉丁 *mens* 心 → 提及，与 mind 同源）。
- **前缀·后缀**：前缀 **re-**（例：return, rebuild）；名词后缀 **-er**（例：reminder, teacher）；形容词后缀 **-ful**（例：helpful, careful）、**-less**（例：hopeless, careless）。
- **同义·反义**：同义 prompt（提醒）, alert（使警觉）；反义 forget（忘记）, ignore（忽视）。
- **变形**：动词 → 第三人称单数：reminds；过去式：reminded；过去分词：reminded；现在分词：reminding；名词派生 → reminder n. 提醒物、提示。

### 22. neck /nɛk/ n. 脖子；颈
- **词根·渊源**：古英语 *hnecca*（颈、后颈）→ 中古英语 *nekke*，本义“颈项”，引申为“瓶颈、衣领”等。
- **同根词**：necklace（neck 颈 + lace 带子 = 项链）、necktie（neck 颈 + tie 领带 = 领带）、neckline（neck 颈 + line 线 = 领口）、turtleneck（turtle 龟 + neck 颈 = 高领毛衣）、bottleneck（bottle 瓶 + neck 颈 = 瓶颈）。
- **前缀·后缀**：无前后缀（单纯词）。
- **同义·反义**：同义 nape（后颈）, collar（衣领）；反义 无。
- **变形**：名词 → 复数：necks；形容词派生 → necked adj. 有颈的。

### 23. cross /krɔːs/ v. 使交叉；使交叠
- **词根·渊源**：拉丁 *crux / cruc-*（十字架）→ 古爱尔兰语 *cros* → 古英语 *cros*，本义“十字架”，引申为“交叉、横穿”。
- **同根词**：crossing（cross + **-ing** 名词后缀 = 十字路口、横渡）、crossroads（cross 交叉 + roads 路 = 十字路口）、across（**a-** 在 + cross 十字 = 横过）、crucial（拉丁 crux 十字 + **-ial** 关键的，源自“十字路口需抉择”）、crucify（拉丁 crux 十字 + **-fy** 使 = 钉十字架）、crusade（拉丁 crux 十字 + **-ade** 名词后缀 = 十字军东征）。
- **前缀·后缀**：名词后缀 **-ing**（例：crossing, building）；前缀 **a-**（例：across, aboard）；动词后缀 **-fy**（例：simplify, beautify）。
- **同义·反义**：同义 intersect（交叉）, traverse（横穿）；反义 uncross（使不交叉）, separate（分开）。
- **变形**：动词 → 第三人称单数：crosses；过去式：crossed；过去分词：crossed；现在分词：crossing；名词派生 → cross n. 十字、交叉；crossing n. 十字路口。

### 24. nod /nɒd/ v. 点头
- **词根·渊源**：中古英语 *nodden*（点头、打盹），可能源自低地德语 *nudden*，本义“上下晃动头部”，引申为“点头同意、打瞌睡”。词源存疑。
- **同根词**：nodding（nod + **-ing** 名词/形容词后缀 = 点头的）、nodder（nod + **-er** 者 = 点头的人）。
- **前缀·后缀**：名词后缀 **-ing**（例：nodding, running）；名词后缀 **-er**（例：nodder, worker）。
- **同义·反义**：同义 bow（鞠躬）, signal（示意）；反义 shake（摇头）。
- **变形**：动词 → 第三人称单数：nods；过去式：nodded；过去分词：nodded；现在分词：nodding；名词派生 → nod n. 点头。

### 25. shake /ʃeɪk/ v.（与某人）握手；摇头；摇动，震动
- **词根·渊源**：古英语 *sceacan*（摇动、振动）→ 中古英语 *shaken*，本义“来回摇动”，引申为“握手、摇头、使震动”。
- **同根词**：shaky（shake + **-y** 形容词后缀 = 摇晃的）、shaking（shake + **-ing** 名词后缀 = 摇动）、shaker（shake + **-er** 者/物 = 摇动者、调酒器）、handshake（hand 手 + shake 摇 = 握手）、milkshake（milk 奶 + shake 摇 = 奶昔）。
- **前缀·后缀**：形容词后缀 **-y**（例：shaky, rainy）；名词后缀 **-ing**（例：shaking, running）；名词后缀 **-er**（例：shaker, worker）。
- **同义·反义**：同义 tremble（颤抖）, vibrate（振动）；反义 steady（使稳定）, still（使静止）。
- **变形**：动词 → 第三人称单数：shakes；过去式：shook；过去分词：shaken；现在分词：shaking；名词派生 → shake n. 摇动、震动；shaky adj. 摇晃的。

### 26. sure /ʃʊə(r)/ adj.（表示同意）当然；确信；肯定；确信的，肯定的
- **词根·渊源**：拉丁 *securus*（无忧的）→ 古法语 *seur* → 英语 sure，本义“安全的、无忧的”，引申为“确信的、肯定的”。
- **同根词**：surely（sure + **-ly** 副词后缀 = 确实地）、sureness（sure + **-ness** 名词后缀 = 确信）、ensure（**en-** 使 + sure 确定 = 确保）、insure（**in-** 使 + sure 确定 = 保险）、assure（**as-** 向 + sure 确定 = 使确信）、security（拉丁 securus 无忧 + **-ity** 名词后缀 = 安全）。
- **前缀·后缀**：副词后缀 **-ly**（例：surely, quickly）；名词后缀 **-ness**（例：sureness, kindness）；前缀 **en-**（例：ensure, enable）、**in-**（例：insure, include）、**as-**（例：assure, assist）。
- **同义·反义**：同义 certain（确定的）, confident（确信的）；反义 unsure（不确定的）, doubtful（怀疑的）。
- **变形**：形容词 → 比较级：surer；最高级：surest；副词派生 → surely adv. 确实地；名词派生 → sureness n. 确信。
