## 二、逐词说文解字

### 1. shake /ʃeɪk/ v. 摇动；抖动
- **词根·渊源**：古英语 *sceacan*（摇动、颤抖）→ 中古英语 *shaken*，本义“快速来回移动”，引申为“摇动；抖动”。
- **同根词**：shaky（shake + **-y** …的：摇摇晃晃的）、shaker（shake + **-er** 做…的人/物：摇动者；调酒器）、shaking（shake + **-ing** 名词/形容词：摇动；颤抖的）。
- **前缀·后缀**：无前缀；动词后缀 **-er** 构成名词（例：teacher, worker）。
- **同义·反义**：同义 tremble（颤抖）, quiver（颤动）；反义 steady（使稳固）, still（使静止）。
- **变形**：动词 → 第三人称单数：shakes；过去式：shook；过去分词：shaken；现在分词：shaking；名词派生 → shakiness n. 摇晃；形容词派生 → shaky adj. 摇晃的；副词派生 → shakily adv. 摇晃地。

### 2. clap /klæp/ v. 鼓掌；拍手
- **词根·渊源**：古英语 *clæppan*（拍击、跳动）→ 中古英语 *clappen*，拟声词，模拟拍击声，本义“拍打”，引申为“鼓掌；拍手”。
- **同根词**：clapper（clap + **-er** 做…的人/物：拍手者；铃舌）、clapping（clap + **-ing** 名词：拍手声）、claptrap（clap + trap 噱头：哗众取宠的话）。
- **前缀·后缀**：无前缀；动词后缀 **-er** 构成名词（例：runner, singer）。
- **同义·反义**：同义 applaud（鼓掌）, pat（轻拍）；反义 boo（嘘声）, hiss（发出嘘声）。
- **变形**：动词 → 第三人称单数：claps；过去式：clapped；过去分词：clapped；现在分词：clapping；名词派生 → clapping n. 拍手；clapper n. 拍手者。

### 3. madam /ˈmædəm/ n. 夫人；女士
- **词根·渊源**：古法语 *ma dame*（我的女士）→ 中古英语 *madame*，本义“我的夫人”，是对女性的尊称，引申为“夫人；女士”。
- **同根词**：madame（法语借词：夫人，用于法语称谓）、madam（本身为复合词，无更多同根词）。
- **前缀·后缀**：无前后缀（复合词，由 *ma* 我的 + *dame* 女士构成）。
- **同义·反义**：同义 lady（女士）, Mrs（夫人）；反义 sir（先生）, gentleman（绅士）。
- **变形**：名词 → 复数：madams（作称呼语时复数少用）；无比较级；无词性派生。

### 4. boss /bɔs/ n. 老板
- **词根·渊源**：荷兰语 *baas*（主人、工头）→ 美式英语 *boss*，19世纪借入，本义“工头”，引申为“老板”。
- **同根词**：bossy（boss + **-y** …的：专横的）、bossism（boss + **-ism** 主义：老板政治）。
- **前缀·后缀**：无前缀；名词后缀 **-y** 构成形容词（例：rainy, dirty）。
- **同义·反义**：同义 employer（雇主）, manager（经理）；反义 employee（雇员）, worker（工人）。
- **变形**：名词 → 复数：bosses；形容词派生 → bossy adj. 专横的；副词派生 → bossily adv. 专横地。

### 5. expression /ɪkˈsprɛʃən/ n. 表情；神色
- **词根·渊源**：拉丁 **ex-**（出）+ **press-**（压）→ 拉丁 *exprimere*（压出、挤出）→ 古法语 *expression* → 英语，本义“挤出”，引申为“表达；表情”。
- **同根词**：express（**ex-** 出 + press 压 = 压出→表达）、expressive（express + **-ive** …的：富有表情的）、impression（**im-** 入 + press 压 + **-ion** 名词：压入→印象）、pressure（press + **-ure** 名词：压力）、compress（**com-** 一起 + press 压 = 压在一起→压缩）。
- **前缀·后缀**：前缀 **ex-**（例：export, exit）；名词后缀 **-ion**（例：action, education）。
- **同义·反义**：同义 look（神情）, face（面部表情）；反义 无。
- **变形**：名词 → 复数：expressions；形容词派生 → expressive adj. 富有表情的；副词派生 → expressively adv. 富有表情地；动词派生 → express v. 表达。

### 6. impression /ˌɪmˈprɛʃən/ n. 印象
- **词根·渊源**：拉丁 **im-**（入）+ **press-**（压）→ 拉丁 *imprimere*（压入）→ 古法语 *impression* → 英语，本义“压入痕迹”，引申为“印象”。
- **同根词**：impress（**im-** 入 + press 压 = 压入→使印象深刻）、impressive（impress + **-ive** …的：给人深刻印象的）、expression（**ex-** 出 + press 压 + **-ion** 名词：表达）、pressure（press + **-ure** 名词：压力）、compress（**com-** 一起 + press 压 = 压缩）。
- **前缀·后缀**：前缀 **im-**（例：import, improve）；名词后缀 **-ion**（例：invention, discussion）。
- **同义·反义**：同义 effect（效果）, feeling（感觉）；反义 无。
- **变形**：名词 → 复数：impressions；形容词派生 → impressive adj. 给人深刻印象的；副词派生 → impressively adv. 令人印象深刻地；动词派生 → impress v. 使印象深刻。

### 7. hold /hoʊld/ v. 使保持（在某位置）
- **词根·渊源**：古英语 *healdan*（握住、保持）→ 中古英语 *holden*，本义“握住”，引申为“使保持（在某位置）”。
- **同根词**：holder（hold + **-er** 做…的人/物：持有者）、holding（hold + **-ing** 名词：持有物）、holdfast（hold + fast 牢固：固定物）。
- **前缀·后缀**：无前缀；动词后缀 **-er** 构成名词（例：keeper, builder）。
- **同义·反义**：同义 keep（保持）, grasp（抓住）；反义 release（释放）, drop（掉落）。
- **变形**：动词 → 第三人称单数：holds；过去式：held；过去分词：held；现在分词：holding；名词派生 → holder n. 持有者；holding n. 持有物。

### 8. observe /əbˈzərv/ v. 注意到；观察到
- **词根·渊源**：拉丁 **ob-**（朝向）+ **serv-**（注视、守护）→ 拉丁 *observare*（注视、遵守）→ 古法语 *observer* → 英语，本义“朝…注视”，引申为“注意到；观察到”。
- **同根词**：observation（observe + **-ation** 名词：观察）、observant（observe + **-ant** …的：善于观察的）、observatory（observe + **-atory** 场所：天文台）、preserve（**pre-** 预先 + serv 守护 = 预先守护→保存）、reserve（**re-** 回 + serv 守护 = 保留）。
- **前缀·后缀**：前缀 **ob-**（例：object, obtain）；名词后缀 **-ation**（例：information, education）。
- **同义·反义**：同义 notice（注意到）, watch（观察）；反义 ignore（忽视）, overlook（忽略）。
- **变形**：动词 → 第三人称单数：observes；过去式：observed；过去分词：observed；现在分词：observing；名词派生 → observation n. 观察；形容词派生 → observant adj. 善于观察的。

### 9. remind /riˈmaɪnd/ v. 提醒；使想起
- **词根·渊源**：**re-**（回）+ **mind**（心、记忆）→ 英语 *remind*，本义“使回到心中”，引申为“提醒；使想起”。
- **同根词**：reminder（remind + **-er** 做…的人/物：提醒物）、mind（心、记忆：单纯词）、mindful（mind + **-ful** …的：留心的）、mindless（mind + **-less** 无…的：无心的）。
- **前缀·后缀**：前缀 **re-**（例：return, recall）；名词后缀 **-er**（例：helper, printer）。
- **同义·反义**：同义 recall（使想起）, prompt（提醒）；反义 forget（忘记）, ignore（忽视）。
- **变形**：动词 → 第三人称单数：reminds；过去式：reminded；过去分词：reminded；现在分词：reminding；名词派生 → reminder n. 提醒物。

### 10. ballet /bæˈleɪ/ n. 芭蕾舞
- **词根·渊源**：意大利语 *balletto*（小舞蹈）→ 法语 *ballet* → 英语，本义“小舞蹈”，源自意大利语 *ballare*（跳舞），引申为“芭蕾舞”。
- **同根词**：ballerina（ballet + **-ina** 女性：芭蕾舞女演员）、ball（舞会：同源词，源自拉丁 *ballare* 跳舞）。
- **前缀·后缀**：无前缀；名词后缀 **-et** 表小（例：floweret, pocket）。
- **同义·反义**：同义 dance（舞蹈）；反义 无。
- **变形**：名词 → 复数：ballets；无比较级；无词性派生。

### 11. emphasize /ˈɛmfəˌsaɪz/ v. 强调
- **词根·渊源**：希腊 **en-**（在…中）+ **phasis**（显现、说）→ 拉丁 *emphasis*（强调）→ 英语 *emphasize*，本义“使显现”，引申为“强调”。
- **同根词**：emphasis（emphasize 的名词形式：强调）、emphatic（emphasis + **-ic** …的：强调的）、emphatically（emphatic + **-ally** 副词：强调地）。
- **前缀·后缀**：前缀 **em-**（例：embrace, empower）；动词后缀 **-ize**（例：realize, modernize）。
- **同义·反义**：同义 stress（强调）, highlight（突出）；反义 understate（轻描淡写）, ignore（忽视）。
- **变形**：动词 → 第三人称单数：emphasizes；过去式：emphasized；过去分词：emphasized；现在分词：emphasizing；名词派生 → emphasis n. 强调；形容词派生 → emphatic adj. 强调的；副词派生 → emphatically adv. 强调地。

### 12. nod /nɑd/ v. 点头
- **词根·渊源**：中古英语 *noddan*（点头、打盹），可能源自低地德语，本义“头向前低”，引申为“点头”。
- **同根词**：nodding（nod + **-ing** 形容词：点头的）、nodder（nod + **-er** 做…的人：点头者）。
- **前缀·后缀**：无前缀；动词后缀 **-er** 构成名词（例：runner, singer）。
- **同义·反义**：同义 bow（鞠躬）, gesture（示意）；反义 shake（摇头）。
- **变形**：动词 → 第三人称单数：nods；过去式：nodded；过去分词：nodded；现在分词：nodding；名词派生 → nod n. 点头；nodding adj. 点头的。

### 13. meaning /ˈminɪŋ/ n. 意义；意思
- **词根·渊源**：**mean**（意欲、表示）+ **-ing**（名词后缀）→ 英语 *meaning*，本义“所意欲表达的东西”，引申为“意义；意思”。
- **同根词**：mean（意欲、表示：单纯词）、meaningful（meaning + **-ful** …的：有意义的）、meaningless（meaning + **-less** 无…的：无意义的）、meaningly（meaning + **-ly** 副词：意味深长地）。
- **前缀·后缀**：无前缀；名词后缀 **-ing**（例：building, feeling）。
- **同义·反义**：同义 sense（意义）, significance（重要性）；反义 nonsense（无意义的话）。
- **变形**：名词 → 复数：meanings；形容词派生 → meaningful adj. 有意义的；meaningless adj. 无意义的；副词派生 → meaningly adv. 意味深长地。

### 14. immediately /ˌɪˈmiˌdiətli/ adv. 立即；马上；立刻
- **词根·渊源**：拉丁 **in-**（不）+ **medi-**（中间）+ **-ate**（形容词后缀）→ 拉丁 *immediatus*（无间隔的）→ 英语 *immediate* + **-ly**，本义“无中间间隔地”，引申为“立即；马上”。
- **同根词**：immediate（**im-** 不 + medi 中间 + **-ate** …的：立即的）、intermediate（**inter-** 在…之间 + medi 中间 + **-ate** …的：中间的）、medium（medi 中间 + **-um** 名词：媒介）、medieval（medi 中间 + ev 时代 + **-al** …的：中世纪的）。
- **前缀·后缀**：前缀 **im-**（例：impossible, impatient）；副词后缀 **-ly**（例：quickly, happily）。
- **同义·反义**：同义 instantly（立即）, at once（立刻）；反义 later（后来）, eventually（最终）。
- **变形**：副词 → 无比较级（绝对副词，不作比较）；形容词派生 → immediate adj. 立即的；名词派生 → immediacy n. 立即性。

### 15. shy /ʃaɪ/ adj. 羞怯的；腼腆的
- **词根·渊源**：古英语 *sceoh*（羞怯的、易受惊的）→ 中古英语 *shy*，本义“易受惊的”，引申为“羞怯的；腼腆的”。
- **同根词**：shyly（shy + **-ly** 副词：羞怯地）、shyness（shy + **-ness** 名词：羞怯）、shyer（shy + **-er** 比较级：更羞怯的）。
- **前缀·后缀**：无前缀；形容词后缀 **-ly** 构成副词（例：quickly, sadly）。
- **同义·反义**：同义 timid（胆小的）, bashful（害羞的）；反义 bold（大胆的）, confident（自信的）。
- **变形**：形容词 → 比较级：shyer；最高级：shyest；名词派生 → shyness n. 羞怯；副词派生 → shyly adv. 羞怯地。

### 16. case /keɪs/ n. 具体情况；事例
- **词根·渊源**：拉丁 **cas-**（落下）→ 拉丁 *casus*（落下、事件）→ 古法语 *cas* → 英语，本义“落下之事”，引申为“具体情况；事例”。
- **同根词**：casual（cas 落下 + **-ual** …的：偶然的）、occasion（**oc-** 向 + cas 落下 + **-ion** 名词：偶然发生的事→场合）、cascade（cas 落下 + **-ade** 名词：瀑布）。
- **前缀·后缀**：无前缀；名词后缀 **-al** 构成形容词（例：natural, formal）。
- **同义·反义**：同义 instance（实例）, situation（情况）；反义 无。
- **变形**：名词 → 复数：cases；形容词派生 → casual adj. 偶然的；副词派生 → casually adv. 偶然地。

### 17. direct /dɪˈrɛkt/ adj. 直接的
- **词根·渊源**：拉丁 **dis-**（分开）+ **regere**（引导、统治）→ 拉丁 *directus*（引导的、直的）→ 英语，本义“被引导成直线的”，引申为“直接的”。
- **同根词**：direction（direct + **-ion** 名词：方向）、director（direct + **-or** 人：导演；主管）、directly（direct + **-ly** 副词：直接地）、indirect（**in-** 不 + direct 直接：间接的）、correct（**cor-** 一起 + rect 引导 = 引导正→正确的）。
- **前缀·后缀**：前缀 **in-**（例：indirect, invisible）；名词后缀 **-ion**（例：action, collection）。
- **同义·反义**：同义 straight（直接的）, immediate（直接的）；反义 indirect（间接的）, roundabout（迂回的）。
- **变形**：形容词 → 比较级：more direct；最高级：most direct；名词派生 → direction n. 方向；director n. 导演；副词派生 → directly adv. 直接地。

### 18. truly /ˈtruli/ adv. 真诚地
- **词根·渊源**：古英语 *trēowe*（忠实的）→ 中古英语 *true* + **-ly**（副词后缀）→ 英语 *truly*，本义“以忠实的方式”，引申为“真诚地”。
- **同根词**：true（忠实的：单纯词）、truth（true + **-th** 名词：真理）、truthful（truth + **-ful** …的：诚实的）、trust（同源词：信任）。
- **前缀·后缀**：无前缀；副词后缀 **-ly**（例：bravely, kindly）。
- **同义·反义**：同义 sincerely（真诚地）, honestly（诚实地）；反义 falsely（虚假地）, insincerely（不真诚地）。
- **变形**：副词 → 无比较级（绝对副词，不作比较）；形容词派生 → true adj. 真实的；名词派生 → truth n. 真理。

### 19. suppose /səˈpoʊz/ v. 假定；假设
- **词根·渊源**：拉丁 **sup-**（= sub-，在下）+ **pon-**（放置）+ **-se**（= -ere，动词后缀）→ 拉丁 *supponere*（置于下、暗中放入）→ 古法语 *supposer*（假定）→ 英语 suppose；本义“把某想法放在下面作底”，引申为“假定、假设”。
- **同根词**：propose（**pro-** 向前 + pos 放 = 放到前面→提议）、compose（**com-** 一起 + pos 放 = 放在一起→组成）、expose（**ex-** 向外 + pos 放 = 放出去→暴露）、position（pos 放 + **-ition** 名词后缀 = 放置之处→位置）、deposit（**de-** 向下 + pos 放 = 放下→存放；存款）、component（**com-** 一起 + pon 放 + **-ent** 名词后缀 = 放在一起的东西→组成部分）。
- **前缀·后缀**：前缀 **sup-**（例：support, suppress）；动词后缀 **-se**（例：compose, propose）。
- **同义·反义**：同义 assume（假定）, presume（推测）；反义 prove（证明）, verify（证实）。
- **变形**：动词 → 第三人称单数：supposes；过去式：supposed；过去分词：supposed；现在分词：supposing；名词派生 → supposition n. 假定；形容词派生 → supposed adj. 假定的；副词派生 → supposedly adv. 据称。

### 20. behaviour /bɪˈheɪvjər/ n. 行为；举止
- **词根·渊源**：**be-**（加强语气）+ 古英语 **habban**（持有、握住）→ 中古英语 *behaven*（持身、自处）→ behaviour；本义“持身自处的方式”，引申为“行为、举止”。（美式拼写 behavior）
- **同根词**：behave（**be-** 加强 + have 持 = 持身→举止表现）、have（古英语 habban 持有→有）、behavioural（behaviour + **-al** …的 = 行为的）、misbehave（**mis-** 坏 + behave = 行为不端）。
- **前缀·后缀**：前缀 **be-**（例：belong, become）；名词后缀 **-iour**（例：saviour）。
- **同义·反义**：同义 conduct（行为）, manner（举止）；反义 无。
- **变形**：名词 → 复数：behaviours；形容词派生 → behavioural adj. 行为的；副词派生 → behaviourally adv. 在行为上。

### 21. uncomfortable /ənˈkəmfərtəbəl/ adj. 不自在的
- **词根·渊源**：**un-**（不）+ comfort（安慰，源自拉丁 **con-** 加强 + **fort-** 强 + **-able** 能…的）→ uncomfortable；本义“不能得到安慰的”，引申为“不舒服的、不自在的”。
- **同根词**：comfort（**com-** 加强 + fort 强 = 使强大→安慰）、comfortable（comfort + **-able** 能…的 = 舒适的）、fortify（fort 强 + **-ify** 使… = 使坚固→加强）、fortress（fort 强 + **-ress** 名词后缀 = 坚固之地→堡垒）、effort（**ef-** 向外 + fort 强 = 使出力量→努力）。
- **前缀·后缀**：前缀 **un-**（例：unhappy, unfair）；后缀 **-able**（例：comfortable, readable）。
- **同义·反义**：同义 uneasy（不安的）, awkward（尴尬的）；反义 comfortable（舒适的）, relaxed（放松的）。
- **变形**：形容词 → 比较级：more uncomfortable；最高级：most uncomfortable；名词派生 → uncomfortableness n. 不自在；副词派生 → uncomfortably adv. 不自在地。
