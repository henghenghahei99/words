## 二、逐词说文解字

### 1. language /ˈlæŋɡwɪdʒ/ n. 语言
- **词根·渊源**：拉丁 **lingua**（舌头；语言）→ 古法语 *langue*（语言）→ 古法语 *language* → 英语；本义“用舌头发出的东西”，即“语言”。
- **同根词**：linguist（lingu 舌头/语言 + **-ist** 人 = 研究语言的人→语言学家）、linguistic（lingu 语言 + **-istic** …的 = 语言的→语言学的）、bilingual（**bi-** 二 + lingu 语言 + **-al** …的 = 两种语言的→双语的）、lingo（ling 舌头/语言 + **-o** 口语后缀 = 语言→行话/外语）。
- **前缀·后缀**：名词后缀 **-age**（例：marriage, package）；前缀 **bi-**（例：bicycle, bilingual）。
- **同义·反义**：同义 tongue, speech；反义 无。
- **词性变化**：linguistic adj. 语言的；语言学的；bilingual adj. 双语的。

### 2. communication /kəˌmjunɪˈkeʃən/ n. 交流；交际；沟通
- **词根·渊源**：拉丁 **communis**（共同的）→ 拉丁 *communicare*（使共同、分享）→ 古法语 *communication* → 英语；本义“使成为共同”，即“分享信息”→交流、沟通。
- **同根词**：communicate（commun 共同 + **-icate** 动词后缀 = 使共同→交流）、common（commun 共同 + **-on** = 共同的）、community（commun 共同 + **-ity** 名词后缀 = 共同体→社区）、communism（commun 共同 + **-ism** 主义 = 共产主义）。
- **前缀·后缀**：名词后缀 **-ation**（例：information, education）；前缀 **com-**（例：common, community）。
- **同义·反义**：同义 exchange, interaction；反义 silence, isolation。
- **词性变化**：communicate v. 交流；communicative adj. 爱交流的；communication n. 交流。

### 3. ballet /bæˈleɪ/ n. 芭蕾舞剧；芭蕾舞团；芭蕾舞；芭蕾舞曲
- **词根·渊源**：意大利 **ballare**（跳舞）→ 意大利 *balletto*（小舞蹈）→ 法语 *ballet* → 英语；本义“小型的舞蹈表演”，即“芭蕾舞”。
- **同根词**：ball（ball 跳舞 + **-∅** = 舞会→球/舞会）、ballad（ball 跳舞 + **-ad** 名词后缀 = 伴舞的歌→民谣）、ballroom（ball 舞会 + room 房间 = 舞厅）、ballerina（ball 跳舞 + **-erina** 女性后缀 = 女芭蕾舞演员）。
- **前缀·后缀**：名词后缀 **-et**（例：ballet, pocket）；无前缀。
- **同义·反义**：同义 dance, dance drama；反义 无。
- **词性变化**：ballet n. 芭蕾舞；ballet dancer n. 芭蕾舞演员。

### 4. accept /ækˈsɛpt/ v. 接受（建议、邀请等）；收受
- **词根·渊源**：拉丁 **accipere**（接受）→ 拉丁 *acceptare*（反复接受）→ 古法语 *accepter* → 英语；本义“拿过来”，即“接受”。
- **同根词**：acceptable（accept 接受 + **-able** 可…的 = 可接受的）、acceptance（accept 接受 + **-ance** 名词后缀 = 接受）、receive（**re-** 回 + ceive 拿 = 拿回来→收到）、concept（**con-** 共同 + cept 拿 = 共同拿住→概念）。
- **前缀·后缀**：前缀 **ac-**（= ad- 向，例：accept, access）；词根 **cept**（拿，例：accept, concept）。
- **同义·反义**：同义 receive, take；反义 reject, refuse。
- **词性变化**：acceptable adj. 可接受的；acceptance n. 接受；accepted adj. 公认的。

### 5. reject /rɪˈdʒekt/ v. 拒绝接受；不予考虑；否决（提议、建议或请求）
- **词根·渊源**：拉丁 **reicere**（扔回）→ 拉丁 *rejectus*（被扔回的）→ 英语；本义“扔回去”，即“拒绝接受”。
- **同根词**：rejection（reject 拒绝 + **-ion** 名词后缀 = 拒绝）、eject（**e-** 出 + ject 扔 = 扔出去→驱逐）、inject（**in-** 入 + ject 扔 = 扔进去→注射）、project（**pro-** 向前 + ject 扔 = 向前扔→投射/项目）。
- **前缀·后缀**：前缀 **re-**（回，例：return, recall）；词根 **ject**（扔，例：eject, inject）。
- **同义·反义**：同义 refuse, decline；反义 accept, approve。
- **词性变化**：rejection n. 拒绝；rejected adj. 被拒绝的。

### 6. meaning /ˈminɪŋ/ v. 意义；意思
- **词根·渊源**：古英语 **mænan**（意欲、打算）→ 中古英语 *menen* → 英语 *mean* + **-ing**；本义“心中所想”，即“意义、意思”。
- **同根词**：mean（mean 意欲 + **-∅** = 意思是）、meaningful（meaning 意义 + **-ful** 充满…的 = 有意义的）、meaningless（meaning 意义 + **-less** 无…的 = 无意义的）、meant（mean 的过去式/过去分词 = 意味着）。
- **前缀·后缀**：名词后缀 **-ing**（例：meeting, building）；无前缀。
- **同义·反义**：同义 sense, significance；反义 nonsense, meaninglessness。
- **词性变化**：mean v. 意思是；meaningful adj. 有意义的；meaningless adj. 无意义的。

### 7. gesture /'dʒestʃə(r)/ n. 手势，姿势；姿态，表示
- **词根·渊源**：拉丁 **gerere**（携带、表现）→ 拉丁 *gestura*（举止、姿态）→ 中世纪拉丁 *gestura* → 英语；本义“身体的举止”，即“手势、姿态”。
- **同根词**：gesticulate（gest 举止 + **-iculate** 动词后缀 = 做手势→打手势）、digest（**di-** 分开 + gest 携带 = 分开携带→消化）、suggest（**sug-** 在下 + gest 携带 = 在下面携带→建议）、register（**re-** 回 + gist 携带 = 带回记录→登记）。
- **前缀·后缀**：名词后缀 **-ure**（例：gesture, picture）；前缀 **di-**（例：digest, divide）。
- **同义·反义**：同义 sign, signal；反义 无。
- **词性变化**：gesture n. 手势；gesture v. 做手势；gestural adj. 手势的。

### 8. message /ˈmesɪdʒ/ n.（书面或口头的）信息；消息；便条；信；口信
- **词根·渊源**：拉丁 **mittere**（送、派）→ 拉丁 *missus*（被送出的）→ 古法语 *message* → 英语；本义“被送出的东西”，即“消息、信息”。
- **同根词**：messenger（message 消息 + **-er** 人 = 送消息的人→信使）、mission（miss 送 + **-ion** 名词后缀 = 被送出的任务→使命）、submit（**sub-** 在下 + mit 送 = 从下送上→提交）、transmit（**trans-** 穿过 + mit 送 = 送过去→传送）。
- **前缀·后缀**：名词后缀 **-age**（例：message, village）；前缀 **sub-**（例：submit, subway）。
- **同义·反义**：同义 note, information；反义 无。
- **词性变化**：messenger n. 信使；message n. 消息；message v. 发消息。

### 9. bored /bɔːd/ adj. 厌倦的；厌烦的;无聊的
- **词根·渊源**：古英语 **borian**（钻孔）→ 中古英语 *boren* → 英语 *bore* + **-ed**；本义“被钻透的”，引申为“被磨得没意思的”→厌倦的。
- **同根词**：bore（bor 钻 + **-e** = 钻孔→使厌烦）、boring（bor 钻 + **-ing** …的 = 令人厌烦的）、boredom（bore 厌烦 + **-dom** 状态 = 厌倦）、borer（bor 钻 + **-er** 工具 = 钻孔器）。
- **前缀·后缀**：形容词后缀 **-ed**（例：bored, tired）；无前缀。
- **同义·反义**：同义 tired, uninterested；反义 interested, excited。
- **词性变化**：bore v. 使厌烦；boring adj. 令人厌烦的；boredom n. 厌倦。

### 10. part time /pɑːt taɪm/ n. 兼职的；部分时间的
- **同义搭配**：on a part-time basis / part-time work
- **反义搭配**：full time / full-time

### 11. well-dressed /ˌwel ˈdrest/ adj. 穿着考究的；穿着入时的
- **词根·渊源**：古英语 **well**（好地）+ 古法语 *dresser*（整理、准备）→ 英语 *dress* + **-ed**；本义“被整理得好的”，即“穿着考究的”。
- **同根词**：dress（dress 整理 + **-∅** = 整理衣服→穿衣）、dressing（dress 穿衣 + **-ing** 名词后缀 = 穿衣→调料）、dresser（dress 整理 + **-er** 人/物 = 整理者→梳妆台）、well-known（well 好 + known 已知 = 著名的）。
- **前缀·后缀**：副词前缀 **well-**（例：well-dressed, well-known）；形容词后缀 **-ed**（例：dressed, tired）。
- **同义·反义**：同义 smartly dressed, elegant；反义 badly dressed, shabby。
- **词性变化**：dress v. 穿衣；dress n. 连衣裙；dressed adj. 穿好衣服的。

### 12. lady /ˈleɪdi/ n. 女士；夫人；小姐
- **词根·渊源**：古英语 **hlǣfdige**（揉面包的人）→ 中古英语 *lady* → 英语；本义“做面包的女主人”，引申为“女士、夫人”。
- **同根词**：ladylike（lady 女士 + **-like** 像…的 = 淑女的）、ladyship（lady 女士 + **-ship** 身份 = 夫人身份）、lord（hlaf 面包 + weard 看守 = 看守面包的人→主人）、landlady（land 土地 + lady 女主人 = 女房东）。
- **前缀·后缀**：名词后缀 **-y**（例：lady, baby）；无前缀。
- **同义·反义**：同义 woman, madam；反义 gentleman, lord。
- **词性变化**：ladylike adj. 淑女的；ladyship n. 夫人身份。

### 13. sigh /saɪ/ v. 叹气，叹息
- **词根·渊源**：古英语 **sīcan**（叹息）→ 中古英语 *siken* → 英语 *sigh*；本义“呼气声”，即“叹气”。
- **同根词**：sigh（sigh 叹息 + **-∅** = 叹气）、sighing（sigh 叹息 + **-ing** 名词后缀 = 叹息声）、sighingly（sigh 叹息 + **-ing** + **-ly** 副词后缀 = 叹息地）。
- **前缀·后缀**：无前后缀（单纯词）。
- **同义·反义**：同义 groan, moan；反义 无。
- **词性变化**：sigh v. 叹气；sigh n. 叹息；sighing n. 叹息。

### 14. matter /ˈmætər/ n. 怎么了
- **词根·渊源**：拉丁 **materia**（物质、材料）→ 古法语 *matere* → 英语；本义“物质、事情”，引申为“问题、怎么了”。
- **同根词**：material（mater 物质 + **-ial** …的 = 物质的→材料）、maternal（mater 母亲 + **-nal** …的 = 母亲的）、matrix（mater 母亲 + **-ix** 名词后缀 = 母体→矩阵）、matter（mater 物质 + **-∅** = 事情）。
- **前缀·后缀**：名词后缀 **-er**（例：matter, teacher）；无前缀。
- **同义·反义**：同义 problem, issue；反义 无。
- **词性变化**：matter n. 事情；matter v. 要紧；material n. 材料。

### 15. expression /ɪkˈspreʃn/ n. 表情；表示；神色；表达方式
- **词根·渊源**：拉丁 **exprimere**（压出、挤出）→ 拉丁 *expressus* → 古法语 *expression* → 英语；本义“被挤出来的东西”，即“表达、表情”。
- **同根词**：express（**ex-** 出 + press 压 = 压出→表达）、pressure（press 压 + **-ure** 名词后缀 = 压力）、impress（**im-** 入 + press 压 = 压入→使印象深刻）、compress（**com-** 共同 + press 压 = 压在一起→压缩）。
- **前缀·后缀**：前缀 **ex-**（出，例：express, exit）；名词后缀 **-ion**（例：expression, action）。
- **同义·反义**：同义 look, phrase；反义 无。
- **词性变化**：express v. 表达；expressive adj. 富有表情的；expression n. 表情。

### 16. appearance /əˈpɪrəns/ n. 出现，起源；外表；外貌
- **词根·渊源**：拉丁 **apparere**（出现）→ 拉丁 *apparentia* → 古法语 *apparence* → 英语；本义“显现出来”，即“出现、外表”。
- **同根词**：appear（**ap-** 向 + pear 出现 = 出现）、apparent（appar 出现 + **-ent** …的 = 明显的）、disappear（**dis-** 否定 + appear 出现 = 消失）、apparition（appar 出现 + **-ition** 名词后缀 = 幽灵）。
- **前缀·后缀**：前缀 **ap-**（= ad- 向，例：appear, approach）；名词后缀 **-ance**（例：appearance, performance）。
- **同义·反义**：同义 look, arrival；反义 disappearance, absence。
- **词性变化**：appear v. 出现；apparent adj. 明显的；disappear v. 消失。

### 17. impression /ɪmˈpreʃn/ n. 印象，感想；影响，作用
- **词根·渊源**：拉丁 **imprimere**（压入）→ 拉丁 *impressus* → 古法语 *impression* → 英语；本义“被压入的痕迹”，即“印象”。
- **同根词**：impress（**im-** 入 + press 压 = 压入→使印象深刻）、express（**ex-** 出 + press 压 = 压出→表达）、pressure（press 压 + **-ure** 名词后缀 = 压力）、compress（**com-** 共同 + press 压 = 压在一起→压缩）。
- **前缀·后缀**：前缀 **im-**（入，例：impress, import）；名词后缀 **-ion**（例：impression, action）。
- **同义·反义**：同义 feeling, effect；反义 无。
- **词性变化**：impress v. 使印象深刻；impressive adj. 令人印象深刻的；impression n. 印象。

### 18. towards /tɔ:rdz/ adv. 朝；向；对着
- **词根·渊源**：古英语 **tōweard**（朝向）→ 中古英语 *toward* + **-s** 副词后缀 → 英语；本义“朝…方向”，即“朝、向”。
- **同根词**：toward（to 向 + ward 方向 = 朝向）、forward（fore 前 + ward 方向 = 向前）、backward（back 后 + ward 方向 = 向后）、upward（up 上 + ward 方向 = 向上）。
- **前缀·后缀**：副词后缀 **-s**（例：towards, afterwards）；后缀 **-ward**（例：forward, backward）。
- **同义·反义**：同义 toward, to；反义 away from。
- **词性变化**：toward prep. 朝向；towards prep. 朝向。

### 19. hold /hoʊld/ v. 使保持（在某位置）
- **词根·渊源**：古英语 *healdan*（握持、看守、保有）→ 中古英语 *holden*，本义“用手握住、看守”，引申为“使保持在某位置、容纳、举行”；与德语 *halten*（持、停）同源，同出日耳曼语 *haldan*。
- **同根词**：holder（hold + **-er** 者：持有者、支架）、holding（hold + **-ing** 名词化：持有物、股份）、uphold（**up-** 向上 + hold 持 = 举起支持→维护）、withhold（**with-** 反向 + hold 持 = 扣住不给→拒给）、behold（**be-** 加强 + hold 看住 = 注视→看）。
- **前缀·后缀**：名词后缀 **-er**（例：worker, teacher）；**-ing**（例：building, meeting）；前缀 **up-**（例：update）、**with-**（例：withdraw）。
- **同义·反义**：同义 keep, grasp, contain；反义 drop, release。
- **词性变化**：holder n. 持有者；holding n. 持有物；hold n. 握；抓。

### 20. later /ˈleɪtə(r)/ adj. 后来，以后
- **词根·渊源**：古英语 *læt*（迟缓的、晚的）→ 中古英语 *lat* → late + 比较级后缀 **-er**，本义“更晚的”，引申为“后来的、以后的”；与德语 *lass*（懒散的）同源，存疑处在于原始日耳曼语 *lata-* 的具体语义演变。
- **同根词**：late（单纯词：晚的）、latest（late + **-est** 最高级：最晚的→最新的）、lately（late + **-ly** 副词化：最近）、lateness（late + **-ness** 名词化：迟、晚）。
- **前缀·后缀**：比较级后缀 **-er**（例：faster, taller）；**-est**（例：fastest, tallest）；**-ly**（例：quickly, slowly）。
- **同义·反义**：同义 afterwards, subsequently；反义 earlier, before。
- **词性变化**：late adj. 晚的；latest adj. 最新的；lately adv. 最近。

### 21. remind /rɪˈmaɪnd/ v. 提醒；使响起
- **词根·渊源**：**re-**（再、回）+ 古英语 *gemynd*（记忆、心智，与 mind 同源）→ 构成 remind，本义“使再想起”，引申为“提醒”；mind 出自 PIE *men-*（思考），与拉丁 *mens*（心）同源。
- **同根词**：mind（单纯词：心智、介意）、reminder（remind + **-er** 者/物：提醒物、提示）、mindful（mind + **-ful** 充满的：留心的）、mindless（mind + **-less** 无的：无心的）、mention（拉丁 *mens* 心 + **-tion** 名词化：提及，同出 *men-*）。
- **前缀·后缀**：前缀 **re-**（例：return, rebuild）；名词后缀 **-er**（例：teacher, worker）；形容词后缀 **-ful**（例：helpful, useful）。
- **同义·反义**：同义 prompt, jog one's memory；反义 forget, ignore。
- **词性变化**：reminder n. 提醒物；mind n. 心智；mindful adj. 留心的。

### 22. neck /nɛk/ n. 脖子；颈
- **词根·渊源**：古英语 *hnecca*（颈、后颈）→ 中古英语 *nekke*，本义“颈项”，引申为“瓶颈、衣领”；与古高地德语 *hnec*（后颈）同源，原始日耳曼语 *hnekk-* 具体来源存疑。
- **同根词**：necklace（neck 颈 + lace 带子 = 颈带→项链）、necktie（neck 颈 + tie 系带 = 领带）、neckline（neck 颈 + line 线 = 领口线）、neckband（neck 颈 + band 带 = 领圈）、roughneck（rough 粗 + neck 颈 = 粗脖子→粗鲁的人）。
- **前缀·后缀**：无前后缀（单纯词）；复合词中作构词成分（例：necklace, necktie）。
- **同义·反义**：同义 nape, collar；反义 无。
- **词性变化**：necklace n. 项链；necktie n. 领带；neckline n. 领口。

### 23. cross /krɔːs/ v. 使交叉；使交叠
- **词根·渊源**：拉丁 *crux / cruc-*（十字架、十字形）→ 古爱尔兰语 *cros* → 古英语 *cros*，本义“十字架”，引申为“交叉、横穿、使交叠”；与 crux（关键、十字）同源。
- **同根词**：crossing（cross + **-ing** 名词化：交叉点、横渡）、crossroads（cross 交叉 + roads 路 = 十字路口）、across（**a-** 在 + cross 十字 = 横过→穿过）、crucial（cruc 十字 + **-ial** 十字路口的→关键的）、crucify（cruc 十字 + **-ify** 使…：钉十字架）。
- **前缀·后缀**：名词后缀 **-ing**（例：building, meeting）；前缀 **a-**（例：aboard, aside）；动词后缀 **-ify**（例：simplify, beautify）。
- **同义·反义**：同义 intersect, traverse；反义 uncross, separate。
- **词性变化**：crossing n. 交叉点；across prep. 穿过；crucial adj. 关键的。

### 24. nod /nɒd/ v. 点头
- **词根·渊源**：中古英语 *nodden*（点头、打盹），可能源自低地德语 *nudden*（点头），本义“头向下点动”，引申为“点头同意、打盹”；原始日耳曼语来源存疑。
- **同根词**：nodding（nod + **-ing** 名词化/形容词化：点头的）、nodder（nod + **-er** 者：点头者）、noddle（nod 点头 + **-le** 表反复/小称：脑袋，口语）。
- **前缀·后缀**：名词后缀 **-ing**（例：running, meeting）；**-er**（例：runner, teacher）；**-le**（例：sparkle, handle）。
- **同义·反义**：同义 bow, signal；反义 shake（摇头）。
- **词性变化**：nodding n. 点头；nod n. 点头。

### 25. shake /ʃeɪk/ v.（与某人）握手；摇头；摇动，震动
- **词根·渊源**：古英语 *sceacan*（摇动、抖动）→ 中古英语 *shaken*，本义“来回摇动”，引申为“握手、摇头、震动”；与中古低地德语 *schaken*（摇动）同源，原始日耳曼语 *skakan*。
- **同根词**：shaky（shake + **-y** 形容词化：摇晃的）、shaker（shake + **-er** 者/物：摇动者、调酒器）、shaking（shake + **-ing** 名词化：摇动）、handshake（hand 手 + shake 摇 = 握手）、milkshake（milk 奶 + shake 摇 = 摇匀的奶→奶昔）。
- **前缀·后缀**：形容词后缀 **-y**（例：rainy, windy）；名词后缀 **-er**（例：worker, teacher）；**-ing**（例：building, meeting）。
- **同义·反义**：同义 tremble, vibrate, quake；反义 steady, still。
- **词性变化**：shaky adj. 摇晃的；shaker n. 摇动者；shake n. 摇动。

### 26. sure /ʃʊə(r)/ adj.（表示同意）当然；确信；肯定；确信的，肯定的
- **词根·渊源**：拉丁 *securus*（无忧的，**se-** 分开 + cura 关心）→ 古法语 *seur* → 英语 sure，本义“无忧的、安全的”，引申为“确信的、肯定的”；与 secure、cure 同源。
- **同根词**：surely（sure + **-ly** 副词化：确实地）、sureness（sure + **-ness** 名词化：确信）、ensure（**en-** 使 + sure 确信 = 使确信→确保）、insure（**in-** 进入 + sure 安全 = 使进入安全→保险）、assure（**as-** 向 + sure 确信 = 向…保证→使确信）、secure（**se-** 分开 + cure 关心 = 无忧的→安全的）。
- **前缀·后缀**：副词后缀 **-ly**（例：quickly, slowly）；名词后缀 **-ness**（例：kindness, happiness）；前缀 **en-**（例：enable）、**in-**（例：include）、**as-**（例：assist）。
- **同义·反义**：同义 certain, confident；反义 unsure, doubtful。
- **词性变化**：surely adv. 确实地；ensure v. 确保；insure v. 保险；assure v. 保证。
