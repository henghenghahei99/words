## 二、逐词说文解字

### 1. everyday /ˈevrideɪl/ adj. 每天的；日常的
- **词根·渊源**：古英语 **dæg**（白天）→ 中古英语 *day*；every（每一个）+ day（天）复合而成，本义“每一天的”，引申为“日常的、平常的”。
- **同根词**：day（单纯词：白天）、daily（day + **-ly** 每…的：每日的）、today（to + day 这一天→今天）、yesterday（yes- 古义“前” + day 天→昨天）、holiday（holy 神圣 + day 日→圣日→假日）、birthday（birth 出生 + day 日→生日）。
- **前缀·后缀**：无前后缀（复合词，every + day）。
- **同义·反义**：同义 daily（每日的）, ordinary（普通的）；反义 unusual（不寻常的）, special（特别的）。
- **变形**：形容词 → 无比较级（关系形容词，不作比较）；名词派生 → everydayness n. 日常性。

### 2. form /fɔːm/ n. 类型；种类
- **词根·渊源**：拉丁 **forma**（形状、模样）→ 古法语 *forme* → 英语；本义“外形、形状”，由“外形”引申为“形式、种类”，再引申为“表格”。
- **同根词**：formal（form + **-al** …的：正式的）、formation（form + **-ation** 名词后缀：形成）、inform（**in-** 进入 + form 形 = 使成形于心中→通知）、reform（**re-** 再 + form 形 = 重新塑造→改革）、uniform（**uni-** 一 + form 形 = 同一形状→制服）、transform（**trans-** 转变 + form 形 = 变形）。
- **前缀·后缀**：名词后缀 **-ation**（例：information, education）；前缀 **in-**（例：inform）、**re-**（例：reform）。
- **同义·反义**：同义 type（类型）, kind（种类）；反义 无。
- **变形**：名词 → 复数：forms；动词派生 → form v. 形成；形容词派生 → formal adj. 正式的；名词派生 → formation n. 形成。

### 3. journey /ˈdʒɜːni/ n.（尤指长途）旅行
- **词根·渊源**：拉丁 **diurnus**（一天的）→ 古法语 *journee*（一天的行程）→ 英语；本义“一天的路程”，后泛指“旅行、旅程”。
- **同根词**：journal（journ 日 + **-al** 名词后缀：日报→日志）、journalist（journal 日志 + **-ist** 人：写日志的人→记者）、diurnal（拉丁 diurnus 一天的 + **-al** …的：白天的）、adjourn（**ad-** 到 + journ 日 = 定到某日→休会）。
- **前缀·后缀**：名词后缀 **-al**（例：arrival, proposal）；前缀 **ad-**（例：advance）。
- **同义·反义**：同义 trip（旅行）, voyage（航行）；反义 无。
- **变形**：名词 → 复数：journeys；动词派生 → journey v. 旅行；名词派生 → journeyer n. 旅行者。

### 4. drop /drɒp/ n. 滴；水珠
- **词根·渊源**：古英语 **dropa**（一滴）→ 中古英语 *drope* → 英语；本义“一滴水”，引申为“落下、下降”，名词义保留“滴、水珠”。
- **同根词**：droplet（drop + **-let** 小：小滴）、droppings（drop + **-ing** + **-s**：落下的东西→粪便）、drip（与 drop 同源，日耳曼语：滴下）、dribble（与 drip 同源：滴流）。
- **前缀·后缀**：指小后缀 **-let**（例：booklet, piglet）；名词后缀 **-ing**（例：building, meeting）。
- **同义·反义**：同义 droplet（小滴）, bead（水珠）；反义 无。
- **变形**：名词 → 复数：drops；动词派生 → drop v. 落下；第三人称单数：drops；过去式：dropped；过去分词：dropped；现在分词：dropping。

### 5. voice /vɔɪs/ n. 说话声
- **词根·渊源**：拉丁 **vox / voc-**（声音、喊叫）→ 古法语 *voiz* → 英语；本义“声音、喊声”，引申为“说话声、嗓音、发言权”。
- **同根词**：vocal（voc 声 + **-al** …的：嗓音的）、vocabulary（voc 声 + **-abul-** + **-ary** 名词后缀：词汇）、vocation（voc 喊 + **-ation** 名词后缀：召唤→职业）、advocate（**ad-** 向 + voc 喊 = 向…呼喊→提倡）、provoke（**pro-** 向前 + voc 喊 = 向前喊→激怒）、revoke（**re-** 回 + voc 喊 = 喊回→撤销）。
- **前缀·后缀**：前缀 **ad-**（例：advance）、**pro-**（例：produce）、**re-**（例：return）；形容词后缀 **-al**（例：natural）。
- **同义·反义**：同义 sound（声音）, tone（语调）；反义 silence（寂静）。
- **变形**：名词 → 复数：voices；动词派生 → voice v. 表达；形容词派生 → vocal adj. 嗓音的；副词派生 → vocally adv. 口头地。

### 6. eventually /ɪˈventʃuəli/ adv. 最后；终于
- **词根·渊源**：拉丁 **evenire**（发生、结果）→ 拉丁 *eventus*（结果）→ 英语 event（事件）+ **-ual** + **-ly**；本义“作为结果地”，引申为“最终、终于”。
- **同根词**：event（**e-** 出 + vent 来 = 出来的事→事件）、eventual（event + **-ual** …的：最终的）、prevent（**pre-** 前 + vent 来 = 先来→预防）、invent（**in-** 进入 + vent 来 = 想法进来→发明）、convention（**con-** 共同 + vent 来 + **-ion** 名词后缀：共同来到→会议、惯例）、adventure（**ad-** 向 + vent 来 + **-ure** 名词后缀：来临之事→冒险）。
- **前缀·后缀**：前缀 **pre-**（例：prepare）、**in-**（例：include）、**con-**（例：connect）；副词后缀 **-ly**（例：quickly, happily）。
- **同义·反义**：同义 finally（最后）, ultimately（最终）；反义 initially（起初）, first（首先）。
- **变形**：副词 → 无比较级；形容词派生 → eventual adj. 最终的；名词派生 → eventuality n. 可能性。

### 7. pipe /paɪp/ n. 管子；管道
- **词根·渊源**：拉丁 **pipare**（啾啾叫）→ 古法语 *pipe*（管乐器）→ 英语；本义“管乐器、哨子”，因管状外形引申为“管子、管道”。
- **同根词**：pipeline（pipe 管 + line 线：管道）、piper（pipe + **-er** 人：吹笛人）、bagpipe（bag 袋 + pipe 管：风笛）、pipette（pipe + **-ette** 小：小管→移液管）。
- **前缀·后缀**：名词后缀 **-er**（例：teacher, worker）；指小后缀 **-ette**（例：cigarette, kitchenette）。
- **同义·反义**：同义 tube（管子）, conduit（导管）；反义 无。
- **变形**：名词 → 复数：pipes；动词派生 → pipe v. 用管道输送；名词派生 → piping n. 管道系统。

### 8. return /rɪˈtɜːn/ v. 回去；返回
- **词根·渊源**：拉丁 **tornare**（车床旋转）→ 古法语 *torner*（转）→ 英语；**re-**（回）+ turn（转），本义“转回来”，引申为“返回、归还”。
- **同根词**：turn（单纯词：转）、turning（turn + **-ing** 名词后缀：转弯处）、returnable（return + **-able** 可…的：可归还的）、turnover（turn 转 + over 过：翻转→营业额）、overturn（**over-** 翻转 + turn 转：推翻）。
- **前缀·后缀**：前缀 **re-**（例：recall, rebuild）、**over-**（例：overcome, overlook）；形容词后缀 **-able**（例：readable, usable）。
- **同义·反义**：同义 come back（回来）, go back（回去）；反义 depart（离开）, leave（离去）。
- **变形**：动词 → 第三人称单数：returns；过去式：returned；过去分词：returned；现在分词：returning；名词派生 → return n. 返回；形容词派生 → returnable adj. 可归还的。

### 9. rush /rʌʃ/ v. 迅速移动
- **词根·渊源**：古法语 **ruser**（击退、匆忙）→ 中古英语 *ruschen* → 英语；本义“猛冲、急行”，引申为“迅速移动、仓促行事”。
- **同根词**：rushing（rush + **-ing** 名词后缀：冲、急流）、rushy（rush + **-y** …的：匆忙的）、brush（与 rush 同源，古法语 brosse：刷子→刷）。
- **前缀·后缀**：名词后缀 **-ing**（例：running, swimming）；形容词后缀 **-y**（例：rainy, windy）。
- **同义·反义**：同义 hurry（匆忙）, dash（猛冲）；反义 dawdle（磨蹭）, linger（逗留）。
- **变形**：动词 → 第三人称单数：rushes；过去式：rushed；过去分词：rushed；现在分词：rushing；名词派生 → rush n. 冲、匆忙。

### 10. bath /bɑːθ/ n. 沐浴；洗澡
- **词根·渊源**：古英语 **bæþ**（洗澡、浴池）→ 中古英语 *bath* → 英语；本义“洗浴、浴池”，引申为“沐浴、洗澡”。
- **同根词**：bathe（bath + **-e** 动词化：洗澡）、bathroom（bath 浴 + room 房间：浴室）、bathtub（bath 浴 + tub 桶：浴缸）、bather（bathe + **-er** 人：洗澡者）。
- **前缀·后缀**：名词后缀 **-room**（例：bedroom, classroom）；动词化后缀 **-e**（例：breathe, clothe）。
- **同义·反义**：同义 shower（淋浴）, washing（洗涤）；反义 无。
- **变形**：名词 → 复数：baths；动词派生 → bathe v. 洗澡；名词派生 → bather n. 洗澡者。

### 11. salt /sɒlt/ adj. 含盐的；咸的
- **词根·渊源**：拉丁 **sal**（盐）→ 古英语 *sealt* → 英语；本义“盐”，形容词义“含盐的、咸的”由名词直接转用。
- **同根词**：salty（salt + **-y** …的：咸的）、saline（拉丁 sal 盐 + **-ine** …的：盐的）、salary（拉丁 sal 盐 + **-ary** 名词后缀：买盐钱→薪水）、salad（拉丁 sal 盐 + **-ad** 名词后缀：加盐的菜→沙拉）、sauce（拉丁 sal 盐 + **-s**：盐水→调味汁）。
- **前缀·后缀**：形容词后缀 **-y**（例：rainy, healthy）；形容词后缀 **-ine**（例：marine, divine）。
- **同义·反义**：同义 salty（咸的）, saline（含盐的）；反义 fresh（淡的）, unsalted（未加盐的）。
- **变形**：形容词 → 比较级：salter；最高级：saltest；名词派生 → salt n. 盐；形容词派生 → salty adj. 咸的。

### 12. brain /breɪn/ n. 脑
- **词根·渊源**：古英语 **brægen**（脑）→ 中古英语 *brain* → 英语；本义“脑髓、大脑”，引申为“智力、头脑”。
- **同根词**：brainy（brain + **-y** …的：聪明的）、brainless（brain + **-less** 无…的：没头脑的）、brainstorm（brain 脑 + storm 风暴：头脑风暴）、brainwash（brain 脑 + wash 洗：洗脑）。
- **前缀·后缀**：形容词后缀 **-y**（例：rainy, cloudy）、**-less**（例：hopeless, careless）。
- **同义·反义**：同义 mind（头脑）, intellect（智力）；反义 无。
- **变形**：名词 → 复数：brains；形容词派生 → brainy adj. 聪明的；brainless adj. 没头脑的。

### 13. public /ˈpʌblɪk/ adj. 公众的；公开的
- **词根·渊源**：拉丁 **publicus**（人民的、公众的）→ 古法语 *public* → 英语；本义“属于人民的”，引申为“公众的、公开的”。
- **同根词**：publicly（public + **-ly** 副词后缀：公开地）、publicity（public + **-ity** 名词后缀：公开性→宣传）、publish（拉丁 publicare 使公开 + **-ish** 动词后缀：出版）、republic（**re-** 事物 + public 公众 = 公共之事→共和国）、publican（public + **-an** 人：收税人→酒馆老板）。
- **前缀·后缀**：名词后缀 **-ity**（例：activity, reality）；动词后缀 **-ish**（例：finish, punish）；前缀 **re-**（例：review, rebuild）。
- **同义·反义**：同义 open（公开的）, communal（公共的）；反义 private（私人的）, secret（秘密的）。
- **变形**：形容词 → 比较级：more public；最高级：most public；名词派生 → public n. 公众；副词派生 → publicly adv. 公开地；名词派生 → publicity n. 宣传。

### 14. population /ˌpɒpjuˈleɪʃn/ n. 人口
- **词根·渊源**：拉丁 **populus**（人民）→ 拉丁 *populatio*（居民）→ 英语；本义“居民、民众”，引申为“人口、种群”。
- **同根词**：populate（popul 人民 + **-ate** 动词后缀：居住于）、popular（popul 人民 + **-ar** …的：人民的→流行的）、populous（popul 人民 + **-ous** 多…的：人口稠密的）、people（拉丁 populus 人民 → 古法语 peuple：人们）。
- **前缀·后缀**：名词后缀 **-ation**（例：information, education）；形容词后缀 **-ar**（例：similar, familiar）、**-ous**（例：famous, dangerous）。
- **同义·反义**：同义 inhabitants（居民）, residents（居民）；反义 无。
- **变形**：名词 → 复数：populations；动词派生 → populate v. 居住于；形容词派生 → popular adj. 流行的；populous adj. 人口稠密的。

### 15. agriculture /ˈæɡrɪkʌltʃə(r)/ n. 农业
- **词根·渊源**：拉丁 **ager / agr-**（田地）+ **cultura**（耕作）→ 拉丁 *agricultura* → 英语；本义“耕种田地”，引申为“农业”。
- **同根词**：agricultural（agriculture + **-al** …的：农业的）、agrarian（agr 田地 + **-arian** …的：土地的）、culture（cult 耕作 + **-ure** 名词后缀：耕作→文化）、cultivate（cult 耕作 + **-ivate** 动词后缀：耕种）、acre（拉丁 ager 田地 → 古英语 æcer：英亩）。
- **前缀·后缀**：名词后缀 **-ure**（例：nature, picture）；形容词后缀 **-al**（例：natural, cultural）。
- **同义·反义**：同义 farming（耕作）, husbandry（农牧业）；反义 industry（工业）。
- **变形**：名词 → 不可数；形容词派生 → agricultural adj. 农业的；副词派生 → agriculturally adv. 农业上。

### 16. trade /treɪd/ n. 贸易；买卖
- **词根·渊源**：中古英语 **trade**（路径、踪迹）→ 英语；本义“道路、轨道”，引申为“行业、手艺”，再引申为“贸易、买卖”（词源存疑，一说与古英语 tredan“踩踏”有关）。
- **同根词**：trader（trade + **-er** 人：商人）、trading（trade + **-ing** 名词后缀：贸易）、tradesman（trade 行业 + **-s** + man 人：商人）、trade-off（trade 交换 + off 离开：权衡）。
- **前缀·后缀**：名词后缀 **-er**（例：teacher, worker）、**-ing**（例：building, meeting）。
- **同义·反义**：同义 commerce（商业）, business（生意）；反义 无。
- **变形**：名词 → 复数：trades；动词派生 → trade v. 交易；第三人称单数：trades；过去式：traded；过去分词：traded；现在分词：trading；名词派生 → trader n. 商人。

### 17. industry /ˈɪndəstri/ n. 工业；生产制造业
- **词根·渊源**：拉丁 **industria**（勤勉、努力）→ 古法语 *industrie* → 英语；本义“勤劳、努力”，引申为“行业、工业”（由“勤奋从事之事”引申）。
- **同根词**：industrial（industry + **-al** …的：工业的）、industrious（industry + **-ous** …的：勤劳的）、industrialize（industrial + **-ize** 动词后缀：使工业化）、industrialization（industrialize + **-ation** 名词后缀：工业化）。
- **前缀·后缀**：形容词后缀 **-al**（例：natural, cultural）、**-ous**（例：famous, dangerous）；动词后缀 **-ize**（例：realize, modernize）。
- **同义·反义**：同义 manufacturing（制造业）, business（行业）；反义 agriculture（农业）。
- **变形**：名词 → 复数：industries；形容词派生 → industrial adj. 工业的；industrious adj. 勤劳的；动词派生 → industrialize v. 使工业化。

### 18. role /rəʊl/ n. 角色
- **词根·渊源**：拉丁 **rotulus**（小卷）→ 古法语 *rolle*（卷轴）→ 英语；本义“卷轴、名单”，因演员台词写在卷轴上，引申为“角色、作用”。
- **同根词**：roll（拉丁 rotulus 卷 → 古法语 roller：卷、滚动）、roller（roll + **-er** 物：滚筒）、enroll（**en-** 使进入 + roll 名单 = 使入名单→登记）、control（**contra-** 相反 + roll 卷 = 对照卷册→控制）、rotary（拉丁 rota 轮 + **-ary** …的：旋转的）。
- **前缀·后缀**：前缀 **en-**（例：enable, enlarge）、**contra-**（例：contrast, contradict）；名词后缀 **-er**（例：teacher, worker）。
- **同义·反义**：同义 part（角色）, function（作用）；反义 无。
- **变形**：名词 → 复数：roles；动词派生 → role-play v. 角色扮演。

### 19. goods /ɡʊdz/ n. 商品；货品
- **词根·渊源**：古英语 **gōd**（好的、合适的）→ 中古英语 *goods* 由形容词“好的”名词化，本义“好的东西、合适之物”，后专指“财产、货物、商品”。
- **同根词**：good（古英语 gōd 好的→好的）、goodly（good + **-ly** …的：好看的、可观的）、goodness（good + **-ness** 性质：善良、美德）、best（古英语 betst，good 的最高级：最好的）。
- **前缀·后缀**：名词复数后缀 **-s**（例：books, pens）；无前缀。
- **同义·反义**：同义 merchandise（商品）, wares（货物）；反义 无。
- **变形**：名词 → 复数：goods（作“商品”义时只用复数）；形容词派生 → good adj. 好的；副词派生 → well adv. 好地。

### 20. overseas /ˌəʊvəˈsiːz/ adv. 在国外；向海外
- **词根·渊源**：**over-**（越过）+ **sea**（海）+ **-s**（副词性属格后缀）→ 本义“越过海地”，即“在海外、向国外”。
- **同根词**：sea（古英语 sǣ 海→海）、seaside（sea + side 边：海滨）、seaman（sea + man 人：海员）、seafood（sea + food 食物：海产食品）、oversea（over + sea：海外的，较少用）。
- **前缀·后缀**：前缀 **over-**（例：overcome, overcoat）；后缀 **-s** 构成副词（例：besides, upwards）。
- **同义·反义**：同义 abroad（在国外）, offshore（在海外）；反义 domestically（在国内）, at home（在国内）。
- **变形**：副词 → 无比较级；形容词派生 → overseas adj. 海外的（如 overseas students）。

### 21. global /ˈɡləʊbl/ adj. 全球的；全世界的
- **词根·渊源**：拉丁 **globus**（球、球体）→ 法语 *globe* → 英语 **globe**（地球、球体）+ **-al**（…的）→ 本义“球体的”，引申为“全球的、全世界的”。
- **同根词**：globe（拉丁 globus 球→地球、球体）、globular（globe + **-ular** 小球状的：球形的）、globally（global + **-ly** 地：全球地）、globalize（global + **-ize** 使…化：使全球化）、globalization（globalize + **-ation** 名词化：全球化）。
- **前缀·后缀**：形容词后缀 **-al**（例：natural, national）；副词后缀 **-ly**（例：globally, happily）。
- **同义·反义**：同义 worldwide（全世界的）, universal（普遍的）；反义 local（地方的）, regional（地区的）。
- **变形**：形容词 → 无比较级（关系形容词，不作比较）；副词派生 → globally adv. 全球地；动词派生 → globalize v. 使全球化；名词派生 → globalization n. 全球化。

### 22. income /ˈɪnkʌm/ n. 收入；收益；所得
- **词根·渊源**：**in-**（进入）+ **come**（来）→ 本义“进来的东西”，即“收入、所得”，与“支出（outgo）”相对。
- **同根词**：come（古英语 cuman 来→来）、outcome（out 出 + come 来：结果）、income tax（income + tax 税：所得税）、coming（come + **-ing** 名词化：到来）、incoming（in + come + **-ing**：进来的）。
- **前缀·后缀**：前缀 **in-**（例：inside, income）；无后缀（复合词）。
- **同义·反义**：同义 earnings（收入）, revenue（收益）；反义 expense（支出）, expenditure（开销）。
- **变形**：名词 → 复数：incomes；形容词派生 → incoming adj. 进来的。

### 23. nearly /ˈnɪəli/ adv. 几乎；差不多；将近
- **词根·渊源**：古英语 **nēar**（更近，near 的比较级）+ **-lice / -ly**（副词后缀）→ 本义“靠近地”，引申为“几乎、差不多”。
- **同根词**：near（古英语 nēar 更近→近的）、nearby（near + by 在旁：附近的）、nearest（near + **-est** 最高级：最近的）、nearness（near + **-ness** 性质：接近）。
- **前缀·后缀**：副词后缀 **-ly**（例：quickly, happily）；无前缀。
- **同义·反义**：同义 almost（几乎）, about（大约）；反义 exactly（确切地）, completely（完全地）。
- **变形**：副词 → 比较级：more nearly；最高级：most nearly；形容词派生 → near adj. 近的。

### 24. business /ˈbɪznəs/ n. 买卖；生意
- **词根·渊源**：古英语 **bisig**（忙碌的）→ busy（忙的）+ **-ness**（名词后缀）→ 本义“忙碌的状态”，后指“所忙之事”，引申为“事务、生意、买卖”。
- **同根词**：busy（古英语 bisig 忙→忙的）、busily（busy + **-ly** 地：忙碌地）、busyness（busy + **-ness** 状态：忙碌）、businessman（business + man 人：商人）。
- **前缀·后缀**：名词后缀 **-ness**（例：happiness, kindness）；无前缀。
- **同义·反义**：同义 trade（贸易）, commerce（商业）；反义 无。
- **变形**：名词 → 复数：businesses；形容词派生 → busy adj. 忙的；副词派生 → busily adv. 忙碌地。

### 25. leisure /ˈleʒə(r)/ n. 闲暇；空闲；休闲
- **词根·渊源**：拉丁 **licēre**（被允许）→ 古法语 *leisir*（空闲、许可）→ 英语 leisure，本义“被允许自由支配的时间”，即“闲暇”。
- **同根词**：leisurely（leisure + **-ly** …地：悠闲地）、leisured（leisure + **-ed** 有…的：有闲的）、license（拉丁 licēre 被允许 + **-ence**：许可）。
- **前缀·后缀**：名词后缀 **-ure**（例：pleasure, culture）；无前缀。
- **同义·反义**：同义 free time（空闲时间）, relaxation（放松）；反义 work（工作）, labor（劳作）。
- **变形**：名词 → 不可数；形容词派生 → leisurely adj. 悠闲的；副词派生 → leisurely adv. 悠闲地。

### 26. throughout /θruːˈaʊt/ prep. 自始至终；贯穿整个时期
- **词根·渊源**：**through**（穿过）+ **out**（出、遍）→ 本义“穿遍、遍及”，引申为“贯穿整个时期、自始至终”。
- **同根词**：through（古英语 þurh 穿过→穿过）、out（古英语 ūt 出→出）、throughout（through + out：遍及）、throughway（through + way 路：直通道路）。
- **前缀·后缀**：无前后缀（复合词，由 through + out 构成）。
- **同义·反义**：同义 all through（贯穿）, during（在…期间）；反义 无。
- **变形**：介词 → 无形态变化；副词派生 → throughout adv. 遍及、始终。

### 27. duty /ˈdjuːti/ n. 责任；义务
- **词根·渊源**：古法语 **deu**（应得的，拉丁 dēbēre“欠、应当”的过去分词）+ **-ty**（名词后缀）→ 本义“应得之物、应尽之事”，即“责任、义务”。
- **同根词**：due（拉丁 dēbēre 欠→应付的）、debt（拉丁 dēbēre 欠→债务）、dutiful（duty + **-ful** 充满…的：尽职的）、dutiable（duty + **-able** 可…的：应缴税的）。
- **前缀·后缀**：名词后缀 **-ty**（例：safety, beauty）；无前缀。
- **同义·反义**：同义 responsibility（责任）, obligation（义务）；反义 无。
- **变形**：名词 → 复数：duties；形容词派生 → dutiful adj. 尽职的；副词派生 → dutifully adv. 尽职地。
