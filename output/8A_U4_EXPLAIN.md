## 二、逐词说文解字

### 1. balloon /bəˈlun/ n. 气球
- **词根·渊源**：意大利 **ballone**（大球）→ 法语 *ballon* → 英语；源自日耳曼语 *ball*（球），本义“大球”，后指充气气球。
- **同根词**：ball（球）、balloonist（balloon + **-ist** 人：气球驾驶员）、ballooning（balloon + **-ing** 活动：乘气球飞行）。
- **前缀·后缀**：名词后缀 **-oon**（例：cartoon, lagoon）。
- **同义·反义**：同义 airship（飞艇）；反义 无。
- **变形**：名词 → 复数：balloons；动词派生 → balloon v. 膨胀；名词派生 → balloonist n. 气球驾驶员。

### 2. wheel /wil/ n. 轮；车轮
- **词根·渊源**：古英语 **hweol**（轮子）→ 中古英语 *wheel* → 英语；与古诺斯语 *hjōl* 同源，本义“圆形转动之物”。
- **同根词**：wheelchair（wheel + chair 椅子：轮椅）、wheelbarrow（wheel + barrow 手推车：独轮车）、wheeler（wheel + **-er** 物：有轮之物）。
- **前缀·后缀**：无前后缀（单纯词）。
- **同义·反义**：同义 tire（轮胎）；反义 无。
- **变形**：名词 → 复数：wheels；动词派生 → wheel v. 推动；形容词派生 → wheeled adj. 有轮的。

### 3. central /ˈsɛntrəl/ adj. 在中心的
- **词根·渊源**：拉丁 **centrum**（中心）→ 拉丁 *centralis* → 法语 *central* → 英语；本义“属于中心的”，引申为“主要的”。
- **同根词**：center（中心）、centralize（central + **-ize** 使……化：集中）、centrally（central + **-ly** 地：在中心地）、eccentric（**ec-** 出 + centr 中心 = 偏离中心的→古怪的）。
- **前缀·后缀**：形容词后缀 **-al**（例：natural, formal）。
- **同义·反义**：同义 middle（中间的）, main（主要的）；反义 peripheral（外围的）, outer（外部的）。
- **变形**：形容词 → 无比较级（关系形容词）；名词派生 → center n. 中心；副词派生 → centrally adv. 在中心地；动词派生 → centralize v. 集中。

### 4. although /ˌɔlˈðoʊ/ conj. 虽然；尽管；即使
- **词根·渊源**：中古英语 **al thogh**（尽管全部）→ 英语；由 all（全部）+ though（虽然）合成，本义“即使全部如此”，引申为“虽然”。
- **同根词**：though（虽然）、all（全部）、even（甚至，与 although 同义用法）。
- **前缀·后缀**：无前后缀（复合词）。
- **同义·反义**：同义 though（虽然）, even though（即使）；反义 无。
- **变形**：连词 → 无形态变化。

### 5. attach /əˈtæʧ/ v. 把……固定；把……附(在……上)
- **词根·渊源**：古法语 **atachier**（固定）→ 英语；源自古法语 *estachier*（钉住），本义“用钉固定”，引申为“附着”。
- **同根词**：attachment（attach + **-ment** 名词：附件）、detach（**de-** 去除 + tach 固定 = 分开→拆卸）、attachable（attach + **-able** 可……的：可附上的）。
- **前缀·后缀**：动词前缀 **at-**（例：attend, attract）；名词后缀 **-ment**（例：movement, agreement）。
- **同义·反义**：同义 fasten（固定）, connect（连接）；反义 detach（拆卸）, separate（分开）。
- **变形**：动词 → 第三人称单数：attaches；过去式：attached；过去分词：attached；现在分词：attaching；名词派生 → attachment n. 附件。

### 6. pull /pʊl/ v. 拉；拽；扯；拖
- **词根·渊源**：古英语 **pullian**（拔、拉）→ 中古英语 *pullen* → 英语；本义“拔除”，引申为“拉、拖”。
- **同根词**：pullover（pull + over 越过：套头衫）、pullback（pull + back 向后：撤退）、puller（pull + **-er** 人/物：拉的人）。
- **前缀·后缀**：无前后缀（单纯词）。
- **同义·反义**：同义 drag（拖）, draw（拉）；反义 push（推）。
- **变形**：动词 → 第三人称单数：pulls；过去式：pulled；过去分词：pulled；现在分词：pulling；名词派生 → pull n. 拉力。

### 7. international /ˌɪnərˈnæʃənɑl/ adj. 国际的
- **词根·渊源**：拉丁 **inter**（在……之间）+ **natio**（出生、民族）→ 法语 *international* → 英语；本义“民族之间的”，引申为“国际的”。
- **同根词**：nation（民族）、national（nation + **-al** 的：国家的）、internationally（international + **-ly** 地：国际地）、interact（**inter-** 之间 + act 行动 = 互动）。
- **前缀·后缀**：前缀 **inter-**（例：interact, internet）；形容词后缀 **-al**（例：natural, national）。
- **同义·反义**：同义 global（全球的）, worldwide（全世界的）；反义 national（国家的）, domestic（国内的）。
- **变形**：形容词 → 无比较级（关系形容词）；名词派生 → international n. 国际比赛；副词派生 → internationally adv. 国际地。

### 8. path /pæθ/ n. 小路；小径
- **词根·渊源**：古英语 **pæþ**（小路）→ 中古英语 *path* → 英语；与德语 *Pfad* 同源，本义“行走的小道”。
- **同根词**：pathway（path + way 路：路径）、footpath（foot 脚 + path 路：人行道）、pathless（path + **-less** 无……的：无路的）。
- **前缀·后缀**：无前后缀（单纯词）。
- **同义·反义**：同义 trail（小径）, track（小道）；反义 无。
- **变形**：名词 → 复数：paths；形容词派生 → pathless adj. 无路的。

### 9. technique /tɛkˈnik/ n. 技巧；技艺
- **词根·渊源**：希腊 **tekhnē**（技艺）→ 拉丁 *technicus* → 法语 *technique* → 英语；本义“技艺”，引申为“技巧”。
- **同根词**：technical（techn + **-ical** 的：技术的）、technology（techn + **-ology** 学：技术学）、technician（techn + **-ician** 人：技术员）。
- **前缀·后缀**：名词后缀 **-ique**（例：unique, antique）。
- **同义·反义**：同义 skill（技能）, method（方法）；反义 无。
- **变形**：名词 → 复数：techniques；形容词派生 → technical adj. 技术的。

### 10. depend /dɪˈpɛnd/ v. 需要；依靠
- **词根·渊源**：拉丁 **dependere**（悬挂于）→ 古法语 *dependre* → 英语；**de-** 下 + **pend** 悬挂，本义“悬挂于下”，引申为“依靠”。
- **同根词**：dependent（depend + **-ent** 的：依赖的）、dependence（depend + **-ence** 名词：依赖）、independent（**in-** 不 + dependent 依赖的 = 独立的）、pendant（pend 悬挂 + **-ant** 物：吊坠）。
- **前缀·后缀**：前缀 **de-**（例：descend, depart）；动词后缀 **-pend**（例：suspend, expend）。
- **同义·反义**：同义 rely（依靠）, count on（指望）；反义 无。
- **变形**：动词 → 第三人称单数：depends；过去式：depended；过去分词：depended；现在分词：depending；名词派生 → dependence n. 依赖；形容词派生 → dependent adj. 依赖的。

### 11. doubt /daʊt/ n. 疑惑；疑问
- **词根·渊源**：拉丁 **dubitare**（犹豫）→ 古法语 *douter* → 英语；本义“在两者间摇摆”，引申为“怀疑”。
- **同根词**：doubtful（doubt + **-ful** 充满……的：怀疑的）、doubtless（doubt + **-less** 无……的：无疑的）、dubious（拉丁 dub 二 + **-ious** 的：可疑的）。
- **前缀·后缀**：名词后缀 **-t**（例：flight, gift）。
- **同义·反义**：同义 uncertainty（不确定）, question（疑问）；反义 certainty（确定）, confidence（信心）。
- **变形**：名词 → 复数：doubts；动词派生 → doubt v. 怀疑；形容词派生 → doubtful adj. 怀疑的；副词派生 → doubtfully adv. 怀疑地。

### 12. personally /ˈpərsənəli/ adv. 就个人意见
- **词根·渊源**：拉丁 **persona**（面具、人）→ 拉丁 *personalis* → 英语 *personal* + **-ly**；本义“以个人身份”，引申为“就个人意见”。
- **同根词**：person（人）、personal（person + **-al** 的：个人的）、personality（personal + **-ity** 名词：个性）、personify（person + **-ify** 使……化：拟人化）。
- **前缀·后缀**：副词后缀 **-ly**（例：quickly, happily）；形容词后缀 **-al**（例：natural, formal）。
- **同义·反义**：同义 individually（个人地）, privately（私下地）；反义 publicly（公开地）, impersonally（非个人地）。
- **变形**：副词 → 无比较级（派生副词）；形容词派生 → personal adj. 个人的；名词派生 → person n. 人。

### 13. statement /ˈsteɪtmənt/ n. 说明
- **词根·渊源**：拉丁 **stare**（站立）→ 古法语 *estat* → 英语 *state* + **-ment**；本义“站立陈述之事”，引申为“说明”。
- **同根词**：state（陈述）、stately（state + **-ly** 的：庄严的）、statemented（statement + **-ed** 的：有说明的）、statist（state + **-ist** 人：统计学家）。
- **前缀·后缀**：名词后缀 **-ment**（例：movement, agreement）。
- **同义·反义**：同义 declaration（声明）, announcement（公告）；反义 无。
- **变形**：名词 → 复数：statements；动词派生 → state v. 陈述；形容词派生 → stately adj. 庄严的。

### 14. benefit /ˈbɛnəfɪt/ n. 益处；优势
- **词根·渊源**：拉丁 **benefactum**（善行）→ 古法语 *benefet* → 英语；**bene-** 好 + **fac** 做，本义“做好事”，引申为“益处”。
- **同根词**：beneficial（benefit + **-ial** 的：有益的）、beneficiary（benefit + **-ary** 人：受益人）、benefit（bene + fit 做：益处）、benevolent（bene 好 + vol 意愿 + **-ent** 的：仁慈的）。
- **前缀·后缀**：前缀 **bene-**（例：benefactor, benevolent）；词根 **-fit**（例：profit, effect）。
- **同义·反义**：同义 advantage（优势）, profit（利润）；反义 harm（伤害）, disadvantage（劣势）。
- **变形**：名词 → 复数：benefits；动词派生 → benefit v. 受益；形容词派生 → beneficial adj. 有益的。

### 15. wing /wɪŋ/ n. (飞行器的)翅膀；机翼
- **词根·渊源**：古诺斯语 **vængr**（翅膀）→ 中古英语 *winge* → 英语；本义“鸟翼”，引申为“机翼”。
- **同根词**：winged（wing + **-ed** 有……的：有翼的）、wingless（wing + **-less** 无……的：无翼的）、winger（wing + **-er** 人：边锋）。
- **前缀·后缀**：无前后缀（单纯词）。
- **同义·反义**：同义 无；反义 无。
- **变形**：名词 → 复数：wings；形容词派生 → winged adj. 有翼的。

### 16. distance /ˈdɪstəns/ n. 距离
- **词根·渊源**：拉丁 **distare**（相隔）→ 古法语 *distance* → 英语；**dis-** 分开 + **sta** 站，本义“分开站立”，引申为“距离”。
- **同根词**：distant（dist + **-ant** 的：远的）、distant（distance 的形容词）、equidistant（**equi-** 相等 + distant 远的：等距的）、stand（sta 站：站立）。
- **前缀·后缀**：前缀 **dis-**（例：disagree, discover）；名词后缀 **-ance**（例：importance, performance）。
- **同义·反义**：同义 gap（间隔）, space（空间）；反义 closeness（接近）, nearness（近）。
- **变形**：名词 → 复数：distances；形容词派生 → distant adj. 远的。

### 17. petrol /ˈpɛtroʊl/ n. 汽油
- **词根·渊源**：拉丁 **petra**（石头）+ **oleum**（油）→ 法语 *pétrole* → 英语；本义“石头的油”，即石油，引申为“汽油”。
- **同根词**：petroleum（petr 石 + oleum 油：石油）、petrology（petr 石 + **-ology** 学：岩石学）、petrify（petr 石 + **-ify** 使……化：石化）。
- **前缀·后缀**：词根 **petr-**（例：petroleum, petrify）；名词后缀 **-ol**（例：alcohol, phenol）。
- **同义·反义**：同义 gasoline（汽油）, fuel（燃料）；反义 无。
- **变形**：名词 → 不可数；形容词派生 → petroliferous adj. 含石油的。

### 18. avoid /əˈvɔɪd/ v. 避免；防止
- **词根·渊源**：古法语 **esvuidier**（清空）→ 中古英语 *avoiden* → 英语；**a-** 出 + **void** 空，本义“清空、离开”，引申为“避免”。
- **同根词**：avoidance（avoid + **-ance** 名词：避免）、avoidable（avoid + **-able** 可……的：可避免的）、void（空）、devoid（**de-** 完全 + void 空 = 缺乏的）。
- **前缀·后缀**：前缀 **a-**（例：aloud, awake）；词根 **void**（例：void, devoid）。
- **同义·反义**：同义 prevent（防止）, escape（逃避）；反义 face（面对）, confront（面对）。
- **变形**：动词 → 第三人称单数：avoids；过去式：avoided；过去分词：avoided；现在分词：avoiding；名词派生 → avoidance n. 避免；形容词派生 → avoidable adj. 可避免的。

### 19. anywhere /ˈɛniˌwɛr/ adv. 在 (或去)任何地方
- **词根·渊源**：古英语 **ænig**（任何）+ **hwær**（何处）→ 中古英语 *anywhere*，本义“在任何地方”，引申为“在/去任何地方”。
- **同根词**：any（古英语 ænig 任何→任何一个）、anyone（any + one 人 = 任何人）、anything（any + thing 事物 = 任何事物）、anyway（any + way 方式 = 无论如何）、anyhow（any + how 方式 = 不管怎样）、somewhere（some 某 + where 何处 = 某处）、everywhere（every 每 + where 何处 = 到处）、nowhere（no 无 + where 何处 = 无处）。
- **前缀·后缀**：复合词由 any + where 构成，无典型前后缀（例：anyone, somewhere）。
- **同义·反义**：同义 wherever（无论何处）, everywhere（到处）；反义 nowhere（无处）。
- **变形**：副词 → 无比较级（地点副词，不作比较）。

### 20. notice /ˈnoʊtɪs/ v. 看(或听)到；注意到
- **词根·渊源**：拉丁 **notus**（已知的，源自 *noscere* 知道）→ 古法语 *notice*（通知、知识）→ 英语，本义“得知、知晓”，引申为“注意到”。
- **同根词**：notion（not 知道 + **-ion** 名词后缀 = 所知→概念）、notify（not 知道 + **-ify** 使 = 使知道→通知）、notable（not 知道 + **-able** 可…的 = 值得知道的→显著的）、notation（not 知道 + **-ation** 名词后缀 = 标记→记号）、notorious（not 知道 + **-orious** 形容词后缀 = 众所周知的→臭名昭著的）、annotate（**an-** 加 + not 知道 + **-ate** 动词后缀 = 加注→注释）。
- **前缀·后缀**：动词后缀 **-ify**（例：simplify, classify）；名词后缀 **-ion**（例：action, nation）。
- **同义·反义**：同义 observe（注意到）, perceive（察觉）；反义 ignore（忽视）, overlook（忽略）。
- **变形**：动词 → 第三人称单数：notices；过去式：noticed；过去分词：noticed；现在分词：noticing；名词派生 → notice n. 通知、注意；形容词派生 → noticeable adj. 显著的；副词派生 → noticeably adv. 显著地。

### 21. type /taɪp/ n. (印刷用的)活字
- **词根·渊源**：希腊 **typos**（打击、印记）→ 拉丁 *typus*（形象、印记）→ 古法语 *type* → 英语，本义“打出的印记”，引申为“活字、类型”。
- **同根词**：typical（typ 印记 + **-ical** 形容词后缀 = 有印记特征的→典型的）、typify（typ 印记 + **-ify** 使 = 使成为典型→代表）、typist（typ 打字 + **-ist** 人 = 打字员）、typewriter（type 打字 + writer 书写者 = 打字机）、prototype（**proto-** 原始 + type 类型 = 原型）、stereotype（**stereo-** 固定 + type 印记 = 固定印记→刻板印象）。
- **前缀·后缀**：前缀 **proto-**（例：protocol, protagonist）、**stereo-**（例：stereophonic）；名词后缀 **-ist**（例：artist, scientist）。
- **同义·反义**：同义 kind（种类）, sort（类别）；反义 无。
- **变形**：名词 → 复数：types；动词派生 → type v. 打字；形容词派生 → typical adj. 典型的；副词派生 → typically adv. 典型地。

### 22. heat /hit/ v. 加热；变热
- **词根·渊源**：古英语 **hǣtu**（热）→ 中古英语 *hete* → 英语，本义“热的状态”，动词化后表示“加热”。
- **同根词**：hot（古英语 hat 热的→热的）、heater（heat 加热 + **-er** 物 = 加热器）、heating（heat 加热 + **-ing** 名词后缀 = 供暖）、heated（heat 加热 + **-ed** 形容词后缀 = 加热的→激烈的）、overheat（**over-** 过度 + heat 加热 = 过热）、preheat（**pre-** 预先 + heat 加热 = 预热）。
- **前缀·后缀**：前缀 **over-**（例：overcome, overdo）、**pre-**（例：preview, prepare）；名词后缀 **-er**（例：teacher, worker）。
- **同义·反义**：同义 warm（使温暖）, warm up（加热）；反义 cool（冷却）, freeze（冻结）。
- **变形**：动词 → 第三人称单数：heats；过去式：heated；过去分词：heated；现在分词：heating；名词派生 → heat n. 热、高温；形容词派生 → heated adj. 加热的、激烈的；副词派生 → heatedly adv. 激烈地。

### 23. press /prɛs/ v. (被) 压
- **词根·渊源**：拉丁 **premere**（压）→ 古法语 *presser* → 英语，本义“压、挤”，引申为“按压、印刷”。
- **同根词**：pressure（press 压 + **-ure** 名词后缀 = 压力）、pressing（press 压 + **-ing** 形容词后缀 = 紧迫的）、compress（**com-** 一起 + press 压 = 压在一起→压缩）、express（**ex-** 出 + press 压 = 压出→表达）、impress（**im-** 进入 + press 压 = 压入→使印象深刻）、depress（**de-** 向下 + press 压 = 压下→使沮丧）、suppress（**sup-** 向下 + press 压 = 压下→镇压）。
- **前缀·后缀**：前缀 **com-**（例：combine, compare）、**ex-**（例：export, exit）、**de-**（例：decrease, defend）；名词后缀 **-ure**（例：failure, mixture）。
- **同义·反义**：同义 push（推压）, squeeze（挤压）；反义 release（松开）, pull（拉）。
- **变形**：动词 → 第三人称单数：presses；过去式：pressed；过去分词：pressed；现在分词：pressing；名词派生 → press n. 新闻界、印刷机；pressure n. 压力；形容词派生 → pressing adj. 紧迫的；副词派生 → pressingly adv. 紧迫地。

### 24. metal /ˈmɛtəl/ n. 金属
- **词根·渊源**：希腊 **metallon**（矿、金属）→ 拉丁 *metallum*（金属、矿）→ 古法语 *metal* → 英语，本义“矿藏”，引申为“金属”。
- **同根词**：metallic（metal 金属 + **-ic** 形容词后缀 = 金属的）、metallurgy（metal 金属 + **-urgy** 工艺 = 冶金学）、metalloid（metal 金属 + **-oid** 像…的 = 类金属）、nonmetal（**non-** 非 + metal 金属 = 非金属）。
- **前缀·后缀**：前缀 **non-**（例：nonsense, nonstop）；形容词后缀 **-ic**（例：basic, historic）。
- **同义·反义**：同义 无；反义 nonmetal（非金属）。
- **变形**：名词 → 复数：metals；形容词派生 → metallic adj. 金属的；metalloid adj. 类金属的。
