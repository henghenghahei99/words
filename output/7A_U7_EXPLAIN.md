## 二、逐词说文解字

### 1. literature /ˈlɪtərəʧər/ n. 文学；文学作品
- **词根·渊源**：拉丁 **littera**（字母，文字）→ 拉丁 *litteratura*（书写，文法）→ 古法语 *litterature* → 英语；本义“文字书写之物”，引申为“文学作品”。
- **同根词**：letter（littera 字母→字母→信件）、literal（littera 字母 + **-al** …的 = 按字母的→字面的）、literate（littera 文字 + **-ate** 有…的 = 识字的）、literary（littera 文字 + **-ary** …的 = 文学的）、literacy（literate + **-cy** 名词后缀 = 读写能力）、illiterate（**il-** 不 + literate 识字的 = 文盲的）。
- **前缀·后缀**：名词后缀 **-ure**（例：culture, nature）；形容词后缀 **-ary**（例：military, ordinary）。
- **同义·反义**：同义 letters（文学）, writing（著作）；反义 无。
- **变形**：名词 → 复数：literatures（作“文学”义时不可数）；形容词派生 → literary adj. 文学的；literate adj. 识字的；名词派生 → literacy n. 读写能力。

### 2. act /ækt/ v. 扮演(戏剧、电影中的角色)
- **词根·渊源**：拉丁 **agere / act-**（驱动，做）→ 拉丁 *actus*（行为，表演）→ 古法语 *acte* → 英语；本义“做、行动”，引申为“在舞台上做出动作→扮演”。
- **同根词**：action（act 做 + **-ion** 名词后缀 = 行动）、active（act 做 + **-ive** …的 = 积极的）、actor（act 演 + **-or** 人 = 男演员）、actress（actor + **-ess** 女性 = 女演员）、actual（act 做 + **-ual** …的 = 实际做出的→实际的）、agenda（ag 做 + **-enda** 应做之事 = 议程）。
- **前缀·后缀**：名词后缀 **-or**（例：visitor, doctor）；形容词后缀 **-ive**（例：creative, native）。
- **同义·反义**：同义 perform（表演）, play（扮演）；反义 无。
- **变形**：动词 → 第三人称单数：acts；过去式：acted；过去分词：acted；现在分词：acting；名词 → 复数：acts；名词派生 → action n. 行动；actor n. 男演员；形容词派生 → active adj. 积极的。

### 3. appreciate /əˈpriʃiˌeɪt/ v. 欣赏；赏识
- **词根·渊源**：拉丁 **pretium**（价格，价值）→ 晚期拉丁 *appretiare*（估价）→ 中世纪拉丁 *appreciatus* → 英语；本义“给…估价”，引申为“看出价值→欣赏、赏识”。
- **同根词**：precious（pretium 价值 + **-ous** …的 = 有价值的→珍贵的）、price（pretium 价格→价格）、praise（pretium 价值→古法语 preisier 估价→赞扬）、appraisal（**ap-** 向 + prais 估价 + **-al** 名词后缀 = 评估）、appreciative（appreciate + **-ive** …的 = 表示感激的）、depreciate（**de-** 向下 + pretium 价格 = 降价→贬值）。
- **前缀·后缀**：动词前缀 **ap-**（= ad- 向）（例：approach, approve）；动词后缀 **-ate**（例：celebrate, create）。
- **同义·反义**：同义 value（重视）, admire（欣赏）；反义 despise（轻视）, depreciate（贬低）。
- **变形**：动词 → 第三人称单数：appreciates；过去式：appreciated；过去分词：appreciated；现在分词：appreciating；名词派生 → appreciation n. 欣赏；形容词派生 → appreciative adj. 感激的。

### 4. join /ʤɔɪn/ v. 成为……的一员；参加
- **词根·渊源**：拉丁 **iungere / iunct-**（连接，结合）→ 古法语 *joindre* → 英语；本义“把…连接在一起”，引申为“加入（使自己和团体连在一起）”。
- **同根词**：joint（join 连接 + **-t** = 接合处→关节）、junction（iunct 连接 + **-ion** 名词后缀 = 连接点）、conjunction（**con-** 共同 + iunct 连接 + **-ion** = 连词）、adjoin（**ad-** 向 + join 连接 = 毗连）、subjunctive（**sub-** 下 + iunct 连接 + **-ive** = 虚拟语气的）、yoke（同出 PIE *yeug-* 连接→轭）。
- **前缀·后缀**：动词前缀 **con-**（例：connect, combine）、**ad-**（例：advance, admit）。
- **同义·反义**：同义 enter（加入）, participate（参加）；反义 leave（离开）, quit（退出）。
- **变形**：动词 → 第三人称单数：joins；过去式：joined；过去分词：joined；现在分词：joining；名词派生 → joint n. 关节；junction n. 连接点。

### 5. definitely /ˈdɛfənətli/ adv. 肯定；没问题；当然；确实
- **词根·渊源**：拉丁 **finis**（界限，终点）→ 拉丁 *definire*（划定界限）→ 拉丁 *definitus* → 英语；本义“划定界限地→明确地”，引申为“肯定地、确实”。
- **同根词**：define（**de-** 彻底 + fin 界限 = 划定界限→定义）、definite（define + **-ite** …的 = 明确的）、definition（definite + **-ion** 名词后缀 = 定义）、finish（fin 终点 + **-ish** 动词后缀 = 到终点→完成）、final（fin 终点 + **-al** …的 = 最终的）、infinite（**in-** 不 + fin 界限 + **-ite** = 无限的）。
- **前缀·后缀**：副词后缀 **-ly**（例：quickly, happily）；前缀 **de-**（例：decline, decide）。
- **同义·反义**：同义 certainly（当然）, surely（确实）；反义 doubtfully（怀疑地）, uncertainly（不确定地）。
- **变形**：副词 → 无比较级；形容词派生 → definite adj. 明确的；动词派生 → define v. 定义；名词派生 → definition n. 定义。

### 6. fair /fɛr/ n. 集市
- **词根·渊源**：拉丁 **feriae**（假日，节日）→ 晚期拉丁 *feria* → 古法语 *feire* → 英语；本义“宗教节日”，节日里人们聚在一起交易，引申为“集市”。
- **同根词**：ferial（feriae 节日 + **-al** …的 = 平日的）、festival（同出拉丁 festum 节日 + **-al** = 节日）、festive（festum 节日 + **-ive** …的 = 节日的）、feast（festum 节日→盛宴）、festivity（festive + **-ity** 名词后缀 = 欢庆）。
- **前缀·后缀**：无前后缀（单纯词）。
- **同义·反义**：同义 market（市场）, bazaar（集市）；反义 无。
- **变形**：名词 → 复数：fairs；形容词派生 → fair adj. 公平的（同形异源，存疑）。

### 7. rocket /ˈrɑkət/ n. 火箭
- **词根·渊源**：意大利语 **rocchetta**（纺锤，小卷线轴）→ 法语 *roquette* → 英语；本义“纺锤形的东西”，因早期火箭形似纺锤而得名“火箭”。
- **同根词**：rocquet（rocchetta 纺锤→一种球戏→槌球，存疑）、racket（同源，球拍，存疑）。
- **前缀·后缀**：名词后缀 **-et**（指小）（例：packet, pocket）。
- **同义·反义**：同义 missile（导弹）；反义 无。
- **变形**：名词 → 复数：rockets；动词派生 → rocket v. 飞快移动。

### 8. launch /lɔnʧ/ v. 发射
- **词根·渊源**：拉丁 **lancea**（长矛）→ 古法语 *lancier*（投掷长矛）→ 古北法语 *lancher* → 英语；本义“投掷长矛”，引申为“发射（火箭等）”。
- **同根词**：lance（lancea 长矛→长矛）、lancer（lance + **-er** 人 = 长矛骑兵）、lanceolate（lance 长矛 + **-olate** 形似…的 = 矛尖形的）。
- **前缀·后缀**：无前后缀（单纯词）。
- **同义·反义**：同义 fire（发射）, send off（发射）；反义 recall（召回）, land（着陆）。
- **变形**：动词 → 第三人称单数：launches；过去式：launched；过去分词：launched；现在分词：launching；名词 → 复数：launches；名词派生 → launch n. 发射。

### 9. shout /ʃaʊt/ v. 大声说；叫
- **词根·渊源**：词源存疑；可能源自古诺斯语 *skúta*（嘲弄）或中古英语 *shouten*，与“喊叫”义相关；本义“大声喊”，引申为“大声说、叫”。
- **同根词**：shouting（shout + **-ing** 名词后缀 = 喊叫）、shouter（shout + **-er** 人 = 喊叫者）。
- **前缀·后缀**：无前后缀（单纯词）。
- **同义·反义**：同义 yell（叫喊）, cry（喊叫）；反义 whisper（低语）, murmur（低声说）。
- **变形**：动词 → 第三人称单数：shouts；过去式：shouted；过去分词：shouted；现在分词：shouting；名词 → 复数：shouts；名词派生 → shout n. 喊叫。

### 10. power /paʊər/ n. 力量；能量
- **词根·渊源**：拉丁 **posse / pot-**（能够）→ 古法语 *povoir*（能够）→ 英语；本义“能够做事的能力”，引申为“力量、能量”。
- **同根词**：potent（pot 能够 + **-ent** …的 = 有力的）、potential（potent + **-ial** …的 = 潜在的）、possible（posse 能够 + **-ible** 可…的 = 可能的）、potentate（potent + **-ate** 人 = 有权势者）、omnipotent（**omni-** 全 + potent 能 = 全能的）、impotent（**im-** 不 + potent 能 = 无力的）。
- **前缀·后缀**：名词后缀 **-er**（例：teacher, worker）；前缀 **im-**（例：impossible, impolite）。
- **同义·反义**：同义 strength（力量）, energy（能量）；反义 weakness（虚弱）, impotence（无力）。
- **变形**：名词 → 复数：powers；形容词派生 → powerful adj. 强大的；powerless adj. 无力的；副词派生 → powerfully adv. 强大地。

### 11. moment /ˈmoʊmənt/ n. 片刻；瞬间
- **词根·渊源**：拉丁 **movere / mot-**（移动）→ 拉丁 *momentum*（运动，瞬间）→ 古法语 *moment* → 英语；本义“运动的一瞬”，引申为“片刻、瞬间”。
- **同根词**：momentum（mot 移动 + **-mentum** 名词后缀 = 动量）、move（movere 移动→移动）、motion（mot 移动 + **-ion** 名词后缀 = 运动）、mobile（mot 移动 + **-ile** 可…的 = 可移动的）、motive（mot 移动 + **-ive** …的 = 动机）、promote（**pro-** 向前 + mot 移动 = 促进）。
- **前缀·后缀**：名词后缀 **-ment**（例：movement, development）；前缀 **pro-**（例：progress, produce）。
- **同义·反义**：同义 instant（瞬间）, minute（片刻）；反义 eternity（永恒）。
- **变形**：名词 → 复数：moments；形容词派生 → momentary adj. 瞬间的；副词派生 → momentarily adv. 短暂地。

### 12. member /ˈmɛmbər/ n. 成员
- **词根·渊源**：拉丁 **membrum**（肢体，部分）→ 古法语 *membre* → 英语；本义“身体的一部分”，引申为“团体的一部分→成员”。
- **同根词**：membership（member + **-ship** 身份 = 会员身份）、dismember（**dis-** 分开 + member 肢体 = 肢解）、membrane（membrum 膜 + **-ane** 名词后缀 = 薄膜）。
- **前缀·后缀**：名词后缀 **-ship**（例：friendship, leadership）；前缀 **dis-**（例：dislike, disagree）。
- **同义·反义**：同义 associate（成员）, participant（参与者）；反义 outsider（局外人）, nonmember（非成员）。
- **变形**：名词 → 复数：members；名词派生 → membership n. 会员身份。

### 13. shape /ʃeɪp/ n. 形状；外形
- **词根·渊源**：古英语 **sceppan**（创造，塑造）→ 中古英语 *shapen* → 英语；本义“创造出的样子”，引申为“形状、外形”。
- **同根词**：shapely（shape + **-ly** …的 = 匀称的）、reshape（**re-** 再 + shape 塑造 = 重塑）、shapeless（shape + **-less** 无…的 = 无形状的）。
- **前缀·后缀**：形容词后缀 **-less**（例：careless, hopeless）；前缀 **re-**（例：rebuild, rewrite）。
- **同义·反义**：同义 form（形状）, figure（外形）；反义 无。
- **变形**：名词 → 复数：shapes；动词 → 第三人称单数：shapes；过去式：shaped；过去分词：shaped；现在分词：shaping；形容词派生 → shapely adj. 匀称的；shapeless adj. 无形状的。

### 14. hike /haɪk/ v. 去…远足；做徒步旅行
- **词根·渊源**：词源存疑；可能源自英语方言 *hyke*（用力拉），19世纪出现“长途步行”义；本义“用力行走”，引申为“远足、徒步旅行”。
- **同根词**：hiker（hike + **-er** 人 = 徒步者）、hiking（hike + **-ing** 名词后缀 = 徒步旅行）。
- **前缀·后缀**：名词后缀 **-er**（例：runner, singer）。
- **同义·反义**：同义 trek（长途跋涉）, tramp（徒步）；反义 无。
- **变形**：动词 → 第三人称单数：hikes；过去式：hiked；过去分词：hiked；现在分词：hiking；名词 → 复数：hikes；名词派生 → hiker n. 徒步者；hiking n. 徒步旅行。

### 15. recently /ˈrisəntli/ adv. 不久前；最近
- **词根·渊源**：拉丁 **recens**（新鲜的，新近的）→ 拉丁 *recent-* → 英语 *recent* + **-ly**；本义“新近地”，引申为“不久前、最近”。
- **同根词**：recent（recens 新鲜的→最近的）、recentness（recent + **-ness** 名词后缀 = 新近）。
- **前缀·后缀**：副词后缀 **-ly**（例：lately, quickly）；形容词后缀 **-ent**（例：silent, different）。
- **同义·反义**：同义 lately（最近）, newly（新近）；反义 long ago（很久以前）。
- **变形**：副词 → 无比较级；形容词派生 → recent adj. 最近的；名词派生 → recentness n. 新近。

### 16. attend /əˈtɛnd/ v. 出席；参加
- **词根·渊源**：拉丁 **tendere / tent-**（伸展）→ 拉丁 *attendere*（**ad-** 向 + tendere 伸 = 把心思伸向）→ 古法语 *atendre* → 英语；本义“把注意力伸向”，引申为“出席、参加”。
- **同根词**：attention（**at-** 向 + tent 伸 + **-ion** 名词后缀 = 注意）、attentive（attention + **-ive** …的 = 专注的）、tend（tendere 伸→趋向）、extend（**ex-** 向外 + tend 伸 = 延伸）、intend（**in-** 向内 + tend 伸 = 打算）、tension（tens 伸 + **-ion** = 紧张）。
- **前缀·后缀**：动词前缀 **at-**（= ad- 向）（例：attract, attempt）；动词后缀 **-end**（例：depend, defend）。
- **同义·反义**：同义 participate（参加）, be present at（出席）；反义 absent（缺席）, miss（错过）。
- **变形**：动词 → 第三人称单数：attends；过去式：attended；过去分词：attended；现在分词：attending；名词派生 → attendance n. 出席；attention n. 注意。

### 17. charity /ˈʧɛrɪti/ n. 慈善机构(或组织)
- **词根·渊源**：拉丁 **carus**（亲爱的）→ 拉丁 *caritas*（爱，仁爱）→ 古法语 *charité* → 英语；本义“仁爱之心”，引申为“慈善机构”。
- **同根词**：cherish（carus 亲爱的→古法语 cherir 珍爱→珍爱）、charitable（charity + **-able** 能…的 = 慈善的）、caress（carus 亲爱的→爱抚）。
- **前缀·后缀**：名词后缀 **-ity**（例：activity, ability）。
- **同义·反义**：同义 philanthropy（慈善）, benevolence（仁爱）；反义 cruelty（残忍）, selfishness（自私）。
- **变形**：名词 → 复数：charities；形容词派生 → charitable adj. 慈善的；副词派生 → charitably adv. 慈善地。

### 18. sale /seɪl/ n. 出售；销售
- **词根·渊源**：古英语 **sala**（出售）→ 中古英语 *sale* → 英语；与古诺斯语 *sala* 同源，本义“出售行为”，引申为“销售”。
- **同根词**：sell（sale 同源动词→卖）、seller（sell + **-er** 人 = 卖者）、salesman（sale + **-s** + man 人 = 男售货员）、wholesale（**whole** 整 + sale 卖 = 批发）、retail（**re-** 再 + tail 切 = 零售，存疑）。
- **前缀·后缀**：名词后缀 **-er**（例：buyer, seller）；前缀 **whole-**（例：wholehearted）。
- **同义·反义**：同义 selling（出售）, trade（交易）；反义 purchase（购买）, buying（购买）。
- **变形**：名词 → 复数：sales；动词派生 → sell v. 卖；名词派生 → seller n. 卖者。

### 19. snack /snæk/ n. 点心；小吃
- **词根·渊源**：中古荷兰语 *snacken*（咬，啃）→ 中古英语 *snak*，本义“一口咬下的东西”，引申为“少量食物、小吃”；与 snatch（抓取）可能同源，存疑。
- **同根词**：snack bar（snack 小吃 + bar 柜台 = 小吃店）、snack food（snack + food 食物 = 零食）。
- **前缀·后缀**：无前后缀（单纯词）。
- **同义·反义**：同义 nibble（小吃）, refreshment（茶点）；反义 meal（正餐）, feast（盛宴）。
- **变形**：名词 → 复数：snacks；动词派生 → snack v. 吃零食；snacker n. 吃零食的人。

### 20. decorate /ˈdɛkərˌeɪt/ v. 装饰；装潢
- **词根·渊源**：拉丁 **decus / decor-**（体面、光彩）→ 拉丁 *decorare*（使光彩）→ 拉丁 *decoratus* → 英语 decorate，本义“使光彩体面”，引申为“装饰”。
- **同根词**：decoration（decorate + **-ion** 名词后缀：装饰）、decorative（decorate + **-ive** …的：装饰性的）、decorator（decorate + **-or** 人：装饰者）、decor（decor 光彩→装饰风格）、decorum（decor 体面 + **-um** 名词后缀：礼仪）。
- **前缀·后缀**：动词后缀 **-ate**（例：celebrate, create）；名词后缀 **-ion**（例：action, education）。
- **同义·反义**：同义 adorn（装饰）, ornament（点缀）；反义 strip（剥去）, bare（使赤裸）。
- **变形**：动词 → 第三人称单数：decorates；过去式：decorated；过去分词：decorated；现在分词：decorating；名词派生 → decoration n. 装饰；decorator n. 装饰者；形容词派生 → decorative adj. 装饰性的。

### 21. difference /ˈdɪfərəns/ n. 差别；差异
- **词根·渊源**：拉丁 **dis-**（分开）+ **ferre**（携带）→ 拉丁 *differre*（分开携带→不同）→ 古法语 *difference* → 英语 difference，本义“分开携带的状态”，引申为“差别”。
- **同根词**：differ（**dif-** 分开 + fer 携带 = 不同→相异）、different（differ + **-ent** …的：不同的）、differently（different + **-ly** 副词后缀：不同地）、differentiate（different + **-iate** 动词后缀：区分）、indifferent（**in-** 不 + different 不同 = 无差别的→漠不关心的）。
- **前缀·后缀**：前缀 **dis-/dif-**（例：disagree, difficult）；名词后缀 **-ence**（例：existence, patience）。
- **同义·反义**：同义 distinction（区别）, disparity（差异）；反义 similarity（相似）, sameness（相同）。
- **变形**：名词 → 复数：differences；形容词派生 → different adj. 不同的；副词派生 → differently adv. 不同地；动词派生 → differ v. 相异。

### 22. compete /kəmˈpit/ v. 参加比赛(或竞赛)
- **词根·渊源**：拉丁 **com-**（共同）+ **petere**（追求、寻求）→ 拉丁 *competere*（共同追求）→ 晚期拉丁 *competere* → 英语 compete，本义“共同追求同一目标”，引申为“竞争、参赛”。
- **同根词**：competition（compete + **-ition** 名词后缀：竞争）、competitive（compete + **-itive** …的：有竞争力的）、competitor（compete + **-itor** 人：竞争者）、petition（**pet-** 追求 + **-ition** 名词后缀：请求）、appetite（**ap-** 向 + pet 追求 + **-ite** = 追求食物→食欲）。
- **前缀·后缀**：前缀 **com-**（例：combine, compare）；动词后缀 **-e**（例：create, debate）。
- **同义·反义**：同义 contend（争夺）, rival（与…竞争）；反义 cooperate（合作）, collaborate（协作）。
- **变形**：动词 → 第三人称单数：competes；过去式：competed；过去分词：competed；现在分词：competing；名词派生 → competition n. 竞争；competitor n. 竞争者；形容词派生 → competitive adj. 有竞争力的。

### 23. event /ɪˈvɛnt/ n. 公开活动；社交场合
- **词根·渊源**：拉丁 **ex-**（出）+ **venire**（来）→ 拉丁 *evenire*（出来→发生）→ 拉丁 *eventus*（结果、发生的事）→ 英语 event，本义“发生出来的事”，引申为“事件、活动”。
- **同根词**：eventful（event + **-ful** 充满…的：多事的）、eventual（event + **-ual** …的：最终的）、eventually（eventual + **-ly** 副词后缀：最终）、invent（**in-** 进入 + vent 来 = 进来→发明）、prevent（**pre-** 前 + vent 来 = 先来→预防）、convention（**con-** 共同 + vent 来 + **-ion** 名词后缀：共同来→会议、惯例）。
- **前缀·后缀**：前缀 **e-/ex-**（例：exit, evolve）；名词后缀 **-t**（例：accent, moment）。
- **同义·反义**：同义 occurrence（事件）, affair（活动）；反义 无。
- **变形**：名词 → 复数：events；形容词派生 → eventful adj. 多事的；eventual adj. 最终的；副词派生 → eventually adv. 最终。

### 24. spoon /spun/ n. 勺；匙
- **词根·渊源**：古英语 *spon*（木片、碎片）→ 中古英语 *spoon*，本义“木片削成的用具”，因早期勺子多为木片制成，引申为“勺、匙”；与古诺斯语 *spann*（木片）同源。
- **同根词**：spoonful（spoon + **-ful** 满…的量：一勺之量）、teaspoon（tea 茶 + spoon 勺 = 茶匙）、tablespoon（table 餐桌 + spoon 勺 = 大汤匙）、spoon-feed（spoon + feed 喂 = 用勺喂→填鸭式灌输）。
- **前缀·后缀**：无前后缀（单纯词）。
- **同义·反义**：同义 scoop（勺）, ladle（长柄勺）；反义 无。
- **变形**：名词 → 复数：spoons；动词派生 → spoon v. 用勺舀；名词派生 → spoonful n. 一勺之量。

### 25. annual /ˈænjuəl/ adj. 每年的；一年一次的
- **词根·渊源**：拉丁 **annus**（年）→ 拉丁 *annualis*（一年的）→ 古法语 *annuel* → 英语 annual，本义“属于一年的”，引申为“每年的、一年一次的”。
- **同根词**：annually（annual + **-ly** 副词后缀：每年地）、anniversary（ann 年 + **vers** 转 + **-ary** = 一年转一次→周年纪念）、annuity（ann 年 + **-uity** 名词后缀：年金）、perennial（**per-** 贯穿 + enn 年 + **-ial** …的：常年的）。
- **前缀·后缀**：形容词后缀 **-al**（例：natural, personal）；副词后缀 **-ly**（例：quickly, happily）。
- **同义·反义**：同义 yearly（每年的）；反义 daily（每日的）, monthly（每月的）。
- **变形**：形容词 → 无比较级（关系形容词，不作比较）；副词派生 → annually adv. 每年地；名词派生 → annual n. 年刊、一年生植物。

### 26. fantastic /fænˈtæstɪk/ adj. 极好的；了不起的
- **词根·渊源**：希腊 **phantazein**（使显现、想象）→ 希腊 *phantastikos*（善于想象的）→ 拉丁 *phantasticus* → 古法语 *fantastique* → 英语 fantastic，本义“想象出来的、幻想的”，引申为“奇异的”，再口语化为“极好的”。
- **同根词**：fantasy（希腊 phantasia 想象→幻想）、fantasize（fantasy + **-ize** 动词后缀：幻想）、phantom（希腊 phantasma 幻影→幽灵）、fantastically（fantastic + **-ally** 副词后缀：极好地）。
- **前缀·后缀**：形容词后缀 **-ic**（例：basic, historic）；副词后缀 **-ally**（例：basically, historically）。
- **同义·反义**：同义 wonderful（极好的）, marvelous（了不起的）；反义 awful（糟糕的）, terrible（可怕的）。
- **变形**：形容词 → 比较级：more fantastic；最高级：most fantastic；副词派生 → fantastically adv. 极好地；名词派生 → fantasy n. 幻想。

### 27. dollar /ˈdɔlər/ n. 元(美国、加拿大、澳大利亚等国的货币单位)
- **词根·渊源**：德语 *Taler*（塔勒银币）→ 低地德语 *daler* → 英语 dollar，本义“来自约阿希姆斯塔尔（Joachimsthal）银矿的银币”，因该地铸银币闻名，引申为“元”。
- **同根词**：dollar bill（dollar + bill 纸币 = 美元纸币）、petrodollar（**petro-** 石油 + dollar 元 = 石油美元）。
- **前缀·后缀**：无前后缀（借词单纯词）。
- **同义·反义**：同义 buck（美元，口语）；反义 无。
- **变形**：名词 → 复数：dollars。

### 28. pie /paɪ/ n. 果馅饼；果馅派
- **词根·渊源**：中世纪拉丁语 *pica*（喜鹊）→ 古法语 *pie*，本义可能与喜鹊“杂凑”习性有关（馅饼杂集各种馅料），存疑；一说来自古英语 *pie*（一种鸟）。
- **同根词**：pie chart（pie 馅饼 + chart 图表 = 饼状图）、piecrust（pie + crust 外壳 = 馅饼皮）、potpie（pot 锅 + pie 馅饼 = 锅烤馅饼）。
- **前缀·后缀**：无前后缀（单纯词）。
- **同义·反义**：同义 tart（果馅饼）, pastry（糕点）；反义 无。
- **变形**：名词 → 复数：pies。

### 29. equipment /ɪkˈwɪpmənt/ n. 设备；器材
- **词根·渊源**：古诺斯语 *skipa*（装备船）→ 古法语 *esquiper*（装备）→ 英语 equip（装备）+ **-ment**（名词后缀）→ equipment，本义“装备的行为/物品”，引申为“设备、器材”。
- **同根词**：equip（equip 装备→配备）、equipped（equip + **-ed** …的：装备好的）、equipping（equip + **-ing** 动名词：装备）。
- **前缀·后缀**：名词后缀 **-ment**（例：movement, development）。
- **同义·反义**：同义 gear（装备）, apparatus（器械）；反义 无。
- **变形**：名词 → 复数：不可数；动词派生 → equip v. 装备；形容词派生 → equipped adj. 装备好的。
