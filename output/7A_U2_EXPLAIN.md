## 二、逐词说文解字

### 1. geography /ʤiˈɑgrəfi/ n. 地理(学)
- **词根·渊源**：希腊 **geo-**（earth 地）+ **-graphy**（writing, description 写、描述）→ 拉丁 *geographia* → 古法语 *geographie* → 英语，本义“对地球的描述”→地理学。
- **同根词**：geology（geo 地 + **-logy** 学科 = 地质学）、geometry（geo 地 + **metron** 测量 = 土地测量→几何学）、geography 本身含 graph 写；photograph（**photo-** 光 + graph 写 = 用光写→照片）、biography（**bio-** 生命 + graph 写 = 写生平→传记）、graph（graph 写→图表）。
- **前缀·后缀**：前缀 **geo-**（例：geology, geometry）；后缀 **-graphy**（例：photography, biography）。
- **同义·反义**：同义 无；反义 无。
- **变形**：名词 → 复数：geographies；形容词派生 → geographic adj. 地理的；副词派生 → geographically adv. 地理上。

### 2. corner /ˈkɔrnər/ n. 角；墙角
- **词根·渊源**：拉丁 **cornu**（horn 角）→ 古法语 *corniere*（角落）→ 英语，本义“角状物、突出的角”→角落、墙角。
- **同根词**：cornet（corn 角 + **-et** 小 = 小角→短号）、cornucopia（cornu 角 + copia 丰富 = 丰饶角）、unicorn（**uni-** 一 + corn 角 = 独角兽）、cornea（corn 角 + **-ea** 名词后缀 = 角膜）。
- **前缀·后缀**：前缀 **uni-**（例：uniform, unite）；后缀 **-er**（例：worker, teacher）。
- **同义·反义**：同义 angle（角）, nook（角落）；反义 无。
- **变形**：名词 → 复数：corners；动词派生 → corner v. 将…逼入角落；形容词派生 → cornered adj. 被逼入角落的。

### 3. activity /ækˈtɪvɪti/ n. 活动
- **词根·渊源**：拉丁 **agere / act-**（do, drive 做、驱动）→ 拉丁 *activus*（活跃的）→ 英语 active + **-ity**，本义“处于行动的状态”→活动。
- **同根词**：act（act 做→行动）、active（act 做 + **-ive** …的 = 活跃的）、actor（act 做 + **-or** 人 = 男演员）、action（act 做 + **-ion** 名词 = 行动）、react（**re-** 回 + act 做 = 反应）、exact（**ex-** 出 + act 做 = 做得精确的）。
- **前缀·后缀**：前缀 **re-**（例：react, return）、**ex-**（例：exact, export）；后缀 **-ity**（例：reality, ability）。
- **同义·反义**：同义 action（行动）, movement（活动）；反义 inactivity（不活动）, rest（休息）。
- **变形**：名词 → 复数：activities；形容词派生 → active adj. 活跃的；副词派生 → actively adv. 活跃地。

### 4. club /kləb/ n. 社团
- **词根·渊源**：古诺斯语 *klubba*（club, cudgel 棍棒）→ 英语，本义“棍棒”；因聚在一起的人如“一捆棍棒”而引申为“社团、俱乐部”（词源存疑）。
- **同根词**：clubhouse（club 社团 + house 房子 = 俱乐部会所）、clubman（club 社团 + **-man** 人 = 俱乐部会员）。
- **前缀·后缀**：无前后缀（单纯词）。
- **同义·反义**：同义 association（协会）, society（社团）；反义 无。
- **变形**：名词 → 复数：clubs；动词派生 → club v. 用棍棒打；形容词派生 → clubbed adj. 棒状的。

### 5. practice /ˈpræktɪs/ v. 练习；训练
- **词根·渊源**：希腊 **praktikos**（fit for action 适于行动的）→ 拉丁 *practicus* → 中世纪拉丁 *practicare* → 英语，本义“反复做以变得熟练”→练习。
- **同根词**：practical（practice 实践 + **-al** …的 = 实际的）、practise（practice 的英式动词变体 = 练习）、practitioner（practic 实践 + **-ion** + **-er** 人 = 从业者）、impractical（**im-** 不 + practical 实际的 = 不切实际的）。
- **前缀·后缀**：前缀 **im-**（例：impossible, impolite）；后缀 **-al**（例：natural, formal）、**-er**（例：teacher, worker）。
- **同义·反义**：同义 exercise（练习）, train（训练）；反义 neglect（忽视）, ignore（忽略）。
- **变形**：动词 → 第三人称单数：practices；过去式：practiced；过去分词：practiced；现在分词：practicing；名词派生 → practice n. 练习；形容词派生 → practical adj. 实际的。

### 6. solve /sɑlv/ v. 解答
- **词根·渊源**：拉丁 **solvere**（loosen, dissolve 松开、解开）→ 拉丁 *solvere* → 英语，本义“解开（结、难题）”→解答、解决。
- **同根词**：solution（solv 解开 + **-ion** 名词 = 解决办法）、solvent（solv 解开 + **-ent** …的 = 能溶解的→溶剂）、dissolve（**dis-** 分开 + solv 解开 = 溶解）、absolve（**ab-** 离开 + solv 解开 = 赦免）、resolve（**re-** 再 + solv 解开 = 决心、解决）。
- **前缀·后缀**：前缀 **dis-**（例：disagree, discover）、**ab-**（例：absent, abnormal）、**re-**（例：return, review）；后缀 **-ion**（例：action, station）。
- **同义·反义**：同义 answer（回答）, resolve（解决）；反义 complicate（使复杂）, confuse（使困惑）。
- **变形**：动词 → 第三人称单数：solves；过去式：solved；过去分词：solved；现在分词：solving；名词派生 → solution n. 解决办法；形容词派生 → solvable adj. 可解决的。

### 7. develop /dɪˈvɛləp/ v. 加强；增强
- **词根·渊源**：古法语 *desveloper*（unwrap, unfurl 展开、打开）→ 英语，本义“把包裹的东西展开”→逐渐展开、发展→加强、增强。
- **同根词**：development（develop 发展 + **-ment** 名词 = 发展）、developer（develop 发展 + **-er** 人 = 开发者）、developmental（development 发展 + **-al** …的 = 发展的）、undeveloped（**un-** 未 + developed 发展的 = 未开发的）。
- **前缀·后缀**：前缀 **un-**（例：unhappy, unable）；后缀 **-ment**（例：movement, agreement）、**-er**（例：teacher, worker）。
- **同义·反义**：同义 grow（成长）, strengthen（加强）；反义 weaken（削弱）, decline（衰退）。
- **变形**：动词 → 第三人称单数：develops；过去式：developed；过去分词：developed；现在分词：developing；名词派生 → development n. 发展；形容词派生 → developed adj. 发达的。

### 8. skill /skɪl/ n. 技术；技能
- **词根·渊源**：古诺斯语 *skil*（distinction, discernment 区分、辨别）→ 中古英语 *skille*（知识、能力）→ 英语，本义“辨别力”→技能、技巧。
- **同根词**：skillful（skill 技能 + **-ful** 充满…的 = 熟练的）、skilled（skill 技能 + **-ed** 有…的 = 有技能的）、unskilled（**un-** 不 + skilled 有技能的 = 不熟练的）。
- **前缀·后缀**：前缀 **un-**（例：unhappy, unable）；后缀 **-ful**（例：helpful, useful）、**-ed**（例：talented, gifted）。
- **同义·反义**：同义 ability（能力）, technique（技术）；反义 inability（无能）, clumsiness（笨拙）。
- **变形**：名词 → 复数：skills；形容词派生 → skillful adj. 熟练的；副词派生 → skillfully adv. 熟练地。

### 9. teen /tin/ adj. 青少年的
- **词根·渊源**：古英语 **-tīene**（ten 十，构成 13–19 的数词后缀）→ 英语 teen，本义“十几（13–19）”→青少年的（teenage 的缩略）。
- **同根词**：teenager（teen 十几 + **-age** 年龄 + **-er** 人 = 青少年）、teens（teen 十几 + **-s** 复数 = 十几岁）、teenage（teen 十几 + age 年龄 = 青少年的）、thirteen（**thir-** 三 + teen 十 = 十三）、fifteen（**fif-** 五 + teen 十 = 十五）。
- **前缀·后缀**：后缀 **-er**（例：teacher, worker）、**-age**（例：marriage, package）。
- **同义·反义**：同义 adolescent（青春期的）, teenage（青少年的）；反义 adult（成年的）。
- **变形**：形容词 → 无比较级（关系形容词，不作比较）；名词派生 → teenager n. 青少年。

### 10. magazine /ˈmægəˌzin/ n. 杂志
- **词根·渊源**：阿拉伯语 *makhzan*（storehouse 仓库）→ 意大利语 *magazzino* → 法语 *magasin* → 英语，本义“仓库”→汇集各种文章的“知识仓库”→杂志。
- **同根词**：magazinist（magazine 杂志 + **-ist** 人 = 杂志撰稿人）。
- **前缀·后缀**：后缀 **-ist**（例：artist, scientist）。
- **同义·反义**：同义 journal（期刊）, periodical（定期刊物）；反义 无。
- **变形**：名词 → 复数：magazines。

### 11. teenager /ˈtiˌneɪʤər/ n. (13至19岁之间的)青少年
- **词根·渊源**：英语 teen（十几）+ **-age**（年龄）+ **-er**（人）→ 英语，本义“处于十几岁年龄的人”→青少年。
- **同根词**：teen（teen 十几 = 青少年的）、teens（teen 十几 + **-s** 复数 = 十几岁）、teenage（teen 十几 + age 年龄 = 青少年的）、thirteen（**thir-** 三 + teen 十 = 十三）。
- **前缀·后缀**：后缀 **-age**（例：marriage, package）、**-er**（例：teacher, worker）。
- **同义·反义**：同义 adolescent（青少年）, youth（青年）；反义 adult（成年人）。
- **变形**：名词 → 复数：teenagers。

### 12. greeting /ˈgritɪŋ/ n. 问候；招呼
- **词根·渊源**：古英语 **grētan**（to greet 问候）→ 英语 greet + **-ing** 名词后缀，本义“问候的行为”→问候、招呼。
- **同根词**：greet（greet 问候→问候）、greeter（greet 问候 + **-er** 人 = 迎接员）、greetings（greeting 问候 + **-s** 复数 = 问候语）。
- **前缀·后缀**：后缀 **-ing**（例：meeting, building）、**-er**（例：teacher, worker）。
- **同义·反义**：同义 salutation（致意）, welcome（欢迎）；反义 farewell（告别）, goodbye（再见）。
- **变形**：名词 → 复数：greetings。

### 13. grade /greɪd/ n. 年级
- **词根·渊源**：拉丁 **gradus**（step, degree 步、等级）→ 法语 *grade* → 英语，本义“一步、一级”→等级→年级。
- **同根词**：gradual（grad 步 + **-ual** …的 = 逐步的）、graduate（grad 步 + **-uate** 动词 = 走完一步→毕业）、degrade（**de-** 向下 + grad 步 = 降级）、upgrade（**up-** 向上 + grade 等级 = 升级）、centigrade（**centi-** 百 + grade 度 = 摄氏的）。
- **前缀·后缀**：前缀 **de-**（例：decrease, depart）、**up-**（例：upgrade, upset）、**centi-**（例：centimeter, centipede）；后缀 **-ual**（例：actual, gradual）。
- **同义·反义**：同义 level（等级）, class（班级）；反义 无。
- **变形**：名词 → 复数：grades；动词派生 → grade v. 评分；形容词派生 → graded adj. 分级的。

### 14. energy /ˈɛnərʤi/ n. 精力；活力
- **词根·渊源**：希腊 **energeia**（activity, operation 活动、作用）→ 拉丁 *energia* → 英语，本义“内在的活动力”→精力、能量。
- **同根词**：energetic（energy 能量 + **-etic** …的 = 精力充沛的）、energize（energy 能量 + **-ize** 使… = 使充满能量）、energetics（energetic 能量的 + **-s** 学科 = 能量学）。
- **前缀·后缀**：后缀 **-etic**（例：genetic, athletic）、**-ize**（例：realize, organize）。
- **同义·反义**：同义 vigor（活力）, vitality（生命力）；反义 weakness（虚弱）, lethargy（无精打采）。
- **变形**：名词 → 复数：energies；形容词派生 → energetic adj. 精力充沛的；副词派生 → energetically adv. 精力充沛地。

### 15. drama /ˈdrɑmə/ n. 戏；剧
- **词根·渊源**：希腊 **dran**（to do, act 做、表演）→ 希腊 *drama*（deed, action 行为、戏剧）→ 拉丁 → 英语，本义“表演出来的行为”→戏剧。
- **同根词**：dramatic（drama 戏剧 + **-tic** …的 = 戏剧性的）、dramatist（drama 戏剧 + **-ist** 人 = 剧作家）、dramatize（drama 戏剧 + **-ize** 使… = 改编成戏剧）。
- **前缀·后缀**：后缀 **-tic**（例：romantic, athletic）、**-ist**（例：artist, scientist）、**-ize**（例：realize, organize）。
- **同义·反义**：同义 play（戏剧）, theater（戏剧）；反义 无。
- **变形**：名词 → 复数：dramas；形容词派生 → dramatic adj. 戏剧性的；副词派生 → dramatically adv. 戏剧性地。

### 16. sincerely /sɪnˈsɪrli/ adv. 真诚地；诚实地
- **词根·渊源**：拉丁 **sincerus**（clean, pure 纯净的）→ 拉丁 *sincerus* → 英语 sincere + **-ly** 副词后缀，本义“纯净地”→真诚地。
- **同根词**：sincere（sincer 纯净 + **-e** = 真诚的）、sincerity（sincer 纯净 + **-ity** 名词 = 真诚）。
- **前缀·后缀**：后缀 **-ly**（例：bravely, quickly）、**-ity**（例：reality, ability）。
- **同义·反义**：同义 honestly（诚实地）, truly（真诚地）；反义 falsely（虚假地）, insincerely（不真诚地）。
- **变形**：副词 → 无比较级（派生副词，不作比较）；形容词派生 → sincere adj. 真诚的；名词派生 → sincerity n. 真诚。

### 17. diary /ˈdaɪəri/ n. 日记；日记簿
- **词根·渊源**：拉丁 **dies**（day 日）→ 拉丁 *diarium*（daily allowance 每日配给）→ 英语，本义“每日记录”→日记。
- **同根词**：diarist（diary 日记 + **-ist** 人 = 记日记的人）、diarial（diary 日记 + **-al** …的 = 日记的）。
- **前缀·后缀**：后缀 **-ist**（例：artist, scientist）、**-al**（例：natural, formal）。
- **同义·反义**：同义 journal（日志）, log（日志）；反义 无。
- **变形**：名词 → 复数：diaries。

### 18. project /ˈprɑʤɛkt/ n. 课题
- **词根·渊源**：拉丁 **proicere / project-**（**pro-** 向前 + **jacere** 投掷 = 向前投出）→ 拉丁 *projectum* → 英语，本义“向前投出的东西”→计划、课题。
- **同根词**：projection（project 投出 + **-ion** 名词 = 投射）、projector（project 投出 + **-or** 物 = 投影仪）、reject（**re-** 回 + ject 投 = 投回→拒绝）、inject（**in-** 入 + ject 投 = 注入）、subject（**sub-** 下 + ject 投 = 置于下→主题）。
- **前缀·后缀**：前缀 **pro-**（例：progress, produce）、**re-**（例：return, review）、**in-**（例：inject, inside）、**sub-**（例：subject, submarine）；后缀 **-ion**（例：action, station）、**-or**（例：actor, doctor）。
- **同义·反义**：同义 plan（计划）, task（任务）；反义 无。
- **变形**：名词 → 复数：projects；动词派生 → project v. 投射、计划；形容词派生 → projected adj. 预计的。

### 19. poster /ˈpoʊstər/ n. 海报
- **词根·渊源**：拉丁 **postis**（柱子、门柱）→ 古法语 *poste* → 英语 post（张贴、邮政），加 **-er** 表“物” → poster，本义“张贴在柱子上的东西”→ 海报。
- **同根词**：post（post 柱子→张贴→邮政）、postage（post 邮政 + **-age** 费用 = 邮资）、postcard（post 邮政 + card 卡片 = 明信片）、posterity（post 后 + **-erity** 后代→子孙，存疑：与 post 柱子不同源）。
- **前缀·后缀**：名词后缀 **-er**（例：teacher, worker）。
- **同义·反义**：同义 bill（海报）, placard（招贴）；反义 无。
- **变形**：名词 → 复数：posters；动词派生 → post v. 张贴；poster 无比较级。

### 20. realize /ˈriəˌlaɪz/ v. 意识到
- **词根·渊源**：拉丁 **realis**（真实的）← res（事物）→ 法语 *réel* → 英语 real，加 **-ize** 动词化 → realize，本义“使成为真实”→ 实现→ 意识到。
- **同根词**：real（real 真实的）、reality（real + **-ity** 性质 = 现实）、realization（realize + **-ation** 名词 = 实现、认识）、really（real + **-ly** 真正地）。
- **前缀·后缀**：动词后缀 **-ize**（例：modernize, organize）；名词后缀 **-ation**（例：realization, organization）。
- **同义·反义**：同义 understand（理解）, recognize（认识到）；反义 ignore（忽视）, overlook（忽略）。
- **变形**：动词 → 第三人称单数：realizes；过去式：realized；过去分词：realized；现在分词：realizing；名词派生 → realization n. 实现、认识。

### 21. luckily /ˈləkəli/ adv. 幸运地；幸好
- **词根·渊源**：中古荷兰语 *luc*（好运）→ 英语 luck（运气），加 **-y** 形容词 → lucky，再加 **-ly** 副词 → luckily，本义“有好运地”→ 幸运地。
- **同根词**：luck（luck 运气）、lucky（luck + **-y** …的 = 幸运的）、unlucky（**un-** 不 + lucky = 不幸的）、luckless（luck + **-less** 无 = 不幸的）。
- **前缀·后缀**：副词后缀 **-ly**（例：happily, quickly）；形容词后缀 **-y**（例：rainy, windy）；否定前缀 **un-**（例：unhappy）。
- **同义·反义**：同义 fortunately（幸运地）, happily（幸好）；反义 unluckily（不幸地）, unfortunately（不幸地）。
- **变形**：副词 → 比较级：more luckily；最高级：most luckily；形容词派生 → lucky adj. 幸运的；名词派生 → luck n. 运气。

### 22. just /ʤɪst/ adv. 恰好
- **词根·渊源**：拉丁 **justus**（公正的）← jus（法律、权利）→ 古法语 *juste* → 英语 just，本义“公正地”→ 恰好、刚刚。
- **同根词**：justice（just + **-ice** 名词 = 正义）、justify（just + **-ify** 使 = 证明正当）、unjust（**un-** 不 + just = 不公正的）、adjust（**ad-** 向 + just 公正 = 使合乎→调整）。
- **前缀·后缀**：前缀 **un-**（例：unfair）、**ad-**（例：advance）；名词后缀 **-ice**（例：justice, service）。
- **同义·反义**：同义 exactly（恰好）, precisely（正好）；反义 roughly（大约）, approximately（大约）。
- **变形**：副词 → 无比较级（作“恰好”义）；形容词派生 → just adj. 公正的；名词派生 → justice n. 正义；副词派生 → justly adv. 公正地。

### 23. presentation /ˌprɛzənˈteɪʃən/ n. 演示
- **词根·渊源**：拉丁 **praesentare**（呈献）← prae（前）+ esse（在）→ 古法语 *presenter* → 英语 present，加 **-ation** 名词 → presentation，本义“呈现在前”→ 演示、介绍。
- **同根词**：present（pre 前 + sent 在 = 呈现在前→呈现）、represent（**re-** 再 + present = 再现→代表）、presenter（present + **-er** 人 = 主持人）、presently（present + **-ly** 目前）。
- **前缀·后缀**：名词后缀 **-ation**（例：information, education）；前缀 **re-**（例：repeat, return）。
- **同义·反义**：同义 demonstration（演示）, display（展示）；反义 无。
- **变形**：名词 → 复数：presentations；动词派生 → present v. 呈现；形容词派生 → present adj. 现在的。

### 24. mood /mud/ n. 情绪；心情
- **词根·渊源**：古英语 **mod**（心、精神、勇气）→ 中古英语 *mood*，本义“心境”→ 情绪、心情；与德语 Mut（勇气）同源。
- **同根词**：moody（mood + **-y** …的 = 情绪化的）、moodily（moody + **-ly** 副词 = 闷闷不乐地）、moodiness（moody + **-ness** 名词 = 喜怒无常）。
- **前缀·后缀**：形容词后缀 **-y**（例：cloudy, sunny）；副词后缀 **-ly**（例：happily）；名词后缀 **-ness**（例：happiness）。
- **同义·反义**：同义 feeling（感觉）, temper（脾气）；反义 无。
- **变形**：名词 → 复数：moods；形容词派生 → moody adj. 情绪化的；副词派生 → moodily adv. 闷闷不乐地。

### 25. mind /maɪnd/ v. 介意
- **词根·渊源**：古英语 **gemynd**（记忆、思想）← PIE *men-*（思考）→ 中古英语 *mind*，本义“心思”→ 注意→ 介意。
- **同根词**：mindful（mind + **-ful** 充满 = 留心的）、mindless（mind + **-less** 无 = 无心的）、remind（**re-** 再 + mind 心 = 再想起→提醒）、mention（拉丁 mens 心 + **-tion** = 提及，同出 *men-*）。
- **前缀·后缀**：形容词后缀 **-ful**（例：helpful）、**-less**（例：careless）；前缀 **re-**（例：recall）。
- **同义·反义**：同义 care（在意）, object（反对）；反义 ignore（忽视）, disregard（不理会）。
- **变形**：动词 → 第三人称单数：minds；过去式：minded；过去分词：minded；现在分词：minding；名词派生 → mind n. 头脑；形容词派生 → mindful adj. 留心的。

### 26. pack /pæk/ v. (把…)打包
- **词根·渊源**：中古荷兰语 **pak**（包、捆）→ 中古英语 *pakke*，本义“捆扎成包”→ 打包、包装。
- **同根词**：package（pack + **-age** 名词 = 包裹）、packet（pack + **-et** 小 = 小包）、packing（pack + **-ing** 名词 = 打包）、unpack（**un-** 相反 + pack = 打开包装）。
- **前缀·后缀**：名词后缀 **-age**（例：baggage）、**-et**（例：pocket）；前缀 **un-**（例：undo）。
- **同义·反义**：同义 bundle（捆扎）, wrap（包裹）；反义 unpack（打开）, empty（倒空）。
- **变形**：动词 → 第三人称单数：packs；过去式：packed；过去分词：packed；现在分词：packing；名词派生 → pack n. 包；package n. 包裹。

### 27. celebrate /ˈsɛləˌbreɪt/ v. 庆祝；庆贺
- **词根·渊源**：拉丁 **celeber**（著名的、热闹的）→ 拉丁 *celebrare*（使热闹、庆祝）→ 英语 celebrate，本义“使众人聚集热闹”→ 庆祝。
- **同根词**：celebration（celebrate + **-ion** 名词 = 庆祝）、celebrated（celebrate + **-ed** …的 = 著名的）、celebrity（celeber 著名 + **-ity** 名词 = 名人）、celebratory（celebrate + **-ory** …的 = 庆祝的）。
- **前缀·后缀**：动词后缀 **-ate**（例：operate, decorate）；名词后缀 **-ion**（例：action）。
- **同义·反义**：同义 observe（庆祝）, commemorate（纪念）；反义 mourn（哀悼）, lament（悲叹）。
- **变形**：动词 → 第三人称单数：celebrates；过去式：celebrated；过去分词：celebrated；现在分词：celebrating；名词派生 → celebration n. 庆祝。

### 28. success /səkˈsɛs/ n. 成功
- **词根·渊源**：拉丁 **succedere**（接替、随后）← sub（下）+ cedere（走）→ 拉丁 *successus* → 英语 success，本义“随后而至”→ 结果→ 成功。
- **同根词**：succeed（suc 下 + ceed 走 = 随后→成功）、successful（success + **-ful** 充满 = 成功的）、successfully（successful + **-ly** 副词 = 成功地）、succession（suc + cess 走 + **-ion** = 连续）。
- **前缀·后缀**：前缀 **suc-**（=sub 下，例：suffer, suggest）；形容词后缀 **-ful**（例：useful）。
- **同义·反义**：同义 achievement（成就）, triumph（胜利）；反义 failure（失败）, defeat（失败）。
- **变形**：名词 → 复数：successes；形容词派生 → successful adj. 成功的；副词派生 → successfully adv. 成功地；动词派生 → succeed v. 成功。

### 29. rocky /ˈrɑki/ adj. 困难的
- **词根·渊源**：古法语 **roche**（岩石）→ 中古英语 *rock*，加 **-y** 形容词 → rocky，本义“多岩石的”→ 崎岖的→ 困难的（引申义）。
- **同根词**：rock（rock 岩石）、rockiness（rocky + **-ness** 名词 = 多岩石、困难）、rocky（rock + **-y** …的 = 多岩石的）。
- **前缀·后缀**：形容词后缀 **-y**（例：sandy, stony）；名词后缀 **-ness**（例：kindness）。
- **同义·反义**：同义 difficult（困难的）, rugged（崎岖的）；反义 smooth（平坦的）, easy（容易的）。
- **变形**：形容词 → 比较级：rockier；最高级：rockiest；名词派生 → rock n. 岩石；rockiness n. 崎岖。
