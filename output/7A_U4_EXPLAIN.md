## 二、逐词说文解字

### 1. system /ˈsɪstəm/ n. 系统
- **词根·渊源**：希腊 **syn-**（一起）+ **histanai**（站立）→ 晚期拉丁 *systema* → 法语 *système* → 英语；本义“组合在一起的整体”，引申为“系统”。
- **同根词**：systematic（system + **-atic** …的：系统的）、systematically（systematic + **-ally** 以…方式：系统地）、ecosystem（**eco-** 生态 + system = 生态系统）、systemic（system + **-ic** …的：全身的、系统的）。
- **前缀·后缀**：名词后缀 **-em**（例：problem, item）；形容词后缀 **-atic**（例：problematic, automatic）。
- **同义·反义**：同义 structure（结构）, organization（组织）；反义 disorder（混乱）, chaos（混沌）。
- **变形**：名词 → 复数：systems；形容词派生 → systematic adj. 系统的；副词派生 → systematically adv. 系统地。

### 2. file /faɪl/ n. 档案
- **词根·渊源**：拉丁 **filum**（线）→ 古法语 *fil* → 英语；本义“用线串起来保存的文件”，引申为“档案、文件夹”。
- **同根词**：profile（**pro-** 向前 + fil 线 = 勾勒轮廓→侧面像、简介）、filament（fila 线 + **-ment** 物 = 细丝）、filigree（fili 线 + granum 颗粒 = 金丝细工）。
- **前缀·后缀**：无前后缀（单纯词，源自拉丁 filum）。
- **同义·反义**：同义 document（文件）, folder（文件夹）；反义 无。
- **变形**：名词 → 复数：files；动词派生 → file v. 归档；filing n. 归档。

### 3. amazing /əˈmeɪzɪŋ/ adj. 令人大为惊奇的
- **词根·渊源**：古英语 **amasian**（使困惑）→ 中古英语 *amazen* → 英语；本义“使人迷惑不解”，引申为“令人惊奇的”。
- **同根词**：amaze（a- 加强 + maze 迷惑 = 使大为惊奇）、amazement（amaze + **-ment** 名词后缀：惊奇）、maze（本义“迷惑、迷宫”）。
- **前缀·后缀**：前缀 **a-**（例：alive, awake）；形容词后缀 **-ing**（例：interesting, exciting）。
- **同义·反义**：同义 surprising（令人惊讶的）, astonishing（令人震惊的）；反义 boring（无聊的）, ordinary（普通的）。
- **变形**：形容词 → 无比较级（多作表语/定语，一般不用 more/most 比较）；副词派生 → amazingly adv. 令人惊奇地；名词派生 → amazement n. 惊奇。

### 4. planet /ˈplænət/ n. 行星
- **词根·渊源**：希腊 **planētēs**（漫游者）→ 拉丁 *planeta* → 古法语 *planete* → 英语；本义“天空中游走的星”，引申为“行星”。
- **同根词**：planetary（planet + **-ary** …的：行星的）、planetarium（planet + **-arium** 场所 = 天文馆）、interplanetary（**inter-** 之间 + planetary = 行星间的）。
- **前缀·后缀**：名词后缀 **-et**（例：rocket, pocket）；形容词后缀 **-ary**（例：ordinary, necessary）。
- **同义·反义**：同义 无；反义 star（恒星）。
- **变形**：名词 → 复数：planets；形容词派生 → planetary adj. 行星的。

### 5. billion /ˈbɪljən/ num. 十亿
- **词根·渊源**：法语 **bi-**（二）+ **-illion**（百万的变体）→ 英语；本义“百万的二次方”（旧英式），现代通用义“十亿”。
- **同根词**：million（**milli-** 千 + **-on** 大数后缀 = 百万）、trillion（**tri-** 三 + **-illion** = 万亿）、millionaire（million + **-aire** 人 = 百万富翁）。
- **前缀·后缀**：前缀 **bi-**（例：bicycle, bilingual）；数词后缀 **-illion**（例：million, trillion）。
- **同义·反义**：同义 无；反义 无。
- **变形**：数词 → 无复数变化（作名词时可复数：billions 数十亿）；形容词派生 → billionth num. 第十亿的。

### 6. cover /ˈkəvər/ v. 盖；覆盖
- **词根·渊源**：拉丁 **cooperire**（完全遮盖）→ 古法语 *covrir* → 英语；本义“完全盖住”，引申为“覆盖、涵盖”。
- **同根词**：discover（**dis-** 去除 + cover 盖 = 揭开盖子→发现）、coverage（cover + **-age** 名词后缀：覆盖范围）、covering（cover + **-ing** 名词后缀：覆盖物）、uncover（**un-** 相反 + cover = 揭开）。
- **前缀·后缀**：前缀 **dis-**（例：disappear）、**un-**（例：unlock）；名词后缀 **-age**（例：marriage）、**-ing**（例：building）。
- **同义·反义**：同义 hide（遮盖）, conceal（隐藏）；反义 uncover（揭开）, expose（暴露）。
- **变形**：动词 → 第三人称单数：covers；过去式：covered；过去分词：covered；现在分词：covering；名词派生 → cover n. 盖子、封面；coverage n. 覆盖范围。

### 7. area /ˈɛriə/ n. 地区；地域
- **词根·渊源**：拉丁 **area**（空地、打谷场）→ 英语；本义“平坦空地”，引申为“地区、面积”。
- **同根词**：areal（area + **-al** …的：区域的）、area code（area + code = 区号）。
- **前缀·后缀**：名词后缀 **-a**（例：idea, sofa）；形容词后缀 **-al**（例：natural, personal）。
- **同义·反义**：同义 region（地区）, zone（地带）；反义 无。
- **变形**：名词 → 复数：areas；形容词派生 → areal adj. 区域的。

### 8. freezing /ˈfrizɪŋ/ adj. 极冷的
- **词根·渊源**：古英语 **frēosan**（结冰）→ 中古英语 *fresen* → 英语；本义“结冰的”，引申为“极冷的”。
- **同根词**：freeze（frēosan 结冰→冻结）、frozen（freeze 的过去分词：冰冻的）、freezer（freeze + **-er** 物 = 冷冻箱）。
- **前缀·后缀**：形容词后缀 **-ing**（例：interesting, boring）。
- **同义·反义**：同义 icy（冰冷的）, chilly（寒冷的）；反义 hot（热的）, warm（温暖的）。
- **变形**：形容词 → 无比较级（多作表语/定语，一般不用 more/most 比较）；动词派生 → freeze v. 结冰；名词派生 → freezer n. 冷冻箱。

### 9. north /nɔrθ/ n. 北；北方
- **词根·渊源**：古英语 **norþ**（北方）→ 英语；与 PIE *ner-*（左、下）相关，古人面东时北方在左；本义“北方”，引申为“北部”。
- **同根词**：northern（north + **-ern** 方向的：北方的）、northeast（north + east = 东北）、northward（north + **-ward** 向…的：向北的）。
- **前缀·后缀**：方向后缀 **-ern**（例：eastern, western）、**-ward**（例：eastward, backward）。
- **同义·反义**：同义 无；反义 south（南；南方）。
- **变形**：名词 → 不可数（作“北方”义）；形容词派生 → northern adj. 北方的；副词派生 → northward adv. 向北。

### 10. pole /poʊl/ n. (行星的)极；地极
- **词根·渊源**：希腊 **polos**（轴、天轴）→ 拉丁 *polus* → 英语；本义“天球旋转的轴”，引申为“地极、极”。
- **同根词**：polar（pole + **-ar** …的：极地的）、polarity（polar + **-ity** 名词后缀：极性）、polarize（polar + **-ize** 使…化：使极化）。
- **前缀·后缀**：形容词后缀 **-ar**（例：similar, familiar）；名词后缀 **-ity**（例：activity, reality）。
- **同义·反义**：同义 extremity（末端）；反义 equator（赤道）。
- **变形**：名词 → 复数：poles；形容词派生 → polar adj. 极地的。

### 11. desert /ˈdɛzərt/ n. 沙漠；荒漠
- **词根·渊源**：拉丁 **deserere**（抛弃、离开）→ 拉丁 *desertum*（被弃之地）→ 古法语 *desert* → 英语；本义“被遗弃的荒芜之地”，引申为“沙漠”。
- **同根词**：deserted（desert + **-ed** …的：被遗弃的）、desertion（desert + **-ion** 名词后缀：遗弃）、deserter（desert + **-er** 人 = 逃兵）。
- **前缀·后缀**：前缀 **de-**（例：depart, decline）；名词后缀 **-ion**（例：action, nation）。
- **同义·反义**：同义 wasteland（荒地）, wilderness（荒野）；反义 oasis（绿洲）。
- **变形**：名词 → 复数：deserts；形容词派生 → deserted adj. 荒芜的、被遗弃的。

### 12. metre /ˈmitər/ n. 米
- **词根·渊源**：希腊 **metron**（度量）→ 法语 *mètre* → 英语；本义“测量的单位”，1791 年法国定为长度单位“米”。
- **同根词**：meter（同源美式拼写：米）、metric（metre + **-ic** …的：公制的）、thermometer（**thermo-** 热 + meter 测量 = 温度计）、diameter（**dia-** 穿过 + meter 测量 = 直径）。
- **前缀·后缀**：名词后缀 **-re**（例：centre, litre）；构词成分 **-meter**（例：barometer, speedometer）。
- **同义·反义**：同义 无；反义 无。
- **变形**：名词 → 复数：metres；形容词派生 → metric adj. 公制的。

### 13. reach /riʧ/ v. 足够达到
- **词根·渊源**：古英语 **rǣcan**（伸手、够到）→ 中古英语 *rechen* → 英语；本义“伸手触及”，引申为“达到、够到”。
- **同根词**：overreach（**over-** 过度 + reach = 伸手过长→做得过头）、unreachable（**un-** 不 + reach + **-able** 可…的 = 不可及的）、reaching（reach + **-ing** …的：延伸的）。
- **前缀·后缀**：前缀 **over-**（例：overcome）、**un-**（例：unable）；形容词后缀 **-able**（例：readable, comfortable）。
- **同义·反义**：同义 arrive at（到达）, attain（达到）；反义 miss（错过）, fall short（不足）。
- **变形**：动词 → 第三人称单数：reaches；过去式：reached；过去分词：reached；现在分词：reaching；名词派生 → reach n. 范围、触及。

### 14. grain /greɪn/ n. 谷粒
- **词根·渊源**：拉丁 **granum**（种子、颗粒）→ 古法语 *grain* → 英语；本义“小颗粒”，引申为“谷粒、谷物”。
- **同根词**：granary（gran 谷 + **-ary** 场所 = 谷仓）、granite（gran 颗粒 + **-ite** 岩石 = 花岗岩）、granule（gran 颗粒 + **-ule** 小 = 小颗粒）。
- **前缀·后缀**：名词后缀 **-ary**（例：library, dictionary）、**-ule**（例：molecule, capsule）。
- **同义·反义**：同义 seed（种子）, cereal（谷物）；反义 无。
- **变形**：名词 → 复数：grains（作“谷物”总称时不可数）；形容词派生 → grainy adj. 粒状的。

### 15. wide /waɪd/ adj. 宽的；宽阔的
- **词根·渊源**：古英语 **wīd**（宽的）→ 英语；与 PIE *wi-*（分开）相关，本义“展开的、宽阔的”，引申为“宽的”。
- **同根词**：width（wide + **-th** 名词后缀：宽度）、widely（wide + **-ly** 副词后缀：广泛地）、widen（wide + **-en** 使…：加宽）、widespread（wide + spread 散布 = 普遍的）。
- **前缀·后缀**：名词后缀 **-th**（例：length, depth）；动词后缀 **-en**（例：strengthen, lengthen）。
- **同义·反义**：同义 broad（宽阔的）, spacious（宽敞的）；反义 narrow（窄的）, tight（紧的）。
- **变形**：形容词 → 比较级：wider；最高级：widest；名词派生 → width n. 宽度；副词派生 → widely adv. 广泛地；动词派生 → widen v. 加宽。

### 16. whale /weɪl/ n. 鲸
- **词根·渊源**：古英语 **hwæl**（鲸）→ 英语；与古高地德语 *wal* 同源，本义“鲸”，词源更早来源存疑。
- **同根词**：whaling（whale + **-ing** 名词后缀：捕鲸）、whalebone（whale + bone 骨 = 鲸须）、whale shark（whale + shark = 鲸鲨）。
- **前缀·后缀**：名词后缀 **-ing**（例：fishing, hunting）。
- **同义·反义**：同义 无；反义 无。
- **变形**：名词 → 复数：whales（作“鲸鱼肉”义时不可数）；名词派生 → whaling n. 捕鲸。

### 17. butterfly /ˈbətərˌflaɪ/ n. 蝴蝶
- **词根·渊源**：古英语 **buttorfleoge**（黄油蝇）→ 英语；本义“黄油色的飞虫”，一说因蝴蝶翅膀黄色或喜落黄油，词源细节存疑；引申为“蝴蝶”。
- **同根词**：butterfly effect（butterfly + effect = 蝴蝶效应）、butterfly stroke（butterfly + stroke = 蝶泳）。
- **前缀·后缀**：无前后缀（复合词：butter + fly）。
- **同义·反义**：同义 无；反义 无。
- **变形**：名词 → 复数：butterflies；形容词派生 → buttery adj. 黄油般的（与 butterfly 无直接派生关系，仅示 butter 派生）。

### 18. provide /prəˈvaɪd/ v. 提供；供应
- **词根·渊源**：拉丁 **providere**（预先看见、预先准备）→ 古法语 *porveoir* → 英语；本义“预先看到并准备”，引申为“提供、供应”。
- **同根词**：provision（**pro-** 预先 + vis 看 + **-ion** 名词后缀 = 预先准备→供给）、provident（**pro-** 预先 + vid 看 + **-ent** …的 = 有远见的）、improvise（**im-** 不 + pro- 预先 + vis 看 = 未预见→即兴创作）、video（拉丁 videre 看 = 视频）。
- **前缀·后缀**：前缀 **pro-**（例：protect, produce）；动词后缀 **-ide**（例：decide, divide）。
- **同义·反义**：同义 supply（供应）, offer（提供）；反义 deny（拒绝给予）, withhold（扣留）。
- **变形**：动词 → 第三人称单数：provides；过去式：provided；过去分词：provided；现在分词：providing；名词派生 → provision n. 供给；provider n. 提供者。

### 19. explore /ɪkˈsplɔr/ v. 探索
- **词根·渊源**：拉丁 **plor-**（喊叫）→ 拉丁 *explorare*（喊叫着搜寻→探查）→ 拉丁 *explorare* 过去分词 *exploratus* → 英语 explore；本义“猎人喊叫着把猎物赶出来”，引申为“探查、探索”。
- **同根词**：exploration（explor(e) + **-ation** 名词后缀：探索）、explorer（explore + **-er** 人：探索者）、exploratory（explor(e) + **-atory** 形容词后缀：探索性的）、inexplorable（**in-** 不 + explorable 可探索的：无法探索的，罕用）。
- **前缀·后缀**：前缀 **ex-**（例：export, exit）；动词后缀 **-e**（例：create, produce，此处为拉丁词干保留）。
- **同义·反义**：同义 search（搜寻）, investigate（调查）；反义 ignore（忽视）, neglect（忽略）。
- **变形**：动词 → 第三人称单数：explores；过去式：explored；过去分词：explored；现在分词：exploring；名词派生 → exploration n. 探索；explorer n. 探索者；形容词派生 → exploratory adj. 探索性的。

### 20. disappear /ˌdɪsəˈpɪr/ v. 消失；不见
- **词根·渊源**：拉丁 **parere**（出现）→ 古法语 *paroir* → 英语 appear（出现）；加否定前缀 **dis-** 构成 disappear，本义“不出现”，即“消失”。
- **同根词**：appear（**ap-** 向 + pear 出现 = 出现）、appearance（appear + **-ance** 名词后缀：出现；外貌）、apparent（**ap-** 向 + par 出现 + **-ent** 形容词后缀：明显的）、reappear（**re-** 再 + appear 出现 = 再出现）。
- **前缀·后缀**：前缀 **dis-**（例：disagree, dislike）；词根 **pear** 来自拉丁 *parere*（例：appear, apparent）。
- **同义·反义**：同义 vanish（消失）, fade（逐渐消失）；反义 appear（出现）, emerge（浮现）。
- **变形**：动词 → 第三人称单数：disappears；过去式：disappeared；过去分词：disappeared；现在分词：disappearing；名词派生 → disappearance n. 消失。

### 21. plastic /ˈplæstɪk/ n. 塑料
- **词根·渊源**：希腊 **plastos**（被塑造的）→ 拉丁 *plasticus* → 英语 plastic；本义“可塑的”，19世纪起指“可塑材料”，后专指“塑料”。
- **同根词**：plaster（希腊 *plastos* 被塑造的 → 古英语 *plaster* 膏药→灰泥）、plastics（plastic + **-s** 复数/学科：塑料制品；塑料学）、plasticity（plastic + **-ity** 名词后缀：可塑性）、plasticize（plastic + **-ize** 动词后缀：使可塑）。
- **前缀·后缀**：形容词/名词后缀 **-ic**（例：basic, music）；名词后缀 **-ity**（例：ability, reality）。
