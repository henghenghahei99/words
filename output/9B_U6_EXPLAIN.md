## 二、逐词说文解字

### 1. conduct /kənˈdʌkt , ˈkɒndʌkt/ v. 实施；执行
- **词根·渊源**：拉丁 **con-**（一起）+ **ducere**（引导）→ 拉丁 *conductus* → 古法语 *conduire* → 英语；本义“引导在一起”，引申为“带领、实施、执行”。
- **同根词**：introduce（**intro-** 向内 + duc 引导 = 引进→介绍）、produce（**pro-** 向前 + duc 引导 = 向前引出→生产）、reduce（**re-** 回 + duc 引导 = 引回→减少）、educate（**e-** 出 + duc 引导 = 引出潜能→教育）、conductive（conduct + **-ive** …的：传导的）。
- **前缀·后缀**：前缀 **con-**（例：connect, confirm）；词根 **duc/duct**（例：product, reduce）。
- **同义·反义**：同义 perform（执行）, carry out（实施）；反义 neglect（忽视）。
- **变形**：动词 → 第三人称单数：conducts；过去式：conducted；过去分词：conducted；现在分词：conducting；名词派生 → conductor n. 指挥、导体；conduction n. 传导；形容词派生 → conductive adj. 传导的。

### 2. lifestyle /'laɪfstaɪl/ n. 生活方式；工作方式
- **词根·渊源**：古英语 **līf**（生命）+ 古法语 **estile**（方式、风格，源自拉丁 *stilus* 笔→书写方式）→ 英语复合词；本义“生活的方式”。
- **同根词**：life（单纯词：生命）、lively（life + **-ly** …地：活泼地）、style（单纯词：风格）、stylish（style + **-ish** …的：时髦的）。
- **前缀·后缀**：无前后缀（复合词：life + style）。
- **同义·反义**：同义 way of life（生活方式）；反义 无。
- **变形**：名词 → 复数：lifestyles；形容词派生 → lifestyle adj. 生活方式的（作定语）。

### 3. quarrel /'kwɒrəl/ n. 争吵
- **词根·渊源**：拉丁 **querela / querella**（抱怨、控诉，源自 *queri* 抱怨）→ 古法语 *querele* → 英语；本义“抱怨、控诉”，引申为“争吵”。
- **同根词**：quarrelsome（quarrel + **-some** 易…的：爱争吵的）、querulous（拉丁 quer 抱怨 + **-ulous** 多…的：爱抱怨的）。
- **前缀·后缀**：名词后缀 **-some**（例：troublesome, handsome）。
- **同义·反义**：同义 argument（争论）, dispute（争端）；反义 agreement（一致）, harmony（和睦）。
- **变形**：名词 → 复数：quarrels；动词派生 → quarrel v. 争吵（第三人称单数：quarrels；过去式：quarrelled；过去分词：quarrelled；现在分词：quarrelling）；形容词派生 → quarrelsome adj. 爱争吵的。

### 4. focus /ˈfəʊkəs/ n. 集中（注意力、精力等）于
- **词根·渊源**：拉丁 **focus**（炉灶、火塘）→ 17世纪拉丁科学用语“光线汇聚点”→ 英语；本义“炉火中心”，引申为“焦点”，再引申为“集中”。
- **同根词**：focal（focus + **-al** …的：焦点的）、focused（focus + **-ed** 集中的）、refocus（**re-** 再 + focus = 重新聚焦）。
- **前缀·后缀**：前缀 **re-**（例：return, rebuild）；形容词后缀 **-al**（例：natural, central）。
- **同义·反义**：同义 concentrate（集中）, center（集中）；反义 distract（分散注意力）。
- **变形**：名词 → 复数：focuses / foci；动词派生 → focus v. 集中（第三人称单数：focuses；过去式：focused；过去分词：focused；现在分词：focusing）；形容词派生 → focused adj. 专注的；focal adj. 焦点的。

### 5. peer /pɪə(r)/ n. 同龄人；同辈
- **词根·渊源**：古法语 **per**（同等的人，源自拉丁 *par* 相等的）→ 英语；本义“地位相等的人”，引申为“同龄人、同辈”。
- **同根词**：peerless（peer + **-less** 无…的：无与伦比的）、peerage（peer + **-age** 集合名词：贵族爵位）。
- **前缀·后缀**：形容词后缀 **-less**（例：hopeless, careless）；名词后缀 **-age**（例：marriage, package）。
- **同义·反义**：同义 equal（同等的人）, contemporary（同代人）；反义 superior（上级）, inferior（下级）。
- **变形**：名词 → 复数：peers；形容词派生 → peerless adj. 无与伦比的。

### 6. pressure /ˈprɛʃɚ/ n. 压力
- **词根·渊源**：拉丁 **premere / press-**（压）→ 拉丁 *pressura* → 古法语 *pressure* → 英语；本义“压的动作”，引申为“压力”。
- **同根词**：press（单纯词：压、按）、compress（**com-** 一起 + press 压 = 压在一起→压缩）、express（**ex-** 出 + press 压 = 压出→表达）、impress（**im-** 入 + press 压 = 压入→使印象深刻）、depress（**de-** 向下 + press 压 = 压下→使沮丧）。
- **前缀·后缀**：前缀 **com-**（例：combine）、**ex-**（例：export）、**im-**（例：import）、**de-**（例：decline）；名词后缀 **-ure**（例：failure, pleasure）。
- **同义·反义**：同义 stress（压力）, burden（负担）；反义 relief（缓解）, ease（轻松）。
- **变形**：名词 → 复数：pressures；动词派生 → pressurize v. 加压；形容词派生 → pressurised adj. 加压的。

### 7. whether /ˈweðər/ conj. 是否；不管
- **词根·渊源**：古英语 **hwæther**（两者中的哪一个，源自 PIE *kwo-* 疑问词根）→ 中古英语 *whether* → 英语；本义“两者中哪一个”，引申为“是否”。
- **同根词**：who（单纯词：谁）、what（单纯词：什么）、which（单纯词：哪一个）、when（单纯词：何时）。
- **前缀·后缀**：无前后缀（单纯词）。
- **同义·反义**：同义 if（是否）；反义 无。
- **变形**：连词 → 无形态变化。

### 8. risk /rɪsk/ n. 危险；风险；冒险
- **词根·渊源**：意大利语 **rischio / risco**（危险，源自希腊 *rhiza* 悬崖？存疑）→ 法语 *risque* → 英语；本义“危险”，引申为“风险、冒险”。
- **同根词**：risky（risk + **-y** 多…的：危险的）、riskless（risk + **-less** 无…的：无风险的）。
- **前缀·后缀**：形容词后缀 **-y**（例：rainy, healthy）；**-less**（例：fearless, hopeless）。
- **同义·反义**：同义 danger（危险）, hazard（风险）；反义 safety（安全）, security（安全）。
- **变形**：名词 → 复数：risks；动词派生 → risk v. 冒险（第三人称单数：risks；过去式：risked；过去分词：risked；现在分词：risking）；形容词派生 → risky adj. 危险的。

### 9. guard /gɑ:rd/ n. 警卫；看守；守卫；保卫
- **词根·渊源**：古法语 **garder**（看守、保护，源自日耳曼语 *wardon* 看守）→ 英语；本义“看守”，引申为“警卫、保卫”。
- **同根词**：guardian（guard + **-ian** 人：监护人）、guarded（guard + **-ed** 被保护的：谨慎的）、safeguard（**safe** 安全 + guard 保护 = 安全保护→保卫）。
- **前缀·后缀**：名词后缀 **-ian**（例：musician, librarian）；形容词后缀 **-ed**（例：talented, gifted）。
- **同义·反义**：同义 watchman（看守）, protector（保护者）；反义 attacker（攻击者）。
- **变形**：名词 → 复数：guards；动词派生 → guard v. 守卫（第三人称单数：guards；过去式：guarded；过去分词：guarded；现在分词：guarding）；名词派生 → guardian n. 监护人；形容词派生 → guarded adj. 谨慎的。

### 10. positive /ˈpɒzətɪv/ adj. 积极乐观的；自信的；正面的
- **词根·渊源**：拉丁 **ponere / posit-**（放置）→ 拉丁 *positivus*（被放置的、确定的）→ 古法语 *positif* → 英语；本义“被确定的”，引申为“积极的、正面的”。
- **同根词**：position（posit 放置 + **-ion** 名词：位置）、compose（**com-** 一起 + pos 放置 = 放在一起→组成）、deposit（**de-** 向下 + posit 放置 = 放下→存款）、expose（**ex-** 出 + pos 放置 = 放出来→暴露）、propose（**pro-** 向前 + pos 放置 = 向前放→提议）。
- **前缀·后缀**：前缀 **com-**（例：combine）、**de-**（例：decline）、**ex-**（例：export）、**pro-**（例：progress）；形容词后缀 **-ive**（例：active, creative）。
- **同义·反义**：同义 optimistic（乐观的）, confident（自信的）；反义 negative（消极的）, pessimistic（悲观的）。
- **变形**：形容词 → 比较级：more positive；最高级：most positive；名词派生 → positivity n. 积极性；副词派生 → positively adv. 积极地。

### 11. cancel /ˈkænsəl/ v. 取消；终止
- **词根·渊源**：拉丁 **cancelli**（栅栏、格子，源自 *cancer* 交叉线）→ 拉丁 *cancellare*（画交叉线划掉）→ 古法语 *canceler* → 英语；本义“画格子划掉”，引申为“取消”。
- **同根词**：cancellation（cancel + **-ation** 名词：取消）、cancelled（cancel + **-ed** 被取消的）。
- **前缀·后缀**：名词后缀 **-ation**（例：information, education）；形容词后缀 **-ed**（例：excited, tired）。
- **同义·反义**：同义 call off（取消）, abolish（废除）；反义 confirm（确认）, continue（继续）。
- **变形**：动词 → 第三人称单数：cancels；过去式：cancelled；过去分词：cancelled；现在分词：cancelling；名词派生 → cancellation n. 取消。

### 12. bright /braɪt/ adj. 有希望的
- **词根·渊源**：古英语 **beorht**（明亮的，源自 PIE *bhereg-* 发光）→ 中古英语 *bright* → 英语；本义“明亮的”，引申为“有希望的”。
- **同根词**：brighten（bright + **-en** 使…：使明亮）、brightly（bright + **-ly** …地：明亮地）、brightness（bright + **-ness** 名词：明亮）。
- **前缀·后缀**：动词后缀 **-en**（例：widen, strengthen）；副词后缀 **-ly**（例：quickly, happily）；名词后缀 **-ness**（例：happiness, darkness）。
- **同义·反义**：同义 promising（有希望的）, hopeful（有希望的）；反义 hopeless（无望的）, dim（暗淡的）。
- **变形**：形容词 → 比较级：brighter；最高级：brightest；动词派生 → brighten v. 使明亮；副词派生 → brightly adv. 明亮地；名词派生 → brightness n. 明亮。

### 13. force /fɔːs/ n. 强迫；迫使（某人做某事）
- **词根·渊源**：拉丁 **fortis**（强壮的）→ 俗拉丁 *fortia* → 古法语 *force* → 英语；本义“力量”，引申为“强迫、迫使”。
- **同根词**：forceful（force + **-ful** 充满…的：有力的）、enforce（**en-** 使 + force 力量 = 使有力量→执行）、reinforce（**re-** 再 + in 入 + force 力量 = 再注入力量→加强）、fortify（拉丁 fort 强 + **-ify** 使…：加固）。
- **前缀·后缀**：前缀 **en-**（例：enable）、**re-**（例：return）；形容词后缀 **-ful**（例：helpful, useful）；动词后缀 **-ify**（例：simplify, beautify）。
- **同义·反义**：同义 compel（强迫）, oblige（迫使）；反义 allow（允许）, permit（准许）。
- **变形**：名词 → 复数：forces；动词派生 → force v. 强迫（第三人称单数：forces；过去式：forced；过去分词：forced；现在分词：forcing）；形容词派生 → forceful adj. 有力的；副词派生 → forcefully adv. 强有力地。

### 14. concert /ˈkɒnsət/ v. 音乐会；演奏会
- **词根·渊源**：拉丁 **con-**（一起）+ **certare**（竞争、努力）→ 意大利语 *concerto*（协调、一致）→ 法语 *concert* → 英语；本义“协调一致”，引申为“音乐会”。

- **变形**：名词 → 复数：concerts；动词派生 → concert v. 协调（第三人称单数：concerts；过去式：concerted；过去分词：concerted；现在分词：concerting）；形容词派生 → concerted adj. 一致的。

### 15. private /ˈpraɪvɪt/ adj. 私人的；私密的
- **词根·渊源**：拉丁 **privus**（个人的、单独的）+ **-atus** → 拉丁 *privatus*（私人的）→ 古法语 *prive* → 英语；本义“个人的”，引申为“私人的、私密的”。

### 18. enemy /ˈenəmi/ n. 危害物；大敌

### 19. regular /ˈreɡjələr/ adj. 有规律的
- **词根·渊源**：拉丁 **regula**（尺子、规则）→ 晚期拉丁 *regularis*（合乎规则的）→ 古法语 *reguler* → 英语 regular；本义“按尺子量过的、合乎规则的”，引申为“有规律的”。
- **同根词**：regulate（regula 规则 + **-ate** 动词后缀 = 按规则管理→调节）、regulation（regulate + **-ion** 名词后缀 = 调节→规章）、rule（拉丁 regula 经古法语 riule 缩合而来 = 尺子→规则）、ruler（rule 规则 + **-er** 表物 = 划线的尺→尺子；表人 = 定规则的人→统治者）、regularity（regular + **-ity** 名词后缀 = 规律性）。
- **前缀·后缀**：形容词后缀 **-ar**（例：similar, familiar）；名词后缀 **-ity**（例：activity, reality）。
- **同义·反义**：同义 steady（稳定的）, routine（例行的）；反义 irregular（不规律的）, random（随意的）。
- **变形**：形容词 → 比较级：more regular；最高级：most regular；名词派生 → regularity n. 规律性；副词派生 → regularly adv. 有规律地；动词派生 → regulate v. 调节。

### 20. cheer /tʃɪə(r)/ v. 鼓励；鼓舞
- **词根·渊源**：古法语 **chiere**（脸、表情）← 晚期拉丁 *cara*（脸）← 希腊 *kara*（头）；本义“面容、神色”，由“面露喜色”引申为“使高兴、鼓舞”。
- **同根词**：cheerful（cheer 高兴 + **-ful** 充满……的 = 高兴的）、cheerless（cheer + **-less** 无……的 = 阴郁的）、cheery（cheer + **-y** 形容词后缀 = 欢快的）、cheerleader（cheer 喝彩 + leader 领头者 = 啦啦队长）。
- **前缀·后缀**：形容词后缀 **-ful**（例：helpful, useful）；否定后缀 **-less**（例：hopeless, careless）。
- **同义·反义**：同义 encourage（鼓励）, applaud（喝彩）；反义 discourage（使泄气）, depress（使沮丧）。
- **变形**：动词 → 第三人称单数：cheers；过去式：cheered；过去分词：cheered；现在分词：cheering；名词 → 复数：cheers；形容词派生 → cheerful adj. 高兴的；副词派生 → cheerfully adv. 高兴地。

### 21. low /ləʊ/ adj. 沮丧的；消沉的；无精打采的
- **词根·渊源**：古诺斯语 **lágr**（低的）→ 中古英语 *low*；本义“位置低”，由“身体低垂、情绪低落”引申为“沮丧的、消沉的”。
- **同根词**：lower（low 低 + **-er** 比较级后缀 = 更低的→降低）、lowly（low + **-ly** 形容词后缀 = 地位低的→谦卑的）、below（**be-** 在 + low 低 = 在下面）、lowland（low 低 + land 地 = 低地）。
- **前缀·后缀**：比较级后缀 **-er**（例：higher, smaller）；前缀 **be-**（例：behind, beneath）。
- **同义·反义**：同义 sad（悲伤的）, depressed（沮丧的）；反义 high（高的）, cheerful（高兴的）。
- **变形**：形容词 → 比较级：lower；最高级：lowest；名词派生 → lowness n. 低；副词派生 → low adv. 低地；动词派生 → lower v. 降低。

### 22. eyesight /'aɪsaɪt/ n. 视力
- **词根·渊源**：古英语 **ēage**（眼）+ **gesihth**（看、景象）→ 中古英语 *eyesight*；复合词，本义“眼睛的看视能力”，即“视力”。
- **同根词**：eye（古英语 ēage 眼 = 眼睛）、sight（古英语 gesihth 看 = 视力、景象）、sightseeing（sight 景象 + seeing 看 = 观光）、insight（**in-** 向内 + sight 看 = 看进去→洞察力）、eyesore（eye 眼 + sore 痛处 = 刺眼之物）。
- **前缀·后缀**：复合词无前后缀（eye + sight 复合）；相关前缀 **in-**（例：indoor, income）。
- **同义·反义**：同义 vision（视力）, sight（视力）；反义 blindness（失明）。
- **变形**：名词 → 复数：不可数；形容词派生 → eyesighted adj. 有视力的。

### 23. dentist /ˈdɛntɪst/ n. 牙医
- **词根·渊源**：拉丁 **dens / dent-**（牙齿）+ 法语 **-iste**（从事……的人）→ 法语 *dentiste* → 英语 dentist；本义“治牙的人”，即“牙医”。
- **同根词**：dental（dent 牙 + **-al** 形容词后缀 = 牙齿的）、dentine（dent + **-ine** 物质后缀 = 牙本质）、denture（dent + **-ure** 名词后缀 = 假牙）、orthodontist（**ortho-** 正 + dont 牙 + **-ist** 人 = 正牙医生）。
- **前缀·后缀**：名词后缀 **-ist**（例：artist, scientist）；形容词后缀 **-al**（例：natural, musical）。
- **同义·反义**：同义 dental surgeon（牙外科医生）；反义 无。
- **变形**：名词 → 复数：dentists；名词派生 → dentistry n. 牙科学；形容词派生 → dental adj. 牙齿的。

### 24. recovery /rɪˈkʌvəri/ n. 恢复；痊愈
- **词根·渊源**：古法语 **recovrer**（重新获得）← 拉丁 *recuperare*（**re-** 再 + *capere* 拿取）→ 英语 recover + **-y** 名词后缀；本义“重新拿回”，引申为“恢复、痊愈”。
- **同根词**：recover（**re-** 再 + cover 拿取 = 重新获得→恢复）、recuperate（拉丁 recuperare 恢复 + **-ate** 动词后缀 = 康复）、cover（拉丁 capere 拿取经古法语 covrir = 遮盖→覆盖）。
- **前缀·后缀**：前缀 **re-**（例：return, rebuild）；名词后缀 **-y**（例：discovery, delivery）。
- **同义·反义**：同义 healing（痊愈）, restoration（恢复）；反义 relapse（复发）, decline（衰退）。
- **变形**：名词 → 复数：recoveries；动词派生 → recover v. 恢复；形容词派生 → recoverable adj. 可恢复的。
