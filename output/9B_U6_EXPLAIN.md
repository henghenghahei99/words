## 二、逐词说文解字

### 1. bell /bɛl/ n. 钟) 声；(铃) 声
- **词根·渊源**：古英语 **bell**（钟）→ 中世纪英语 *belle*，本义“钟、铃”，拟声来源，模仿钟铃之声；引申为“钟声、铃声”。
- **同根词**：bellboy（bell + boy = 按铃叫的男孩→旅馆侍者）、bellman（bell + man = 摇铃人→更夫）、bellflower（bell + flower = 钟形花→风铃草）、doorbell（door + bell = 门铃）、belfry（bell + **-ry** 场所 = 钟楼）。
- **前缀·后缀**：无前后缀（单纯词）。
- **同义·反义**：同义 chime（钟声）, ring（铃声）；反义 无。
- **变形**：名词 → 复数：bells；形容词派生 → bell-like adj. 钟形的。

### 2. thankfully /ˈθæŋkfəli/ adv. 用以表示高兴）幸亏
- **词根·渊源**：古英语 **thanc**（思想、感谢）→ 古英语 *þancian*（感谢）→ thank + **-ful**（充满…的）+ **-ly**（…地），本义“充满感谢地”，引申为“幸亏、令人高兴地”。
- **同根词**：thank（古英语 þancian 感谢→感谢）、thankful（thank + **-ful** 充满…的→感激的）、thankless（thank + **-less** 无…的→不感激的）、thanksgiving（thanks + giving 给→感恩）。
- **前缀·后缀**：形容词后缀 **-ful**（例：helpful, useful）；副词后缀 **-ly**（例：quickly, happily）。
- **同义·反义**：同义 fortunately（幸运地）, luckily（幸亏）；反义 unfortunately（不幸地）, sadly（遗憾地）。
- **变形**：副词 → 无比较级（派生副词，不作比较）；形容词派生 → thankful adj. 感激的；名词派生 → thankfulness n. 感激。

### 3. slide /slaɪd/ n. 幻灯片
- **词根·渊源**：古英语 **slīdan**（滑行）→ 中世纪英语 *sliden*，本义“滑动”，引申为“滑动的透明片”→幻灯片。
- **同根词**：slider（slide + **-er** 物→滑动者/滑动物）、sliding（slide + **-ing** …的→滑动的）、slip（同源日耳曼语滑→滑倒）、sled（同源→雪橇）、sledge（同源→雪橇）。
- **前缀·后缀**：名词后缀 **-er**（例：worker, teacher）。
- **同义·反义**：同义 transparency（幻灯片）, film（胶片）；反义 无。
- **变形**：名词 → 复数：slides；动词 → 第三人称单数：slides；过去式：slid；过去分词：slid；现在分词：sliding；形容词派生 → sliding adj. 滑动的。

### 4. flag /flæg/ n. 旗
- **词根·渊源**：中世纪英语 **flagge**（旗）→ 可能源自日耳曼语 *flak-*（飘动），本义“飘动的布片”，引申为“旗帜”；词源存疑。
- **同根词**：flagpole（flag + pole 杆→旗杆）、flagstone（flag 石板 + stone 石→石板）、flagship（flag + ship 船→旗舰）、flagman（flag + man 人→旗手）。
- **前缀·后缀**：无前后缀（单纯词）。
- **同义·反义**：同义 banner（旗帜）, standard（旗标）；反义 无。
- **变形**：名词 → 复数：flags；动词 → 第三人称单数：flags；过去式：flagged；过去分词：flagged；现在分词：flagging。

### 5. anyway /ˈɛniˌweɪ/ adv. 尽管；即使这样
- **词根·渊源**：古英语 **ān**（一）+ **weg**（路）→ any + way，本义“任何一条路”，引申为“无论如何、尽管”。
- **同根词**：any（古英语 ænig 任何→任何）、anyhow（any + how 方式→无论如何）、anyone（any + one 人→任何人）、anything（any + thing 事物→任何事物）、anywhere（any + where 地方→任何地方）。
- **前缀·后缀**：无前后缀（复合词）。
- **同义·反义**：同义 anyhow（无论如何）, nevertheless（尽管如此）；反义 无。
- **变形**：副词 → 无比较级（复合副词，不作比较）。

### 6. bat /bæt/ n. 球棒；球拍
- **词根·渊源**：古英语 **batt**（棒）→ 古法语 *batte*（棒），本义“打击用的棒”，引申为“球棒、球拍”。
- **同根词**：batter（bat + **-er** 反复动作→连续猛击）、batsman（bat + s + man 人→击球手）、batting（bat + **-ing** 动作→击球）。
- **前缀·后缀**：名词后缀 **-er**（例：runner, player）。
- **同义·反义**：同义 club（棍棒）, racket（球拍）；反义 无。
- **变形**：名词 → 复数：bats；动词 → 第三人称单数：bats；过去式：batted；过去分词：batted；现在分词：batting。

### 7. similarity /ˌsɪməˈlɛrəti/ n. 相似处；相似点
- **词根·渊源**：拉丁 **similis**（相似的）→ 古法语 *similaire* → 英语 similar + **-ity**（性质），本义“相似的性质”，引申为“相似处”。
- **同根词**：similar（拉丁 similis 相似 + **-ar** …的→相似的）、similarly（similar + **-ly** …地→相似地）、simile（拉丁 similis 相似→明喻）、simulate（拉丁 simulare 使相似→模拟）、assimilate（**as-** 向 + simil 相似 + **-ate** 使→同化）。
- **前缀·后缀**：名词后缀 **-ity**（例：activity, reality）；形容词后缀 **-ar**（例：familiar, popular）。
- **同义·反义**：同义 resemblance（相似）, likeness（相像）；反义 difference（不同）, dissimilarity（相异）。
- **变形**：名词 → 复数：similarities；形容词派生 → similar adj. 相似的；副词派生 → similarly adv. 相似地。

### 8. primary /ˈpraɪˌmɛri/ adj. 初等教育的；小学教育的
- **词根·渊源**：拉丁 **primus**（第一）→ 拉丁 *primarius*（首要的）→ 英语 primary，本义“第一的、首要的”，引申为“初等的、小学的”。
- **同根词**：prime（拉丁 primus 第一→首要的）、primal（拉丁 primus 第一 + **-al** …的→最初的）、primate（拉丁 primas 首领→灵长类）、primer（prime + **-er** 物→入门书）、primitive（拉丁 primitivus 最初的→原始的）。
- **前缀·后缀**：形容词后缀 **-ary**（例：ordinary, necessary）。
- **同义·反义**：同义 elementary（初等的）, basic（基本的）；反义 secondary（中等的）, advanced（高级的）。
- **变形**：形容词 → 无比较级（关系形容词，不作比较）；名词派生 → primary n. 初选；副词派生 → primarily adv. 主要地。

### 9. custom /ˈkəstəm/ n. 风俗；习俗
- **词根·渊源**：拉丁 **consuetudo**（习惯）→ 古法语 *costume* → 英语 custom，本义“惯常做法”，引申为“风俗、习俗”。
- **同根词**：customer（custom + **-er** 人→习惯来买东西的人→顾客）、customary（custom + **-ary** …的→习惯的）、customize（custom + **-ize** 使→定制）、accustom（**ac-** 使 + custom 习惯→使习惯）、costume（同源→服装）。
- **前缀·后缀**：名词后缀 **-er**（例：farmer, buyer）；动词前缀 **ac-**（例：accept, achieve）。
- **同义·反义**：同义 tradition（传统）, convention（惯例）；反义 无。
- **变形**：名词 → 复数：customs；形容词派生 → customary adj. 习惯的；动词派生 → customize v. 定制。

### 10. packet /ˈpækɪt/ n. 商品的）小包装纸袋
- **词根·渊源**：中古英语 **pak**（包）→ 英语 pack + **-et**（小），本义“小包”，引申为“小包装纸袋”。
- **同根词**：pack（中古英语 pak 包→打包）、package（pack + **-age** 名词→包裹）、packer（pack + **-er** 人→包装工）、packet（pack + **-et** 小→小包）。
- **前缀·后缀**：指小后缀 **-et**（例：bullet, pocket）；名词后缀 **-age**（例：baggage, postage）。
- **同义·反义**：同义 package（包裹）, parcel（小包）；反义 无。
- **变形**：名词 → 复数：packets；动词派生 → pack v. 打包。

### 11. exist /ɪgˈzɪst/ v. 存在；实际上有
- **词根·渊源**：拉丁 **existere**（出现、站出）→ 拉丁 *exsistere*（ex- 出 + sistere 站立）→ 英语 exist，本义“站出来、显现”，引申为“存在”。
- **同根词**：existence（exist + **-ence** 名词→存在）、existent（exist + **-ent** …的→存在的）、existing（exist + **-ing** …的→现存的）、coexist（**co-** 共同 + exist 存在→共存）、preexist（**pre-** 先 + exist 存在→先存在）。
- **前缀·后缀**：前缀 **ex-**（例：exit, export）；前缀 **co-**（例：cooperate, connect）；名词后缀 **-ence**（例：difference, silence）。
- **同义·反义**：同义 be（存在）, live（生存）；反义 vanish（消失）, die（消亡）。
- **变形**：动词 → 第三人称单数：exists；过去式：existed；过去分词：existed；现在分词：existing；名词派生 → existence n. 存在；形容词派生 → existent adj. 存在的。

### 12. dictionary /ˈdɪkʃəˌnɛri/ n. 词典；字典
- **词根·渊源**：拉丁 **dictio**（说、词）→ 中世纪拉丁 *dictionarium*（词集）→ 英语 dictionary，本义“词语的汇集”，引申为“词典”。
- **同根词**：dictate（拉丁 dictare 口述→口述）、dictation（dictate + **-ion** 名词→听写）、dictator（dictate + **-or** 人→独裁者）、predict（**pre-** 先 + dict 说→预言）、contradict（**contra-** 反 + dict 说→反驳）。
- **前缀·后缀**：名词后缀 **-ary**（例：library, salary）；前缀 **pre-**（例：preview, prepare）；前缀 **contra-**（例：contrast, contrary）。
- **同义·反义**：同义 lexicon（词典）, glossary（词汇表）；反义 无。
- **变形**：名词 → 复数：dictionaries。

### 13. pronounce /prəˈnaʊns/ v. 发音；读 (音)
- **词根·渊源**：拉丁 **pronuntiare**（宣布）→ 古法语 *prononcier* → 英语 pronounce，本义“公开说出”，引申为“发音”。
- **同根词**：pronunciation（pronounce + **-iation** 名词→发音）、pronouncement（pronounce + **-ment** 名词→声明）、announce（**an-** 向 + nounce 说→宣布）、denounce（**de-** 向下 + nounce 说→谴责）、enunciate（**e-** 出 + nunci 说 + **-ate** 动词→清晰发音）。
- **前缀·后缀**：前缀 **pro-**（例：protect, produce）；前缀 **an-**（例：announce, annoy）；名词后缀 **-ment**（例：movement, agreement）。
- **同义·反义**：同义 articulate（清晰发音）, utter（说出）；反义 无。
- **变形**：动词 → 第三人称单数：pronounces；过去式：pronounced；过去分词：pronounced；现在分词：pronouncing；名词派生 → pronunciation n. 发音。

### 14. firework /ˈfaɪrˌwərk/ n. 烟火；烟花
- **词根·渊源**：古英语 **fȳr**（火）+ **weorc**（工作）→ fire + work，本义“火的作品”，引申为“烟火、烟花”。
- **同根词**：fire（古英语 fȳr 火→火）、work（古英语 weorc 工作→工作）、fireman（fire + man 人→消防员）、fireplace（fire + place 地方→壁炉）、firewood（fire + wood 木→柴火）。
- **前缀·后缀**：无前后缀（复合词）。
- **同义·反义**：同义 fireworks（烟花）, pyrotechnics（烟火）；反义 无。
- **变形**：名词 → 复数：fireworks。

### 15. evidence /ˈɛvədəns/ n. 根据；证明
- **词根·渊源**：拉丁 **evidentia**（明显）→ 古法语 *evidence* → 英语 evidence，本义“明显可见之物”，引申为“证据、证明”。
- **同根词**：evident（拉丁 evidens 明显 + **-ent** …的→明显的）、evidently（evident + **-ly** …地→明显地）、evidential（evidence + **-ial** …的→证据的）。
- **前缀·后缀**：前缀 **e-**（例：evolve, emit）；名词后缀 **-ence**（例：difference, patience）。
- **同义·反义**：同义 proof（证明）, testimony（证词）；反义 无。
- **变形**：名词 → 复数：evidences（多作不可数）；形容词派生 → evident adj. 明显的；副词派生 → evidently adv. 明显地。
