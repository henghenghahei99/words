## 二、逐词说文解字

### 1. guide /gaɪd/ n. 指南；手册
- **词根·渊源**：日耳曼语 *witan*（知道、引导）→ 古法语 *guider*（引导）→ 英语 guide；本义“引导、指路”，引申为“起引导作用的东西”→指南、手册。
- **同根词**：guidance（guide + **-ance** 名词后缀：引导、指导）、guideline（guide 引导 + line 线 = 引导线→指导方针）、misguide（**mis-** 错误 + guide 引导 = 错误引导→误导）、guider（guide + **-er** 人：引导者）。
- **前缀·后缀**：名词后缀 **-ance**（例：importance, distance）；前缀 **mis-**（例：mistake, misunderstand）。
- **同义·反义**：同义 manual（手册）, handbook（手册）；反义 无。
- **变形**：名词 → 复数：guides；动词派生 → guide v. 引导；名词派生 → guidance n. 指导；形容词派生 → guiding adj. 指导的。

### 2. east /ist/ n. 东；东方;adv.朝东
- **词根·渊源**：原始日耳曼语 *aust-*（朝向日出方向）→ 古英语 *ēast*；本义“日出之处”，即“东方”；与拉丁 *aurora*（黎明）同出 PIE *aus-*（发光、黎明）。
- **同根词**：eastern（east + **-ern** 方位后缀：东方的）、eastward（east + **-ward** 朝…方向：向东）、northeast（north 北 + east 东 = 东北）、southeast（south 南 + east 东 = 东南）。
- **前缀·后缀**：方位后缀 **-ern**（例：western, southern）；方向后缀 **-ward**（例：forward, backward）。
- **同义·反义**：同义 orient（东方）；反义 west（西方）。
- **变形**：名词 → 复数：easts（作方位义通常不可数）；副词 → 无比较级（方位副词）；形容词派生 → eastern adj. 东方的；副词派生 → eastward adv. 向东。

### 3. west /wɛst/ n. 西；西方;adv.朝西
- **词根·渊源**：原始日耳曼语 *west-*（日落方向）→ 古英语 *west*；本义“日落之处”，即“西方”；与拉丁 *vesper*（傍晚）同出 PIE *wes-pero-*（傍晚）。
- **同根词**：western（west + **-ern** 方位后缀：西方的）、westward（west + **-ward** 朝…方向：向西）、northwest（north 北 + west 西 = 西北）、southwest（south 南 + west 西 = 西南）。
- **前缀·后缀**：方位后缀 **-ern**（例：eastern, northern）；方向后缀 **-ward**（例：toward, homeward）。
- **同义·反义**：同义 occident（西方）；反义 east（东方）。
- **变形**：名词 → 复数：wests（作方位义通常不可数）；副词 → 无比较级（方位副词）；形容词派生 → western adj. 西方的；副词派生 → westward adv. 向西。

### 4. mix /mɪks/ n. 混合；结合
- **词根·渊源**：拉丁 *miscēre*（混合）→ 古法语 *mixte* 的动词 *mixer* → 英语 mix；本义“把不同东西掺在一起”，名词义“混合体、混合物”。
- **同根词**：mixture（mix + **-ture** 名词后缀：混合物）、mixed（mix + **-ed** 形容词后缀：混合的）、mixer（mix + **-er** 工具/人：搅拌器）、admix（**ad-** 向 + mix 混合 = 掺入）。
- **前缀·后缀**：名词后缀 **-ture**（例：picture, nature）；前缀 **ad-**（例：advance, admit）。
- **同义·反义**：同义 blend（混合）, combine（结合）；反义 separate（分开）, divide（分开）。
- **变形**：名词 → 复数：mixes；动词派生 → mix v. 混合；名词派生 → mixture n. 混合物；形容词派生 → mixed adj. 混合的。

### 5. western /ˈwɛstərn/ adj. 西方的；西方国家的
- **词根·渊源**：west（西方）+ 日耳曼语方位后缀 *-ern* → 古英语 *western*；本义“位于西方的”，引申为“西方国家的、西方文化的”。
- **同根词**：west（west 西方：西方）、westward（west + **-ward** 朝…方向：向西）、westerner（western + **-er** 人：西方人）、northwestern（north 北 + western 西方的 = 西北的）。
- **前缀·后缀**：方位后缀 **-ern**（例：eastern, southern）；名词后缀 **-er**（例：teacher, worker）。
- **同义·反义**：同义 occidental（西方的）；反义 eastern（东方的）。
- **变形**：形容词 → 比较级：more western；最高级：most western；名词派生 → westerner n. 西方人；副词派生 → westward adv. 向西。

### 6. style /staɪl/ n. 风格
- **词根·渊源**：拉丁 *stilus*（尖笔、书写工具）→ 古法语 *style* → 英语 style；本义“用尖笔书写的方式”，引申为“写作/表达的方式”→风格、样式。
- **同根词**：stylish（style + **-ish** …的：时髦的）、stylist（style + **-ist** 人：造型师）、stylize（style + **-ize** 使…化：使风格化）、stylus（拉丁 stilus 直接借入：尖笔、触控笔）。
- **前缀·后缀**：形容词后缀 **-ish**（例：childish, foolish）；动词后缀 **-ize**（例：modernize, realize）。
- **同义·反义**：同义 fashion（方式、风尚）, manner（方式）；反义 无。
- **变形**：名词 → 复数：styles；形容词派生 → stylish adj. 时髦的；名词派生 → stylist n. 造型师；动词派生 → stylize v. 使风格化。

### 7. popular /ˈpɑpjələr/ adj. 大众喜爱的；广受欢迎的
- **词根·渊源**：拉丁 **popul-**（人民）→ 拉丁 *popularis*（人民的、大众的）→ 英语 popular；本义“属于人民的”，引申为“受大众喜爱的”。
- **同根词**：population（popul 人民 + **-ation** 名词后缀：人口）、populate（popul 人民 + **-ate** 动词后缀：居住于、使有人口）、populous（popul 人民 + **-ous** 多的：人口稠密的）、public（拉丁 populus 人民 → 公众的）。
- **前缀·后缀**：名词后缀 **-ation**（例：information, education）；形容词后缀 **-ous**（例：famous, dangerous）。
- **同义·反义**：同义 well-liked（受欢迎的）, favored（受喜爱的）；反义 unpopular（不受欢迎的）。
- **变形**：形容词 → 比较级：more popular；最高级：most popular；名词派生 → popularity n. 受欢迎；副词派生 → popularly adv. 普遍地。

### 8. site /saɪt/ n. (建筑物、城镇等的)地点
- **词根·渊源**：拉丁 *situs*（位置、地点，源自 *sinere* 放置）→ 拉丁 *situs* 直接借入英语 site；本义“放置之处”→地点、场所。
- **同根词**：situate（situs 位置 + **-ate** 动词后缀：使位于）、situation（situate + **-ion** 名词后缀：情况、位置）、situated（situate + **-ed**：位于…的）。
- **前缀·后缀**：动词后缀 **-ate**（例：create, calculate）；名词后缀 **-ion**（例：action, nation）。
- **同义·反义**：同义 location（地点）, place（地方）；反义 无。
- **变形**：名词 → 复数：sites；动词派生 → site v. 选址；名词派生 → situation n. 位置、情况。

### 9. across /əˈkrɔs/ prep. 在…对面;在……对过
- **词根·渊源**：古法语 *a croix*（成十字形）→ 中古英语 *acros*；本义“呈十字交叉地”，引申为“横过、穿过”→在…对面。
- **同根词**：cross（拉丁 crux 十字 → 十字、横过）、crossing（cross + **-ing** 名词后缀：十字路口、横渡）、crossroads（cross 交叉 + roads 路 = 十字路口）。
- **前缀·后缀**：前缀 **a-**（例：aboard, asleep）；名词后缀 **-ing**（例：meeting, building）。
- **同义·反义**：同义 over（在…对面）, opposite（在…对面）；反义 无。
- **变形**：介词 → 无形态变化；副词派生 → across adv. 横过；名词派生 → crossing n. 十字路口。

### 10. adult /ˈædəlt/ n. 成年人
- **词根·渊源**：拉丁 *adultus*（已长大的，*adolescere* 的过去分词：ad- 向 + alescere 生长）→ 英语 adult；本义“已长成的”，名词义“成年人”。
- **同根词**：adolescent（拉丁 adolescere 生长 + **-ent** 形容词/名词后缀：青春期的、青少年）、adolescence（adolescere 生长 + **-ence** 名词后缀：青春期）、adulthood（adult + **-hood** 状态后缀：成年期）。
- **前缀·后缀**：前缀 **ad-**（例：advance, admit）；名词后缀 **-hood**（例：childhood, neighborhood）。
- **同义·反义**：同义 grown-up（成年人）；反义 child（儿童）, minor（未成年人）。
- **变形**：名词 → 复数：adults；形容词派生 → adult adj. 成年的；名词派生 → adulthood n. 成年期。

### 11. senior /ˈsinjər/ n. 老年人；长者
- **词根·渊源**：拉丁 *senior*（更年长的，*senex* 年老 的比较级）→ 英语 senior；本义“较年长者”，引申为“老年人、长者”，也指“上级、高年级生”。
- **同根词**：senate（拉丁 senex 老人 + **-ate** 集合名词：元老院→参议院）、senator（senate + **-or** 人：参议员）、senile（senex 年老 + **-ile** 形容词后缀：衰老的）、seniority（senior + **-ity** 名词后缀：年资）。
- **前缀·后缀**：名词后缀 **-ity**（例：activity, ability）；形容词后缀 **-ile**（例：fragile, mobile）。
- **同义·反义**：同义 elder（长者）, older person（年长者）；反义 junior（较年幼者）。
- **变形**：名词 → 复数：seniors；形容词派生 → senior adj. 年长的、高级的；名词派生 → seniority n. 年资。

### 12. customer /ˈkəstəmər/ n. 顾客；主顾；客户
- **词根·渊源**：拉丁 *consuetudo*（习惯）→ 古法语 *costume*（惯例）→ 英语 custom（习惯、惯例）；customer 本义“常来某店的人（习惯性光顾者）”→顾客。
- **同根词**：custom（拉丁 consuetudo 习惯 → 习俗、惯例）、customary（custom + **-ary** 形容词后缀：习惯的、惯常的）、accustom（**ac-** 向 + custom 习惯 = 使习惯）、customize（custom + **-ize** 使…化：定制）。
- **前缀·后缀**：名词后缀 **-er**（例：teacher, worker）；前缀 **ac-**（例：accept, accompany）。
- **同义·反义**：同义 client（客户）, buyer（买主）；反义 seller（卖主）。
- **变形**：名词 → 复数：customers；名词派生 → custom n. 习俗；形容词派生 → customary adj. 惯常的。

### 13. design /dɪˈzaɪn/ n. 设计
- **词根·渊源**：拉丁 **sign-**（记号、标记）→ 拉丁 *designare*（de- 出 + signare 标记 = 标出）→ 法语 *dessein* → 英语 design；本义“标出、画出记号”，引申为“设计、构思”。
- **同根词**：sign（拉丁 signum 记号：记号、签名）、signal（sign + **-al** 名词/形容词后缀：信号）、designer（design + **-er** 人：设计师）、designate（de- 出 + sign 标记 + **-ate** 动词后缀：标出→指定）。
- **前缀·后缀**：前缀 **de-**（例：depart, describe）；名词后缀 **-er**（例：writer, painter）。
- **同义·反义**：同义 plan（计划）, pattern（图案）；反义 无。
- **变形**：名词 → 复数：designs；动词派生 → design v. 设计；名词派生 → designer n. 设计师。

### 14. else /ɛls/ adv. 其他的；别的
- **词根·渊源**：原始日耳曼语 *aljaz*（其他的）→ 古英语 *elles*（否则、另外）；本义“另外地”，引申为“其他的、别的”。
- **同根词**：elsewhere（else 其他 + where 哪里 = 在别处）、elsehow（else + how 怎样：存疑，罕用）。
- **前缀·后缀**：无前后缀（单纯词）。
- **同义·反义**：同义 other（其他的）, otherwise（另外）；反义 无。
- **变形**：副词 → 无比较级；副词派生 → elsewhere adv. 在别处。

### 15. suggestion /səˈʤɛsʧən/ n. 建议；提议
- **词根·渊源**：拉丁 **gest-**（带来、搬运，源自 *gerere*）→ 拉丁 *suggestio*（sug- 在下 + gest 带 = 从下面带来）→ 英语 suggestion；本义“暗中带来（想法）”，引申为“建议、提议”。
- **同根词**：suggest（sug- 在下 + gest 带 = 从下面带来→建议）、digest（di- 分开 + gest 带 = 分开搬运→消化）、congest（con- 共同 + gest 带 = 聚在一起→拥塞）、gesture（gest 带 + **-ure** 名词后缀：手势）。
- **前缀·后缀**：前缀 **sug-**（=sub- 在下，例：support, suppose）；名词后缀 **-ion**（例：action, nation）。
- **同义·反义**：同义 advice（建议）, proposal（提议）；反义 无。
- **变形**：名词 → 复数：suggestions；动词派生 → suggest v. 建议；形容词派生 → suggestive adj. 提示性的。

### 16. tip /tɪp/ n. 指点；实用的提示
- **词根·渊源**：中古英语 *tippen*（轻触、点）→ 英语 tip；本义“轻点、尖端”，引申为“点一下的提示”→指点、实用提示（此义项词源存疑）。
- **同根词**：tiptoe（tip 尖端 + toe 脚趾 = 脚尖）、tipper（tip + **-er** 人：给小费者）、tipsy（tip + **-sy** 形容词后缀：微醉的，词源存疑）。
- **前缀·后缀**：名词后缀 **-er**（例：runner, singer）；形容词后缀 **-sy**（例：tricky, clumsy）。
- **同义·反义**：同义 hint（提示）, advice（建议）；反义 无。
- **变形**：名词 → 复数：tips；动词派生 → tip v. 轻触、给小费；名词派生 → tipper n. 给小费者。

### 17. historic /hɪˈstɔrɪk/ adj. 历史上齐名(或重要)的；可名乘背史的
- **词根·渊源**：希腊 **histor-**（见证者、知情者，源自 *histōr* 智者）→ 拉丁 *historia*（历史）→ 英语 history + **-ic**；本义“与历史有关的”，引申为“历史上重要的”。
- **同根词**：history（希腊 historia 历史：历史）、historical（history + **-ical** 形容词后缀：历史的）、historian（history + **-ian** 人：历史学家）、prehistoric（**pre-** 前 + historic 历史的 = 史前的）。
- **前缀·后缀**：形容词后缀 **-ic**（例：basic, scientific）；前缀 **pre-**（例：preview, prepare）。
- **同义·反义**：同义 important（重要的）, momentous（重大的）；反义 unimportant（不重要的）。
- **变形**：形容词 → 无比较级（关系形容词，不作比较）；名词派生 → history n. 历史；副词派生 → historically adv. 历史上地。

### 18. list /lɪst/ n. 名单；目录
- **词根·渊源**：原始日耳曼语 *listiz*（边、条）→ 古英语 *liste*（边、条带）；本义“条、边”，引申为“一条条列出的东西”→名单、目录（词源存疑）。
- **同根词**：listen（古英语 hlysnan 听，与 list 边 存疑关联：听）、listing（list + **-ing** 名词后缀：列表、清单）、enlist（**en-** 使 + list 名单 = 使入名单→征募）。
- **前缀·后缀**：名词后缀 **-ing**（例：building, meeting）；前缀 **en-**（例：enable, enrich）。
- **同义·反义**：同义 catalog（目录）, roll（名单）；反义 无。
- **变形**：名词 → 复数：lists；动词派生 → list v. 列出；名词派生 → listing n. 列表。

### 19. landscape /ˈlænˌskeɪp/ n. 风景；景色
- **词根·渊源**：荷兰语 **land**（土地）+ **-schap**（状态、景象，对应英语 -ship）→ 荷兰语 *landschap*（地区、一片土地）→ 英语 landscape，本义“一片土地的样子”，引申为“风景、景色”。
- **同根词**：land（本词根，土地→陆地）、landscape 的 land 部分即“土地”；seascape（sea 海 + -scape 景：海景）、cityscape（city 城市 + -scape 景：城市景观）、landlord（land 土地 + lord 主人：地主）、landmark（land 土地 + mark 标记：地标）。
- **前缀·后缀**：后缀 **-scape**（例：seascape, cityscape）；无前缀。
- **同义·反义**：同义 scenery（风景）, view（景色）；反义 无。
- **变形**：名词 → 复数：landscapes；形容词派生 → landscaped adj. 经景观设计的；名词派生 → landscaper n. 园林设计师。

### 20. memory /ˈmɛməri/ n. 回忆；记忆
- **词根·渊源**：拉丁 **memor**（记得的）→ 拉丁 *memoria*（记忆）→ 古法语 *memoire* → 英语 memory，本义“记得的状态”，引申为“记忆、回忆”。
- **同根词**：memorize（memory 的记忆 + **-ize** 使…化：记住）、memorial（memor 记得 + **-ial** …的：纪念的）、remember（**re-** 再 + member 记忆 = 再次记起→记得）、memorable（memor 记得 + **-able** 可…的：值得记住的）、commemorate（**com-** 共同 + memor 记得 + **-ate** 动词化：共同纪念）。
- **前缀·后缀**：名词后缀 **-y**（例：history, victory）；动词化后缀 **-ize**（例：realize, organize）。
- **同义·反义**：同义 recollection（回忆）, remembrance（记忆）；反义 forgetfulness（健忘）。
- **变形**：名词 → 复数：memories；形容词派生 → memorable adj. 难忘的；动词派生 → memorize v. 记住；副词派生 → memorably adv. 难忘地。

### 21. general /ˈʤɛnərəl/ n. 将军
- **词根·渊源**：拉丁 **genus / gener-**（种类、族类）→ 拉丁 *generalis*（属于全类的、普遍的）→ 古法语 *general* → 英语 general；本义“全体的、普遍的”，军中“统领全军者”称 general（将军），名词义由此而来。
- **同根词**：generate（gener 种类 + **-ate** 动词化：产生）、generation（generate 产生 + **-ion** 名词化：一代人）、generic（gener 种类 + **-ic** …的：种类的、通用的）、genuine（拉丁 genu 出生 + **-ine** …的：天生的→真正的）、genre（法语 genre 种类：体裁）。
- **前缀·后缀**：形容词后缀 **-al**（例：natural, national）；无前缀。
- **同义·反义**：同义 commander（指挥官）, marshal（元帅）；反义 无。
- **变形**：名词 → 复数：generals；形容词 → 比较级：more general；最高级：most general；副词派生 → generally adv. 通常地；名词派生 → generality n. 普遍性。

### 22. sight /saɪt/ n. 看见
- **词根·渊源**：古英语 **gesihth**（看见、景象），与 **see**（看）同源，出自日耳曼语 *sekhwan*；本义“看的行为”，引申为“视力、看见、景象”。
- **同根词**：see（同源，看）、sightseeing（sight 看见 + seeing 看：观光）、insight（**in-** 向内 + sight 看：洞察力）、eyesight（eye 眼 + sight 视力：视力）、foresight（**fore-** 预先 + sight 看：先见之明）。
- **前缀·后缀**：无前后缀（单纯词）；复合词中见 **in-**（例：inside）、**fore-**（例：forecast）。
- **同义·反义**：同义 vision（视力）, view（景象）；反义 blindness（失明）。
- **变形**：名词 → 复数：sights；形容词派生 → sightly adj. 悦目的；副词派生 → sightlessly adv. 盲目地；动词派生 → sight v. 看见。

### 23. natural /ˈnæʧərəl/ adj. 自然的；天然的
- **词根·渊源**：拉丁 **natura**（自然、天性，源自 nasci 出生）→ 拉丁 *naturalis* → 古法语 *natural* → 英语 natural，本义“与生俱来的”，引申为“自然的、天然的”。
- **同根词**：nature（natura 自然：自然）、naturally（natural + **-ly** 副词化：自然地）、native（拉丁 nativus 出生的：本地的）、nation（拉丁 natio 出生、族群：民族）、innate（**in-** 在内 + nat 出生 + **-ate** …的：天生的）。
- **前缀·后缀**：形容词后缀 **-al**（例：formal, normal）；副词后缀 **-ly**（例：usually, finally）。
- **同义·反义**：同义 innate（天生的）, normal（正常的）；反义 artificial（人造的）, unnatural（不自然的）。
- **变形**：形容词 → 比较级：more natural；最高级：most natural；副词派生 → naturally adv. 自然地；名词派生 → naturalness n. 自然；名词派生 → nature n. 自然。

### 24. almost /ˈɔlˌmoʊst/ adv. 几乎；差不多
- **词根·渊源**：古英语 **ealmæst** = **eall**（全部）+ **mæst**（最多、大部分）→ 中古英语 *almost*，本义“几乎全部”，引申为“几乎、差不多”。
- **同根词**：most（mæst 最多：最多）、mostly（most + **-ly** 副词化：主要地）、all（eall 全部：全部）、utmost（**ut** 外 + most 最：极度的）、foremost（**fore-** 前 + most 最：最前的）。
- **前缀·后缀**：无前后缀（复合词，由 all + most 构成）。
- **同义·反义**：同义 nearly（几乎）, about（大约）；反义 exactly（恰好）, completely（完全地）。
- **变形**：副词 → 无比较级（绝对程度副词，不作比较）；无词性派生。

### 25. become /bɪˈkəm/ v. 开始变得；变成
- **词根·渊源**：古英语 **becuman** = **be-**（周围、加强）+ **cuman**（来，即 come）→ 中古英语 *become*，本义“来到、发生”，引申为“成为、变得”。
- **同根词**：come（cuman 来：来）、becoming（become + **-ing** …的：合适的）、income（**in-** 进入 + come 来：收入）、outcome（**out-** 出 + come 来：结果）、welcome（**wel-** 好 + come 来：欢迎）。
- **前缀·后缀**：前缀 **be-**（例：belong, believe）；无后缀。
- **同义·反义**：同义 turn（变成）, grow（变得）；反义 remain（保持）。
- **变形**：动词 → 第三人称单数：becomes；过去式：became；过去分词：become；现在分词：becoming；名词派生 → becoming n. 形成；形容词派生 → becoming adj. 合适的。

### 26. gateway /ˈgeɪtˌweɪ/ n. (通往其他地区的)门户
- **词根·渊源**：古英语 **geat**（门）+ **weg**（路，即 way）→ 英语 gateway，本义“门旁的路、出入口”，引申为“门户、通道”。
- **同根词**：gate（geat 门：大门）、way（weg 路：道路）、highway（high 高 + way 路：公路）、railway（rail 铁轨 + way 路：铁路）、pathway（path 小路 + way 路：小径）。
- **前缀·后缀**：无前后缀（复合词，由 gate + way 构成）。
- **同义·反义**：同义 entrance（入口）, portal（门户）；反义 exit（出口）。
- **变形**：名词 → 复数：gateways；无词性派生。

### 27. influence /ˈɪnfluəns/ v. 影响；对…起作用
- **词根·渊源**：拉丁 **in-**（向内）+ **fluere**（流）→ 中世纪拉丁 *influentia*（流入，占星中指星体流出的力量）→ 古法语 *influence* → 英语 influence，本义“流入的力量”，引申为“影响”。
- **同根词**：fluent（flu 流 + **-ent** …的：流利的）、fluid（flu 流 + **-id** …的：流体）、flush（flu 流 + **-sh** 动词化：冲洗）、affluent（**af-** 向 + flu 流 + **-ent** …的：富裕的）、influenza（influence 的意大利语同源词，本义“星体影响所致之病”：流感）。
- **前缀·后缀**：前缀 **in-**（例：inside, income）；名词后缀 **-ence**（例：difference, silence）。
- **同义·反义**：同义 affect（影响）, sway（左右）；反义 无。
- **变形**：动词 → 第三人称单数：influences；过去式：influenced；过去分词：influenced；现在分词：influencing；名词派生 → influence n. 影响；形容词派生 → influential adj. 有影响力的。

### 28. artwork /ˈɑrtˌwərk/ n. 艺术作品
- **词根·渊源**：**art**（艺术，源自拉丁 ars 技艺）+ **work**（作品，古英语 weorc 工作）→ 英语 artwork，本义“技艺之作”，引申为“艺术作品”。
- **同根词**：art（拉丁 ars 技艺：艺术）、work（weorc 工作：工作）、artist（art 艺术 + **-ist** 人：艺术家）、artistic（artist 艺术家 + **-ic** …的：艺术的）、workman（work 工作 + man 人：工人）。
- **前缀·后缀**：无前后缀（复合词，由 art + work 构成）。
- **同义·反义**：同义 art piece（艺术品）, creation（创作）；反义 无。
- **变形**：名词 → 复数：artworks；无词性派生。

### 29. painting /ˈpeɪnɪŋ/ n. 绘画
- **词根·渊源**：拉丁 **pingere**（画、涂色）→ 古法语 *peindre* → 英语 paint + **-ing**（名词化）→ painting，本义“涂色的行为”，引申为“绘画、画作”。
- **同根词**：paint（pingere 画：绘画）、painter（paint 画 + **-er** 人：画家）、picturesque（picture 画 + **-esque** 如…的：如画的）、depict（**de-** 向下 + pict 画：描绘）。
- **前缀·后缀**：名词后缀 **-ing**（例：building, meeting）；动词后缀 **-er**（例：teacher, worker）。
- **同义·反义**：同义 picture（图画）, drawing（素描）；反义 无。
- **变形**：名词 → 复数：paintings；动词派生 → paint v. 绘画；名词派生 → painter n. 画家。

### 30. scene /sin/ n. 场面；情景
- **词根·渊源**：希腊 **skene**（帐篷、舞台背景）→ 拉丁 *scena* → 古法语 *scene* → 英语 scene，本义“舞台布景”，引申为“场面、情景”。
- **同根词**：scenery（scene 景 + **-ery** 集合名词：风景）、scenic（scene 景 + **-ic** …的：风景优美的）、scenario（scene 场景 + **-ario** 意大利语名词化：剧情梗概）、obscene（**ob-** 相反 + scene 舞台：不雅的）。
- **前缀·后缀**：名词后缀 **-ery**（例：bakery, bravery）；形容词后缀 **-ic**（例：basic, magic）。
- **同义·反义**：同义 view（景象）, setting（场景）；反义 无。
- **变形**：名词 → 复数：scenes；形容词派生 → scenic adj. 风景优美的；副词派生 → scenically adv. 风景优美地。

### 31. wife /waɪf/ n. 妻子
- **词根·渊源**：古英语 **wif**（女人、妇女，非专指已婚）→ 中古英语 *wif*，本义“女人”，后与 husband 相对，专指“妻子”；与德语 Weib（女人）同源。
- **同根词**：housewife（house 家 + wife 女人：家庭主妇）、midwife（mid 中 + wife 女人：助产士）、wifehood（wife + **-hood** 身份：妻子身份）、wifely（wife + **-ly** …的：妻子的）。
- **前缀·后缀**：名词后缀 **-hood**（例：childhood, brotherhood）；形容词后缀 **-ly**（例：friendly, lovely）。
- **同义·反义**：同义 spouse（配偶）, partner（伴侣）；反义 husband（丈夫）。
- **变形**：名词 → 复数：wives；形容词派生 → wifely adj. 妻子的；名词派生 → wifehood n. 妻子身份。

### 32. stone /stoʊn/ n. 石头；石料
- **词根·渊源**：古英语 **stan**（石头）→ 中古英语 *ston* → 英语 stone，出自日耳曼语 *stainaz*，本义“石头”，引申为“石料、宝石”。
- **同根词**：stony（stone + **-y** …的：多石的）、stonework（stone 石 + work 工：石造物）、milestone（mile 英里 + stone 石：里程碑）、limestone（lime 石灰 + stone 石：石灰岩）、stonemason（stone 石 + mason 石匠：石匠）。
- **前缀·后缀**：形容词后缀 **-y**（例：rainy, windy）；无前缀。
- **同义·反义**：同义 rock（岩石）, pebble（卵石）；反义 无。
- **变形**：名词 → 复数：stones（作“石料”义时不可数）；形容词派生 → stony adj. 多石的；动词派生 → stone v. 向…扔石头。

### 33. reflection /rɪˈflɛkʃən/ n. 映像；映照出的影像
- **词根·渊源**：拉丁 **re-**（回）+ **flectere**（弯曲）→ 拉丁 *reflectere*（弯回、反射）→ 古法语 *reflexion* → 英语 reflection，本义“折回”，引申为“反射、映像、沉思”。

- **前缀·后缀**：前缀 **re-**（例：return, recall）；名词后缀 **-ion**（例：action, decision）。
- **同义·反义**：同义 image（映像）, mirroring（映照）；反义 无。
- **变形**：名词 → 复数：reflections；动词派生 → reflect v. 反射；形容词派生 → reflective adj. 反射的；副词派生 → reflectively adv. 沉思地。
