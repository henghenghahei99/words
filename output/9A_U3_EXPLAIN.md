## 二、逐词说文解字

### 1. indeed /ˌɪnˈdid/ adv. 确实(强调肯定的陈述或答复)
- **词根·渊源**：古英语 **in**（在……中）+ **dēd**（行为、事实）→ 中古英语 *in dede*，本义“在事实中、事实上”，引申为“确实、的确”。
- **同根词**：deed（**dēd** 行为→行为、事迹）、indeed 本身即 in + deed 的合并。
- **前缀·后缀**：前缀 **in-**（例：income, inside）；无后缀（复合词）。
- **同义·反义**：同义 truly（确实地）, really（真正地）；反义 doubtfully（怀疑地）。
- **变形**：副词 → 无比较级（绝对副词，不作比较）；无词性派生。

### 2. match /mæʧ/ n. 火柴
- **词根·渊源**：古法语 *meiche* / *mèche*（灯芯）→ 中古英语 *macche*，本义“浸蜡的灯芯、引火绳”，后指“火柴”；与希腊语 *myxa*（灯芯）同源，存疑。
- **同根词**：matchbox（match 火柴 + box 盒 = 火柴盒）、matchstick（match 火柴 + stick 棍 = 火柴棍）。
- **前缀·后缀**：无前缀；无后缀（单纯词）。
- **同义·反义**：同义 firestick（引火棍，罕用）；反义 无。
- **变形**：名词 → 复数：matches；无词性派生。

### 3. shame /ʃeɪm/ n. 令人惋惜的事;让人遗憾的事
- **词根·渊源**：古英语 **scamu**（羞耻、耻辱）→ 中古英语 *shame*，本义“羞耻感”，引申为“令人羞耻/惋惜的事”。
- **同根词**：ashamed（**a-** 处于……状态 + shame 羞耻 = 感到羞耻的）、shameful（shame + **-ful** 充满……的 = 可耻的）、shameless（shame + **-less** 无……的 = 无耻的）。
- **前缀·后缀**：前缀 **a-**（例：alive, asleep）；后缀 **-ful**（例：helpful）、**-less**（例：hopeless）。
- **同义·反义**：同义 pity（遗憾的事）, disgrace（耻辱）；反义 honor（荣誉）, pride（自豪）。
- **变形**：名词 → 复数：shames（多作不可数）；形容词派生 → shameful adj. 可耻的；shameless adj. 无耻的；副词派生 → shamefully adv. 可耻地。

### 4. lower /loʊər/ v. 把......放低
- **词根·渊源**：中古英语 **low**（低的）+ 比较级后缀 **-er** → *lower*，本义“更低的”，动词化后表示“使更低、放低”。
- **同根词**：low（**low** 低的→低的）、lowly（low + **-ly** ……地/……的 = 低微的）、below（**be-** 在 + low 低 = 在……下面）。
- **前缀·后缀**：前缀 **be-**（例：behind, beneath）；后缀 **-er**（例：higher, teacher）。
- **同义·反义**：同义 drop（放下）, descend（下降）；反义 raise（举起）, lift（抬起）。
- **变形**：动词 → 第三人称单数：lowers；过去式：lowered；过去分词：lowered；现在分词：lowering；形容词 → 比较级：lower（本身即比较级）；最高级：lowest；名词派生 → lowering n. 降低。

### 5. practice /ˈpræktɪs/ n. 实践;实际行动
- **词根·渊源**：希腊语 **praktikos**（善于行动的）→ 中世纪拉丁 *practica* → 古法语 *practique* → 英语，本义“实际行动”，引申为“实践、练习”。
- **同根词**：practical（practice + **-al** ……的 = 实际的）、practise（practice 的动词形式→练习）、practitioner（practic- 实践 + **-ion** + **-er** 人 = 从业者）。
- **前缀·后缀**：无前缀；后缀 **-ice**（例：service, justice）。
- **同义·反义**：同义 exercise（练习）, action（行动）；反义 theory（理论）。
- **变形**：名词 → 复数：practices；形容词派生 → practical adj. 实际的；副词派生 → practically adv. 实际上；动词派生 → practise v. 练习。

### 6. decision /dɪˈsɪʒən/ n. 决定
- **词根·渊源**：拉丁 **dēcīdere**（切断、裁定）= **de-** 离 + **caedere** 切 → 古法语 *decision* → 英语，本义“切断（疑虑）→ 裁定”，引申为“决定”。
- **同根词**：decide（**de-** 离 + cid 切 = 切断疑虑→决定）、decisive（decid- 决定 + **-ive** ……的 = 决定性的）、incision（**in-** 入 + cis 切 + **-ion** = 切口）。
- **前缀·后缀**：前缀 **de-**（例：depart, decline）；后缀 **-ion**（例：action, vision）。
- **同义·反义**：同义 choice（选择）, resolution（决心）；反义 hesitation（犹豫）, indecision（优柔寡断）。
- **变形**：名词 → 复数：decisions；形容词派生 → decisive adj. 决定性的；副词派生 → decisively adv. 果断地；动词派生 → decide v. 决定。

### 7. cheat /ʧit/ v. 欺骗;蒙骗
- **词根·渊源**：中古英语 **chete**（欺诈），可能源自盎格鲁-法语 *escheat*（无主财产归领主），本义“侵占财产”，引申为“欺骗”；词源存疑。
- **同根词**：cheater（cheat + **-er** 人 = 骗子）、cheating（cheat + **-ing** 行为 = 作弊）。
- **前缀·后缀**：无前缀；后缀 **-er**（例：teacher, worker）。
- **同义·反义**：同义 deceive（欺骗）, trick（哄骗）；反义 be honest（诚实）。
- **变形**：动词 → 第三人称单数：cheats；过去式：cheated；过去分词：cheated；现在分词：cheating；名词派生 → cheater n. 骗子；cheating n. 作弊。

### 8. strengthen /ˈstrɛŋθən/ v. 加强;增强;巩固
- **词根·渊源**：古英语 **strengþu**（力量）+ 动词后缀 **-en** → *strengthen*，本义“使有力量”，引申为“加强、巩固”。
- **同根词**：strength（**strengþ** 力量→力量）、strong（与 strength 同源，**strang-** 强壮的→强壮的）、strongly（strong + **-ly** ……地 = 强壮地）。
- **前缀·后缀**：无前缀；后缀 **-en**（例：widen, lengthen）。
- **同义·反义**：同义 reinforce（加强）, fortify（巩固）；反义 weaken（削弱）。
- **变形**：动词 → 第三人称单数：strengthens；过去式：strengthened；过去分词：strengthened；现在分词：strengthening；名词派生 → strengthening n. 加强。

### 9. fold /foʊld/ v. 折叠
- **词根·渊源**：古英语 **fealdan**（折叠）→ 中古英语 *folden*，本义“把东西折起来”，引申为“折叠、对折”；与德语 *falten* 同源。
- **同根词**：folder（fold + **-er** 物 = 文件夹）、unfold（**un-** 相反 + fold 折 = 展开）、manifold（**mani-** 多 + fold 折 = 多种的）。
- **前缀·后缀**：前缀 **un-**（例：unhappy, undo）；后缀 **-er**（例：worker, teacher）。
- **同义·反义**：同义 bend（弯曲）, crease（折皱）；反义 unfold（展开）。
- **变形**：动词 → 第三人称单数：folds；过去式：folded；过去分词：folded；现在分词：folding；名词派生 → folder n. 文件夹。

### 10. repetition /ˌrɛpəˈtɪʃən/ n. 重复
- **词根·渊源**：拉丁 **repetere**（再寻求）= **re-** 再 + **petere** 寻求 → 古法语 *repetition* → 英语，本义“再次寻求”，引申为“重复”。
- **同根词**：repeat（**re-** 再 + peat 寻求 = 重复）、repetitive（repetit- 重复 + **-ive** ……的 = 重复的）、petition（**pet-** 寻求 + **-ion** = 请愿）。
- **前缀·后缀**：前缀 **re-**（例：return, rebuild）；后缀 **-ion**（例：action, nation）。
- **同义·反义**：同义 recurrence（反复）, duplication（复制）；反义 无。
- **变形**：名词 → 复数：repetitions；形容词派生 → repetitive adj. 重复的；副词派生 → repetitively adv. 重复地；动词派生 → repeat v. 重复。

### 11. vacation /veɪˈkeɪʃən/ n. 假期
- **词根·渊源**：拉丁 **vacare**（空着、空闲）+ **-ion** → 古法语 *vacation* → 英语，本义“空闲状态”，引申为“假期”。
- **同根词**：vacant（**vac-** 空 + **-ant** ……的 = 空的）、vacate（vac 空 + **-ate** 使…… = 腾空）、vacuum（vac 空 + **-um** 名词 = 真空）。
- **前缀·后缀**：无前缀；后缀 **-ion**（例：action, station）。
- **同义·反义**：同义 holiday（假日）, break（休息）；反义 workday（工作日）。
- **变形**：名词 → 复数：vacations；动词派生 → vacation v. 度假；形容词派生 → vacationing adj. 度假的。

### 12. somehow /ˈsəmˌhaʊ/ adv. 不知为什么
- **词根·渊源**：中古英语 **some**（某个）+ **how**（如何）→ *somehow*，本义“以某种方式”，引申为“不知怎么地、不知为什么”。
- **同根词**：somewhat（some + what = 有点）、somewhere（some + where = 某处）、anyhow（any + how = 无论如何）。
- **前缀·后缀**：无前缀；无后缀（复合词）。
- **同义·反义**：同义 in some way（以某种方式）, anyhow（无论如何）；反义 无。
- **变形**：副词 → 无比较级（绝对副词，不作比较）；无词性派生。

### 13. awkward /ˈɔkwərd/ adj. 令人尴尬的
- **词根·渊源**：中古英语 **awk**（反手、错误方向，源自古诺斯语 *afugr*）+ **-ward**（朝向）→ *awkward*，本义“朝反方向的”，引申为“笨拙的、令人尴尬的”。
- **同根词**：awkwardly（awkward + **-ly** ……地 = 尴尬地）、awkwardness（awkward + **-ness** 性质 = 尴尬）、backward（back + **-ward** 朝向 = 向后的）。
- **前缀·后缀**：无前缀；后缀 **-ward**（例：forward, toward）。
- **同义·反义**：同义 embarrassing（令人尴尬的）, clumsy（笨拙的）；反义 graceful（优雅的）, comfortable（自在的）。
- **变形**：形容词 → 比较级：more awkward；最高级：most awkward；副词派生 → awkwardly adv. 尴尬地；名词派生 → awkwardness n. 尴尬。

### 14. laughter /ˈlæftər/ n. 笑;笑声
- **词根·渊源**：古英语 **hleahtor**（笑）→ 中古英语 *laughter*，本义“笑的行为”，引申为“笑声”。
- **同根词**：laugh（与 laughter 同源，**hlæh-** 笑→笑）、laughing（laugh + **-ing** ……的 = 笑的）、laughable（laugh + **-able** 可……的 = 可笑的）。
- **前缀·后缀**：无前缀；后缀 **-ter**（例：laughter 中的名词后缀，类似 water）。
- **同义·反义**：同义 laughing（笑）, giggle（咯咯笑）；反义 crying（哭泣）, weeping（哭泣）。
- **变形**：名词 → 不可数；形容词派生 → laughable adj. 可笑的；动词派生 → laugh v. 笑。

### 15. tear /tɪr/ n. 眼泪
- **词根·渊源**：古英语 **tēar**（眼泪）→ 中古英语 *teer*，本义“眼泪”；与希腊语 *dakry* 同出 PIE *dakru-*。
- **同根词**：tearful（tear + **-ful** 充满……的 = 含泪的）、teardrop（tear + drop 滴 = 泪珠）、tearless（tear + **-less** 无……的 = 无泪的）。
- **前缀·后缀**：无前缀；后缀 **-ful**（例：helpful）、**-less**（例：hopeless）。
- **同义·反义**：同义 teardrop（泪珠）；反义 无。
- **变形**：名词 → 复数：tears；形容词派生 → tearful adj. 含泪的；副词派生 → tearfully adv. 含泪地。

### 16. with admiration  prep. 钦佩地;赞赏地
- **同义搭配**：with respect / in admiration
- **反义搭配**：with contempt

### 17. right and wrong  n. 是非
- **同义搭配**：good and evil / right and wrong
- **反义搭配**：无

### 18. fresh in one's memory  n. 记忆犹新
- **同义搭配**：vivid in one's memory / still remembered clearly
- **反义搭配**：forgotten

### 19. bed sheet  n. 床单
- **同义搭配**：sheet / bed linen
- **反义搭配**：无
