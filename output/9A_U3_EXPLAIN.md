## 二、逐词说文解字

### 1. meal /miːl/ n. 餐；一顿饭
- **词根·渊源**：古英语 **mǣl**（时间、固定时刻）→ 中古英语 *meel*，本义“固定的时间点”，因进餐有固定时间，引申为“进餐的时刻→一顿饭”；与德语 *Mahl*（餐）同源。
- **同根词**：piecemeal（piece 块 + meal 时间部分 = 一件一件地→零碎地）、mealtime（meal 餐 + time 时间 = 用餐时间）。
- **前缀·后缀**：无前后缀（单纯词）。
- **同义·反义**：同义 repast（餐）, dinner（正餐）；反义 无。
- **变形**：名词 → 复数：meals；形容词派生 → mealtime n. 用餐时间。

### 2. share /ʃer/ v. 把自己的想法（或经历、感情）告诉（某人）
- **词根·渊源**：古英语 **scearu**（切分、份额）→ 中古英语 *share*，本义“把东西切开分份”，由“分份”引申为“分享、共同拥有”，再引申为“把想法告诉别人→倾诉”。
- **同根词**：shareholder（share 股份 + holder 持有者 = 股东）、sharing（share + **-ing** 名词后缀 = 分享）。
- **前缀·后缀**：无前缀；名词后缀 **-ing**（例：meeting, building）。
- **同义·反义**：同义 tell（告诉）, confide（倾诉）；反义 withhold（隐瞒）, keep（保留）。
- **变形**：动词 → 第三人称单数：shares；过去式：shared；过去分词：shared；现在分词：sharing；名词派生 → share n. 份额；sharing n. 分享。

### 3. decision /dɪˈsɪʒn/ n. 决定；抉择
- **词根·渊源**：拉丁 **decidere**（de- 离开 + caedere 切 = 切下去→裁定）→ 古法语 *decision* → 英语，本义“切下、裁定”，引申为“作出决定”。
- **同根词**：decide（**de-** 离开 + cid 切 = 切下去→决定）、decisive（decide + **-ive** …的 = 决定性的）、indecision（**in-** 不 + decision = 犹豫不决）、scissors（拉丁 caedere 切 + **-ors** 工具 = 剪刀）。
- **前缀·后缀**：前缀 **de-**（例：depart, decline）；名词后缀 **-ion**（例：action, nation）。
- **同义·反义**：同义 choice（选择）, resolution（决心）；反义 indecision（犹豫不决）, hesitation（迟疑）。
- **变形**：名词 → 复数：decisions；动词派生 → decide v. 决定；形容词派生 → decisive adj. 决定性的；副词派生 → decisively adv. 果断地。

### 4. possessions /pə'zeʃənz/ n. 个人财产；私人物品
- **词根·渊源**：拉丁 **possidere**（pot- 能力 + sedere 坐 = 能坐拥→占有）→ 古法语 *possesser* → 英语 possess，加 **-ion** 成名词，复数指“占有的东西→财产”。
- **同根词**：possess（**pos-** 能力 + sess 坐 = 坐拥→占有）、possessive（possess + **-ive** …的 = 占有欲强的）、possessor（possess + **-or** 人 = 占有者）。
- **前缀·后缀**：无前缀；名词后缀 **-ion**（例：decision, action）；复数后缀 **-s**（例：books, pens）。
- **同义·反义**：同义 belongings（财物）, property（财产）；反义 无。
- **变形**：名词 → 复数：possessions（常用复数）；动词派生 → possess v. 拥有；形容词派生 → possessive adj. 占有欲强的。

### 5. expect /ɪkˈspekt/ v. 期待；预计；要求，指望
- **词根·渊源**：拉丁 **exspectare**（ex- 向外 + spectare 看 = 向外张望→等待）→ 拉丁 *expectare* → 英语，本义“向外看、等候”，引申为“期待、预计”。
- **同根词**：inspect（**in-** 向内 + spect 看 = 向内看→检查）、respect（**re-** 回 + spect 看 = 回头看→尊敬）、spectator（spect 看 + **-ator** 人 = 观众）、suspect（**sus-** 下 + spect 看 = 从下看→怀疑）。
- **前缀·后缀**：前缀 **ex-**（例：exit, export）；词根 spect（例：inspect, respect）。
- **同义·反义**：同义 anticipate（预期）, await（等待）；反义 doubt（怀疑）, despair（绝望）。
- **变形**：动词 → 第三人称单数：expects；过去式：expected；过去分词：expected；现在分词：expecting；名词派生 → expectation n. 期望；形容词派生 → expected adj. 预期的。

### 6. abroad /əˈbrɔːd/ adv. 到国外；在国外
- **词根·渊源**：古英语 **on brād**（on 在 + brād 宽阔 = 在广阔处）→ 中古英语 *abrood*，本义“广泛地、到处”，后专指“到广阔的外面→在国外”。
- **同根词**：broad（古英语 brād 宽阔的）、broaden（broad + **-en** 使… = 加宽）、breadth（broad + **-th** 名词后缀 = 宽度）。
- **前缀·后缀**：前缀 **a-**（on 的弱化，例：away, asleep）；无后缀。
- **同义·反义**：同义 overseas（在海外）；反义 at home（在国内）, domestically（在国内）。
- **变形**：副词 → 无比较级（地点副词，不作比较）。

### 7. business /ˈbɪznəs/ n. 商业，买卖，生意；商务，公事
- **词根·渊源**：古英语 **bisignes**（bisig 忙碌 + **-nes** 名词后缀 = 忙碌状态）→ 中古英语 *businesse*，本义“忙碌、事务”，因做生意最忙碌，引申为“商业、生意”。
- **同根词**：busy（古英语 bisig 忙碌的）、busily（busy + **-ly** 副词后缀 = 忙碌地）、busyness（busy + **-ness** 名词后缀 = 忙碌）。
- **前缀·后缀**：无前缀；名词后缀 **-ness**（例：happiness, kindness）。
- **同义·反义**：同义 commerce（商业）, trade（贸易）；反义 leisure（闲暇）。
- **变形**：名词 → 复数：businesses；形容词派生 → busy adj. 忙碌的；副词派生 → busily adv. 忙碌地。

### 8. personal /ˈpɜːrsənl/ adj. 个人的；私人的
- **词根·渊源**：拉丁 **persona**（面具、角色）→ 拉丁 *personalis* → 古法语 *personel* → 英语，本义“与角色有关的”，引申为“与个人有关的→私人的”。
- **同根词**：person（拉丁 persona 面具→人）、personality（person + **-ality** 名词后缀 = 个性）、personally（personal + **-ly** 副词后缀 = 亲自地）、personify（person + **-ify** 使… = 拟人化）。
- **前缀·后缀**：无前缀；形容词后缀 **-al**（例：natural, national）。
- **同义·反义**：同义 private（私人的）, individual（个人的）；反义 public（公共的）, general（普遍的）。
- **变形**：形容词 → 比较级：more personal；最高级：most personal；名词派生 → person n. 人；personality n. 个性；副词派生 → personally adv. 亲自地。

### 9. set /sɛt/ v. 安排；确定；决定
- **词根·渊源**：古英语 **settan**（使坐下、放置）→ 中古英语 *setten*，本义“使就座、放置”，由“放定”引申为“确定、安排、决定”；与 sit 同源。
- **同根词**：setting（set + **-ing** 名词后缀 = 环境、设置）、settle（set + **-le** 反复后缀 = 安放下来→定居）、upset（**up-** 向上 + set 放 = 翻倒→使心烦）。
- **前缀·后缀**：无前缀；无后缀（单纯词）。
- **同义·反义**：同义 arrange（安排）, fix（确定）；反义 cancel（取消）, unsettle（使不安定）。
- **变形**：动词 → 第三人称单数：sets；过去式：set；过去分词：set；现在分词：setting；名词派生 → setting n. 环境；set n. 一套。

### 10. daughter /ˈdɔːtər/ n. 女儿
- **词根·渊源**：古英语 **dohtor** → 中古英语 *doghter*，源自 PIE *dhugheter*（女儿），与德语 *Tochter*、希腊 *thygatēr* 同源，词形自古英语以来基本未变。
- **同根词**：daughter-in-law（daughter 女儿 + in-law 姻亲 = 儿媳）、stepdaughter（**step-** 继 + daughter 女儿 = 继女）、granddaughter（**grand-** 隔代 + daughter 女儿 = 孙女）。
- **前缀·后缀**：无前后缀（单纯词）。
- **同义·反义**：同义 girl（女孩）；反义 son（儿子）。
- **变形**：名词 → 复数：daughters。

### 11. mind /maɪnd/ n. 介意,反对
- **词根·渊源**：古英语 **gemynd**（记忆、思想）→ 中古英语 *mind*，本义“记忆、心思”，由“心里在意”引申为动词“介意、反对”（本词条释义为动词用法）。
- **同根词**：mindful（mind + **-ful** 充满…的 = 留心的）、mindless（mind + **-less** 无…的 = 无心的）、remind（**re-** 再 + mind 心 = 再想起→提醒）。
- **前缀·后缀**：无前缀；无后缀（单纯词）。
- **同义·反义**：同义 care（在意）, object（反对）；反义 ignore（忽视）, disregard（不理会）。
- **变形**：动词 → 第三人称单数：minds；过去式：minded；过去分词：minded；现在分词：minding；名词派生 → mind n. 头脑；形容词派生 → mindful adj. 留心的。

### 12. fashionable /ˈfæʃnəbl/ adj. 时髦的；流行的
- **词根·渊源**：拉丁 **factio**（facere 做 + **-tio** 名词后缀 = 制作、做法）→ 古法语 *façon*（样式）→ 英语 fashion，加 **-able** 成形容词，本义“可做成样式的→合乎时尚的”。
- **同根词**：fashion（拉丁 factio 做法→样式→时尚）、fashionably（fashionable + **-ly** 副词后缀 = 时髦地）、fashionista（fashion + 意大利 **-ista** 人 = 时尚达人）。
- **前缀·后缀**：无前缀；形容词后缀 **-able**（例：comfortable, readable）。
- **同义·反义**：同义 stylish（时髦的）, trendy（流行的）；反义 unfashionable（过时的）, outdated（过时的）。
- **变形**：形容词 → 比较级：more fashionable；最高级：most fashionable；名词派生 → fashion n. 时尚；副词派生 → fashionably adv. 时髦地。

### 13. fashion /ˈfæʃn/ n. 流行款式；时兴式样；时髦打扮，流行装扮；时尚，时兴
- **词根·渊源**：拉丁 **factio**（facere 做 + **-tio** 名词后缀 = 制作、做法）→ 古法语 *façon*（样式、做法）→ 英语，本义“做法、样式”，引申为“流行的样式→时尚”。
- **同根词**：fashionable（fashion + **-able** 可…的 = 时髦的）、fashionably（fashionable + **-ly** 副词后缀 = 时髦地）、fashionista（fashion + **-ista** 人 = 时尚达人）。
- **前缀·后缀**：无前缀；名词后缀 **-ion**（例：nation, action）。
- **同义·反义**：同义 style（风格）, trend（潮流）；反义 无。
- **变形**：名词 → 复数：fashions；形容词派生 → fashionable adj. 时髦的；副词派生 → fashionably adv. 时髦地。

### 14. out of date /ˌaʊt əv ˈdeɪt/ n. 过时的；过期的；废弃的
- **同义搭配**：outdated（过时的） / old-fashioned（老式的）
- **反义搭配**：up to date（最新的） / fashionable（时髦的）

### 15. iron /ˈaɪərn/ n. 熨；熨烫；熨斗
- **词根·渊源**：古英语 **īsern** → 中古英语 *iren*，源自原始日耳曼语 *isarnan*（金属、铁），本义“铁”，因熨斗用铁制成，引申为“熨斗→熨烫”。
- **同根词**：ironing（iron + **-ing** 名词后缀 = 熨烫）、irony（iron + **-y** …的 = 铁似的；注意与“反讽”irony 不同源）、ironworks（iron 铁 + works 工厂 = 铁厂）。
- **前缀·后缀**：无前后缀（单纯词）。
- **同义·反义**：同义 press（熨烫）, smooth（熨平）；反义 wrinkle（弄皱）。
- **变形**：名词 → 复数：irons（作“铁”义时不可数）；动词 → 第三人称单数：irons；过去式：ironed；过去分词：ironed；现在分词：ironing；名词派生 → ironing n. 熨烫。

### 16. event /ɪˈvent/ n. 比赛；事件，大事；公开活动；社交场合
- **词根·渊源**：拉丁 **evenire**（ex- 出 + venire 来 = 出来、发生）→ 拉丁 *eventus*（结果、发生的事）→ 英语，本义“发生出来的事”，引申为“事件、活动、比赛项目”。
- **同根词**：prevent（**pre-** 前 + vent 来 = 先来→阻止）、invent（**in-** 向内 + vent 来 = 想出来→发明）、convention（**con-** 共同 + vent 来 + **-ion** = 共同来→集会、惯例）、adventure（**ad-** 向 + vent 来 + **-ure** = 来临之事→冒险）。
- **前缀·后缀**：无前缀；名词后缀 **-ent**（例：student, president）。
- **同义·反义**：同义 occurrence（发生的事）, incident（事件）；反义 无。
- **变形**：名词 → 复数：events；形容词派生 → eventful adj. 多事的。

### 17. suppose /səˈpoʊz/ v. 认为；相信；推断；料想；假定，假设
- **词根·渊源**：拉丁 **supponere**（sub- 在下 + ponere 放 = 放在下面→作为基础）→ 古法语 *supposer* → 英语，本义“放在下面作依据”，引申为“假定、认为”。
- **同根词**：supposition（suppose + **-ition** 名词后缀 = 假定）、supposedly（supposed + **-ly** 副词后缀 = 据称）、propose（**pro-** 向前 + pose 放 = 向前放→提议）、compose（**com-** 共同 + pose 放 = 放在一起→组成）。
- **前缀·后缀**：前缀 **sup-**（sub- 的变体，例：support, suspend）；词根 pos（例：propose, compose）。
- **同义·反义**：同义 assume（假定）, presume（推测）；反义 prove（证明）, know（确知）。
- **变形**：动词 → 第三人称单数：supposes；过去式：supposed；过去分词：supposed；现在分词：supposing；名词派生 → supposition n. 假定；副词派生 → supposedly adv. 据称。

### 18. either /ˈiðɚ/ adv. 也
- **词根·渊源**：古英语 **ǣghwæðer**（ǣg 每 + hwæðer 两者之一 = 两者中任一个）→ 中古英语 *either*，本义“两者中的任一个”，用于否定句句末引申为“也（不）”。
- **同根词**：neither（**n-** 不 + either = 两者都不）、whether（古英语 hwæðer 两者之一→是否）。
- **前缀·后缀**：无前后缀（单纯词）。
- **同义·反义**：同义 also（也，用于肯定句）, too（也，用于肯定句）；反义 neither（也不）。
- **变形**：副词 → 无比较级（不作比较）。

### 19. relationship /rɪˈleʃənˌʃɪp/ n. 关系；联系
- **词根·渊源**：拉丁 **relatio / relation-**（带回、报告，源自 **re-** 回 + **lat-** 带、运 + **-ion** 名词后缀）→ 古法语 *relation* → 英语 relation（关系）+ 后缀 **-ship**（表状态、身份），本义“相关联的状态”，引申为“关系；联系”。
- **同根词**：relate（**re-** 回 + **lat-** 带 = 把…带回联系→使有联系、讲述）、relation（**re-** 回 + **lat-** 带 + **-ion** 名词后缀 = 带回的联系→关系、亲属）、relative（relat- 联系 + **-ive** …的 = 有联系的→相对的、亲属）、translate（**trans-** 横过 + **lat-** 带 = 带过去→翻译）、refer（**re-** 回 + **fer-** 带 = 带回→提及、参考）。
- **前缀·后缀**：前缀 **re-**（例：return, review）；名词后缀 **-ship**（例：friendship, leadership）。
- **同义·反义**：同义 connection（联系）, tie（关系）；反义 separation（分离）, independence（独立）。
- **变形**：名词 → 复数：relationships；形容词派生 → relational adj. 关系的；副词派生 → relationally adv. 在关系上。

### 20. invite /ɪnˈvaɪt/ v. 邀请
- **词根·渊源**：拉丁 **invitare**（邀请、款待）→ 古法语 *inviter* → 英语 invite；词源可分析为 **in-** 进入 + 拉丁 **vit-**（与“愿望、寻求”相关，存疑），本义“请人进入、盛情相邀”，引申为“邀请”。
- **同根词**：invitation（invite + **-ation** 名词后缀 = 邀请、请柬）、inviting（invite + **-ing** …的 = 诱人的、吸引人的）、invitational（invitation + **-al** …的 = 邀请赛的）。
- **前缀·后缀**：前缀 **in-**（例：include, inside）；动词后缀 **-ite**（例：unite, excite）。
- **同义·反义**：同义 ask（邀请、请求）, request（请求）；反义 reject（拒绝）, refuse（拒绝）。
- **变形**：动词 → 第三人称单数：invites；过去式：invited；过去分词：invited；现在分词：inviting；名词派生 → invitation n. 邀请；形容词派生 → inviting adj. 诱人的。

### 21. cost /kɒst/ n. 费用；花费；价钱为
- **词根·渊源**：拉丁 **constare**（站立在一起、花费，由 **con-** 共同 + **stare** 站立构成）→ 古法语 *coste / couster* → 英语 cost，本义“付出、花费”，引申为“费用；花费；价钱为”。
- **同根词**：costly（cost + **-ly** …的 = 昂贵的）、costing（cost + **-ing** 名词后缀 = 成本核算）、costless（cost + **-less** 无…的 = 无成本的）。
- **前缀·后缀**：前缀 **co-/con-**（例：connect, combine）；形容词后缀 **-ly**（例：friendly, lovely）。
- **同义·反义**：同义 price（价格）, expense（费用）；反义 profit（利润）, gain（收益）。
- **变形**：名词 → 复数：costs；动词 → 第三人称单数：costs；过去式：cost；过去分词：cost；现在分词：costing；形容词派生 → costly adj. 昂贵的。

### 22. type /taɪp/ n. 种；类；类型
- **词根·渊源**：希腊 **typos**（打击留下的印记、模型）→ 拉丁 *typus* → 法语 *type* → 英语 type，本义“印记、模型”，引申为“类型；种类”。
- **同根词**：typical（type + **-ical** …的 = 典型的）、typist（type + **-ist** 人 = 打字员）、typewriter（type + writer 写者 = 打字机）、prototype（**proto-** 最初 + type 模型 = 原型）、typography（type + **-graphy** 写、印 = 排版术）。
- **前缀·后缀**：前缀 **proto-**（例：protocol, protagonist）；名词后缀 **-ist**（例：artist, scientist）。
- **同义·反义**：同义 kind（种类）, sort（种类）；反义 无。
- **变形**：名词 → 复数：types；动词 → 第三人称单数：types；过去式：typed；过去分词：typed；现在分词：typing；形容词派生 → typical adj. 典型的；副词派生 → typically adv. 典型地。

- **反义搭配**：hinder（阻碍）

### 24. be on business /bi ɔn ˈbɪznɪs/ v. 出差

- **反义搭配**：be on vacation（度假）
