## 二、逐词说文解字

### 1. spacesuit /ˈspeɪˌsut/ n. 航天服；宇航服
- **词根·渊源**：space（空间→太空）+ suit（一套衣服）；space 源自拉丁 *spatium*（空间）→ 古法语 *espace* → 英语，suit 源自通俗拉丁 *sequi*（跟随）→ 古法语 *suite*（随行的一套）→ 英语；20世纪航天时代复合而成“太空穿的一套衣服”。
- **同根词**：spacecraft（space 太空 + craft 飞行器 = 航天器）、spaceman（space + man 人 = 宇航员）、spaceship（space + ship 船 = 宇宙飞船）、spatial（spati 空间 + **-al** …的 = 空间的）、suitable（suit 相配 + **-able** 能…的 = 合适的）、suite（suit 随行的一套 = 套房）。
- **前缀·后缀**：名词后缀 **-al**（例：natural, cultural）；形容词后缀 **-able**（例：comfortable, readable）。
- **同义·反义**：同义 space gear（太空装备）, pressure suit（压力服）；反义 无。
- **变形**：名词 → 复数：spacesuits；形容词派生 → spacesuited adj. 穿航天服的。

### 2. collect /kəˈlɛkt/ v. 收集；采集
- **词根·渊源**：拉丁 **col- / com-**（一起）+ **leg- / lect-**（挑选、读）→ 拉丁 *colligere*（聚拢）→ 古法语 *collecter* → 英语；本义“把东西挑到一起”，引申为“收集、采集”。
- **同根词**：collection（collect + **-ion** 名词后缀 = 收集；收藏品）、collector（collect + **-or** 人 = 收集者）、collective（collect + **-ive** …的 = 集体的）、select（**se-** 分开 + lect 挑 = 挑出来→选择）、elect（**e-** 出 + lect 挑 = 挑出→选举）、lecture（lect 读 + **-ure** 名词后缀 = 读讲→讲座）、legend（leg 读 + **-end** 应读之物 = 传说）。
- **前缀·后缀**：前缀 **col- / com-**（例：combine, connect）；名词后缀 **-ion**（例：action, education）、**-or**（例：actor, visitor）；形容词后缀 **-ive**（例：active, creative）。
- **同义·反义**：同义 gather（聚集）, accumulate（积累）；反义 scatter（散开）, disperse（驱散）。
- **变形**：动词 → 第三人称单数：collects；过去式：collected；过去分词：collected；现在分词：collecting；名词派生 → collection n. 收集；collector n. 收集者；形容词派生 → collective adj. 集体的；副词派生 → collectively adv. 集体地。

### 3. leave /liv/ v. 离开
- **词根·渊源**：古英语 *lǣfan*（留下、遗留），与 *belifan*（remain 留下）同源，属日耳曼语族；本义“使留下”，后引申出“离开（把某地留在身后）”。
- **同根词**：leftover（left 留下 + over 多余 = 剩饭；剩余的）、left（leave 的过去分词→留下的→左边的，因古时以左手为“留下不管”之手，存疑）。
- **前缀·后缀**：无前后缀（单纯词）。
- **同义·反义**：同义 depart（离开）, quit（离开）；反义 arrive（到达）, stay（停留）。
- **变形**：动词 → 第三人称单数：leaves；过去式：left；过去分词：left；现在分词：leaving；名词派生 → leaver n. 离开者。

### 4. kilometre /ˌkɪˈlɔˌmətər/ n. 千米；公里
- **词根·渊源**：法语 **kilo-**（千，源自希腊 *khilioi* 一千）+ **metre**（米，源自希腊 *metron* 度量）→ 法语 *kilomètre* → 英语；本义“一千米”。
- **同根词**：kilogram（kilo 千 + gram 克 = 千克）、kilowatt（kilo 千 + watt 瓦特 = 千瓦）、millimetre（milli 千分之一 + metre 米 = 毫米）、centimetre（centi 百分之一 + metre 米 = 厘米）、metre（metr 度量 = 米）、metric（metr 度量 + **-ic** …的 = 公制的）、thermometer（thermo 热 + meter 测量 = 温度计）。
- **前缀·后缀**：前缀 **kilo-**（例：kilogram, kilowatt）、**milli-**（例：milligram, millilitre）、**centi-**（例：centigram, centilitre）；名词后缀 **-ic**（例：music, magic）。
- **同义·反义**：同义 kilometer（公里，美式拼写）, km（千米缩写）；反义 无。
- **变形**：名词 → 复数：kilometres；形容词派生 → kilometric adj. 千米的。

### 5. weak /wik/ adj. 虚弱的；无力的
- **词根·渊源**：古诺斯语 *veikr*（柔弱的）→ 古英语 *wāc*，属日耳曼语族，与 *weichen*（让步、变软）同源；本义“易弯的、软弱的”，引申为“虚弱的”。
- **同根词**：weakness（weak + **-ness** 名词后缀 = 虚弱；弱点）、weaken（weak + **-en** 使… = 使变弱）、weakling（weak + **-ling** 小/可怜的人 = 体弱者）、weakly（weak + **-ly** …地 = 虚弱地）。
- **前缀·后缀**：名词后缀 **-ness**（例：kindness, darkness）；动词后缀 **-en**（例：widen, strengthen）；副词后缀 **-ly**（例：quickly, badly）。
- **同义·反义**：同义 feeble（虚弱的）, faint（无力的）；反义 strong（强壮的）, powerful（有力的）。
- **变形**：形容词 → 比较级：weaker；最高级：weakest；名词派生 → weakness n. 虚弱；动词派生 → weaken v. 使变弱；副词派生 → weakly adv. 虚弱地。

### 6. tie /taɪ/ v. (用线、绳等)拴
- **词根·渊源**：古英语 *tīgan*（系、绑），属日耳曼语族，与 *tēag*（绳）同源；本义“用绳系住”，引申为“拴、绑”。
- **同根词**：untie（**un-** 相反 + tie 系 = 解开）、tie-up（tie 系 + up 上 = 停顿；关联）、bow tie（bow 蝴蝶结 + tie 领带 = 领结）。
- **前缀·后缀**：前缀 **un-**（例：unlock, undo）。
- **同义·反义**：同义 bind（捆绑）, fasten（系紧）；反义 untie（解开）, loosen（松开）。
- **变形**：动词 → 第三人称单数：ties；过去式：tied；过去分词：tied；现在分词：tying；名词派生 → tie n. 领带；平局。

### 7. low /loʊ/ adj. 低于通常(或平均)数量(或水平、价值)的
- **词根·渊源**：古诺斯语 *lágr*（低的）→ 中古英语 *low*，属日耳曼语族，与 *lie*（躺）同源；本义“躺在地上的、位置低的”，引申为“低于通常水平的”。
- **同根词**：lower（low + **-er** 比较级→动词化 = 降低）、lowly（low + **-ly** …的 = 低微的）、below（**be-** 在 + low 低 = 在下面）、lowland（low 低 + land 地 = 低地）。
- **前缀·后缀**：前缀 **be-**（例：behind, beside）；形容词/副词后缀 **-ly**（例：friendly, kindly）。
- **同义·反义**：同义 short（不足的）, inferior（较低的）；反义 high（高的）, tall（高的）。
- **变形**：形容词 → 比较级：lower；最高级：lowest；副词派生 → low adv. 低地；lowly adv. 低微地；动词派生 → lower v. 降低。

### 8. weigh /weɪ/ v. 有…重；重
- **词根·渊源**：古英语 *wegan*（举起、称重），属日耳曼语族，与 *weight* 同源，源自 PIE *wegh-*（运送、移动）；本义“把东西举起来估量”，引申为“称重、有…重”。
- **同根词**：weight（weigh + **-t** 名词后缀 = 重量）、weighbridge（weigh 称 + bridge 桥 = 地磅）、weigh-in（weigh 称 + in 进 = 赛前称重）、outweigh（**out-** 超过 + weigh 重 = 重于）。
- **前缀·后缀**：前缀 **out-**（例：outrun, outnumber）；名词后缀 **-t**（例：gift, flight）。
- **同义·反义**：同义 measure（测量）, consider（考虑）；反义 无。
- **变形**：动词 → 第三人称单数：weighs；过去式：weighed；过去分词：weighed；现在分词：weighing；名词派生 → weight n. 重量。

### 9. breathe /brið/ v. 呼吸
- **词根·渊源**：中古英语 *brethen*，源自古英语 *brǣþ*（气味、呼吸），属日耳曼语族；本义“呼出气息”，引申为“呼吸”。
- **同根词**：breath（breathe 去掉 e = 呼吸；气息）、breathing（breathe + **-ing** 名词后缀 = 呼吸）、breather（breathe + **-er** 人/物 = 短暂休息）、breathless（breath + **-less** 无…的 = 气喘的）。
- **前缀·后缀**：名词后缀 **-ing**（例：running, swimming）、**-er**（例：teacher, worker）；形容词后缀 **-less**（例：hopeless, careless）。
- **同义·反义**：同义 respire（呼吸）, inhale（吸气）；反义 suffocate（窒息）, choke（窒息）。
- **变形**：动词 → 第三人称单数：breathes；过去式：breathed；过去分词：breathed；现在分词：breathing；名词派生 → breath n. 呼吸；breathing n. 呼吸。

### 10. facility /fəˈsɪlɪti/ n. 设施；设备
- **词根·渊源**：拉丁 **facil-**（容易的，源自 *facere* 做）+ **-ity**（名词后缀）→ 拉丁 *facilitas*（容易）→ 法语 *facilité* → 英语；本义“容易做到”，引申为“使事情容易的设施、设备”。
- **同根词**：facilitate（facil 容易 + **-itate** 动词后缀 = 使容易→促进）、facile（facil 容易 + **-e** = 容易的；肤浅的）、fact（fac 做 + **-t** = 做成的事→事实）、factory（fact 做 + **-ory** 场所 = 制造场所→工厂）、perfect（**per-** 完全 + fect 做 = 完全做好→完美的）、effect（**e-** 出 + fect 做 = 做出→效果）。
- **前缀·后缀**：名词后缀 **-ity**（例：ability, activity）、**-ory**（例：dormitory, laboratory）；动词后缀 **-itate**（例：imitate, irritate）；前缀 **per-**（例：perform, permit）、**e-**（例：elect, emerge）。
- **同义·反义**：同义 equipment（设备）, amenity（便利设施）；反义 无。
- **变形**：名词 → 复数：facilities；动词派生 → facilitate v. 促进；形容词派生 → facile adj. 容易的。

### 11. adventure /ədˈvɛnʧər/ n. 冒险；冒险经历；奇遇
- **词根·渊源**：拉丁 **ad-**（向）+ **vent-**（来，源自 *venire*）→ 拉丁 *adventurus*（将要到来的事）→ 古法语 *aventure* → 英语；本义“将要发生的事”，引申为“冒险、奇遇”。
- **同根词**：adventurous（adventure + **-ous** …的 = 爱冒险的）、adventurer（adventure + **-er** 人 = 冒险家）、advent（**ad-** 向 + vent 来 = 到来）、event（**e-** 出 + vent 来 = 发生的事→事件）、invent（**in-** 进 + vent 来 = 走进→发明）、prevent（**pre-** 前 + vent 来 = 先来→阻止）、convention（**con-** 一起 + vent 来 + **-ion** = 一起来→会议；惯例）。
- **前缀·后缀**：前缀 **ad-**（例：advance, admire）、**e-**（例：exit, evade）、**in-**（例：include, inform）、**pre-**（例：predict, prepare）、**con-**（例：connect, confirm）；名词后缀 **-ure**（例：picture, nature）、**-ion**（例：action, decision）；形容词后缀 **-ous**（例：famous, dangerous）。
- **同义·反义**：同义 exploit（壮举）, venture（冒险）；反义 safety（安全）, security（安全）。
- **变形**：名词 → 复数：adventures；形容词派生 → adventurous adj. 爱冒险的；副词派生 → adventurously adv. 冒险地；名词派生 → adventurer n. 冒险家。

### 12. pass /pæs/ v. 沿某方向前进；向某方向移动
- **词根·渊源**：拉丁 **passus**（步、步伐，源自 *pandere* 伸展）→ 古法语 *passer*（走过）→ 英语；本义“迈步走过”，引申为“沿某方向前进、移动”。
- **同根词**：passage（pass + **-age** 名词后缀 = 通道；段落）、passenger（pass + **-enger** 人 = 过路人→乘客）、passport（pass 通过 + port 港口 = 通过港口的证件→护照）、passable（pass + **-able** 能…的 = 可通过的）、surpass（**sur-** 超过 + pass 过 = 超过）、trespass（**tres-** 越过 + pass 过 = 非法侵入）。
- **前缀·后缀**：名词后缀 **-age**（例：marriage, package）、**-able**（例：comfortable, readable）；前缀 **sur-**（例：surface, survive）、**tres-**（例：trespass 本身）。
- **同义·反义**：同义 move（移动）, proceed（前进）；反义 stop（停止）, halt（停下）。
- **变形**：动词 → 第三人称单数：passes；过去式：passed；过去分词：passed；现在分词：passing；名词派生 → passage n. 通道；passenger n. 乘客。

### 13. experiment /ɪkˈspɛrəmənt/ n. 实验；试验
- **词根·渊源**：拉丁 **ex-**（出）+ **peri-**（尝试，源自 *periri* 试）→ 拉丁 *experimentum*（试验）→ 古法语 *experiment* → 英语；本义“试出来的结果”，引申为“实验、试验”。
- **同根词**：experimental（experiment + **-al** …的 = 实验的）、experimenter（experiment + **-er** 人 = 实验者）、experience（**ex-** 出 + peri 试 + **-ence** = 试出来的→经验）、expert（**ex-** 出 + pert 试 = 试出来的→专家）、peril（peri 试→危险）。
- **前缀·后缀**：前缀 **ex-**（例：exit, export）；名词后缀 **-ence**（例：difference, patience）、**-al**（例：natural, cultural）、**-er**（例：teacher, worker）。
- **同义·反义**：同义 test（测试）, trial（试验）；反义 无。
- **变形**：名词 → 复数：experiments；形容词派生 → experimental adj. 实验的；副词派生 → experimentally adv. 实验地；名词派生 → experimenter n. 实验者。

### 14. prepare /priˈpɛr/ v. 使做好准备；把……预备好
- **词根·渊源**：拉丁 **pre-**（前）+ **parare**（准备、使就绪）→ 拉丁 *praeparare* → 法语 *préparer* → 英语；本义“事先弄好”，引申为“使做好准备”。
- **同根词**：preparation（prepare + **-ation** 名词后缀 = 准备）、preparatory（prepare + **-atory** …的 = 预备的）、repair（**re-** 再 + pair 准备 = 重新弄好→修理）、apparatus（**ad-** 向 + par 准备 + **-atus** = 备好的东西→器械）、separate（**se-** 分开 + par 准备 = 分开准备→分离）。
- **前缀·后缀**：前缀 **pre-**（例：predict, prevent）、**re-**（例：return, rebuild）、**se-**（例：select, secure）；名词后缀 **-ation**（例：information, education）；形容词后缀 **-atory**（例：explanatory, observatory）。
- **同义·反义**：同义 ready（使准备好）, arrange（安排）；反义 neglect（忽视）, ignore（忽略）。
- **变形**：动词 → 第三人称单数：prepares；过去式：prepared；过去分词：prepared；现在分词：preparing；名词派生 → preparation n. 准备；形容词派生 → prepared adj. 有准备的；preparatory adj. 预备的。

### 15. dream /drim/ n. 梦想；理想；v.做梦；梦见
- **词根·渊源**：中古英语 *dreme*，源自古英语 *drēam*（欢乐、音乐），后受古诺斯语 *draumr*（梦）影响，词义转为“梦”；本义“幻象、梦境”，引申为“梦想、理想”。
- **同根词**：dreamer（dream + **-er** 人 = 做梦的人；梦想家）、dreamy（dream + **-y** …的 = 梦幻的）、daydream（day 白天 + dream 梦 = 白日梦）、dreamland（dream 梦 + land 地 = 梦境）。
- **前缀·后缀**：名词后缀 **-er**（例：teacher, worker）；形容词后缀 **-y**（例：rainy, windy）。
- **同义·反义**：同义 vision（幻想）, aspiration（渴望）；反义 reality（现实）, fact（事实）。
- **变形**：名词 → 复数：dreams；动词 → 第三人称单数：dreams；过去式：dreamed/dreamt；过去分词：dreamed/dreamt；现在分词：dreaming；形容词派生 → dreamy adj. 梦幻的；名词派生 → dreamer n. 梦想家。

### 16. chance /ʧæns/ n. 机会；机遇
- **词根·渊源**：通俗拉丁 *cadentia*（落下，源自 *cadere* 落下）→ 古法语 *cheance*（骰子落下的结果）→ 英语；本义“骰子落下的偶然结果”，引申为“机会、机遇”。

### 35. kilogram /ˈkɪləˌgræm/ n. 千克；公斤
- **词根·渊源**：希腊 **khilioi**（一千）+ 法语 **gramme**（克，源自希腊 gramma 小重量）→ 法语 *kilogramme* → 英语 kilogram，本义“一千克”，即“千克、公斤”。
- **同根词**：kilo（希腊 khilioi 一千→千）、gram（希腊 gramma 小重量→克）、kilometer（kilo 千 + meter 米 = 千米→公里）、milligram（**milli-** 千分之一 + gram 克 = 毫克）。
- **前缀·后缀**：前缀 **kilo-**（例：kilometer, kilowatt）；词根 **-gram**（例：telegram, diagram）。
- **同义·反义**：同义 kilo（公斤，口语）；反义 无。
- **变形**：名词 → 复数：kilograms；缩写 → kg。

### 36. programme /ˈproʊˌgræm/ n. 计划；方案
- **词根·渊源**：希腊 **pro-**（在前）+ **gramma**（写下的东西）→ 希腊 *programma*（预先写下的公告）→ 法语 *programme* → 英语 programme，本义“预先写下的东西”，引申为“计划、方案”。
- **同根词**：program（同源，美式拼写→程序、节目）、grammar（希腊 gramma 写下的东西 + **-ar** = 写下的规则→语法）、telegram（**tele-** 远 + gram 写 = 远距离写来的东西→电报）、diagram（**dia-** 穿过 + gram 写 = 画穿的线→图表）、gram（希腊 gramma 小重量→克）。
- **前缀·后缀**：前缀 **pro-**（例：progress, project）；词根 **-gram**（例：telegram, diagram）。
- **同义·反义**：同义 plan（计划）, schedule（日程）；反义 无。
- **变形**：名词 → 复数：programmes；动词派生 → programme v. 编程、计划。
