## 二、逐词说文解字

### 1. respond /rɪˈspɑːnd/ v.（口头或书面）回答，回应；作出反应，回应
- **词根·渊源**：拉丁 **respond-**（回应、承诺）→ 古法语 *respondre* → 英语 respond；本义“回话、作答”，引申为“作出反应”。
- **同根词**：response（respond + **-se** 名词后缀 = 回答→回应）、responsible（**re-** 回 + spons 承诺 + **-ible** 能…的 = 能兑现承诺的→负责任的）、responsibility（responsible + **-ity** 名词后缀 = 责任）、correspond（**cor-** 共同 + respond 回应 = 互相回应→通信、相符）。
- **前缀·后缀**：前缀 **re-**（例：return, reply）；无后缀（动词原形）。
- **同义·反义**：同义 answer（回答）, reply（答复）；反义 ignore（忽视）, ask（询问）。
- **变形**：动词 → 第三人称单数：responds；过去式：responded；过去分词：responded；现在分词：responding；名词派生 → response n. 回答、反应；形容词派生 → responsive adj. 响应的、反应快的。

### 2. complaint /kəm'pleɪnt/ n. 抱怨，投诉；不满的缘由，抱怨的问题；疾病，不适
- **词根·渊源**：拉丁 **plangere**（拍打胸口、哀叹）→ 古法语 *complaindre* → 英语 complain；com-（加强）+ plangere = 大声哀叹→抱怨；名词 complaint 由 complain 加 **-t** 构成，本义“哀叹之声”，引申为“投诉、不满之事”，再引申为“疾病”。
- **同根词**：complain（com- 加强 + plain 哀叹 = 抱怨、投诉）、complaining（complain + **-ing** 形容词后缀 = 抱怨的）、plaintive（plaint 哀叹 + **-ive** …的 = 哀伤的）。
- **前缀·后缀**：前缀 **com-**（例：comfort, combine）；名词后缀 **-t**（例：complaint 本身；gift, flight）。
- **同义·反义**：同义 protest（抗议）, grievance（不满）；反义 praise（赞扬）, satisfaction（满意）。
- **变形**：名词 → 复数：complaints；动词派生 → complain v. 抱怨；形容词派生 → complaining adj. 抱怨的。

### 3. cause /kɔːz/ v. 造成；引起，使发生
- **词根·渊源**：拉丁 **causa**（原因、理由、诉讼）→ 古法语 *cause* → 英语 cause；本义“原因”，动词化后表示“成为…的原因”，即“造成、引起”。
- **同根词**：because（**be-** 由 + cause 原因 = 由于…原因→因为）、causal（caus 原因 + **-al** …的 = 原因的、因果的）、causation（caus 原因 + **-ation** 名词后缀 = 因果关系）。
- **前缀·后缀**：无前缀（单纯词）；无后缀（动词原形）。
- **同义·反义**：同义 produce（产生）, trigger（引发）；反义 prevent（阻止）, stop（停止）。
- **变形**：动词 → 第三人称单数：causes；过去式：caused；过去分词：caused；现在分词：causing；名词派生 → cause n. 原因、事业；形容词派生 → causal adj. 因果的。

### 4. chocolate /ˈtʃɒklət/ n. 巧克力
- **词根·渊源**：纳瓦特尔语（阿兹特克语）*chocolātl*（一种苦味饮料）→ 西班牙语 *chocolate* → 英语 chocolate；本义“可可饮料”，后指“巧克力（糖）”。
- **同根词**：chocolaty（chocolate + **-y** …的 = 巧克力味的）、chocoholic（choco 巧克力 + **-holic** 沉迷者 = 巧克力迷）。
- **前缀·后缀**：无前缀（借词）；无后缀（名词原形）。
- **同义·反义**：同义 candy（糖果）, cocoa（可可）；反义 无。
- **变形**：名词 → 复数：chocolates（作“巧克力糖”义可数；作“巧克力”物质义不可数）；形容词派生 → chocolaty adj. 巧克力味的。

### 5. dolphin /ˈdɒlfɪn/ n. 海豚
- **词根·渊源**：希腊语 *delphīs / delphin-*（海豚，亦指德尔斐）→ 拉丁 *delphinus* → 古法语 *daulphin* → 英语 dolphin；本义即“海豚”，词源细节存疑。
- **同根词**：dolphinarium（dolphin + **-arium** 场所 = 海豚馆）、delphinium（希腊 delphin 海豚 + **-ium** 植物名后缀 = 飞燕草，因花形似海豚）。
- **前缀·后缀**：无前缀（借词）；无后缀（名词原形）。
- **同义·反义**：同义 porpoise（鼠海豚）；反义 无。
- **变形**：名词 → 复数：dolphins；形容词派生 → dolphinlike adj. 海豚般的。

### 6. click /klɪk/ v. 点击；使发出咔哒声
- **词根·渊源**：拟声词，模拟短促的“咔哒”声（比较荷兰语 *klikken*、法语 *cliquer*）→ 英语 click；本义“发出咔哒声”，计算机时代引申为“点击（鼠标）”。
- **同根词**：clicker（click + **-er** 物/人 = 发出咔哒声的东西→遥控器）、clickable（click + **-able** 可…的 = 可点击的）。
- **前缀·后缀**：无前缀（拟声单纯词）；无后缀（动词原形）。
- **同义·反义**：同义 tap（轻敲）, snap（啪地响）；反义 无。
- **变形**：动词 → 第三人称单数：clicks；过去式：clicked；过去分词：clicked；现在分词：clicking；名词派生 → click n. 咔哒声、点击。

### 7. reason /ˈrizən/ n. 原因；理由
- **词根·渊源**：拉丁 **ratio / ration-**（计算、理性）→ 古法语 *raison* → 英语 reason；本义“计算、思量”，引申为“理性”，再引申为“原因、理由”。
- **同根词**：reasonable（reason + **-able** 能…的 = 有理由的→合理的）、reasoning（reason + **-ing** 名词后缀 = 推理）、rational（ratio 理性 + **-al** …的 = 理性的）、ratio（直接借自拉丁 ratio = 比率）。
- **前缀·后缀**：无前缀（借词）；无后缀（名词原形）。
- **同义·反义**：同义 cause（原因）, ground（根据）；反义 unreason（无理）, 无直接反义名词。
- **变形**：名词 → 复数：reasons；动词派生 → reason v. 推理、说服；形容词派生 → reasonable adj. 合理的；副词派生 → reasonably adv. 合理地。

### 8. cute /kjuːt/ adj. 可爱的；机灵的；讨人喜欢的
- **词根·渊源**：由 **acute**（敏锐的）缩略而来 → 英语 cute；本义“敏锐的、机灵的”，19世纪美式英语引申为“可爱的、讨人喜欢的”。
- **同根词**：acute（a- 加强 + cut 尖 = 尖锐的→敏锐的、急性的）、cuteness（cute + **-ness** 名词后缀 = 可爱）、cutely（cute + **-ly** 副词后缀 = 可爱地）。
- **前缀·后缀**：无前缀（缩略词）；无后缀（形容词原形）。
- **同义·反义**：同义 lovely（可爱的）, charming（迷人的）；反义 ugly（丑陋的）, unattractive（不吸引人的）。
- **变形**：形容词 → 比较级：cuter；最高级：cutest；名词派生 → cuteness n. 可爱；副词派生 → cutely adv. 可爱地。

### 9. responsibility /rɪˌspɑːnsəˈbɪləti/ n. 责任，负责
- **词根·渊源**：拉丁 **respond-**（回应、承诺）→ responsible + **-ity**；本义“能够回应、兑现承诺的状态”，即“责任、负责”。
- **同根词**：responsible（**re-** 回 + spons 承诺 + **-ible** 能…的 = 能兑现承诺的→负责的）、respond（re- 回 + spond 承诺 = 回应）、response（respond + **-se** = 回答）、sponsor（spons 承诺 + **-or** 人 = 承诺担保者→赞助者）。
- **前缀·后缀**：前缀 **re-**（例：return, reply）；名词后缀 **-ity**（例：activity, ability）。
- **同义·反义**：同义 duty（职责）, obligation（义务）；反义 irresponsibility（不负责任）。
- **变形**：名词 → 复数：responsibilities；形容词派生 → responsible adj. 负责的；副词派生 → responsibly adv. 负责地。

### 10. feed /fiːd/ v. 喂，喂养；为……提供食物
- **词根·渊源**：古英语 *fēdan*（喂养）→ 中古英语 *feden* → 英语 feed；与 food 同源，本义“给…食物”，引申为“提供、供给”。
- **同根词**：food（与 feed 同源，古英语 fōda = 食物）、feeder（feed + **-er** 物/人 = 喂食器、饲养员）、feedback（feed 供给 + back 回 = 反馈）、feeding（feed + **-ing** 名词后缀 = 喂养）。
- **前缀·后缀**：无前缀（单纯词）；无后缀（动词原形）。
- **同义·反义**：同义 nourish（滋养）, supply（供给）；反义 starve（使挨饿）, fast（禁食）。
- **变形**：动词 → 第三人称单数：feeds；过去式：fed；过去分词：fed；现在分词：feeding；名词派生 → feed n. 饲料、喂养；feeder n. 饲养员、喂食器。

### 11. according to /əˈkɔːdɪŋ tə/ n. 按照；根据；据（......所说）
- **同义搭配**：in accordance with（依照）/ on the basis of（根据）
- **反义搭配**：contrary to（与……相反）

### 12. faithfully /ˈfeɪθfəli/ adv. 忠实地，忠诚地；准确地，如实地；有规律地
- **词根·渊源**：拉丁 **fides**（信任、信念）→ 古法语 *feid* → 英语 faith；faithful（faith + **-ful** 充满…的 = 充满信念的→忠实的）+ **-ly** 副词后缀 = 忠实地；引申为“准确地、有规律地”。
- **同根词**：faith（拉丁 fides 信任 = 信念、信仰）、faithful（faith + **-ful** 充满…的 = 忠实的）、faithfulness（faithful + **-ness** 名词后缀 = 忠实）、fidelity（拉丁 fides 信任 + **-ity** 名词后缀 = 忠诚）。
- **前缀·后缀**：无前缀（借词）；副词后缀 **-ly**（例：quickly, happily）；形容词后缀 **-ful**（例：helpful, careful）。
- **同义·反义**：同义 loyally（忠诚地）, accurately（准确地）；反义 unfaithfully（不忠地）, disloyally（不忠地）。
- **变形**：副词 → 无比较级（多音节副词用 more/ most，但通常不作比较）；形容词派生 → faithful adj. 忠实的；名词派生 → faithfulness n. 忠实。

### 13. sofa /ˈsəʊfə/ n. 长沙发
- **词根·渊源**：阿拉伯语 *ṣuffa*（铺有垫子的长凳）→ 土耳其语 *sofa* → 法语 *sofa* → 英语 sofa；本义“长凳、坐榻”，引申为“长沙发”。
- **同根词**：sofa bed（sofa + bed = 沙发床）。
- **前缀·后缀**：无前缀（借词）；无后缀（名词原形）。
- **同义·反义**：同义 couch（长沙发）, settee（长靠椅）；反义 无。
- **变形**：名词 → 复数：sofas；无形容词派生（常用复合词 sofa bed）。

### 14. noisy /ˈnɔɪzi/ adj. 吵闹的；嘈杂的
- **词根·渊源**：古法语 *noise*（喧闹、争吵，词源存疑）→ 英语 noise；noise + **-y** 形容词后缀 = 充满噪音的→吵闹的。
- **同根词**：noise（古法语 noise 喧闹 = 噪音）、noisily（noisy 变 y 为 i + **-ly** 副词后缀 = 吵闹地）、noisiness（noisy 变 y 为 i + **-ness** 名词后缀 = 吵闹）。
- **前缀·后缀**：无前缀（借词）；形容词后缀 **-y**（例：rainy, windy）。
- **同义·反义**：同义 loud（大声的）, rowdy（喧闹的）；反义 quiet（安静的）, silent（寂静的）。
- **变形**：形容词 → 比较级：noisier；最高级：noisiest；名词派生 → noisiness n. 吵闹；副词派生 → noisily adv. 吵闹地。

### 15. nearly /ˈnɪəli/ adv. 几乎；差不多，将近
- **词根·渊源**：古英语 *nēar*（更近，near 的比较级）+ **-ly** → 中古英语 *nerly* → 英语 nearly；本义“接近地”，引申为“几乎、差不多”。
- **同根词**：near（古英语 nēar 更近 = 近的）、nearby（near + by 在旁 = 附近的）、nearness（near + **-ness** 名词后缀 = 接近）。
- **前缀·后缀**：无前缀（单纯词）；副词后缀 **-ly**（例：quickly, badly）。
- **同义·反义**：同义 almost（几乎）, approximately（大约）；反义 exactly（确切地）, completely（完全地）。
- **变形**：副词 → 无比较级（多音节副词通常不作比较）；形容词派生 → near adj. 近的；名词派生 → nearness n. 接近。

### 16. stranger /ˈstrendʒɚ/ adj. 陌生人，外来者
- **词根·渊源**：拉丁 **extraneus**（外来的）→ 古法语 *estrange* → 英语 strange；strange + **-er** 人 = 外来的人→陌生人。
- **同根词**：strange（拉丁 extraneus 外来的 = 奇怪的、陌生的）、strangely（strange + **-ly** 副词后缀 = 奇怪地）、strangeness（strange + **-ness** 名词后缀 = 奇怪）、estrange（**e-** 出 + strange 陌生 = 使疏远）。
- **前缀·后缀**：无前缀（借词）；名词后缀 **-er**（例：teacher, worker）。
- **同义·反义**：同义 outsider（外来者）, foreigner（外国人）；反义 acquaintance（熟人）, friend（朋友）。
- **变形**：名词 → 复数：strangers；形容词派生 → strange adj. 奇怪的、陌生的；副词派生 → strangely adv. 奇怪地。

### 17. common /ˈkɑːmən/ adj. 普通的；常见的；普遍的；一般的
- **词根·渊源**：拉丁 **communis**（共同的、公共的）→ 古法语 *comun* → 英语 common；本义“共有的”，引申为“普遍的、常见的、普通的”。
- **同根词**：community（commun 共同 + **-ity** 名词后缀 = 共同体→社区）、communicate（commun 共同 + **-icate** 动词后缀 = 使共同→交流）、communism（commun 共同 + **-ism** 主义 = 共产主义）、commonplace（common + place 地方 = 平常的）。
- **前缀·后缀**：前缀 **com-**（例：combine, comfort）；无后缀（形容词原形）。
- **同义·反义**：同义 ordinary（普通的）, usual（通常的）；反义 rare（稀有的）, unusual（不寻常的）。
- **变形**：形容词 → 比较级：commoner；最高级：commonest；名词派生 → commonness n. 普通；副词派生 → commonly adv. 通常地。

### 18. choice /tʃɔɪs/ n. 选择；挑选；抉择
- **词根·渊源**：古法语 *chois*（选择）→ 英语 choice；源自动词 *choisir*（选择），与 choose 同源，本义“挑选的行为”，引申为“选择、抉择”。
- **同根词**：choose（古英语 cēosan 选择 = 选择）、choosy（choose 变 oo 为 o + **-y** 形容词后缀 = 挑剔的）、choosing（choose + **-ing** 名词后缀 = 选择）。
- **前缀·后缀**：无前缀（借词）；无后缀（名词原形）。
- **同义·反义**：同义 selection（挑选）, option（选项）；反义 rejection（拒绝）, refusal（拒绝）。
- **变形**：名词 → 复数：choices；动词派生 → choose v. 选择；形容词派生 → choosy adj. 挑剔的。

### 19. lie /laɪ/ v. 躺；平躺；平放
- **词根·渊源**：古英语 *licgan*（躺卧）→ 中古英语 *lien* → 现代英语 lie；与德语 *liegen*、拉丁 *lectus*（床）同出 PIE 词根 *legh-*（躺下）。本义即“躺卧”，后引申出“平放、位于”等义。注意与 lie（说谎）为同形异源词。
- **同根词**：lying（lie + **-ing** 现在分词/动名词：躺着的；躺卧）、lay（古英语 *lecgan*，lie 的使役形式：使躺下→放置，与 lie 同源）、ledge（与 lie 同源，本义“躺卧之处”→壁架）、lair（古英语 *leger*“床、卧处”→兽穴）。
- **前缀·后缀**：无前后缀（单纯词）。
- **同义·反义**：同义 recline（斜躺）, rest（休息躺卧）；反义 stand（站立）, rise（起身）。
- **变形**：动词 → 第三人称单数：lies；过去式：lay；过去分词：lain；现在分词：lying；名词派生 → lie n. 位置、状态（如 the lie of the land）；名词派生 → lying n. 躺卧。

### 20. attention /əˈtɛnʃən/ n. 注意力；留心
- **词根·渊源**：拉丁 **tend- / tens-**（伸展）→ 拉丁 *attendere*（ad- 向 + tendere 伸 = 把心思伸向）→ 古法语 *atencion* → 英语 attention；本义“心思向某物伸展”，即“注意、留心”。
- **同根词**：attend（**at-** 向 + tend 伸 = 把心思伸向→出席、照料）、tend（tend 伸→趋向、倾向）、tension（tens 伸 + **-ion** 名词后缀 = 拉紧→紧张）、extend（**ex-** 向外 + tend 伸 = 向外伸展→延伸）、intend（**in-** 向内 + tend 伸 = 心思伸向→打算）、pretend（**pre-** 在前 + tend 伸 = 在前面张开→假装）。
- **前缀·后缀**：前缀 **at-**（例：attend, attract）；名词后缀 **-ion**（例：action, tension）。
- **同义·反义**：同义 focus（专注）, notice（注意）；反义 inattention（不注意）, neglect（忽视）。
- **变形**：名词 → 复数：attentions（常用不可数）；形容词派生 → attentive adj. 注意的、专心的；副词派生 → attentively adv. 专心地；动词派生 → attend v. 出席、照料。

### 21. scare /skɛr/ v. 使害怕；使恐惧；使惊恐，吓唬
- **词根·渊源**：中古英语 *skerren*（使害怕），源自古诺斯语 *skirra*（使惊恐），与古英语 *scearu*（恐惧）相关，词源可追溯至 PIE *sker-*（跳跃、惊跳）；本义“使人惊跳”，引申为“使害怕、吓唬”。
- **同根词**：scary（scare + **-y** …的：吓人的）、scared（scare + **-ed** 被吓的：害怕的）、scaresome（scare + **-some** 令人…的：可怕的，较少用）。
- **前缀·后缀**：无前缀；形容词后缀 **-y**（例：rainy, dirty）、**-ed**（例：tired, excited）。
- **同义·反义**：同义 frighten（使害怕）, terrify（使恐惧）；反义 calm（使平静）, comfort（安慰）。
- **变形**：动词 → 第三人称单数：scares；过去式：scared；过去分词：scared；现在分词：scaring；名词派生 → scare n. 惊恐、恐慌；形容词派生 → scary adj. 吓人的；scared adj. 害怕的。

### 22. believe /bɪˈliːv/ v. 相信，认为有可能，认定，看作
- **词根·渊源**：古英语 *belēfan*（**be-** 加强 + *lēfan* 相信、允许）→ 中古英语 *bileven* → 现代英语 believe；与德语 *glauben*、拉丁 *libet*（使高兴、许可）同源，本义“认为可信、认可”，引申为“相信、认为”。
- **同根词**：belief（believe 的名词形式，古英语 *gelēafa*：相信→信念）、believer（believe + **-er** 人：信徒）、believable（believe + **-able** 可…的：可信的）、unbelievable（**un-** 不 + believable 可信的：难以置信的）、beloved（**be-** 加强 + loved 被爱的：心爱的，与 believe 同源 *lēfan* 爱）。
- **前缀·后缀**：前缀 **be-**（例：become, belong）；名词后缀 **-er**（例：teacher, worker）；形容词后缀 **-able**（例：readable, usable）。
- **同义·反义**：同义 trust（信任）, think（认为）；反义 doubt（怀疑）, disbelieve（不相信）。
- **变形**：动词 → 第三人称单数：believes；过去式：believed；过去分词：believed；现在分词：believing；名词派生 → belief n. 信念；believer n. 信徒；形容词派生 → believable adj. 可信的；unbelievable adj. 难以置信的。

### 23. heart /hɑːrt/ n. 心，内心；心脏
- **词根·渊源**：古英语 *heorte*（心脏、内心）→ 中古英语 *herte* → 现代英语 heart；与拉丁 *cor / cord-*、希腊 *kardia* 同出 PIE *kerd-*（心）。本义“心脏”，引申为“内心、感情、核心”。
- **同根词**：hearty（heart + **-y** …的：衷心的、丰盛的）、heartless（heart + **-less** 无…的：无情的）、hearten（heart + **-en** 使…：使振作）、heartily（hearty + **-ly** 副词后缀：衷心地）、cordial（拉丁 cor 心 + **-ial** …的：衷心的）、record（**re-** 回 + cor 心 = 记在心里→记录）、courage（拉丁 cor 心 + **-age** 名词后缀：由心而发的力量→勇气）。
- **前缀·后缀**：无前缀；形容词后缀 **-y**（例：windy, sunny）、**-less**（例：hopeless, careless）；动词后缀 **-en**（例：widen, strengthen）。
- **同义·反义**：同义 core（核心）, center（中心）；反义 无。
- **变形**：名词 → 复数：hearts；形容词派生 → hearty adj. 衷心的；heartless adj. 无情的；副词派生 → heartily adv. 衷心地；动词派生 → hearten v. 使振作。

### 24. heart attack /ˈhɑːt ətæk/ n. 心脏病发作
- **同义搭配**：cardiac arrest（心脏骤停）/ myocardial infarction（心肌梗死）
- **反义搭配**：无

### 25. until /ənˈtɪl/ prep. 到……时，直到……为止
- **词根·渊源**：古诺斯语 *und*（直到）+ *til*（到）→ 中古英语 *untill* → 现代英语 until；本义“直到某时”，由“und（直到）+ til（到）”复合而成，引申为“到……为止”。
- **同根词**：till（until 的缩略形式，古英语 *til*：直到）、unto（古英语 *und* + *to*：到、向，与 until 同源）。
- **前缀·后缀**：无前后缀（复合词，由 und + til 构成）。
- **同义·反义**：同义 till（直到）, up to（直到）；反义 since（自从）。
- **变形**：介词/连词 → 无形态变化（不变词）。
