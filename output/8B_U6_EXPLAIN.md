## 二、逐词说文解字

### 1. stage /steɪʤ/ n. 舞台
- **词根·渊源**：拉丁 **stare**（站立）→ 古法语 *estage*（住所、楼层）→ 英语 stage；本义“站立之处/层”，后指舞台。
- **同根词**：static（**sta-** 站 + **-tic** …的 = 站住不动的→静态的）、station（**sta-** 站 + **-tion** 名词后缀 = 站立之所→车站）、stable（**sta-** 站 + **-ble** 能…的 = 能站稳的→稳定的）、statue（**sta-** 站 + **-ue** 名词后缀 = 站立之像→雕像）、stay（**sta-** 站 → 停留）、stage（本词）。
- **前缀·后缀**：无前后缀（单纯词）。
- **同义·反义**：同义 platform（台）, scene（场景）；反义 无。
- **变形**：名词 → 复数：stages；动词派生 → stage v. 上演；形容词派生 → staged adj.  staged 的、分阶段的。

### 2. clue /klu/ n. 线索；提示
- **词根·渊源**：古英语 *cliewen*（线团）→ 中古英语 *clewe*；本义“线团”，由“顺着线团找路”引申为“线索”。
- **同根词**：clew（同源异体，线团→线索）、clue（本词）。
- **前缀·后缀**：无前后缀（单纯词）。
- **同义·反义**：同义 hint（提示）, sign（迹象）；反义 无。
- **变形**：名词 → 复数：clues；动词派生 → clue v. 提示；形容词派生 → clueless adj. 无线索的、无知的。

### 3. promote /prəˈmoʊt/ v. 促进；推动
- **词根·渊源**：拉丁 **promovere**（向前移动）＝ **pro-** 向前 + **mov-** 移动 → 英语 promote；本义“向前推”，引申为促进、提升。
- **同根词**：move（**mov-** 移动 → 移动）、motion（**mot-** 移动 + **-ion** 名词后缀 = 移动→运动）、mobile（**mob-** 移动 + **-ile** 可…的 = 可移动的）、remove（**re-** 回 + **mov-** 移动 = 移回→移除）、promotion（**pro-** 向前 + **mot-** 移动 + **-ion** = 向前推→促进、晋升）。
- **前缀·后缀**：前缀 **pro-**（例：progress, produce）；词根 **mov-/mot-**（例：movement, motor）。
- **同义·反义**：同义 advance（推进）, encourage（促进）；反义 hinder（阻碍）, prevent（阻止）。
- **变形**：动词 → 第三人称单数：promotes；过去式：promoted；过去分词：promoted；现在分词：promoting；名词派生 → promotion n. 促进、晋升；形容词派生 → promotional adj. 促销的。

### 4. abroad /əˈbrɔd/ adv. 在国外；到国外
- **词根·渊源**：古英语 *on brād*（在广阔处）＝ **a-** 在 + **broad** 宽广 → 中古英语 abroad；本义“广泛地、在外”，后指在国外。
- **同根词**：broad（**brād** 宽广 → 宽的）、breadth（**brād** 宽 + **-th** 名词后缀 = 宽度）、broaden（broad + **-en** 使… = 使变宽）。
- **前缀·后缀**：前缀 **a-**（例：away, asleep）；词根 **broad**（例：broadcast, broad）。
- **同义·反义**：同义 overseas（在海外）；反义 home（在国内）。
- **变形**：副词 → 无比较级（方向副词，不作比较）。

### 5. costume /ˈkɑstum/ n. 戏装；装扮用服装
- **词根·渊源**：拉丁 **consuetudo**（习惯）→ 意大利语 *costume*（风俗、服饰）→ 法语 *costume* → 英语 costume；本义“习俗所定之衣”，引申为戏装。
- **同根词**：custom（**con-** 共同 + **sue-** 习惯 = 共同习惯→习俗）、customary（custom + **-ary** …的 = 习惯的）、accustom（**ac-** 使 + custom 习惯 = 使习惯）。
- **前缀·后缀**：无前后缀（借词整体）。
- **同义·反义**：同义 outfit（服装）, dress（服装）；反义 无。
- **变形**：名词 → 复数：costumes；形容词派生 → costumed adj. 穿着戏装的。

### 6. opportunity /ˌɑpərˈtunəti/ n. 机会
- **词根·渊源**：拉丁 **opportunus**（顺风的、适时的）＝ **ob-** 朝向 + **portus** 港口 → 拉丁 *opportunitas* → 古法语 *opportunité* → 英语 opportunity；本义“顺风入港”，引申为良机。
- **同根词**：opportune（**op-** 朝向 + **port** 港口 + **-une** …的 = 顺风的→适时的）、importune（**im-** 不 + **port** 港口 = 无港口可入→强求）、port（**portus** 港口 → 港口）、portable（**port-** 携带 + **-able** 可…的 = 可携带的）。
- **前缀·后缀**：前缀 **op-/ob-**（例：oppose, obtain）；名词后缀 **-ity**（例：ability, activity）。
- **同义·反义**：同义 chance（机会）, occasion（时机）；反义 无。
- **变形**：名词 → 复数：opportunities；形容词派生 → opportune adj. 适时的；副词派生 → opportunely adv. 适时地。

### 7. acquire /əkˈwaɪər/ v. 获得；得到
- **词根·渊源**：拉丁 **acquirere**（获得）＝ **ad-** 向 + **quaerere** 寻求 → 古法语 *aquerre* → 英语 acquire；本义“寻求而得”，即获得。
- **同根词**：require（**re-** 再 + **quir-** 寻求 = 再寻求→需要）、inquire（**in-** 向内 + **quir-** 寻求 = 向内问→询问）、question（**quest-** 寻求 + **-ion** 名词后缀 = 寻求→问题）、conquer（**con-** 完全 + **quer-** 寻求 = 完全求得→征服）、acquisition（**ac-** 向 + **quisit-** 寻求 + **-ion** = 获得）。
- **前缀·后缀**：前缀 **ac-/ad-**（例：accept, admire）；词根 **quir-/quis-**（例：require, inquiry）。
- **同义·反义**：同义 obtain（获得）, gain（得到）；反义 lose（失去）, forfeit（丧失）。
- **变形**：动词 → 第三人称单数：acquires；过去式：acquired；过去分词：acquired；现在分词：acquiring；名词派生 → acquisition n. 获得；形容词派生 → acquired adj. 获得的。

### 8. sheet /ʃit/ n. 一张（通常指标准尺寸的纸）
- **词根·渊源**：古英语 *scēte*（布片、床单）→ 中古英语 *shete*；本义“展开的布片”，引申为纸张一张。
- **同根词**：sheet（本词）、shoot（同源，**skeut-** 射出→投射→伸展）。
- **前缀·后缀**：无前后缀（单纯词）。
- **同义·反义**：同义 leaf（纸页）, page（页）；反义 无。
- **变形**：名词 → 复数：sheets；形容词派生 → sheeted adj. 铺床单的。

### 9. conclusion /kənˈkluʒən/ n. 结束；结尾
- **词根·渊源**：拉丁 **concludere**（关闭、结束）＝ **con-** 完全 + **cludere** 关闭 → 拉丁 *conclusio* → 古法语 → 英语 conclusion；本义“完全关闭”，引申为结束、结论。
- **同根词**：conclude（**con-** 完全 + **clud-** 关闭 = 完全关闭→结束）、include（**in-** 向内 + **clud-** 关闭 = 关进去→包括）、exclude（**ex-** 向外 + **clud-** 关闭 = 关在外→排除）、close（**clos-** 关闭 → 关闭）、clause（**claus-** 关闭 + **-e** = 关闭的句子→从句）。
- **前缀·后缀**：前缀 **con-**（例：connect, contain）；名词后缀 **-sion**（例：decision, division）。
- **同义·反义**：同义 ending（结尾）, end（结束）；反义 beginning（开始）, opening（开端）。
- **变形**：名词 → 复数：conclusions；动词派生 → conclude v. 结束、推断；形容词派生 → conclusive adj. 决定性的。

### 10. poetry /ˈpoʊətri/ n. 诗歌
- **词根·渊源**：希腊 **poiein**（制作）→ 拉丁 **poeta**（诗人）→ 古法语 *poete* → 英语 poet + **-ry**；本义“制作出来的东西”，即诗作。
- **同根词**：poet（**poie-** 制作 + **-t** 人 = 制作者→诗人）、poem（**poie-** 制作 + **-m** 物 = 制作之物→诗）、poetic（poet + **-ic** …的 = 诗的）。
- **前缀·后缀**：名词后缀 **-ry**（例：bakery, jewelry）。
- **同义·反义**：同义 verse（韵文）, rhyme（韵诗）；反义 prose（散文）。
- **变形**：名词 → 不可数；形容词派生 → poetic adj. 诗的；副词派生 → poetically adv. 诗意地。

### 11. concerned /kənˈsərnd/ adj. 关切的；关注的
- **词根·渊源**：拉丁 **concernere**（混合、涉及）＝ **con-** 共同 + **cernere** 筛、分辨 → 法语 *concerner* → 英语 concern + **-ed**；本义“筛在一起→相关”，引申为关切。
- **同根词**：concern（**con-** 共同 + **cern-** 筛 = 筛在一起→涉及）、discern（**dis-** 分开 + **cern-** 筛 = 筛分开→辨别）、certain（**cert-** 确定 + **-ain** …的 = 确定的）、secret（**se-** 分开 + **cret-** 筛 = 筛出分开→秘密的）。
- **前缀·后缀**：前缀 **con-**（例：connect, confirm）；形容词后缀 **-ed**（例：interested, excited）。
- **同义·反义**：同义 worried（担心的）, caring（关心的）；反义 unconcerned（漠不关心的）, indifferent（冷淡的）。
- **变形**：形容词 → 比较级：more concerned；最高级：most concerned；名词派生 → concern n. 关心；副词派生 → concernedly adv. 关切地。

### 12. creative /kriˈeɪtɪv/ adj. 创造（性）的；创作的
- **词根·渊源**：拉丁 **creare**（创造）→ 拉丁 *creativus* → 英语 create + **-ive**；本义“有创造力的”。
- **同根词**：create（**cre-** 创造 + **-ate** 动词后缀 = 创造）、creation（**cre-** 创造 + **-ation** 名词后缀 = 创造）、creature（**cre-** 创造 + **-ure** 名词后缀 = 被造物→生物）、creator（**cre-** 创造 + **-or** 人 = 创造者）。
- **前缀·后缀**：形容词后缀 **-ive**（例：active, attractive）。
- **同义·反义**：同义 inventive（有创造力的）, imaginative（富有想象力的）；反义 uncreative（缺乏创造力的）, unimaginative（无想象力的）。
- **变形**：形容词 → 比较级：more creative；最高级：most creative；名词派生 → creativity n. 创造力；副词派生 → creatively adv. 创造性地。

### 13. pleasure /ˈplɛʒər/ n. 高兴；快乐
- **词根·渊源**：拉丁 **placere**（使高兴）→ 古法语 *plaisir* → 英语 pleasure；本义“使人愉悦之事”，即快乐。
- **同根词**：please（**plac-** 使高兴 + **-e** = 使高兴）、pleasant（**plac-** 使高兴 + **-ant** …的 = 令人愉快的）、pleasing（please + **-ing** …的 = 令人愉快的）、placate（**plac-** 使高兴 + **-ate** 动词后缀 = 安抚）。
- **前缀·后缀**：名词后缀 **-ure**（例：nature, culture）。
- **同义·反义**：同义 joy（快乐）, delight（高兴）；反义 pain（痛苦）, sorrow（悲伤）。
- **变形**：名词 → 复数：pleasures；形容词派生 → pleasant adj. 愉快的；副词派生 → pleasantly adv. 愉快地。

### 14. rosy /ˈroʊzi/ adj. 粉红色的
- **词根·渊源**：拉丁 **rosa**（玫瑰）→ 古英语 *rose* → 英语 rose + **-y**；本义“玫瑰色的”，引申为粉红色的。
- **同根词**：rose（**rosa** 玫瑰 → 玫瑰）、rosary（**ros-** 玫瑰 + **-ary** 名词后缀 = 玫瑰园→念珠）。
- **前缀·后缀**：形容词后缀 **-y**（例：rainy, sunny）。
- **同义·反义**：同义 pink（粉红色的）, rosy-colored（玫瑰色的）；反义 pale（苍白的）。
- **变形**：形容词 → 比较级：rosier；最高级：rosiest；名词派生 → rosiness n. 玫瑰色。

### 15. youth /juθ/ n. 年轻；青春
- **词根·渊源**：古英语 *geoguth*（青年时期）→ 中古英语 *youthe*；本义“年轻的状态”，即青春。
- **同根词**：young（**ju-** 年轻 + **-ng** = 年轻的）、youngster（young + **-ster** 人 = 年轻人）。
- **前缀·后缀**：名词后缀 **-th**（例：warmth, truth）。
- **同义·反义**：同义 adolescence（青春期）, young age（年轻）；反义 old age（老年）, adulthood（成年）。
- **变形**：名词 → 复数：youths（作“青春”义时不可数）；形容词派生 → youthful adj. 年轻的；副词派生 → youthfully adv. 年轻地。

### 16. worth /wərθ/ adj. 有……价值
- **词根·渊源**：古英语 *weorth*（价值、值得）→ 中古英语 *worth*；本义“有价值”，引申为值得。
- **同根词**：worthy（worth + **-y** …的 = 值得的）、worthless（worth + **-less** 无…的 = 无价值的）、worthwhile（worth + while 时间 = 值得花时间的）。
- **前缀·后缀**：无前后缀（单纯词）。
- **同义·反义**：同义 valuable（有价值的）, deserving（值得的）；反义 worthless（无价值的）。
- **变形**：形容词 → 无比较级（表价值，不作比较）；名词派生 → worth n. 价值；形容词派生 → worthy adj. 值得的。

### 17. Christmas /ˈkrɪsməs/ n. 圣诞节
- **词根·渊源**：古英语 *Cristes mæsse*（基督的弥撒）＝ **Christ** 基督 + **mass** 弥撒 → 中古英语 Christmas；本义“基督弥撒”，即圣诞节。
- **同根词**：Christ（**chrism-** 涂油 + **-t** = 受膏者→基督）、Christian（Christ + **-ian** 人 = 基督徒）、christen（Christ + **-en** 动词后缀 = 施洗命名）。
- **前缀·后缀**：无前后缀（复合词）。
- **同义·反义**：同义 Xmas（圣诞节）；反义 无。
- **变形**：名词 → 复数：Christmases；形容词派生 → Christmassy adj. 有圣诞气氛的。

### 18. eve /iv/ n. 前夜；前夕
- **词根·渊源**：古英语 *ǣfen*（傍晚）→ 中古英语 *eve*；本义“傍晚”，引申为节日的前夜。
- **同根词**：evening（**ǣfen** 傍晚 + **-ing** 名词后缀 = 傍晚）、eve（本词）。
- **前缀·后缀**：无前后缀（单纯词）。
- **同义·反义**：同义 evening（傍晚）, night before（前夜）；反义 无。
- **变形**：名词 → 复数：eves。

### 19. take the opportunity  v. 抓住机会
- **同义搭配**：seize the opportunity（抓住机会） / grasp the chance（抓住机会）
- **反义搭配**：miss the opportunity（错过机会）

### 20. be concerned about  v. 关心；担忧
- **同义搭配**：care about（关心） / worry about（担忧）
- **反义搭配**：be indifferent to（对……漠不关心）

### 21. be worth doing  v. 值得做
- **同义搭配**：be worthy of doing（值得做） / deserve doing（值得做）
- **反义搭配**：be unworthy of doing（不值得做）

### 22. on Christmas Eve  prep. 在圣诞前夜
- **同义搭配**：on the night before Christmas（在圣诞前夜）
- **反义搭配**：无

### 23. creative writing  n. 创意写作
- **同义搭配**：imaginative writing（富有想象力的写作）
- **反义搭配**：technical writing（技术写作）

## 三、本单元前缀 / 后缀小结

| 词缀 | 含义 | 本单元例词 | 扩展例词 |
|---|---|---|---|
| pro- | 向前；在前 | promote | progress, produce, protect, project |
| a- | 在……上；到…… | abroad | away, ahead, alive, asleep |
| -tion | 名词后缀，表行为/状态 | conclusion | action, education, information, attention |
| -ive | 形容词后缀，表有……性质的 | creative | active, attractive, effective, expensive |
| -ure | 名词后缀，表行为/结果 | pleasure | failure, pressure, mixture, exposure |
| -y | 形容词后缀，表有……特征的 | rosy | rainy, sunny, healthy, dirty |
| -th | 名词后缀，表状态/性质 | youth | truth, warmth, length, strength |
| -ous | 形容词后缀，表充满……的 |（本单元无直接例词，concerned为-ed后缀） | famous, dangerous, nervous, curious |
| -ed | 形容词后缀，表具有……的 | concerned | interested, excited, surprised, tired |
| -ty | 名词后缀，表性质/状态 | opportunity | ability, activity, safety, beauty |
| -er | 名词后缀，表人/物 |（本单元无直接例词） | teacher, worker, writer, singer |
| -ing | 名词/形容词后缀 | creative writing | reading, swimming, interesting, exciting |
