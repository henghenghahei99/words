## 二、逐词说文解字

### 1. description /dɪˈskrɪpʃn/ n. 描述，形容，说明；类型
- **词根·渊源**：拉丁 **scribere / script-**（写）→ 拉丁 *descriptio*（描写）→ 古法语 *description* → 英语；**de-** 向下 + script 写 = 写下来→描述、说明。
- **同根词**：describe（**de-** 向下 + scribe 写 = 写下来→描述）、script（script 写→写下的东西→脚本）、manuscript（**manu-** 手 + script 写 = 手写的→手稿）、subscribe（**sub-** 在下 + scribe 写 = 写在下面→订阅）、prescription（**pre-** 先 + script 写 + **-ion** 名词 = 预先写好的→处方）。
- **前缀·后缀**：前缀 **de-**（例：describe, decline）；后缀 **-tion**（例：action, nation）。
- **同义·反义**：同义 account, depiction；反义 无。
- **词性变化**：describe v. 描述；descriptive adj. 描写的。

### 2. describe /dɪˈskraɪb/ v. 描述；形容
- **词根·渊源**：拉丁 **scribere / script-**（写）→ 拉丁 *describere*（写下、描写）→ 中古英语 *descriven* → 英语；**de-** 向下 + scribe 写 = 写下来→描述。
- **同根词**：description（**de-** + script 写 + **-ion** 名词 = 描述）、script（script 写→脚本）、manuscript（**manu-** 手 + script 写 = 手稿）、subscribe（**sub-** 在下 + scribe 写 = 订阅）、prescribe（**pre-** 先 + scribe 写 = 预先写→开处方）。
- **前缀·后缀**：前缀 **de-**（例：decline, depart）；无后缀（动词原形）。
- **同义·反义**：同义 depict, portray；反义 无。
- **词性变化**：description n. 描述；descriptive adj. 描写的。

### 3. fisherman /ˈfɪʃəmən/ n. 渔民，钓鱼的人
- **词根·渊源**：古英语 **fisc**（鱼）+ **mann**（人）→ 古英语 *fiscere*（渔夫）→ 中古英语 *fisherman* → 英语；fish 鱼 + **-er** 从事者 + man 人 = 捕鱼的人→渔民。
- **同根词**：fish（fish 鱼→鱼）、fishing（fish + **-ing** 名词 = 钓鱼）、fishery（fish + **-ery** 场所 = 渔场）、fishy（fish + **-y** …的 = 鱼腥的→可疑的）。
- **前缀·后缀**：后缀 **-er**（例：worker, teacher）；复合词后缀 **-man**（例：policeman, postman）。
- **同义·反义**：同义 angler；反义 无。
- **词性变化**：fish n. 鱼；fishing n. 钓鱼。

### 4. net /nɛt/ n. 网
- **词根·渊源**：古英语 **net**（网）→ 中古英语 *net* → 英语；与古高地德语 *nezzi*、拉丁 *nassa*（鱼篓）同源，本义“编织的网”，引申为网络、网状物。
- **同根词**：network（net 网 + work 工作 = 网状系统→网络）、netting（net + **-ing** 名词 = 网织物）、internet（**inter-** 之间 + net 网 = 互联网）、netlike（net + **-like** 像…的 = 网状的）。
- **前缀·后缀**：无前后缀（单纯词）。
- **同义·反义**：同义 mesh, web；反义 无。
- **词性变化**：network n. 网络；netting n. 网织物。

### 5. although /ɔlˈðo/ conj. 虽然；尽管；即使
- **词根·渊源**：中古英语 **al**（完全）+ **thogh**（though 虽然）→ 中古英语 *al thogh* → 英语；al 全 + though 虽然 = 尽管如此→虽然。
- **同根词**：though（though 虽然→虽然）、all（al 全→全部）、also（al 全 + so 如此 = 完全如此→也）、almighty（al 全 + mighty 强大 = 全能的）。
- **前缀·后缀**：无前后缀（复合词）。
- **同义·反义**：同义 though, even though；反义 无。
- **词性变化**：though conj. 虽然。

### 6. fit /fɪt/ adj. 健壮的；健康的
- **词根·渊源**：中古英语 **fit**（合适的、匹配的），可能源自古英语 *fitt*（斗争、匹配），词源存疑；本义“适合的”，引申为“身体适合的→健壮的”。
- **同根词**：fitness（fit + **-ness** 名词 = 健康）、fitting（fit + **-ing** 形容词 = 合适的）、fitly（fit + **-ly** 副词 = 合适地）、misfit（**mis-** 坏 + fit 合适 = 不合适的人）。
- **前缀·后缀**：无前后缀（单纯词）。
- **同义·反义**：同义 healthy, strong；反义 unfit, unhealthy。
- **词性变化**：fitness n. 健康；fitting adj. 合适的。

### 7. cormorant /'kɔːmərənt/ n. 鸬鹚；贪婪的人
- **词根·渊源**：拉丁 **corvus marinus**（海鸦）→ 古法语 *cormoran* → 英语；corvus 鸦 + marinus 海的 = 海鸦→鸬鹚；因鸬鹚贪食，引申为“贪婪的人”。
- **同根词**：corvine（corv 鸦 + **-ine** …的 = 鸦科的）、marine（mar 海 + **-ine** …的 = 海的）、maritime（mar 海 + **-time** …的 = 海上的）、cormorant（corv 鸦 + mar 海 + **-ant** 名词 = 海鸦→鸬鹚）。
- **前缀·后缀**：后缀 **-ant**（例：servant, assistant）。
- **同义·反义**：同义 glutton；反义 无。
- **词性变化**：无。

### 8. dive /daɪv/ n. 下降，下潜；扑向，冲向
- **词根·渊源**：古英语 **dyfan**（浸入）→ 中古英语 *diven* → 英语；本义“浸入水中”，引申为“下潜、俯冲”。
- **同根词**：diver（dive + **-er** 人 = 潜水员）、diving（dive + **-ing** 名词 = 潜水）、dove（dive 的过去式→潜入）。
- **前缀·后缀**：无前后缀（单纯词）。
- **同义·反义**：同义 plunge, submerge；反义 surface, ascend。
- **词性变化**：diver n. 潜水员；diving n. 潜水。

### 9. ready /ˈredi/ adj. 准备好，准备完毕
- **词根·渊源**：古英语 **rǣde**（准备好的、骑乘的）→ 中古英语 *redy* → 英语；与 ride 同源，本义“备好马可出发的”，引申为“准备好的”。
- **同根词**：readily（ready + **-ly** 副词 = 乐意地）、readiness（ready + **-ness** 名词 = 准备就绪）、already（**al-** 全 + ready 准备好 = 已经）、unready（**un-** 不 + ready = 未准备的）。
- **前缀·后缀**：后缀 **-y**（例：happy, rainy）。
- **同义·反义**：同义 prepared, set；反义 unprepared, unready。
- **词性变化**：readily adv. 乐意地；readiness n. 准备就绪。

### 10. reach /ritʃ/ v. 伸手；到达；抵达
- **词根·渊源**：古英语 **rǣcan**（伸手、够到）→ 中古英语 *rechen* → 英语；本义“伸手够取”，引申为“到达、抵达”。
- **同根词**：reachable（reach + **-able** 可…的 = 可到达的）、unreachable（**un-** 不 + reachable = 不可到达的）、overreach（**over-** 过度 + reach 伸 = 伸得过远→过度）。
- **前缀·后缀**：无前后缀（单纯词）。
- **同义·反义**：同义 arrive, attain；反义 depart, leave。
- **词性变化**：reachable adj. 可到达的；unreachable adj. 不可到达的。

### 11. attract /ə'trækt/ v. 吸引；使喜爱
- **词根·渊源**：拉丁 **trahere / tract-**（拉、拖）→ 拉丁 *attrahere*（拉向）→ 英语；**ad-** 向 + tract 拉 = 拉向自己→吸引。
- **同根词**：attraction（**ad-** 向 + tract 拉 + **-ion** 名词 = 吸引）、attractive（**ad-** + tract 拉 + **-ive** …的 = 有吸引力的）、tractor（tract 拉 + **-or** 物 = 拖拉机）、extract（**ex-** 出 + tract 拉 = 拉出→提取）、contract（**con-** 一起 + tract 拉 = 拉到一起→合同）。
- **前缀·后缀**：前缀 **ad-**（例：advance, admire）；无后缀（动词原形）。
- **同义·反义**：同义 draw, appeal；反义 repel, distract。
- **词性变化**：attraction n. 吸引；attractive adj. 有吸引力的。

### 12. hang /hæŋ/ v. 悬挂;吊;垂下;垂落
- **词根·渊源**：古英语 **hangian**（悬挂）→ 中古英语 *hangen* → 英语；与古高地德语 *hāhan* 同源，本义“悬挂”，引申为“垂下、垂落”。
- **同根词**：hanger（hang + **-er** 物 = 挂钩）、hanging（hang + **-ing** 名词 = 悬挂）、overhang（**over-** 在上 + hang 挂 = 悬垂）、hangman（hang 绞 + man 人 = 刽子手）。
- **前缀·后缀**：无前后缀（单纯词）。
- **同义·反义**：同义 suspend, dangle；反义 drop, fall。
- **词性变化**：hanger n. 挂钩；hanging n. 悬挂。

### 13. post /poʊst/ v. 柱；杆；桩
- **词根·渊源**：拉丁 **postis**（柱子）→ 古英语 *post* → 英语；本义“柱子、杆”，引申为“张贴、邮寄”（因古代驿站立柱为标志）。
- **同根词**：poster（post 张贴 + **-er** 物 = 海报）、postage（post 邮寄 + **-age** 费用 = 邮费）、postal（post 邮寄 + **-al** …的 = 邮政的）、postcard（post 邮寄 + card 卡片 = 明信片）。
- **前缀·后缀**：无前后缀（单纯词）。
- **同义·反义**：同义 pole, pillar；反义 无。
- **词性变化**：poster n. 海报；postage n. 邮费。

### 14. require /rɪˈkwaɪr/ v. 需要；依靠；要求
- **词根·渊源**：拉丁 **quaerere / quaesit-**（寻求）→ 拉丁 *requirere*（再寻求）→ 古法语 *requerre* → 英语；**re-** 再 + quire 寻求 = 一再寻求→需要、要求。
- **同根词**：requirement（require + **-ment** 名词 = 要求）、request（**re-** 再 + quest 寻求 = 请求）、question（quest 寻求 + **-ion** 名词 = 问题）、inquire（**in-** 向内 + quire 寻求 = 询问）、acquire（**ad-** 向 + quire 寻求 = 获得）。
- **前缀·后缀**：前缀 **re-**（例：repeat, return）；无后缀（动词原形）。
- **同义·反义**：同义 need, demand；反义 无。
- **词性变化**：requirement n. 要求；request n. 请求。

### 15. practise /ˈpræktɪs/ v. 从事，执业；实施，实行；信奉
- **词根·渊源**：希腊 **praktikos**（实践的）→ 拉丁 *practicare* → 古法语 *practiser* → 英语；prakt 做 + **-ise** 动词 = 反复做→练习、从事。
- **同根词**：practice（pract 做 + **-ice** 名词 = 练习）、practical（pract 做 + **-ical** …的 = 实际的）、practically（practical + **-ly** 副词 = 实际上）、practitioner（pract 做 + **-itioner** 人 = 从业者）。
- **前缀·后缀**：后缀 **-ise**（例：realise, organise）。
- **同义·反义**：同义 exercise, perform；反义 neglect, ignore。
- **词性变化**：practice n. 练习；practical adj. 实际的。

### 16. tool /tul/ v. 用具；器具；工具
- **词根·渊源**：古英语 **tōl**（工具）→ 中古英语 *tool* → 英语；与古诺斯语 *tól* 同源，本义“工具、器具”，引申为“手段”。
- **同根词**：toolbox（tool 工具 + box 箱 = 工具箱）、toolkit（tool 工具 + kit 套件 = 工具包）、tooling（tool + **-ing** 名词 = 工具加工）。
- **前缀·后缀**：无前后缀（单纯词）。
- **同义·反义**：同义 instrument, implement；反义 无。
- **词性变化**：toolbox n. 工具箱；toolkit n. 工具包。

### 17. scissors /ˈsɪzəz/ n. 剪刀
- **词根·渊源**：拉丁 **caedere / cis-**（切）→ 古法语 *cisoires*（剪刀）→ 中古英语 *sisoures* → 英语；cis 切 + **-ors** 物 = 切割之物→剪刀。
- **同根词**：scissor（scissors 单数化→剪）、scissile（sciss 切 + **-ile** 可…的 = 可切割的）、decide（**de-** 离 + cide 切 = 切离→决定）、precise（**pre-** 先 + cise 切 = 预先切好的→精确的）、incision（**in-** 入 + cis 切 + **-ion** 名词 = 切口）。
- **前缀·后缀**：后缀 **-ors**（例：scissors 本身）；无前缀。
- **同义·反义**：同义 shears；反义 无。
- **词性变化**：scissor v. 剪。

### 18. pattern /ˈpætərn/ n. 图案；模式；形式；方式
- **词根·渊源**：拉丁 **patronus**（保护人、范本）→ 古法语 *patron*（范本）→ 中古英语 *patron* → 英语 *pattern*；patr 父 + **-on** 人 = 父亲般的范本→模式、图案。
- **同根词**：patron（patr 父 + **-on** 人 = 保护人）、patronage（patron + **-age** 名词 = 赞助）、paternal（pater 父 + **-al** …的 = 父亲的）、patriot（patr 父 + **-iot** 人 = 爱国者）。
- **前缀·后缀**：后缀 **-ern**（例：pattern 本身；eastern, western）。
- **同义·反义**：同义 design, model；反义 无。
- **词性变化**：patterned adj. 有图案的。

### 19. character /ˈkærəktɚ/ n. 人物；角色；文字；符号
- **词根·渊源**：希腊 **kharaktēr**（刻痕、印记）→ 拉丁 *character*（烙印、特征）→ 古法语 *caractere* → 英语；本义“刻下的记号”，引申为“文字符号”，再由“特征、性格”引申为文学中的“人物、角色”。
- **同根词**：characteristic（character 特征 + **-istic** …的：特有的）、characterize（character + **-ize** 使…化：描绘…的特征）、uncharacteristic（**un-** 不 + characteristic 特有的：不典型的）。
- **前缀·后缀**：名词后缀 **-er**（例：teacher, worker）；后缀 **-istic**（例：realistic, artistic）。
- **同义·反义**：同义 figure, role, letter, symbol；反义 无。
- **词性变化**：characteristic adj. 特有的；characterize v. 描绘…的特征；characterless adj. 无特征的。

### 20. health /helθ/ n. 健康(状况)
- **词根·渊源**：古英语 **hāl**（完整的、健全的）→ *hælth*（健全状态）→ 中古英语 *helthe* → 英语；本义“完整无损的状态”，引申为“身体健康”。
- **同根词**：healthy（health + **-y** …的：健康的）、healthful（health + **-ful** 充满…的：有益健康的）、heal（古英语 hælan 使完整→治愈）、whole（与 hāl 同源：完整的）。
- **前缀·后缀**：名词后缀 **-th**（例：warmth, length）；形容词后缀 **-y**（例：rainy, windy）、**-ful**（例：helpful, useful）。
- **同义·反义**：同义 well-being, fitness；反义 illness, sickness。
- **词性变化**：healthy adj. 健康的；healthful adj. 有益健康的；unhealthy adj. 不健康的。

### 21. luck /lʌk/ n. 运气；幸运
- **词根·渊源**：中古荷兰语 **luc**（好运）→ 中古低地德语 *luk* → 英语；可能源自中古荷兰语 *gheluc*（好运），词源存疑；本义“好运”，后泛指“运气”。
- **同根词**：lucky（luck + **-y** …的：幸运的）、luckily（lucky + **-ly** …地：幸运地）、unlucky（**un-** 不 + lucky 幸运的：不幸的）。
- **前缀·后缀**：形容词后缀 **-y**（例：cloudy, sunny）；副词后缀 **-ly**（例：quickly, happily）；否定前缀 **un-**（例：unhappy, unfair）。
- **同义·反义**：同义 fortune, chance；反义 misfortune, bad luck。
- **词性变化**：lucky adj. 幸运的；luckily adv. 幸运地；unlucky adj. 不幸的。

### 22. wedding /ˈwedɪŋ/ n. 婚礼；结婚庆典
- **词根·渊源**：古英语 **weddian**（许诺、结婚）→ 中古英语 *wedding* → 英语；本义“立誓、许诺”，因婚礼核心是立誓，引申为“婚礼”。
- **同根词**：wed（古英语 weddian 立誓→结婚）、wedded（wed + **-ed** …的：已婚的）、wedlock（wed 誓约 + **-lock** 状态：婚姻）。
- **前缀·后缀**：名词后缀 **-ing**（例：meeting, building）；后缀 **-ed**（例：married, learned）。
- **同义·反义**：同义 marriage ceremony, nuptials；反义 divorce。
- **词性变化**：wed v. 结婚；wedded adj. 已婚的。

### 23. dough /doʊ/ n. 生面团
- **词根·渊源**：古英语 **dāg**（面团）→ 中古英语 *dough* → 英语；与德语 *Teig* 同源，本义“揉捏成团的东西”，即“生面团”。
- **同根词**：doughy（dough + **-y** …的：面团似的）、doughnut（dough 面团 + nut 坚果：油炸面圈→甜甜圈）。
- **前缀·后缀**：形容词后缀 **-y**（例：salty, sugary）；无前缀。
- **同义·反义**：同义 batter, paste；反义 无。
- **词性变化**：doughy adj. 面团似的；doughnut n. 甜甜圈。

### 24. rough /rʌf/ adj.（表面）粗糙的，不平的
- **词根·渊源**：古英语 **rūh**（粗糙的、多毛的）→ 中古英语 *rough* → 英语；本义“表面不平、多毛”，引申为“粗糙的、粗暴的”。
- **同根词**：roughly（rough + **-ly** …地：粗略地）、roughness（rough + **-ness** 性质：粗糙）、roughen（rough + **-en** 使…：使变粗糙）。
- **前缀·后缀**：副词后缀 **-ly**（例：badly, softly）；名词后缀 **-ness**（例：kindness, darkness）；动词后缀 **-en**（例：widen, strengthen）。
- **同义·反义**：同义 uneven, coarse；反义 smooth, even。
- **词性变化**：roughly adv. 粗略地；roughness n. 粗糙；roughen v. 使变粗糙。

### 25. size /saɪz/ n. 尺码；号；大小
- **词根·渊源**：古法语 **sise**（规定、尺寸）→ 中古英语 *size* → 英语；本义“规定的标准、量度”，引申为“大小、尺码”。
- **同根词**：sizable（size + **-able** 可…的：相当大的）、oversize（**over-** 超过 + size 尺寸：超大号的）、sized（size + **-ed** …的：有…尺寸的）。
- **前缀·后缀**：形容词后缀 **-able**（例：comfortable, readable）；前缀 **over-**（例：overweight, overwork）。
- **同义·反义**：同义 dimension, measure；反义 无。
- **词性变化**：sizable adj. 相当大的；oversize adj. 超大号的。

### 26. simple /ˈsɪmpl/ adj. 简单的，简易的
- **词根·渊源**：拉丁 **simplus**（单一的、不复杂的）→ 古法语 *simple* → 英语；本义“单一的”，引申为“简单的、朴素的”。
- **同根词**：simply（simple + **-ly** …地：简单地）、simplify（simple + **-ify** 使…化：简化）、simplicity（拉丁 simplicitas 单一→简单）。
- **前缀·后缀**：副词后缀 **-ly**（例：easily, gently）；动词后缀 **-ify**（例：beautify, classify）。
- **同义·反义**：同义 easy, plain；反义 complex, difficult。
- **词性变化**：simply adv. 简单地；simplify v. 简化；simplicity n. 简单。

### 27. lovely /ˈlʌvli/ adj. 可爱的，迷人的；有吸引力的
- **词根·渊源**：古英语 **luflic**（可爱的）→ 中古英语 *lovely* → 英语；由 love（爱）+ **-ly**（…的）构成，本义“值得爱的”，引申为“可爱的、迷人的”。
- **同根词**：love（古英语 lufu 爱）、loving（love + **-ing** …的：充满爱的）、beloved（**be-** 加强 + loved 被爱的：心爱的）。
- **前缀·后缀**：形容词后缀 **-ly**（例：friendly, kindly）；前缀 **be-**（例：belong, become）。
- **同义·反义**：同义 beautiful, charming；反义 ugly, unpleasant。
- **词性变化**：loveliness n. 可爱；love n./v. 爱；loving adj. 充满爱的。
