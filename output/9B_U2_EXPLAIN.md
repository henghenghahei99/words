## 二、逐词说文解字

### 1. exam /ɪgˈzæm/ n. 考试
- **词根·渊源**：拉丁 **examen**（天平之针、检验）→ 拉丁 *examinare*（称量、检验）→ 古法语 *examiner* → 英语 examination 的缩略形式 exam；本义“用天平称量以检验”，引申为“考试、检验”。
- **同根词**：examine（**ex-** 出 + **ag-** 驱动、称量 = 称量检验→检查）、examination（examine + **-ation** 名词后缀→考试、检查）、examiner（examine + **-er** 人→主考人）、cross-examine（cross 交叉 + examine 询问 = 交叉询问→盘问）。
- **前缀·后缀**：前缀 **ex-**（例：exit, export）；名词后缀 **-ation**（例：information, education）。
- **同义·反义**：同义 test（测验）, quiz（小测验）；反义 无。
- **变形**：名词 → 复数：exams；动词派生 → examine v. 检查、考试；名词派生 → examination n. 考试、检查；examiner n. 主考人。

### 2. aware /əˈwɛr/ adj. 知道，意识到
- **词根·渊源**：古英语 **gewær**（警觉的）→ 中古英语 *iwar, aware*；与 ward（看守）、wary（警惕的）同出 PIE *wer-*（注意、看守）；本义“警觉、留神”，引申为“知道、意识到”。
- **同根词**：awareness（aware + **-ness** 名词后缀→意识）、unaware（**un-** 不 + aware = 不知道的）、wary（古英语 wær 警觉的→谨慎的）、ward（古英语 weard 看守→保卫）、beware（**be-** 加强 + ware 警觉 = 当心）。
- **前缀·后缀**：前缀 **un-**（例：unhappy, unable）；名词后缀 **-ness**（例：kindness, happiness）。
- **同义·反义**：同义 conscious（意识到的）, mindful（留心的）；反义 unaware（不知道的）, ignorant（无知的）。
- **变形**：形容词 → 无比较级（表状态，通常不作比较）；名词派生 → awareness n. 意识；副词派生 → 无（常用 be aware of 结构）。

### 3. reduce /rɪˈdus/ v. 减少
- **词根·渊源**：拉丁 **reducere**（**re-** 回 + **ducere** 引导 = 引回）→ 中古英语 *reducen*；本义“带回、引回”，引申为“使变小、减少”。
- **同根词**：reduction（reduce + **-tion** 名词后缀→减少）、reducible（reduce + **-ible** 可…的→可减少的）、produce（**pro-** 向前 + duc 引导 = 引出→生产）、introduce（**intro-** 向内 + duc 引导 = 引入→介绍）、conduct（**con-** 共同 + duct 引导 = 共同引导→指挥）、educate（**e-** 出 + duc 引导 = 引出才能→教育）。
- **前缀·后缀**：前缀 **re-**（例：return, review）、**pro-**（例：progress）、**con-**（例：connect）；后缀 **-tion**（例：action, station）。
- **同义·反义**：同义 decrease（减少）, lessen（减少）；反义 increase（增加）, raise（提高）。
- **变形**：动词 → 第三人称单数：reduces；过去式：reduced；过去分词：reduced；现在分词：reducing；名词派生 → reduction n. 减少；形容词派生 → reducible adj. 可减少的。

### 4. goal /goʊl/ n. 目标
- **词根·渊源**：中古英语 **gol**（边界、界限）→ 英语 goal；本义“界限、终点标记”，引申为“赛跑终点→球门→目标”。词源存疑（一说与古英语 gāl 障碍有关）。
- **同根词**：goalkeeper（goal 球门 + keeper 守门员 = 守门员）、goalie（goal + **-ie** 昵称后缀→守门员）、goalless（goal + **-less** 无…的→无进球的）。
- **前缀·后缀**：后缀 **-keeper**（例：shopkeeper, housekeeper）、**-less**（例：hopeless, careless）。
- **同义·反义**：同义 aim（目标）, target（目标）；反义 无。
- **变形**：名词 → 复数：goals；形容词派生 → goalless adj. 无进球的；名词派生 → goalkeeper n. 守门员。

### 5. lemon /ˈlɛmən/ n. 柠檬
- **词根·渊源**：阿拉伯语 **laymūn**（柠檬）→ 古法语 *limon* → 中古英语 *lymon*；本义即“柠檬（树/果）”，词源可追溯至波斯语 līmū。
- **同根词**：lemonade（lemon + **-ade** 饮料后缀→柠檬水）、lemony（lemon + **-y** …味的→柠檬味的）、lemonade stand（lemonade + stand 摊位 = 柠檬水摊）。
- **前缀·后缀**：后缀 **-ade**（例：orangeade, parade）、**-y**（例：rainy, salty）。
- **同义·反义**：同义 无（具体水果名，无常用同义词）；反义 无。
- **变形**：名词 → 复数：lemons；形容词派生 → lemony adj. 柠檬味的；名词派生 → lemonade n. 柠檬水。

### 6. jogging /ˈʤɔgɪŋ/ n. 慢跑；慢步长跑
- **词根·渊源**：中古英语 **joggen**（轻推、颠动）→ 英语 jog（慢跑）+ **-ing** 名词后缀；本义“颠动、轻摇”，引申为“慢而稳地跑”。
- **同根词**：jog（joggen 轻推→慢跑）、jogger（jog + **-er** 人→慢跑者）、jogged（jog + **-ed** 过去式→慢跑了）。
- **前缀·后缀**：后缀 **-ing**（例：running, swimming）、**-er**（例：runner, swimmer）。
- **同义·反义**：同义 running（跑步）, trotting（小跑）；反义 sprinting（冲刺）。
- **变形**：名词 → 不可数（作运动名）；动词派生 → jog v. 慢跑；名词派生 → jogger n. 慢跑者。

### 7. quarter /kˈwɔrtər/ n. 15 分钟；一刻钟
- **词根·渊源**：拉丁 **quartus**（第四）→ 拉丁 *quartarius*（四分之一）→ 古法语 *quartier* → 英语 quarter；本义“四分之一”，引申为“一刻钟（一小时的 1/4）”。
- **同根词**：quarterly（quarter + **-ly** 每…的→每季度的）、quart（拉丁 quartus 第四→四分之一加仑）、quartet（意大利 quarto 四 + **-et** 小→四重奏）、four（PIE *kwetwer- 四→四）。
- **前缀·后缀**：后缀 **-ly**（例：monthly, yearly）、**-et**（例：packet, pocket）。
- **同义·反义**：同义 fifteen minutes（十五分钟）；反义 无。
- **变形**：名词 → 复数：quarters；形容词派生 → quarterly adj. 每季度的；副词派生 → quarterly adv. 每季度地。

### 8. keyboard /ˈkiˌbɔrd/ n. 键盘式电子乐器
- **词根·渊源**：**key**（键）+ **board**（板）复合而成；key 源自古英语 cǣg（钥匙），board 源自古英语 bord（板）；本义“带键的板”，引申为“键盘→键盘式电子乐器”。
- **同根词**：key（古英语 cǣg 钥匙→键）、board（古英语 bord 板→板）、keyboardist（keyboard + **-ist** 人→键盘手）、keyhole（key + hole 孔 = 钥匙孔）。
- **前缀·后缀**：后缀 **-ist**（例：pianist, artist）；复合词无前后缀（key + board）。
- **同义·反义**：同义 electronic keyboard（电子键盘）；反义 无。
- **变形**：名词 → 复数：keyboards；名词派生 → keyboardist n. 键盘手。

### 9. band /bænd/ n. 流行音乐乐队
- **词根·渊源**：古法语 **bande**（一队人、带子）→ 中古英语 *bande*；本义“带子、一群人”，引申为“乐队”。词源存疑（一说与哥特语 bandwa 旗帜有关）。
- **同根词**：bandage（band 带子 + **-age** 名词后缀→绷带）、bandwidth（band 带 + width 宽度 = 带宽）、husband（古诺斯 hús 房屋 + bóndi 住户 = 一家之主→丈夫）。
- **前缀·后缀**：后缀 **-age**（例：package, marriage）。
- **同义·反义**：同义 group（乐队、团体）, ensemble（乐团）；反义 无。
- **变形**：名词 → 复数：bands；名词派生 → bandage n. 绷带。

### 10. chat /ʧæt/ v. 闲谈；聊天
- **词根·渊源**：中古英语 **chatten**（闲谈）→ 英语 chat；本义“闲聊”，与 chatter（喋喋不休）同源，拟声词，模拟说话声。
- **同根词**：chatter（chat + **-er** 反复后缀→喋喋不休）、chatty（chat + **-y** …的→爱闲聊的）、chatroom（chat + room 房间 = 聊天室）。
- **前缀·后缀**：后缀 **-er**（例：waver, mutter）、**-y**（例：rainy, noisy）。
- **同义·反义**：同义 talk（交谈）, gossip（闲聊）；反义 无。
- **变形**：动词 → 第三人称单数：chats；过去式：chatted；过去分词：chatted；现在分词：chatting；名词派生 → chatter n. 喋喋不休；形容词派生 → chatty adj. 爱闲聊的。

### 11. stomach /ˈstəmək/ n. 胃；腹部
- **词根·渊源**：希腊 **stomachos**（食道、胃）→ 拉丁 *stomachus* → 古法语 *estomac* → 英语 stomach；本义“胃”，引申为“腹部”。
- **同根词**：stomachache（stomach + ache 痛 = 胃痛）、stomachic（stomach + **-ic** …的→健胃的）、stomachful（stomach + **-ful** 满→一胃之量）。
- **前缀·后缀**：后缀 **-ache**（例：headache, toothache）、**-ic**（例：basic, magic）。
- **同义·反义**：同义 belly（腹部）, abdomen（腹部）；反义 无。
- **变形**：名词 → 复数：stomachs；形容词派生 → stomachic adj. 健胃的；名词派生 → stomachache n. 胃痛。

### 12. headache /ˈhɛˌdeɪk/ n. 头痛
- **词根·渊源**：**head**（头）+ **ache**（痛）复合；head 源自古英语 hēafod（头），ache 源自古英语 acan（疼痛）；本义“头痛”，引申为“令人头痛的事”。
- **同根词**：head（古英语 hēafod 头→头）、ache（古英语 acan 痛→疼痛）、toothache（tooth 牙 + ache 痛 = 牙痛）、stomachache（stomach 胃 + ache 痛 = 胃痛）、headline（head + line 行 = 标题）。
- **前缀·后缀**：后缀 **-ache**（例：toothache, backache）；复合词无前后缀（head + ache）。
- **同义·反义**：同义 无（具体病症名，无常用同义词）；反义 无。
- **变形**：名词 → 复数：headaches；形容词派生 → headachy adj. 头痛的。

### 13. upright /ˈəˌpraɪt/ adv. 竖立着；垂直着
- **词根·渊源**：**up**（向上）+ **right**（直的）复合；up 源自古英语 up（向上），right 源自古英语 riht（直的）；本义“直向上”，引申为“竖立着、垂直着”。
- **同根词**：up（古英语 up 向上→向上）、right（古英语 riht 直的→直的）、rightly（right + **-ly** 副词后缀→正确地）、uprightness（upright + **-ness** 名词后缀→正直）。
- **前缀·后缀**：后缀 **-ly**（例：quickly, badly）、**-ness**（例：kindness, darkness）；复合词无前后缀（up + right）。
- **同义·反义**：同义 vertically（垂直地）, erectly（竖立地）；反义 horizontally（水平地）。
- **变形**：副词 → 无比较级（表状态，通常不作比较）；形容词派生 → upright adj. 竖立的、正直的；名词派生 → uprightness n. 正直。

### 14. merry /ˈmɛri/ adj. 愉快的，高兴的
- **词根·渊源**：古英语 **myrige**（愉快的）→ 中古英语 *merie* → 英语 merry；本义“令人愉快的、高兴的”，与古高地德语 murg（短）可能有关，词源存疑。
- **同根词**：merrily（merry + **-ly** 副词后缀→愉快地）、merriment（merry + **-ment** 名词后缀→欢乐）、merry-go-round（merry + go + round 旋转 = 旋转木马）。
- **前缀·后缀**：后缀 **-ly**（例：happily, sadly）、**-ment**（例：enjoyment, movement）。
- **同义·反义**：同义 happy（高兴的）, cheerful（愉快的）；反义 sad（悲伤的）, gloomy（忧郁的）。
- **变形**：形容词 → 比较级：merrier；最高级：merriest；副词派生 → merrily adv. 愉快地；名词派生 → merriment n. 欢乐。

### 15. stare /stɛr/ v. 盯着看；凝视
- **词根·渊源**：古英语 **starian**（凝视）→ 中古英语 *staren* → 英语 stare；本义“长时间盯着看”，与 star（星）可能有关（瞪眼如星），词源存疑。
- **同根词**：staring（stare + **-ing** 分词→凝视的）、starer（stare + **-er** 人→凝视者）、starry（star + **-y** …的→多星的）。
- **前缀·后缀**：后缀 **-ing**（例：looking, walking）、**-er**（例：worker, teacher）。
- **同义·反义**：同义 gaze（凝视）, gape（目瞪口呆地看）；反义 glance（瞥一眼）。
- **变形**：动词 → 第三人称单数：stares；过去式：stared；过去分词：stared；现在分词：staring；名词派生 → starer n. 凝视者；形容词派生 → staring adj. 凝视的。

### 16. strike /straɪk/ v. 撞击，碰撞
- **词根·渊源**：古英语 **strican**（抚摸、移动、打击）→ 中古英语 *striken* → 英语 strike；本义“滑动、抚摸”，引申为“打击、撞击”。
- **同根词**：striker（strike + **-er** 人→打击者）、striking（strike + **-ing** …的→显著的）、stroke（古英语 strac 打击→一击、中风）。
- **前缀·后缀**：后缀 **-er**（例：worker, player）、**-ing**（例：interesting, exciting）。
- **同义·反义**：同义 hit（打击）, knock（敲击）；反义 无。
- **变形**：动词 → 第三人称单数：strikes；过去式：struck；过去分词：struck；现在分词：striking；名词派生 → striker n. 打击者；形容词派生 → striking adj. 显著的。

### 17. mild /maɪld/ adj. 和善的，随和的
- **词根·渊源**：古英语 **milde**（温和的、宽厚的）→ 中古英语 *milde* → 英语 mild；本义“温和的”，与古诺斯语 mildr 同源，引申为“和善的、随和的”。
- **同根词**：mildly（mild + **-ly** 副词后缀→温和地）、mildness（mild + **-ness** 名词后缀→温和）、mildew（古英语 mildeaw 蜜露→霉，词源另说）。
- **前缀·后缀**：后缀 **-ly**（例：kindly, softly）、**-ness**（例：kindness, softness）。
- **同义·反义**：同义 gentle（温和的）, kind（和善的）；反义 harsh（严厉的）, severe（严厉的）。
- **变形**：形容词 → 比较级：milder；最高级：mildest；副词派生 → mildly adv. 温和地；名词派生 → mildness n. 温和。

| re- | 前缀，表“回；再” | reduce | return, review, rebuild, recall |
| -ing | 名词后缀，表活动/动作 | jogging | swimming, running, shopping, reading |
| -er | 名词后缀，表“物/人” | quarter | teacher, worker, computer, player |
| key- | 复合词首部，表“键” | keyboard | keyhole, keynote, keystroke |
| -board | 复合词尾部，表“板” | keyboard | blackboard, cupboard, skateboard |
