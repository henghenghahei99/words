## 二、逐词说文解字

### 1. culture shock /ˈkʌltʃərəl ʃɑːk/ n. 文化冲击；文化休克
- **同义搭配**：cultural conflict（文化冲突） / cultural disorientation（文化迷失）
- **反义搭配**：cultural adaptation（文化适应）

### 2. camp /kæmp/ n. 度假营
- **词根·渊源**：拉丁 **campus**（田野、平地）→ 意大利语 *campo*（营地）→ 法语 *camp* → 英语 camp，本义“野外平地”，引申为“驻扎之地→营地→度假营”。
- **同根词**：campus（camp 的拉丁原形 campus 直接借入英语 = 校园）、campaign（camp + **-aign** 原义“在田野上作战”→战役→运动）、champion（拉丁 campio 战场上的斗士→冠军）、decamp（**de-** 离开 + camp 营地 = 拔营→逃走）。
- **前缀·后缀**：无前后缀（单纯词）。
- **同义·反义**：同义 campsite（营地）, encampment（营地）；反义 无。
- **变形**：名词 → 复数：camps；动词派生 → camp v. 露营；名词派生 → camper n. 露营者；camping n. 露营。

### 3. firework /ˈfaɪərwɜ:rk/ n. 烟花；烟火
- **词根·渊源**：古英语 **fȳr**（火）+ **weorc**（工作、制品）→ 中古英语 *firework*，本义“用火做出来的东西”，即“烟火制品→烟花”。
- **同根词**：fireman（fire 火 + man 人 = 救火的人→消防员）、fireplace（fire 火 + place 地方 = 生火的地方→壁炉）、fireproof（fire 火 + proof 防…的 = 防火的）、workman（work 工作 + man 人 = 工人）、homework（home 家 + work 工作 = 在家做的功课→家庭作业）。
- **前缀·后缀**：无前缀；复合词由 fire + work 构成（例：fireman, homework）。
- **同义·反义**：同义 firecracker（鞭炮）, pyrotechnic（烟火的）；反义 无。
- **变形**：名词 → 复数：fireworks（作“烟花表演”时常用复数）；形容词派生 → firework adj. 烟花的（作定语）。

### 4. turkey /ˈtɜːki/ n. 火鸡；火鸡肉
- **词根·渊源**：源自 **Turkey**（土耳其）。16 世纪这种鸟经土耳其传入欧洲，英语误以为产自土耳其，故称 turkey；后专指“火鸡”。（词源存疑：一说原指珍珠鸡，后转指火鸡。）
- **同根词**：Turkey（国名土耳其，turkey 的直接来源）、Turkish（Turk 土耳其人 + **-ish** …的 = 土耳其的）。
- **前缀·后缀**：无前后缀（单纯词）。
- **同义·反义**：同义 无；反义 无。
- **变形**：名词 → 复数：turkeys；形容词派生 → turkey adj. 火鸡的（作定语）。

### 5. international /ˌɪntərˈnæʃnəl/ adj. 国际的；世界的
- **词根·渊源**：拉丁 **inter-**（在…之间）+ **natio / nation-**（出生、民族）→ 法语 *international* → 英语，本义“存在于民族之间的”，即“国际的”。
- **同根词**：nation（nat 出生 + **-ion** 名词后缀 = 出生在同一地方的人→民族、国家）、national（nation + **-al** …的 = 国家的）、native（nat 出生 + **-ive** …的 = 出生的→本地的）、nature（nat 出生 + **-ure** 名词后缀 = 天生之物→自然）、interact（**inter-** 相互 + act 行动 = 相互作用）、intercity（**inter-** 之间 + city 城市 = 城市间的）。
- **前缀·后缀**：前缀 **inter-**（例：interact, intercity）；形容词后缀 **-al**（例：national, natural）。
- **同义·反义**：同义 global（全球的）, worldwide（全世界的）；反义 national（国内的）, domestic（本国的）。
- **变形**：形容词 → 无比较级（关系形容词，不作比较）；副词派生 → internationally adv. 国际地；名词派生 → internationalism n. 国际主义。

### 6. admit /ədˈmɪt/ v. (常指勉强)承认
- **词根·渊源**：拉丁 **ad-**（向）+ **mittere**（送、放）→ 拉丁 *admittere*“送进去、允许进入”→ 古法语 *admettre* → 英语 admit，本义“让进入→接纳→承认（把事实放进来）”。
- **同根词**：admission（ad + miss 送 + **-ion** 名词后缀 = 送入→准许进入→承认）、mission（miss 送 + **-ion** = 送出去的事→使命）、submit（**sub-** 向下 + mit 送 = 向下送→提交→屈服）、permit（**per-** 通过 + mit 送 = 让通过→允许）、transmit（**trans-** 横过 + mit 送 = 传送）、commit（**com-** 共同 + mit 送 = 一起送出→委托→犯（罪））。
- **前缀·后缀**：前缀 **ad-**（例：advance, addition）；词根 mit 见上。
- **同义·反义**：同义 acknowledge（承认）, confess（坦白）；反义 deny（否认）, refuse（拒绝）。
- **变形**：动词 → 第三人称单数：admits；过去式：admitted；过去分词：admitted；现在分词：admitting；名词派生 → admission n. 准许进入、承认；admittance n. 进入权。

### 7. spare /spɛr/ adj. 空闲的；空余的；备用的
- **词根·渊源**：古英语 **sparian**（节省、不伤害）→ 中古英语 *spare*，本义“节省下来的、留着不用的”，引申为“空闲的、备用的”。
- **同根词**：sparing（spare + **-ing** …的 = 节省的）、sparely（spare + **-ly** 副词后缀 = 节省地）。
- **前缀·后缀**：无前缀；形容词后缀 **-ing**（例：interesting）、副词后缀 **-ly**（例：bravely）。
- **同义·反义**：同义 free（空闲的）, extra（额外的）；反义 busy（忙的）, occupied（被占用的）。
- **变形**：形容词 → 比较级：sparer；最高级：sparest；动词派生 → spare v. 节省、抽出（时间）；副词派生 → sparely adv. 节省地。

### 8. degree /dɪˈɡri/ n.（大学）学位；程度；度，度数
- **词根·渊源**：拉丁 **de-**（向下）+ **gradus**（步、级）→ 古法语 *degre* → 英语 degree，本义“下降的一级→等级→程度→（学位的）等级→学位”。
- **同根词**：grade（grad 步、级 = 等级、年级）、gradual（grad 级 + **-ual** …的 = 一步一步的→逐渐的）、graduate（grad 级 + **-uate** 动词后缀 = 走完各级→毕业）、upgrade（**up-** 向上 + grade 级 = 升级）、degrade（**de-** 向下 + grade 级 = 降级→贬低）。
- **前缀·后缀**：前缀 **de-**（例：degrade, decline）；无后缀（借词原形）。
- **同义·反义**：同义 level（水平）, extent（程度）；反义 无。
- **变形**：名词 → 复数：degrees。

### 9. fail /feɪl/ v. 失败;未能(做到)
- **词根·渊源**：拉丁 **fallere**（欺骗、使失望）→ 古法语 *faillir*（缺乏、失误）→ 英语 fail，本义“使失望、欠缺”，引申为“失败、未能做到”。
- **同根词**：failure（fail + **-ure** 名词后缀 = 失败）、failing（fail + **-ing** 名词/形容词后缀 = 缺点、衰退的）、fallible（拉丁 fall 欺骗 + **-ible** 可…的 = 可能出错的）、infallible（**in-** 不 + fallible = 不会出错的）。
- **前缀·后缀**：无前缀；名词后缀 **-ure**（例：failure, pleasure）。
- **同义·反义**：同义 flop（失败）, miss（未击中）；反义 succeed（成功）, manage（设法做到）。
- **变形**：动词 → 第三人称单数：fails；过去式：failed；过去分词：failed；现在分词：failing；名词派生 → failure n. 失败。

### 10. manage /ˈmænɪdʒ/ v. 完成（困难的事）；应付（困难局面）
- **词根·渊源**：意大利语 **maneggiare**（驯马、用手操控）← 拉丁 **manus**（手）→ 法语 *manège* → 英语 manage，本义“用手驾驭马”，引申为“操控→管理→设法完成”。
- **同根词**：manager（manage + **-er** 人 = 管理者）、management（manage + **-ment** 名词后缀 = 管理）、manual（manu 手 + **-al** …的 = 手的→手册）、manufacture（manu 手 + fact 做 + **-ure** = 用手做→制造）、manuscript（manu 手 + script 写 = 手写的→手稿）。
- **前缀·后缀**：无前缀；名词后缀 **-ment**（例：movement, development）。
- **同义·反义**：同义 handle（应付）, cope（应对）；反义 fail（失败）, mismanage（管理不善）。
- **变形**：动词 → 第三人称单数：manages；过去式：managed；过去分词：managed；现在分词：managing；名词派生 → manager n. 经理；management n. 管理。

### 11. idiom /ˈɪdiəm/ n. 习语；惯用语
- **词根·渊源**：希腊 **idios**（自己的、特有的）→ 希腊 *idiōma*（特殊表达）→ 拉丁 *idioma* → 法语 → 英语 idiom，本义“某语言特有的说法”，即“习语”。
- **同根词**：idiot（希腊 idiōtēs 平民、外行→白痴）、idiomatic（idiom + **-atic** …的 = 习语性的）、idiosyncrasy（idio 自己 + syn 共同 + crasis 混合 = 个人特有的气质→癖好）。
- **前缀·后缀**：无前缀；形容词后缀 **-atic**（例：idiomatic, dramatic）。
- **同义·反义**：同义 expression（表达方式）, phrase（短语）；反义 无。
- **变形**：名词 → 复数：idioms；形容词派生 → idiomatic adj. 习语性的；副词派生 → idiomatically adv. 按习语地。

### 12. everyday /ˈɛvriˈde/ adj. 每天的；日常的
- **词根·渊源**：古英语 **æfre ælc**（每一个）→ every + 古英语 **dæg**（日）→ 复合词 everyday，本义“每一天的”，引申为“日常的”。
- **同根词**：every（ever 永远 + each 每一 = 每一个）、everyone（every + one 一 = 每个人）、everything（every + thing 事物 = 每件事）、daily（day 日 + **-ly** …的 = 每日的）、daytime（day 日 + time 时间 = 白天）。
- **前缀·后缀**：无前缀；复合词由 every + day 构成（例：everyone, daytime）。
- **同义·反义**：同义 daily（每日的）, ordinary（普通的）；反义 unusual（不寻常的）, special（特别的）。
- **变形**：形容词 → 无比较级（关系形容词，不作比较）。

### 13. pink /pɪŋk/ adj. 粉色；粉色的
- **词根·渊源**：可能源自荷兰语 **pinck**（一种小花）或英语方言 pink（刺、戳），16 世纪指一种石竹花，因其颜色得名“粉色”。（词源存疑。）
- **同根词**：pinkish（pink + **-ish** 略…的 = 略带粉色的）、pinky（pink + **-y** …的 = 粉红的）。
- **前缀·后缀**：无前缀；形容词后缀 **-ish**（例：childish, reddish）。
- **同义·反义**：同义 rosy（玫瑰色的）, rose-colored（玫瑰色的）；反义 无。
- **变形**：形容词 → 比较级：pinker；最高级：pinkest；名词派生 → pink n. 粉色；pinkness n. 粉红。

### 14. purple /ˈpɜːpl/ adj. 紫色；紫色的
- **词根·渊源**：希腊 **porphyra**（一种产紫色染料的贝）→ 拉丁 *purpura* → 古英语 *purpure* → 英语 purple，本义“紫贝染出的颜色”，即“紫色”。
- **同根词**：purplish（purple + **-ish** 略…的 = 略带紫色的）、purplely（purple + **-ly** 副词后缀 = 呈紫色地）。
- **前缀·后缀**：无前缀；形容词后缀 **-ish**（例：greenish, bluish）。
- **同义·反义**：同义 violet（紫罗兰色的）, mauve（淡紫色的）；反义 无。
- **变形**：形容词 → 比较级：purpler；最高级：purplest；名词派生 → purple n. 紫色；purpleness n. 紫色。

### 15. anyway /ˈeniweɪ/ adv. 无论如何；而且；尽管，即使这样
- **词根·渊源**：古英语 **ænig**（任何）+ **weg**（路）→ any + way 复合，本义“以任何方式”，引申为“无论如何、而且”。
- **同根词**：any（ænig 任何 = 任何的）、anyone（any + one 人 = 任何人）、anything（any + thing 事物 = 任何事物）、anywhere（any + where 地方 = 任何地方）、way（weg 路 = 路、方式）、always（al 全 + way 路 + **-s** 副词后缀 = 一路总是→总是）。
- **前缀·后缀**：无前缀；复合词由 any + way 构成（例：anyone, always）。
- **同义·反义**：同义 anyhow（无论如何）, in any case（无论如何）；反义 无。
- **变形**：副词 → 无比较级（不作比较）。

### 16. especially /ɪˈspeʃəli/ adv. 尤其，特别；专门
- **词根·渊源**：拉丁 **species**（外观、种类）→ **specialis**（特定种类的）→ 古法语 *especial* → 英语 especial + **-ly**，本义“以特定方式”，引申为“尤其、专门”。
- **同根词**：special（spec 看 + **-ial** …的 = 看得出的→特别的）、species（spec 看 + **-ies** 名词后缀 = 外观→种类）、specify（spec 种类 + **-ify** 使… = 使具体→明确说明）、specific（spec 种类 + **-ific** …的 = 特定种类的→具体的）、spectacle（spect 看 + **-acle** 名词后缀 = 看的东西→景象）。
- **前缀·后缀**：无前缀；副词后缀 **-ly**（例：bravely, quickly）。
- **同义·反义**：同义 particularly（尤其）, specially（专门地）；反义 generally（一般地）, ordinarily（通常地）。
- **变形**：副词 → 无比较级（不作比较）；形容词派生 → especial adj. 特别的（较少用）。

### 17. baseball /ˈbeɪsbɔːl/ n. 棒球运动
- **词根·渊源**：**base**（垒、基地）+ **ball**（球）→ 美式英语复合词 baseball，本义“以垒为目标的球戏”，即“棒球运动”。
- **同根词**：base（希腊 basis 基础 = 垒、基地）、basic（base + **-ic** …的 = 基本的）、basement（base + **-ment** 名词后缀 = 底部→地下室）、football（foot 足 + ball 球 = 足球）、basketball（basket 篮 + ball 球 = 篮球）。
- **前缀·后缀**：无前缀；复合词由 base + ball 构成（例：football, basketball）。
- **同义·反义**：同义 无；反义 无。
- **变形**：名词 → 复数：baseballs（作“棒球运动”时不可数）；名词派生 → baseballer n. 棒球运动员。

### 18. educational /ˌedʒuˈkeɪʃənl/ adj. 有关教育的；有教育意义的
- **词根·渊源**：拉丁 **e-**（出）+ **ducere**（引导）→ *educare*“引导出来、培养”→ 英语 educate + **-ion** + **-al**，本义“引导培养的过程”，引申为“有关教育的、有教育意义的”。
- **同根词**：educate（e 出 + duc 引导 + **-ate** 动词后缀 = 引导出来→教育）、education（educate + **-ion** 名词后缀 = 教育）、educator（educate + **-or** 人 = 教育者）、conduct（**con-** 共同 + duct 引导 = 共同引导→指挥、行为）、introduce（**intro-** 向内 + duc 引导 = 引进去→介绍）、produce（**pro-** 向前 + duc 引导 = 向前引出→生产）。
- **前缀·后缀**：前缀 **e-**（例：educate, emit）；形容词后缀 **-al**（例：national, natural）。
- **同义·反义**：同义 instructive（有教育意义的）, academic（学术的）；反义 无。
- **变形**：形容词 → 无比较级（关系形容词，不作比较）；副词派生 → educationally adv. 教育上地；名词派生 → education n. 教育。

### 19. state /steɪt/ v. 国家；州；政府；状态
- **词根·渊源**：拉丁 **status**（站立的状态、地位）→ 古法语 *estat* → 英语 state；本义“站立的方式→状况”，引申为“政治共同体→国家、州”。
- **同根词**：station（stat 站 + **-ion** 名词后缀 = 站立之处→车站）、statue（stat 站 + **-ue** = 立像→雕像）、status（stat 站 + **-us** 拉丁名词后缀 = 站立的状态→地位）、statistics（stat 状态 + **-istics** 学科 = 研究国家状态的学问→统计学）、constant（**con-** 完全 + stant 站 = 始终站立→不变的）、establish（**e-** 出 + stabl 站 = 使站稳→建立）。
- **前缀·后缀**：无前后缀（单纯词，源自拉丁 status）。
- **同义·反义**：同义 condition（状况）, nation（国家）；反义 无。
- **变形**：动词 → 第三人称单数：states；过去式：stated；过去分词：stated；现在分词：stating；名词 → 复数：states；形容词派生 → stately adj. 庄严的；名词派生 → statement n. 陈述、声明。

### 20. national /ˈnæʃnəl/ adj. 国家的；名族的；全国的
- **词根·渊源**：拉丁 **natio / nation-**（出生、族群）→ 古法语 *nacion* → 英语 nation + **-al**；本义“同出生的人群→民族”，引申为“国家的、全国的”。
- **同根词**：nation（nat 出生 + **-ion** = 同出生的人群→民族、国家）、native（nat 出生 + **-ive** …的 = 出生地的→本地的）、nature（nat 出生 + **-ure** = 天生之物→自然）、international（**inter-** 之间 + national 国家的 = 国家之间的→国际的）、nationality（national + **-ity** 名词后缀 = 国民身份→国籍）。
- **前缀·后缀**：形容词后缀 **-al**（例：natural, personal）；前缀 **inter-**（例：international, interact）。
- **同义·反义**：同义 nationwide（全国的）, state（国家的）；反义 local（地方的）, international（国际的）。
- **变形**：形容词 → 比较级：more national；最高级：most national；名词派生 → nationality n. 国籍；副词派生 → nationally adv. 全国性地；动词派生 → nationalize v. 国有化。

### 21. president /ˈprezɪdənt/ n. 总统，国家主席
- **词根·渊源**：拉丁 **prae-**（在前）+ **sedere**（坐）→ 拉丁 *praesidere*（坐在前面→主持）→ 古法语 *president* → 英语 president；本义“坐在前面主持的人”，引申为“总统、主席”。
- **同根词**：preside（**pre-** 前 + sid 坐 + **-e** = 坐在前面→主持）、reside（**re-** 回 + sid 坐 = 坐下不走→居住）、resident（**re-** 回 + sid 坐 + **-ent** 人 = 坐下居住的人→居民）、session（sess 坐 + **-ion** = 坐在一起→会议）、sediment（sed 坐 + **-iment** = 沉坐下去的东西→沉淀物）。
- **前缀·后缀**：前缀 **pre-**（例：prepare, predict）；名词后缀 **-ent**（例：student, resident）。
- **同义·反义**：同义 chairman（主席）, head of state（国家元首）；反义 无。
- **变形**：名词 → 复数：presidents；名词派生 → presidency n. 总统职位；形容词派生 → presidential adj. 总统的。

### 22. vacation /veɪˈkeɪʃn/ n. 假期
- **词根·渊源**：拉丁 **vacare**（空着、空闲）→ 拉丁 *vacatio*（空闲）→ 古法语 *vacation* → 英语 vacation；本义“空闲不做事”，引申为“假期”。
- **同根词**：vacant（vac 空 + **-ant** …的 = 空着的→空缺的）、vacancy（vac 空 + **-ancy** 名词后缀 = 空的状态→空缺）、vacuum（vac 空 + **-uum** 拉丁名词后缀 = 空处→真空）、evacuate（**e-** 出 + vac 空 + **-ate** 动词后缀 = 使空出来→疏散）、vacate（vac 空 + **-ate** = 使空出→腾出）。
- **前缀·后缀**：名词后缀 **-ion**（例：action, station）；前缀 **e-**（例：evacuate, emit）。
- **同义·反义**：同义 holiday（假日）, break（休息）；反义 workday（工作日）, term（学期）。
- **变形**：名词 → 复数：vacations；动词派生 → vacation v. 度假；名词派生 → vacationer n. 度假者。

### 23. schedule /ˈʃedjuːl/ n. 工作计划；日程安排
- **词根·渊源**：希腊 **skhedē**（纸片、便条）→ 拉丁 *schedula*（小纸片）→ 古法语 *cedule* → 英语 schedule；本义“写有小字条的单子”，引申为“日程表、计划表”。
- **同根词**：schematic（schem 纸片上的图 + **-atic** …的 = 图式的→纲要的）、scheme（schem 纸片上的计划 = 方案→计划）、schedular（schedule + **-ar** …的 = 日程的→按表的）。
- **前缀·后缀**：名词后缀 **-ule**（例：schedule, capsule）。
- **同义·反义**：同义 timetable（时间表）, plan（计划）；反义 无。
- **变形**：名词 → 复数：schedules；动词派生 → schedule v. 安排、排定；第三人称单数：schedules；过去式：scheduled；过去分词：scheduled；现在分词：scheduling。

### 24. set off /set ɒf/ v. 使（炸弹等）爆炸
- **同义搭配**：explode（使爆炸） / blow up（炸毁）
- **反义搭配**：defuse（拆除引信）

### 25. take off /ˈteɪk ɒf/ v. 脱下；（飞机等）起飞；摘掉
- **同义搭配**：remove（脱下、摘掉） / depart（起飞、离开）
- **反义搭配**：put on（穿上） / land（降落）

### 26. in one's spare time /ɪn wʌnz sper taɪm/ prep. 在某人的空闲时间里
- **同义搭配**：in one's free time（在某人空闲时） / at leisure（闲暇时）
- **反义搭配**：at work（在工作时）

### 27. to a certain degree /tu ə ˈsɜːrtn dɪˈɡriː/ prep. 在某种程度上
- **同义搭配**：to some extent（在某种程度上） / in a sense（在某种意义上）
- **反义搭配**：not at all（完全不）

### 28. get used to /gɪt juzd tɪ/ v. 习惯于,适应
- **同义搭配**：be accustomed to（习惯于） / adapt to（适应）
- **反义搭配**：be unaccustomed to（不习惯于）

### 29. under the weather /'ʌndə ðə 'weðə/ prep. 略有不适；不得劲
- **同义搭配**：feel ill（感到不适） / be off color（身体不舒服）
- **反义搭配**：feel well（感觉良好）

### 30. uniform /ˈjuːnɪfɔːrm/ adj. 制服；校服
- **词根·渊源**：拉丁 **unus**（一）+ **forma**（形状）→ 拉丁 *uniformis*（同一形状的）→ 法语 *uniforme* → 英语 uniform；本义“形状统一的”，引申为“统一的服装→制服”。
- **同根词**：unify（**uni-** 一 + fy 使 = 使成为一体→统一）、union（**uni-** 一 + **-on** 名词后缀 = 结合为一体→联合）、unique（**uni-** 一 + **-que** = 唯一的→独特的）、uniformity（uniform + **-ity** 名词后缀 = 同一形状的状态→一致性）、reform（**re-** 再 + form 形状 = 再塑形状→改革）。
- **前缀·后缀**：前缀 **uni-**（例：unify, union）；词根 **form**（例：reform, inform）。
- **同义·反义**：同义 costume（服装）, outfit（套装）；反义 无。
- **变形**：形容词 → 无比较级（关系形容词，不作比较）；名词 → 复数：uniforms；形容词派生 → uniformed adj. 穿制服的；副词派生 → uniformly adv. 一致地。

### 31. whatever /wətˈevə(r)/ adj. 任何事物；一切事物
- **词根·渊源**：古英语 **hwæt**（什么）+ **efre**（曾经）→ 中古英语 *what ever* → 英语 whatever；本义“无论什么”，引申为“任何事物、一切事物”。
- **同根词**：what（hwæt 什么 = 什么）、whoever（who 谁 + **-ever** 无论 = 无论谁）、whenever（when 何时 + **-ever** 无论 = 无论何时）、wherever（where 何地 + **-ever** 无论 = 无论何地）、however（how 如何 + **-ever** 无论 = 无论如何）。
- **前缀·后缀**：后缀 **-ever**（例：whoever, whenever）。
- **同义·反义**：同义 anything（任何事物）, everything（一切事物）；反义 nothing（没有什么）。
- **变形**：形容词 → 无比较级（不定代词性形容词，不作比较）；代词派生 → whatever pron. 无论什么。
