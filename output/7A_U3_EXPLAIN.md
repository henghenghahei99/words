## 二、逐词说文解字

### 1. footprint /ˈfʊtˌprɪnt/ n. 脚印；足迹
- **词根·渊源**：古英语 **fōt**（脚）+ 古法语 *empreinte*（印记，源自拉丁 *imprimere* 压入）→ 英语 *footprint*，本义“脚留下的印痕”，引申为“足迹”。
- **同根词**：foot（**fōt** 脚：脚）、football（foot 脚 + ball 球 = 用脚踢的球→足球）、footer（foot + **-er** 表物 = 页脚）、print（*empreinte* 印记：印刷；印记）、imprint（**im-** 入 + print 压印 = 压入印记→印刻）。
- **前缀·后缀**：复合词无前后缀（foot + print 复合）；名词后缀 **-er**（例：teacher, worker）。
- **同义·反义**：同义 track（足迹）, trace（痕迹）；反义 无。
- **变形**：名词 → 复数：footprints；形容词派生 → footprinted adj. 有足迹的。

### 2. wet /wɛt/ adj. 潮湿的
- **词根·渊源**：古英语 **wǣt**（湿的）→ 中古英语 *wet* → 英语 wet；与 water 同出 PIE *wed-*（水）。
- **同根词**：water（**wed-** 水 + **-er** 表物 = 水）、wetter（wet + **-er** 表人/物 = 弄湿者）、wetness（wet + **-ness** 名词后缀 = 潮湿）、wetland（wet 湿 + land 地 = 湿地）。
- **前缀·后缀**：形容词后缀 **-ness**（例：happiness, darkness）；比较后缀 **-er**（例：warmer, faster）。
- **同义·反义**：同义 damp（潮湿的）, moist（湿润的）；反义 dry（干燥的）。
- **变形**：形容词 → 比较级：wetter；最高级：wettest；名词派生 → wetness n. 潮湿；动词派生 → wet v. 弄湿。

### 3. deep /dip/ adj. 深的
- **词根·渊源**：古英语 **dēop**（深的）→ 中古英语 *deep* → 英语 deep；与 dip 同出 PIE *dheub-*（深、凹）。
- **同根词**：deeply（deep + **-ly** 副词后缀 = 深深地）、deepen（deep + **-en** 动词后缀 = 加深）、depth（deep 的名词形式，源自古英语 *dēopþu* = 深度）、dip（**dheub-** 深/凹 → 浸入）。
- **前缀·后缀**：副词后缀 **-ly**（例：quickly, slowly）；动词后缀 **-en**（例：widen, strengthen）。
- **同义·反义**：同义 profound（深的）；反义 shallow（浅的）。
- **变形**：形容词 → 比较级：deeper；最高级：deepest；副词派生 → deeply adv. 深深地；名词派生 → depth n. 深度；动词派生 → deepen v. 加深。

### 4. sandy /ˈsændi/ adj. 铺满沙子的；含沙的
- **词根·渊源**：古英语 **sand**（沙）+ 形容词后缀 **-y** → 英语 sandy，本义“多沙的”，引申为“铺满沙子的”。
- **同根词**：sand（**sand** 沙：沙）、sandbox（sand 沙 + box 箱 = 沙箱）、sandstone（sand 沙 + stone 石 = 砂岩）、sander（sand + **-er** 表工具 = 打磨机）。
- **前缀·后缀**：形容词后缀 **-y**（例：rainy, windy）；名词后缀 **-er**（例：worker, teacher）。
- **同义·反义**：同义 gritty（含沙的）；反义 无。
- **变形**：形容词 → 比较级：sandier；最高级：sandiest；名词派生 → sandiness n. 多沙。

### 5. kick /kɪk/ v. 踢；踹
- **词根·渊源**：中古英语 *kiken*（踢），词源存疑，可能源自斯堪的纳维亚语或拟声词；本义“用脚猛击”，即“踢”。
- **同根词**：kicker（kick + **-er** 表人 = 踢球者）、kickoff（kick 踢 + off 开 = 开球→开始）、kicky（kick + **-y** 形容词后缀 = 刺激的）。
- **前缀·后缀**：名词后缀 **-er**（例：runner, singer）；形容词后缀 **-y**（例：rainy, happy）。
- **同义·反义**：同义 boot（踢）, punt（踢）；反义 无。
- **变形**：动词 → 第三人称单数：kicks；过去式：kicked；过去分词：kicked；现在分词：kicking；名词派生 → kick n. 踢；kicker n. 踢者。

### 6. town /taʊn/ n. 镇；市镇
- **词根·渊源**：古英语 **tūn**（围场、村庄）→ 中古英语 *toun* → 英语 town；本义“有围栏的居住地”，引申为“市镇”。
- **同根词**：township（town + **-ship** 名词后缀 = 镇区）、townsman（town + man 人 = 镇民）、downtown（down 下 + town 镇 = 市中心）。
- **前缀·后缀**：名词后缀 **-ship**（例：friendship, leadership）；复合词无前后缀（down + town 复合）。
- **同义·反义**：同义 village（村庄）, city（城市）；反义 countryside（乡村）。
- **变形**：名词 → 复数：towns；名词派生 → township n. 镇区；townsman n. 镇民。

### 7. feature /ˈfiʧər/ n. 特色；特征
- **词根·渊源**：拉丁 **factura**（制作，源自 *facere* 做）→ 古法语 *faiture*（形状）→ 英语 feature；本义“造出的形状”，引申为“特征”。
- **同根词**：fact（**fac-** 做 + **-t** 名词后缀 = 事实）、factory（fact 做 + **-ory** 场所 = 工厂）、effect（**ef-** 出 + fact 做 = 做出效果→效果）、perfect（**per-** 完全 + fact 做 = 完全做成的→完美的）、feasible（**fac-** 做 + **-ible** 可…的 = 可行的）。
- **前缀·后缀**：名词后缀 **-ure**（例：picture, nature）；前缀 **ef-**（例：effect）、**per-**（例：perfect）。
- **同义·反义**：同义 characteristic（特征）, trait（特点）；反义 无。
- **变形**：名词 → 复数：features；动词派生 → feature v. 以…为特色；形容词派生 → featureless adj. 无特色的。

### 8. south /saʊθ/ n. 南；南方
- **词根·渊源**：古英语 **sūþ**（南）→ 中古英语 *south* → 英语 south；与 sun 同出 PIE *sawel-*（太阳），本义“太阳所在的方向”，即“南方”。
- **同根词**：southern（south + **-ern** 方向后缀 = 南方的）、southward（south + **-ward** 方向后缀 = 向南）、southeast（south 南 + east 东 = 东南）、southerner（southern + **-er** 表人 = 南方人）。
- **前缀·后缀**：方向后缀 **-ern**（例：eastern, western）、**-ward**（例：northward, backward）；名词后缀 **-er**（例：teacher, worker）。
- **同义·反义**：同义 southward（向南）；反义 north（北）。
- **变形**：名词 → 复数：souths（少用）；形容词派生 → southern adj. 南方的；副词派生 → southward adv. 向南。

### 9. clear /klɪr/ adj. 晴朗的
- **词根·渊源**：拉丁 **clarus**（明亮的、清楚的）→ 古法语 *cler* → 英语 clear；本义“明亮的”，引申为“晴朗的”。
- **同根词**：clearly（clear + **-ly** 副词后缀 = 清楚地）、clarity（**clar-** 清楚 + **-ity** 名词后缀 = 清晰）、clarify（**clar-** 清楚 + **-ify** 动词后缀 = 澄清）、declare（**de-** 完全 + clar 清楚 = 完全说清→宣布）。
- **前缀·后缀**：副词后缀 **-ly**（例：quickly, slowly）；名词后缀 **-ity**（例：activity, reality）；动词后缀 **-ify**（例：simplify, beautify）；前缀 **de-**（例：decrease, defend）。
- **同义·反义**：同义 bright（明亮的）, sunny（晴朗的）；反义 cloudy（多云的）, unclear（不清楚的）。
- **变形**：形容词 → 比较级：clearer；最高级：clearest；副词派生 → clearly adv. 清楚地；名词派生 → clarity n. 清晰；动词派生 → clarify v. 澄清。

### 10. loudly /ˈlaʊdli/ adv. 喧闹地；响亮地
- **词根·渊源**：古英语 **hlūd**（响亮的）+ 副词后缀 **-ly** → 英语 loudly；本义“以响亮的方式”，即“喧闹地”。
- **同根词**：loud（**hlūd** 响亮的：响亮的）、loudness（loud + **-ness** 名词后缀 = 响亮）、loudspeaker（loud 响亮 + speaker 扬声器 = 扬声器）、aloud（**a-** 在…状态 + loud 响亮 = 出声地）。
- **前缀·后缀**：副词后缀 **-ly**（例：quickly, bravely）；名词后缀 **-ness**（例：happiness, darkness）；前缀 **a-**（例：alive, asleep）。
- **同义·反义**：同义 noisily（喧闹地）；反义 quietly（安静地）。
- **变形**：副词 → 比较级：more loudly；最高级：most loudly；形容词派生 → loud adj. 响亮的；名词派生 → loudness n. 响亮。

### 11. thunder /ˈθəndər/ n. 雷
- **词根·渊源**：古英语 **þunor**（雷）→ 中古英语 *thunder* → 英语 thunder；与拉丁 *tonare*（打雷）同出 PIE *(s)ten-*（轰鸣），本义“轰鸣声”，即“雷”。
- **同根词**：thunderous（thunder + **-ous** 形容词后缀 = 雷鸣般的）、thunderstorm（thunder 雷 + storm 暴风雨 = 雷暴）、thunderbolt（thunder 雷 + bolt 闪电 = 雷电）、thunderstruck（thunder 雷 + struck 击中 = 震惊的）。
- **前缀·后缀**：形容词后缀 **-ous**（例：famous, dangerous）；复合词无前后缀（thunder + storm 复合）。
- **同义·反义**：同义 无；反义 无。
- **变形**：名词 → 复数：thunders（少用，多不可数）；形容词派生 → thunderous adj. 雷鸣般的；动词派生 → thunder v. 打雷。

### 12. lightning /ˈlaɪtnɪŋ/ n. 闪电
- **词根·渊源**：中古英语 *lightning*，由 **lighten**（发光，源自古英语 *līhtan* 照亮）+ **-ing** 名词后缀构成；本义“发光现象”，即“闪电”。
- **同根词**：light（**līht** 光：光）、lighten（light + **-en** 动词后缀 = 照亮）、lightning（lighten + **-ing** 名词后缀 = 闪电）、enlighten（**en-** 使 + lighten 照亮 = 启发）。
- **前缀·后缀**：名词后缀 **-ing**（例：building, meeting）；动词后缀 **-en**（例：widen, strengthen）；前缀 **en-**（例：enable, encourage）。
- **同义·反义**：同义 flash（闪光）；反义 无。
- **变形**：名词 → 复数：lightnings（少用，多不可数）；形容词派生 → lightning adj. 闪电般的。

### 13. fresh /frɛʃ/ adj. 新鲜的
- **词根·渊源**：古英语 **fersc**（新鲜的）→ 中古英语 *fressh* → 英语 fresh；与德语 *frisch* 同源，本义“未变质的”，即“新鲜的”。
- **同根词**：freshly（fresh + **-ly** 副词后缀 = 新鲜地）、freshness（fresh + **-ness** 名词后缀 = 新鲜）、refresh（**re-** 再 + fresh 新鲜 = 使恢复新鲜→刷新）、freshman（fresh 新 + man 人 = 新生）。
- **前缀·后缀**：副词后缀 **-ly**（例：quickly, bravely）；名词后缀 **-ness**（例：happiness, darkness）；前缀 **re-**（例：return, rebuild）。
- **同义·反义**：同义 new（新的）, recent（最近的）；反义 stale（不新鲜的）, old（旧的）。
- **变形**：形容词 → 比较级：fresher；最高级：freshest；副词派生 → freshly adv. 新鲜地；名词派生 → freshness n. 新鲜；动词派生 → refresh v. 刷新。

### 14. gather /ˈgæðər/ v. 采集(植物、水果等)
- **词根·渊源**：古英语 **gaderian**（聚集）→ 中古英语 *gaderen* → 英语 gather；与 together 同出 PIE *ghedh-*（联合），本义“聚在一起”，引申为“采集”。
- **同根词**：together（**to-** 到 + gether 聚集 = 一起）、gathering（gather + **-ing** 名词后缀 = 聚集）、gatherer（gather + **-er** 表人 = 采集者）、altogether（**al-** 全 + together 一起 = 完全）。
- **前缀·后缀**：名词后缀 **-ing**（例：building, meeting）；名词后缀 **-er**（例：teacher, worker）；前缀 **to-**（例：today, tonight）。
- **同义·反义**：同义 collect（收集）, pick（采摘）；反义 scatter（散开）, disperse（分散）。
- **变形**：动词 → 第三人称单数：gathers；过去式：gathered；过去分词：gathered；现在分词：gathering；名词派生 → gathering n. 聚集；gatherer n. 采集者。

### 15. peaceful /ˈpisfəl/ adj. 安静的；平静的
- **词根·渊源**：拉丁 **pax / pac-**（和平）→ 古法语 *pais* → 英语 peace + 形容词后缀 **-ful** → 英语 peaceful；本义“充满和平的”，引申为“安静的”。
- **同根词**：peace（**pax** 和平：和平）、pacify（**pac-** 和平 + **-ify** 动词后缀 = 使平静）、pacific（**pac-** 和平 + **-ific** 形容词后缀 = 和平的）、peacemaker（peace 和平 + maker 制造者 = 调解人）。
- **前缀·后缀**：形容词后缀 **-ful**（例：helpful, useful）；动词后缀 **-ify**（例：simplify, beautify）；形容词后缀 **-ific**（例：scientific, specific）。
- **同义·反义**：同义 calm（平静的）, quiet（安静的）；反义 noisy（吵闹的）, violent（暴力的）。
- **变形**：形容词 → 比较级：more peaceful；最高级：most peaceful；副词派生 → peacefully adv. 平静地；名词派生 → peacefulness n. 平静。

### 16. snake /sneɪk/ n. 蛇
- **词根·渊源**：古英语 **snaca**（蛇）→ 中古英语 *snake* → 英语 snake；与德语 *Schlange* 同源，本义“爬行的动物”，即“蛇”。
- **同根词**：snaky（snake + **-y** 形容词后缀 = 蛇般的）、snakeskin（snake 蛇 + skin 皮 = 蛇皮）、snakebite（snake 蛇 + bite 咬 = 蛇咬伤）。
- **前缀·后缀**：形容词后缀 **-y**（例：rainy, windy）；复合词无前后缀（snake + skin 复合）。
- **同义·反义**：同义 serpent（蛇）；反义 无。
- **变形**：名词 → 复数：snakes；形容词派生 → snaky adj. 蛇般的；动词派生 → snake v. 蜿蜒。

### 17. through /θru/ prep. 自始至终；从头到尾
- **词根·渊源**：古英语 **þurh**（穿过）→ 中古英语 *thurgh* → 英语 through；与德语 *durch* 同源，本义“穿过”，引申为“自始至终”。
- **同根词**：throughout（through 穿过 + out 出 = 遍及）、throughput（through 穿过 + put 放 = 吞吐量）、breakthrough（break 破 + through 穿过 = 突破）。
- **前缀·后缀**：复合词无前后缀（through + out 复合）；无前后缀（单纯词）。
- **同义·反义**：同义 throughout（遍及）；反义 无。
- **变形**：介词 → 无形态变化；副词派生 → throughout adv. 遍及。

### 18. part /pɑrt/ n. 区域；地区
- **词根·渊源**：拉丁 **pars / part-**（部分）→ 古法语 *part* → 英语 part；本义“一部分”，引申为“区域、地区”。
- **同根词**：partial（part + **-ial** 形容词后缀 = 部分的）、partly（part + **-ly** 副词后缀 = 部分地）、partner（part + **-ner** 表人 = 合伙人）、partake（part 部分 + take 拿 = 参与）、particle（part 部分 + **-icle** 小后缀 = 微粒）。
- **前缀·后缀**：形容词后缀 **-ial**（例：social, special）；副词后缀 **-ly**（例：quickly, slowly）；小称后缀 **-icle**（例：article, vehicle）。
- **同义·反义**：同义 region（地区）, area（区域）；反义 whole（整体）。
- **变形**：名词 → 复数：parts；形容词派生 → partial adj. 部分的；副词派生 → partly adv. 部分地；动词派生 → part v. 分开。

### 19. article /ˈɑrtɪkəl/ n. 文章
- **词根·渊源**：拉丁 **artus**（关节）→ 拉丁 *articulus*（小关节、条款）→ 古法语 *article* → 英语；本义“小关节→条文、条款”，文章由若干段落“关节”组成，引申为“文章”。
- **同根词**：articulate（articul 关节 + **-ate** 使… = 使关节分明→清晰表达）、artifact（arte 技艺 + fact 做 = 做出来的东西→人工制品）、artificial（artific 技艺 + **-ial** …的 = 人造的）、artisan（art 技艺 + **-isan** 人 = 手艺人）。
- **前缀·后缀**：名词后缀 **-icle**（例：particle, vehicle）。
- **同义·反义**：同义 essay（短文）, piece（篇章）；反义 无。
- **变形**：名词 → 复数：articles；形容词派生 → articled adj. 订约的；名词派生 → article n. 条款（同形）。

### 20. reason /ˈrizən/ n. 原因；理由
- **词根·渊源**：拉丁 **ratio / ration-**（计算、理性）→ 古法语 *raison* → 英语；本义“计算、推理”，引申为“理由、原因”。
- **同根词**：reasonable（reason + **-able** 能…的 = 讲道理的）、reasoning（reason + **-ing** 名词 = 推理）、rational（ration 理性 + **-al** …的 = 理性的）、ratio（直接借自拉丁 = 比率）、rate（拉丁 rata 计算→比率）。
- **前缀·后缀**：名词后缀 **-on**（例：season, lesson）。
- **同义·反义**：同义 cause（原因）, motive（动机）；反义 无。
- **变形**：名词 → 复数：reasons；动词派生 → reason v. 推理；形容词派生 → reasonable adj. 合理的；副词派生 → reasonably adv. 合理地。

### 21. alive /əˈlaɪv/ adj. 有生气；有活力
- **词根·渊源**：古英语 **on life**（在生命之中）→ 中古英语 *alive*；本义“活着的”，引申为“有生气、有活力”。
- **同根词**：life（古英语 lif = 生命）、live（古英语 libban = 活着）、lively（live + **-ly** …地 = 活泼的）、living（live + **-ing** …的 = 活着的）。
- **前缀·后缀**：前缀 **a-**（例：asleep, awake）。
- **同义·反义**：同义 lively（活泼的）, energetic（有活力的）；反义 dead（死的）, lifeless（无生气的）。
- **变形**：形容词 → 无比较级（表语形容词，不作比较）；名词派生 → aliveness n. 活力。

### 22. sandcastle  n. 沙堡
- **词根·渊源**：古英语 **sand**（沙）+ 拉丁 *castellum*（小堡垒）→ 古北法语 *castel* → 英语 castle；复合词，本义“用沙做的城堡”。
- **同根词**：sand（古英语 sand = 沙）、castle（拉丁 castellum 小堡垒→城堡）、sandbox（sand + box 箱 = 沙箱）、sandstone（sand + stone 石 = 砂岩）。
- **前缀·后缀**：无前后缀（复合词：sand + castle）。
- **同义·反义**：同义 无；反义 无。
- **变形**：名词 → 复数：sandcastles。

### 23. follow /ˈfɑloʊ/ v. 按……方式发展
- **词根·渊源**：古英语 **folgian**（跟随）→ 中古英语 *folwen* → 英语；本义“跟随”，引申为“按照……方式发展、遵循”。
- **同根词**：follower（follow + **-er** 人 = 追随者）、following（follow + **-ing** …的 = 接着的）、follow-up（follow + up = 跟进）。
- **前缀·后缀**：无前后缀（单纯词）。
- **同义·反义**：同义 pursue（追随）, obey（遵循）；反义 lead（带领）, precede（先于）。
- **变形**：动词 → 第三人称单数：follows；过去式：followed；过去分词：followed；现在分词：following；名词派生 → follower n. 追随者；following n. 追随者群体。

### 24. divide /dɪˈvaɪd/ v. (使)分开
- **词根·渊源**：拉丁 **dividere**（分开）= **dis-** 分开 + videre 分 → 古法语 *divider* → 英语；本义“使分离”，即“分开、划分”。
- **同根词**：division（divis 分 + **-ion** 名词 = 分开、部门）、individual（**in-** 不 + divid 分 + **-ual** …的 = 不可再分的→个人的）、dividend（divid 分 + **-end** 应得之物 = 被分出的数→股息）。
- **前缀·后缀**：前缀 **di-/dis-**（例：divide, divert）；动词后缀 **-e**（例：decide, provide）。
- **同义·反义**：同义 separate（分开）, split（分裂）；反义 unite（联合）, combine（结合）。
- **变形**：动词 → 第三人称单数：divides；过去式：divided；过去分词：divided；现在分词：dividing；名词派生 → division n. 分开；形容词派生 → divisible adj. 可分的。

### 25. decide /ˌdɪˈsaɪd/ v. 对…作出抉择；决定
- **词根·渊源**：拉丁 **decidere**（切断）= **de-** 离开 + caedere 切 → 古法语 *decider* → 英语；本义“切断（犹豫）”，引申为“作出决定”。
- **同根词**：decision（decis 切 + **-ion** 名词 = 切断犹豫→决定）、decisive（decis 切 + **-ive** …的 = 果断的）、precise（**pre-** 预先 + cis 切 = 预先切好的→精确的）、scissors（拉丁 cis 切 + **-ors** 工具 = 切割工具→剪刀）。
- **前缀·后缀**：前缀 **de-**（例：decline, depart）；动词后缀 **-e**（例：divide, provide）。
- **同义·反义**：同义 determine（决定）, resolve（决心）；反义 hesitate（犹豫）, waver（动摇）。
- **变形**：动词 → 第三人称单数：decides；过去式：decided；过去分词：decided；现在分词：deciding；名词派生 → decision n. 决定；形容词派生 → decisive adj. 果断的；副词派生 → decidedly adv. 果断地。

### 26. crop /krɑp/ n. 庄稼；作物
- **词根·渊源**：古英语 **cropp**（植物的顶端、穗）→ 中古英语 *crop* → 英语；本义“植物顶端”，引申为“一季收获的庄稼、作物”。
- **同根词**：cropper（crop + **-er** 人/物 = 种植者）、crop-dusting（crop + dusting 喷粉 = 作物喷药）。
- **前缀·后缀**：无前后缀（单纯词）。
- **同义·反义**：同义 harvest（收成）, produce（农产品）；反义 无。
- **变形**：名词 → 复数：crops；动词派生 → crop v. 剪短、收割；过去式：cropped；过去分词：cropped；现在分词：cropping。

### 27. culture /ˈkəlʧər/ n. 文化；文明
- **词根·渊源**：拉丁 **cultura**（耕作、培育）= cult 耕种 + **-ura** 名词 → 古法语 *culture* → 英语；本义“耕作土地”，引申为“培育心智→文化、文明”。
- **同根词**：cultivate（cultiv 耕种 + **-ate** 动词 = 耕作、培养）、agriculture（agri 田地 + culture 耕作 = 农业）、cultural（culture + **-al** …的 = 文化的）、cult（拉丁 cultus 耕作→崇拜）。
- **前缀·后缀**：名词后缀 **-ure**（例：nature, picture）。
- **同义·反义**：同义 civilization（文明）, refinement（教养）；反义 无。
- **变形**：名词 → 复数：cultures；形容词派生 → cultural adj. 文化的；副词派生 → culturally adv. 文化上地；动词派生 → cultivate v. 培养。

### 28. local /ˈloʊkəl/ adj. 地方的；当地的
- **词根·渊源**：拉丁 **locus**（地方）→ 晚期拉丁 *localis* → 古法语 *local* → 英语；本义“属于某地方的”，即“地方的、当地的”。
- **同根词**：locate（loc 地方 + **-ate** 动词 = 定位）、location（locat 定位 + **-ion** 名词 = 位置）、locomotive（loco 地方 + motiv 移动 = 从一地移到另一地的→机车）、allocate（**al-** 向 + loc 地方 = 分配到某处）。
- **前缀·后缀**：形容词后缀 **-al**（例：natural, national）。
- **同义·反义**：同义 regional（地区的）, native（本地的）；反义 national（全国的）, global（全球的）。
- **变形**：形容词 → 无比较级（关系形容词，不作比较）；名词派生 → local n. 当地人；副词派生 → locally adv. 当地地；动词派生 → locate v. 定位。

### 29. tradition /trəˈdɪʃən/ n. 传统
- **词根·渊源**：拉丁 **traditio**（交出、传递）= **trans-** 越过 + dare 给 → 古法语 *tradicion* → 英语；本义“传递下去的东西”，引申为“传统”。
- **同根词**：traditional（tradition + **-al** …的 = 传统的）、traditionally（traditional + **-ly** 副词 = 传统上）、traitor（拉丁 trad 交出 + **-or** 人 = 交出别人的人→叛徒）、betray（**be-** 加强 + tray 交出 = 背叛）。
- **前缀·后缀**：名词后缀 **-tion**（例：action, nation）。
- **同义·反义**：同义 custom（习俗）, convention（惯例）；反义 innovation（创新）, novelty（新奇）。
- **变形**：名词 → 复数：traditions；形容词派生 → traditional adj. 传统的；副词派生 → traditionally adv. 传统上。

### 30. continue /kənˈtɪnju/ v. 持续；继续存在
- **词根·渊源**：拉丁 **continuare**（使连接）= **con-** 一起 + tenere 握持 → 古法语 *continuer* → 英语；本义“连在一起不断”，引申为“持续、继续”。
- **同根词**：continuous（continu 连续 + **-ous** …的 = 连续不断的）、continual（continu 连续 + **-al** …的 = 反复不断的）、contain（**con-** 一起 + tain 握 = 握在一起→包含）、content（**con-** 一起 + tent 握 = 握住的→满足的）。
- **前缀·后缀**：前缀 **con-**（例：connect, contain）；动词后缀 **-ue**（例：argue, value）。
- **同义·反义**：同义 persist（坚持）, proceed（继续进行）；反义 stop（停止）, cease（终止）。
- **变形**：动词 → 第三人称单数：continues；过去式：continued；过去分词：continued；现在分词：continuing；名词派生 → continuation n. 继续；形容词派生 → continuous adj. 连续的；副词派生 → continuously adv. 连续地。
