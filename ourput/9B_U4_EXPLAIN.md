## 二、逐词说文解字

### 1. asteroid /ˈæstərɔɪd/ adj. 小行星
- **词根·渊源**：希腊 **aster / astron-**（星）+ **-oeidēs**（像…的）→ 希腊 *asteroeidēs*（星状的）→ 英语 *asteroid*；本义“星状的”，因小行星在望远镜中呈星点状而得名。
- **同根词**：astronomy（aster 星 + nomos 法则 = 星辰的法则→天文学）、astronaut（aster 星 + nautēs 水手 = 星际水手→宇航员）、asterisk（aster 星 + **-isk** 小 = 小星号→星号）、disaster（**dis-** 坏 + aster 星 = 星位不利→灾难）、astrology（aster 星 + logos 言说 = 论星→占星术）。
- **前缀·后缀**：后缀 **-oid**（例：humanoid, planetoid）。
- **同义·反义**：同义 planetoid；反义 无。
- **词性变化**：asteroidal adj. 小行星的。

### 2. typhoon /taɪ'fuːn/ n. 台风
- **词根·渊源**：希腊 **typhōn**（旋风、巨风，原为神话中的风魔 Typhon）→ 阿拉伯语 *ṭūfān*（大洪水、风暴）→ 葡萄牙语 *tufão* → 英语 *typhoon*；本义“猛烈的旋风”，引申为“台风”。词源有争议，汉语“台风”与希腊来源的关系存疑。
- **同根词**：typhonic（typhoon + **-ic** …的：台风的）、typhoonish（typhoon + **-ish** 似…的：台风似的）。
- **前缀·后缀**：无前后缀（单纯词）。
- **同义·反义**：同义 cyclone, hurricane；反义 无。
- **词性变化**：typhonic adj. 台风的。

### 3. earthquake /ˈɜ:rθkweɪk/ n. 地震
- **词根·渊源**：古英语 **eorþe**（地）+ **cwacian**（摇动）→ 中古英语 *erthequake* → 英语 *earthquake*；本义“大地摇动”，即“地震”。
- **同根词**：earth（地：earthquake 的前半）、earthy（earth + **-y** …的：泥土的）、earthly（earth + **-ly** …的：尘世的）、quaky（quake + **-y** …的：摇晃的）、quaver（与 quake 同源，摇动→颤抖）。
- **前缀·后缀**：无前后缀（复合词）。
- **同义·反义**：同义 quake, tremor；反义 无。
- **词性变化**：earthquaked adj. 受地震影响的（罕用）。

### 4. melt /mɛlt/ v.（使）熔化；（使）融化
- **词根·渊源**：古英语 **meltan**（熔化、消化）→ 中古英语 *melten* → 英语 *melt*；与古诺斯语 *melta* 同源，本义“使变软、化开”，引申为“熔化、融化”。
- **同根词**：molten（melt 的过去分词变体：熔化的）、melting（melt + **-ing** …的：融化的）、meltable（melt + **-able** 可…的：可熔化的）、meltdown（melt + down 向下 = 熔毁→核熔毁）。
- **前缀·后缀**：无前后缀（单纯词）。
- **同义·反义**：同义 thaw, dissolve；反义 freeze, solidify。
- **词性变化**：melting adj. 融化的；melted adj. 熔化的。

### 5. flood /flʌd/ n.（使）灌满水；淹没
- **词根·渊源**：古英语 **flōd**（洪水、水流）→ 中古英语 *flod* → 英语 *flood*；与 flow 同出 PIE *pleu-*（流动），本义“大水流动”，引申为“洪水、淹没”。
- **同根词**：flow（与 flood 同源：流动）、flooding（flood + **-ing** 名词：泛滥）、floodgate（flood + gate 门 = 防洪闸门）、floodlight（flood + light 光 = 泛光灯）。
- **前缀·后缀**：无前后缀（单纯词）。
- **同义·反义**：同义 deluge, inundate；反义 drought, drain。
- **词性变化**：flooding n. 泛滥；flooded adj. 被淹没的。

### 6. badly /ˈbædli/ adv. 严重地；厉害地
- **词根·渊源**：古英语 **bæddel**（坏人或坏东西）→ 中古英语 *badde*（坏的）+ **-ly**（…地）→ 英语 *badly*；本义“以坏的方式”，引申为“严重地、厉害地”。
- **同根词**：bad（badly 的词根：坏的）、worse（bad 的比较级：更坏的）、worst（bad 的最高级：最坏的）、badness（bad + **-ness** 名词：坏）。
- **前缀·后缀**：副词后缀 **-ly**（例：quickly, happily）。
- **同义·反义**：同义 severely, seriously；反义 well。
- **词性变化**：bad adj. 坏的；worse adj. 更坏的；worst adj. 最坏的。

### 7. alive /əˈlaɪv/ adj. 活着的，在世的
- **词根·渊源**：古英语 **on līfe**（在生命之中）→ 中古英语 *alive* → 英语 *alive*；本义“处于生命状态”，即“活着的”。
- **同根词**：life（与 alive 同源：生命）、live（与 alive 同源：活着）、lively（live + **-ly** …的：活泼的）、living（live + **-ing** …的：活着的）、lifeless（life + **-less** 无…的：无生命的）。
- **前缀·后缀**：前缀 **a-**（例：asleep, awake）。
- **同义·反义**：同义 living, animate；反义 dead。
- **词性变化**：life n. 生命；live v. 活着；lively adj. 活泼的。

### 8. pool /puːl/ n. 水坑；水塘
- **词根·渊源**：古英语 **pōl**（水塘、池）→ 中古英语 *pol* → 英语 *pool*；与德语 *Pfuhl* 同源，本义“小水塘”，引申为“水坑、游泳池”。
- **同根词**：puddle（与 pool 同源：小水坑）、poolside（pool + side 边 = 池边）。
- **前缀·后缀**：无前后缀（单纯词）。
- **同义·反义**：同义 pond, puddle；反义 无。
- **词性变化**：pooled adj. 汇集的（另一义）。

### 9. object /ˈɑ:bdʒekt/ n. 物体；物品；目的，目标
- **词根·渊源**：拉丁 **ob-**（对着）+ **jacere**（投、扔）→ 拉丁 *objectum*（投在面前的东西）→ 中世纪拉丁 *objectum* → 英语 *object*；本义“投放在眼前之物”，引申为“物体、目标”。
- **同根词**：objection（**ob-** 对着 + ject 投 + **-ion** 名词 = 投反对意见→反对）、objective（object + **-ive** …的：客观的）、project（**pro-** 向前 + ject 投 = 向前投→投射、项目）、reject（**re-** 回 + ject 投 = 投回→拒绝）、inject（**in-** 入 + ject 投 = 投入→注射）、subject（**sub-** 下 + ject 投 = 投于下→主题、臣民）。
- **前缀·后缀**：前缀 **ob-**（例：obtain, observe）；词根 **ject**（例：project, reject）。
- **同义·反义**：同义 thing, item, aim；反义 无。
- **词性变化**：object v. 反对；objection n. 反对；objective adj. 客观的。

### 10. coach /kəʊtʃ/ n. 长途旅游车，长途汽车
- **词根·渊源**：法语 **coche**（马车）→ 匈牙利语 *kocsi*（科奇村制造的车）→ 英语 *coach*；本义“四轮大马车”，引申为“长途客车、教练”。
- **同根词**：coachman（coach + man 人 = 马车夫）、coaching（coach + **-ing** 名词：教练工作）。
- **前缀·后缀**：无前后缀（单纯词）。
- **同义·反义**：同义 bus, carriage；反义 无。
- **词性变化**：coach v. 训练；coachman n. 马车夫。

### 11. pass /pɑːs/ v. 通过
- **词根·渊源**：拉丁 **passus**（步、步伐）→ 俗拉丁 *passare*（行走）→ 古法语 *passer*（经过）→ 英语 *pass*；本义“迈步走过”，引申为“通过”。
- **同根词**：passage（pass + **-age** 名词 = 通过→通道）、passenger（pass + **-enger** 人 = 过路人→乘客）、passport（pass + port 港口 = 通过港口→护照）、passable（pass + **-able** 可…的：可通过的）、surpass（**sur-** 超过 + pass 过 = 超过）。
- **前缀·后缀**：前缀 **sur-**（例：surface, survive）。
- **同义·反义**：同义 go through, cross；反义 fail, stop。
- **词性变化**：passage n. 通道；passenger n. 乘客；passport n. 护照。

### 12. line /laɪn/ n. 电话线路
- **词根·渊源**：拉丁 **linea**（线、绳）→ 古法语 *ligne* → 英语 *line*；本义“亚麻绳、直线”，引申为“线路、电话线”。
- **同根词**：linear（line + **-ar** …的：线性的）、lineage（line + **-age** 名词 = 线→血统）、outline（**out-** 外 + line 线 = 外线→轮廓）、underline（**under-** 下 + line 线 = 下划线）、linen（与 line 同源：亚麻布）。
- **前缀·后缀**：前缀 **out-**（例：outdoor, outside）、**under-**（例：underground, understand）。
- **同义·反义**：同义 wire, cable；反义 无。
- **词性变化**：linear adj. 线性的；outline n. 轮廓；underline v. 下划线。

### 13. dead /dɛd/ adj.（因为缺电）不运行的；不转动的
- **词根·渊源**：古英语 **dēad**（死的）→ 中古英语 *ded* → 英语 *dead*；与古诺斯语 *dauðr* 同源，本义“失去生命的”，引申为“不运行的、不转动的”。
- **同根词**：death（dead + **-th** 名词：死亡）、deadly（dead + **-ly** …的：致命的）、deadline（dead + line 线 = 死线→截止日期）、die（与 dead 同源：死）。
- **前缀·后缀**：无前后缀（单纯词）。
- **同义·反义**：同义 lifeless, inactive；反义 alive, live。
- **词性变化**：death n. 死亡；deadly adj. 致命的；die v. 死。

### 14. boss /bɔːs/ n. 老板；上司
- **词根·渊源**：荷兰语 **baas**（主人、师傅）→ 美国英语 *boss*；本义“主人、工头”，引申为“老板、上司”。词源存疑，可能源自荷兰语 baas。
- **同根词**：bossy（boss + **-y** …的：专横的）、bossism（boss + **-ism** 主义：老板政治）。
- **前缀·后缀**：无前后缀（单纯词）。
- **同义·反义**：同义 employer, manager；反义 employee, worker。
- **词性变化**：bossy adj. 专横的；boss v. 指挥。

### 15. deaf /dɛf/ adj. 聋的
- **词根·渊源**：古英语 **dēaf**（聋的）→ 中古英语 *def* → 英语 *deaf*；与古诺斯语 *daufr* 同源，本义“听觉迟钝的”，即“聋的”。
- **同根词**：deafen（deaf + **-en** 使…：使聋）、deafness（deaf + **-ness** 名词：聋）、deafening（deafen + **-ing** …的：震耳欲聋的）。
- **前缀·后缀**：动词后缀 **-en**（例：widen, strengthen）；名词后缀 **-ness**（例：kindness, darkness）。
- **同义·反义**：同义 hard of hearing；反义 hearing。
- **词性变化**：deafen v. 使聋；deafness n. 聋；deafening adj. 震耳欲聋的。

### 16. stare /stɛr/ v. 盯；注视
- **词根·渊源**：古英语 **starian**（凝视）→ 中古英语 *staren* → 英语 *stare*；与古诺斯语 *stara* 同源，本义“睁大眼睛看”，引申为“盯、注视”。
- **同根词**：staring（stare + **-ing** …的：凝视的）、starrer（stare + **-er** 人：凝视者）。
- **前缀·后缀**：无前后缀（单纯词）。
- **同义·反义**：同义 gaze, gape；反义 glance, peek。
- **词性变化**：staring adj. 凝视的；stare n. 凝视。

### 17. screen /skriːn/ n. 显示屏，屏幕
- **词根·渊源**：古法语 **escren**（屏风、挡板）→ 中古英语 *screne* → 英语 *screen*；本义“遮挡物、屏风”，引申为“屏幕、显示屏”。
- **同根词**：screening（screen + **-ing** 名词： screening→筛选）、screener（screen + **-er** 人/物：筛选者）、screenshot（screen + shot 拍摄 = 屏幕截图）。
- **前缀·后缀**：无前后缀（单纯词）。
- **同义·反义**：同义 display, monitor；反义 无。
- **词性变化**：screening n. 筛选；screenshot n. 截图。

### 18. notice /ˈnoʊtɪs/ v. 看（或听）到；注意，察觉；意识到
- **词根·渊源**：拉丁 **notus**（已知的，noscere 的过去分词）+ **-itia**（名词后缀）→ 拉丁 *notitia*（知识、通知）→ 古法语 *notice* → 英语 *notice*；本义“得知、知道”，引申为“注意到、察觉”。
- **同根词**：notion（not 知 + **-ion** 名词 = 所知→概念）、notify（not 知 + **-ify** 使… = 使知道→通知）、notable（not 知 + **-able** 可…的 = 可知的→显著的）、notorious（not 知 + **-orious** …的 = 众所周知的→臭名昭著的）、annotate（**an-** 加 + not 知 + **-ate** 动词 = 加注→注释）。
- **前缀·后缀**：前缀 **an-**（例：announce, annex）；后缀 **-ify**（例：simplify, beautify）。
- **同义·反义**：同义 observe, perceive；反义 ignore, overlook。
- **词性变化**：notice n. 通知；notify v. 通知；notion n. 概念；notable adj. 显著的。

### 19. immediately /ɪˈmiːdiətli/ adv. 立即,马上
- **词根·渊源**：拉丁 **medi-**（中间）→ 拉丁 *immediatus*（没有中间物的）→ 中古英语 *immediat* + 副词后缀 **-ly**；本义“中间不隔任何东西”→ 引申为“立即、马上”。
- **同根词**：immediate（**im-** 不 + medi 中间 + **-ate** 形容词后缀 = 中间不隔的→立即的）、mediate（medi 中间 + **-ate** 动词后缀 = 居间调停）、medium（medi 中间 + **-um** 名词后缀 = 中间物→媒介）、intermediate（**inter-** 在…之间 + medi 中间 + **-ate** = 中间的）、mediterranean（medi 中间 + terra 土地 = 位于陆地中间的→地中海的）。
- **前缀·后缀**：否定前缀 **im-**（例：impossible, impolite）；副词后缀 **-ly**（例：quickly, happily）。
- **同义·反义**：同义 at once, right away；反义 later, eventually。
- **词性变化**：immediate adj. 立即的；immediacy n. 直接性。

### 20. missing /ˈmɪsɪŋ/ adj. 找不到的；失踪的
- **词根·渊源**：古英语 **missan**（未击中、未找到）→ 中古英语 *missen* → 动词 miss + 现在分词后缀 **-ing** 作形容词；本义“未找到的”→ 引申为“失踪的、缺失的”。
- **同根词**：miss（miss 未击中 = 未击中→错过）、missile（miss 投掷 + **-ile** 可…的 = 可投掷之物→导弹）、mission（miss 送 + **-ion** 名词后缀 = 送出去的任务→使命）、dismiss（**dis-** 离开 + miss 送 = 送走→解散）、admit（**ad-** 向 + mit 送 = 送入→准许进入，mit/miss 同源变体）。
- **前缀·后缀**：形容词后缀 **-ing**（例：interesting, exciting）；动词前缀 **dis-**（例：disappear）、**ad-**（例：advance）。
- **同义·反义**：同义 lost, absent；反义 found, present。
- **词性变化**：miss v. 错过；missing 本身为形容词，无其他常见派生。

### 21. fellow /'feləʊ/ n. 同类的；同伴的
- **词根·渊源**：古诺斯语 **félagi**（合伙者）→ 古英语 *feolaga*，由 **fe**（钱财）+ **lag**（放置、合伙）构成，本义“共同出钱合伙的人”→ 引申为“同伴、同类”。
- **同根词**：fellowship（fellow 同伴 + **-ship** 名词后缀表状态 = 同伴关系→友谊、团体）、fellowman（fellow 同类 + man 人 = 同胞）、lay（lag 放置 = 放置→放下的，与 fellow 同源，存疑）。
- **前缀·后缀**：名词后缀 **-ship**（例：friendship, leadership）；无前缀。
- **同义·反义**：同义 companion, comrade；反义 stranger, enemy。
- **词性变化**：fellowship n. 友谊；团体；fellow 作形容词时意为“同类的”。

### 24. sit around /sɪt əˈraʊnd/ v. 无所事事地消磨时间；闲坐
