## 二、逐词说文解字

### 1. praise /preɪz/ n. 表扬，赞扬；称赞
- **词根·渊源**：拉丁 **preti-**（价值、价格）→ 古法语 *preisier*（估价、珍视）→ 中古英语 *preisen*，本义“评定价值→珍视→称赞”；与 price、precious 同源。
- **同根词**：price（拉丁 pretium 价值→价格）、precious（preti- 价值 + **-ous** …的 = 有价值的→珍贵的）、appraise（**ap-** 向 + praise 估价 = 评估）、appreciate（**ap-** 向 + preti- 价值 + **-ate** 动词后缀 = 看出价值→欣赏）。
- **前缀·后缀**：动词前缀 **ap-**（例：appear, approve）；名词后缀 **-al**（例：arrival, proposal）。
- **同义·反义**：同义 commend, applaud；反义 blame, criticize。
- **词性变化**：praise v. 表扬；praiseworthy adj. 值得称赞的。

### 2. view /vjuː/ n. 看；观看；观点，看法
- **词根·渊源**：拉丁 **vid-**（看）→ 古法语 *veue*（看见、景象）→ 中古英语 *vewe*，本义“看见→所见之景→看法”；与 vision、video 同出 PIE *weid-*（看见）。
- **同根词**：vision（vid- 看 + **-ion** 名词后缀 = 视力→远见）、video（拉丁 videre 看见→录像）、evident（**e-** 出 + vid- 看 + **-ent** …的 = 看得出来的→明显的）、supervise（**super-** 在上 + vis- 看 = 从上面看→监督）、revise（**re-** 再 + vis- 看 = 再看一遍→修订）。
- **前缀·后缀**：名词后缀 **-ion**（例：action, decision）；前缀 **re-**（例：review, return）。
- **同义·反义**：同义 sight, opinion；反义 无。
- **词性变化**：viewer n. 观看者；review v. 复习；观看。

### 3. script /skrɪpt/ n. 剧本，讲稿；广播（或讲话等）稿
- **词根·渊源**：拉丁 **script-**（写，来自 scribere 写）→ 拉丁 *scriptum*（写下的东西）→ 中古英语，本义“写下的东西→文稿→剧本”。
- **同根词**：describe（**de-** 向下 + scrib 写 = 写下来→描述）、prescribe（**pre-** 预先 + scrib 写 = 预先写下→开处方）、subscribe（**sub-** 在下 + scrib 写 = 在下面签名→订阅）、manuscript（**manu-** 手 + script 写 = 手写的→手稿）、inscription（**in-** 在上 + script 写 + **-ion** = 刻写上去→铭文）。
- **前缀·后缀**：前缀 **de-**（例：decline, depart）；名词后缀 **-ion**（例：description, subscription）。
- **同义·反义**：同义 screenplay, text；反义 无。
- **词性变化**：scripted adj. 照稿念的；describe v. 描述；prescription n. 处方。

### 4. director /dəˈrektər/ n. 导演；部门负责人
- **词根·渊源**：拉丁 **direct-**（使直，来自 dirigere 引导）→ 晚期拉丁 *director*（引导者）→ 英语，本义“指路的人→管理者→导演”。
- **同根词**：direct（**di-** 加强 + rect 直 = 使直→指导）、direction（direct + **-ion** 名词后缀 = 方向）、directly（direct + **-ly** 副词后缀 = 直接地）、correct（**cor-** 加强 + rect 直 = 使直→改正）、erect（**e-** 出 + rect 直 = 竖起来→竖立）。
- **前缀·后缀**：前缀 **di-**（例：divide, divert）；名词后缀 **-or**（例：actor, visitor）。
- **同义·反义**：同义 manager, filmmaker；反义 无。
- **词性变化**：direct v. 指导；direct adj. 直接的；direction n. 方向。

### 5. make-up /ˈmeɪk ʌp/ n. 化妆；化妆品
- **词根·渊源**：英语本土复合词，**make**（做）+ **up**（向上、完成），本义“做成、补足→化妆（把脸‘做’好）”；19世纪起指化妆品。
- **同根词**：make（古英语 macian 做→制造）、maker（make + **-er** 者 = 制造者）、up（古英语 up 向上）、makeup（同词连写形式）。
- **前缀·后缀**：无前后缀（复合词：make + up）。
- **同义·反义**：同义 cosmetics；反义 无。
- **词性变化**：make v. 做；制造；makeup n. 化妆（连写形式）。

### 6. artist /ˈɑːtɪst/ n. 画家；艺术家
- **词根·渊源**：拉丁 **art-**（技艺，来自 ars 技艺）→ 古法语 *artiste* → 英语，本义“有技艺的人→艺术家”。
- **同根词**：art（拉丁 ars 技艺→艺术）、artistic（artist + **-ic** …的 = 艺术的）、artful（art + **-ful** 充满…的 = 有技巧的→狡猾的）、artificial（**arti-** 技艺 + **fic-** 做 + **-ial** …的 = 人工做的→人造的）。
- **前缀·后缀**：名词后缀 **-ist**（例：pianist, scientist）；形容词后缀 **-ic**（例：basic, historic）。
- **同义·反义**：同义 painter, creator；反义 无。
- **词性变化**：art n. 艺术；artistic adj. 艺术的。

### 7. studio /ˈstuːdioʊ/ n. 工作室；录音室；演播室
- **词根·渊源**：拉丁 **stud-**（热心、钻研，来自 studere 致力于）→ 意大利语 *studio*（书房、钻研之所）→ 英语，本义“钻研的房间→工作室→演播室”。
- **同根词**：study（拉丁 studere 致力于→学习）、student（stud- 钻研 + **-ent** 人 = 钻研的人→学生）、studious（studi- 钻研 + **-ous** …的 = 好学的）、studio（同词）。
- **前缀·后缀**：名词后缀 **-ent**（例：agent, resident）；形容词后缀 **-ous**（例：famous, nervous）。
- **同义·反义**：同义 workshop, atelier；反义 无。
- **词性变化**：study v. 学习；student n. 学生。

### 8. contestant /kənˈtestənt/ n. 参赛者，竞争者；比赛者
- **词根·渊源**：拉丁 **test-**（见证，来自 testis 证人）→ 拉丁 *contestari*（共同作证→争辩）→ 古法语 *contester* → 英语 contest + **-ant**，本义“争辩的人→参赛者”。
- **同根词**：contest（**con-** 共同 + test 见证 = 共同作证→争辩→比赛）、test（拉丁 testum 陶罐→检验→测试）、testify（test 见证 + **-ify** 使… = 作证）、protest（**pro-** 向前 + test 见证 = 公开作证→抗议）、testimony（test 见证 + **-mony** 名词后缀 = 证词）。
- **前缀·后缀**：前缀 **con-**（例：connect, confirm）；名词后缀 **-ant**（例：servant, assistant）。
- **同义·反义**：同义 competitor, player；反义 无。
- **词性变化**：contest n. 比赛；v. 争辩；test n. 测试。

### 9. upon /əˈpɑːn/ prep. 在......上；到......上
- **词根·渊源**：古英语 **uppan**（up + on 的合并形式），本义“在上面”，是 up + on 的合写；与 on 同源。
- **同根词**：up（古英语 up 向上）、on（古英语 on 在…上）、onto（on + to = 到…上）、above（古英语 abufan 在上面）。
- **前缀·后缀**：无前后缀（复合词：up + on）。
- **同义·反义**：同义 on；反义 beneath, under。
- **词性变化**：无派生词。

### 10. among /əˈmʌŋ/ prep. 在……当中，周围是；与……在一起
- **词根·渊源**：古英语 **on gemang**（在人群中，ge- 集合前缀 + mang 人群）→ 中古英语 *among*，本义“在人群之中→在……当中”。
- **同根词**：mingle（古英语 mengan 混合→混杂）、mongrel（mang 混合 + **-rel** 名词后缀 = 混血→杂种狗）、amongst（among + **-st** 副词性后缀 = 在…当中，变体）。
- **前缀·后缀**：前缀 **a-**（古英语 on 的弱化，例：alive, asleep）；后缀 **-st**（例：whilst, amidst）。
- **同义·反义**：同义 amidst, in the middle of；反义 无。
- **词性变化**：无派生词。

### 11. onto /ˈɑːntə/ prep. 向；朝
- **词根·渊源**：英语本土复合词，**on**（在…上）+ **to**（向），本义“到……上面去”，18世纪起广泛使用。
- **同根词**：on（古英语 on 在…上）、to（古英语 to 向）、into（in + to = 进入）、upon（up + on = 在…上）。
- **前缀·后缀**：无前后缀（复合词：on + to）。
- **同义·反义**：同义 on top of；反义 off。
- **词性变化**：无派生词。

### 12. forward /ˈfɔ:rwərd/ adv. 转寄；发送；向前；前进
- **词根·渊源**：古英语 **foreweard**（fore 前 + weard 向…方向），本义“朝前的方向→向前→转寄（向前发送）”。
- **同根词**：fore（古英语 fore 在前→前部）、forehead（fore 前 + head 头 = 前额）、before（**be-** 在 + fore 前 = 在…之前）、forecast（fore 预先 + cast 投 = 预先投出→预报）、forward（同词）。
- **前缀·后缀**：前缀 **fore-**（例：foresee, foretell）；后缀 **-ward**（例：backward, toward）。
- **同义·反义**：同义 ahead, onward；反义 backward。
- **词性变化**：forward adj. 向前的；forwardness n. 早熟；冒进。

### 13. second /ˈsekənd , sɪˈkɒnd/ n. 秒(时间单位)
- **词根·渊源**：拉丁 **secund-**（第二，来自 sequi 跟随）→ 拉丁 *secunda*（第二的）→ 古法语 *seconde*，本义“第二→秒（一小时的第二次细分，即分之后再分）”。
- **同根词**：sequence（sequ 跟随 + **-ence** 名词后缀 = 跟随的顺序→序列）、consequence（**con-** 共同 + sequ 跟随 + **-ence** = 随之而来的→结果）、subsequent（**sub-** 在下 + sequ 跟随 + **-ent** = 随后来的→随后的）、pursue（**pur-** 向前 + sue 跟随 = 追随→追求）。
- **前缀·后缀**：前缀 **con-**（例：connect, conclude）；名词后缀 **-ence**（例：difference, silence）。
- **同义·反义**：同义 moment, instant；反义 无。
- **词性变化**：second adj. 第二的；secondly adv. 其次。

### 14. relaxed /rɪˈlækst/ adj. 放松的;自在的;冷静的
- **词根·渊源**：拉丁 **lax-**（松，来自 laxus 松的）→ 拉丁 *relaxare*（放松）→ 英语 relax + **-ed**，本义“被放松的→放松的”。
- **同根词**：relax（**re-** 加强 + lax 松 = 使松→放松）、lax（拉丁 laxus 松的→松弛的）、laxative（lax 松 + **-ative** …的 = 使松的→通便的）、release（**re-** 回 + lease 松 = 松开→释放）。
- **前缀·后缀**：前缀 **re-**（例：return, rebuild）；形容词后缀 **-ed**（例：tired, excited）。
- **同义·反义**：同义 calm, easy；反义 tense, nervous。
- **词性变化**：relax v. 放松；relaxation n. 放松。

### 15. ahead of /əˈhed əv/ n. 在……前面；领先
- **同义搭配**：in front of / in advance of / leading
- **反义搭配**：behind / at the back of

### 16. beat(beat) /bit/ v. 打败；战胜；赢
- **词根·渊源**：古英语 **beatan**（打、敲击）→ 中古英语 *beten*，本义“打→打击→打败”；与 battle 同源。
- **同根词**：battle（拉丁 battuere 打→古法语 bataille 战斗→战役）、battery（battre 打 + **-ery** 名词后缀 = 打击→电池组）、combat（**com-** 共同 + bat 打 = 一起打→战斗）、abate（**a-** 向 + bate 打 = 打下去→减弱）。
- **前缀·后缀**：前缀 **com-**（例：combine, compare）；名词后缀 **-ery**（例：bakery, bravery）。
- **同义·反义**：同义 defeat, win；反义 lose。
- **词性变化**：beat n. 节拍；beaten adj. 被打败的。

### 17. still /stɪl/ adj. 平静的；安静的；宁静的，寂静的
- **词根·渊源**：古英语 **stille**（不动的、安静的）→ 中古英语 *still*，本义“不动的→静止的→平静的”；与 stall（停住）同源。
- **同根词**：stillness（still + **-ness** 名词后缀 = 静止）、stall（古英语 steall 位置→停住→ stalls 摊位）、install（**in-** 进入 + stall 位置 = 安置→安装）。
- **前缀·后缀**：名词后缀 **-ness**（例：kindness, darkness）；前缀 **in-**（例：include, invent）。
- **同义·反义**：同义 calm, quiet；反义 noisy, moving。
- **词性变化**：stillness n. 静止；still adv. 仍然。

### 18. single /ˈsɪŋɡəl/ adj. 仅一个的；单个的；单身的
- **词根·渊源**：拉丁 **singul-**（单个，来自 singulus 一个的）→ 古法语 *sengle* → 中古英语 *single*，本义“一个的→单个的→单身的”。
- **同根词**：singular（singul- 单个 + **-ar** …的 = 单数的→奇特的）、singles（single + **-s** 复数 = 单打比赛）、simple（拉丁 simplus 单一的→简单的）、simplicity（simpl- 简单 + **-icity** 名词后缀 = 简单）。
- **前缀·后缀**：形容词后缀 **-ar**（例：similar, familiar）；名词后缀 **-ity**（例：activity, ability）。
- **同义·反义**：同义 sole, unmarried；反义 double, married。
- **词性变化**：single n. 单打；singles n. 单打比赛；singular adj. 单数的。

### 19. victory /ˈvɪktəri/ n. 胜利；成功
- **词根·渊源**：拉丁 **vinc- / vict-**（征服、战胜）→ 拉丁 *victoria*（胜利）→ 古法语 *victorie* → 英语 victory；本义“战胜对手的行为”，引申为“胜利、成功”。
- **同根词**：victor（vict 战胜 + **-or** 人 = 胜利者）、invincible（**in-** 不 + vinc 战胜 + **-ible** 可…的 = 不可战胜的）、convince（**con-** 完全 + vinc 征服 = 彻底征服对方→使信服）、evict（**e-** 出 + vict 征服 = 把租户赶出去→驱逐）、victorious（victory + **-ous** …的：胜利的）。
- **前缀·后缀**：名词后缀 **-ory**（例：history, factory）；否定前缀 **in-**（例：invisible, incorrect）。
- **同义·反义**：同义 triumph, success；反义 defeat, failure。
- **词性变化**：victorious adj. 胜利的；victor n. 胜利者；victimize v. 使受害。

### 20. England /ˈɪŋɡlənd/ n. 英格兰
- **词根·渊源**：古英语 *Englaland*，由 **Engle**（盎格鲁人，日耳曼部族名）+ **land**（土地）构成，本义“盎格鲁人的土地”；盎格鲁人来自今德国北部 Angeln 地区，部族名可能源自“狭窄”（指其居住的狭长半岛），存疑。
- **同根词**：English（Engle 盎格鲁人 + **-ish** …的 = 盎格鲁人的→英语/英格兰的）、Anglo-（Angl 盎格鲁 + 组合形式 = 英国的，如 Anglo-Saxon）、land（单纯词：土地）、landlord（land 土地 + lord 主人 = 地主）、island（与 land 同源，但拼写受拉丁 insula 影响，存疑）。
- **前缀·后缀**：无前缀；后缀 **-ish**（例：Spanish, foolish）；复合成分 **land**（例：homeland, farmland）。
- **同义·反义**：同义 Britain（泛指英国，非精确同义）；反义 无。
- **词性变化**：English adj. 英格兰的；n. 英语；Englishman n. 英格兰人。

### 21. lucky /ˈlʌki/ adj. 运气好的;幸运的;带来好运的
- **词根·渊源**：中古荷兰语 **luc**（好运、幸福）→ 中古低地德语 *lucke* → 英语 luck（运气）+ **-y**（…的）；本义“有好运的”，引申为“幸运的、带来好运的”。
- **同根词**：luck（单纯词：运气）、luckily（lucky + **-ly** …地 = 幸运地）、unlucky（**un-** 不 + lucky = 不幸的）、misfortune（**mis-** 坏 + fortune 运气 = 不幸，与 luck 同义不同源）、lucky charm（lucky + charm 护身符 = 幸运符）。
- **前缀·后缀**：形容词后缀 **-y**（例：rainy, healthy）；否定前缀 **un-**（例：unhappy, unfair）。
- **同义·反义**：同义 fortunate, blessed；反义 unlucky, unfortunate。
- **词性变化**：luck n. 运气；luckily adv. 幸运地；unlucky adj. 不幸的。

### 22. survey /ˈsɜːrve/ v. 调查；查看
- **词根·渊源**：拉丁 **super-**（在上）+ **vid-**（看）→ 盎格鲁-法语 *surveier* → 英语 survey；本义“从上方俯视、察看”，引申为“调查、测量”。
- **同根词**：visible（vis 看 + **-ible** 可…的 = 可见的）、vision（vis 看 + **-ion** 名词 = 视力/远见）、supervise（**super-** 在上 + vis 看 = 从上面看→监督）、video（拉丁 videre 看 = 视频）、evident（**e-** 出 + vid 看 = 看得出来的→明显的）。
- **前缀·后缀**：前缀 **sur-**（= super-，例：surface, surpass）；名词后缀 **-ey**（例：journey, attorney）。
