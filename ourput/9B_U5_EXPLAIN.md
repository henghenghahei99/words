## 二、逐词说文解字

### 1. announcement /ə'naʊnsmənt/ n. 公告；通告
- **词根·渊源**：拉丁 **nuntius**（消息、信使）→ 拉丁 *annuntiare*（宣告）→ 古法语 *anoncier* → 英语 announce + 名词后缀 **-ment**；本义“使消息传开”，引申为“公告、通告”。
- **同根词**：announce（**an-** 向 + nounce 消息 = 向人报信→宣布）、pronounce（**pro-** 向前 + nounce 说 = 说出声→发音）、denounce（**de-** 向下 + nounce 说 = 贬说→谴责）、renounce（**re-** 回 + nounce 说 = 收回声明→放弃）。
- **前缀·后缀**：名词后缀 **-ment**（例：movement, agreement）；动词前缀 **an-**（例：announce）、**pro-**（例：pronounce）。
- **同义·反义**：同义 notice, declaration；反义 无。
- **词性变化**：announce v. 宣布；announcer n. 播音员。

### 2. passport /ˈpɑːspɔːt/ n. 护照
- **词根·渊源**：拉丁 **porta**（门、港口）→ 古法语 *port*（港口）→ 英语 pass + port；本义“通过港口的通行证”，后指“护照”。
- **同根词**：port（port 港口 = 港口）、porter（port 港口 + **-er** 人 = 搬运工）、import（**im-** 入 + port 运 = 运进来→进口）、export（**ex-** 出 + port 运 = 运出去→出口）、transport（**trans-** 越过 + port 运 = 运过去→运输）。
- **前缀·后缀**：无前后缀（复合词 pass + port）。
- **同义·反义**：同义 travel document；反义 无。
- **词性变化**：无。

### 3. the Pacific /ðə pəˈsɪfɪk/ n. 太平洋
- **同义搭配**：the Pacific Ocean
- **反义搭配**：无

### 4. Canada /ˈkænədə/ n. 加拿大
- **词根·渊源**：休伦-易洛魁语 **kanata**（村落、聚居地）→ 法语 *Canada* → 英语 Canada；1535 年法国探险家卡蒂埃误用此词指称当地，后成为国名，本义“村落”引申为“加拿大”。
- **同根词**：Canadian（Canada + **-ian** 人/的 = 加拿大人/加拿大的）。
- **前缀·后缀**：无前后缀（专有名词）。
- **同义·反义**：同义 无；反义 无。
- **词性变化**：Canadian adj. 加拿大的；n. 加拿大人。

### 5. resort /rɪˈzɔːrt/ n. 度假地
- **词根·渊源**：拉丁 **sort-**（命运、种类）→ 古法语 *resort*（回去、常去之处）→ 英语 resort；本义“常去的地方”，引申为“度假地”。
- **同根词**：sort（sort 种类 = 种类）、assort（**as-** 向 + sort 种类 = 分类→搭配）、consort（**con-** 共同 + sort 命运 = 共命运→配偶）。
- **前缀·后缀**：前缀 **re-**（例：return, recall）。
- **同义·反义**：同义 holiday spot；反义 无。
- **词性变化**：resort v. 常去；诉诸。

### 6. Canadian /kəˈneɪdiən/ adj. 加拿大的；加拿大人的
- **词根·渊源**：休伦-易洛魁语 **kanata**（村落）→ 法语 *Canada* → 英语 Canada + 后缀 **-ian**；本义“加拿大的人/的”，引申为“加拿大的、加拿大人的”。
- **同根词**：Canada（Canada 加拿大 = 加拿大）。
- **前缀·后缀**：形容词/名词后缀 **-ian**（例：Italian, musician）。
- **同义·反义**：同义 无；反义 无。
- **词性变化**：Canada n. 加拿大。

### 7. slope /sləʊp/ n. 斜坡；坡地
- **词根·渊源**：中古英语 *slopen*（溜走、倾斜），可能与古英语 *slūpan*（滑）有关，词源存疑；本义“倾斜”，引申为“斜坡、坡地”。
- **同根词**：sloping（slope + **-ing** …的 = 倾斜的）、slippery（与 slip 同源，滑的）。
- **前缀·后缀**：无前后缀（单纯词）。
- **同义·反义**：同义 incline, gradient；反义 无。
- **词性变化**：slope v. 倾斜；sloping adj. 倾斜的。

### 8. opposite /ˈɑːpəzɪt/ adj. 在……的对面，相反的；对面的
- **词根·渊源**：拉丁 **opponere**（放在对面）→ 拉丁 *oppositus*（对面的）→ 古法语 *opposite* → 英语 opposite；本义“被放在对面的”，引申为“对面的、相反的”。
- **同根词**：oppose（**op-** 反对 + pose 放 = 放在对面→反对）、opposition（oppose + **-ition** 名词 = 反对）、opponent（**op-** 反对 + pon 放 + **-ent** 人 = 对手）、pose（pose 放 = 摆姿势）、compose（**com-** 共同 + pose 放 = 放在一起→组成）。
- **前缀·后缀**：前缀 **op-**（例：oppose, oppress）；形容词后缀 **-ite**（例：favorite, definite）。
- **同义·反义**：同义 contrary, facing；反义 same, identical。
- **词性变化**：oppose v. 反对；opposition n. 反对；opponent n. 对手。

### 9. glove /ɡlʌv/ n.（分手指的）手套
- **词根·渊源**：古英语 **glōf**（手套），与古诺尔斯语 *glōfi* 同源，词源存疑；本义即“手套”，指分手指的手套。
- **同根词**：gloved（glove + **-ed** 戴手套的 = 戴手套的）。
- **前缀·后缀**：无前后缀（单纯词）。
- **同义·反义**：同义 mitten（连指手套）；反义 无。
- **词性变化**：gloved adj. 戴手套的。

### 10. couple /ˈkʌpl/ n. 一对夫妇
- **词根·渊源**：拉丁 **copula**（联结、纽带）→ 古法语 *cople* → 英语 couple；本义“联结在一起的两个”，引申为“一对、夫妇”。
- **同根词**：couple（couple 联结 = 一对）、couplet（couple + **-et** 小 = 对联）、copula（copula 联结 = 系词）、coupling（couple + **-ing** 名词 = 联结）。
- **前缀·后缀**：无前后缀（单纯词）。
- **同义·反义**：同义 pair, twosome；反义 single。
- **词性变化**：couple v. 连接；coupled adj. 连接的。

### 11. gentle /ˈdʒentl/ adj. 平缓的
- **词根·渊源**：拉丁 **gens / gent-**（氏族、出身）→ 古法语 *gentil*（出身高贵的）→ 英语 gentle；本义“出身高贵的”，引申为“温和的、平缓的”。
- **同根词**：gentleman（gentle 高贵 + man 人 = 绅士）、gently（gentle + **-ly** 地 = 温和地）、gentry（gent + **-ry** 阶层 = 绅士阶层）、generous（gener 出身 + **-ous** 高贵的→慷慨的）、genuine（genu 出生 + **-ine** 天生的→真正的）。
- **前缀·后缀**：形容词后缀 **-le**（例：little, noble）。
- **同义·反义**：同义 mild, soft；反义 steep, harsh。
- **词性变化**：gently adv. 温和地；gentleness n. 温和。

### 12. honest /ˈɑ:nɪst/ adj. 诚实的；老实的；正直的
- **词根·渊源**：拉丁 **honos / honor-**（荣誉）→ 古法语 *honeste* → 英语 honest；本义“有荣誉的”，引申为“诚实的、正直的”。
- **同根词**：honor（honor 荣誉 = 荣誉）、honesty（honest + **-y** 名词 = 诚实）、honorable（honor + **-able** 可…的 = 可敬的）、dishonest（**dis-** 不 + honest = 不诚实的）。
- **前缀·后缀**：形容词后缀 **-est**（例：modest）；否定前缀 **dis-**（例：dishonest, disagree）。
- **同义·反义**：同义 truthful, sincere；反义 dishonest, deceitful。
- **词性变化**：honesty n. 诚实；honestly adv. 诚实地；dishonest adj. 不诚实的。

### 13. rope /roʊp/ v. 绳子，绳索
- **词根·渊源**：古英语 **rāp**（绳），与古诺尔斯语 *reip* 同源，词源存疑；本义“绳”，动词义“用绳捆”。
- **同根词**：ropy（rope + **-y** …的 = 绳状的）、roped（rope + **-ed** 用绳围的 = 用绳围的）。
- **前缀·后缀**：无前后缀（单纯词）。
- **同义·反义**：同义 cord, line；反义 无。
- **词性变化**：rope n. 绳子；ropy adj. 绳状的。

### 14. rapid /ˈræpɪd/ adj. 迅速的；快速的
- **词根·渊源**：拉丁 **rapere**（夺取、急速带走）→ 拉丁 *rapidus*（急速的）→ 法语 *rapide* → 英语 rapid；本义“急速夺取的”，引申为“迅速的”。
- **同根词**：rape（rap 夺取 = 掠夺）、rapture（rapt 夺取 + **-ure** 名词 = 被夺走心神→狂喜）、ravish（rav 夺取 + **-ish** 动词 = 夺走→使狂喜）、rapidly（rapid + **-ly** 地 = 迅速地）。
- **前缀·后缀**：形容词后缀 **-id**（例：valid, vivid）。
- **同义·反义**：同义 fast, quick；反义 slow。
- **词性变化**：rapidly adv. 迅速地；rapidity n. 迅速。

### 15. over /ˈəʊvə(r)/ adv. 结束；穿过；多于
- **词根·渊源**：古英语 **ofer**（在上方、越过），与德语 *über* 同源，出自 PIE *uper*（在上）；本义“在上方”，引申为“越过、结束、多于”。
- **同根词**：overcome（over 越过 + come 来 = 克服）、overlook（over 在上 + look 看 = 俯视→忽视）、overcoat（over 在上 + coat 外套 = 大衣）、overdo（over 过度 + do 做 = 做得过分）。
- **前缀·后缀**：前缀 **over-**（例：overcome, overlook）。
- **同义·反义**：同义 above, across；反义 under。
- **词性变化**：over prep. 在……上方；overly adv. 过度地。

### 16. shame /ʃem/ v. 可惜；遗憾
- **词根·渊源**：古英语 **sceamu**（羞耻），与古诺尔斯语 *skömm* 同源，出自 PIE *kem-*（遮盖）；本义“羞耻”，引申为“可惜、遗憾”。
- **同根词**：shameful（shame + **-ful** 充满…的 = 可耻的）、shameless（shame + **-less** 无…的 = 无耻的）、ashamed（**a-** 使 + shame 羞 = 感到羞耻的）。
- **前缀·后缀**：形容词后缀 **-ful**（例：helpful）、**-less**（例：hopeless）；前缀 **a-**（例：asleep, alive）。
- **同义·反义**：同义 pity, disgrace；反义 honor, pride。
- **词性变化**：shameful adj. 可耻的；shameless adj. 无耻的；ashamed adj. 羞愧的。

### 17. fee /fiː/ n. 费用
- **词根·渊源**：古英语 **feoh**（牲畜、财产），与德语 *Vieh* 同源，出自 PIE *peku-*（牲畜）；本义“牲畜（财富）”，引申为“费用、酬金”。

### 18. enter /ˈentə(r)/ v. 报名参加
- **词根·渊源**：拉丁 **intra**（在内）→ 拉丁 *intrare*（进入）→ 古法语 *entrer* → 英语 enter；本义“进入”，引申为“报名参加”。
- **同根词**：entrance（enter + **-ance** 名词 = 入口）、entry（enter + **-y** 名词 = 进入→条目）、enterprise（**enter-** 进入 + prise 拿 = 着手做→企业）。

### 19. semi-final /ˌsemi ˈfaɪnl/ adj. 半决赛
- **词根·渊源**：拉丁 **semi-**（一半）+ 拉丁 **finis**（终点、界限）→ 古法语 *final* → 英语 final；semi-final 即“走到终点前一半的（比赛）”，引申为“半决赛”。
- **同根词**：final（fin 终点 + **-al** …的 = 终点的→决赛的）、finale（fin 终点 + **-ale** 名词后缀 = 终场→终曲）、finish（古法语 *finir* 结束 ← fin 终点 = 结束）、finance（fin 结算 + **-ance** 名词后缀 = 结清账目→财政）、semicircle（**semi-** 半 + circle 圆 = 半圆）、semiconductor（**semi-** 半 + conductor 导体 = 半导体）。
- **前缀·后缀**：前缀 **semi-**（例：semicircle, semiconductor）；形容词后缀 **-al**（例：final, natural）。
- **同义·反义**：同义 last-four match；反义 final（决赛）。
- **词性变化**：final n. 决赛；finalist n. 决赛选手；semifinalist n. 半决赛选手。

### 20. final /ˈfaɪnl/ adj. 决赛
- **词根·渊源**：拉丁 **finis**（终点、界限）→ 拉丁 *finalis*（终点的）→ 古法语 *final* → 英语；本义“属于终点的”，引申为“最后的”，名词化后指“决赛”。
- **同根词**：finish（古法语 *finir* 结束 ← fin 终点 = 结束）、finite（fin 界限 + **-ite** …的 = 有界限的→有限的）、infinite（**in-** 不 + finite 有限的 = 无限的）、define（**de-** 彻底 + fin 界限 = 划定界限→定义）、finance（fin 结算 + **-ance** 名词后缀 = 结清账目→财政）、finale（fin 终点 + **-ale** 名词后缀 = 终场→终曲）。
- **前缀·后缀**：前缀 **in-**（例：infinite, incorrect）；形容词后缀 **-al**（例：natural, national）。
- **同义·反义**：同义 last, ultimate；反义 first, initial。
- **词性变化**：finally adv. 最后；finalist n. 决赛选手；finalize v. 最终确定。

### 21. badminton /ˈbædmɪntən/ n. 羽毛球运动
- **词根·渊源**：源自英国格洛斯特郡的庄园 **Badminton House**（巴德明顿庄园），19世纪驻印度的英国军官把类似羽毛球的游戏带回此庄园表演，运动遂以庄园名命名；庄园名本身源自古英语人名 *Baduhelm* + **-tun**（围场、村落）。
- **同根词**：本词为专有地名转化词，无常用同根派生词；相关运动词 shuttlecock（shuttle 梭子 + cock 公鸡 = 像公鸡羽毛做的梭子→羽毛球）、racket（阿拉伯语 *rāḥat* 手掌 → 古法语 *raquette* = 球拍）。
- **前缀·后缀**：无前后缀（单纯词，由地名整体借入）。
- **同义·反义**：同义 the game of badminton；反义 无。
- **词性变化**：badminton player n. 羽毛球运动员。

### 22. stress /strɛs/ n. 精神压力；心理负担；紧张
- **词根·渊源**：拉丁 **strictus**（拉紧的，*stringere* 拉紧的过去分词）→ 古法语 *destresse*（压迫、困苦）→ 中古英语 *destresse* 缩略为 *stresse*；本义“被拉紧的状态”，引申为“精神上的紧绷→压力、紧张”。
- **同根词**：strict（strict 拉紧的 = 严格的）、restrict（**re-** 回 + strict 拉紧 = 拉回→限制）、district（**dis-** 分开 + strict 拉紧 = 划出的拉紧区域→地区）、strain（拉丁 *stringere* 拉紧 → 古法语 *estreindre* = 拉紧→紧张）、distress（**dis-** 分开 + stress 拉紧 = 被扯开→痛苦）、stringent（string 拉紧 + **-ent** …的 = 严格的）。
- **前缀·后缀**：前缀 **dis-**（例：distress, distract）、**re-**（例：restrict, return）。
- **同义·反义**：同义 pressure, tension, strain；反义 relaxation, calm。
- **词性变化**：stressful adj. 有压力的；stressed adj. 感到压力的；distress n. 痛苦。
