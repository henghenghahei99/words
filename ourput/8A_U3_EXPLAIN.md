## 二、逐词说文解字

### 1. order /ˈɔːrdər/ n. 点餐；订货；订购
- **词根·渊源**：拉丁 **ordo / ordin-**（顺序、行列）→ 古法语 *ordre* → 英语 order；本义“排列好的次序”，引申为“命令、订购（按次序安排）”，再引申为“点餐、订货”。
- **同根词**：ordinary（ordin 次序 + **-ary** …的 = 按常规次序的→普通的）、organize（organ 源自 ordin 变体“安排” + **-ize** 使…化 = 使有条理→组织）、ornament（orn 源自 ordin 变体“装饰排列” + **-ment** 名词后缀 = 装饰品）。
- **前缀·后缀**：无前缀；名词后缀 **-er**（例：teacher, worker）。
- **同义·反义**：同义 command, sequence；反义 disorder, chaos。
- **词性变化**：orderly adj. 有秩序的；disorder n. 混乱。

### 2. compare /kəmˈper/ v. 比较；对比
- **词根·渊源**：拉丁 **comparare**（com- 共同 + par 相等 = 使相等、配对）→ 古法语 *comparer* → 英语 compare；本义“把两物放在一起看是否相等”，引申为“比较、对比”。
- **同根词**：comparison（compar 比较 + **-ison** 名词后缀 = 比较）、comparable（compar 比较 + **-able** 可…的 = 可比较的）、peer（par 相等 → 同辈、同等的人）、parity（par 相等 + **-ity** 名词后缀 = 平等）。
- **前缀·后缀**：前缀 **com-**（共同）（例：combine, connect）；无后缀。
- **同义·反义**：同义 contrast, liken；反义 无。
- **词性变化**：comparison n. 比较；comparable adj. 可比较的。

### 3. monitor /ˈmɑ:nɪtə(r)/ n.（计算机）显示器；班长；监督员
- **词根·渊源**：拉丁 **monere / monit-**（警告、提醒）→ 英语 monitor；本义“提醒者、告诫者”，引申为“监督员、班长”，再因显示器“提醒、显示信息”的功能引申为“显示器”。
- **同根词**：monition（monit 警告 + **-ion** 名词后缀 = 告诫）、admonish（**ad-** 向 + mon 警告 + **-ish** 动词后缀 = 向人警告→告诫）、monument（mon 提醒 + **-ment** 名词后缀 = 提醒后人的东西→纪念碑）、summon（**sum-** 在下 + mon 提醒 = 从下面提醒→召唤）。
- **前缀·后缀**：无前缀；名词后缀 **-or**（例：actor, doctor）。
- **同义·反义**：同义 screen, supervisor；反义 无。
- **词性变化**：monitor v. 监控；monitoring n. 监控。

### 4. speaker /ˈspiːkər/ n. 发言者，演讲者；说话者；讲某种语言的人；扬声器，喇叭
- **词根·渊源**：古英语 **specan / sprecan**（说）→ 中古英语 *speken* → 英语 speak + **-er**（者/物）；本义“说话的人”，引申为“发言者、讲某种语言的人”，再引申为“发出声音的装置→扬声器”。
- **同根词**：speech（speak 的名词形式，古英语 *spæc* = 说话→演讲）、bespeak（**be-** 加强 + speak 说 = 预先说→预订）、spokesman（spoke 说 + man 人 = 发言人）。
- **前缀·后缀**：无前缀；名词后缀 **-er**（例：teacher, singer）。
- **同义·反义**：同义 orator, lecturer；反义 listener, audience。
- **词性变化**：speak v. 说话；speech n. 演讲。

### 5. main unit /meɪn ˈjuːnɪt/ n. （计算机）主机；主要部件
- **同义搭配**：central processing unit / system unit / main component
- **反义搭配**：peripheral device / external device

### 6. keyboard /ˈki:bɔ:rd/ n. 键盘式电子乐器；键盘
- **词根·渊源**：key 源自古英语 **cæg**（钥匙）→ 中古英语 *keye*，引申为“按键”；board 源自古英语 **bord**（木板）→ 中古英语 *boord*；合成 key + board = “装有按键的板”，即“键盘”，再引申为“键盘式电子乐器”。
- **同根词**：keyboardist（keyboard 键盘 + **-ist** 人 = 键盘手）、keyhole（key 钥匙 + hole 孔 = 锁孔）、keynote（key 关键 + note 音符 = 主音→主旨）、blackboard（black 黑 + board 板 = 黑板）、aboard（**a-** 在 + board 板 = 在船上）。
- **前缀·后缀**：无前缀；无后缀（复合词）。
- **同义·反义**：同义 keypad；反义 无。
- **词性变化**：keyboard v. 用键盘输入；keyboardist n. 键盘手。

### 7. mouse /maʊs/ n.（计算机）鼠标；老鼠，耗子
- **词根·渊源**：古英语 **mūs**（老鼠）→ 中古英语 *mous* → 英语 mouse；本义“老鼠”，因计算机鼠标外形似老鼠、带“尾巴”（线）而引申为“鼠标”。
- **同根词**：mice（mouse 的复数，古英语 *mȳs* 元音变化）、mousetrap（mouse 鼠 + trap 陷阱 = 捕鼠器）、mousy（mouse 鼠 + **-y** …的 = 像鼠的→胆小的）。
- **前缀·后缀**：无前后缀（单纯词）。
- **同义·反义**：同义 rodent, pointer；反义 无。
- **词性变化**：mice n. 老鼠（复数）；mousy adj. 胆小的。

### 8. type /taɪp/ n. 打字
- **词根·渊源**：希腊 **typos**（印记、模型）→ 拉丁 *typus* → 古法语 *type* → 英语 type；本义“印出的模型、字样”，引申为“类型、打字（用字模印出）”，此处名词义“打字”。
- **同根词**：typical（typ 类型 + **-ical** …的 = 典型的）、typewriter（type 打字 + writer 书写者 = 打字机）、typist（typ 打字 + **-ist** 人 = 打字员）、prototype（**proto-** 原始 + type 模型 = 原型）、typography（typo 字 + graph 写 + **-y** 名词后缀 = 排版术）。
- **前缀·后缀**：无前缀；无后缀（单纯词）。
- **同义·反义**：同义 kind, print；反义 无。
- **词性变化**：typical adj. 典型的；typist n. 打字员。

### 9. brain /breɪn/ n. 大脑；智力；脑力
- **词根·渊源**：古英语 **brægen**（脑）→ 中古英语 *brain* → 英语 brain；本义“大脑”，引申为“智力、脑力”。
- **同根词**：brainy（brain 脑 + **-y** …的 = 聪明的）、brainstorm（brain 脑 + storm 风暴 = 头脑风暴）、brainwash（brain 脑 + wash 洗 = 洗脑）。
- **前缀·后缀**：无前后缀（单纯词）。
- **同义·反义**：同义 mind, intellect；反义 无。
- **词性变化**：brainy adj. 聪明的；brainless adj. 无脑的。

### 10. control /kənˈtroʊl/ n. 操作；操纵；控制，支配
- **词根·渊源**：古法语 **contrerolle**（对照登记册，contre- 对照 + rolle 卷册）→ 中古英语 *controllen* → 英语 control；本义“用副本核对账目”，引申为“核查、管理”，再引申为“控制、操纵”。
- **同根词**：controller（control 控制 + **-er** 者 = 控制器）、controlled（control 控制 + **-ed** …的 = 受控的）、roll（rolle 卷册 → 卷、滚动）。
- **前缀·后缀**：前缀 **contra-**（对照、相反）（例：contrast, contradict）；无后缀。
- **同义·反义**：同义 manage, regulate；反义 release, free。
- **词性变化**：controller n. 控制器；controlled adj. 受控的。

### 11. expensive /ɪkˈspensɪv/ adj. 昂贵的；价格高的；花钱多的
- **词根·渊源**：拉丁 **expendere**（ex- 出 + pend 称量、支付 = 付出称量→花费）→ 拉丁 *expensa*（花费）→ 英语 expense + **-ive**（…的）；本义“花费多的”，即“昂贵的”。
- **同根词**：expense（ex 出 + pens 支付 + **-e** = 支出→费用）、expend（ex 出 + pend 支付 = 花费）、expenditure（expend 花费 + **-iture** 名词后缀 = 支出）、pension（pens 支付 + **-ion** 名词后缀 = 支付的款项→养老金）、compensate（**com-** 共同 + pens 支付 + **-ate** 动词后缀 = 一起支付→补偿）。
- **前缀·后缀**：前缀 **ex-**（出）（例：export, exit）；形容词后缀 **-ive**（例：active, creative）。
- **同义·反义**：同义 costly, dear；反义 cheap, inexpensive。
- **词性变化**：expense n. 费用；expensively adv. 昂贵地。

### 12. tiny /ˈtaɪni/ adj. 极小的；微小的
- **词根·渊源**：中古英语 **tine**（小、微小）→ 英语 tiny；词源存疑，一说与 tine（尖齿）有关，15世纪起表“极小的”。
- **同根词**：无常用同根词（存疑）。
- **前缀·后缀**：无前缀；形容词后缀 **-y**（例：happy, rainy）。
- **同义·反义**：同义 small, minute；反义 huge, enormous。
- **词性变化**：tininess n. 微小。

### 13. depend /dɪˈpɛnd/ v. 依靠；信赖；取决于
- **词根·渊源**：拉丁 **dependere**（de- 向下 + pend 悬挂 = 悬挂于下）→ 古法语 *dependre* → 英语 depend；本义“悬挂在…之下”，引申为“依靠、取决于”。
- **同根词**：dependent（depend 依靠 + **-ent** …的 = 依赖的）、dependence（depend 依靠 + **-ence** 名词后缀 = 依赖）、independent（**in-** 不 + dependent 依赖的 = 独立的）、pendant（pend 悬挂 + **-ant** 物 = 悬挂物→吊坠）、suspend（**sus-** 在下 + pend 悬挂 = 悬吊→暂停）。
- **前缀·后缀**：前缀 **de-**（向下）（例：descend, decline）；无后缀。
- **同义·反义**：同义 rely, trust；反义 无。
- **词性变化**：dependent adj. 依赖的；dependence n. 依赖；independent adj. 独立的。

### 14. calculate /ˈkælkjuleɪt/ v. 计算，核算；预测，推测
- **词根·渊源**：拉丁 **calculus**（小石子，用于计数）→ 拉丁 *calculare*（用石子计数）→ 英语 calculate；本义“用小石子计数”，引申为“计算、推测”。
- **同根词**：calculation（calcul 计算 + **-ation** 名词后缀 = 计算）、calculator（calcul 计算 + **-ator** 物 = 计算器）、calculus（calcul 石子 + **-us** 名词后缀 = 微积分；结石）、incalculable（**in-** 不 + calculable 可计算的 = 不可估量的）。
- **前缀·后缀**：无前缀；动词后缀 **-ate**（例：create, educate）。
- **同义·反义**：同义 compute, reckon；反义 guess, estimate（存疑）。
- **词性变化**：calculation n. 计算；calculator n. 计算器。

### 15. speed /spiːd/ v. 速度；超速行驶
- **词根·渊源**：古英语 **spēd**（成功、迅速）→ 中古英语 *spede* → 英语 speed；本义“成功、 prosper”，引申为“迅速”，再引申为“速度、超速行驶”。
- **同根词**：speedy（speed 迅速 + **-y** …的 = 迅速的）、speedily（speed 迅速 + **-ily** 副词后缀 = 迅速地）、speedometer（speed 速度 + meter 测量仪 = 速度计）、speedway（speed 速度 + way 路 = 高速公路）。
- **前缀·后缀**：无前后缀（单纯词）。
- **同义·反义**：同义 velocity, pace；反义 slowness。
- **词性变化**：speedy adj. 迅速的；speedily adv. 迅速地。

### 16. operate /ˈɑːpəreɪt/ v. 操纵，操作（机器或设备）；控制；（机器等）运转，运行
- **词根·渊源**：拉丁 **operari / operat-**（工作、劳作，源自 opus 工作）→ 拉丁 *operatus* → 英语 operate；本义“工作、劳作”，引申为“操作机器、运转”。
- **同根词**：operation（operat 工作 + **-ion** 名词后缀 = 操作、手术）、operator（operat 操作 + **-or** 人 = 操作员）、operatic（opera 歌剧 + **-tic** …的 = 歌剧的）、opus（拉丁 opus 作品 = 作品）、cooperate（**co-** 共同 + oper 工作 + **-ate** 动词后缀 = 合作）。
- **前缀·后缀**：无前缀；动词后缀 **-ate**（例：create, calculate）。
- **同义·反义**：同义 run, control；反义 无。
- **词性变化**：operation n. 操作；operator n. 操作员；cooperate v. 合作。

### 17. railway /ˈrelˌwe/ n. 铁路；铁道；铁路系统
- **词根·渊源**：rail 源自古法语 **reille**（铁条、横杆）→ 英语 rail（铁轨）；way 源自古英语 **weg**（道路）→ 英语 way；合成 rail + way = “铺铁轨的路”，即“铁路”。
- **同根词**：railroad（rail 铁轨 + road 路 = 铁路，美式）、railing（rail 栏杆 + **-ing** 名词后缀 = 栏杆）、railcar（rail 铁轨 + car 车 = 轨道车）、highway（high 高 + way 路 = 公路）、subway（**sub-** 下 + way 路 = 地铁）。
- **前缀·后缀**：无前缀；无后缀（复合词）。
- **同义·反义**：同义 railroad, track；反义 无。
- **词性变化**：rail n. 铁轨；railroad n. 铁路。

### 18. company /ˈkʌmpəni/ n. 公司
- **词根·渊源**：拉丁 **companio**（com- 共同 + panis 面包 = 一起吃面包的人→同伴）→ 古法语 *compagnie*（同伴团体）→ 英语 company；本义“同伴、一群人”，引申为“公司（一群人组成的团体）”。
- **同根词**：companion（compan 同伴 + **-ion** 人 = 同伴）、accompany（**ac-** 向 + company 同伴 = 陪伴）、panis（拉丁“面包”→ 存疑，英语中无常用派生）、pantry（pan 面包 + **-try** 名词后缀 = 面包房→食品储藏室）。
- **前缀·后缀**：前缀 **com-**（共同）（例：combine, compare）；名词后缀 **-y**（例：family, memory）。
- **同义·反义**：同义 firm, corporation；反义 无。
- **词性变化**：companion n. 同伴；accompany v. 陪伴。

### 19. price /praɪs/ n. 价格，价钱
- **词根·渊源**：拉丁 **pretium**（价值、报酬）→ 古法语 *pris*（价值、价格）→ 英语 price；本义“某物所值的报酬”，引申为“价格、价钱”。
- **同根词**：precious（preti 价值 + **-ous** …的 = 有价值的→珍贵的）、appreciate（**ap-** 加强 + preti 价值 + **-ate** 动词后缀 = 看出价值→欣赏、感激）、depreciate（**de-** 下降 + preti 价值 + **-ate** = 价值下降→贬值）、praise（经古法语 preisier 评价→称赞，与 price 同源）。
- **前缀·后缀**：无前后缀（单纯词）。
- **同义·反义**：同义 cost, charge；反义 无。
- **词性变化**：priceless adj. 无价的；priced adj. 标价的；overprice v. 定价过高。

### 20. total /ˈtoʊtl/ adj. 总数；合计；总的；总体的
- **词根·渊源**：拉丁 **totus**（全部的、整个的）→ 中世纪拉丁 *totalis* → 古法语 *total* → 英语 total；本义“全部的”，引申为“总的、总体的”，再作名词“总数”。
- **同根词**：totally（total + **-ly** 副词后缀 = 完全地）、totality（total + **-ity** 名词后缀 = 全体、总数）、subtotal（**sub-** 在下 + total = 小计）、totalitarian（total + **-itarian** 形容词后缀 = 总体的→极权的）。
- **前缀·后缀**：形容词后缀 **-al**（例：final, normal）。
- **同义·反义**：同义 whole, entire, sum；反义 partial, partial。
- **词性变化**：totally adv. 完全地；totality n. 全体；total v. 合计。

### 21. inch /ɪntʃ/ n. 英寸
- **词根·渊源**：拉丁 **uncia**（十二分之一）→ 古英语 *ynce* → 英语 inch；本义“一英尺的十二分之一”，即“英寸”。
- **同根词**：ounce（经古法语 unce，同出拉丁 uncia 十二分之一→盎司）、uncial（拉丁 uncia 十二分之一 + **-al** …的 = 一英寸高的→安色尔字体的）。
- **前缀·后缀**：无前后缀（单纯词）。
- **同义·反义**：同义 无；反义 无。
- **词性变化**：inched adj. 有…英寸的；inch v. 缓慢移动。

### 22. sell /sɛl/ v. 出售；售卖；销售
- **词根·渊源**：古英语 **sellan**（给予、交出）→ 中古英语 *sellen* → 英语 sell；本义“交出、给予”，引申为“出售、售卖”。
- **同根词**：seller（sell + **-er** 人 = 卖者）、sale（sell 的名词形式，古英语 sala 出售）、best-seller（best 最好 + seller 卖者 = 畅销品）。
- **前缀·后缀**：无前后缀（单纯词）。
- **同义·反义**：同义 trade, vend；反义 buy, purchase。
- **词性变化**：sale n. 出售；seller n. 卖者；sold adj. 售出的。

### 23. popular /ˈpɒpjələ(r)/ adj. 受喜爱的；受欢迎的
- **词根·渊源**：拉丁 **populus**（人民）→ 拉丁 *popularis*（人民的）→ 英语 popular；本义“属于人民的”，引申为“大众喜爱的、受欢迎的”。
- **同根词**：population（popul 人民 + **-ation** 名词后缀 = 人口）、populate（popul 人民 + **-ate** 动词后缀 = 使有人居住）、populous（popul 人民 + **-ous** …的 = 人口稠密的）、public（与 populus 同源，公共的）。
- **前缀·后缀**：形容词后缀 **-ar**（例：similar, familiar）。
- **同义·反义**：同义 well-liked, favored；反义 unpopular, disliked。
- **词性变化**：popularity n. 受欢迎；popularly adv. 普遍地；popularize v. 使流行。
