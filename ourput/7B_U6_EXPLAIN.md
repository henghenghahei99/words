## 二、逐词说文解字

### 1. battery /ˈbætəri/ n. 电池
- **词根·渊源**：拉丁 **battuere**（打、击）→ 古法语 *batterie*（打击、连续炮击）→ 英语 battery；本义“连续打击的一群火炮”，18世纪电学借用为“一组串联的伏打电堆”，后泛指“电池”。
- **同根词**：batter（**batt-** 打 + **-er** 反复动作 = 连续猛击）、battle（batt 打 + **-le** 动作 = 战斗）、combat（**com-** 共同 + bat 打 = 互相打→战斗）、debate（**de-** 加强 + bat 打 = 用言语交锋→辩论）。
- **前缀·后缀**：名词后缀 **-ery**（例：bakery, surgery）。
- **同义·反义**：同义 cell, power pack；反义 无。
- **词性变化**：batter v. 连续猛击；battered adj.  battered 破旧的。

### 2. electricity /ɪˌlekˈtrɪsəti/ n. 电；电能
- **词根·渊源**：希腊 **ēlektron**（琥珀）→ 拉丁 *electrum* → 英语 electric + **-ity**；古人发现摩擦琥珀能吸引轻物，1600年 Gilbert 造 *electricus*“像琥珀的”，后加 -ity 成“电（能）”。
- **同根词**：electric（electr 琥珀 + **-ic** …的 = 电的）、electron（electr 琥珀 + **-on** 粒子 = 电子）、electronic（electron + **-ic** 电子的）、electrician（electric + **-ian** 人 = 电工）。
- **前缀·后缀**：名词后缀 **-ity**（例：activity, reality）；形容词后缀 **-ic**（例：basic, historic）。
- **同义·反义**：同义 power, current；反义 无。
- **词性变化**：electric adj. 电的；electrical adj. 电的；electrify v. 使 electrify 通电。

### 3. switch-off /ˈswɪtʃ ˈɒf/ adj. 关闭（电灯、机器等）的
- **词根·渊源**：中古荷兰语 *swijch*（细枝）→ 英语 switch“细枝、开关”；off 古英语 *of*“离开”；合成 switch-off 本义“把开关拨离（通电位置）”，引申为“关闭的”。
- **同根词**：switch（**switch** 细枝→开关 = 切换）、switchboard（switch 开关 + board 板 = 配电盘）、off（**off** 离开 = 关掉）、offset（off 离开 + set 放 = 抵消）。
- **前缀·后缀**：复合词无前后缀（switch + off 合成）。
- **同义·反义**：同义 turned off, powered down；反义 switch-on, turned on。
- **词性变化**：switch n. 开关；switch v. 转换；switch-off n. 关闭。

### 4. task /tɑːsk/ n. 任务；活动
- **词根·渊源**：拉丁 **taxare**（评估、征税）→ 古北法语 *tasque*（税、劳役）→ 英语 task；本义“按评估摊派的劳役”，引申为“任务、工作”。
- **同根词**：tax（**tax-** 评估 + **-∅** = 征税）、taxation（tax + **-ation** 名词 = 征税）、taxi（tax 计程 + **-i** = 计程车）、taskmaster（task 任务 + master 主人 = 监工）。
- **前缀·后缀**：无前后缀（单纯词）。
- **同义·反义**：同义 job, assignment；反义 无。
- **词性变化**：task v. 派任务；tasking n. 任务分配。

### 5. while /waɪl/ n. 一段时间；一会儿
- **词根·渊源**：古英语 **hwīl**（一段时间）→ 中古英语 *while* → 英语 while；本义“一段时间”，作名词即“一会儿”，作连词表“当……时”。
- **同根词**：whilst（while + **-st** 副词尾 = 当……时）、meanwhile（mean 中间 + while 时间 = 与此同时）、worthwhile（worth 值得 + while 时间 = 值得的）、awhile（**a-** 在 + while 时间 = 片刻）。
- **前缀·后缀**：无前后缀（单纯词）。
- **同义·反义**：同义 time, spell；反义 无。
- **词性变化**：while conj. 当……时；while v. 消磨（时间）。

### 6. tablet /ˈtæblət/ n. 平板电脑
- **词根·渊源**：拉丁 **tabula**（板、平板）→ 古法语 *tablete*（小牌）→ 英语 tablet；本义“小石板、药片”，20世纪借指“平板电脑”。
- **同根词**：table（**tabl-** 板 + **-e** = 桌子）、tabular（tabula 板 + **-ar** …的 = 表格的）、tabulate（tabula 板 + **-ate** 动词 = 列成表）、tablet（tabl 板 + **-et** 小 = 小牌→药片/平板）。
- **前缀·后缀**：名词后缀 **-et**（例：packet, pocket）。
- **同义·反义**：同义 pad, slate；反义 无。
- **词性变化**：table n. 桌子；tabular adj. 表格的。

### 7. fridge /frɪdʒ/ n. 冰箱
- **词根·渊源**：拉丁 **frigus**（寒冷）→ 英语 refrigerator 的缩略口语形式 fridge；20世纪口语截短 refrigerator，本义“使冷的东西”，即“冰箱”。
- **同根词**：refrigerator（**re-** 加强 + friger 冷 + **-ator** 物 = 冰箱）、refrigerate（re- 加强 + friger 冷 + **-ate** 动词 = 冷藏）、frigid（frig 冷 + **-id** …的 = 寒冷的）、frigidity（frigid + **-ity** 名词 = 寒冷）。
- **前缀·后缀**：无前后缀（缩略词）。
- **同义·反义**：同义 refrigerator, cooler；反义 无。
- **词性变化**：refrigerate v. 冷藏；refrigeration n. 冷藏。

### 8. yogurt /ˈjɒɡət/ n. 酸奶
- **词根·渊源**：土耳其语 **yoğurt**（凝乳）→ 英语 yogurt；本义“发酵凝乳”，即“酸奶”。
- **同根词**：yogurt（**yogurt** 凝乳 = 酸奶）、yoghurt（yogurt 变体拼写 = 酸奶）、yogurt-maker（yogurt + maker 制作者 = 酸奶机）。
- **前缀·后缀**：无前后缀（借词）。
- **同义·反义**：同义 yoghurt, curd；反义 无。
- **词性变化**：无派生词。

### 9. apartment /əˈpɑːtmənt/ n. 公寓套房
- **词根·渊源**：拉丁 **pars / part-**（部分）→ 意大利语 *appartamento*（分开的房间）→ 法语 *appartement* → 英语 apartment；本义“分隔开的一套房间”，即“公寓套房”。
- **同根词**：part（**part-** 部分 = 部分）、partial（part 部分 + **-ial** …的 = 部分的）、partner（part 部分 + **-ner** 人 = 合伙人）、apart（**a-** 分开 + part 部分 = 分开）、department（**de-** 分开 + part 部分 + **-ment** = 部门）。
- **前缀·后缀**：前缀 **a-**（例：apart, aside）；名词后缀 **-ment**（例：movement, agreement）。
- **同义·反义**：同义 flat, suite；反义 无。
- **词性变化**：apart adv. 分开地；department n. 部门。

### 10. household /ˈhaʊshəʊld/ adj. 家庭的
- **词根·渊源**：古英语 **hūs**（房屋）+ **hlāford**（家主）→ 中古英语 *household*；本义“一家人同住一户”，引申为“家庭的”。
- **同根词**：house（**hūs** 房屋 = 房子）、hold（**hold** 持有 = 掌握）、householder（house + holder 持有者 = 户主）、household（house 家 + hold 持有 = 家庭）。
- **前缀·后缀**：复合词无前后缀（house + hold 合成）。
- **同义·反义**：同义 domestic, family；反义 无。
- **词性变化**：household n. 家庭；householder n. 户主。

### 11. against /əˈɡenst/ prep. 紧靠；碰；撞
- **词根·渊源**：古英语 **ongean**（朝向、对面）→ 中古英语 *agenes* → 英语 against；本义“面对、逆着”，引申为“紧靠、碰、撞”。
- **同根词**：again（**again** 再、又 = 再一次）、gain（**gain** 获得 = 得到）、gainsay（gain 反对 + say 说 = 否认）。
- **前缀·后缀**：前缀 **a-**（例：along, across）。
- **同义·反义**：同义 touching, upon；反义 无。
- **词性变化**：again adv. 再一次。

### 12. speed /spiːd/ n. 速度；速率
- **词根·渊源**：古英语 **spēd**（成功、迅速）→ 中古英语 *spede* → 英语 speed；本义“成功、兴旺”，后转指“快速”，再引申为“速度”。
- **同根词**：speedy（**speed** 快 + **-y** …的 = 快速的）、speedily（speedy + **-ly** 副词 = 快速地）、speedometer（speed 速度 + meter 计 = 速度计）、speeding（speed + **-ing** 名词 = 超速）。
- **前缀·后缀**：无前后缀（单纯词）。
- **同义·反义**：同义 velocity, pace；反义 slowness。
- **词性变化**：speedy adj. 快速的；speed v. 加速。

### 13. safety /ˈseɪfti/ n. 安全；平安
- **词根·渊源**：拉丁 **salvus**（安全的）→ 古法语 *sauf* → 英语 safe + **-ty**；本义“平安无事的状态”，即“安全”。
- **同根词**：safe（**salv-** 安全 + **-e** = 安全的）、safely（safe + **-ly** 副词 = 安全地）、safeguard（safe 安全 + guard 保护 = 保卫）、save（salv 安全 + **-e** = 拯救）。
- **前缀·后缀**：名词后缀 **-ty**（例：beauty, loyalty）。
- **同义·反义**：同义 security, protection；反义 danger, risk。
- **词性变化**：safe adj. 安全的；safely adv. 安全地。

### 14. instruction /ɪnˈstrʌkʃn/ n. 用法说明；操作指南
- **词根·渊源**：拉丁 **instruere**（建造、教导）→ 拉丁 *instructio* → 古法语 *instruction* → 英语 instruction；本义“在头脑中搭建知识”，引申为“教导、说明”。
- **同根词**：instruct（**in-** 在内 + struct 建造 = 教导）、instructor（instruct + **-or** 人 = 教师）、structure（struct 建造 + **-ure** 名词 = 结构）、construct（**con-** 共同 + struct 建造 = 建造）、destruct（**de-** 去除 + struct 建造 = 破坏）。
- **前缀·后缀**：前缀 **in-**（例：include, inform）；名词后缀 **-ion**（例：action, education）。
- **同义·反义**：同义 direction, guide；反义 无。
- **词性变化**：instruct v. 教导；instructor n. 教师；instructive adj. 有教益的。

### 15. connect /kəˈnekt/ v.（使）连接
- **词根·渊源**：拉丁 **connectere**（绑在一起）→ 英语 connect；**con-** 共同 + **nect-** 绑，本义“绑在一起”，即“连接”。
- **同根词**：connection（connect + **-ion** 名词 = 连接）、connective（connect + **-ive** …的 = 连接的）、connector（connect + **-or** 物 = 连接器）、annex（**an-** 向 + nex 绑 = 附加）。
- **前缀·后缀**：前缀 **con-**（例：combine, collect）；词根 **nect-**（例：annex, nexus）。
- **同义·反义**：同义 link, join；反义 disconnect, separate。
- **词性变化**：connection n. 连接；connective adj. 连接的；connector n. 连接器。

### 16. device /dɪˈvaɪs/ n. 装置；设备
- **词根·渊源**：拉丁 **dividere**（分开）→ 古法语 *devis*（设计、安排）→ 英语 device；本义“分派、设计出的东西”，引申为“装置、设备”。
- **同根词**：devise（**de-** 分开 + vis 看 = 设计）、divide（**di-** 分开 + vid 分 = 分开）、division（divide + **-ion** 名词 =  division 分开）、individual（**in-** 不 + divid 分 + **-ual** …的 = 不可分的→个人的）。

- **同义·反义**：同义 gadget, apparatus；反义 无。
- **词性变化**：devise v. 设计；device n. 装置。

### 17. rule /ruːl/ n. 规则；条例
- **词根·渊源**：拉丁 **regula**（直尺、规则）→ 古法语 *reule* → 英语 rule；本义“直尺”，引申为“标准、规则”。
- **同根词**：ruler（**rule** 规则 + **-er** 人/物 = 统治者/尺子）、ruling（rule + **-ing** 名词 = 裁决）、regular（regula 规则 + **-ar** …的 = 规则的）、regulate（regula 规则 + **-ate** 动词 = 管理）。

- **词性变化**：ruler n. 统治者；ruling n. 裁决；rule v. 统治。

### 18. climate /ˈklaɪmət/ n. 气候
- **词根·渊源**：希腊 **klima**（倾斜、地带）→ 拉丁 *clima* → 古法语 *climat* → 英语 climate；本义“地球倾斜形成的气候带”，引申为“气候”。

- **词性变化**：climatic adj. 气候的；climatology n. 气候学。

### 19. amount /əˈmaʊnt/ n. 数量；数额
- **词根·渊源**：拉丁 **ad-**（向）+ **mont-**（山，拉丁 mons）→ 古法语 *amonter*“往上爬、升至”，本义“向上累积到某一高度”，引申为“合计、总计”，再名词化为“总数、数额”。
- **同根词**：mountain（mount 山 + **-ain** 名词后缀 = 山→山脉）、surmount（**sur-** 在上 + mount 山 = 在山上→克服）、paramount（**para-** 旁/最高 + mount 山 = 凌驾山顶→最高的）、dismount（**dis-** 去除 + mount 上马 = 下马）。
- **前缀·后缀**：前缀 **ad-**（例：advance, admire）；名词后缀 **-ment** 变体 -mount 无独立后缀（例：movement, agreement）。
- **同义·反义**：同义 quantity, sum, total；反义 无。
- **词性变化**：amount v. 合计；总计。

### 20. power /ˈpaʊə(r)/ v. 驱动；推动（机器或车辆）
- **词根·渊源**：拉丁 **posse / pot-**（能够，PIE *poti-* 有能力的）→ 古法语 *povoir*“能够”→ 英语 power，本义“能力”，引申为“力量、权力”，动词义“给…提供动力”即“使能运转”。
- **同根词**：powerful（power + **-ful** 充满…的 = 有力量的）、powerless（power + **-less** 无…的 = 无力的）、possible（**poss-** 能 + **-ible** 可…的 = 可能的）、potent（pot 能 + **-ent** …的 = 有力的）、omnipotent（**omni-** 全 + potent 能 = 全能的）。
- **前缀·后缀**：无前缀；名词后缀 **-er** 构成 power 本身无派生（例：teacher, worker）。
- **同义·反义**：同义 drive, propel, energize；反义 无。
- **词性变化**：power n. 力量；权力；powerful adj. 强大的；powerless adj. 无力的。
