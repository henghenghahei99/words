## 二、逐词说文解字

### 1. adventure /ədˈventʃər/ v. 冒险；冒险(经历)
- **词根·渊源**：拉丁 **ad-**（向）+ **venire**（来）→ 未来之事→机缘→冒险；经古法语 *aventure* 进入英语，本义“将要发生之事”，引申为“冒险经历”。
- **同根词**：event（**e-** 出 + vent 来 = 出来之事→事件）、invent（**in-** 入 + vent 来 = 走进头脑→发明）、prevent（**pre-** 前 + vent 来 = 先来挡住→预防）、convention（**con-** 共同 + vent 来 = 大家来到一起→会议/惯例）、avenue（**a-** 向 + ven 来 = 来之路→大街）。
- **前缀·后缀**：前缀 **ad-**（例：advance, admire）；名词后缀 **-ure**（例：pleasure, failure）。
- **同义·反义**：同义 venture, risk；反义 safety, security。
- **词性变化**：adventure n. 冒险；adventurous adj. 爱冒险的；adventurer n. 冒险家。

### 2. novel /ˈnɑ:vl/ n.（长篇）小说
- **词根·渊源**：拉丁 **novus**（新的）→ 意大利语 *novella*（新鲜小故事）→ 古法语 *novelle* → 英语，本义“新奇之事”，后指“虚构的长篇故事”。
- **同根词**：novelty（novel 新 + **-ty** 名词后缀 = 新奇事物）、innovate（**in-** 使 + nov 新 + **-ate** 动词后缀 = 使更新→创新）、renovate（**re-** 再 + nov 新 + **-ate** = 使再新→翻新）、novice（nov 新 + **-ice** 人 = 新手）、nova（拉丁 novus 新 + **-a** 阴性 = 新星）。
- **前缀·后缀**：前缀 **in-**（例：invent, inspire）、**re-**（例：return, rebuild）；名词后缀 **-el**（例：channel, tunnel）。
- **同义·反义**：同义 fiction, story；反义 nonfiction, fact。
- **词性变化**：novelist n. 小说家；novelty n. 新奇；novel adj. 新奇的。

### 3. frog /frɒɡ/ n. 蛙；青蛙
- **词根·渊源**：古英语 *frogga*，与古诺尔斯语 *froskr* 同源，本义即“蛙”；词源存疑，或与蛙的跳跃声/动作有关。
- **同根词**：frogman（frog 蛙 + man 人 = 蛙人）、froglet（frog 蛙 + **-let** 小 = 小蛙）、bullfrog（bull 牛 + frog 蛙 = 牛蛙）、tree frog（tree 树 + frog 蛙 = 树蛙）。
- **前缀·后缀**：无前后缀（单纯词）；复合词中 **-let** 表小（例：booklet, piglet）。
- **同义·反义**：同义 toad（蟾蜍，近义）；反义 无。
- **词性变化**：froggy adj. 蛙的；frogman n. 蛙人。

### 4. congratulations /kənˌgrætʃəˈleɪʃənz/ n. 祝贺；恭贺
- **词根·渊源**：拉丁 **con-**（共同）+ **gratulari**（表示高兴，源自 gratus 令人愉快的）→ 拉丁 *congratulatio* → 英语，本义“共同表达喜悦”，引申为“祝贺”。
- **同根词**：congratulate（**con-** 共同 + gratul 高兴 + **-ate** 动词后缀 = 共同高兴→祝贺）、grateful（grat 感谢 + **-ful** 充满…的 = 充满感谢的→感激的）、gratitude（grat 感谢 + **-itude** 名词后缀 = 感激之情）、gratify（grat 愉快 + **-ify** 使… = 使愉快→满足）、grace（拉丁 gratia 恩惠→优雅）。
- **前缀·后缀**：前缀 **con-**（例：connect, combine）；名词后缀 **-ation**（例：information, celebration）、复数 **-s**（例：thanks, regards）。
- **同义·反义**：同义 felicitations, good wishes；反义 condolences（哀悼）。
- **词性变化**：congratulate v. 祝贺；congratulatory adj. 祝贺的。

### 5. sympathy /'sɪmpəθi/ n. 同情（心），理解；赞同，支持
- **词根·渊源**：希腊 **syn-**（共同）+ **pathos**（感受）→ 希腊 *sympatheia* → 拉丁 → 英语，本义“共同感受”，引申为“同情、赞同”。
- **同根词**：sympathetic（sym 共同 + path 感受 + **-etic** 形容词后缀 = 同感的→同情的）、sympathize（sym 共同 + path 感受 + **-ize** 动词后缀 = 共同感受→同情）、pathetic（path 感受 + **-etic** = 引发感受的→可怜的）、apathy（**a-** 无 + path 感受 + **-y** = 无感觉→冷漠）、pathos（path 感受 + **-os** 名词后缀 = 感伤力）。
- **前缀·后缀**：前缀 **sym-/syn-**（例：symphony, synonym）；名词后缀 **-y**（例：harmony, victory）。
- **同义·反义**：同义 compassion, understanding；反义 indifference, apathy。
- **词性变化**：sympathetic adj. 同情的；sympathize v. 同情；sympathetically adv. 同情地。

### 6. steamboat /'stiːmbəʊt/ n. 汽船，轮船
- **词根·渊源**：**steam**（蒸汽）+ **boat**（船）复合而成；steam 源自古英语 *stēam*（蒸汽），boat 源自古英语 *bāt*（船），本义“以蒸汽为动力的船”。
- **同根词**：steamship（steam 蒸汽 + ship 船 = 汽船）、steamengine（steam 蒸汽 + engine 发动机 = 蒸汽机）、steamroller（steam 蒸汽 + roller 压路机 = 蒸汽压路机）、steamboat 本身为复合词；boat 相关：boating（boat + **-ing** 名词后缀 = 划船）、lifeboat（life 生命 + boat 船 = 救生船）。
- **前缀·后缀**：复合词无前后缀；**-ing** 名词后缀（例：boating, sailing）。
- **同义·反义**：同义 steamship, steamer；反义 无。
- **词性变化**：steam n. 蒸汽；steamy adj. 蒸汽的；steamboat n. 汽船。

### 7. steam /stiːm/ v. 蒸汽，水蒸气；水汽，雾气；蒸汽动力
- **词根·渊源**：古英语 *stēam*（蒸汽、热气），与德语 *Dampf* 同源，本义“冒出的热气”，引申为“蒸汽动力”。
- **同根词**：steamy（steam 蒸汽 + **-y** 形容词后缀 = 蒸汽的）、steamer（steam 蒸汽 + **-er** 物 = 汽船/蒸锅）、steamroller（steam 蒸汽 + roller 压路机 = 蒸汽压路机）、steamship（steam 蒸汽 + ship 船 = 汽船）。
- **前缀·后缀**：无前缀；后缀 **-y**（例：rainy, windy）、**-er**（例：boiler, cooker）。
- **同义·反义**：同义 vapor, mist；反义 无。
- **词性变化**：steam n. 蒸汽；steamy adj. 蒸汽的；steamer n. 汽船。

### 8. writer /ˈraɪtə(r)/ n. 作家，作者
- **词根·渊源**：古英语 **writan**（刻划、书写）→ write + **-er**（人），本义“书写的人”，引申为“作家、作者”。
- **同根词**：write（古英语 writan 刻写→写）、writing（write + **-ing** 名词后缀 = 写作）、writ（write 的过去分词→ writ 文书）、rewrite（**re-** 再 + write 写 = 重写）、typewriter（type 打字 + writer 写者 = 打字机）。
- **前缀·后缀**：前缀 **re-**（例：rewrite, reread）；后缀 **-er** 表人（例：teacher, singer）。
- **同义·反义**：同义 author, novelist；反义 reader（读者）。
- **词性变化**：write v. 写；writing n. 写作；writer n. 作家。

### 9. humorous /ˈhjumərəs/ adj. 有幽默感的；滑稽有趣的；诙谐的
- **词根·渊源**：拉丁 **humor**（体液）→ 古法语 *humour* → 英语，中世纪认为人体四种体液决定性格，幽默感源于“体液”平衡，引申为“诙谐的”。
- **同根词**：humor（humor 体液→幽默）、humorist（humor 幽默 + **-ist** 人 = 幽默家）、humorless（humor 幽默 + **-less** 无 = 无幽默感的）、humid（hum 湿 + **-id** 形容词后缀 = 潮湿的）、humility（hum 土 + **-ility** 名词后缀 = 谦卑）。
- **前缀·后缀**：无前缀；后缀 **-ous** 形容词后缀（例：famous, dangerous）。
- **同义·反义**：同义 funny, witty；反义 serious, solemn。
- **词性变化**：humor n. 幽默；humorously adv. 幽默地；humorless adj. 无幽默感的。

### 10. fence /fɛns/ v. 篱笆，栅栏，围栏
- **词根·渊源**：中古英语 **fens**（防御）→ 缩写自 **defence**（防御），本义“防御物”，引申为“篱笆、围栏”。
- **同根词**：defence（**de-** 去除 + fens 打击 = 防御）、defend（**de-** 去除 + fend 打击 = 保卫）、offend（**of-** 反对 + fend 打击 = 冒犯）、fencing（fence 围栏 + **-ing** 名词后缀 = 击剑/围栏材料）。
- **前缀·后缀**：无前缀；后缀 **-ing**（例：building, fencing）。
- **同义·反义**：同义 barrier, railing；反义 无。
- **词性变化**：fence n. 篱笆；fencing n. 击剑；fencer n. 击剑者。

### 11. task /tæsk/ v. 任务；工作
- **词根·渊源**：古法语 **tasque**（税、劳役）→ 中世纪拉丁 *tasca*，本义“规定的劳役”，引申为“任务、工作”。
- **同根词**：taskmaster（task 任务 + master 主人 = 监工）、multitask（**multi-** 多 + task 任务 = 多任务处理）、taskforce（task 任务 + force 力量 = 特遣队）。
- **前缀·后缀**：前缀 **multi-**（例：multimedia, multitask）；无后缀（单纯词）。
- **同义·反义**：同义 job, assignment；反义 leisure（闲暇）。
- **词性变化**：task n. 任务；tasking n. 任务分配。

### 12. yard /jɑːrd/ n. 码（长度单位）
- **词根·渊源**：古英语 **gyrd**（棍、杆）→ 中古英语 *yerde*，本义“量尺之杆”，后固定为长度单位“码”（约0.914米）。
- **同根词**：yardstick（yard 码 + stick 棍 = 码尺→标准）、yardage（yard 码 + **-age** 名词后缀 = 码数）、courtyard（court 庭院 + yard 院子 = 庭院）、shipyard（ship 船 + yard 场地 = 造船厂）。
- **前缀·后缀**：无前缀；后缀 **-age**（例：mileage, yardage）。
- **同义·反义**：同义 无（长度单位）；反义 无。
- **词性变化**：yard n. 码；yardage n. 码数；yardstick n. 码尺。

### 13. board /bɔːd/ n. 布告牌；木板
- **词根·渊源**：古英语 **bord**（木板、桌子），本义“木板”，引申为“布告牌、董事会”。
- **同根词**：blackboard（black 黑 + board 板 = 黑板）、keyboard（key 键 + board 板 = 键盘）、aboard（**a-** 在 + board 船板 = 在船上）、boarding（board 板 + **-ing** 名词后缀 = 登机/寄宿）、cupboard（cup 杯 + board 板 = 碗柜）。
- **前缀·后缀**：前缀 **a-**（例：aboard, aside）；后缀 **-ing**（例：boarding, painting）。
- **同义·反义**：同义 plank, panel；反义 无。
- **词性变化**：board n. 木板；boarding n. 登机；boarder n. 寄宿生。

### 14. survey /ˈsɜːrveɪ/ v. 查看，审视，检查
- **词根·渊源**：拉丁 **super-**（在上）+ **videre**（看）→ 古法语 *surveir* → 英语，本义“从上方看”，引申为“审视、调查”。
- **同根词**：supervise（**super-** 在上 + vis 看 = 从上监督）、visible（vis 看 + **-ible** 可…的 = 可见的）、vision（vis 看 + **-ion** 名词后缀 = 视力/愿景）、revise（**re-** 再 + vis 看 = 再看→修订）、evident（**e-** 出 + vid 看 + **-ent** = 看得出的→明显的）。
- **前缀·后缀**：前缀 **sur-/super-**（例：surface, supervise）；名词后缀 **-ey**（例：journey, attorney）。
- **同义·反义**：同义 inspect, examine；反义 ignore, overlook。
- **词性变化**：survey n. 调查；surveyor n. 测量员；surveying n. 测量。

### 15. progress /ˈprɑ:gres/ v. 进步；进展
- **词根·渊源**：拉丁 **pro-**（向前）+ **gradi**（走）→ 拉丁 *progressus* → 英语，本义“向前走”，引申为“进步、进展”。
- **同根词**：progressive（pro 向前 + gress 走 + **-ive** 形容词后缀 = 进步的）、regress（**re-** 回 + gress 走 = 后退→倒退）、congress（**con-** 共同 + gress 走 = 走到一起→国会）、aggressive（**ag-** 向 + gress 走 + **-ive** = 向前走的→侵略的）、grade（grad 走→等级）。
- **前缀·后缀**：前缀 **pro-**（例：promote, proceed）；名词后缀 **-ess**（例：process, access）。
- **同义·反义**：同义 advance, improvement；反义 regress, decline。
- **词性变化**：progress n. 进步；progressive adj. 进步的；progression n. 进展。

### 16. rest /rɛst/ v. 休息（时间）
- **词根·渊源**：古英语 **ræst**（休息、床），本义“休息”，引申为“休息时间”。
- **同根词**：restful（rest 休息 + **-ful** 充满…的 = 宁静的）、restless（rest 休息 + **-less** 无 = 不安的）、restroom（rest 休息 + room 房间 = 洗手间）、arrest（**ar-** 使 + rest 停 = 使停下→逮捕）。
- **前缀·后缀**：前缀 **a-**（例：arrest, arise）；后缀 **-ful**（例：helpful, restful）、**-less**（例：hopeless, restless）。
- **同义·反义**：同义 break, relaxation；反义 work, activity。
- **词性变化**：rest n. 休息；restful adj. 宁静的；restless adj. 不安的。

### 17. pity /ˈpɪti/ n. 遗憾；可惜
- **词根·渊源**：古法语 **pité**（同情）→ 拉丁 **pietas**（虔诚、怜悯），本义“怜悯”，引申为“遗憾、可惜”。
- **同根词**：pitiful（pity 怜悯 + **-ful** 充满…的 = 可怜的）、pitiless（pity 怜悯 + **-less** 无 = 无情的）、pious（pi 虔诚 + **-ous** = 虔诚的）、piety（pi 虔诚 + **-ety** 名词后缀 = 虔诚）。
- **前缀·后缀**：无前缀；后缀 **-ful**（例：merciful, pitiful）、**-less**（例：merciless, pitiless）。
- **同义·反义**：同义 shame, regret；反义 cruelty, indifference。
- **词性变化**：pity v. 同情；pitiful adj. 可怜的；pitiless adj. 无情的。

### 18. silence /ˈsaɪləns/ n. 寂静，无声；沉默，默不作声:；保持沉默，拒绝回答
- **词根·渊源**：拉丁 **silere**（安静）→ 拉丁 *silentium* → 古法语 *silence* → 英语，本义“安静状态”，引申为“沉默”。
- **同根词**：silent（sil 安静 + **-ent** 形容词后缀 = 安静的）、silently（silent 安静的 + **-ly** 副词后缀 = 安静地）、silencer（silence 安静 + **-er** 物 = 消音器）。
- **前缀·后缀**：无前缀；后缀 **-ence** 名词后缀（例：difference, patience）。
- **同义·反义**：同义 quiet, stillness；反义 noise, sound。
- **词性变化**：silent adj. 安静的；silently adv. 安静地；silence v. 使沉默。

### 19. while /waɪl/ n. 在...期间；一会儿，一段时间；当...的时候
- **词根·渊源**：古英语 *hwīl*（一段时间）→ 中古英语 *while*，本义“一段时间”，引申为连词“当……的时候”及名词“一会儿”。
- **同根词**：whilst（while + **-st** 副词性后缀：当……时，英式旧用）、worthwhile（worth 值得 + while 一段时间 = 值得花时间的→值得的）、awhile（**a-** 在……之中 + while 一段时间 = 片刻）。
- **前缀·后缀**：无前后缀（单纯词）。
- **同义·反义**：同义 moment, time；反义 无。
- **词性变化**：while conj. 当……时；whilst conj. 当……时（英式）。

### 20. careful /ˈkeəfl/ adj. 小心；谨慎；小心的；仔细的，认真的
- **词根·渊源**：古英语 *caru*（忧虑、关心）→ 中古英语 *care*（关心）→ care + **-ful**（充满……的），本义“充满关心的”，引申为“小心的、仔细的”。
- **同根词**：care（古英语 caru 忧虑→关心）、careless（care + **-less** 无……的：粗心的）、caring（care + **-ing** ……的：关心的）、caringly（caring + **-ly** ……地：关心地）。
- **前缀·后缀**：形容词后缀 **-ful**（例：helpful, useful）。
- **同义·反义**：同义 cautious, attentive；反义 careless, negligent。
- **词性变化**：care n. 关心 → careful adj. 小心的；carefully adv. 小心地；carefulness n. 小心。

### 21. deal /diːl/ v. 协议；交易；处理；给予
- **词根·渊源**：古英语 *dǣlan*（分开、分配）→ 中古英语 *delen*，本义“分份、分配”，引申为“交易、协议”及“处理”。
- **同根词**：dealer（deal + **-er** 人：商人）、dealing（deal + **-ing** 名词后缀：交易、处理）、dealings（dealing + **-s** 复数：往来）。
- **前缀·后缀**：名词后缀 **-er**（例：teacher, worker）。
- **同义·反义**：同义 trade, handle；反义 无。
- **词性变化**：deal n. 交易；dealer n. 商人；dealing n. 交易。

### 22. coat /koʊt/ v. 涂料层，覆盖层
- **词根·渊源**：古法语 *cote*（外套、罩衣）→ 中古英语 *cote*，本义“外套”，引申为“覆盖层、涂层”及动词“涂上”。
- **同根词**：coating（coat + **-ing** 名词后缀：涂层）、coated（coat + **-ed** ……的：有涂层的）、overcoat（**over-** 在上 + coat 外套 = 大衣）、raincoat（rain 雨 + coat 外套 = 雨衣）。
- **前缀·后缀**：名词后缀 **-ing**（例：building, painting）。
- **同义·反义**：同义 layer, cover；反义 无。
- **词性变化**：coat n. 外套；coating n. 涂层；coated adj. 有涂层的。

### 23. celebrated /ˈselɪbreɪtɪd/ adj. 著名的；闻名的；有名望的
- **词根·渊源**：拉丁 *celeber*（著名的、热闹的）→ 拉丁 *celebrāre*（庆祝、使著名）→ 英语 celebrate + **-ed**（……的），本义“被庆祝的”，引申为“著名的”。
- **同根词**：celebrate（拉丁 celebrāre 庆祝→庆祝）、celebration（celebrate + **-ion** 名词后缀：庆祝）、celebrity（拉丁 celebritās 名声→名人）、celebratory（celebrate + **-ory** ……的：庆祝的）。
- **前缀·后缀**：形容词后缀 **-ed**（例：talented, excited）。
- **同义·反义**：同义 famous, renowned；反义 unknown, obscure。
- **词性变化**：celebrate v. 庆祝 → celebration n. 庆祝；celebrity n. 名人。

### 24. lead /liːd; led/ n. 铅
- **词根·渊源**：古英语 *lēad*（铅）→ 中古英语 *lead*，本义“铅金属”，词源与日耳曼语同源，存疑处在于与动词 lead（引导）同形异源。
- **同根词**：leaden（lead + **-en** 由……制成的：铅制的）、leaded（lead + **-ed** 含铅的：含铅的）、leading（lead + **-ing** 名词后缀：铅制品，较少用）。
- **前缀·后缀**：形容词后缀 **-en**（例：wooden, golden）。
- **同义·反义**：同义 Pb（化学符号）；反义 无。
- **词性变化**：leaden adj. 铅制的；leaded adj. 含铅的。

### 25. plot /plɑːt/ v. 阴谋，密谋；故事情节；构思（情节）
- **词根·渊源**：古英语 *plot*（一块土地）→ 中古英语 *plot*，本义“小块地”，引申为“图纸上的地块→情节布局→密谋”，词源存疑。
- **同根词**：plotter（plot + **-er** 人：密谋者）、plotting（plot + **-ing** 名词后缀：密谋）、subplot（**sub-** 下面 + plot 情节 = 次要情节）。
- **前缀·后缀**：名词后缀 **-er**（例：writer, singer）。
- **同义·反义**：同义 scheme, conspire；反义 无。
- **词性变化**：plot n. 情节；密谋；plotter n. 密谋者。

### 26. lazy /ˈleɪzi/ adj. 懒惰的，懒散的
- **词根·渊源**：可能来自低地德语 *lasich*（懒散的）或古英语 *lesu*（弱的），词源存疑；本义“无力的、懒散的”，引申为“懒惰的”。
- **同根词**：lazily（lazy + **-ly** ……地：懒散地）、laziness（lazy + **-ness** 名词后缀：懒惰）、laze（lazy 去 y + **-e** 动词化：懒散度日）。
- **前缀·后缀**：形容词后缀 **-y**（例：rainy, windy）。
- **同义·反义**：同义 idle, indolent；反义 diligent, industrious。
- **词性变化**：lazily adv. 懒散地；laziness n. 懒惰；laze v. 懒散度日。

### 27. pretend /prɪˈtend/ v. 伪装，假装；佯装；（玩游戏时）假扮，装扮
- **词根·渊源**：拉丁 *praetendere*（向前伸展、声称）→ 古法语 *pretendre* → 英语 pretend，本义“向前伸张→声称”，引申为“假装”。
- **同根词**：pretense（**pre-** 前 + tens 伸 + **-e** 名词后缀：假装）、pretension（pretense + **-ion** 名词后缀：自称）、pretentious（pretend + **-ious** ……的：自命不凡的）。
- **前缀·后缀**：前缀 **pre-**（例：preview, prepare）。
- **同义·反义**：同义 feign, fake；反义 无。
- **词性变化**：pretense n. 假装；pretentious adj. 自命不凡的。
