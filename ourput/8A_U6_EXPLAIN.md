## 二、逐词说文解字

### 1. ancient /ˈenʃənt/ adj. 古代的；古老的
- **词根·渊源**：拉丁 **ante-**（在……之前）→ 古法语 *ancien*（以前的）→ 英语 ancient，本义“在前的、以前的”，引申为“古代的、古老的”。
- **同根词**：ancestor（**ante-** 前 + cess 走 + **-or** 人 = 走在前面的人→祖先）、antecedent（**ante-** 前 + ced 走 + **-ent** 名词/形容词后缀 = 走在前面的事物→先行词/先行的）、antique（拉丁 antiquus 古代的→古董的）、anticipate（**ante-** 前 + cip 拿 + **-ate** 动词后缀 = 提前拿到→预期）。
- **前缀·后缀**：前缀 **ante-**（例：anteroom, antedate）；形容词后缀 **-ent**（例：different, silent）。
- **同义·反义**：同义 old, antique；反义 modern, recent。
- **词性变化**：antiquity n. 古代；古老。

### 2. Trojan /ˈtroʊʤən/ adj. 特洛伊人；特洛伊的；特洛伊人的
- **词根·渊源**：希腊语 **Troia**（特洛伊城）→ 拉丁 *Troianus* → 古英语 *Troian* → 英语 Trojan，本义“特洛伊城的（人）”，专有地名派生词。
- **同根词**：Troy（特洛伊城，专有名词，无构词分析）、Trojan horse（特洛伊木马，Trojan + horse 复合词）。
- **前缀·后缀**：形容词/名词后缀 **-an**（例：American, Roman）。
- **同义·反义**：同义 无；反义 无。
- **词性变化**：Troy n. 特洛伊（地名）。

### 3. war /wɔːr/ n. 战争
- **词根·渊源**：古北法语 *werre* → 古高地德语 *werra*（混乱、纷争）→ 英语 war，本义“混乱、争斗”，引申为“战争”。
- **同根词**：warrior（war + **-ior** 人 = 打仗的人→战士）、warfare（war + fare 进行 = 进行战争→作战）、warlike（war + like 像……的 = 好战的）。
- **前缀·后缀**：无前后缀（单纯词）。
- **同义·反义**：同义 conflict, battle；反义 peace。
- **词性变化**：warrior n. 战士；warfare n. 战争；warlike adj. 好战的。

### 4. understand (understood) /ˌʌndərˈstænd/ v. 懂；理解；明白
- **同义搭配**：figure out / make sense of / catch on to
- **反义搭配**：misunderstand / be confused about

### 5. difference /ˈdɪfrəns/ n. 差异；差别：不同之处
- **词根·渊源**：拉丁 **dis-**（分开）+ **ferre**（携带、拿）→ 拉丁 *differentia* → 古法语 *difference* → 英语 difference，本义“分开携带”，引申为“差异、不同”。
- **同根词**：differ（**dif-** 分开 + fer 携带 = 分开拿→不同）、different（differ + **-ent** 形容词后缀 = 不同的）、differential（different + **-ial** 形容词后缀 = 差别的）、transfer（**trans-** 转移 + fer 携带 = 转移→搬运）、refer（**re-** 回 + fer 携带 = 带回→提及）。
- **前缀·后缀**：前缀 **dis-/dif-**（例：disagree, difficult）；名词后缀 **-ence**（例：patience, silence）。
- **同义·反义**：同义 distinction, contrast；反义 similarity, sameness。
- **词性变化**：differ v. 不同；different adj. 不同的；differently adv. 不同地。

### 6. pyramid /ˈpɪrəmɪd/ v.（古埃及的）金字塔
- **词根·渊源**：希腊语 **pyramis / pyramid-**（尖塔形物）→ 拉丁 *pyramis* → 法语 *pyramide* → 英语 pyramid，本义“尖塔形建筑”，指古埃及金字塔。
- **同根词**：pyramidal（pyramid + **-al** 形容词后缀 = 金字塔形的）。
- **前缀·后缀**：形容词后缀 **-al**（例：natural, musical）。
- **同义·反义**：同义 无；反义 无。
- **词性变化**：pyramidal adj. 金字塔形的。

### 7. captain /ˈkæptɪn/ n. 队长；首领
- **词根·渊源**：拉丁 **caput / capit-**（头）→ 拉丁 *capitaneus*（为首的）→ 古法语 *capitaine* → 英语 captain，本义“为首的人”，引申为“队长、首领”。
- **同根词**：capital（capit 头 + **-al** 形容词后缀 = 头的→首要的/首都）、decapitate（**de-** 去除 + capit 头 + **-ate** 动词后缀 = 去掉头→斩首）、capitulate（capit 头 + **-ulate** 动词后缀 = 按条目分头列出→投降）、chief（源自拉丁 caput 头→首领）。
- **前缀·后缀**：名词后缀 **-ain**（例：villain, mountain）。
- **同义·反义**：同义 leader, chief；反义 follower。
- **词性变化**：captaincy n. 队长职位；capital n. 首都；adj. 首要的。

### 8. Greek /ɡriːk/ n. 希腊语；希腊人
- **词根·渊源**：拉丁 **Graecus**（希腊的）→ 古英语 *Grēc* → 英语 Greek，源自希腊部落名 Graeci，本义“希腊人”，引申为“希腊语”。
- **同根词**：Greece（希腊，源自拉丁 Graecia，专有地名）、grecian（Greek 变体 + **-ian** 形容词后缀 = 希腊式的）。
- **前缀·后缀**：无前后缀（专有名词）。
- **同义·反义**：同义 Hellene（希腊人，书面语）；反义 无。
- **词性变化**：Greece n. 希腊。

### 9. capture /ˈkæptʃər/ v. 用武力夺取；攻占；占领
- **词根·渊源**：拉丁 **capere / capt-**（抓、拿）→ 拉丁 *captura*（捕获）→ 法语 *capture* → 英语 capture，本义“抓住”，引申为“用武力夺取、攻占”。
- **同根词**：captive（capt 抓 + **-ive** 形容词/名词后缀 = 被抓住的→俘虏）、captivate（captiv + **-ate** 动词后缀 = 使被抓住→迷住）、accept（**ac-** 加强 + cept 拿 = 拿过来→接受）、receive（**re-** 回 + ceive 拿 = 拿回→收到）、concept（**con-** 共同 + cept 拿 = 共同拿住→概念）。
- **前缀·后缀**：名词后缀 **-ure**（例：failure, mixture）。
- **同义·反义**：同义 seize, take；反义 release, free。
- **词性变化**：captive n. 俘虏；adj. 被俘的；capture n. 捕获。

### 10. soldier /ˈsoʊldʒər/ n. 士兵，战士
- **词根·渊源**：拉丁 **solidus**（一种金币）→ 古法语 *soudier*（领饷的人）→ 英语 soldier，本义“为军饷服役的人”，引申为“士兵”。
- **同根词**：solid（拉丁 solidus 坚实→坚固的，同源但意义分化）、soldiery（soldier + **-y** 集合名词后缀 = 士兵们）。
- **前缀·后缀**：名词后缀 **-ier**（例：cashier, brigadier）。
- **同义·反义**：同义 warrior, fighter；反义 civilian。
- **词性变化**：soldiery n. 军队；士兵们。

### 11. huge /hjuːʤ/ adj. 巨大的，极多的
- **词根·渊源**：古法语 **ahuge / huge**（巨大的），词源不确定，可能源自法兰克语 *hūba*（土堆），**存疑**；本义“巨大的”，引申为“极多的”。
- **同根词**：hugely（huge + **-ly** 副词后缀 = 巨大地）、hugeness（huge + **-ness** 名词后缀 = 巨大）。
- **前缀·后缀**：形容词后缀 **-e**（无实义，单纯词变体）。
- **同义·反义**：同义 enormous, vast；反义 tiny, small。
- **词性变化**：hugely adv. 巨大地；hugeness n. 巨大。

### 12. pull /pʊl/ v. 拉；拖；拽；拉动
- **词根·渊源**：古英语 **pullian**（拔、摘），词源不确定，可能与低地德语 *pulen*（拔）有关，**存疑**；本义“拔、拉”，引申为“拖、拽”。
- **同根词**：pullover（pull + over 在上 = 拉过来套上→套头衫）、pullback（pull + back 向后 = 拉回→撤退）。
- **前缀·后缀**：无前后缀（单纯词）。
- **同义·反义**：同义 drag, draw；反义 push。
- **词性变化**：pull n. 拉；拉力。

### 13. main /meɪn/ adj. 主要的；最重要的
- **词根·渊源**：古英语 **mægen**（力量、强大）→ 中古英语 *main*，本义“强大的”，引申为“主要的、最重要的”。
- **同根词**：mainly（main + **-ly** 副词后缀 = 主要地）、mainland（main + land 陆地 = 主要陆地→大陆）、mainstay（main + stay 支撑 = 主要支柱）。
- **前缀·后缀**：无前后缀（单纯词）。
- **同义·反义**：同义 chief, principal；反义 minor, secondary。
- **词性变化**：mainly adv. 主要地；mainland n. 大陆。

### 14. celebrate /ˈselɪbreɪt/ v. 庆祝；庆贺
- **词根·渊源**：拉丁 **celeber / celebr-**（著名的、热闹的）→ 拉丁 *celebrare*（使著名、举行庆典）→ 英语 celebrate，本义“使热闹、举行庆典”，引申为“庆祝”。
- **同根词**：celebration（celebrate + **-ion** 名词后缀 = 庆祝）、celebrity（celeber 著名 + **-ity** 名词后缀 = 名人）、celebrated（celebrate + **-ed** 形容词后缀 = 著名的）。
- **前缀·后缀**：动词后缀 **-ate**（例：create, educate）；名词后缀 **-ion**（例：action, education）。
- **同义·反义**：同义 observe, commemorate；反义 mourn。
- **词性变化**：celebration n. 庆祝；celebrity n. 名人；celebrated adj. 著名的。

### 15. stupid /ˈstuːpɪd/ adj. 愚蠢的；笨的；糊涂的
- **词根·渊源**：拉丁 **stupere**（发呆、惊呆）→ 拉丁 *stupidus*（发呆的）→ 法语 *stupide* → 英语 stupid，本义“发呆的、麻木的”，引申为“愚蠢的”。
- **同根词**：stupor（stup 发呆 + **-or** 名词后缀 = 昏迷、麻木）、stupidity（stupid + **-ity** 名词后缀 = 愚蠢）、stupefy（stup 发呆 + **-fy** 使…… = 使发呆→使惊呆）。
- **前缀·后缀**：形容词后缀 **-id**（例：rapid, vivid）。
- **同义·反义**：同义 foolish, silly；反义 clever, smart。
- **词性变化**：stupidity n. 愚蠢；stupidly adv. 愚蠢地。

### 16. midnight /ˈmɪdnaɪt/ n. 子夜,午夜
- **词根·渊源**：古英语 **midniht**，由 **mid-**（中间）+ **niht**（夜）构成，本义“夜的中间”，即“午夜”。
- **同根词**：midday（**mid-** 中间 + day 白天 = 正午）、midway（**mid-** 中间 + way 路 = 中途）、midland（**mid-** 中间 + land 陆地 = 内陆）、night（夜，单纯词）。
- **前缀·后缀**：前缀 **mid-**（例：midday, midway）。
- **同义·反义**：同义 无；反义 midday, noon。
- **词性变化**：midday n. 正午；midway adv. 中途。

### 17. empty /ˈempti/ adj. 空的
- **词根·渊源**：古英语 **ǣmettig**（空闲的）→ 中古英语 *empty*，由 **ǣmetta**（空闲）派生，本义“空闲的”，引申为“空的”。
- **同根词**：emptiness（empty + **-ness** 名词后缀 = 空）、emptily（empty + **-ly** 副词后缀 = 空地）。
- **前缀·后缀**：形容词后缀 **-y**（例：happy, dirty）。
- **同义·反义**：同义 vacant, bare；反义 full, filled。
- **词性变化**：emptiness n. 空；emptily adv. 空地。

### 18. except /ɪkˈsɛpt/ prep. 除……之外；除了；只是
- **词根·渊源**：拉丁 **ex-**（出）+ **capere**（拿）→ 拉丁 *exceptus*（被拿出的）→ 英语 except，本义“被拿出来的”，引申为“除……之外”。
- **同根词**：exception（except + **-ion** 名词后缀 = 例外）、exceptional（exception + **-al** 形容词后缀 = 例外的/杰出的）、accept（**ac-** 加强 + cept 拿 = 拿过来→接受）、capture（capt 抓 + **-ure** 名词后缀 = 捕获）。
- **前缀·后缀**：前缀 **ex-**（例：exit, export）；词根 **cept**（例：accept, concept）。
- **同义·反义**：同义 excluding, but；反义 including。
- **词性变化**：exception n. 例外；exceptional adj. 例外的；except prep. 除……之外。

### 19. secret /ˈsiːkrət/ adj. 秘密的，保密的；（感情、担心、行动）不公开的，暗自的
- **词根·渊源**：拉丁 **secernere / secret-**（分开、筛出）→ 拉丁 *secretus*（被分开的、隐藏的）→ 古法语 *secret* → 英语；本义“被分离出来不让人知道的”，引申为“秘密的、保密的”。
- **同根词**：secrete（**se-** 分开 + cret 筛 = 分出来藏起→分泌；隐藏）、secretion（secrete + **-ion** 名词后缀：分泌物）、secretive（secret + **-ive** …倾向的：爱保密的）、secretly（secret + **-ly** 副词后缀：秘密地）、discern（**dis-** 分开 + cern 筛 = 分辨出来→辨别）。
- **前缀·后缀**：前缀 **se-**（例：separate, select）；后缀 **-ive**（例：active, creative）、**-ly**（例：quickly, happily）。
- **同义·反义**：同义 hidden, private, confidential；反义 public, open, known。
- **词性变化**：secret n. 秘密；secretly adv. 秘密地；secrecy n. 保密；secretive adj. 爱保密的。

### 20. side /saɪd/ n. 侧面；一方；队
- **词根·渊源**：古英语 **side**（身体的侧面、 flank）→ 中古英语 *side* → 英语；与古诺尔斯语 *síða*、德语 *Seite* 同源，本义“身体的侧边”，引申为“物体的侧面”“对立中的一方”“队伍”。
- **同根词**：beside（**be-** 在…旁 + side 边 = 在旁边）、besides（beside + **-s** 副词性词尾：此外）、sideways（side + **-ways** 方向后缀：向侧面地）、siding（side + **-ing** 名词后缀： siding 侧线；护墙板）、outside（**out-** 外 + side 边 = 外面）。
- **前缀·后缀**：前缀 **be-**（例：behind, below）、**out-**（例：outside, outdoor）；后缀 **-ways**（例：always, sideways）。
- **同义·反义**：同义 flank, aspect, party, team；反义 无（作“中心”义时反义 center）。
- **词性变化**：side adj. 旁边的；sideways adv. 向侧面地；beside prep. 在…旁边。

### 21. quietly /ˈkwaɪətlɪ/ adv. 小声地；安静地，寂静地
- **词根·渊源**：拉丁 **quietus**（安静的，休息的）→ 古法语 *quiet* → 英语 *quiet*（安静的）+ **-ly**（副词后缀）→ quietly；本义“处于安静状态地”，引申为“小声地、寂静地”。
- **同根词**：quiet（拉丁 quietus 安静的→安静的）、quieten（quiet + **-en** 动词后缀：使安静）、quietness（quiet + **-ness** 名词后缀：安静）、quiescent（拉丁 quies 休息 + **-escent** 开始…的：静止的）、acquit（**ac-** 使 + quit 安静 = 使安静→宣告无罪）。
- **前缀·后缀**：后缀 **-ly**（例：slowly, carefully）、**-en**（例：widen, strengthen）、**-ness**（例：kindness, darkness）。
- **同义·反义**：同义 silently, softly, calmly；反义 loudly, noisily。
- **词性变化**：quiet adj. 安静的；quietly adv. 安静地；quietness n. 安静；quieten v. 使安静。

### 22. army /ˈɑːrmi/ n. 军队
- **词根·渊源**：拉丁 **arma**（武器）→ 古法语 *armée*（武装力量）→ 英语 *army*；本义“武装起来的人群”，引申为“军队”。
- **同根词**：arm（拉丁 arma 武器→武装）、armament（arma 武器 + **-ment** 名词后缀：军备）、armor（拉丁 armatura 装备→盔甲）、disarm（**dis-** 去除 + arm 武器 = 解除武装）、armistice（arma 武器 + stitium 停止 = 停战）。
- **前缀·后缀**：前缀 **dis-**（例：disappear, disagree）；后缀 **-ment**（例：movement, government）。
- **同义·反义**：同义 military, troops, forces；反义 无（作“平民”义时反义 civilians）。
- **词性变化**：arm v. 武装；armed adj. 武装的；armament n. 军备。

### 23. enter /ˈentər/ v. 进来；进入
- **词根·渊源**：拉丁 **intra**（在内）→ 拉丁 *intrare*（进入）→ 古法语 *entrer* → 英语；本义“走到里面”，引申为“进入、参加”。
- **同根词**：entry（enter + **-y** 名词后缀：进入；入口）、entrance（enter + **-ance** 名词后缀：入口；进入）、entrant（enter + **-ant** 人：进入者）、introduce（**intro-** 向内 + duc 引导 = 引入→介绍）、internal（intern 内部 + **-al** …的：内部的）。
- **前缀·后缀**：前缀 **intro-**（例：introduce, introvert）；后缀 **-ance**（例：importance, performance）、**-ant**（例：servant, assistant）。
- **同义·反义**：同义 come in, go into, join；反义 exit, leave。
- **词性变化**：entry n. 进入；入口；entrance n. 入口；进入；entrant n. 进入者。

### 24. succeed /səkˈsid/ v. 实现目标；成功；达到目的
- **词根·渊源**：拉丁 **sub-**（在下、接着）+ **cedere**（走）→ 拉丁 *succedere*（接着走、接替）→ 古法语 *succeder* → 英语；本义“接着走、接替”，引申为“随后发生”“达到目的、成功”。
- **同根词**：success（succeed + **-cess** 走的名词形式：成功）、successful（success + **-ful** 充满…的：成功的）、succession（sub + cess 走 + **-ion** 名词后缀：连续；继承）、successive（succession + **-ive** …的：连续的）、proceed（**pro-** 向前 + ceed 走 = 向前走→继续进行）。
- **前缀·后缀**：前缀 **sub-**（例：subway, submarine）、**pro-**（例：progress, produce）；后缀 **-ful**（例：helpful, useful）、**-ion**（例：action, education）。
- **同义·反义**：同义 achieve, accomplish, thrive；反义 fail, lose。
- **词性变化**：success n. 成功；successful adj. 成功的；successfully adv. 成功地；succession n. 连续；继承。

### 25. trick /trɪk/ v. 计谋；恶作剧；诡计
- **词根·渊源**：古法语 **trique**（欺骗、诡计）→ 中古英语 *trik* → 英语；本义“欺骗行为”，引申为“计谋、恶作剧、诡计”；进一步词源存疑（一说与拉丁 *tricari* 推诿有关）。
- **同根词**：tricky（trick + **-y** …的：狡猾的；棘手的）、trickery（trick + **-ery** 行为名词后缀：欺骗行为）、trickster（trick + **-ster** 人：骗子）、trickily（tricky + **-ly** 副词后缀：狡猾地）。
- **前缀·后缀**：后缀 **-y**（例：rainy, happy）、**-ery**（例：bravery, bakery）、**-ster**（例：gangster, youngster）。
- **同义·反义**：同义 deceive, cheat, prank；反义 无（作“诚实”义时反义 honesty）。
- **词性变化**：trick n. 诡计；tricky adj. 狡猾的；trickery n. 欺骗；trickster n. 骗子。

### 26. prince /prɪns/ n. 王子
- **词根·渊源**：拉丁 **princeps**（第一人、首领）= **primus**（第一）+ **capere**（拿、取）→ 古法语 *prince* → 英语；本义“居首位者”，引申为“王子、亲王”。
- **同根词**：princess（prince + **-ess** 女性后缀：公主）、princely（prince + **-ly** …的：王子的；慷慨的）、principal（prin 第一 + cip 拿 + **-al** …的：主要的）、principle（prin 第一 + cip 拿 + **-le** 名词后缀：原则）、prime（拉丁 primus 第一→首要的）。
- **前缀·后缀**：后缀 **-ess**（例：actress, waitress）、**-al**（例：natural, national）、**-le**（例：simple, table）。
- **同义·反义**：同义 ruler, royal heir；反义 无（作“平民”义时反义 commoner）。
- **词性变化**：princess n. 公主；princely adj. 王子的；principal adj. 主要的。

### 27. queen /kwiːn/ n. 女王；王后
- **词根·渊源**：古英语 **cwēn**（女人、妻子、王后）→ 中古英语 *quene* → 英语；与古诺尔斯语 *kvan*、哥特语 *qens* 同源，本义“女人、妻子”，后专指“王后、女王”。
- **同根词**：queenly（queen + **-ly** …的：女王般的）、queenship（queen + **-ship** 身份后缀：女王身份）、queen-size（queen + size 尺寸：大号的）。
- **前缀·后缀**：后缀 **-ly**（例：friendly, lovely）、**-ship**（例：friendship, leadership）。
- **同义·反义**：同义 monarch, empress；反义 无（作“国王”义时反义 king）。
- **词性变化**：queenly adj. 女王般的；queenship n. 女王身份。

### 28. punish /ˈpʌnɪʃ/ v. 处罚；惩罚
- **词根·渊源**：拉丁 **poena**（惩罚、代价）→ 古法语 *punir*（惩罚）→ 英语 *punish*；本义“施加惩罚”，引申为“处罚、惩罚”。
- **同根词**：punishment（punish + **-ment** 名词后缀：惩罚）、punishable（punish + **-able** 可…的：可惩罚的）、punitive（拉丁 punire 惩罚 + **-ive** …的：惩罚性的）、penalty（拉丁 poena 惩罚 + **-ty** 名词后缀：处罚）、penal（poena 惩罚 + **-al** …的：刑罚的）。
- **前缀·后缀**：后缀 **-ment**（例：achievement, development）、**-able**（例：readable, comfortable）、**-ive**（例：active, effective）。
- **同义·反义**：同义 penalize, discipline, chastise；反义 reward, forgive。
- **词性变化**：punishment n. 惩罚；punishable adj. 可惩罚的；punitive adj. 惩罚性的。

### 29. scene /siːn/ n. [戏剧中的]一场
- **词根·渊源**：希腊 **skēnē**（帐篷、舞台背景）→ 拉丁 *scaena* → 古法语 *scene* → 英语；本义“舞台上的布景”，引申为“戏剧中的一场”“场景”。
- **同根词**：scenery（scene + **-ery** 集合名词后缀：风景；舞台布景）、scenic（scene + **-ic** …的：风景优美的）、scenario（scene + **-ario** 意大利语名词后缀：剧情梗概；设想）、scenography（scene + graph 写 + **-y** 名词后缀：舞台布景术）。
- **前缀·后缀**：后缀 **-ery**（例：bakery, bravery）、**-ic**（例：music, magic）。
- **同义·反义**：同义 setting, stage, view；反义 无。
- **词性变化**：scenery n. 风景；scenic adj. 风景优美的；scenario n. 剧情梗概；设想。

### 30. sir /sɜː(r)/ n.（对男子或男教师的礼貌称呼）先生；长官
- **词根·渊源**：古法语 **sire**（老爷、君主）→ 中古英语 *sir* → 英语；源自拉丁 **senior**（年长者），本义“长者、老爷”，引申为对男子的尊称“先生、长官”。
- **同根词**：sire（古法语 sire 老爷→陛下；父畜）、senior（拉丁 senior 年长的→年长的；上级）、senate（拉丁 senatus 元老院→参议院）、senator（senate + **-or** 人：参议员）、senile（拉丁 senilis 年老的→衰老的）。
- **前缀·后缀**：后缀 **-or**（例：actor, doctor）。
- **同义·反义**：同义 mister, gentleman, officer；反义 madam（女性尊称）。
- **词性变化**：sire n. 陛下；senior adj. 年长的；senator n. 参议员。
