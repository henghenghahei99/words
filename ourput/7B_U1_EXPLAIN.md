## 二、逐词说文解字

### 1. advice /ədˈvaɪs/ n. 建议
- **词根·渊源**：拉丁 **vid-**（看）→ 古法语 *avis*（看法、意见）→ 英语 advice；本义“看后形成的看法”，引申为“建议”。
- **同根词**：visible（vis 看 + **-ible** 能…的 = 能看见的→可见的）、vision（vis 看 + **-ion** 名词后缀 = 看→视力、远见）、visit（vis 看 + **it** 去 = 去看→拜访）、evident（**e-** 出 + vid 看 + **-ent** …的 = 看得出来的→明显的）、provide（**pro-** 向前 + vid 看 = 向前看→预备、提供）、supervise（**super-** 在上 + vis 看 = 从上面看→监督）。
- **前缀·后缀**：名词后缀 **-ice**（例：service, justice）；前缀 **ad-**（例：advance, admire）。
- **同义·反义**：同义 suggestion, counsel；反义 无。
- **词性变化**：advise v. 建议；advisable adj. 明智的；adviser n. 顾问。

### 2. encourage /ɪnˈkʌrɪdʒ/ v. 鼓励；激励
- **词根·渊源**：拉丁 **cor / cord-**（心）→ 古法语 *corage*（勇气）→ 英语 courage；加前缀 **en-**（使…）构成，本义“给心打气”，即“鼓励”。
- **同根词**：courage（cor 心 + **-age** 名词后缀 = 由心而发的力量→勇气）、courageous（courage + **-ous** …的 = 勇敢的）、discourage（**dis-** 去除 + courage = 夺心→使气馁）、cordial（cord 心 + **-ial** …的 = 出自内心的→衷心的）、record（**re-** 回 + cord 心 = 记在心里→记录）、accord（**ac-** 向 + cord 心 = 心向心→一致）。
- **前缀·后缀**：动词化前缀 **en-**（例：enable, enlarge）；名词后缀 **-age**（例：marriage, package）。
- **同义·反义**：同义 inspire, motivate；反义 discourage, dishearten。
- **词性变化**：encouragement n. 鼓励；encouraging adj. 鼓舞人心的；encouraged adj. 受鼓舞的。

### 3. retire /rɪˈtaɪə(r)/ v. (令)退休；(使)退休
- **词根·渊源**：古法语 *retirer*（拉回、撤回）→ 英语 retire；**re-**（回）+ 古法语 *tirer*（拉），本义“拉回、撤退”，引申为“退职、退休”。
- **同根词**：retirement（retire + **-ment** 名词后缀 = 退休）、retired（retire + **-ed** …的 = 退休的）、tirade（法语 tirer 拉 + **-ade** 名词后缀 = 拉长的话→长篇抨击，存疑）。
- **前缀·后缀**：前缀 **re-**（例：return, recall）；后缀 **-ment**（例：movement, development）。
- **同义·反义**：同义 withdraw, step down；反义 无。
- **词性变化**：retirement n. 退休；retired adj. 退休的。

### 4. cheerful /ˈtʃɪəfl/ adj. 快乐的；高兴的
- **词根·渊源**：古法语 *chiere*（面容、神色）→ 英语 cheer（心情、欢呼）；加后缀 **-ful**（充满…的）构成，本义“满面喜色的”，即“快乐的”。
- **同根词**：cheer（cheer 面容→使振作→欢呼）、cheerfully（cheerful + **-ly** 副词后缀 = 快乐地）、cheerfulness（cheerful + **-ness** 名词后缀 = 快乐）、cheering（cheer + **-ing** …的 = 令人振奋的）。
- **前缀·后缀**：形容词后缀 **-ful**（例：helpful, useful）；副词后缀 **-ly**（例：quickly, happily）。
- **同义·反义**：同义 happy, joyful；反义 sad, gloomy。
- **词性变化**：cheer n./v. 欢呼；cheerfully adv. 快乐地；cheerfulness n. 快乐。

### 5. community /kəˈmjuːnəti/ n. 社区
- **词根·渊源**：拉丁 **communis**（共同的）→ 古法语 *comunete* → 英语 community；**com-**（共同）+ **munis**（义务、服务），本义“共同承担义务的人群”，引申为“社区”。
- **同根词**：common（com 共同 + mun 义务 = 共同的→普通的）、commune（com 共同 + mun 服务 = 公社）、communicate（commun 共同 + **-icate** 动词后缀 = 使共同→交流）、communism（commun 共同 + **-ism** 主义 = 共产主义）、communion（commun 共同 + **-ion** 名词后缀 = 共享→交流）。
- **前缀·后缀**：前缀 **com-**（例：combine, compare）；名词后缀 **-ity**（例：activity, ability）。
- **同义·反义**：同义 neighborhood, society；反义 无。
- **词性变化**：communal adj. 公共的；communicate v. 交流；communication n. 交流。

### 6. medical /ˈmedɪkl/ adj. 医学的；医疗的
- **词根·渊源**：拉丁 **medicus**（医生）→ 拉丁 *medicus*（医术的）→ 英语 medical；词根 **med-**（治疗），本义“与治疗有关的”，即“医学的”。
- **同根词**：medicine（med 治疗 + **-icine** 名词后缀 = 医学、药）、medicate（med 治疗 + **-icate** 动词后缀 = 用药治疗）、medication（medicate + **-ion** 名词后缀 = 药物治疗）、medic（med 治疗 + **-ic** 人 = 医生、医学生）。
- **前缀·后缀**：形容词后缀 **-al**（例：natural, national）；名词后缀 **-ine**（例：machine, routine）。
- **同义·反义**：同义 healing, therapeutic；反义 无。
- **词性变化**：medicine n. 医学；medically adv. 医学上；medicate v. 用药治疗。

### 7. fried /fraɪd/ adj. 油炸的；油煎的；油炒的
- **词根·渊源**：古法语 *frire*（油炸）→ 英语 fry；加后缀 **-ed** 构成过去分词作形容词，本义“被油炸过的”，即“油炸的”。
- **同根词**：fry（fry 油炸→油炸食物）、frying（fry + **-ing** …的 = 用于油炸的）、fryer（fry + **-er** 工具 = 油炸锅）。
- **前缀·后缀**：形容词后缀 **-ed**（例：boiled, baked）；动词后缀 **-er**（例：teacher, cooker）。
- **同义·反义**：同义 deep-fried, sautéed；反义 boiled, steamed。
- **词性变化**：fry v. 油炸；frying n. 油炸；fryer n. 油炸锅。

### 8. wherever /weərˈevə(r)/ conj. 各处；处处
- **词根·渊源**：古英语 **hwær**（哪里）+ **efre**（永远）→ 英语 wherever；**where**（哪里）+ **ever**（无论），本义“无论在哪里”，即“各处；处处”。
- **同根词**：where（where 哪里→在哪里）、whenever（when 何时 + ever 无论 = 无论何时）、whatever（what 什么 + ever 无论 = 无论什么）、whoever（who 谁 + ever 无论 = 无论谁）、however（how 如何 + ever 无论 = 无论如何）。
- **前缀·后缀**：后缀 **-ever**（例：whenever, whatever）；无前缀（复合词）。
- **同义·反义**：同义 anywhere, everywhere；反义 nowhere。
- **词性变化**：where adv. 在哪里；whenever conj. 无论何时；whatever pron. 无论什么。

### 9. future /ˈfjuːtʃə(r)/ n. 将来；未来
- **词根·渊源**：拉丁 **futurus**（将要发生的，是 esse“是”的将来分词）→ 古法语 *futur* → 英语 future；本义“将要成为的”，引申为“将来”。
- **同根词**：futuristic（future + **-istic** …的 = 未来主义的）、futurity（future + **-ity** 名词后缀 = 未来性）、futurology（future + **-ology** 学科 = 未来学）。
- **前缀·后缀**：名词后缀 **-ure**（例：nature, culture）；形容词后缀 **-istic**（例：artistic, realistic）。
- **同义·反义**：同义 tomorrow, prospect；反义 past, present。
- **词性变化**：futuristic adj. 未来主义的；futurity n. 未来性。

### 10. soon /suːn/ adv. 很快；马上；不久
- **词根·渊源**：古英语 **sōna**（立刻、马上）→ 中古英语 *sone* → 英语 soon；本义“立即”，引申为“很快；不久”。
- **同根词**：sooner（soon + **-er** 比较级 = 更早）、soonest（soon + **-est** 最高级 = 最早）。
- **前缀·后缀**：无前后缀（单纯词）；比较级后缀 **-er**（例：faster, later）。
- **同义·反义**：同义 shortly, presently；反义 later, eventually。
- **词性变化**：sooner adv. 更早；soonest adv. 最早。

### 11. smart /smɑːt/ adj. 聪明的；机敏的
- **词根·渊源**：古英语 **smeortan**（刺痛）→ 中古英语 *smert*（疼痛的、尖锐的）→ 英语 smart；本义“刺痛的”，引申为“敏锐的、机敏的、聪明的”。
- **同根词**：smartly（smart + **-ly** 副词后缀 = 聪明地）、smartness（smart + **-ness** 名词后缀 = 聪明）、smartphone（smart 智能 + phone 电话 = 智能手机）。
- **前缀·后缀**：副词后缀 **-ly**（例：quickly, badly）；名词后缀 **-ness**（例：kindness, darkness）。
- **同义·反义**：同义 clever, bright；反义 stupid, dull。
- **词性变化**：smartly adv. 聪明地；smartness n. 聪明；smartphone n. 智能手机。

### 12. attention /əˈtenʃn/ n. 专心；注意力
- **词根·渊源**：拉丁 **tendere**（伸展）→ 拉丁 *attendere*（伸向、注意）→ 古法语 *atencion* → 英语 attention；**ad-**（向）+ **tend-**（伸展），本义“把心思伸向某处”，即“注意力”。
- **同根词**：attend（**at-** 向 + tend 伸展 = 把心思伸向→出席、注意）、attentive（attend + **-ive** …的 = 注意的）、tend（tend 伸展→趋向）、tension（tens 伸展 + **-ion** 名词后缀 = 拉紧→紧张）、extend（**ex-** 出 + tend 伸展 = 向外伸→延伸）、intend（**in-** 向内 + tend 伸展 = 心思向内伸→打算）。
- **前缀·后缀**：前缀 **ad-**（例：advance, admire）；名词后缀 **-tion**（例：action, education）。
- **同义·反义**：同义 focus, concentration；反义 inattention, distraction。
- **词性变化**：attend v. 出席；attentive adj. 注意的；attentively adv. 专心地。

### 13. seldom /ˈseldəm/ adv. 不常；很少；难得
- **词根·渊源**：古英语 **seldan**（不常）→ 中古英语 *selden* → 英语 seldom；本义“不常”，即“很少；难得”。
- **同根词**：seldom 无常用同根派生词（存疑）。
- **前缀·后缀**：无前后缀（单纯词）。
- **同义·反义**：同义 rarely, infrequently；反义 often, frequently。
- **词性变化**：无。

### 14. bored /bɔːd/ adj. (对某人/事物)厌倦的；烦闷的
- **词根·渊源**：古英语 **borian**（钻孔）→ 英语 bore（钻孔→使厌烦）；加后缀 **-ed** 构成过去分词作形容词，本义“被钻透的”，引申为“被烦透的→厌倦的”。
- **同根词**：bore（bore 钻孔→使厌烦）、boring（bore + **-ing** …的 = 令人厌烦的）、boredom（bore + **-dom** 名词后缀 = 厌倦）。
- **前缀·后缀**：形容词后缀 **-ed**（例：tired, excited）；名词后缀 **-dom**（例：freedom, kingdom）。
- **同义·反义**：同义 tired, weary；反义 interested, excited。
- **词性变化**：bore v. 使厌烦；boring adj. 令人厌烦的；boredom n. 厌倦。

### 15. strict /strɪkt/ adj. 要求严格的；严厉的
- **词根·渊源**：拉丁 **stringere**（拉紧、束紧）→ 拉丁 *strictus*（拉紧的）→ 英语 strict；本义“被拉紧的”，引申为“严格约束的→严厉的”。
- **同根词**：strictly（strict + **-ly** 副词后缀 = 严格地）、strictness（strict + **-ness** 名词后缀 = 严格）、restrict（**re-** 回 + strict 拉紧 = 拉回→限制）、constrict（**con-** 一起 + strict 拉紧 = 一起拉紧→收缩）、stringent（string 拉紧 + **-ent** …的 = 严格的）。
- **前缀·后缀**：副词后缀 **-ly**（例：quickly, badly）；前缀 **re-**（例：return, recall）。
- **同义·反义**：同义 severe, stern；反义 lenient, lax。
- **词性变化**：strictly adv. 严格地；strictness n. 严格；restrict v. 限制。

### 16. relative /ˈrelətɪv/ n. 亲戚；亲属
- **词根·渊源**：拉丁 **referre**（带回、关联）→ 拉丁 *relativus*（有关的）→ 英语 relative；**re-**（回）+ **lat-**（带来），本义“有关系的（人）”，引申为“亲戚”。
- **同根词**：relate（**re-** 回 + lat 带来 = 带回关联→联系）、relation（relate + **-ion** 名词后缀 = 关系、亲属）、relationship（relation + **-ship** 名词后缀 = 关系）、relatively（relative + **-ly** 副词后缀 = 相对地）、translate（**trans-** 转移 + lat 带来 = 带过去→翻译）。
- **前缀·后缀**：前缀 **re-**（例：return, recall）；形容词后缀 **-ive**（例：active, creative）。
- **同义·反义**：同义 relation, kin；反义 stranger。
- **词性变化**：relate v. 联系；relation n. 关系；relatively adv. 相对地。

### 17. uniform /ˈjuːnɪfɔːm/ n. 制服；校服
- **词根·渊源**：拉丁 **unus**（一）+ **forma**（形状）→ 拉丁 *uniformis*（同一形状的）→ 英语 uniform；本义“形式统一的”，引申为“统一服装→制服”。
- **同根词**：uniformly（uniform + **-ly** 副词后缀 = 一致地）、uniformity（uniform + **-ity** 名词后缀 = 一致性）、form（form 形状→形式）、reform（**re-** 再 + form 形状 = 再塑形→改革）、inform（**in-** 进入 + form 形状 = 把形状放入心中→通知）、transform（**trans-** 转变 + form 形状 = 变形）。
- **前缀·后缀**：前缀 **uni-**（例：unicycle, unite）；词根 **form**（例：form, reform）。
- **同义·反义**：同义 outfit, dress；反义 无。
- **词性变化**：uniformly adv. 一致地；uniformity n. 一致性；form n. 形式。

### 18. personality /ˌpɜːsəˈnæləti/ n. 性格；个性
- **词根·渊源**：拉丁 **persona**（面具、角色）→ 拉丁 *personalitas* → 英语 personality；**person-**（人、角色）+ **-ality**（名词后缀），本义“作为人的特质”，即“性格；个性”。
- **同根词**：person（persona 面具→角色→人）、personal（person + **-al** …的 = 个人的）、personally（personal + **-ly** 副词后缀 = 亲自地）、personify（person + **-ify** 使…化 = 使人格化→体现）。
- **前缀·后缀**：名词后缀 **-ality**（例：reality, nationality）；形容词后缀 **-al**（例：natural, national）。
- **同义·反义**：同义 character, nature；反义 无。
- **词性变化**：person n. 人；personal adj. 个人的；personally adv. 亲自地。

### 19. characteristic /ˌkærəktəˈrɪstɪk/ n. 特点；品质
- **词根·渊源**：希腊 **kharakter**（刻印、标记）→ 拉丁 *character*（印记、特征）→ 法语 *caractéristique* → 英语；本义“刻下的印记”，引申为“区别于他物的标志→特点、品质”。
- **同根词**：character（kharakter 刻印 = 刻在人身上的印记→性格、角色）、characterize（character + **-ize** 使……化 = 刻画特征→描述……的特性）、characterization（characterize + **-ation** 名词化 = 特征刻画→人物塑造）。
- **前缀·后缀**：形容词后缀 **-istic**（例：realistic, artistic）。
- **同义·反义**：同义 feature, trait, quality；反义 无。
- **词性变化**：character n. 性格；characterize v. 描述……的特征；characteristically adv. 典型地。

### 20. topic /ˈtɒpɪk/ n. 话题；标题
- **词根·渊源**：希腊 **topos**（地方）→ 拉丁 *topica*（论题，亚里士多德书名《论题篇》）→ 英语；本义“（讨论所涉及的）地方”，引申为“话题、论题”。
- **同根词**：topical（topic + **-al** ……的 = 话题的→时事的）、topography（topo 地方 + **-graphy** 写 = 地方志→地形学）、toponym（topo 地方 + **-onym** 名 = 地名）。
- **前缀·后缀**：名词后缀 **-ic**（例：music, magic）。
- **同义·反义**：同义 subject, theme；反义 无。
- **词性变化**：topical adj. 话题的；topically adv.  topical 地。

### 21. active /ˈæktɪv/ adj. 忙碌的；活跃的
- **词根·渊源**：拉丁 **agere / act-**（做、驱动）→ 拉丁 *activus* → 英语；本义“正在做事的”，引申为“活跃的、忙碌的”。
- **同根词**：act（act 做 = 行动）、action（act + **-ion** 名词化 = 行动）、actor（act + **-or** 做的人 = 演员）、react（**re-** 回 + act 做 = 回做→反应）、exact（**ex-** 出 + act 做 = 做出来的→精确的）。
- **前缀·后缀**：形容词后缀 **-ive**（例：creative, native）。
- **同义·反义**：同义 busy, lively, energetic；反义 inactive, passive。
- **词性变化**：act v. 行动；activity n. 活动；actively adv. 活跃地。

### 22. smartphone /ˈsmɑːtfəʊn/ n. 智能手机
- **词根·渊源**：**smart**（聪明的，古英语 *smeortan* 刺痛→机敏的）+ **phone**（希腊 *phōnē* 声音→电话）；20 世纪末复合新词，本义“聪明的电话”，即“智能手机”。
- **同根词**：smartly（smart + **-ly** ……地 = 聪明地）、smartness（smart + **-ness** 名词化 = 聪明）、telephone（tele 远 + phone 声音 = 远声→电话）、microphone（micro 小 + phone 声音 = 小声音放大→麦克风）。
- **前缀·后缀**：无前后缀（复合词）。
- **同义·反义**：同义 mobile phone, cell phone；反义 无。
- **词性变化**：smart adj. 聪明的；phone n. 电话。

### 23. wisely /ˈwaɪzli/ adv. 聪明地；明智地
- **词根·渊源**：古英语 **wīs**（有智慧的，与 *witan* 知道同源）→ wise + **-ly**；本义“以有知识的方式”，即“明智地”。
- **同根词**：wise（wīs 知道 = 有智慧的）、wisdom（wise + **-dom** 状态 = 智慧）、wisely 之外的 unwise（**un-** 不 + wise = 不明智的）。
- **前缀·后缀**：副词后缀 **-ly**（例：quickly, happily）。
- **同义·反义**：同义 cleverly, sensibly；反义 foolishly, unwisely。
- **词性变化**：wise adj. 明智的；wisdom n. 智慧。

### 24. competition /ˌkɒmpəˈtɪʃn/ n. 比赛；竞赛
- **词根·渊源**：拉丁 **com-**（共同）+ **petere**（追求、寻求）→ 拉丁 *competere*（共同追求）→ 晚期拉丁 *competitio* → 英语；本义“共同追逐同一目标”，引申为“竞争、比赛”。
- **同根词**：compete（com 共同 + pete 追求 = 共同追求→竞争）、competitor（compete + **-itor** 人 = 竞争者）、competitive（compete + **-itive** ……的 = 竞争的）、appetite（**ad-** 向 + pete 追求 = 追求→食欲）、petition（pete 追求 + **-ition** = 请求）。
- **前缀·后缀**：前缀 **com-**（例：combine, compare）；名词后缀 **-ition**（例：condition, addition）。
- **同义·反义**：同义 contest, match, rivalry；反义 cooperation。
- **词性变化**：compete v. 竞争；competitor n. 竞争者；competitive adj. 竞争的。

### 25. shower /ˈʃaʊə(r)/ n. 淋浴
- **词根·渊源**：古英语 **scūr**（阵雨、急降）→ 中古英语 *shour* → 英语；本义“阵雨”，因淋浴如阵雨浇身，引申为“淋浴、淋浴器”。
- **同根词**：shower 的动词用法 shower（阵雨→淋浴）；同源词 存疑（与德语 *Schauer* 阵雨同源）。
- **前缀·后缀**：名词后缀 **-er**（例：worker, teacher）。
- **同义·反义**：同义 bath（淋浴义近）；反义 无。
- **词性变化**：shower v. 淋浴；showery adj. 阵雨的。

### 26. online /ˈɒnˈlaɪn/ adj. 在线的
- **词根·渊源**：**on**（在……上，古英语 *on*）+ **line**（线，拉丁 *linea*）；20 世纪计算机术语，本义“在（通信）线路上的”，即“在线的”。
- **同根词**：line（linea 线 = 线）、linear（line + **-ar** ……的 = 线的→线性的）、offline（**off-** 离开 + line 线 = 离线）、outline（**out-** 外 + line 线 = 外轮廓→大纲）。
- **前缀·后缀**：无前后缀（复合词）。
- **同义·反义**：同义 connected, on the Internet；反义 offline。
- **词性变化**：line n. 线；offline adj. 离线的。

### 27. site /saɪt/ n. 建筑工地
- **词根·渊源**：拉丁 **situs**（位置、地点，*sinere* 放置的过去分词）→ 古法语 *site* → 英语；本义“地点、位置”，引申为“（建筑的）场地、工地”。
- **同根词**：situate（situs 位置 + **-ate** 动词化 = 使位于）、situation（situate + **-ion** 名词化 = 位置→形势）、situated（situate + **-ed** ……的 = 位于……的）。
- **前缀·后缀**：无前后缀（单纯词）。
- **同义·反义**：同义 location, place, spot；反义 无。
- **词性变化**：situate v. 使位于；situation n. 位置；形势。

### 28. narrow /ˈnærəʊ/ adj. 狭窄的；窄小的
- **词根·渊源**：古英语 **nearu**（狭窄的、紧的）→ 中古英语 *narwe* → 英语；本义“紧的、窄的”，引申为“狭窄的、范围小的”。
- **同根词**：narrowly（narrow + **-ly** ……地 = 狭窄地→勉强地）、narrowness（narrow + **-ness** 名词化 = 狭窄）、narrow 的动词用法 narrow（使变窄）。
- **前缀·后缀**：无前后缀（单纯词）。
- **同义·反义**：同义 tight, thin；反义 wide, broad。
- **词性变化**：narrowly adv. 狭窄地；narrowness n. 狭窄。

### 29. superman /ˈsuːpəmæn/ n. 超人
- **词根·渊源**：拉丁 **super-**（在上、超过）+ 古英语 **man**（人）；本义“超过常人的人”，尼采哲学与漫画形象使其通行，即“超人”。
- **同根词**：super（super 在上 = 超级的）、supermarket（super 超级 + market 市场 = 超市）、supernatural（super 超 + natural 自然的 = 超自然的）、supervise（super 在上 + vis 看 = 从上看→监督）。
- **前缀·后缀**：前缀 **super-**（例：superstar, superpower）。
- **同义·反义**：同义 hero；反义 无。
- **词性变化**：super adj. 超级的；man n. 人。
