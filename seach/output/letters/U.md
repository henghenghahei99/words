# U

### ugly  /ˈʌɡli/  〔高中·CET4〕
- **释义**：adj. 丑陋的；可怕的
- **词源**：源自古诺斯语 uggligr（令人恐惧的），词根 uggr（恐惧）+ -ligr（…的）；经中古英语 ugli 进入英语；本义“令人害怕的”弱化为“难看的、丑陋的”，并保留“可怕的”义。
- **同根词**：ugliness（ugly + -ness 性质 = 丑陋）；uglify（**ugli-** 丑 + -fy 使… = 使变丑）；ugly-looking（ugly + looking 样子 = 难看的）；uggligr（古诺斯语“可怕的”，词源词）
- **词缀**：-ly 此处为形容词后缀（源自古诺斯语 -ligr），例：friendly（友好的）, lovely（可爱的）
- **同义·反义**：同义 hideous（丑陋可怕的）, unattractive（不好看的）；反义 beautiful（美丽的）, pretty（漂亮的）
- **变形**：形容词 → 比较级 uglier，最高级 ugliest；派生 → ugliness n. 丑陋；uglify v. 使变丑；uglily adv. 丑陋地

### ultimate  /ˈʌltɪmət/  〔CET4·CET6〕
- **释义**：adj. 最后的，最终的
- **词源**：词根 ultim（最远的，源自拉丁语 ultimus，ultra 超越的最高级）+ -ate（形容词后缀）；经晚期拉丁语 ultimatus → 英语；本义“最远的”引申为“最后的、最终的”。
- **同根词**：ultimately（ultimate + -ly …地 = 最终）；ultimatum（**ultim-** 最后 + -atum 中性名词 = 最后通牒）；ultra（**ultra-** 超越 = 极端的）；ultraviolet（**ultra-** 超越 + violet 紫 = 紫外的）；penultimate（**pen-** 几乎 + ultimate 最后 = 倒数第二的）
- **词缀**：-ate 表形容词“…的”，例：accurate（准确的）, fortunate（幸运的）
- **同义·反义**：同义 final（最后的）, last（最后的）；反义 initial（最初的）, first（第一的）
- **变形**：形容词 → 比较级 more ultimate，最高级 most ultimate；派生 → ultimately adv. 最终；ultimateness n. 终极性

### ultimately  /ˈʌltɪmətli/  〔CET4〕
- **释义**：adv. 最终，最后
- **词源**：ultimate（最后的，源自拉丁语 ultimus 最远的）+ -ly（…地）；本义“以最后的方式”即“最终”。
- **同根词**：ultimate（**ultim-** 最远 + -ate …的 = 最后的）；ultimatum（**ultim-** 最后 + -atum = 最后通牒）；ultra（**ultra-** 超越 = 极端的）；ultraviolet（**ultra-** 超越 + violet 紫 = 紫外的）；penultimate（**pen-** 几乎 + ultimate 最后 = 倒数第二的）
- **词缀**：-ly 表副词“…地”，例：finally（最终地）, quickly（迅速地）
- **同义·反义**：同义 finally（最终）, eventually（最后）；反义 initially（最初）, firstly（首先）
- **变形**：副词 → 比较级 more ultimately，最高级 most ultimately；派生 → ultimate adj. 最后的；ultimateness n. 终极性

### ultraviolet  /ˌʌltrəˈvaɪələt/  〔CET6〕
- **释义**：adj. 紫外的；紫外线的
- **词源**：前缀 ultra-（超越，源自拉丁语 ultra 在…之外）+ violet（紫色，源自古法语 violette，出自拉丁语 viola 紫罗兰）；19世纪科学术语；本义“在紫色之外的（光谱）”即今义。
- **同根词**：ultra（**ultra-** 超越 = 极端的）；ultimate（**ultim-** 最远 + -ate …的 = 最后的）；violet（紫罗兰；紫色，本词第二成分）；ultrasonic（**ultra-** 超越 + sonic 声的 = 超声的）；ultramodern（**ultra-** 超越 + modern 现代的 = 超现代的）
- **词缀**：ultra- 表“超越、在…之外”，例：ultrasonic（超声的）, ultramarine（群青色的）
- **同义·反义**：同义 UV（紫外线的，缩写）；反义 infrared（红外的）
- **变形**：形容词 → 比较级 more ultraviolet，最高级 most ultraviolet；派生 → ultraviolet n. 紫外线（作名词用）

### umbrella  /ʌmˈbrelə/  〔小学·初中·高中·CET4〕
- **释义**：n. 雨伞
- **词源**：词根 umbr（阴影，源自拉丁语 umbra 阴影）+ -ella（指小后缀）；经意大利语 ombrella → 英语；本义“小阴影”指遮阳伞，后泛指雨伞。
- **同根词**：umbrage（**umbr-** 阴影 + -age 状态 = 不悦；树荫）；umbra（**umbr-** 阴影 = 阴影，天文学用语）；umbral（umbra + -al …的 = 阴影的）；umbriferous（**umbr-** 阴影 + -ferous 带有 = 成荫的）；sombre（**sombr-** 阴影，同源 = 阴沉的）
- **词缀**：-ella 表指小（意大利语借入），例：novella（中篇小说）, umbrella 本身即例
- **同义·反义**：同义 parasol（遮阳伞）, sunshade（遮阳伞）；反义 无
- **变形**：名词 → 复数：复数 umbrellas；派生 → umbrellaed adj. 撑伞的（罕用）；umbrella-like adj. 伞状的

### unable  /ʌnˈeɪbl/  〔高中·CET4〕

- **词源**：前缀 un-（不）+ able（能够的，源自拉丁语 habilis 易握的，出自 habere 持有）；本义“不能够的”即今义。

- **词缀**：un- 表“不”，例：unhappy（不快乐的）, unfair（不公平的）
- **同义·反义**：同义 incapable（无能力的）, not able（不能的）；反义 able（能够的）, capable（有能力的）
- **变形**：形容词 → 比较级 more unable，最高级 most unable；派生 → inability n. 无能力；unably adv. 不能地（罕用）

### unanimous  /juːˈnænɪməs/  〔CET6〕
- **释义**：adj. 一致同意的，一致通过的
- **词源**：词根 un（一，源自拉丁语 unus 一）+ anim（心意，源自拉丁语 animus 心灵）+ -ous（…的）；经拉丁语 unanimus → 英语；本义“同一心意的”即“一致同意的”。
- **同根词**：unanimity（**un-** 一 + **anim-** 心 + -ity 性质 = 一致同意）；animus（**anim-** 心 = 敌意；意图）；animate（**anim-** 生命 + -ate 使… = 使有生气）；magnanimous（**magn-** 大 + **anim-** 心 + -ous …的 = 宽宏大量的）；equanimity（**equ-** 平 + **anim-** 心 + -ity 性质 = 镇定）
- **词缀**：-ous 表形容词“…的”，例：famous（著名的）, dangerous（危险的）
- **同义·反义**：同义 united（一致的）, concordant（协调的）；反义 divided（分歧的）, split（分裂的）
- **变形**：形容词 → 比较级 more unanimous，最高级 most unanimous；派生 → unanimously adv. 一致地；unanimity n. 一致同意
