# G

### gain  /ɡeɪn/  〔高中·CET4〕
- **释义**：vt. 获得，增加；n. 增进，收益
- **词源**：古法语 gaaignier（耕作，获利）→ 中古英语 gainen；源自日耳曼语，本义“耕作、狩猎所得”，引申为“获得、增加”。
- **同根词**：gainful（有收益的，gain + -ful）；gainer（获得者，gain + -er）；gainings（收益，gain + -ing）；regain（重新获得，re- 再 + gain）
- **词缀**：无（单纯词）
- **同义·反义**：同义 obtain（获得）, acquire（取得）；反义 lose（失去）, forfeit（丧失）
- **变形**：名词 → 复数：复数 gains；动词 → 第三人称单数 gains，过去式 gained，过去分词 gained，现在分词 gaining；派生 gainful adj. 有收益的；gainer n. 获得者

### galaxy  /ˈɡæləksi/  〔CET6〕
- **释义**：n. 星系；n. （首字母大写）银河系；n. 一群（杰出或著名的人物）
- **词源**：希腊语 galaxias（银河的），源自 gala（奶）→ 拉丁 galaxias → 古法语 galaxie → 英语；本义“乳汁般的银河”，后泛指星系，再引申为“一群杰出人物”。
- **同根词**：galactic（银河的，希腊 gala 奶 + -actic）；galaxy-wide（全星系的，galaxy + wide）；intergalactic（星系间的，inter- 之间 + galactic）
- **词缀**：无（单纯词）
- **同义·反义**：同义 nebula（星云）, assemblage（聚集）；反义 无
- **变形**：名词 → 复数：复数 galaxies；派生 galactic adj. 银河的

### gallery  /ˈɡæləri/  〔高中·CET4〕
- **释义**：n. 长廊，游廊；n. 画廊，美术馆
- **词源**：中世纪拉丁 galeria（门廊，长廊）→ 古法语 galerie → 英语；词源存疑，可能与 galilaea（教堂门廊）相关；本义“有顶的长廊”，后指陈列艺术品的“画廊”。
- **同根词**：galleried（有长廊的，gallery + -ed）；gallerist（画廊经营者，gallery + -ist）；gallery-goer（常去画廊的人，gallery + goer）
- **词缀**：后缀 -ery 表“场所、集合”，例：bakery（面包店）、nursery（托儿所）
- **同义·反义**：同义 corridor（走廊）, museum（博物馆）；反义 无
- **变形**：名词 → 复数：复数 galleries；派生 galleried adj. 有长廊的；gallerist n. 画廊经营者

- **词源**：词根 geo-（地球，希腊 gē）+ -logy（学科、论述，希腊 logia）；希腊 gē + logia → 近代拉丁 geologia → 英语 geology；本义“关于地球的论述”，即研究地球岩石与构造的学科。
- **同根词**：geography（**geo-** 地球 + -graphy 描述 = 地理学）, geologist（**geo-** 地球 + -logist 学者 = 地质学家）, biology（**bio-** 生命 + -logy 学科 = 生物学）, logic（**log-** 言说 + -ic = 逻辑）, geology 的派生 geological（**geo-** 地球 + -logical 学科的 = 地质的）
- **词缀**：前缀 geo-（地球），例：geocentric（地心的）；后缀 -logy（学科），例：psychology（心理学）
- **同义·反义**：同义 earth science（地球科学）；反义 无
- **变形**：复数 geologies；派生 geologist n. 地质学家；geological adj. 地质的；geologically adv. 地质上
