# Q

### quake  /kweɪk/  〔高中〕
- **释义**：vi. 颤抖，震动；n. 地震
- **词源**：词根 quak（摇动）+ 语源链：古英语 cwacian（颤抖）→ 中古英语 quaken → 英语 quake；本义“颤抖、摇动”，引申为“地震”。
- **同根词**：quiver（**qu** 摇动 → 颤抖）, quaver（**qu** 摇动 → 颤声）, earthquake（**earth** 地 + quake 震动 = 地震）
- **词缀**：无（单纯词）
- **同义·反义**：同义 tremble（颤抖）, shudder（战栗）；反义 steady（使稳定）
- **变形**：动词 → 第三人称单数：quakes；过去式：quaked；过去分词：quaked；现在分词：quaking；名词 → 复数：quakes；词性派生 → 形容词 quaky adj. 颤抖的

### qualification  /ˌkwɒlɪfɪˈkeɪʃn/  〔高中〕
- **释义**：n. 资格；条件；合格证书
- **词源**：词根 qual（何种，性质）+ 词根 fic（做）+ 后缀 -ation（名词）← 拉丁 qualis（何种）+ facere（做）；本义“使具备某种性质”，引申为资格、条件。
- **同根词**：qualify（qual 性质 + -ify 使 = 使合格）, quality（qual 性质 + -ity 名词 = 质量）, disqualify（dis- 否定 + qualify = 取消资格）, qualitative（qual 性质 + -ative …的 = 定性的）
- **词缀**：-ation 名词后缀，例：education（教育）；-fic 做，例：scientific（科学的）
- **同义·反义**：同义 certificate（证书）, requirement（条件）；反义 disqualification（取消资格）
- **变形**：名词 → 复数：复数 qualifications；派生 → qualify v. 使合格；qualified adj. 合格的；qualificatory adj. 资格上的

### qualify  /ˈkwɒlɪfaɪ/  〔CET4〕
- **释义**：vt. 使具有资格；vi. 取得资格；vt. 限定，修饰
- **词源**：词根 qual（性质、种类，拉丁 qualis “什么样的”）+ -ify（使……化，拉丁 -ificare）→ 中世纪拉丁 qualificare → 英语；本义“赋予某种性质”，引申为“使具备条件、取得资格”。
- **同根词**：quality（qual 性质 + -ity 名词后缀 = 性质、质量）, qualification（qualify + -ication 名词后缀 = 资格）, qualitative（qual 性质 + -ative 形容词后缀 = 定性的）, disqualified（dis- 否定 + qualify + -ed = 被取消资格的）
- **词缀**：前缀无；后缀 -ify 表“使……化”，例：simplify（简化）
- **同义·反义**：同义 entitle（使有权利）, certify（证明合格）；反义 disqualify（使不合格）
- **变形**：动词 → 第三人称单数：qualifies；过去式：qualified；过去分词：qualified；现在分词：qualifying；词性派生 → qualification n. 资格；qualified adj. 合格的；qualifier n. 预赛，限定词

### qualitative  /ˈkwɒlɪtətɪv/  〔CET6〕
- **释义**：adj. 质量上的，性质上的；（化学）定性的
- **词源**：词根 qual（何种，性质）+ 后缀 -itative（…的）← 拉丁 qualis（何种）；本义“关于性质的”，引申为定性的、质量上的。
- **同根词**：quality（qual 性质 + -ity 名词 = 质量）, qualify（qual 性质 + -ify 使 = 使合格）, qualification（qual 性质 + -ification 名词 = 资格）, quantitive（quant 量 + -itive …的 = 定量的）
- **词缀**：-ative …的，例：creative（创造的）；qual- 性质，例：quality（质量）
- **同义·反义**：同义 无；反义 quantitative（定量的）
- **变形**：形容词 → 比较级：比较级 more qualitative；最高级：最高级 most qualitative；派生 → qualitatively adv. 定性地；quality n. 质量

### quality  /ˈkwɒləti/  〔初中·高中·CET4〕

- **词源**：词根 qual（何种，性质）+ 后缀 -ity（名词）← 拉丁 qualis（何种）；本义“某物具有的性质”，引申为品质、质量。
- **同根词**：qualify（qual 性质 + -ify 使 = 使合格）, qualification（qual 性质 + -ification 名词 = 资格）, qualitative（qual 性质 + -ative …的 = 定性的）, disquality（dis- 否定 + quality = 无品质，罕用）

- **变形**：名词 → 复数：复数 qualities；派生 → qualitative adj. 定性的；qualitatively adv. 定性地；qualify v. 使合格

### quantify  /ˈkwɒntɪfaɪ/  〔CET6〕
- **释义**：v. 量度，确定数量，量化
- **词源**：词根 quant（多少，拉丁 quantus “多少”）+ -ify（使……化）→ 中世纪拉丁 quantificare → 英语；本义“确定数量”，即“量化”。
- **同根词**：quantity（quant 多少 + -ity 名词后缀 = 数量）, quantitative（quant 数量 + -itative 形容词后缀 = 定量的）, quantum（quant 多少 + -um 拉丁中性后缀 = 量子，定量）, quantifiable（quantify + -able 可……的 = 可量化的）
- **词缀**：前缀无；后缀 -ify 表“使……化”，例：clarify（澄清）
- **同义·反义**：同义 measure（测量）, calculate（计算）；反义 无
- **变形**：动词 → 第三人称单数：quantifies；过去式：quantified；过去分词：quantified；现在分词：quantifying；词性派生 → quantification n. 量化；quantitative adj. 定量的；quantifier n. 量词

### quantitative  /ˈkwɒntɪtətɪv/  〔CET6〕

- **词源**：词根 quant（多少）+ 后缀 -itative（…的）← 拉丁 quantus（多少）；本义“关于数量的”，引申为定量的。
- **同根词**：quantity（quant 多少 + -ity 名词 = 数量）, quantify（quant 多少 + -ify 使 = 量化）, quantum（quant 多少 = 量子）, qualitative（qual 性质 + -ative …的 = 定性的）
- **词缀**：-ative …的，例：creative（创造的）；quant- 多少，例：quantity（数量）
- **同义·反义**：同义 无；反义 qualitative（定性的）
- **变形**：形容词 → 比较级：比较级 more quantitative；最高级：最高级 most quantitative；派生 → quantitatively adv. 定量地；quantity n. 数量

### quantity  /ˈkwɒntəti/  〔高中·CET4〕
- **释义**：n. 量，数量；n. 分量

- **同根词**：quantify（**quant-** 多少 + **-ify** 使…化 = 量化）, quantitative（**quant-** 多少 + **-itative** 形容词后缀 = 定量的）, quantity（本词）, quantum（**quant-** 多少 + **-um** 中性名词后缀 = 量子；份额）
- **词缀**：后缀 **-ity** 表名词“性质、状态”，例：quality（质量）、reality（现实）

- **变形**：名词 → 复数：复数 quantities；派生 → quantitative adj. 定量的；quantify v. 量化
