# V

### vacant  /ˈveikənt/  〔高中·CET4·CET6〕
- **释义**：adj. 空的；未被占用的
- **词源**：词根 vac-（空，来自拉丁语 vacare“空着”）+ -ant（形容词后缀）→ 拉丁语 vacans → 古法语 vacant → 英语；本义“空着的”，引申为“未被占用的、空缺的”。
- **同根词**：vacancy（vac 空 + -ancy 名词后缀 = 空缺）, vacate（vac 空 + -ate 动词后缀 = 腾出）, vacation（vac 空 + -ation 名词后缀 = 假期）, vacuum（vac 空 + -uum 名词后缀 = 真空）, evacuee（e- 出 + vac 空 + -ee 人 = 被疏散者）
- **词缀**：后缀 -ant 表“处于……状态的”，例：distant（遥远的）, pleasant（令人愉快的）
- **同义·反义**：同义 empty（空的）, unoccupied（未被占用的）；反义 occupied（被占用的）, full（满的）
- **变形**：形容词 → 比较级 more vacant，最高级 most vacant；派生 vacancy n. 空缺；vacantly adv. 茫然地

### vacation  /veɪˈkeɪʃn/  〔初中·高中·CET4〕
- **释义**：n. 假期
- **词源**：词根 vac-（空，来自拉丁语 vacare“空着”）+ -ation（名词后缀）→ 拉丁语 vacatio“免除、空闲” → 古法语 vacation → 英语；本义“空闲、免除工作”，引申为“假期”。
- **同根词**：vacant（vac 空 + -ant ……的 = 空的）, vacancy（vac 空 + -ancy 名词后缀 = 空缺）, vacate（vac 空 + -ate 动词后缀 = 腾出）, vacuum（vac 空 + -uum 名词后缀 = 真空）, evacuee（e- 出 + vac 空 + -ee 人 = 被疏散者）
- **词缀**：后缀 -ation 表“行为、状态”，例：creation（创造）, education（教育）
- **同义·反义**：同义 holiday（假日）, break（休息）；反义 workday（工作日）
- **变形**：名词 → 复数：复数 vacations；派生 vacationer n. 度假者；vacation vi. 度假（vacationed, vacationed, vacationing）

### vacuum  /ˈvækjuəm/  〔CET4〕
- **释义**：n. 真空；真空吸尘器
- **词源**：词根 vac-（空，来自拉丁语 vacare“空着”）+ -uum（中性名词后缀）→ 拉丁语 vacuum“空处” → 英语；本义“空的空间”，引申为“真空”，再指“真空吸尘器”。
- **同根词**：vacant（vac 空 + -ant ……的 = 空的）, vacancy（vac 空 + -ancy 名词后缀 = 空缺）, vacate（vac 空 + -ate 动词后缀 = 腾出）, vacation（vac 空 + -ation 名词后缀 = 假期）, evacuee（e- 出 + vac 空 + -ee 人 = 被疏散者）
- **词缀**：后缀 -uum 表中性名词，例：museum（博物馆）, forum（论坛）
- **同义·反义**：同义 void（空虚）, emptiness（空）；反义 matter（物质）, fullness（充满）
- **变形**：名词 → 复数：复数 vacuums 或 vacua；派生 vacuum vt. 用吸尘器清扫（vacuumed, vacuumed, vacuuming）

### vague  /veig/  〔高中·CET4〕
- **释义**：adj. 模糊的，含糊的
- **词源**：词根 vag-（漫游，来自拉丁语 vagus“漫游的、不定的”）→ 法语 vague → 英语；本义“游移不定的”，引申为“模糊的、含糊的”。
- **同根词**：vagabond（vaga 漫游 + -bond 人 = 流浪者）, vagary（vag 漫游 + -ary 名词后缀 = 奇想）, vagrant（vagr 漫游 + -ant 人 = 流浪者）, divagate（di- 离开 + vag 漫游 + -ate 动词后缀 = 离题）, extravagance（extra- 超出 + vag 漫游 + -ance 名词后缀 = 奢侈）
- **词缀**：无（单纯词，源自拉丁语 vagus）
- **同义·反义**：同义 unclear（不清楚的）, ambiguous（模棱两可的）；反义 clear（清楚的）, definite（明确的）
- **变形**：形容词 → 比较级 vaguer，最高级 vaguest；派生 vaguely adv. 模糊地；vagueness n. 模糊

- **词缀**：后缀 -eer 表“从事……的人”，例：engineer（工程师）
- **同义·反义**：同义 offer（主动提出）, enlist（自愿加入）；反义 conscript（征召）
- **变形**：名词 → 复数：volunteers；动词 → 第三人称单数：volunteers；过去式：volunteered；过去分词：volunteered；现在分词：volunteering；形容词派生：voluntary adj. 自愿的

### vote  /vəʊt/  〔高中·CET4〕
- **释义**：n. 选举，投票，表决；v. 投票，表决
- **词源**：词根 vot（许愿、发誓）← 拉丁 votum（许愿、誓言）→ 中世纪拉丁 votare（投票）→ 英语 vote；本义“许愿、表达意愿”，引申为“投票、表决”。
- **同根词**：voter（**vot-** 投票 + -er 人 = 投票者）；devote（**de-** 加强 + vot 许愿 = 献身）；votive（**vot-** 许愿 + -ive 形容词 = 许愿的）；devotion（**de-** 加强 + vot 许愿 + -ion 名词 = 献身）
- **词缀**：无（单纯词）
- **同义·反义**：同义 ballot（投票）, elect（选举）；反义 abstain（弃权）
- **变形**：名词 → 复数：votes；动词 → 第三人称单数：votes；过去式：voted；过去分词：voted；现在分词：voting；名词派生：voter n. 投票者

### Voyage  /ˈvɔɪɪdʒ/  〔初中·高中·CET4〕
- **释义**：n. 航行；航海；旅行
- **词源**：词根 voy（道路）+ -age（名词后缀）← 拉丁 viaticum（旅途所需）← via（道路）→ 古法语 voiage → 英语 voyage；本义“旅程”，引申为“航行、航海”。
- **同根词**：via（**via-** 道路 = 经由）；viaduct（**via-** 道路 + duct 引导 = 高架桥）；deviate（**de-** 离开 + vi 道路 + -ate = 偏离）；obvious（**ob-** 在前 + vi 道路 + -ous = 挡在路上→明显的）
- **词缀**：后缀 -age 表“行为、状态”，例：marriage（婚姻）
- **同义·反义**：同义 journey（旅行）, cruise（航行）；反义 无
- **变形**：名词 → 复数：voyages；动词 → 第三人称单数：voyages；过去式：voyaged；过去分词：voyaged；现在分词：voyaging；名词派生：voyager n. 航行者

### vulgar  /ˈvʌlɡə/  〔CET6〕
- **释义**：adj. 粗鲁的，卑下的；adj. 庸俗的，低级的
- **词源**：词根 vulg-（平民，大众）+ 拉丁语 vulgāris（大众的）→ 英语 vulgar；本义“普通民众的”，后因阶层偏见引申为“粗俗的、低级的”。
- **同根词**：vulgarity（vulgar 粗俗 + -ity 名词后缀 = 粗俗）, vulgarize（vulgar 粗俗 + -ize 动词后缀 = 使粗俗化）, divulge（di- 分开 + vulg 大众 = 向大众泄露）, vulgate（vulg 大众 + -ate = 通俗拉丁文本）, vulgarly（vulgar 粗俗 + -ly 副词后缀 = 粗俗地）
- **词缀**：无（借自拉丁语的整体词）；例：无
- **同义·反义**：同义 rude（粗鲁的）, coarse（粗俗的）；反义 refined（文雅的）, elegant（优雅的）
- **变形**：形容词 → 比较级 more vulgar，最高级 most vulgar；名词派生 vulgarity n. 粗俗；副词派生 vulgarly adv. 粗俗地

### vulnerable  /ˈvʌlnərəbl/  〔CET6〕
- **释义**：adj. 易受攻击的，有弱点的；adj. 易受伤害的，脆弱的，敏感的
- **词源**：词根 vulner-（伤）+ 拉丁语 vulnerāre（使受伤）+ -able（能…的）→ 英语 vulnerable；本义“能被伤害的”，引申为“易受攻击的、脆弱的”。
- **同根词**：vulnerability（vulner 伤 + -ability 能力 = 脆弱性）, vulnerably（vulnerable + -ly 副词后缀 = 脆弱地）, invulnerable（in- 不 + vulner 伤 + -able = 不会受伤的）, vulnerary（vulner 伤 + -ary = 治伤的）, vulnerate（vulner 伤 + -ate = 使受伤）
- **词缀**：后缀 -able 表“能…的”；例：readable（read 读 + -able = 可读的）
- **同义·反义**：同义 weak（虚弱的）, susceptible（易受影响的）；反义 invulnerable（不会受伤的）, protected（受保护的）
- **变形**：形容词 → 比较级 more vulnerable，最高级 most vulnerable；名词派生 vulnerability n. 脆弱性；副词派生 vulnerably adv. 脆弱地
