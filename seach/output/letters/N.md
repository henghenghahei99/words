# N

### nail  /neɪl/  〔初中·高中·CET4〕
- **释义**：n. 钉；钉子；指甲；v. 钉住
- **词源**：词根 nægl-（指甲、钉）；古英语 nægl（指甲、钉子）→ 中古英语 nail → 英语 nail。本义指指甲，因形似而引申为“钉子”，再引申为“钉住”。
- **同根词**：nailer（**nail** + -er 人 = 钉钉者）；nailfile（**nail** 指甲 + file 锉 = 指甲锉）；nailbrush（**nail** 指甲 + brush 刷 = 指甲刷）；nailhead（**nail** 钉 + head 头 = 钉头）
- **词缀**：无（单纯词，古英语 nægl）
- **同义·反义**：同义 spike（长钉）, tack（图钉）；反义 无
- **变形**：名词 → 复数：复数 nails；动词 → 三单 nails，过去式 nailed，过去分词 nailed，现在分词 nailing；派生 → nailer n. 钉钉者

### naive  /nɑːˈiːv/  〔CET6〕
- **释义**：adj. 幼稚的；无知的；天真的
- **词源**：词根 naiv-（天生的、自然的）；拉丁语 nativus（天生的）→ 法语 naïve（天真的）→ 英语 naive。本义指“天生的、自然的”，引申为“天真的、幼稚的”。
- **同根词**：native（**nat-** 出生 + -ive 形容词后缀 = 本地的）；nature（**nat-** 出生 + -ure 名词后缀 = 自然）；natal（**nat-** 出生 + -al 形容词后缀 = 出生的）；nation（**nat-** 出生 + -ion 名词后缀 = 民族）
- **词缀**：无（单纯词，源自法语 naïve）
- **同义·反义**：同义 innocent（天真的）, childish（幼稚的）；反义 sophisticated（老练的）, mature（成熟的）
- **变形**：形容词 → 比较级 naiver，最高级 naivest；派生 → naively adv. 天真地；naivety n. 天真

- **词缀**：后缀 -ed（表形容词，例：wicked 邪恶的）
- **同义·反义**：同义 bare（赤裸的）, nude（裸体的）；反义 clothed（穿衣的）, covered（覆盖的）
- **变形**：形容词 → 比较级 more naked，最高级 most naked；派生 → nakedly adv. 赤裸地；nakedness n. 裸体

### napkin  /ˈnæpkɪn/  〔CET6〕
- **释义**：n. 餐巾；n. 餐巾纸
- **词源**：源自古法语 nappe（桌布）+ -kin（指小后缀），可追溯至拉丁语 mappa（布、餐巾）；本义“小桌布”，后专指进餐时用的方巾。

- **词缀**：后缀 -kin 表“小”，例：lambkin（小羊羔）
- **同义·反义**：同义 serviette（餐巾）, table napkin（餐巾）；反义 无
- **变形**：名词 → 复数：复数 napkins；派生 napkinful n. 一餐巾之量（罕用）

- **词缀**：无（借词，源自拉丁 nutrire）
- **同义·反义**：同义 caregiver（护理者）, tend（照料）；反义 无
- **变形**：复数：nurses；第三人称单数：nurses；过去式：nursed；过去分词：nursed；现在分词：nursing；派生：nursing n. 护理；nursery n. 托儿所

### nursery  /ˈnɜːsəri/  〔高中·CET4〕
- **释义**：n. 托儿所；苗圃
- **词源**：nurs-（养育，见 nurse）+ -ery（名词后缀，表场所）→ 英语 nursery；本义“养育幼儿的场所”，引申为“培育植物幼苗的场所（苗圃）”。
- **同根词**：nurse（养育者→护士）；nurture（nurt 滋养 + -ure = 养育）；nursing（nurs + -ing = 护理）；nourish（nour 滋养 + -ish = 滋养）
- **词缀**：-ery 名词后缀，表场所、行为，例：bakery（面包店）
- **同义·反义**：同义 creche（托儿所）, seedbed（苗床）；反义 无
- **变形**：名词 → 复数：复数 nurseries；派生 → nurseryman n. 苗圃工人

### nurture  /ˈnɜːtʃə/  〔CET6〕
- **释义**：v. 养育，教育；v. 培育，扶植；n. 养育，培养
- **词源**：词根 nour/nutr（滋养）+ 古法语 nourriture（食物，养育）→ 中古英语 norture → 英语 nurture；本义“喂养、供给营养”，引申为“养育、培育”。
- **同根词**：nourish（nour 滋养 + -ish 动词后缀 = 滋养）, nutrition（nutr 滋养 + -ition 名词后缀 = 营养）, nutritious（nutrit 营养 + -ious …的 = 有营养的）, nurse（nurs 滋养 + -e = 护士，哺育）, nutrient（nutri 滋养 + -ent 名词后缀 = 营养素）
- **词缀**：后缀 -ure 表名词“行为/结果”，例：failure（失败）
- **同义·反义**：同义 foster（培养）, cultivate（培育）；反义 neglect（忽视）, starve（使挨饿）
- **变形**：动词 → 第三人称单数：nurtures；过去式：nurtured；过去分词：nurtured；现在分词：nurturing；名词：nurture n. 养育；形容词：nurturing adj. 养育的；副词：nurturingly adv. 养育地；名词 → 不可数

### nut  /nʌt/  〔高中·CET4〕
- **释义**：n. 坚果，干果；螺母
- **词源**：源自古英语 hnutu（坚果），与古诺尔斯语 hnot、德语 Nuss 同源，原始日耳曼语 *khnut-；本义“硬壳果”，因螺母形似坚果而得名“螺母”。
- **同根词**：nutmeg（nut 坚果 + meg 麝香 = 肉豆蔻）；nutrient（nutri 滋养 + -ent = 营养物，与 nut 同源存疑）；nutty（nut + -y 形容词后缀 = 有坚果味的；古怪的）；nutshell（nut + shell 壳 = 坚果壳）
- **词缀**：无（单纯词）
- **同义·反义**：同义 kernel（果仁）, seed（种子）；反义 无
- **变形**：名词 → 复数：复数 nuts；派生 → nutty adj. 有坚果味的；nuts adj. 发疯的（俚）

### nutrition  /njuːˈtrɪʃən/  〔高中·CET6〕
- **释义**：n. 营养，滋养；营养物，食物
- **词源**：nutri-（滋养，拉丁 nutrire 滋养）+ -tion（名词后缀，表行为、结果）→ 拉丁 nutritio → 古法语 nutrition → 英语 nutrition；本义“滋养的过程”，引申为“营养、营养物”。
- **同根词**：nutrient（nutri 滋养 + -ent = 营养物）；nurture（nurt 滋养 + -ure = 养育）；nurse（养育者→护士）；nutritious（nutri 滋养 + -tious 形容词后缀 = 有营养的）
- **词缀**：-tion 名词后缀，表行为、结果，例：action（行动）
- **同义·反义**：同义 nourishment（营养）, sustenance（食物）；反义 malnutrition（营养不良）
- **变形**：名词 → 复数：复数 nutritions（罕用）；派生 → nutritional adj. 营养的；nutritionist n. 营养学家；nutritious adj. 有营养的

### nylon  /ˈnaɪlɒn/  〔CET4〕
- **释义**：n. 尼龙，耐纶
- **词源**：20世纪30年代美国杜邦公司为合成纤维所造商品名，词源不确定；通行说法认为由 -on（仿 cotton 棉、rayon 人造丝等纤维词尾）构成，nyl- 部分来源存疑（一说取自 New York 与 London 的缩合，未证实）。
- **同根词**：rayon（人造丝，-on 纤维词尾）；cotton（棉，-on 词尾类比）；nylons（nylon + -s = 尼龙长袜）；nylonase（nylon + -ase 酶后缀 = 尼龙酶）
- **词缀**：-on 名词后缀（仿纤维类词），例：rayon（人造丝）
- **同义·反义**：同义 polyamide（聚酰胺，尼龙的化学名）；反义 无
- **变形**：名词 → 复数：复数 nylons（亦指尼龙长袜）；派生 → nylon adj. 尼龙的（作定语）
