# W

### wag  /wæɡ/  〔高中〕
- **释义**：v. 摇摆，摇动（尤指尾巴）；n. 摇动
- **词源**：词根源自古英语 wagian（摇动、摆动）→ 中古英语 waggen → 英语 wag；本义“摇动”，今义保留“（尾巴等）摇摆”。
- **同根词**：waggle（**wag-** 摇动 + -le 反复 = 来回摇动）；waggish（**wag-** 摇动 + -ish 形容词 = 爱开玩笑的）；wagtail（**wag-** 摇动 + tail 尾 = 鹡鸰）
- **词缀**：无（单纯词）
- **同义·反义**：同义 waggle（摇摆）, swing（摆动）；反义 still（使静止）
- **变形**：名词 → 复数：wags；动词 → 第三人称单数：wags；过去式：wagged；过去分词：wagged；现在分词：wagging

### wage  /weɪdʒ/  〔高中·CET4〕
- **释义**：n. 工资，报酬；v. 进行，发动（战争等）
- **词源**：词根源自古法语 wage（抵押、报酬）← 日耳曼语 *wadja（抵押）→ 英语 wage；本义“抵押、报酬”，引申为“工资”，动词义“以……为担保→进行（战争）”。
- **同根词**：wager（**wag-** 抵押 + -er 名词 = 赌注）；wages（**wage-** 工资 + -s 复数 = 工资）；wage-earner（**wage-** 工资 + earner 挣得者 = 工薪族）
- **词缀**：无（单纯词）
- **同义·反义**：同义 pay（报酬）, salary（薪水）；反义 无
- **变形**：名词 → 复数：wages；动词 → 第三人称单数：wages；过去式：waged；过去分词：waged；现在分词：waging

- **释义**：n. 四轮运货马车；n. 铁路货车
- **词源**：词根 wag-（摇动）+ 中古荷兰语 wagen（车）→ 英语 waggon（wagon 的英式拼写）；本义“会摇动的车”，指四轮运货车。
- **同根词**：wagon（waggon 的美式拼写 = 运货车）, wagoner（wagon 车 + -er 人 = 车夫）, wagonette（wagon 车 + -ette 小 = 轻便马车）, station wagon（station 站 + wagon 车 = 旅行车）, wagonload（wagon 车 + load 装载 = 一车之量）
- **词缀**：无（借自荷兰语的整体词）；例：无
- **同义·反义**：同义 cart（马车）, carriage（马车）；反义 无
- **变形**：名词 → 复数：复数 waggons；名词派生 waggoner n. 车夫

- **词缀**：无（单纯词，wrongly 中 -ly 为后缀）
- **同义·反义**：同义 incorrect（错误的）, mistaken（弄错的）；反义 right（正确的）, correct（正确的）
- **变形**：形容词 → 比较级 wronger / 最高级 wrongest（或 more/most wrong）；副词 wrongly 错误地；名词 wrong 错误；wrongness n. 错误；wrongful adj. 不正当的
