# Z

### zeal  /ziːl/  〔CET4〕
- **释义**：n. 热心；n. 热情；n. 热忱
- **词源**：源自拉丁语 zelus“热情”，借自希腊语 zēlos“热忱、竞争心”；经古法语 zel 进入英语，本义“强烈的热情”，引申为“热心、热忱”。
- **同根词**：zealous（zeal 热情 + -ous …的 = 热心的）, zealot（zeal 热情 + -ot 人 = 狂热者）, zealously（zealous + -ly = 热心地）, jealous（源自同一希腊词根 zēlos，嫉妒的）
- **词缀**：无（单纯词；相关后缀 -ous 见 zealous）
- **同义·反义**：同义 enthusiasm（热情）, passion（热忱）；反义 indifference（冷漠）, apathy（无动于衷）
- **变形**：复数 zeals（少用）；派生 zealous adj. 热心的；zealously adv. 热心地；zealousness n. 热心

### zealous  /ˈzeləs/  〔CET4〕
- **释义**：adj. 热心的；adj. 热情的；adj. 狂热的
- **词源**：zeal（热情）+ -ous（充满…的）；zeal 源自希腊语 zēlos“热忱”，加后缀表示“充满热情的”，引申为“热心的”。
- **同根词**：zeal（热情）, zealot（狂热者）, zealously（zealous + -ly = 热心地）, jealous（同源，嫉妒的）
- **词缀**：后缀 -ous 表“充满…的”，例：famous（著名的）
- **同义·反义**：同义 enthusiastic（热情的）, passionate（热忱的）；反义 indifferent（冷漠的）, apathetic（无动于衷的）
- **变形**：比较级 more zealous，最高级 most zealous；派生 zealously adv. 热心地；zealousness n. 热心；名词形式 zeal n. 热情

### zebra  /ˈziːbrə; (US) ˈziːbrə/  〔高中·CET4〕
- **释义**：n. 斑马；n. 斑马纹（作定语）
- **词源**：源自意大利语 zebra，可能经葡萄牙语或刚果语系语言传入，原指非洲一种马科动物；词源细节存疑，18 世纪进入英语，指“斑马”。
- **同根词**：zebrine（zebra 斑马 + -ine …的 = 斑马的，罕用）, zebrawood（zebra 斑马 + wood 木 = 斑马木）, zebra crossing（斑马线，复合词）, zebra fish（斑马鱼，复合词）
- **词缀**：无（单纯词；相关后缀 -ine 见 zebrine）
- **同义·反义**：同义 无（动物专名）；反义 无
- **变形**：复数 zebras（英式也可作 zebra）；无动词、形容词三级变形；派生 zebrine adj. 斑马的（罕用）

### zero  /ˈzɪərəʊ; (US) ˈzɪroʊ/  〔初中·高中·CET4〕
- **释义**：num. 零；n. 零度；n. 零点
- **词源**：源自阿拉伯语 ṣifr“空、零”，经中世纪拉丁语 zephirum、意大利语 zero 进入英语，本义“空无”，引申为数字“零”及“零度、零点”。
- **同根词**：cipher（源自同一阿拉伯词 ṣifr，密码/零）, decipher（de- 去除 + cipher 密码 = 破译）, zilch（零，口语，可能同源）, nil（零，同义常用词）
- **词缀**：无（单纯词）
- **同义·反义**：同义 nil（零）, nought（零）；反义 无
- **变形**：复数 zeros 或 zeroes；动词 zero 的第三人称单数 zeroes，过去式 zeroed，过去分词 zeroed，现在分词 zeroing；派生 zeroed adj. 归零的；zeroing n. 归零

### zinc  /zɪŋk/  〔CET6〕
- **释义**：n. 锌（金属元素）；vt. 镀锌
- **词源**：源自德语 Zink，可能来自德语 Zinke“尖齿、叉齿”（因锌矿石结晶形状），16 世纪进入英语，指金属锌；词源细节存疑。
- **同根词**：zincic（zinc 锌 + -ic …的 = 锌的）, zincify（zinc 锌 + -ify 使…化 = 镀锌）, zincous（zinc + -ous …的 = 含锌的）, zincate（zinc + -ate 盐 = 锌酸盐）
- **词缀**：无（单纯词；相关后缀 -ic 见 zincic）
- **同义·反义**：同义 无（化学元素专名）；反义 无
- **变形**：复数 zincs；动词 zinc 的第三人称单数 zincs，过去式 zincked 或 zinced，过去分词 zincked 或 zinced，现在分词 zincking 或 zincing；派生 zincic adj. 锌的；zincify v. 镀锌

### zip  /zɪp/  〔高中〕
- **释义**：n. 拉链；v. 拉上拉链；v. 快速移动
- **词源**：拟声词，模拟快速移动或拉链拉合的声音；19 世纪英语中作动词表示“嗖地快速移动”，后引申为“拉链”及“拉上拉链”。词源存疑。
- **同根词**：zipper（zip 拉链 + -er 物 = 拉链）, zippy（zip 活力 + -y …的 = 活泼的）, zippily（zippy + -ly = 活泼地）, unzip（un- 相反 + zip 拉上 = 拉开拉链）
- **词缀**：无（单纯词；相关后缀 -er 见 zipper）
- **同义·反义**：同义 fastener（扣件）, dash（疾冲）；反义 unzip（拉开拉链）
- **变形**：复数 zips；动词 zip 的第三人称单数 zips，过去式 zipped，过去分词 zipped，现在分词 zipping；派生 zippy adj. 活泼的；zippily adv. 活泼地

### zipper  /ˈzɪpə(r)/  〔高中〕
- **释义**：n. 拉链；v. 拉上拉链
- **词源**：zip（拉链/拟声）+ -er（表物）；zip 为拟声词，模拟拉合声，加 -er 表示“拉合的东西”，即“拉链”，20 世纪美式英语常用。
- **同根词**：zip（拉链）, zippy（活泼的）, unzip（拉开拉链）, zippered（zipper + -ed = 带拉链的）
- **词缀**：后缀 -er 表“物、工具”，例：clipper（剪刀/快船）
- **同义·反义**：同义 zip（拉链）, fastener（扣件）；反义 无
- **变形**：复数 zippers；动词 zipper 的第三人称单数 zippers，过去式 zippered，过去分词 zippered，现在分词 zippering；派生 zippered adj. 带拉链的

### zone  /zəʊn; (US) zoʊn/  〔高中·CET4〕
- **释义**：n. 地区；n. 区域；n. 范围
- **词源**：源自希腊语 zōnē“腰带、带子”，经拉丁语 zona、法语 zone 进入英语，本义“环绕的带子”，引申为地球上划分的“地带”，再泛指“地区、区域、范围”。
- **同根词**：zonal（zone 地带 + -al …的 = 地带的）, zoning（zone + -ing 名词 = 分区规划）, zonate（zone + -ate …的 = 有环带的）, zonation（zone + -ation 名词 = 分带）
- **词缀**：无（单纯词；相关后缀 -al 见 zonal）
- **同义·反义**：同义 area（地区）, region（区域）；反义 无
- **变形**：复数 zones；动词 zone 的第三人称单数 zones，过去式 zoned，过去分词 zoned，现在分词 zoning；派生 zonal adj. 地带的；zoned adj. 分区的；zoning n. 分区规划

### zoo  /zuː/  〔初中·高中·CET4〕
- **释义**：n. 动物园
- **词源**：缩略自 zoological garden（动物学园）；zoological 源自希腊语 zōion“动物”+ -logia“学科”，19 世纪缩略为 zoo，指“动物园”。
- **同根词**：zoology（zoo 动物 + -logy 学科 = 动物学）, zoological（zoology + -ical …的 = 动物学的）, zoologist（zoology + -ist 人 = 动物学家）, zooplankton（zoo 动物 + plankton 浮游生物 = 浮游动物）
- **词缀**：无（缩略词；相关词根 zoo- 表“动物”，例：zoology 动物学）
- **同义·反义**：同义 menagerie（动物园/兽苑）；反义 无
- **变形**：复数 zoos；无动词、形容词三级变形；派生 zoological adj. 动物学的；zoologically adv. 动物学上；zoology n. 动物学

### zoom  /zuːm/  〔高中〕
- **释义**：v. 快速移动（常带轰鸣声）；v. 缩放（镜头/图像）；n. 变焦镜头
- **词源**：拟声词，模拟快速移动的嗡嗡声或轰鸣声；19 世纪末英语中表示“嗡嗡作响地快速移动”，20 世纪引申为摄影“变焦、缩放”。词源存疑。
- **同根词**：zoomy（zoom 快速 + -y …的 = 快速的，口语）, zoomable（zoom + -able 可…的 = 可缩放的）, zoomer（zoom + -er 人/物 = 快速移动者/变焦镜头）, zoom lens（变焦镜头，复合词）
- **词缀**：无（单纯词；相关后缀 -able 见 zoomable）
- **同义·反义**：同义 dash（疾冲）, speed（快速移动）；反义 crawl（缓慢移动）, creep（爬行）
- **变形**：复数 zooms；动词 zoom 的第三人称单数 zooms，过去式 zoomed，过去分词 zoomed，现在分词 zooming；派生 zoomable adj. 可缩放的；zoomy adj. 快速的（口语）
