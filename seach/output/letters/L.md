# L

### lab  /læb/  〔初中·高中·CET4〕
- **释义**：n. 实验室（laboratory 的缩略形式）
- **词源**：laboratory 的口语缩略。laboratory 源自拉丁语 laborare（劳动、工作）+ -torium（场所），本义“劳作之处”，后专指进行科学实验的场所，缩略为 lab。
- **同根词**：laboratory（**labor** 劳动 + **-atory** 场所 = 实验室）；labor（劳动）；laborious（**labor** 劳动 + **-ious** 多……的 = 费力的）；collaborate（**col-** 共同 + labor 劳动 + **-ate** = 合作）
- **词缀**：无（缩略词，由 laboratory 截短而来）
- **同义·反义**：同义 laboratory（实验室）；反义 无
- **变形**：名词 → 复数：复数 labs

### label  /ˈleɪbl/  〔CET4·CET6〕
- **释义**：n. 标签；标记，符号；vt. 贴标签于；把……称为
- **词源**：源自古法语 label（布条、飘带），可能来自日耳曼语系，与古弗里斯语 labba（破布）相关（存疑）。本义“悬挂的布条”，后指附在物品上的标签，引申为“标记、符号”及动词“贴标签、归类”。
- **同根词**：labelled（**label** + **-ed** 已贴标签的）；labelling（**label** + **-ing** 贴标签）；relabel（**re-** 再 + label 贴标签 = 重新贴标签）
- **词缀**：无（单纯词，源自法语）
- **同义·反义**：同义 tag（标签）, mark（标记）；反义 无
- **变形**：名词 → 复数：复数 labels；动词 → 三单 labels，过去式 labelled（英）/labeled（美），过去分词 labelled/labeled，现在分词 labelling/labeling；派生 → labelled adj. 贴有标签的；labelling n. 贴标签

### labor  /ˈleɪbə(r)/  〔高中〕
- **释义**：n. 劳动；工作；劳工；vi. 劳动；努力
- **词源**：拉丁语 labor（劳动、辛劳）→ 古法语 labour → 英语 labor（美式拼写）。本义“辛劳、劳作”，引申为“工作、劳工”及动词“劳动、努力”。
- **同根词**：laboratory（**labor** 劳动 + **-atory** 场所 = 实验室）；laborious（**labor** 劳动 + **-ious** 多……的 = 费力的）；collaborate（**col-** 共同 + labor 劳动 + **-ate** = 合作）；elaborate（**e-** 出 + labor 劳动 + **-ate** = 精心制作的）
- **词缀**：无（单纯词，源自拉丁语）
- **同义·反义**：同义 work（工作）, toil（辛劳）；反义 rest（休息）, leisure（闲暇）
- **变形**：名词 → 复数：复数 labors；动词 → 三单 labors，过去式 labored，过去分词 labored，现在分词 laboring；派生 → laborer n. 劳工；laborious adj. 费力的

### lunar  /ˈluːnə/  〔CET6〕
- **释义**：adj. 月的，月球的，阴历的
- **词源**：lun（月亮）+ -ar（形容词后缀，…的）→ 拉丁 lunaris（月的）→ 古法语 lunaire → 英语，本义“月亮的”→ 今义“月的，阴历的”。
- **同根词**：lunatic（疯子，lun 月 + -atic，古信月圆致疯）；lunation（朔望月，lun 月 + -ation）；sublunar（月下的，sub- 下 + lun 月 + -ar）；lunate（新月形的，lun 月 + -ate）
- **词缀**：-ar 表…的；例：solar（太阳的）、similar（相似的）
- **同义·反义**：同义 moonlike（似月的）；反义 solar（太阳的）
- **变形**：形容词 → 无比较级（绝对形容词）；派生 lunation n. 朔望月；lunar module n. 登月舱

### lunch  /lʌntʃ/  〔小学·初中·高中·CET4〕
- **释义**：n. 午餐；v. 吃午餐
- **词源**：可能由 luncheon（午餐）缩略而来，luncheon 来源不确定（存疑），或与古英语 nuncheon（中午点心）有关；本义“中午的便餐”，引申为“午餐”。

- **词缀**：无（单纯词）
- **同义·反义**：同义 midday meal（午餐）, luncheon（午餐）；反义 breakfast（早餐）, dinner（晚餐）
- **变形**：复数：lunches；第三人称单数：lunches；过去式：lunched；过去分词：lunched；现在分词：lunching

### lung  /lʌŋ/  〔高中·CET4〕
- **释义**：n. 肺脏，肺

- **词缀**：无（单纯词）
- **同义·反义**：同义 lights（肺，动物肺）；反义 无
- **变形**：复数：lungs

### lure  /ljʊə/  〔CET6〕
- **释义**：n. 引诱物，诱惑力；v. 引诱，诱惑
- **词源**：古法语 loirre（诱饵）→ 中古英语 lure → 英语 lure；本义“猎鹰用的诱饵”，引申为“引诱物、诱惑”。
- **同根词**：luring（诱人的），lurid（苍白的，可能同源，存疑）
- **词缀**：无（单纯词）
- **同义·反义**：同义 entice（引诱）, tempt（诱惑）；反义 repel（排斥）, deter（阻止）
- **变形**：复数：lures；第三人称单数：lures；过去式：lured；过去分词：lured；现在分词：luring；形容词：luring 诱人的

### luxury  /ˈlʌkʃəri/  〔CET4·CET6〕
- **释义**：n. 奢侈，奢华；奢侈品
- **词源**：拉丁 luxuria（过度、奢侈）→ 古法语 luxurie → 英语 luxury；本义“过度放纵”，引申为“奢侈、奢侈品”。
- **同根词**：luxurious（奢侈的），luxuriate（纵情享受），luxuriance（繁茂）
- **词缀**：无（单纯词）
- **同义·反义**：同义 extravagance（奢侈）, opulence（富裕）；反义 poverty（贫穷）, austerity（朴素）
- **变形**：复数：luxuries；形容词：luxurious 奢侈的；副词：luxuriously 奢侈地
