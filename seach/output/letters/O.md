# O

### o'clock  /əˈklɒk/  〔小学·初中·高中〕
- **释义**：adv. ……点钟
- **词源**：o'（of 的缩约）+ clock（钟）→ of the clock（按钟点）的缩略 → 英语 o'clock；本义“照钟面所示”，后固定为表示整点的副词。
- **同根词**：clock（钟）；clockwise（clock + -wise 方向后缀 = 顺时针的）；clockwork（clock + work = 钟表机构）；cloche（钟形罩，与 clock 同源）
- **词缀**：o' 为 of 的缩约形式，例：o'er（over 的诗歌缩约）
- **同义·反义**：同义 无（时间副词，无常用同义词）；反义 无
- **变形**：副词，无比较级、最高级变化；派生 → 无

### oak  /əʊk/  〔CET4·CET6〕
- **释义**：n. 栎属植物，橡树；栎木，橡木
- **词源**：源自古英语 āc（橡树），与古诺尔斯语 eik、德语 Eiche 同源，原始日耳曼语 *aiks；本义即“橡树”，后兼指其木材。
- **同根词**：oaken（oak + -en 形容词后缀 = 橡木制的）；oakum（源自古英语 ācumba，与 oak 同源存疑 = 填絮）；acorn（源自古英语 æcern，与 oak 同源 = 橡子）
- **词缀**：无（单纯词）
- **同义·反义**：同义 oak tree（橡树）；反义 无
- **变形**：名词 → 复数：复数 oaks；派生 → oaken adj. 橡木制的

### oar  /ɔːr/  〔CET4〕
- **释义**：n. 桨，橹
- **词源**：源自古英语 ār（桨），与古诺尔斯语 ár、德语 Ruder 同源，原始日耳曼语 *airō；本义即“划船的桨”。
- **同根词**：oarsman（oar + -s + man = 划桨者）；oarswoman（oar + -s + woman = 女划桨者）；oarage（oar + -age 名词后缀 = 划桨设备）；oarlock（oar + lock = 桨架）
- **词缀**：无（单纯词）
- **同义·反义**：同义 paddle（短桨）, scull（双桨）；反义 无
- **变形**：名词 → 复数：复数 oars；派生 → oarsman n. 划桨者；oarage n. 划桨设备

### oath  /əʊθ/  〔CET6〕
- **释义**：n. 誓言；辱骂
- **词源**：源自古英语 āþ（誓言），与古诺尔斯语 eiðr、德语 Eid 同源，原始日耳曼语 *aithaz；本义“宣誓”，后引申出“咒骂语”（因发誓时常带咒骂）。
- **同根词**：oath 的复合词 oath-taking（oath + taking = 宣誓）；swear（与 oath 义近，非同根）；oathbreaker（oath + breaker = 背誓者）；oathbound（oath + bound = 受誓言约束的）
- **词缀**：无（单纯词）
- **同义·反义**：同义 vow（誓约）, pledge（保证）；反义 无
- **变形**：名词 → 复数：复数 oaths；派生 → oathbreaker n. 背誓者；oathbound adj. 受誓言约束的

### obedient  /əˈbiːdiənt/  〔CET6〕
- **释义**：adj. 顺从的，听话的；adj. 服从的
- **词源**：词根 oboedire（听从）→ 拉丁 oboedientem（服从的）→ 古法语 obedient → 英语；由“愿意听从”引申为“顺从的、听话的”。
- **同根词**：obey（**ob-** 向 + audire 听 = 听从→服从）, obedience（**ob-** 向 + audire 听 + -ence 名词后缀 = 服从）, audience（audi 听 + -ence = 听众）, audio（audi 听 = 音频的）, inaudible（**in-** 不 + audi 听 + -ible 可…的 = 听不见的）
- **词缀**：前缀 ob-（向、朝向），例：obtain；后缀 -ent（形容词后缀，…的），例：different
- **同义·反义**：同义 compliant（顺从的）, submissive（服从的）；反义 disobedient（不服从的）, rebellious（叛逆的）
- **变形**：比较级 more obedient，最高级 most obedient；派生 obedience n. 服从；obediently adv. 顺从地

### obey  /əˈbeɪ/  〔初中·高中·CET4〕
- **释义**：v. 服从，听从；v. 遵守
- **词源**：词根 oboedire（听从）→ 拉丁 oboedire（ob- 向 + audire 听）→ 古法语 obeir → 英语；本义“侧耳倾听”，引申为“听从、服从”。
- **同根词**：obedient（**ob-** 向 + audire 听 + -ent = 顺从的）, obedience（**ob-** 向 + audire 听 + -ence = 服从）, audience（audi 听 + -ence = 听众）, audio（audi 听 = 音频的）, inaudible（**in-** 不 + audi 听 + -ible = 听不见的）
- **词缀**：前缀 ob-（向、朝向），例：object；无常见后缀（动词词干）

- **变形**：第三人称单数 obeys，过去式 obeyed，过去分词 obeyed，现在分词 obeying；派生 obedience n. 服从；obedient adj. 顺从的；obediently adv. 顺从地

### object  /ˈɑbdʒɛkt/  〔初中·高中·CET4·CET6〕
- **释义**：n. 物体，物品；n. 目标，对象；v. 反对
- **词源**：词根 objectum（投放在面前之物）→ 拉丁 obicere（ob- 对着 + jacere 投掷）→ 中世纪拉丁 objectum → 英语；本义“投在眼前的东西”，引申为“物体、对象”，动词义“把反对意见摆到面前→反对”。
- **同根词**：objection（**ob-** 对着 + jac 投 + -ion 名词后缀 = 反对）, objective（**ob-** 对着 + jac 投 + -ive = 客观的）, eject（**e-** 出 + ject 投 = 投出→驱逐）, project（**pro-** 向前 + ject 投 = 向前投→投射、项目）, reject（**re-** 回 + ject 投 = 投回→拒绝）
- **词缀**：前缀 ob-（对着、反对），例：obstacle；词根 -ject（投掷），例：inject
- **同义·反义**：同义 thing（东西）, item（物品）；反义 subject（主体）
- **变形**：复数 objects；第三人称单数 objects，过去式 objected，过去分词 objected，现在分词 objecting；派生 objection n. 反对；objective adj. 客观的；objector n. 反对者

### objection  /əbˈdʒekʃən/  〔CET4·CET6〕
- **释义**：n. 反对，异议；n. 不喜欢
- **词源**：词根 objectio（反对）→ 拉丁 obicere（ob- 对着 + jacere 投掷）的过去分词 objectus + -ion → 古法语 objection → 英语；由“把反对意见摆到面前”引申为“反对、异议”。
- **同根词**：object（**ob-** 对着 + ject 投 = 物体；反对）, objective（**ob-** 对着 + ject 投 + -ive = 客观的）, eject（**e-** 出 + ject 投 = 驱逐）, project（**pro-** 向前 + ject 投 = 投射）, reject（**re-** 回 + ject 投 = 拒绝）
- **词缀**：前缀 ob-（对着、反对），例：obscure；后缀 -ion（名词后缀，表行为或结果），例：action
- **同义·反义**：同义 protest（抗议）, dissent（异议）；反义 approval（赞成）, agreement（同意）
- **变形**：复数 objections；派生 object v. 反对；objectionable adj. 令人反感的；objectionably adv. 令人反感地

### objective  /əbˈdʒektɪv/  〔CET4·CET6〕
- **释义**：adj. 客观的，无偏见的；n. 目标，目的
- **词源**：词根 objectivus（与对象有关的）→ 中世纪拉丁 objectum（投在面前之物）+ -ivus → 法语 objectif → 英语；由“关于客体的”引申为“客观的”，名词义“所指向的目标”。
- **同根词**：object（**ob-** 对着 + ject 投 = 物体；反对）, objection（**ob-** 对着 + ject 投 + -ion = 反对）, eject（**e-** 出 + ject 投 = 驱逐）, project（**pro-** 向前 + ject 投 = 项目）, subject（**sub-** 在下 + ject 投 = 主体）
- **词缀**：前缀 ob-（对着），例：obtain；后缀 -ive（形容词后缀，…的），例：active
- **同义·反义**：同义 impartial（公正的）, unbiased（无偏见的）；反义 subjective（主观的）, biased（有偏见的）
- **变形**：比较级 more objective，最高级 most objective；复数 objectives；派生 objectively adv. 客观地；objectivity n. 客观性

### obligation  /ˌɑːblɪˈɡeɪʃn/  〔初中·CET6〕
- **释义**：n. 义务，责任；n. 恩惠
- **词源**：词根 obligatio（约束）→ 拉丁 obligare（ob- 向 + ligare 捆绑）的过去分词 obligatus + -ion → 古法语 obligation → 英语；本义“被捆绑住”，引申为“受约束的义务、责任”。
- **同根词**：oblige（**ob-** 向 + lig 捆绑 = 迫使；施恩）, obligatory（**ob-** 向 + lig 捆绑 + -atory = 义务的）, league（lig 捆绑→结盟）, liable（lig 捆绑→有责任的）, religion（**re-** 再 + lig 捆绑 + -ion = 宗教）
- **词缀**：前缀 ob-（向、朝向），例：observe；后缀 -ion（名词后缀，表行为或状态），例：action
- **同义·反义**：同义 duty（义务）, responsibility（责任）；反义 right（权利）, option（选择权）
- **变形**：复数 obligations；派生 oblige v. 迫使；obligatory adj. 义务的；obligated adj. 有义务的

### own  /oʊn/  〔初中·高中·CET4〕

- **词源**：古英语 agen（自己的）→ 中古英语 owen → 英语；由“属于自己的”引申出动词“拥有”。
- **同根词**：owner（own 拥有 + -er 人 = 所有者）, ownership（owner 所有者 + -ship 名词后缀 = 所有权）, owe（owe 欠 = 欠）〔同源〕
- **词缀**：无（单纯词）
- **同义·反义**：同义 possess（拥有）, personal（个人的）；反义 无
- **变形**：形容词 → 无比较级；动词 → 第三人称单数：owns；过去式：owned；过去分词：owned；现在分词：owning；名词派生：owner n. 所有者；ownership n. 所有权

### owner  /ˈəʊnə(r)/  〔初中·高中·CET4〕
- **释义**：n. 物主，所有人
- **词源**：词根 own（拥有）+ 后缀 -er（表人）+ 古英语 āgan（拥有）→ 中古英语 owen → 英语 own + -er；本义“拥有者”，即对某物享有所有权的人。
- **同根词**：own（拥有）；ownership（owner + **-ship** 身份 = 所有权）；owe（古英语 āgan 拥有→欠）；ought（同源，欠）
- **词缀**：后缀 **-er** 表“做某事的人”，例：teacher（教师）、worker（工人）
- **同义·反义**：同义 proprietor（业主）, possessor（持有者）；反义 tenant（租户）, borrower（借用人）
- **变形**：名词 → 复数：复数 owners；派生 → ownership n. 所有权；own v. 拥有

### ownership  /ˈəʊnəʃɪp/  〔高中·CET4〕
- **释义**：n. 所有（权），所有制
- **词源**：词根 own（拥有）+ 后缀 -er（者）+ 后缀 -ship（身份、状态）+ 古英语 āgan（拥有）→ 英语 owner + -ship；本义“所有者身份”，引申为法律上的所有权、所有制。
- **同根词**：owner（所有者）；own（拥有）；owe（同源，欠）；ought（同源，欠）
- **词缀**：后缀 **-ship** 表“身份、状态”，例：friendship（友谊）、membership（会员资格）
- **同义·反义**：同义 possession（占有）, proprietorship（所有权）；反义 无
- **变形**：名词 → 复数：复数 ownerships（少用）；派生 → owner n. 所有者；own v. 拥有

### ox  /ɒks/  〔高中·CET4〕
- **释义**：n. 牛；公牛，阉牛
- **词源**：词根 ok̑s-（牛，印欧语）+ 古英语 oxa → 中古英语 ox → 英语 ox；本义“牛”，特指阉割过的公牛，复数 oxen 保留古英语 -en 复数。
- **同根词**：oxen（ox + 古英语复数 **-en** = 牛，复数）；oxford（Ox + ford 渡口 = 牛津，地名）；oxeye（ox + eye 眼 = 牛眼菊）；oxbow（ox + bow 弯 = 牛轭弯）
- **词缀**：无（单纯词，日耳曼语源）
- **同义·反义**：同义 bull（公牛）, steer（阉牛）；反义 cow（母牛）
- **变形**：名词 → 复数：复数 oxen；派生 → oxen n. 牛（复数形式）

### oxide  /ˈɒksaɪd/  〔CET6〕
- **释义**：n. 氧化物
- **词源**：词根 oxy-（氧，希腊语 oxys 酸、尖锐）+ 后缀 -ide（化合物）+ 法语 oxide → 英语 oxide；本义“与氧化合的化合物”，由“酸”引申为氧的化合物。
- **同根词**：oxygen（oxy- 氧 + **-gen** 产生 = 氧）；dioxide（**di-** 二 + oxide = 二氧化物）；monoxide（**mono-** 一 + oxide = 一氧化物）；hydroxide（**hydro-** 水 + oxide = 氢氧化物）
- **词缀**：前缀 **oxy-** 表“氧、酸”，例：oxygen（氧）、oxymoron（矛盾修辞，存疑）；后缀 **-ide** 表“化合物”，例：chloride（氯化物）
- **同义·反义**：同义 无；反义 无
- **变形**：名词 → 复数：复数 oxides；派生 → oxidize v. 氧化；oxidation n. 氧化；oxidic adj. 氧化物的

### oxygen  /ˈɒksɪdʒən/  〔初中·高中·CET6〕
- **释义**：n. 氧；氧气
- **词源**：词根 oxy-（酸，希腊语 oxys 尖锐）+ 后缀 -gen（产生）+ 法语 oxygène → 英语 oxygen；本义“产生酸的元素”，因早期化学家认为氧是成酸要素而得名。
- **同根词**：oxide（oxy- + **-ide** 化合物 = 氧化物）；dioxide（**di-** 二 + oxide = 二氧化物）；oxygenate（oxygen + **-ate** 使… = 氧化）；oxygenation（oxygenate + **-ion** 名词 = 氧化作用）
- **词缀**：前缀 **oxy-** 表“氧、酸”，例：oxide（氧化物）；后缀 **-gen** 表“产生者”，例：hydrogen（氢）、nitrogen（氮）
- **同义·反义**：同义 O₂（氧气分子）；反义 无
- **变形**：名词 → 复数：复数 oxygens（少用）；派生 → oxygenate v. 氧化；oxygenation n. 氧化；oxygenous adj. 含氧的

### ozone  /ˈəʊzəʊn/  〔CET6〕
- **释义**：n. 臭氧
- **词源**：词根 oz-（气味，希腊语 ozein 闻）+ 后缀 -one（化学名词）+ 法语 ozone → 英语 ozone；本义“有气味的物质”，因臭氧有特殊臭味而得名。
- **同根词**：ozonic（ozone + **-ic** …的 = 臭氧的）；ozonize（ozone + **-ize** 使… = 臭氧化）；ozonosphere（ozone + **-sphere** 层 = 臭氧层）；ozonide（ozone + **-ide** 化合物 = 臭氧化物）
- **词缀**：后缀 **-one** 表化学物质，例：acetone（丙酮）；前缀 **oz-** 表“气味”，例：ozone（臭氧）
- **同义·反义**：同义 O₃（臭氧分子）；反义 无
- **变形**：名词 → 复数：复数 ozones（少用）；派生 → ozonic adj. 臭氧的；ozonize v. 臭氧化；ozonation n. 臭氧化
