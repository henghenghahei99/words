# I

### I  /aɪ/  〔初中·CET4〕
- **释义**：pron. 我；n. 自我；n. 字母 I
- **词源**：原始印欧语 *egom（我）→ 古英语 ic（我）→ 中古英语 I，本义“说话者自身”，后固定为第一人称单数主格代词。
- **同根词**：me（我，宾格）；my（我的）；mine（我的）；myself（我本人）
- **词缀**：无（单纯词）
- **同义·反义**：同义 me（我，宾格）, myself（我自己）；反义 you（你）, he（他）
- **变形**：代词 → 主格 I、宾格 me、形容词性物主代词 my、名词性物主代词 mine、反身代词 myself；名词 → 复数：复数 I's 或 Is（字母 I 的复数）

### i.e  /ˌaɪˈiː/  〔CET4〕
- **释义**：abbr. 那就是，即（= that is）；abbr. 换言之
- **词源**：拉丁语 id est（那就是）的缩写，id（那个）+ est（是）→ 英语 i.e.，本义“也就是说”，用于进一步解释前文。
- **同根词**：id（id 那个，拉丁语）；est（est 是，拉丁语）；e.g.（exempli gratia 例如）；etc.（et cetera 等等）
- **词缀**：无（缩写词）
- **同义·反义**：同义 that is（那就是）, namely（即）；反义 无
- **变形**：无词形变化（缩写词，固定形式）

### ice  /aɪs/  〔初中·高中·CET4〕
- **释义**：n. 冰；vt. 使结冰，冰镇
- **词源**：日耳曼语 *īsa-（冰）→ 古英语 īs（冰）→ 中古英语 is → 英语 ice；本义即“冰”，后作动词表“使结冰、冰镇”。
- **同根词**：icy（ic 冰 + -y …的 = 冰冷的）；icicle（ice 冰 + 古英语 gicel 冰柱 = 冰柱）；Iceland（ice 冰 + land 土地 = 冰岛）；icing（ice + -ing 名词后缀 = 糖霜）
- **词缀**：无（单纯词）
- **同义·反义**：同义 frost（霜）, rime（白霜）；反义 fire（火）, heat（热）
- **变形**：名词 → 复数：复数 ices；动词 → 第三人称单数：第三人称单数 ices；过去式：iced；过去分词：iced；现在分词：icing；形容词派生 icy adj. 冰冷的；动词派生 iced adj. 冰镇的

### ice-cream  /aɪs-kriːm/  〔初中·高中·CET4〕
- **释义**：n. 冰淇淋
- **词源**：ice（冰）+ cream（奶油）复合而成；cream 源自拉丁 crāmum（奶油）→ 古法语 cresme → 英语 cream；本义“冰镇奶油”，后指冰淇淋。
- **同根词**：cream（拉丁 crāmum 奶油 → 英语 cream = 奶油）；creamy（cream + -y …的 = 奶油般的）；iceberg（ice 冰 + 荷兰语 berg 山 = 冰山）；icebox（ice 冰 + box 箱 = 冰箱）
- **词缀**：无（复合词）
- **同义·反义**：同义 frozen dessert（冷冻甜点）, gelato（意式冰淇淋）；反义 无
- **变形**：名词 → 复数：复数 ice-creams；形容词派生 ice-cream adj. 冰淇淋的

- **变形**：名词 → 复数：复数 ideas；形容词派生 ideal adj. 理想的；副词派生 ideally adv. 理想地

- **变形**：名词 → 复数：Italians；词性派生 → Italy n. 意大利；形容词 → 无比较级（关系/专有形容词，不作比较）

### item  /ˈaɪtəm/  〔初中·CET4·CET6〕
- **释义**：n. 一件商品（或物品）；项目，条款
- **词源**：拉丁 item（同样地，又）→ 英语；本义“同样、又一项”，引申为“一项、一件物品”。
- **同根词**：itemize（item 项目 + **-ize** 动词后缀 = 逐项列出）；itemization（itemize + **-ation** 名词后缀 = 逐项列出）；iterate（**iter-** 再次 + -ate = 重复）
- **词缀**：无（单纯词，源自拉丁 item）；例：itemize（逐项列出）
- **同义·反义**：同义 article（物品）, entry（条目）；反义 whole（整体）
- **变形**：复数 items；派生：itemize v. 逐项列出；itemized adj. 逐项列出的；itemization n. 逐项列出

### its  /ɪts/  〔初中·高中·CET4〕
- **释义**：pron. 它的（it 的所有格）
- **词源**：it（它）+ -s（所有格后缀）→ 英语；本义“它的”，指代事物或动物的所属。
- **同根词**：it（它）；itself（it + **self** 自己 = 它自己）；they（他们）；their（他们的）
- **词缀**：后缀 -s（所有格后缀）；例：hers（她的），ours（我们的）
- **同义·反义**：同义 无；反义 无
- **变形**：无（代词所有格，无复数、比较级等变化）

### itself  /ɪtˈself/  〔初中·高中·CET4〕
- **释义**：pron. 它自己，它本身
- **词源**：it（它）+ self（自己）→ 英语；本义“它自己”，用于强调或反身指代。
- **同根词**：it（它）；its（它的）；myself（**my-** 我的 + self 自己 = 我自己）；yourself（**your-** 你的 + self 自己 = 你自己）
- **词缀**：后缀 -self（自己）；例：himself（他自己），themselves（他们自己）
- **同义·反义**：同义 无；反义 无
- **变形**：复数 themselves；派生：无

### ivory  /ˈaɪvəri/  〔CET6〕
- **释义**：n. 象牙，牙质；n. 象牙色，乳白色；adj. 象牙制的，象牙色的，乳白色的
- **词源**：词根 ebur（象牙）← 拉丁 ebur/eboreus（象牙的）→ 古法语 ivurie → 英语；本义“象牙”，由象牙的颜色引申为“象牙色、乳白色”。
- **同根词**：eburnean（eburn 象牙 + -ean …的 = 象牙般的）（较生僻）；同族常用词较少，其余存疑
- **词缀**：后缀 -y（名词后缀，表物或性质）；例：-y：rosy（玫瑰色的）
- **同义·反义**：同义 tusk（象牙，长牙）, cream（乳白色）；反义 无
- **变形**：名词 → 复数：ivories；词性派生 → ivory adj. 象牙色的（本词兼作形容词）；形容词 → 无比较级（关系/专有形容词，不作比较）
