# X

### X-ray  /ˈeks reɪ/  〔初中·高中·CET4〕
- **释义**：n. X射线；X光；X光片
- **词源**：X（未知数符号）+ ray（射线）；ray 源自拉丁 radius（光线、辐条），1895 年伦琴因不知此射线性质而以数学符号 X 命名，本义“未知射线”引申为“X光”。
- **同根词**：ray（射线，复合成分）；X-rayed（照X光的，X-ray + -ed）；X-raying（照X光，X-ray + -ing）
- **词缀**：无（复合词，X + ray）
- **同义·反义**：同义 radiograph（X光片）, Roentgen ray（伦琴射线）；反义 无
- **变形**：名词 → 复数：复数 X-rays；动词 → 第三人称单数：X-rays；过去式：X-rayed；过去分词：X-rayed；现在分词：X-raying；派生 X-rayed adj. 照过X光的
