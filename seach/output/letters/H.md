### habit  /ˈhæbɪt/  〔初中·高中·CET4〕
- **释义**：n. 习惯；n. 习性
- **词源**：词根 habit（持有、状态），源自拉丁语 habitus（状态、举止），为 habēre（持有）的过去分词；经古法语 abit 进入英语；由“持有的状态”引申为“习惯、习性”。
- **同根词**：habitat（**habit** 居住 + -at 场所 = 栖息地）；inhabit（**in-** 在内 + habit 居住 = 居住于）；habitual（**habit** 习惯 + -ual …的 = 习惯性的）；habituate（**habit** 习惯 + -uate 使 = 使习惯）
- **词缀**：无（单纯词）
- **同义·反义**：同义 custom（习俗）, practice（惯例）；反义 无
- **变形**：名词 → 复数：复数 habits；形容词派生 → habitual adj. 习惯性的；动词派生 → habituate v. 使习惯；名词派生 → habituation n. 习惯化

### habitual  /həˈbitjuəl/  〔CET4〕
- **释义**：a. 习惯性的，惯常的
- **词源**：词根 habit（拥有、习性）+ 后缀 -ual（形容词后缀）+ 拉丁 habitus（状态、习性）→ 英语 habitual；本义“与习性有关的”，引申为“习惯性的、惯常的”。
- **同根词**：habit（**habit** 习性 = 习惯）, habituate（**habit** 习性 + -uate 动词后缀 = 使习惯）, inhabit（**in-** 在内 + habit 居住 = 居住于）, habitat（**habit** 居住 + -at 名词后缀 = 栖息地）, habitué（**habit** 习性 + -ué 人 = 常客）
- **词缀**：后缀 -ual 构成形容词，表“…的”，例：habitual（习惯性的）；无前缀。
- **同义·反义**：同义 customary（惯常的）, usual（通常的）, routine（例行的）；反义 occasional（偶尔的）, unusual（不寻常的）
- **变形**：形容词 → 无比较级；词性派生 → 名词：habit n. 习惯；habitualness n. 习惯性；副词：habitually adv. 习惯性地
