# J

### jacket  /ˈdʒækɪt/  〔小学·初中·高中·CET4〕
- **释义**：n. 夹克，短外套；护封，书套
- **词源**：古法语 jaquet（短上衣）→ 英语；本义“短上衣”，引申为“护封、外套”。
- **同根词**：jack（**jack-** 男子，源自人名 = 千斤顶，插孔）；jacketless（jacket + **-less** 无…的 = 无外套的）；jacketed（jacket + **-ed** 有…的 = 有护套的）
- **词缀**：后缀 -et（小称后缀，表“小”）；例：pocket（口袋），bullet（子弹）
- **同义·反义**：同义 coat（外套）, blazer（西装外套）；反义 无
- **变形**：复数 jackets；派生：jacketed adj. 有护套的；jacketless adj. 无外套的

### jail  /dʒeɪl/  〔CET4〕
- **释义**：n. 监狱；vi. 监禁
- **词源**：拉丁 cavea（笼子）→ 古法语 jaiole（监狱）→ 英语；本义“笼子、囚禁处”，引申为“监狱、监禁”。
- **同根词**：jailer（jail 监狱 + **-er** 人 = 狱卒）；jailbreak（jail + **break** 打破 = 越狱）；cage（拉丁 cavea 笼子 = 笼子）；cave（拉丁 cavus 洞穴 = 洞穴）
- **词缀**：无（单纯词，源自拉丁 cavea）；例：jailer（狱卒）
- **同义·反义**：同义 prison（监狱）, imprison（监禁）；反义 release（释放）, free（释放）
- **变形**：复数 jails；三单 jails；过去式 jailed；过去分词 jailed；现在分词 jailing；派生：jailer n. 狱卒；jailbreak n. 越狱

### jam  /dʒæm/  〔初中·高中·CET4〕
- **释义**：n. 果酱；阻塞；v. 挤满，堵塞
- **词源**：词源存疑；一说源自中古英语 jam（挤压），与法语 jambon（火腿）无直接关系；果酱义可能由“压碎水果”引申，阻塞义由“挤压”引申。
- **同根词**：jammed（**jam** 挤压 + -ed 形容词后缀 = 挤满的）；jamming（**jam** 挤压 + -ing 名词后缀 = 干扰）；jam-pack（**jam** 挤压 + pack 塞满 = 塞满）；traffic jam（traffic 交通 + **jam** 阻塞 = 交通堵塞）
- **词缀**：无（单纯词）
- **同义·反义**：同义 jelly（果酱）, congestion（阻塞）；反义 无
- **变形**：名词复数：jams；动词第三人称单数：jams；过去式：jammed；过去分词：jammed；现在分词：jamming；形容词派生：jammed adj. 挤满的

### January  /ˈdʒænjʊərɪ; (US) ˈdʒænjʊerɪ/  〔初中·CET4〕
- **释义**：n. 一月
- **词源**：词根 Janu-（罗马门神雅努斯 Janus）+ -ary（名词后缀，表“与…有关”）；拉丁 Januarius → 古法语 janvier → 英语 January；因雅努斯司门户与开端，故指一年之始的月份。
- **同根词**：Janus（雅努斯，罗马门神）；janitor（看门人，源自拉丁 janitor 守门者）；janiform（有两副面孔的，源自 Janus）；January 的变体 Januarius（拉丁语一月）
- **词缀**：-ary（名词后缀，表“与…有关的物/月”）；例：February（二月）, library（图书馆）
- **同义·反义**：同义 无；反义 无
- **变形**：名词 → 复数：Januaries（罕见复数，通常作专有名词无复数）；派生 → January 无常见派生词

### Japan  /dʒæˈpæn/  〔小学·初中·CET4〕
- **释义**：n. 日本
- **词源**：词源存疑；通行说法为源自汉语“日本”（字面“日出之地”），经马来语 Japang 或葡萄牙语 Japão 进入英语；本义即“日出之国”，今为日本国名。

- **词缀**：无（专有名词，单纯词）
- **同义·反义**：同义 无；反义 无
- **变形**：名词 → 复数：无复数（专有名词）；派生 → Japanese adj. 日本的 n. 日本人；Japanize v. 使日本化

### junior  /ˈdʒuːnɪə(r)/  〔初中·高中·CET4〕
- **释义**：a. 初级的；年少的；n. 年少者；下级
- **词源**：词根 jun-（年轻，源自拉丁 iunior，juvenis 的比较级）+-ior（比较级后缀）→ 拉丁 junior → 英语；本义“更年轻的”，引申为“级别较低的”。
- **同根词**：juvenile（juven 年轻 + -ile = 少年的）, rejuvenate（re- 再 + juven 年轻 + -ate = 使恢复青春）, juniors（junior 的复数）
- **词缀**：前缀 re- 表“再”，例：rejuvenate（使恢复青春）；后缀 -ior 表比较级，例：senior（年长的）
- **同义·反义**：同义 younger（较年轻的）, subordinate（下级的）；反义 senior（年长的；高级的）
- **变形**：复数 juniors；比较级无（本身为比较级形式）；派生 juniority n. 年少；下级地位

### junk  /dʒʌŋk/  〔CET6〕
- **释义**：n. 无用的或无价值的东西；n. 废旧杂物
- **词源**：词源存疑，一说源自中古英语 junk（旧缆绳、碎木），可能与古法语 jonc（芦苇）相关；本指船上废旧绳索，后泛指废旧杂物。
- **同根词**：junky（junk + -y 劣质的；吸毒者）, junkie（junk + -ie 吸毒成瘾者）, junket（junk 相关，凝乳食品；公费旅游）
- **词缀**：后缀 -y 表“具有…性质的”，例：junky（劣质的）；后缀 -ie 表“人”，例：junkie（成瘾者）
- **同义·反义**：同义 rubbish（垃圾）, trash（废物）；反义 treasure（珍宝）
- **变形**：复数 junks；派生 junky adj. 劣质的；n. 吸毒者；junky 比较级 junkier, 最高级 junkiest

### jury  /ˈdʒuəri/  〔CET4·CET6〕
- **释义**：n. 陪审团；n. 评奖团
- **词源**：词根 jur-（发誓，源自拉丁 iurare 发誓）+-y（名词后缀）→ 古法语 juree（宣誓）→ 英语 jury；本义“宣誓的一群人”，引申为陪审团。
- **同根词**：juror（jur 发誓 + -or 人 = 陪审员）, jurist（jur 法律 + -ist 人 = 法学家）, justice（just 公正 + -ice = 正义）, injure（in- 不 + jur 法 = 伤害，存疑）
- **词缀**：后缀 -or 表“人”，例：juror（陪审员）；后缀 -ist 表“人”，例：jurist（法学家）
- **同义·反义**：同义 panel（陪审团；专门小组）；反义 无
- **变形**：复数 juries；派生 juror n. 陪审员；jury 无其他词性变化

### just  /dʒʌst/  〔小学·初中·高中·CET4〕
- **释义**：ad. 只是；正好；a. 公正的
- **词源**：词根 just-（公正，源自拉丁 iustus 公正的）→ 古法语 juste → 英语；本义“公正的”，副词义“正好、仅仅”由“恰好合乎”引申。
- **同根词**：justice（just 公正 + -ice = 正义）, justify（just 公正 + -ify 使 = 证明正当）, unjust（un- 不 + just 公正 = 不公正的）, justly（just + -ly 公正地）
- **词缀**：前缀 un- 表“不”，例：unjust（不公正的）；后缀 -ly 表副词，例：justly（公正地）
- **同义·反义**：同义 fair（公平的）, exactly（正好）；反义 unjust（不公正的）
- **变形**：形容词比较级 juster, 最高级 justest；副词无比较级；派生 justice n. 正义；justly adv. 公正地；justness n. 公正

### justice  /ˈdʒʌstis/  〔高中·CET4〕
- **释义**：n. 正义，公正；n. 司法
- **词源**：词根 just-（公正，拉丁 iustus）+-ice（名词后缀）→ 拉丁 iustitia → 古法语 justice → 英语；由“公正”引申指“司法制度”。
- **同根词**：just（公正的）, justify（证明正当）, unjust（不公正的）, justly（公正地）
- **词缀**：后缀 -ice 表“性质/状态”，例：justice（正义）；前缀 un- 表“不”，例：unjust（不公正的）
- **同义·反义**：同义 fairness（公平）, equity（公正）；反义 injustice（不公正）
- **变形**：复数 justices；派生 just adj. 公正的；justly adv. 公正地

### justify  /ˈdʒʌstɪfaɪ/  〔CET4〕
- **释义**：vt. 证明…是正当的；为…辩护；说明…有理
- **词源**：词根 just（公正的）+ 拉丁语 iustificare（使公正）→ 古法语 justifier → 英语 justify；本义“使合乎公正”，引申为“证明正当、辩护”。
- **同根词**：justice（just 公正 + -ice 名词后缀 = 正义）, just（公正的）, unjust（un- 不 + just 公正 = 不公正的）, justification（just 公正 + -ification 使…化 = 正当理由）
- **词缀**：后缀 -ify 表“使…化、使成为”，例：simplify（简化）；词根 just- 表“公正”
- **同义·反义**：同义 defend（辩护）, vindicate（证明无罪）；反义 condemn（谴责）
- **变形**：动词 → 第三人称单数：justifies；过去式：justified；过去分词：justified；现在分词：justifying；派生 → justification n. 正当理由；justifiable adj. 可辩护的；justifiably adv. 正当地
